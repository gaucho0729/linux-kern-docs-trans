ACPIデバッグ出力¶

ACPI CA（ACPI デバッグ出力の実装）、Linux の ACPI コア、一部の ACPI ドライバはデバッグ出力を生成できます。このドキュメントでは、この機能の使い方について説明します。

コンパイル時の設定¶

ACPI デバッグ出力は CONFIG_ACPI_DEBUG によってグローバルに有効になります。この設定オプションがオフの場合、デバッグメッセージはカーネルに組み込まれることすらありません。

ブート時および実行時での設定¶

CONFIG_ACPI_DEBUG=y の場合、興味のあるコンポーネントとメッセージレベルを選択できます。ブート時に acpi.debug_layer および acpi.debug_level というカーネルコマンドラインオプションを使用します。ブート後は、/sys/module/acpi/parameters/ 以下の debug_layer および debug_level ファイルを編集することでデバッグメッセージを制御できます。

debug_layer（コンポーネント）¶

「debug_layer」は、興味のあるコンポーネント（特定のドライバや ACPI 解釈器の一部など）を選択するためのマスクです。debug_layer ビットマスクを構築するには、ACPI ソースファイル内の「#define _COMPONENT」を確認してください。

ブート時に acpi.debug_layer コマンドライン引数を使用して debug_layer マスクを設定でき、ブート後は /sys/module/acpi/parameters/debug_layer に値を書き込むことで変更できます。

可能なコンポーネントは include/acpi/acoutput.h および include/acpi/acpi_drivers.h に定義されています。/sys/module/acpi/parameters/debug_layer を読み込むと、現在サポートされているマスク値が表示されます（現在の値は以下の通り）：

debug_level¶

「debug_level」は、メッセージの種類（初期化関連、メソッド実行、情報メッセージなど）を選択するためのマスクです。debug_level を構築するには、ACPI_DEBUG_PRINT() ステートメント内のレベルを確認してください。

ACPI 解釈器は複数のレベルを使用しますが、Linux の ACPI コアおよび ACPI ドライバは一般的に ACPI_LV_INFO だけを使用します。

ブート時に acpi.debug_level コマンドライン引数を使用して debug_level マスクを設定でき、ブート後は /sys/module/acpi/parameters/debug_level に値を書き込むことで変更できます。

可能なレベルは include/acpi/acoutput.h に定義されています。/sys/module/acpi/parameters/debug_level を読み込むと、現在サポートされているマスク値が表示されます（現在の値は以下の通り）：

例¶

たとえば、drivers/acpi/bus.c には以下が含まれています：

#define _COMPONENT              ACPI_BUS_COMPONENT
...
ACPI_DEBUG_PRINT((ACPI_DB_INFO, "Device insertion detected\n"));

このメッセージを有効にするには、acpi.debug_layer に ACPI_BUS_COMPONENT ビットを設定し、acpi.debug_level に ACPI_LV_INFO ビットを設定してください。（ACPI_DEBUG_PRINT ステートメントは ACPI_DB_INFO を使用しますが、これは ACPI_LV_INFO の定義に基づくマクロです。）

ブート時に AML の「Debug」出力（AML 解釈中に Debug オブジェクトへの保存）をすべて有効にする：

acpi.debug_layer=0xffffffff acpi.debug_level=0x2

PCI および PCI インターリーブド ルーティングのデバッグメッセージを有効にする：

acpi.debug_layer=0x400000 acpi.debug_level=0x4

すべてのACPIハードウェア関連メッセージを有効にする:

acpi.debug_layer=0x2 acpi.debug_level=0xffffffff

起動後にすべてのACPI_DB_INFOメッセージを有効にする:

# echo 0x4 > /sys/module/acpi/parameters/debug_level

すべての有効なコンポーネント値を表示:

# cat /sys/module/acpi/parameters/debug_layer
