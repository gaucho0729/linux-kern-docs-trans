このドキュメントでは、Linuxカーネルに埋め込まれたAMLデバッガーの使用方法について説明しています。

1. デバッガーのビルド¶

LinuxカーネルからAMLデバッガーインターフェースを有効にするには、以下のカーネルの構成項目が必要です：

CONFIG_ACPI_DEBUGGER=y
CONFIG_ACPI_DEBUGGER_USER=m

以下のコマンドを使用して、カーネルソースツリーからユーザースペースユーティリティをビルドできます：

$ cd tools
$ make acpi

結果として得られるユーザースペースツールのバイナリは、以下にあります：

tools/power/acpi/acpidbg

「make install」を実行することで、システムディレクトリにインストールできます（十分な権限を持つユーザーとして実行してください）。

2. ユーザースペースデバッガーインターフェースの起動¶

デバッガーが埋め込まれたカーネルを起動した後、以下のコマンドを使用してデバッガーを起動できます：

# mount -t debugfs none /sys/kernel/debug
# modprobe acpi_dbg
# tools/power/acpi/acpidbg

インタラクティブなAMLデバッガー環境を生成し、デバッガーコマンドを実行できます。

コマンドは、「ACPICA概要とプログラマーリファレンス」ドキュメントに記載されており、以下からダウンロードできます：

https://acpica.org/documentation

詳細なデバッガーコマンドリファレンスは、第12章「ACPICAデバッガーリファレンス」にあります。『help』コマンドを使用すると、素早く参照できます。

3. ユーザースペースデバッガーインターフェースの停止¶

インタラクティブなデバッガーインターフェースは、Ctrl+Cを押すか、「quit」または「exit」コマンドを使用して閉じられます。完了したら、以下のコマンドでモジュールをアンロードしてください：

# rmmod acpi_dbg

acpidbgのインスタンスが実行されている場合、モジュールのアンロードに失敗する可能性があります。

4. スクリプトでデバッガーを実行¶

テストスクリプトでAMLデバッガーを実行するのも役立ちます。「acpidbg」は特別な「バッチモード」でこれをサポートしています。例えば、以下のコマンドはすべてのACPI名前空間を出力します：

# acpidbg -b "namespace"
