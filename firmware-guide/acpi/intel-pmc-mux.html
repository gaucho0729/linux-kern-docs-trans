Intel North Mux-Agent¶

はじめに¶

North Mux-Agent は、Intel PMC ファームウェアの機能であり、PMC マイクロコントローラーを搭載したほとんどの Intel ベースプラットフォームでサポートされています。これは、システム内のさまざまな USB マルチプレクサ/デマルチプレクサを設定するために使用されます。オペレーティングシステムから mux-agent を設定可能なプラットフォームでは、ACPI デバイスオブジェクト（ノード）で HID 「INTC105C」が割り当てられたノードが存在します。

North Mux-Agent（通称：Intel PMC マルチコントロール、または単に mux-agent）ドライバーは、PMC マイクロコントローラーと通信するために PMC IPC メソッド（drivers/platform/x86/intel_scu_ipc.c）を使用します。このドライバーは USB Type-C マルチクラスに登録され、USB Type-C コントローラーおよびインターフェースドライバーがケーブルプラグの向きとモード（代替モードを含む）を設定できるようになります。また、USB ロールクラスにも登録されており、USB ホストモードとデバイスマードの両方をサポートしています。ドライバーは以下にあります：drivers/usb/typec/mux/intel_pmc_mux.c。

ポートノード¶

一般¶

システム内のmux-agentの制御下にあるすべてのUSB Type-Cコネクタに対して、PMC mux-agentデバイスノードの下に個別の子ノードが存在します。これらのノードは実際のコネクタを表すのではなく、コネクタに関連するmux-agent内の「チャンネル」を表します。

Scope (_SB.PCI0.PMC.MUX)
{
    Device (CH0)
    {
        Name (_ADR, 0)
    }

    Device (CH1)
    {
        Name (_ADR, 1)
    }
}

_PLD（デバイスの物理的位置）¶

オプションの_PLDオブジェクトはポート（チャンネル）ノードと併用できます。_PLDが提供されている場合、その値はコネクタノードの_PLDと一致する必要があります。

Scope (_SB.PCI0.PMC.MUX)
{
    Device (CH0)
    {
        Name (_ADR, 0)
        Method (_PLD, 0, NotSerialized)
        {
            /* Consider this as pseudocode. */
            Return (\_SB.USBC.CON0._PLD())
        }
    }
}

mux-agent固有の_DSDデバイスプロパティ¶

ポート番号¶

USB Type-Cコネクタの背後にあるmuxを設定するためには、PMCファームウェアがそのコネクタに関連するUSB2ポートとUSB3ポートを把握する必要があります。ドライバーは「usb2-port-number」と「usb3-port-number」という特定の_DSDデバイスプロパティを読み取ることで正しいポート番号を抽出します。これらのプロパティは整数値を持ち、ポートインデックスを表します。ポートインデックスは1ベースで、値0は無効です。ドライバーはこれらのデバイスプロパティから抽出した数値を変更することなく、PMCへのmux-agent固有メッセージ送信時に使用します。

Name (_DSD, Package () {
    ToUUID("daffd814-6eba-4d8c-8a91-bc9bbf4aa301"),
    Package() {
        Package () {"usb2-port-number", 6},
        Package () {"usb3-port-number", 3},
    },
})

向き¶

プラットフォームによっては、コネクタから来るデータおよびSBUラインが「固定」されている可能性があり、これはmux-agentの観点から見ると、mux-agentドライバーがケーブルプラグの向きに基づいて設定を行わないことを意味します。たとえば、プラットフォーム上のリテイマがケーブルプラグの向きを処理している場合などです。ドライバーは、これらのラインが「固定」されているかを確認するため、特定のデバイスプロパティ「sbu-orientation」（SBU）および「hsl-orientation」（データ）を使用します。これらのプロパティの値は文字列であり、「USB Type-Cコネクタの向き」で定義された「normal」（通常）または「reversed」（逆）のいずれかです:

Name (_DSD, Package () {
    ToUUID("daffd814-6eba-4d8c-8a91-bc9bbf4aa301"),
    Package() {
        Package () {"sbu-orientation", "normal"},
        Package () {"hsl-orientation", "normal"},
    },
})

例: ASL¶

以下のASLは、mux-agentノードとその制御下にある2つのコネクタを示す例です:

Scope (_SB.PCI0.PMC)
{
    Device (MUX)
    {
        Name (_HID, "INTC105C")

        Device (CH0)
        {
            Name (_ADR, 0)

            Name (_DSD, Package () {
                ToUUID("daffd814-6eba-4d8c-8a91-bc9bbf4aa301"),
                Package() {
                    Package () {"usb2-port-number", 6},
                    Package () {"usb3-port-number", 3},
                    Package () {"sbu-orientation", "normal"},
                    Package () {"hsl-orientation", "normal"},
                },
            })
        }

        Device (CH1)
        {
            Name (_ADR, 1)

            Name (_DSD, Package () {
                ToUUID("daffd814-6eba-4d8c-8a91-bc9bbf4aa301"),
                Package() {
                    Package () {"usb2-port-number", 5},
                    Package () {"usb3-port-number", 2},
                    Package () {"sbu-orientation", "normal"},
                    Package () {"hsl-orientation", "normal"},
                },
            })
        }
    }
}
