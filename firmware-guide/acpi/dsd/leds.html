ACPIにおけるLEDの記述と参照¶

個々のLEDは、デバイスノードであるLEDドライバチップの下で階層的なデータ拡張[6]ノードによって記述されます。LED固有ノードの「reg」プロパティは、LEDが接続されている個々のLED出力の数値IDを示します[3]。階層的なデータノードは「led@X」と名付けられ、XはLED出力の番号です。

デバイスツリーにおけるLEDの参照は[4]の「flash-leds」プロパティドキュメンテーションに記載されています。要約すると、LEDはphandleを直接使って参照されます。

デバイスツリーは木構造内の任意のノードを参照できます[1]が、ACPIでは参照はデバイスノードに限定されています[2]。このため、ACPIにおいて同じメカニズムを使用することはできません。非デバイスのACPIノードを参照するメカニズムは[7]に記載されています。

ACPIは（DTと同様に）参照の後に整数引数を使用できます。LEDドライバデバイス参照と、関連するLEDの「reg」プロパティを参照する整数引数の組み合わせで個々のLEDを特定します。『reg』プロパティの値はファームウェアとソフトウェアの間の契約であり、LEDドライバ出力を一意に識別します。

LEDドライバデバイスの下で、最初の階層的なデータ拡張パッケージリスト項目には「led@」という文字列が続き、LEDの番号が続き、参照されるオブジェクト名が続きます。そのオブジェクトは「LED」に続き、LEDの番号で名付けられます。

例¶

カメラセンサデバイスと2つのLED用のLEDドライバデバイスのASL例を以下に示します。LEDに関係ないオブジェクトやそれらへの参照は省略しています。

Device (LED)
{
        Name (_DSD, Package () {
                ToUUID("dbb8e3e6-5886-4ba6-8795-1319f52a966b"),
                Package () {
                        Package () { "led@0", LED0 },
                        Package () { "led@1", LED1 },
                }
        })
        Name (LED0, Package () {
                ToUUID("daffd814-6eba-4d8c-8a91-bc9bbf4aa301"),
                Package () {
                        Package () { "reg", 0 },
                        Package () { "flash-max-microamp", 1000000 },
                        Package () { "flash-timeout-us", 200000 },
                        Package () { "led-max-microamp", 100000 },
                        Package () { "label", "white:flash" },
                }
        })
        Name (LED1, Package () {
                ToUUID("daffd814-6eba-4d8c-8a91-bc9bbf4aa301"),
                Package () {
                        Package () { "reg", 1 },
                        Package () { "led-max-microamp", 10000 },
                        Package () { "label", "red:indicator" },
                }
        })
}

Device (SEN)
{
        Name (_DSD, Package () {
                ToUUID("daffd814-6eba-4d8c-8a91-bc9bbf4aa301"),
                Package () {
                        Package () {
                                "flash-leds",
                                Package () { ^LED, "led@0", ^LED, "led@1" },
                        }
                }
        })
}

オプションを指定する必要があります。形式は以下の通りです：

LED     LED driver device
LED0    First LED
LED1    Second LED
SEN     Camera sensor device (or another device the LED is related to)
