鍵合意プロトコル素子（KPP）暗号アルゴリズム定義¶

struct kpp_request¶

定義

struct kpp_request {
  struct crypto_async_request base;
  struct scatterlist *src;
  struct scatterlist *dst;
  unsigned int src_len;
  unsigned int dst_len;
  void *__ctx[] ;
};

メンバ

base

非同期暗号リクエストの共通属性

src

ソースデータ

dst

宛先データ

src_len

入力バッファのサイズ

dst_len

出力バッファのサイズ。操作によって予想される結果のサイズに応じて、少なくともそのサイズ以上である必要があります。操作後、実際の結果のサイズが更新されます。dst sglサイズが不足している場合のエラーでは、操作に必要なサイズに更新されます。

__ctx

プライベートコンテキストデータの開始

定義

struct crypto_kpp {
  struct crypto_tfm base;
};

メンバ

base

共通暗号APIアルゴリズムデータ構造

struct kpp_alg¶

汎用キーアグリーメントプロトコルプリミティブ

定義

struct kpp_alg {
  int (*set_secret)(struct crypto_kpp *tfm, const void *buffer, unsigned int len);
  int (*generate_public_key)(struct kpp_request *req);
  int (*compute_shared_secret)(struct kpp_request *req);
  unsigned int (*max_size)(struct crypto_kpp *tfm);
  int (*init)(struct crypto_kpp *tfm);
  void (*exit)(struct crypto_kpp *tfm);
  unsigned int reqsize;
  struct crypto_alg base;
};

メンバ

set_secret

関数は、秘密のプライベートキーとパラメータを保存するプロトコル固有の関数を呼び出します。実装はバッファをデコードする方法を知っています

generate_public_key

関数は、相手に送信するパブリックキーを生成します。出力が十分でない場合、req->dst_lenが操作に必要なサイズに更新されます

compute_shared_secret

関数はアルゴリズムで定義された共有秘密を計算します。結果はユーザーに返されます。出力が十分でない場合、req->dst_lenが操作に必要なサイズに更新されます

max_size

関数は出力バッファのサイズを返します

init

オブジェクトの初期化。これはインスタンス化時にのみ呼び出されます。暗号化ハードウェアの初期化が必要な場合、ソフトウェアのフォールバックをここに実装する必要があります

exit

すべてを元に戻す init が行った操作を逆にします。

reqsize

アルゴリズム実装に必要なリクエストコンテキストのサイズ

base

共通暗号APIアルゴリズムデータ構造
