ランダム数アルゴリズム定義¶

struct rng_alg¶

ランダム数生成器の定義

定義

struct rng_alg {
  int (*generate)(struct crypto_rng *tfm,const u8 *src, unsigned int slen, u8 *dst, unsigned int dlen);
  int (*seed)(struct crypto_rng *tfm, const u8 *seed, unsigned int slen);
  void (*set_ent)(struct crypto_rng *tfm, const u8 *data, unsigned int len);
  unsigned int seedsize;
  struct crypto_alg base;
};

メンバ

generate

この変数で定義された関数はランダム数を取得します。ランダム数生成器変換は、この呼び出しで提供されたコンテキストからランダム数を生成しなければなりません。追加データが提供された場合は、それに加えて生成しなければなりません。

seed

ランダム数生成器の種を設定または再設定します。この関数呼び出しにより、ランダム数生成器は生成準備になります。ランダム数生成器が新しい状態を設定するために種を必要とする場合、この関数を呼び出す際には消費者が種を提供しなければなりません。必要な種のサイズは seedsize .

set_ent

エントロピー源から取得するエントロピーを設定します。内部使用専用です。

seedsize

この変数で定義されたランダム数生成器の初期化に必要な種サイズです。一部のランダム数生成器は種を必要としません。種の設定は内部で実装されるため、消費者のサポートが不要です。その場合、種サイズはゼロに設定されます。

base

一般的な暗号APIアルゴリズムデータ構造

暗号API ランダム数API¶

ランダム数生成器APIは、/proc/cryptoでタイプ「rng」としてリストされているCRYPTO_ALG_TYPE_RNG型の暗号アルゴリズムと併用されます

struct crypto_rng *crypto_alloc_rng(const char *alg_name, u32 type, u32 mask)¶

  • RNGハンドルを割り当てます

パラメータ

const char *alg_name

メッセージディジェスト暗号のcra_name / nameまたはcra_driver_name / driver name

u32 type

暗号の種類を指定します

u32 mask

暗号のマスクを指定します

説明

ランダム数生成器用の暗号ハンドルを割り当てます。返されるstruct crypto_rngは、そのランダム数生成器に関するすべての後のAPI呼び出しに必要な暗号ハンドルです。

すべてのランダム数生成器に対して、この呼び出しが他のインスタンスと共有しない新しいプライベートなコピーを生成します。例外は「krng」ランダム数生成器で、これは/dev/randomドライバのget_random_bytes()関数のカーネル暗号API使用例です。

戻り値

成功した場合の割り当てられた暗号ハンドル；IS_ERR()が真の場合、PTR_ERR()はエラーコードを返します。

エラーの場合、PTR_ERR()はエラーコードを返します。

int crypto_rng_reset(struct crypto_rng *tfm, const u8 *seed, unsigned int slen)¶

RNGを再初期化します

パラメータ

struct crypto_rng *tfm

暗号ハンドル

const u8 *seed

種入力データ

unsigned int slen

種入力データの長さ

説明

リセット機能は、暗号ハンドルで参照されるランダム数生成器の現在の状態をクリアし、ランダム数生成器の種類に応じて、呼び出し元が提供した種（seed）をもとに新たな状態を初期化します（ANSI X9.31 RNGは呼び出し元が提供した種を必要とし、SP800-90A DRBGは自動的に種付けを行います）。この関数呼び出しには種をパラメータとして提供します。提供された種は、ランダム数生成器で定義された種サイズの長さを持つ必要があります。

戻り値

鍵の設定が成功した場合は0；エラーが発生した場合は<0

int crypto_rng_seedsize(struct crypto_rng *tfm)¶

RNGの種(seed)サイズを取得する

パラメータ

struct crypto_rng *tfm

暗号ハンドル

説明

この関数は、暗号ハンドルで参照されるランダム数生成器の種サイズを返します。ランダム数生成器が再種付けを実装していない場合、この値はゼロになる可能性があります。たとえば、SP800-90A DRBGは、事前に定義されたしきい値に達した後に自動的に再種付けを行います。

戻り値

ランダム数生成器の種(seed)サイズ
