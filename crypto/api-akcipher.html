サイズの dst バッファ（検証を除くすべての操作）。操作に応じて予想される結果のサイズ以上である必要があります。操作後、実際の結果のサイズが更新されます。dst sglのサイズが不足している場合、必要なサイズに更新されます。検証操作では、digest部分のサイズです src.

struct akcipher_alg¶

汎用公開鍵アルゴリズム

定義

struct akcipher_alg {
  int (*sign)(struct akcipher_request *req);
  int (*verify)(struct akcipher_request *req);
  int (*encrypt)(struct akcipher_request *req);
  int (*decrypt)(struct akcipher_request *req);
  int (*set_pub_key)(struct crypto_akcipher *tfm, const void *key, unsigned int keylen);
  int (*set_priv_key)(struct crypto_akcipher *tfm, const void *key, unsigned int keylen);
  unsigned int (*max_size)(struct crypto_akcipher *tfm);
  int (*init)(struct crypto_akcipher *tfm);
  void (*exit)(struct crypto_akcipher *tfm);
  unsigned int reqsize;
  struct crypto_alg base;
};

メンバ

sign

関数は公開鍵アルゴリズムで定義された署名操作を実行します。dst_lenが不足している場合、req->dst_lenが操作に必要なサイズに更新されます

verify

関数は公開鍵アルゴリズムで定義された完全な検証操作を実行し、検証ステータスを返します。入力パラメータとしてハッシュ値を必要とします

encrypt

関数は公開鍵アルゴリズムで定義された暗号化操作を実行します。dst_lenが不足している場合、req->dst_lenが操作に必要なサイズに更新されます

decrypt

関数は公開鍵アルゴリズムで定義された復号化操作を実行します。dst_lenが不足している場合、req->dst_lenが操作に必要なサイズに更新されます

set_pub_key

関数はアルゴリズム固有の公開鍵設定関数を呼び出し、BER符号化された公開鍵とパラメータをデコード・解釈する方法を知っています

set_priv_key

関数はアルゴリズム固有の秘密鍵設定関数を呼び出し、BER符号化された秘密鍵とパラメータをデコード・解釈する方法を知っています

max_size

関数は指定された鍵に必要な宛先バッファのサイズを返します

init

暗号化変換オブジェクトを初期化します。この関数は暗号化変換オブジェクトを初期化するために使用されます。この関数は、変換コンテキストが割り当てられた直後にのみ1回呼び出されます。暗号化ハードウェアがソフトウェアで処理する特別な要件がある場合、この関数は変換の正確な要件を確認し、必要なソフトウェアのフォールバックを実装する必要があります。

exit

暗号化変換オブジェクトをデイジニライズします。これは initの対応処理で、に設定されたさまざまな変更を解除します init.

reqsize

アルゴリズム実装に必要なリクエストコンテキストのサイズ

base

共通暗号APIアルゴリズムデータ構造

パラメータ

u32 type
