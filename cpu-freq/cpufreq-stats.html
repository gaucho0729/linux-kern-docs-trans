sysfs CPUFreqステータスの一般的な説明¶

ユーザー向け情報

著者: Venkatesh Pallipadi <venkatesh.pallipadi@intel.com>

1. はじめに¶

cpufreq-stats は各 CPU に対して CPU 周波数の統計情報を提供するドライバです。これらの統計情報は /sysfs に読み取り専用インターフェースとして提供されます。このインターフェース（設定されている場合）は、/sysfs の cpufreq ディレクトリ下に各 CPU ごとに個別のディレクトリとして出現します（<sysfs root>/devices/system/cpu/cpuX/cpufreq/stats/）。このディレクトリにはさまざまな統計情報が読み取り専用ファイルとして配置されます。

このドライバは、特定の cpufreq ドライバに依存しない設計です。したがって、どの cpufreq ドライバとも互換性があります。

2. 提供される統計情報（例付き）¶

cpufreq stats は以下の統計情報を提供します（詳細は以下で説明します）。

  • time_in_state

  • total_trans

  • trans_table

すべての統計情報は、stats ドライバが挿入された時点（または stats のリセットされた時点）から、特定の統計情報の読み取りが行われる時点までの期間を示します。明らかに、stats ドライバは stats ドライバの挿入以前の周波数遷移に関する情報は持ちません。

<mysystem>:/sys/devices/system/cpu/cpu0/cpufreq/stats # ls -l
total 0
drwxr-xr-x  2 root root    0 May 14 16:06 .
drwxr-xr-x  3 root root    0 May 14 15:58 ..
--w-------  1 root root 4096 May 14 16:06 reset
-r--r--r--  1 root root 4096 May 14 16:06 time_in_state
-r--r--r--  1 root root 4096 May 14 16:06 total_trans
-r--r--r--  1 root root 4096 May 14 16:06 trans_table

  • リセット

統計カウンタをリセットするために使用できる書き込み専用属性です。これにより、再起動せずに異なるガバナーモードでのシステム挙動を評価できます。

  • time_in_state

この情報は、この CPU がサポートする各周波数でどれだけの時間を過ごしたかを示します。cat 出力では、各ラインに「<frequency> <time>」のペアが表示され、この CPU は <frequency> で <time> ユーザータイム単位の時間を過ごしたことを意味します。出力にはサポートされている各周波数に対応する 1 行ずつが表示されます。ここでいうユーザータイム単位は 10mS（/proc にエクスポートされている他の時間と同様）です。

<mysystem>:/sys/devices/system/cpu/cpu0/cpufreq/stats # cat time_in_state
3600000 2089
3400000 136
3200000 34
3000000 67
2800000 172488

  • total_trans

この情報は、この CPU における周波数遷移の総数を示します。cat 出力では、総数を示す単一のカウントが表示されます。

<mysystem>:/sys/devices/system/cpu/cpu0/cpufreq/stats # cat total_trans
20

  • trans_table

これはすべての CPU 周波数遷移に関する詳細な情報を提供します。cat 出力では、2 次元の行列形式が表示され、エントリ <i,j>（行 i、列 j）は Freq_i から Freq_j への遷移回数を示します。Freq_i 行と Freq_j 列は、ドライバが初期に cpufreq コアに提供した周波数テーブルの並び順に従い、並び替え（昇順または降順）または未並び替えの状態を保持します。出力には各行と列の実際の周波数値も含まれており、読みやすさを向上させています。

遷移テーブルが PAGE_SIZE より大きい場合、読み取りは -EFBIG エラーを返します。

<mysystem>:/sys/devices/system/cpu/cpu0/cpufreq/stats # cat trans_table
From  :    To
        :   3600000   3400000   3200000   3000000   2800000
3600000:         0         5         0         0         0
3400000:         4         0         2         0         0
3200000:         0         1         0         2         0
3000000:         0         0         1         0         3
2800000:         0         0         0         2         0

3. cpufreq-stats の設定¶

カーネルでcpufreq-statsを設定するには:

Config Main Menu
        Power management options (ACPI, APM)  --->
                CPU Frequency scaling  --->
                        [*] CPU Frequency scaling
                        [*]   CPU frequency translation statistics

「CPU Frequency scaling」(CONFIG_CPU_FREQ)を有効にする必要があります。

「CPU frequency translation statistics」(CONFIG_CPU_FREQ_STAT)は、time_in_state、total_trans、trans_tableを含む統計情報を提供します。

このオプションを有効にし、CPUがcpufrequencyをサポートしている場合、/sysfsにCPU周波数の統計情報を確認できます。
