ARM LinuxにおけるTCM（タイトーリーニングメモリ）の処理¶

Linus Walleij によって書かれました <linus.walleij@stericsson.com>

一部のARM SoCには、いわゆるTCM（Tightly-Coupled Memory）と呼ばれるメモリがあります。これは通常、ARMプロセッサ内に4〜64KiBのRAMが含まれています。

CPU内に埋め込まれているため、TCMはハーバードアーキテクチャを持ち、ITCM（指令TCM）とDTCM（データTCM）の2種類があります。DTCMには指令は含まれませんが、ITCMにはデータが含まれることがあります。DTCMまたはITCMのサイズは最小4KiBであり、典型的な最小構成は4KiBのITCMと4KiBのDTCMです。

ARM CPUには、TCMメモリの状態、物理位置、サイズを読み出すための特別なレジスタがあります。arch/arm/include/asm/cputype.hには、CPUID_TCMレジスタが定義されており、システムコントロールコプロセッサから読み出すことができます。ARMのドキュメンテーションは以下にあります http://infocenter.arm.com、"TCMステータスレジスタ"を検索して、すべてのCPUのドキュメントを確認できます。このレジスタを読み込むことで、マシンにITCM（ビット1〜0）および/またはDTCM（ビット17〜16）が存在するかを確認できます。

さらに、TCM領域レジスタ（ARMサイトで"TCM領域レジスタ"を検索）があり、TCMメモリの位置とサイズを実時間で報告および変更できます。これはTCMの位置とサイズを読み出し、変更するために使用されます。注意点として、これはMMUテーブルではなく、TCMの物理的な位置を実際に移動させます。配置した場所では、CPUから下位のRAMをマスクするため、TCMと物理的なRAMを重複させないことが通常は望ましいです。

TCMメモリは、MMUを使用して別のアドレスに再マッピングできますが、注意点としてTCMは通常MMUがオフになっている状況で使用されます。混乱を避けるため、現在のLinux実装では、カーネルが指定した場所から物理メモリを仮想メモリに1対1マッピングします。現在のLinuxでは、ITCMを0xfffe0000から開始し、DTCMを0xfffe8000から開始し、最大32KiBのITCMと32KiBのDTCMをサポートしています。

新しい領域レジスタは、これらのTCMを2つの別個のバンクに分割することもサポートしており、例えば8KiBのITCMは2つの4KiBのバンクに分割され、それぞれの制御レジスタを持ちます。この目的は、セキュアワールド（TrustZone）の使用に1つのバンクをロックし、隠蔽することです。

TCMは以下の用途に使用されます：

  • 決定的なタイミングが必要で、キャッシュミスを待つことができないFIQおよびその他の割込みハンドラ。

  • すべての外部RAMがセルフリフレッシュリテンションモードに設定され、CPUがアクセスできるのはオンチップRAMのみで、その後、ITCM内で割込みを待つアイドルループ。

  • 外部RAMコントローラーをオフにしたり再構成したりする他の操作も含まれます。

ARMアーキテクチャでは<asm/tcm.h>にTCMを使用するためのインターフェースがあります。このインターフェースを使用することで、以下のような操作が可能です：

  • ITCMおよびDTCMの物理アドレスとサイズを定義します。

  • ITCMにコンパイルされる関数をタグ付けします。

  • DTCMおよびITCMに割り当てられるデータと定数をタグ付けします。

  • 残りのTCM RAMは特別な割り当てプールに追加され、 gen_pool_create() および gen_pool_add() このメモリ用にtcm_alloc()とtcm_free()が提供されます。このようなヒープは、デバイス電源ドメインをオフにした際にデバイス状態を保存するなど、さまざまな用途に適しています。

TCMメモリを持つマシンは、arch/arm/Kconfigで自身にHAVE_TCMを選択する必要があります。TCMを使用するコードは<asm/tcm.h>を#includeします。

ITCMに配置する関数は次のようになります：int __tcmfunc foo(int bar);

これらの関数はlong_callsとしてマークされるため、ローカルでTCM内から呼び出したい場合にスペースを節約するため、__tcmlocalfuncプレフィックスを使用して相対呼び出しを実現できます。

DTCMに配置する変数は次のようになります：

int __tcmdata foo;

定数は次のようになります：

int __tcmconst foo;

アセンブリをTCMに組み込むには、次のようにします：

.section ".tcm.text" or .section ".tcm.data"

それぞれに保存されます

例コード：

#include <asm/tcm.h>

/* Uninitialized data */
static u32 __tcmdata tcmvar;
/* Initialized data */
static u32 __tcmdata tcmassigned = 0x2BADBABEU;
/* Constant */
static const u32 __tcmconst tcmconst = 0xCAFEBABEU;

static void __tcmlocalfunc tcm_to_tcm(void)
{
      int i;
      for (i = 0; i < 100; i++)
              tcmvar ++;
}

static void __tcmfunc hello_tcm(void)
{
      /* Some abstract code that runs in ITCM */
      int i;
      for (i = 0; i < 100; i++) {
              tcmvar ++;
      }
      tcm_to_tcm();
}

static void __init test_tcm(void)
{
      u32 *tcmem;
      int i;

      hello_tcm();
      printk("Hello TCM executed from ITCM RAM\n");

      printk("TCM variable from testrun: %u @ %p\n", tcmvar, &tcmvar);
      tcmvar = 0xDEADBEEFU;
      printk("TCM variable: 0x%x @ %p\n", tcmvar, &tcmvar);

      printk("TCM assigned variable: 0x%x @ %p\n", tcmassigned, &tcmassigned);

      printk("TCM constant: 0x%x @ %p\n", tcmconst, &tcmconst);

      /* Allocate some TCM memory from the pool */
      tcmem = tcm_alloc(20);
      if (tcmem) {
              printk("TCM Allocated 20 bytes of TCM @ %p\n", tcmem);
              tcmem[0] = 0xDEADBEEFU;
              tcmem[1] = 0x2BADBABEU;
              tcmem[2] = 0xCAFEBABEU;
              tcmem[3] = 0xDEADBEEFU;
              tcmem[4] = 0x2BADBABEU;
              for (i = 0; i < 5; i++)
                      printk("TCM tcmem[%d] = %08x\n", i, tcmem[i]);
              tcm_free(tcmem, 20);
      }
}
