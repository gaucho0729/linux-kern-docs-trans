ARM Linuxにおけるカーネル初期化パラメータ¶

以下のドキュメントは、ARM Linuxアーキテクチャで主に使用される「struct param_struct」と呼ばれるカーネル初期化パラメータ構造体について説明しています。

この構造体は、カーネルローダーからLinuxカーネル本体へ初期化パラメータを渡すために使用され、カーネル初期化プロセス中は一時的に存在する可能性があります。一般的には、arch/arm/kernel/setup.c:setup_arch()の外側で参照すべきではありません。

その中には多くのパラメータが含まれており、以下にそれぞれ説明します：

page_size

このパラメータは機械のページサイズに設定され、カーネルによってチェックされます。

nr_pages

システム内のメモリの総ページ数を表します。メモリがバンク形式の場合、システム全体のページ数を含める必要があります。

システムに別途VRAMが存在する場合は、この値にはVRAMの情報を含めないでください。

ramdisk_size

このパラメータは非推奨となり、使用すべきではありません。

フラグ

さまざまなカーネルフラグ、例えば：

ビット0

1 = ルートマウントを読み取り専用に

ビット1

未使用

ビット2

0 = ラムディスクをロード

ビット3

0 = ラムディスクのプロンプトを表示
rootdev

ルートファイルシステムとしてマウントするデバイスのメジャーマイナーペア。

video_num_cols / video_num_rows

これらは仮想コンソールまたはVGAコンソールの文字サイズを記述します。他の用途には使用しないでください。

通常、標準VGAまたはfbconディスプレイの同等の文字サイズに設定するのが良いです。これにより、起動メッセージが正しく表示されます。

video_x / video_y

これはVGAコンソールにおけるカーソルの文字位置を記述し、他のコンソールタイプや用途には使用しないでください。

memc_control_reg

Acorn ArchimedesおよびAcorn A5000ベースのマシン用のMEMCチップ制御レジスタ。異なるアーキテクチャで使用方法が異なる可能性があります。

sounddefault

Acornマシンのデフォルトサウンド設定。異なるアーキテクチャで使用方法が異なる可能性があります。

adfsdrives

ADFS/MFMディスクの数。異なるアーキテクチャで使用方法が異なる可能性があります。

bytes_per_char_h / bytes_per_char_v

これらは非推奨となり、使用すべきではありません。

pages_in_bank[4]

システムメモリの各バンクのページ数（RiscPC用）。プロセッサの観点から物理メモリが連続していないシステムで使用することを意図しています。

pages_in_vram

VRAMのページ数（Acorn RiscPCで使用されます）。この値は、ビデオRAMのサイズがハードウェアから取得できない場合、ローダーによっても使用されることがあります。

initrd_start / initrd_size

これは、カーネルの仮想開始アドレスおよび初期RAMディスクのサイズを記述しています。

rd_start

フロッピーディスク上のRAMディスクイメージのセクタ開始アドレス。

system_rev

システムのリビジョン番号。

system_serial_low / system_serial_high

システムの64ビットシリアル番号

mem_fclk_21285

21285（フットブリッジ）への外部オシレーターの速度。これはメモリバス、タイマーやシリアルポートの速度を制御します。CPUの速度によっては、この値は0〜66 MHzの範囲になります。パラメータが渡されない場合や0が渡された場合、21285アーキテクチャではデフォルトで50 MHzが使用されます。

paths[8][128]

これらは非推奨となり、使用すべきではありません。

commandline

カーネルコマンドラインパラメータ。詳細は他の場所で確認してください。
