S3C24XX ARM リナックス概要¶

はじめに¶

サムスンのS3C24XXシリーズARM9システムオンチップCPUは、ARM Linuxの「s3c2410」アーキテクチャによってサポートされています。現在、S3C2410、S3C2412、S3C2413、S3C2416、S3C2440、S3C2442、S3C2443、S3C2450のデバイスがサポートされています。

S3C2400およびS3C24A0シリーズのサポートは完成しておらず、対応するコードはしばらくしてから削除されました。誰かがこの取り組みを再開したい場合、以前のLinuxバージョンから部分的なサポートを取得できます。

S3C2416とS3C2450デバイスは非常に類似しており、S3C2450のサポートはarch/arm/mach-s3c2416ディレクトリに含まれています。注意点として、これらのSoCのコアサポートは完了していますが、一部の追加周辺機器や割込みの作業はまだ進行中です。

設定¶

一般的なS3C2410の設定が提供されており、 make s3c2410_defconfigコマンドでデフォルトとして使用できます。この設定はすべてのマシンに対応しており、それらのデバイスで一般的に使用される機能もサポートしています。

一部のマシンは独自のデフォルト設定を持つ場合もありますので、マシン固有のドキュメントを確認してください。

レイアウト¶

コアサポートファイルは、arch/arm/plat-s3c24xxに含まれるプラットフォームコードに位置しており、ヘッダーファイルはinclude/asm-arm/plat-s3c24xxにあります。このディレクトリは、プラットフォームコード（arch/arm/plat-s3c24xx）とarch/arm/mach-s3c24*コードで共有される項目を保持する必要があります。

各CPUにはそのCPU用のサポートファイルと、そのデバイスを搭載するマシンのディレクトリがあります。たとえばS3C2410はarch/arm/mach-s3c2410に、S3C2440はarch/arm/mach-s3c2440に含まれています。

レジスタ、カーネルおよびプラットフォームデータの定義は、arch/arm/mach-s3c2410ディレクトリにあります。/include/mach

arch/arm/plat-s3c24xx:

ここにあるファイルは、すべてのs3c24xxファミリに共通しているか、一部のファミリにのみ共通しており、その状態を示す名前で命名されています。すべてのファミリに共通しないファイルは、シリーズでサポートするCPUの初期文字を名前に含めることで、誤解の可能性を排除しながら短い名前を保つようにしています。

例として、最初はs3c244xはs3c2440とs3c2442をカバーしていましたが、s3c2443がこのディレクトリで多くのドライバを共有しないことにより、名前が不適切になりました。そのため、s3c2440-<x>という形式に変更し、s3c2440およびs3c2442との互換性を示しています。

これにより、特定のSoCの状態を確認するには複数のディレクトリを検索する必要があります。

新しいマシンの追加¶

アーキテクチャは、1つのカーネルビルドで構成できるすべてのマシンをサポートするように設計されており、今後の追加では、自分のマシンファイル以外の項目を変更する前にこの点を考慮する必要があります。

マシンの定義はlinux/arch/arm/mach-s3c2410に保持し、いくつかの例を確認できます。

パッチを送信する前に、カーネルパッチ送信ポリシーおよびDocumentation/armディレクトリを読みましょう。ARMカーネルシリーズはRussell Kingが管理しており、パッチシステムは以下にあります： http://www.arm.linux.org.uk/developer/patches/ 同じサイトから見つけることができるメールリストも含まれます。

ご協力として、以下のアドレスにご連絡ください：ben-linux@fluff.org新しいマシンやその他の変更について。

大規模な変更や新しいドライバは、ARMカーネルメールリスト（linux-arm-kernel）で事前に議論する必要があります。詳しくは以下をご参照ください。 http://www.arm.linux.org.uk/mailinglists/ メールリストに関する情報はこちら。

I2C¶

CPU内のハードウェアI2Cコアは、シングルマスターモードでサポートされており、プラットフォームデータを介して設定できます。

RTC¶

オンボードRTCユニットのサポート、アラーム機能を含む。

これは最近、新しいRTCコアを使用するようアップグレードされ、モジュールはrtc-s3cにリネームされて新しいRTCネーミングスキーマに合わせています。

ウォッチドッグ¶

オンチップウォッチドッグは標準のウォッチドッグインターフェースを通じて利用可能です。

NAND¶

現在のカーネルはs3c2410 NANDコントローラーをサポートしています。問題が発生した場合は、最新のlinux-mtdコードは以下から確認できます： http://www.linux-mtd.infradead.org/

詳しくは以下をご参照ください。 S3C24XX NANDサポート

SD/MMC¶

SD/MMCハードウェア（S3C2443以前）は現在のカーネルでサポートされており、ドライバはdrivers/mmc/host/s3cmci.cで、1bitおよび4bitのSDまたはMMCカードをサポートします。

このドライバのSDIO動作は完全にテストされていません。現在、ハードウェアSDIO割込みのサポートはありません。

シリアル¶

s3c2410シリアルドライバは内部シリアルポートのサポートを提供します。これらのデバイスは/dev/ttySAC0から3まで表示されます。

これらのデバイス用のデバイスノードを作成するには、次のコマンドを使用してください

mknod ttySAC0 c 204 64 mknod ttySAC1 c 204 65 mknod ttySAC2 c 204 66

GPIO¶

コアにはGPIOの操作をサポートしており、このファイルと同じディレクトリにあるGPIO.txtドキュメンテーションを参照してください。

新しいカーネルはGPIOLIBを搭載しており、サポートはこの方向へ移行しています。一部の古いサポートは将来的に削除される予定です。

v2.6.34以降では、gpiolibのサポートを使用する方向へほぼ完了しており、古い呼び出しの残りは極めて少なくなっています。

参照 S3C24XX GPIO制御 S3C24XX固有のサポートと Samsung GPIOの実装 サムスンコアの実装についてです。

クロック管理¶

コアはヘッダーファイルinclude/asm-arm/hardware/clock.hで定義されたインターフェースを提供し、さまざまなクロックユニットの制御を可能にします。

RAMへのスリープ¶

RAMへのスリープをサポートするボードでは、システムを低電力スリープ状態に置くことができます。

詳細についてはSuspend.txtを参照してください。

SPI¶

SPIドライバは、組み込みハードウェア（DMAサポートはまだありません）とジェネリックなGPIOベースのソリューションの両方で利用可能です。

LED¶

LEDサブシステム内のプラットフォームドライバを通じて、GPIOベースのLEDのサポートがあります。

プラットフォームデータ¶

デバイスがマシンごとに指定されるプラットフォーム固有のデータがある場合、以下の点に注意する必要があります：

  1. マシンが起動時にデータを設定しない場合、デバイスにデフォルトデータが残らないようにする

  2. データは（可能であれば）__initdataとしてマークされ、マシンが現在使用していない場合にデータが破棄されるようにする必要があります。

    これを実行する最善の方法は、関数を作成して、 kmalloc()メモリの領域を作成し、__initdataをコピーして、関連するデバイスのプラットフォームデータを設定することです。関数を作成することで、 __init 初期化コードと同時にデータが破棄されるように保証されます：

     static __init void s3c24xx_xxx_set_platdata(struct xxx_data *pd)
 {
     struct s3c2410_xxx_mach_info *npd;

   npd = kmalloc(sizeof(struct s3c2410_xxx_mach_info), GFP_KERNEL);
   if (npd) {
      memcpy(npd, pd, sizeof(struct s3c2410_xxx_mach_info));
      s3c_device_xxx.dev.platform_data = npd;
   } else {
        printk(KERN_ERR "no memory for xxx platform data\n");
   }
}

Note, since the code is marked as __init, it should not be
exported outside arch/arm/mach-s3c2410/, or exported to
modules via EXPORT_SYMBOL() and related functions.
