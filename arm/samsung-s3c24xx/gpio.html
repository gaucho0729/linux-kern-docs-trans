S3C24XX GPIO制御¶

はじめに¶

s3c2410カーネルは、GPIOピンの設定と状態の操作、およびその他の情報を取得するためのインターフェースを提供しています。

s3c2410 GPIOシステムの設定にはいくつかの条件があります。完全なリストについては、Samsungが提供するデータシート/ユーザーマニュアルを参照してください。

参照 Samsung GPIOの実装 コア実装用に。

GPIOLIB¶

drivers/gpioにGPIOLIBが導入されることで、ピンの読み書きなどの一部GPIO機能のサポートは、この一般的なアクセス方法に代わって削除されます。

すべての既存ドライバが変換された後、以下の関数は削除されます（今後、__deprecatedとしてマークされる可能性があります）。

以下の関数は現在、 s3c_ 特定の変体を持つか、gpiolibに統合されています。arch/arm/plat-samsung/include/plat/gpio-cfg.hの定義を参照してください：

  • s3c2410_gpio_setpin() gpio_set_value() または gpio_direction_output()

  • s3c2410_gpio_getpin() gpio_get_value() または gpio_direction_input()

  • s3c2410_gpio_getirq() gpio_to_irq()

  • s3c2410_gpio_cfgpin() s3c_gpio_cfgpin()

  • s3c2410_gpio_getcfg() s3c_gpio_getcfg()

  • s3c2410_gpio_pullup() s3c_gpio_setpull()

GPIOLIBへの移行¶

ボードやドライバを古いs3c2410 APIからGPIOLIBに移行する必要がある場合、移行プロセスに関するいくつかの注意点を以下に示します。

  1. GPIOを唯一の用途として使用しているボードの場合（例：外設機器の電源制御）、gpio_request()でGPIOを要求する必要があります。

    初期化時に少なくともWARN_ON()で返値を確認することをお勧めします。

  2. s3c2410_gpio_cfgpin()は引数が同じため、s3c_gpio_cfgpin()に直接置き換えることができます。ピン固有の値や、より一般的な特殊機能番号の引数をどちらも受け取れます。

  3. s3c2410_gpio_pullup()の変更では、s3c2410_gpio_pullup(x, 1)はs3c_gpio_setpull(x, S3C_GPIO_PULL_NONE)に簡単に置き換えられますが、s3c2410_gpio_pullup(x, 0)はそう簡単ではありません。

    s3c2410_gpio_pullup(x, 0)はプルアップ（一部のデバイスではプルダウン）を有効化します。新しいAPIではUPとDOWNの区別が行われるため、現在は「単にONにする」設定が存在せず、これが問題になる可能性があります。

  4. s3c2410_gpio_setpin()はgpio_set_value()に置き換えられます。古い関数はGPIOを出力に設定するのを明示的にしないので、gpio_set_value()を使う前にGPIOの方向を変更する必要があります。

  5. s3c2410_gpio_getpin()は、ピンが入力に設定されている場合、gpio_get_value()で置き換え可能です。現在、出力ピンに対してgpio_get_value()を使用する際の挙動は不明です（s3c2410_gpio_getpinはピンが出力すべき値を返します）。

  6. s3c2410_gpio_getirq()はgpio_to_irq()呼び出しで直接置き換え可能です。

s3c2410_gpioと gpio_ の呼び出しは常に同じgpio番号空間を扱っており、呼び出し間でのgpio番号の変換に問題はありません。

ヘッダ¶

GPIOピンの一覧とその設定値は、arch/arm/mach-s3c24xx/include/mach/regs-gpio.hに記載されています。#include <mach/regs-gpio.h>でこのヘッダをインクルードします。

ピン番号¶

各ピンはregs-gpio.hで一意の番号が割り当てられています（例：S3C2410_GPA(0)やS3C2410_GPF(1)）。これらの定義はGPIO関数がどのピンを使用するかを指定するために使われます。

gpiolibへの移行により、以前のカーネルのようにgpioピン番号からレジスタベースアドレスへの直接変換は行われません。これは、新しいSoCで後続のGPIOが連続していないための数値空間の必要性に起因します。

ピンの設定¶

次の関数を使用して、指定されたピンの設定を変更できます。

void s3c_gpio_cfgpin(unsigned int pin, unsigned int function);

e.g.:

s3c_gpio_cfgpin(S3C2410_GPA(0), S3C_GPIO_SFN(1)); s3c_gpio_cfgpin(S3C2410_GPE(8), S3C_GPIO_SFN(2));

これによりGPA(0)は最低アドレスラインA0に、GPE(8)はSDIO/MMCコントローラーのSDDAT1ラインに接続されます。

現在の設定の読み取り¶

ピンの現在の設定は、標準のgpiolib関数を使用して読み取れます：

s3c_gpio_getcfg(unsigned int pin);

返却値はs3c_gpio_cfgpin()に渡せる同じ値のセットから取得されます。

プルアップ抵抗の設定¶

S3C2410のGPIOピンの多くは弱いプルアップ抵抗を有効化できます。これを設定するには次の関数を使用します：

void s3c_gpio_setpull(unsigned int pin, unsigned int to);

toの値はS3C_GPIO_PULL_NONEでプルアップをオフ、S3C_GPIO_PULL_UPで指定されたプルアップを有効にします。他の値は現在未定義です。

ピンの状態の取得と設定¶

これらの呼び出しは現在、関連するgpiolib呼び出しで実装されています。ボードまたはドライバをgpiolibに移行してください。

ピンに関連するIRQ番号の取得¶

標準のgpiolib関数を使用して、指定されたピン番号をIRQ番号にマッピングできます。

int gpio_to_irq(unsigned int pin);

注意：すべてのピンがIRQを持つわけではありません。
