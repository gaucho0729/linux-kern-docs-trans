現在の状態¶

以下の記述は、NetWinderの浮動小数点数エミュレータの現在の状態を示しています。

浮動小数点数命令の説明には、以下の用語が使用されています。これはARMマニュアルにおける慣例に従っています。

<S|D|E> = <single|double|extended>, no default
{P|M|Z} = {round to +infinity,round to -infinity,round to zero},
          default = round to nearest

注意: { } で囲まれた項目はオプションです。

浮動小数点数コプロセッサデータ転送命令 (CPDT)¶

LDF/STF - 浮動小数点数の読み込みと保存

<LDF|STF>{cond}<S|D|E> Fd, Rn <LDF|STF>{cond}<S|D|E> Fd, [Rn, #<expression>]{!} <LDF|STF>{cond}<S|D|E> Fd, [Rn], #<expression>

これらの命令は完全に実装されています。

LFM/SFM - 浮動小数点数の複数読み込みと保存

形式1構文: <LFM|SFM>{cond}<S|D|E> Fd, <count>, [Rn] <LFM|SFM>{cond}<S|D|E> Fd, <count>, [Rn, #<expression>]{!} <LFM|SFM>{cond}<S|D|E> Fd, <count>, [Rn], #<expression>

形式2構文: <LFM|SFM>{cond}<FD,EA> Fd, <count>, [Rn]{!}

これらの命令は完全に実装されています。これらは、各浮動小数点数レジスタに対してメモリ位置に3ワードを保存/読み込みます。メモリ形式は他の実装と互換性がなく、特に実際のハードウェアと不一致する可能性があります。ARMマニュアルでこの点が明記されています。

浮動小数点数コプロセッサレジスタ転送命令 (CPRT)¶

変換、ステータス/コントロールレジスタの読み込み/書き込み命令

FLT{cond}<S,D,E>{P,M,Z} Fn, Rd 整数を浮動小数点数に変換 FIX{cond}{P,M,Z} Rd, Fn 浮動小数点数を整数に変換 WFS{cond} Rd 浮動小数点数ステータスレジスタの書き込み RFS{cond} Rd 浮動小数点数ステータスレジスタの読み込み WFC{cond} Rd 浮動小数点数コントロールレジスタの書き込み RFC{cond} Rd 浮動小数点数コントロールレジスタの読み込み

FLT/FIXは完全に実装されています。

RFS/WFSは完全に実装されています。

RFC/WFCは完全に実装されています。RFC/WFCはスーパーバイザ専用の命令であり、現在はCPUモードを確認し、スーパーバイザモードから呼び出されない場合に無効な命令トラップを発生させます。

比較命令

CMF{cond} Fn, Fm 浮動小数点数の比較 CMFE{cond} Fn, Fm 浮動小数点数の比較（例外）CNF{cond} Fn, Fm 負の浮動小数点数の比較 CNFE{cond} Fn, Fm 負の浮動小数点数の比較（例外）

これらは完全に実装されています。

浮動小数点数コプロセッサデータ命令 (CPDT)¶

二項演算:

ADF{cond}<S|D|E>{P,M,Z} Fd, Fn, <Fm,#value> - 加算 SUF{cond}<S|D|E>{P,M,Z} Fd, Fn, <Fm,#value> - 減算 RSF{cond}<S|D|E>{P,M,Z} Fd, Fn, <Fm,#value> - 反転減算 MUF{cond}<S|D|E>{P,M,Z} Fd, Fn, <Fm,#value> - 乗算 DVF{cond}<S|D|E>{P,M,Z} Fd, Fn, <Fm,#value> - 除算 RDV{cond}<S|D|E>{P,M,Z} Fd, Fn, <Fm,#value> - 反転除算

これらは完全に実装されています。

FML{cond}<S|D|E>{P,M,Z} Fd, Fn, <Fm,#value> - 高速乗算 FDV{cond}<S|D|E>{P,M,Z} Fd, Fn, <Fm,#value> - 高速除算 FRD{cond}<S|D|E>{P,M,Z} Fd, Fn, <Fm,#value> - 高速逆除算

これらも完全に実装されています。非高速版と同じアルゴリズムを使用しているため、この実装でのパフォーマンスはMUF/DVF/RDV命令と同等です。ARMマニュアルではこれを受け入れるとしています。マニュアルではこれらが単項演算専用で定義されていると記載されており、実際のFPA11ハードウェアでは倍精度または拡張精度のオペランドには動作しません。エミュレータは現在、要求された許可条件をチェックせず、要求された操作を実行します。

RMF{cond}<S|D|E>{P,M,Z} Fd, Fn, <Fm,#value> - IEEE剰余

これらも完全に実装されています。

単項演算:

MVF{cond}<S|D|E>{P,M,Z} Fd, <Fm,#value> - 移動 MNF{cond}<S|D|E>{P,M,Z} Fd, <Fm,#value> - 負符号付き移動

これらは完全に実装されています。

ABS{cond}<S|D|E>{P,M,Z} Fd, <Fm,#value> - 絶対値 SQT{cond}<S|D|E>{P,M,Z} Fd, <Fm,#value> - 平方根 RND{cond}<S|D|E>{P,M,Z} Fd, <Fm,#value> - 四捨五入

これらは完全に実装されています。

URD{cond}<S|D|E>{P,M,Z} Fd, <Fm,#value> - 正規化されていない四捨五入 NRM{cond}<S|D|E>{P,M,Z} Fd, <Fm,#value> - 正規化

これらは実装されています。URDはRND命令と同じコードを使用しています。URDが正規化されていない数を返すことはできないため、NRMはNOPになります。

ライブラリ呼び出し:

POW{cond}<S|D|E>{P,M,Z} Fd, Fn, <Fm,#value> - べき乗 RPW{cond}<S|D|E>{P,M,Z} Fd, Fn, <Fm,#value> - 逆べき乗 POL{cond}<S|D|E>{P,M,Z} Fd, Fn, <Fm,#value> - 絶対値（arctan2）

LOG{cond}<S|D|E>{P,M,Z} Fd, <Fm,#value> - 10進対数 LGN{cond}<S|D|E>{P,M,Z} Fd, <Fm,#value> - 自然対数 EXP{cond}<S|D|E>{P,M,Z} Fd, <Fm,#value> - 指数 SIN{cond}<S|D|E>{P,M,Z} Fd, <Fm,#value> - サイン COS{cond}<S|D|E>{P,M,Z} Fd, <Fm,#value> - コサイン TAN{cond}<S|D|E>{P,M,Z} Fd, <Fm,#value> - タンジェント ASN{cond}<S|D|E>{P,M,Z} Fd, <Fm,#value> - 反正弦 ACS{cond}<S|D|E>{P,M,Z} Fd, <Fm,#value> - 反余弦 ATN{cond}<S|D|E>{P,M,Z} Fd, <Fm,#value> - 反正切

これらは実装されていません。現在のコンパイラからは発行されず、libc内のルーチンで処理されています。これらはFPA11ハードウェアでは実装されていませんが、浮動小数点サポートコードで処理されています。今後のバージョンで実装される予定です。

シグナル処理:

シグナルは実装されています。しかしRebel.comが生成する現在のELFカーネルには、モジュールがSIGFPEを生成できないというバグがあります。これはfp_currentをカーネル変数current_set[0]に正しくアリアス化できていないためです。

このディストリビューションに同梱されているカーネル(vmlinux-nwfpe-0.93)には、この問題に対する修正が含まれており、さらに現在のエミュレータの最新バージョンが直接組み込まれています。このカーネルを使用することで、浮動小数点モジュールをロードせずに動作することが可能です。これは技術のデモンストレーションとして提供されており、シグナルに依存した浮動小数点処理を行うユーザー向けのものです。モジュールの使用は厳密には必須ではありません。

Russell Kingが提供するモジュール、またはこのディストリビューションに同梱されているモジュールのいずれかをロードすることで、カーネルに組み込まれたエミュレータの機能を置き換えることが可能です。
