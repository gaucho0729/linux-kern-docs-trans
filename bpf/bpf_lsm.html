LSM BPF プログラム¶

これらのBPFプログラムは、特権ユーザーが実行時インストゥレーションによりLSMハックを監視し、システム全体のMAC（強制アクセス制御）および監査ポリシーをeBPFで実装するためのものです。

Structure¶

例として、eBPFプログラムがアタッチされる file_mprotect LSMハック:

int file_mprotect(struct vm_area_struct *vma, unsigned long reqprot, unsigned long prot);¶

他のインストゥレーション可能なLSMハックは include/linux/lsm_hooks.h.

eBPFプログラムが使用する BPF Type Format (BTF) は、アタッチされたeBPFプログラムのコンテキストから情報を取得するためにカーネルヘッダーを含む必要がありません。eBPFプログラム内で構造体を宣言し、アクセスが必要なフィールドのみを指定すればよいです。

struct mm_struct {
        unsigned long start_brk, brk, start_stack;
} __attribute__((preserve_access_index));

struct vm_area_struct {
        unsigned long start_brk, brk, start_stack;
        unsigned long vm_start, vm_end;
        struct mm_struct *vm_mm;
} __attribute__((preserve_access_index));

注意

フィールドの順序は関係ありません。

ビルド時にBTF情報にアクセスできる場合、さらに簡略化できます。 vmlinux.h 以下のように変更してください：

# bpftool btf dump file <path-to-btf-vmlinux> format c > vmlinux.h

注意

path-to-btf-vmlinux can be /sys/kernel/btf/vmlinux ビルド環境がBPFプログラムの展開環境と一致する場合、

以下の vmlinux.h はBPFプログラムに直接含めることで、型の定義を必要としなくなります。

eBPFプログラムは``BPF_PROG``マクロを用いて tools/lib/bpf/bpf_tracing.hで宣言できます。この例では:

  • "lsm/file_mprotect" はプログラムがアタッチする必要のあるLSMハックを示します

  • mprotect_audit はeBPFプログラムの名前です

SEC("lsm/file_mprotect")
int BPF_PROG(mprotect_audit, struct vm_area_struct *vma,
             unsigned long reqprot, unsigned long prot, int ret)
{
        /* ret is the return value from the previous BPF program
         * or 0 if it's the first hook.
         */
        if (ret != 0)
                return ret;

        int is_heap;

        is_heap = (vma->vm_start >= vma->vm_mm->start_brk &&
                   vma->vm_end <= vma->vm_mm->brk);

        /* Return an -EPERM or write information to the perf events buffer
         * for auditing
         */
        if (is_heap)
                return -EPERM;
}

以下の __attribute__((preserve_access_index)) はclangの機能で、BPF検証者が実行時におけるアクセスのオフセットを更新するための BPF Type Format (BTF) 情報を使用します。BPF検証者が型を把握しているため、eBPFプログラム内で行われる各種型へのアクセスを検証します。

読み込み中¶

eBPFプログラムは bpf(2) システムコールの BPF_PROG_LOAD 操作でロードできます:

struct bpf_object *obj;

obj = bpf_object__open("./my_prog.o");
bpf_object__load(obj);

skeleton headerを生成する bpftool:

# bpftool gen skeleton my_prog.o > my_prog.skel.h

を使用することで簡略化できます。プログラムは my_prog.skel.h を含め、生成されたヘルパー my_prog__open_and_load.

を使用してロードできます。¶

LSMハックへのアタッチメント bpf(2) システムコールの BPF_RAW_TRACEPOINT_OPEN LSMは bpf_program__attach_lsm.

操作またはより簡潔にlibbpfヘルパーを使用してeBPFプログラムをLSMハックにアタッチできます は 、そして link で返されるリンクを破壊することで、プログラムをLSMハックから分離できます bpf_program__attach_lsm を使用して bpf_link__destroy.

で生成されたヘルパーを使用できます my_prog.skel.h i.e. my_prog__attach 添付用と my_prog__destroy クリーンアップ用の。
