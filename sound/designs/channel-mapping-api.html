ALSA PCM チャンネルマッピング API¶

Takashi Iwai <tiwai@suse.de>

一般¶

チャンネルマッピング API は、ユーザーが可能なチャンネルマッピングや現在のチャンネルマッピングを照会でき、必要に応じて現在のストリームのチャンネルマッピングを変更できるようにします。

チャンネルマッピングとは、各 PCM チャンネルの位置を表す配列です。通常、ステレオ PCM ストリームは以下のチャンネルマッピングを持ちます： { front_left, front_right } 4.0 サウンドバー PCM ストリームは以下のチャンネルマッピングを持ちます： { front left, front right, rear left, rear right }.

これまでの問題は、明示的な標準チャンネルマッピングが存在せず、アプリケーションがどのチャンネルがどの（スピーカー）位置に対応するかを把握できなかったことです。これにより、アプリケーションは5.1出力用に誤ったチャンネルを適用し、急に後方から不思議な音が聞こえるなどの問題が発生しました。また、一部のデバイスではセンターチャンネル/LFEを3番/4番チャンネルと仮定しているのに対し、他のデバイスではC/LFEを5番/6番チャンネルと仮定しているため、互換性の問題が生じていました。

さらに、HDMIなどのデバイスは、合計チャンネル数が同じでもスピーカーの位置を変更可能に設定できます。しかし、チャンネルマッピング仕様が存在しないため、これを指定する方法がありませんでした。これらが新しいチャンネルマッピングAPIの主な動機です。

設計¶

実際、「チャンネルマッピングAPI」は、カーネル/ユーザー空間のABI観点では何も新しいことを導入していません。既存の制御要素機能のみを使用しています。

設計の基本として、各PCMサブストリームにはチャンネルマッピング情報と設定を提供する制御要素が含まれます。この要素は以下のようになります：

  • iface = SNDRV_CTL_ELEM_IFACE_PCM

  • name = "Playback Channel Map" または "Capture Channel Map"

  • device = そのPCMサブストリームに割り当てられたデバイス番号と同じ

  • index = そのPCMサブストリームに割り当てられたインデックス番号と同じ

PCMサブストリームの方向によって名前が異なります

各コントロール要素は少なくともTLV読み取り操作と読み取り操作を提供します。オプションで書き込み操作を提供することもでき、ユーザーがチャネルマップを動的に変更できるようにします

TLV¶

TLV操作は利用可能なチャネルマップの一覧を提供します。チャネルマップの一覧項目は通常、 type data-bytes ch0 ch1 ch2... typeがTLVのタイプ値で、第二引数はチャネル値の総バイト数（数値ではなく）で、残りは各チャネルの位置値です

TLVタイプとして、 SNDRV_CTL_TLVT_CHMAP_FIXED, SNDRV_CTL_TLV_CHMAP_VAR または SNDRV_CTL_TLVT_CHMAP_PAIRED が使用できます。 _FIXED typeは固定チャネル位置のチャネルマップで、後者の2つは柔軟なチャネル位置のチャネルマップです _VAR typeはすべてのチャネルが自由に交換可能なチャネルマップで、 _PAIRED typeはペアワイズチャネルが交換可能なチャネルマップです。例えば{FL/FR/RL/RR}チャネルマップの場合, _PAIRED このタイプは、{RL/RR/FL/FR}のみを交換可能で、 _VAR このタイプは、FLとRRの交換も可能になります。

これらの新しいTLVタイプは、 sound/tlv.h.

利用可能なチャンネル位置値は、 sound/asound.h、以下が切り抜きです：

/* channel positions */
enum {
      SNDRV_CHMAP_UNKNOWN = 0,
      SNDRV_CHMAP_NA,         /* N/A, silent */
      SNDRV_CHMAP_MONO,       /* mono stream */
      /* this follows the alsa-lib mixer channel value + 3 */
      SNDRV_CHMAP_FL,         /* front left */
      SNDRV_CHMAP_FR,         /* front right */
      SNDRV_CHMAP_RL,         /* rear left */
      SNDRV_CHMAP_RR,         /* rear right */
      SNDRV_CHMAP_FC,         /* front center */
      SNDRV_CHMAP_LFE,        /* LFE */
      SNDRV_CHMAP_SL,         /* side left */
      SNDRV_CHMAP_SR,         /* side right */
      SNDRV_CHMAP_RC,         /* rear center */
      /* new definitions */
      SNDRV_CHMAP_FLC,        /* front left center */
      SNDRV_CHMAP_FRC,        /* front right center */
      SNDRV_CHMAP_RLC,        /* rear left center */
      SNDRV_CHMAP_RRC,        /* rear right center */
      SNDRV_CHMAP_FLW,        /* front left wide */
      SNDRV_CHMAP_FRW,        /* front right wide */
      SNDRV_CHMAP_FLH,        /* front left high */
      SNDRV_CHMAP_FCH,        /* front center high */
      SNDRV_CHMAP_FRH,        /* front right high */
      SNDRV_CHMAP_TC,         /* top center */
      SNDRV_CHMAP_TFL,        /* top front left */
      SNDRV_CHMAP_TFR,        /* top front right */
      SNDRV_CHMAP_TFC,        /* top front center */
      SNDRV_CHMAP_TRL,        /* top rear left */
      SNDRV_CHMAP_TRR,        /* top rear right */
      SNDRV_CHMAP_TRC,        /* top rear center */
      SNDRV_CHMAP_LAST = SNDRV_CHMAP_TRC,
};

PCMストリームが複数のチャンネルマップを提供できる場合、複数のチャンネルマップをTLVコンテナタイプ内で提供できます。返されるTLVデータには以下のようなものが含まれます：

SNDRV_CTL_TLVT_CONTAINER 96
    SNDRV_CTL_TLVT_CHMAP_FIXED 4 SNDRV_CHMAP_FC
    SNDRV_CTL_TLVT_CHMAP_FIXED 8 SNDRV_CHMAP_FL SNDRV_CHMAP_FR
    SNDRV_CTL_TLVT_CHMAP_FIXED 16 NDRV_CHMAP_FL SNDRV_CHMAP_FR \
        SNDRV_CHMAP_RL SNDRV_CHMAP_RR

チャンネル位置はLSB 16ビットで提供されます。上位ビットはビットフラグとして使用されます。

#define SNDRV_CHMAP_POSITION_MASK       0xffff
#define SNDRV_CHMAP_PHASE_INVERSE       (0x01 << 16)
#define SNDRV_CHMAP_DRIVER_SPEC         (0x02 << 16)

SNDRV_CHMAP_PHASE_INVERSE チャンネルが位相反転していることを示します（したがって、左右チャンネルを足すとほぼ静寂になります）。一部のデジタルマイクデバイスではこの機能があります。

が呼ばれるとき、modprobeは SNDRV_CHMAP_DRIVER_SPEC 設定されている場合、すべてのチャンネル位置値は上記の標準定義に従わず、ドライバ固有のものです。

読み取り操作¶

コントロール読み取り操作は、指定されたストリームの現在のチャンネルマップを提供するためのものです。コントロール要素は、各チャンネルの位置を含む整数配列を返します。

チャンネル数が指定される前（つまり、hw_paramsが設定されている場合）にこの操作が実行される場合、すべてのチャンネルを以下のように設定して返す必要があります： UNKNOWN.

書き込み操作¶

コントロール書き込み操作はオプションであり、HDMIなどのチャンネル構成を即座に変更できるデバイス専用です。ユーザーは、割り当てられたPCMサブストリームのすべてのチャンネルの有効なチャンネル位置を含む整数値を渡す必要があります。

この操作はPCM PREPARED状態でのみ許可されます。他の状態で呼び出された場合、エラーを返します。
