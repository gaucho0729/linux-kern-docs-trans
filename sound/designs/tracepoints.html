ALSA におけるトレースポイント¶

2017/07/02 Takasahi Sakamoto

ALSA PCM コアにおけるトレースポイント¶

ALSA PCMコアレジスタ snd_pcm カーネルトレースポイントシステムへのサブシステム。このサブシステムには、PCMバッファの状態とPCMハードウェアパラメータの処理に関する2つのカテゴリのトレースポイントが含まれます。これらのトレースポイントは、対応するカーネル構成が有効になっているときに利用可能です。When CONFIG_SND_DEBUG 有効になっている場合、後者のトレースポイントが利用可能です。追加で SND_PCM_XRUN_DEBUG 有効にもなれば、前者のトレースポイントが有効になります。

PCMバッファの状態に関するトレースポイント¶

このカテゴリには4つのトレースポイントが含まれます; hwptr, applptr, xrun および hw_ptr_error.

PCMハードウェアパラメータの処理に関するトレースポイント¶

このカテゴリには2つのトレースポイントが含まれます; hw_mask_param および hw_interval_param.

ALSA PCMコアの設計では、データ送信はPCMサブストリームとして抽象化されています。アプリケーションはPCMサブストリームを管理して、PCMフレームのデータ送信を維持します。データ送信を開始する前に、アプリケーションはPCMサブストリームを設定する必要があります。この手順では、アプリケーションとALSA PCMコアの相互作用によってPCMハードウェアパラメータが決定されます。決定されると、PCMサブストリームのランタイムはこれらのパラメータを保持します。

パラメータはstruct snd_pcm_hw_paramsで記述されます。この構造体にはいくつかのパラメータタイプが含まれます。アプリケーションはこれらのパラメータに好ましい値を設定し、SNDRV_PCM_IOCTL_HW_REFINEまたはSNDRV_PCM_IOCTL_HW_PARAMSを用いてioctl(2)を実行します。前者は利用可能なパラメータセットの精査にのみ使用され、後者は実際にパラメータを決定するために使用されます。

struct snd_pcm_hw_params構造体には以下のメンバがあります:

flags

設定可能。ALSA PCMコアと一部のドライバーがこのフラグを処理して、便利なパラメータを選択したり、動作を変更したりします。

masks

設定可能。このタイプのパラメータはstruct snd_maskで記述され、マスク値を表します。PCMプロトコルv2.0.13以降で3つのタイプが定義されています。

  • SNDRV_PCM_HW_PARAM_ACCESS

  • SNDRV_PCM_HW_PARAM_FORMAT

  • SNDRV_PCM_HW_PARAM_SUBFORMAT

intervals

設定可能。このタイプのパラメータはstruct snd_intervalで記述され、範囲を持つ値を表します。PCMプロトコルv2.0.13以降で12つのタイプが定義されています。

  • SNDRV_PCM_HW_PARAM_SAMPLE_BITS

  • SNDRV_PCM_HW_PARAM_FRAME_BITS

  • SNDRV_PCM_HW_PARAM_CHANNELS

  • SNDRV_PCM_HW_PARAM_RATE

  • SNDRV_PCM_HW_PARAM_PERIOD_TIME

  • SNDRV_PCM_HW_PARAM_PERIOD_SIZE

  • SNDRV_PCM_HW_PARAM_PERIOD_BYTES

  • SNDRV_PCM_HW_PARAM_PERIODS

  • SNDRV_PCM_HW_PARAM_BUFFER_TIME

  • SNDRV_PCM_HW_PARAM_BUFFER_SIZE

  • SNDRV_PCM_HW_PARAM_BUFFER_BYTES

  • SNDRV_PCM_HW_PARAM_TICK_TIME

rmask

設定可能。これはioctl(2)でSNDRV_PCM_IOCTL_HW_REFINEのみ評価されます。アプリケーションはALSA PCMコアがどのマスク/インターバルパラメータを変更できるかを選択できます。SNDRV_PCM_IOCTL_HW_PARAMSでioctl(2)を実行する際には、このマスクは無視され、すべてのパラメータが変更されます。

cmask

読み取り専用。ioctl(2)から戻った後、ユーザー空間のstruct snd_pcm_hw_paramsのバッファには各操作の結果が含まれます。このマスクは実際に変更されたマスク/インターバルパラメータを表します。

info

読み取り専用。これはSNDRV_PCM_INFO_XXXのビットフラグでハードウェア/ドライバの機能を表します。通常、アプリケーションはSNDRV_PCM_IOCTL_HW_REFINEでioctl(2)を実行してこのフラグを取得し、その後パラメータ候補を決定してSNDRV_PCM_IOCTL_HW_PARAMSでioctl(2)を実行してPCMサブストリームを設定します。

msbits

読み取り専用。この値はPCMサンプルのMSB側の利用可能なビット幅を表します。SNDRV_PCM_HW_PARAM_SAMPLE_BITSのパラメータが固定数として決定された場合、この値はそれに応じて計算されます。それ以外はゼロです。ただし、この挙動はドライバ側の実装に依存します。

rate_num

読み取り専用。この値は分数表記におけるサンプリングレートの分子を表します。基本的に、SNDRV_PCM_HW_PARAM_RATEのパラメータが単一値として決定された場合、この値はそれに応じて計算されます。それ以外はゼロです。ただし、この挙動はドライバ側の実装に依存します。

rate_den

読み取り専用。この値は分数表記におけるサンプリングレートの分母を表します。基本的に、SNDRV_PCM_HW_PARAM_RATEのパラメータが単一値として決定された場合、この値はそれに応じて計算されます。それ以外はゼロです。ただし、この挙動はドライバ側の実装に依存します。

fifo_size

読み取り専用。この値はハードウェアのシリアルサウンドインターフェース内のFIFOのサイズを表します。基本的に、各ドライバはこのパラメータに適切な値を割り当てることができます。ただし、一部のドライバはハードウェア設計やデータ伝送プロトコルを考慮してゼロを意図的に設定する場合があります。

ALSA PCMコアは、アプリケーションがSNDRV_PCM_HW_REFINEまたはSNDRV_PCM_HW_PARAMSでioctl(2)を実行する際、struct snd_pcm_hw_paramsのバッファを処理します。バッファ内のパラメータはstruct snd_pcm_hardwareとランタイムの制約ルールに基づいて変更されます。この構造体は処理対象のハードウェアの機能を記述し、ルールはパラメータが他のパラメータに依存して決定される関係を示します。ルールにはコールバック関数があり、ドライバは任意の関数を登録してターゲットパラメータを計算できます。ALSA PCMコアはデフォルトでいくつかのルールをランタイムに登録します。

各ドライバは、struct snd_pcm_ops.openのコールバックで2つのパラメータに準備ができている限り、インタラクションに参加できます。

  1. このコールバックでは、ドライバは、対応するハードウェアの能力に応じて、struct snd_pcm_hardware型のメンバーをランタイムで変更する必要があります。

  2. 同じコールバックでは、複数のパラメータがハードウェア設計により依存関係を持つ場合、ドライバはその制約ルールをランタイムに追加する必要があります。

ドライバはstruct snd_pcm_ops.hw_paramsのコールバックでインタラクションの結果を参照できますが、内容を変更してはいけません。

このカテゴリのトレースポイントは、マスク/インターバルパラメータの変更を追跡するように設計されています。ALSA PCMコアがこれらを変更する場合、 hw_mask_param または hw_interval_param 変更されたパラメータの種類に応じてイベントが検出されます。

ALSA PCMコアは、各トレースポイントに対してフォーマットを備えています。以下は例です。 hw_mask_param.

hw_mask_param: pcmC0D0p 001/023 FORMAT 00000000000000000000001000000044 00000000000000000000001000000044

以下は例です。 hw_interval_param.

hw_interval_param: pcmC0D0p 000/023 BUFFER_SIZE 0 0 [0 4294967295] 0 1 [0 4294967295]

最初の3つのフィールドは共通しています。これらはALSA PCMキャラクタデバイスの名前、制約ルール、変更されたパラメータの名前を順に表します。制約ルールのフィールドは2つのサブフィールドから構成され、適用されたルールのインデックスとランタイムに追加されたルールの総数です。例外として、インデックス000は、ルールに関係なくALSA PCMコアがパラメータを変更したことを示します。

残りのフィールドはパラメータの変更前後の状態を表します。これらのフィールドはパラメータの種類によって異なります。マスク型のパラメータでは、フィールドはパラメータの内容の16進数ダンプを表し、インターバル型のパラメータでは、 empty, integer, openmin, min, max, openmax struct snd_intervalのメンバーの値をこの順序で表します。
