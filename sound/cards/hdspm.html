ソフトウェアインターフェース ALSA-DSP MADIドライバ — Linuxカーネルドキュメンテーション¶

(ドイツ語から翻訳されたため、英語としては不完全 ;-),

2004 - winfried ritsch

ドライバに完全な機能が追加されました。一部のコントロールと起動オプションはALSA標準であり、特記事項となるコントロールについては以下で説明・論じます。

ハードウェア機能¶

オーディオ伝送¶

  • チャンネル数 – 伝送モードにより異なります

    選択されたチャンネル数は1..Nmaxです。少ないチャンネル数を使用する理由はリソース割り当てに限られ、未使用のDMAチャンネルは無効化され、メモリの割り当て量も減少します。したがってPCIシステムのスループットもスケーラブルです。(低性能ボードにおいてのみ重要です)

  • シングルスピード – 1..64チャンネル

注意

(注: 伝送または受信モードで56チャンネルモードを選択すると、MADI経由で56チャンネルのみが送信/受信されますが、ミキサーではすべての64チャンネルが利用可能なので、ドライバのチャンネル数)

  • ダブルスピード – 1..32チャンネル

注意

注: 伝送/受信モードで56チャンネルモードを選択すると、MADI経由で28チャンネルのみが送信/受信されますが、ミキサーではすべての32チャンネルが利用可能なので、ドライバのチャンネル数

  • クォドスピード – 1..16チャンネル

注意

伝送/受信モードで56チャンネルモードを選択すると、MADI経由で14チャンネルのみが送信/受信されますが、ミキサーではすべての16チャンネルが利用可能なので、ドライバのチャンネル数

  • フォーマット – 符号付き32ビットリトルエンディアン (SNDRV_PCM_FMTBIT_S32_LE)

  • サンプルレート –

    シングルスピード – 32000, 44100, 48000

    ダブルスピード – 64000, 88200, 96000 (未検証)

    クォドスピード – 128000, 176400, 192000 (未検証)

  • アクセスモード – MMAP (メモリマッピング), PCM_NON-INTERLEAVED

  • バッファサイズ – 64,128,256,512,1024,2048,8192 サンプル

  • フラグメント – 2

  • ハードウェアポインタ – 2モード

    このカードはDMAが読み書きする際の現在のバッファポインタの読み出しをサポートしています。PCIのバルクモードのため、精度は64バイトのみです。したがってALSAミッドレベル機能には実用性が低く、(ここではバッファIDがより良い結果をもたらします)。アプリケーションがMMAPを使用する場合、この機能はロード時にパラメータ precise-pointer で設定可能です。

ヒント

(ヒント: 実験を通じて、ポインタが最大64バイト以上になることが確認され、常に小さすぎることはありません。したがって、64を引くことで常に安全なポインタを得ることができ、このモードでALSA内では使用されます。理論上、中断可能性の1/4に相当する16サンプルのレイテンシーが達成可能です。)

  • 正確なポインタ – オフ

    ポインタ計算用の割込み

  • 正確なポインタ – 有効

    ハードウェアポインタが使用されています。

コントローラー¶

DSP-MADI-Mixerは8152フェーダーを備えており、標準のミキサー制御を使用する意味がありません。これはグラフィックのALSA-Mixer GUIの多くを破壊するためです。そのため、hwdepインターフェースを用いた2次元コントローラーでミキサー制御を提供する必要があります。

また、すべての128+256ピークおよびRMSメーターもhwdepインターフェース経由でアクセス可能です。ピークおよびRMSレベルのコピーと変換を常に実行するとパフォーマンス上の問題になる可能性があるため、必要に応じてハードウェア構造をエクスポートしました。これにより、ドライバ専門家がioctl経由でミキサーまたはピークメーターのメモリマッピングを実装したり、コピーのみを実行したりできます。テストアプリケーションではコントローラーの使用法を示しています。

  • レイテンシ制御 — 実装されていません！！！

注意

注意: Windowsドライバ内ではレイテンシーが制御パネルからアクセス可能ですが、バッファサイズはhwparamsコールでALSAから制御され、実行状態で変更すべきではありません。ここでは実装していません。

  • システムクロック – 停止！！！

    • 名前 – 「システムクロックモード」

    • アクセス – 読み取り/書き込み

    • 値 – 「マスター」「スレーブ」

注意

!!!! この機能はハードウェア関連ですが、クロックソースコントローラー（ALSA標準の一種）と衝突しています。スタジオでは音声アプリケーションを起動せずにでも同期設定が動作する必要がありますので、カードを特別なモード（特定周波数でのマスターまたはスレーブ）に設定する意味があります。そのため、クロックソースコントローラーを使用してください！！！

  • クロックソース

    • 名前 – 「サンプルクロックソース」

    • アクセス – 読み取り/書き込み

    • 値 – 「オートシンク」、『内部32.0kHz』、『内部44.1kHz』、『内部48.0kHz』、『内部64.0kHz』、『内部88.2kHz』、『内部96.0kHz』

      特定周波数でのマスターまたはスピードモード、またはスレーブ（オートシンク）を選択できます。また、「好ましい同期参照」も参照してください。

警告

!!!! この機能は純粋なハードウェア機能ではありませんが、一部のALSAドライバでALSAによって実装されていましたので、こちらも使用しています。!!!

  • 好ましい同期参照

    • 名前 – 「好ましい同期参照」

    • アクセス – 読み取り/書き込み

    • 値 – 「ワード」「MADI」

      オートシンクモードでは好ましい同期ソースを選択できます。利用不可の場合は他のソースを使用します。

注意

注意: MADIはワードクロックよりもはるかに高いビットレートを持ちますので、MADIモードではカードがより正確に同期するはずです。しかしRME-PLLは非常に優れており、ワードクロックでもほぼ問題ありません。私は違いを確認したことはありません。

  • TX 64チャンネル

    • 名前 – 「TX 64チャンネルモード」

    • アクセス – 読み取り/書き込み

    • 値 – 0 1

      MADI送信用に64チャンネルモード（1）または56チャンネルモード（0）を選択します。

注意

注意: このコントロールは出力専用です。入力モードはMADIを送信するハードウェアから自動的に検出されます。

  • TMSをクリア

    • 名前 – 「トラックマーカーをクリア」

    • アクセス – 読み取り/書き込み

    • 値 – 0 1

      AESの5 Audio-bitsを追加ビットとして低減する用途には使用しないでください。

  • セーフモードまたはオート入力

    • 名前 – 「セーフモード」

    • アクセス – 読み取り/書き込み

    • 値 – 0 1（デフォルトはオン）

      オン（1）の場合、光ファイバーまたはコァックス接続のいずれかで障害が発生した場合、動作する接続に自動的に切り替わり、サンプルの喪失は発生しません。これは2番目の接続をバックアップとして使用する場合にのみ有効です。

  • 入力

    • 名前 – 「入力選択」

    • アクセス – 読み取り/書き込み

    • 値 – 光ファイバー コァックス

      入力の選択（光ファイバーまたはコァックス）。セーフモードが有効な場合、この入力が優先されます。

ミキサー¶

  • ミキサー

    • 名前 – 「ミキサー」

    • アクセス – 読み取り/書き込み

    • 値 - <チャネル番号 0-127> <値 0-65535>

      最初の値としてチャネルインデックスを取得し、対応するミキサーのチャネルを設定します。0-63は入力から出力へのフェーダー、64-127は再生から出力へのフェーダーを表します。値0はチャネルをミュートし、32768は増幅率1を表します。

  • チャネル 1-64

    ALSAミキサーユーティリティ用の高速ミキサー。ミキサー行列の対角線は再生から出力に実装されています。

  • ライン出力

    • 名前 – 「ライン出力」

    • アクセス – 読み取り/書き込み

    • 値 – 0 1

      アナログ出力をオン/オフする機能で、ミキシングやルーティングとは関係ありません。アナログ出力はチャネル63、64を反映しています。

情報（読み取り専用）¶

  • サンプルレート

    • 名前 – 「システムサンプルレート」

    • アクセス – 読み取り専用

      サンプルレートを取得します。

  • 外部レート測定

    • 名前 – 「外部レート」

    • アクセス – 読み取り専用

      「オートシンクレート」であるべきですが、使用されている名前はALSAスキーマです。オートシンクで使用される外部サンプル周波数が報告されます。

  • MADI同期ステータス

    • 名前 – 「MADI同期ロックステータス」

    • アクセス – 読み取り

    • 値 – 0,1,2

      MADI入力は0=アンロック、1=ロック、または2=同期状態です。

  • ワードクロック同期ステータス

    • 名前 – 「ワードクロックロックステータス」

    • アクセス – 読み取り

    • 値 – 0,1,2

      ワードクロック入力は0=アンロック、1=ロック、または2=同期状態です。

  • オートシンク

    • 名前 – 「オートシンク参照」

    • アクセス – 読み取り

    • 値 – 「ワードクロック」、「MADI」、「なし」

      同期参照は「WordClock」、「MADI」、または無しです。

  • RX 64ch — まだ実装されていません

    MADI-Receiver は 64 チャネルモード または 56 チャネルモード です。

  • AB_inp — テストされていません

    自動入力用の入力。

  • 現在のバッファ位置 — まだ実装されていません

    !!! これは ALSA の内部関数なので、制御は使用されません !!!

呼び出しパラメータ¶

  • インデックス int 配列 (min = 1, max = 8)

    RME HDSPM インターフェースのインデックス値。ALSA 内のカードインデックス

    注: ALSA 標準

  • ID 文字列配列 (min = 1, max = 8)

    RME HDSPM インターフェースの ID 文字列。

    注: ALSA 標準

  • 有効化 int 配列 (min = 1, max = 8)

    特定の HDSPM サウンドカードを有効/無効にする。

    注: ALSA 標準

  • 正確なポインタ int 配列 (min = 1, max = 8)

    正確なポインタを有効にするか、無効にするか

注意

注: アプリケーションがこれをサポートしている場合にのみ使用してください（これは特殊なケースです）。

  • ラインアウトモニタ int 配列 (min = 1, max = 8)

    再生ストリームをアナログ出力にデフォルトで送信する

注意

注: 各再生チャネルは同じ番号の出力チャネルにミキシングされます（ルーテッド）。これは ALSA の規約と反しており、ドライバをロード後にすべてのチャネルをミュートする必要がありますが、以前の他のカードでは使用されていましたので、私は歴史的に再び使用しています。

  • モニタ有効化 int 配列 (min = 1, max = 8)

    チャネル63/64のアナログ出力をデフォルトで有効にする

注意

注: ここではアナログ出力が有効になっています（ただしルーテッドされていません）。
