Sound Blaster Audigy ミキサー / デフォルトDSPコード¶

これはsb-live-mixer.rstに基づいています。

EMU10K2チップにはDSP部があり、これはサンプル処理のさまざまな方法をサポートするためにプログラミング可能で、ここに説明されています。(この記事ではEMU10K2チップ全体の機能については扱いません。詳細についてはマニュアルセクションを参照してください。)

ALSAドライバーは、このチップの一部をデフォルトコードでプログラムします（後で変更可能です）。以下に提供する機能があります：

デジタルミキサー制御¶

これらの制御はDSP指令を使用して構築されており、拡張機能を提供します。ここではALSAドライバーのデフォルトの組み込みコードのみが説明されています。注意点として、これらの制御はアタenuエータとして動作し、最大値は信号を変更せずに中立位置を表します。また、複数の制御で同じ宛先が指定されている場合、信号は蓄積され、オーバーフローのチェックなしに最大値または最小値に設定されることがあります。

使用する略語の説明：

DAC

デジタルからアナログへのコンバーター

ADC

アナログからデジタルへのコンバーター

I2S

フェリックスセミコンダクターのデジタルサウンド用の1方向3ワイヤーシリアルバス（この標準はスタンドアロンDACおよびADCコンバーターを接続するために使用されます）

LFE

低周波エフェクト（サブウーファー信号）

AC97

アナログミキサー、DACおよびADCコンバーターを含むチップ

IEC958

S/PDIF

FXバス

EMU10K2チップには、64つのアキュムレータを含むエフェクトバスがあります。各シンセサイザーボイスは、これらのアキュムレータに出力を送信でき、DSPマイクロコントローラーはその結果の合計を処理できます。

name=’PCM Front Playback Volume’,index=0¶

この制御は、左と右のフロントPCM FXバスアキュムレータにサンプルを減衰させるために使用されます。ALSAは、5.1再生用の左と右のフロントPCMサンプルにアキュムレータ8と9を使用します。結果のサンプルは、Philips DACのフロントDAC PCMスロットに転送されます。

name=’PCM Surround Playback Volume’,index=0¶

この制御は、左と右のサウンドPCM FXバスアキュムレータにサンプルを減衰させるために使用されます。ALSAは、5.1再生用の左と右のサウンドPCMサンプルにアキュムレータ2と3を使用します。結果のサンプルは、Philips DACのサウンドDAC PCMスロットに転送されます。

name=’PCM Center Playback Volume’,index=0¶

この制御は、センターPCM FXバスアキュムレータにサンプルを減衰させるために使用されます。ALSAは、5.1再生用のセンターPCMサンプルにアキュムレータ6を使用します。結果のサンプルは、Philips DACのセンターDAC PCMスロットに転送されます。

name=’PCM LFE Playback Volume’,index=0¶

このコントロールは、LFE PCM FXバスアキュムレータ用のサンプルを減衰させるために使用されます。ALSAは、5.1再生用のLFE PCMサンプルにアキュムレータ7を使用します。結果のサンプルは、Philips DACのLFE DAC PCMスロットに転送されます。

name=’PCM Playback Volume’,index=0¶

このコントロールは、左と右のPCM FXバスアキュムレータ用のサンプルを減衰させるために使用されます。ALSAは、ステレオ再生用の左と右のPCMサンプルにアキュムレータ0と1を使用します。結果のサンプルは、Philips DACのフロントDAC PCMスロットに転送されます。

name=’PCM Capture Volume’,index=0¶

このコントロールは、左と右のPCM FXバスアキュムレータ用のサンプルを減衰させるために使用されます。ALSAは、左と右のPCMにアキュムレータ0と1を使用します。結果はADCキャプチャFIFO（標準キャプチャPCMデバイスに）に転送されます。

name=’Music Playback Volume’,index=0¶

このコントロールは、左と右のMIDI FXバスアキュムレータ用のサンプルを減衰させるために使用されます。ALSAは、左と右のMIDIサンプルにアキュムレータ4と5を使用します。結果のサンプルは、AC97コーデックのフロントDAC PCMスロットに転送されます。

name=’Music Capture Volume’,index=0¶

これらのコントロールは、左と右のMIDI FXバスアキュムレータ用のサンプルを減衰させるために使用されます。ALSAは、左と右のPCMにアキュムレータ4と5を使用します。結果はADCキャプチャFIFO（標準キャプチャPCMデバイスに）に転送されます。

name=’Mic Playback Volume’,index=0¶

このコントロールは、左と右のマイク入力用のサンプルを減衰させるために使用されます。マイク入力にはAC97コーデックが使用されます。結果のサンプルは、Philips DACのフロントDAC PCMスロットに転送され、ボリューム制御なしでマイクキャプチャFIFO（デバイス1 - 16bit/8KHzモノラル）にも転送されます。

name=’Mic Capture Volume’,index=0¶

このコントロールは、左と右のマイク入力用のサンプルを減衰させるために使用されます。結果はADCキャプチャFIFO（標準キャプチャPCMデバイスに）に転送されます。

name=’Audigy CD Playback Volume’,index=0¶

このコントロールは、左と右のIEC958 TTLデジタル入力（通常はCDROMドライブで使用されます）からのサンプルを減衰させるために使用されます。結果のサンプルは、Philips DACのフロントDAC PCMスロットに転送されます。

name=’Audigy CD Capture Volume’,index=0¶

このコントロールは、左と右のIEC958 TTLデジタル入力（通常はCDROMドライブで使用されます）からのサンプルを減衰させるために使用されます。結果のサンプルは、ADCキャプチャFIFO（標準キャプチャPCMデバイスに）に転送されます。

name=’IEC958 Optical Playback Volume’,index=0¶

このコントロールは、左および右のIEC958光デジタル入力からのサンプルを減衰させます。結果のサンプルは、Philips DACのフロントDAC PCMスロットに送信されます。

name=’IEC958 Optical Capture Volume’,index=0¶

このコントロールは、左および右のIEC958光デジタル入力からのサンプルを減衰させます。結果のサンプルは、ADCキャプチャFIFO（標準キャプチャPCMデバイスに送信されます）に送信されます。

name=’Line2 Playback Volume’,index=0¶

このコントロールは、左および右のI2S ADC入力（AudigyDrive上）からのサンプルを減衰させます。結果のサンプルは、Philips DACのフロントDAC PCMスロットに送信されます。

name=’Line2 Capture Volume’,index=1¶

このコントロールは、左および右のI2S ADC入力（AudigyDrive上）からのサンプルを減衰させます。結果のサンプルは、ADCキャプチャFIFO（標準キャプチャPCMデバイスに送信されます）に送信されます。

name=’Analog Mix Playback Volume’,index=0¶

このコントロールは、左および右のI2S ADC入力（Philips ADCから）からのサンプルを減衰させます。結果のサンプルは、Philips DACのフロントDAC PCMスロットに送信されます。これはCD、ラインイン、オーディオ入力などのアナログソースからのミックスを含みます。

name=’Analog Mix Capture Volume’,index=1¶

このコントロールは、左および右のI2S ADC入力（Philips ADCから）からのサンプルを減衰させます。結果のサンプルは、ADCキャプチャFIFO（標準キャプチャPCMデバイスに送信されます）に送信されます。

name=’Aux2 Playback Volume’,index=0¶

このコントロールは、左および右のI2S ADC入力（AudigyDrive上）からのサンプルを減衰させます。結果のサンプルは、Philips DACのフロントDAC PCMスロットに送信されます。

name=’Aux2 Capture Volume’,index=1¶

このコントロールは、左および右のI2S ADC入力（AudigyDrive上）からのサンプルを減衰させます。結果のサンプルは、ADCキャプチャFIFO（標準キャプチャPCMデバイスに送信されます）に送信されます。

name=’Front Playback Volume’,index=0¶

すべてのステレオ信号がミックスされ、サウンド、センター、LFEにリフレクションされます。このコントロールは、このミックスの左および右のフロントスピーカー用のサンプルを減衰させます。

name=’Surround Playback Volume’,index=0¶

すべてのステレオ信号がミックスされ、サウンド、センター、LFEにリフレクションされます。このコントロールは、このミックスの左および右のサウンドスピーカー用のサンプルを減衰させます。

name=’Center Playback Volume’,index=0¶

すべてのステレオ信号がミックスされ、サウンド、センター、LFEにリフレクションされます。このコントロールは、このミックスのセンタースピーカー用のサンプルを減衰させます。

name=’LFE Playback Volume’,index=0¶

すべてのステレオ信号がミックスされ、サウンド、センター、LFEにリフレクションされます。このコントロールは、このミックスのLFEスピーカー用のサンプルを減衰させます。

name=’Tone Control - Switch’,index=0¶

このコントロールは、トーンコントロールをオンまたはオフにします。フロント、リア、センター/LFE出力のサンプルに影響を与えます。

name=’Tone Control - Bass’,index=0¶

このコントロールはベースの強度を設定します。中立値は存在しません!! テンションコントロールコードが有効になると、サンプルは常に変更されます。純粋な信号に最も近い値は20です。

name=’Tone Control - Treble’,index=0¶

このコントロールはトレブルの強度を設定します。中立値は存在しません!! テンションコントロールコードが有効になると、サンプルは常に変更されます。純粋な信号に最も近い値は20です。

name=’Master Playback Volume’,index=0¶

このコントロールはフロント、サウンド、センターおよびLFE出力用のサンプルを減衰させるために使用されます。

name=’IEC958 Optical Raw Playback Switch’,index=0¶

このスイッチがオンの場合、IEC958（S/PDIF）デジタル出力用のサンプルはRAW FX8010 PCMのみから取得されます。それ以外の場合は標準的なフロントPCMサンプルが取得されます。

PCMストリーム関連のコントロール¶

name=’EMU10K1 PCM Volume’,index 0-31¶

チャンネル音量減衰範囲 0-0xffff。最大値（減衰なし）はデフォルト値です。3つの値のチャンネルマッピングは以下の通りです：

  • 0 - モノラル、デフォルト 0xffff（減衰なし）

  • 1 - 左チャンネル、デフォルト 0xffff（減衰なし）

  • 2 - 右チャンネル、デフォルト 0xffff（減衰なし）

name=’EMU10K1 PCM Send Routing’,index 0-31¶

このコントロールは宛先 - FXバスの蓄積器を指定します。このマッピングには24の値があります：

  • 0 - モノラル、A宛（FXバス0-63）、デフォルト 0

  • 1 - モノラル、B宛（FXバス0-63）、デフォルト 1

  • 2 - モノラル、C宛（FXバス0-63）、デフォルト 2

  • 3 - モノラル、D宛（FXバス0-63）、デフォルト 3

  • 4 - モノラル、E宛（FXバス0-63）、デフォルト 0

  • 5 - モノラル、F宛（FXバス0-63）、デフォルト 0

  • 6 - モノラル、G宛（FXバス0-63）、デフォルト 0

  • 7 - モノラル、H宛（FXバス0-63）、デフォルト 0

  • 8 - 左チャンネル、A宛（FXバス0-63）、デフォルト 0

  • 9 - 左チャンネル、B宛（FXバス0-63）、デフォルト 1

  • 10 - 左チャンネル、C宛（FXバス0-63）、デフォルト 2

  • 11 - 左チャンネル、D宛（FXバス0-63）、デフォルト 3

  • 12 - 左チャンネル、E宛（FXバス0-63）、デフォルト 0

  • 13 - 左チャンネル、F宛（FXバス0-63）、デフォルト 0

  • 14 - 左チャンネル、G宛（FXバス0-63）、デフォルト 0

  • 15 - 左チャンネル、H宛（FXバス0-63）、デフォルト 0

  • 16 - 右チャンネル、A宛（FXバス0-63）、デフォルト 0

  • 17 - 右チャンネル、B宛（FXバス0-63）、デフォルト 1

  • 18 - 右チャンネル、C宛（FXバス0-63）、デフォルト 2

  • 19 - 右チャンネル、D宛（FXバス0-63）、デフォルト 3

  • 20 - 右チャンネル、E宛（FXバス0-63）、デフォルト 0

  • 21 - 右チャンネル、F宛（FXバス0-63）、デフォルト 0

  • 22 - 右チャンネル、G宛（FXバス0-63）、デフォルト 0

  • 23 - 右チャンネル、H宛（FXバス0-63）、デフォルト 0

同じFXバスアキュムレータにチャンネルを複数回割り当てることは違法です（0=0 && 1=0は無効な組み合わせです）。

name=’EMU10K1 PCM Send Volume’,index 0-31¶

指定された宛先の減衰量（量）を0〜255の範囲で指定します。チャンネルマッピングは以下の通りです：

  • 0 - モノラル、A宛先の減衰量、デフォルト255（減衰なし）

  • 1 - モノラル、B宛先の減衰量、デフォルト255（減衰なし）

  • 7 - モノラル、H宛先の減衰量、デフォルト0（ミュート）

  • 8 - レフト、A宛先の減衰量、デフォルト255（減衰なし）

  • 9 - レフト、B宛先の減衰量、デフォルト0（ミュート）
