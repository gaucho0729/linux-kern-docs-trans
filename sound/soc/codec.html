ASoC コーデッククラスドライバ¶

コードッククラスドライバーは、コードック、FM、MODEM、BT、または外部DSPを設定してオーディオの録音と再生を提供する汎用でハードウェアに依存しないコードです。ターゲットプラットフォームやマシンに特有のコードは含めず、すべてのプラットフォームおよびマシン固有のコードはそれぞれプラットフォームドライバーおよびマシンドライバーに追加する必要があります。

各コードッククラスドライバー grace periodsを尊重しなければなりませんし、 以下の機能を提供します:-

  1. コードックDAIおよびPCMの設定

  2. コードック制御IO - RegMap APIを使用

  3. ミキサーやオーディオ制御

  4. コードックオーディオ操作

  5. DAPMの説明。

  6. DAPMイベントハンドラ。

オプションで、コードックドライバーは以下の機能も提供できます:-

  1. DACデジタルミュート制御。

このガイドはsound/soc/codecs/にある既存のコードックドライバーのコードと併用するのが最善です。

ASoCコードックドライバーの構成¶

コードックDAIおよびPCMの設定¶

各コードックドライバーは、DAIおよびPCMの機能と操作を定義するためにstruct snd_soc_dai_driverを必要とします。この構造体は、マシンドライバーによってコアに登録できるようにエクスポートされます。

e.g.

static struct snd_soc_dai_ops wm8731_dai_ops = {
      .prepare        = wm8731_pcm_prepare,
      .hw_params      = wm8731_hw_params,
      .shutdown       = wm8731_shutdown,
      .digital_mute   = wm8731_mute,
      .set_sysclk     = wm8731_set_dai_sysclk,
      .set_fmt        = wm8731_set_dai_fmt,
};

struct snd_soc_dai_driver wm8731_dai = {
      .name = "wm8731-hifi",
      .playback = {
              .stream_name = "Playback",
              .channels_min = 1,
              .channels_max = 2,
              .rates = WM8731_RATES,
              .formats = WM8731_FORMATS,},
      .capture = {
              .stream_name = "Capture",
              .channels_min = 1,
              .channels_max = 2,
              .rates = WM8731_RATES,
              .formats = WM8731_FORMATS,},
      .ops = &wm8731_dai_ops,
      .symmetric_rates = 1,
};

コードック制御IO¶

コードックは通常、I2CまたはSPIスタイルのインターフェース（AC97はDAI内で制御とデータを組み合わせる）を介して制御されます。コードックドライバーはすべてのコードックIOにRegmap APIを使用する必要があります。include/linux/regmap.hと既存のコードックドライバーを参照してください。

ミキサーやオーディオ制御¶

すべてのコードックミキサーおよびオーディオ制御は、soc.hで定義された便利なマクロを使用して定義できます。

#define SOC_SINGLE(xname, reg, shift, mask, invert)

単一の制御を定義するには次のとおりです:-

xname = Control name e.g. "Playback Volume"
reg = codec register
shift = control bit(s) offset in register
mask = control bit size(s) e.g. mask of 7 = 3 bits
invert = the control is inverted

その他のマクロには次のとおりです:-

#define SOC_DOUBLE(xname, reg, shift_left, shift_right, mask, invert)

ステレオ制御

#define SOC_DOUBLE_R(xname, reg_left, reg_right, shift, mask, invert)

2つのレジスタをまたぐステレオ制御

#define SOC_ENUM_SINGLE(xreg, xshift, xmask, xtexts)

単一の列挙型制御を定義するには次のとおりです:-

xreg = register
xshift = control bit(s) offset in register
xmask = control bit(s) size
xtexts = pointer to array of strings that describe each setting

#define SOC_ENUM_DOUBLE(xreg, xshift_l, xshift_r, xmask, xtexts)

ステレオ列挙型制御を定義します

コードックオーディオ操作¶

コードックドライバーは以下のALSA PCM操作もサポートします:-

/* SoC audio ops */
struct snd_soc_ops {
      int (*startup)(struct snd_pcm_substream *);
      void (*shutdown)(struct snd_pcm_substream *);
      int (*hw_params)(struct snd_pcm_substream *, struct snd_pcm_hw_params *);
      int (*hw_free)(struct snd_pcm_substream *);
      int (*prepare)(struct snd_pcm_substream *);
};

詳細については、ALSAドライバーPCMドキュメンテーションを参照してください。 http://www.alsa-project.org/~iwai/writing-an-alsa-driver/

DAPMの説明¶

動的オーディオ電源管理の説明は、コードック電源コンポーネントとそれらのASoCコアへの関係およびレジスタを記述しています。説明の構築に関する詳細はdapm.rstを参照してください。

他のコードックドライバーの例も参照してください。

DAPMイベントハンドラ¶

この関数は、コードックドメインPM呼び出しとシステムドメインPM呼び出し（例: スリープと再開）を処理するコールバックです。使用されていないときにコードックをスリープ状態にします。

電源状態:-

SNDRV_CTL_POWER_D0: /* full On */
/* vref/mid, clk and osc on, active */

SNDRV_CTL_POWER_D1: /* partial On */
SNDRV_CTL_POWER_D2: /* partial On */

SNDRV_CTL_POWER_D3hot: /* Off, with power */
/* everything off except vref/vmid, inactive */

SNDRV_CTL_POWER_D3cold: /* Everything Off, without power */

コードックDACデジタルミュート制御¶

ほとんどのコードックは、DACの前にデジタルミュートがあり、システムノイズを最小限に抑えることができます。ミュートはデジタルデータがDACに入らないようにします。

ミュートが適用または解放されるたびにコアが各コードックDAIに対して呼び出すコールバックを作成できます。

i.e.

static int wm8974_mute(struct snd_soc_dai *dai, int mute)
{
      struct snd_soc_component *component = dai->component;
      u16 mute_reg = snd_soc_component_read32(component, WM8974_DAC) & 0xffbf;

      if (mute)
              snd_soc_component_write(component, WM8974_DAC, mute_reg | 0x40);
      else
              snd_soc_component_write(component, WM8974_DAC, mute_reg);
      return 0;
}
