5.5. ioctl MEDIA_IOC_G_TOPOLOGY¶

5.5.1. 名前¶

MEDIA_IOC_G_TOPOLOGY - グラフのトポロジとグラフ要素のプロパティを列挙します

5.5.2. 概要¶

MEDIA_IOC_G_TOPOLOGY¶

int ioctl(int fd, MEDIA_IOC_G_TOPOLOGY, struct media_v2_topology *argp)

5.5.3. 引数¶

fd

返されるファイル記述子 open().

argp

struct mem_ctl_info media_v2_topology.

5.5.4. 説明¶

このioctlの典型的な使用方法は、これを2回呼び出すことです。最初の呼び出しでは、構造体structで定義された構造体をゼロにします。 media_v2_topology 返却時にエラーがなければ、このioctlは、エントリティ、インターフェース、パッド、リンクの総数を返します。 topology_version 2回目の呼び出し前に、ユーザー空間は、必要なグラフ要素を格納する配列を確保し、ptr_entities、ptr_interfaces、ptr_linksおよび/またはptr_padsにポインタを設定し、他の値は変更せずに保持する必要があります。

他の値は変更せずに保持する必要があります。このioctlは、必要な配列にメディアグラフ要素を埋め込みます。

5.5.5. 戻り値¶

成功した場合、0 が返されます。エラーの場合、-1 が返され、変数が適切に設定されます。 errno 一般的なエラーコードは、 汎用エラーコード 章。

ENOSPC

num_entities、num_interfaces、num_links、num_padsのいずれか1つ以上がゼロでない場合、かつ実際のグラフ内の要素数より小さい場合に返されます。これは、 topology_version 最後にこのioctlが呼び出されたときと比較して変更されている場合に発生します。ユーザースペースでは通常、ポインタの領域を解放し、構造体要素をゼロにしてからこのioctlを再度呼び出す必要があります。
