5.1. media open()¶

5.1.1. 名前¶

media-open - メディアデバイスを開く

5.1.2. 概要¶

#include <fcntl.h>
int open(const char *device_name, int フラグ)¶

5.1.3. 引数¶

device_name

開くデバイス。

flags

オープンフラグ。アクセスモードは次のいずれかでなければなりません O_RDONLY または O_RDWR. その他のフラグは効果がありません。

5.1.4. 説明¶

メディアデバイスを開くには、アプリケーションは open() 望むデバイス名で呼び出します。この関数は副作用がありません。デバイスの設定は変更されません。

デバイスが読み取り専用モードで開かれた場合、設定を変更する試みはエラーとなり、 errno が EBADF に設定されます。

5.1.5. 戻り値¶

open() 成功時は新しいファイル記述子を返します。エラーの場合、-1 を返し、 errno 適切に設定されます。可能なエラー コードは:

EACCES

ファイルへのアクセスが許可されていません。

EMFILE

プロセスが最大のファイル数を開いているためです。

ENFILE

システムのオープンファイルの総数の制限に達しています。

ENOMEM

カーネルのメモリが不足しています。

ENXIO

このデバイス専用ファイルに対応するデバイスがありません。
