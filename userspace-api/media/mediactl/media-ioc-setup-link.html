5.8. ioctl MEDIA_IOC_SETUP_LINK¶

5.8.1. 名前¶

MEDIA_IOC_SETUP_LINK - リンクのプロパティを変更する

5.8.2. 概要¶

MEDIA_IOC_SETUP_LINK¶

int ioctl(int fd, MEDIA_IOC_SETUP_LINK, struct media_link_desc *argp)

5.8.3. 引数¶

fd

返されるファイル記述子 open().

argp

struct mem_ctl_info media_link_desc.

5.8.4. 説明¶

リンクのプロパティを変更するには、アプリケーションはリンクの識別情報（ソースおよびシンクのパッド）と新しいリクエストされたリンクフラグを含む構造体を埋めます。 media_link_desc その後、その構造体へのポインタを渡してMEDIA_IOC_SETUP_LINK ioctを呼び出します。

設定可能なプロパティはただ一つで、 ENABLED リンクフラグでリンクを有効/無効にするものです。リンクフラグでマークされたリンクは有効または無効にできません IMMUTABLE リンクフラグ

リンクの設定は他のリンクに副作用を及ぼしません。シンクパッドで有効なリンクがリンクを有効にできない場合、ドライバーはエラーを返します。 EBUSY エラー コードに設定します。

みつからないリンク、または変更不可能なリンクの設定を試みた場合 DYNAMIC ストリーミング中のメディアデータを処理している間、リンクフラグで指定されたリンクのみが有効/無効にできます。ストリーミング中の非動的リンクを有効/無効にしようとすると、エラーが返されます。 EBUSY エラー コードに設定します。

指定されたリンクが見つからない場合、ドライバーはエラーを返します。 EINVAL エラー コードに設定します。

5.8.5. 戻り値¶

成功した場合、0 が返されます。エラーの場合、-1 が返され、変数が適切に設定されます。 errno 一般的なエラーコードは、 汎用エラーコード 章。

EINVAL

構造体 media_link_desc 非存在するリンクを参照している、またはリンクが変更不可能であり、その設定を変更しようとした場合
