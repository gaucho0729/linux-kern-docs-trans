用語集¶

注意

このセクションの目的は、メディアユーザースペースAPIドキュメント内で使用される用語を標準化することです。これは作業中です。

Bridge Driver¶

A デバイスドライバ メディアハードウェアと通信するための主要なロジックを実装しています。

CEC API¶

コンシューマー・エレクトロニクス制御API

HDMI CECインターフェースを介してデータを受信および送信するためのAPIです。

参照 第5部 - コンシューマエレクトロニクス制御API.

デバイスドライバ¶

Linux Kernelの一部で、ハードウェアコンポーネントのサポートを実装しています。

デバイスノード¶

カーネルドライバーとデータをやり取りするためのキャラクターデバイスノードです。

Digital TV API¶

以前はDVB APIと呼ばれていました。

特定のサブセットを制御するためのAPIです。 メディアハードウェア デジタルTV（例：DVB、ATSC、ISDBなど）を実装しています。

参照 第2部 - デジタルTV API.

DSP¶

デジタル信号処理装置（DSP）

専用の マイクロプロセッサデジタル信号処理の運用ニーズに最適化されたアーキテクチャを持つものです。

FPGA¶

フィールドプログラマブルゲートアレイ（FPGA）

ある IC 製造後に顧客や設計者が設定できるように設計された回路です。

参照 https://en.wikipedia.org/wiki/Field-programmable_gate_array.

ハードウェア コンポーネント¶

以下のサブセットです。 メディアハードウェア例えば、 I²C または SPI デバイス、または IP ブロック 内の SoC または FPGA.

ハードウェア パーティキュラ¶

グループの ハードウェアコンポーネント を組み合わせて、より大きなユーザー向けの機能的な外設機器を構成します。例えば、 SoC ISP IP ブロック 外部カメラセンサーと組み合わせて、カメラハードウェア外設機器を構成します。

別名 Peripheral.

I²C¶

I²C（インターフェース・インテグレーテッド・サーキット）

複数のマスターおよびスレーブ、パケット交換、シングルエンドのシリアルコンピュータバスで、サブデバイスなどのハードウェアコンポーネントを制御します。

参照 http://www.nxp.com/docs/en/user-guide/UM10204.pdf.

IC¶

集積回路（IC）

半導体材料（通常はシリコン）の小さな平たい板上に配置された電子回路の集合です。

チップとも呼ばれます。

IP ブロック¶

知的財産コア（IPコア）

電子設計において、半導体知的財産コアは、特定の当事者に属する論理、セル、または集積回路レイアウト設計の再利用可能な単位です。IPブロックは他の当事者にライセンスされるか、または単一の当事者が所有して使用できます。

参照 https://en.wikipedia.org/wiki/Semiconductor_intellectual_property_core).

ISP¶

画像信号処理装置（ISP）

画像データの処理に特化したプロセッサで、レンズシャドウ補正、デモザイキング、スケーリング、ピクセルフォーマット変換などのアルゴリズムを実装します。ISPは、自動露出、ホワイトバランス、フォーカスなどの制御アルゴリズムの使用に必要な統計情報も生成します。

メディアAPI¶

メディアハードウェアを制御するためのユーザースペースAPIの集合です。これは以下のもので構成されています：

  • CEC API;

  • Digital TV API;

  • MC API;

  • RC API；および

  • V4L2 API.

参照 Linux Media Infrastructure ユーザースペースAPI.

MC API¶

メディアコントローラーAPI

マルチメディアデバイスとサブデバイス間の関係を公開および制御するためのAPIです。

参照 第 IV 章 - Media Controller API.

MC中心的¶

V4L2ハードウェア 必要なデバイスドライバーは MC API.

このようなドライバーは V4L2_CAP_IO_MC device_capsフィールドが設定されています（参照 ioctl VIDIOC_QUERYCAP).

参照 V4L2を介してハードウェア外設機器を制御する 詳細についてはこちら。

メディアハードウェア¶

Linux Media APIでサポートされているハードウェアのサブセット

これはオーディオおよびビデオの収録・再生ハードウェア、デジタルおよびアナログTV、カメラセンサー、ISP、リモコン、コーデック、HDMI Consumer Electronics Control、HDMI収録など、メディアハードウェアの一部を含みます

マイクロプロセッサ¶

コンピュータプログラムの指示に従って電子回路が実行する基本的な算術、論理、制御および入出力(I/O)操作を1つの集積回路で実行する電子回路

Peripheral¶

同じく ハードウェア パーティキュラ.

RC API¶

リモコンコントローラAPI

リモコンからデータを受信および送信するためのAPI

参照 第3部 - リモコンAPI.

SMBus¶

I²Cのサブセットで、バスの使用をより厳格に定義しています

SPI¶

シリアルペリフェラルインターフェースバス

短距離通信に主に使用される同期シリアル通信インターフェース仕様、埋め込みシステムで使用されます

SoC¶

システムオンチップ

コンピュータやその他の電子システムのすべてのコンポーネントを統合した集積回路

V4L2 API¶

V4L2ユーザースペースAPI

定義されたユーザースペースAPI 第1部 - Video for Linux APIV4L2ハードウェアを制御するために使用されます

V4L2デバイスノード¶

A デバイスノード V4Lドライバに関連付けられています

V4L2デバイスノードの命名規則は以下に定義されています V4L2デバイスノードの命名.

V4L2ハードウェア¶

サポートされているメディアハードウェアの一部 V4L2 API.

V4L2サブデバイス¶

V4L2ハードウェアコンポーネントで、コントロールされていない Bridge Driverのみ サブデバイスインターフェース.

Video-node-centric¶

メディアコントローラーを使用しなくても動作するV4L2デバイスドライバ

このようなドライバは V4L2_CAP_IO_MC device_capsフィールドが未設定になっています（参照 ioctl VIDIOC_QUERYCAP).

V4L2サブデバイスAPI¶

の V4L2 API を制御する V4L2サブデバイスセンサー、HDMI受信機、スケーラー、デインターレーサーなど

参照 V4L2を介してハードウェア外設機器を制御する 詳細についてはこちら。
