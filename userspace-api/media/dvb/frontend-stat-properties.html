2.3.2. フロントエンド統計インジケーター¶

値は dtv_property.statを通じて返されます。このプロパティがサポートされている場合、 dtv_property.stat.len がゼロより大きいです。

ほとんどの配信システムでは、 dtv_property.stat.len が統計がサポートされている場合1となり、各パラメータに対して単一の値が返されます。

ただし、新しいOFDM配信システム（例：ISDB）では、キャリアグループごとに異なる変調タイプを使用することがあります。このような規格では、最大で3つの統計グループが提供され、 dtv_property.stat.len は「グローバル」メトリクスを反映し、各キャリアグループ（ISDBでは「レイヤー」と呼ばれる）ごとに1つのメトリクスが追加されます。

他の配信システムと整合性を保つため、 dtv_property.stat.dtv_stats 配列の最初の値はグローバルメトリクスを表し、他の要素はレイヤーごとに順にレイヤーA（インデックス1）、レイヤーB（インデックス2）などとなります。

埋められた要素数は dtv_property.stat.len.

配列の各要素は2つの要素からなり、 dtv_property.stat.dtv_stats は測定値の符号付き値（dB測定値）で、

  • svalue または uvalueでは、 svalue は符号なし値（カウンタ、相対スケール）です。 uvalue - 値のスケール。これは以下の通りです：

  • scale - フロントエンドがこのパラメータをサポートしていますが、収集できませんでした（一時的または永久的な状態の可能性があります）

    • FE_SCALE_NOT_AVAILABLE - これは符号付き値で、1/1000 dB単位で測定されます

    • FE_SCALE_DECIBEL - これは符号なし値で、0は0%を、65535は100%を表します

    • FE_SCALE_RELATIVE - これはイベントの発生回数をカウントする符号なし値です（例：ビットエラー、ブロックエラー、経過時間など）

    • FE_SCALE_COUNTER チューナーやデモッドのアナログ部分における信号強度レベルを示します。

2.3.2.1. DTV_STAT_SIGNAL_STRENGTH¶
