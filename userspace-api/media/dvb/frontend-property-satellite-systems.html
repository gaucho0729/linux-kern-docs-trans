2.3.5. 衛星配信システムで使用されるプロパティ。¶

2.3.5.1. DVB-S 配信システム¶

DVB-S に有効なパラメータは次の通りです:

  • DTV_API_VERSION

  • DTV_DELIVERY_SYSTEM

  • DTV_TUNE

  • DTV_CLEAR

  • DTV_FREQUENCY

  • DTV_INVERSION

  • DTV_SYMBOL_RATE

  • DTV_INNER_FEC

  • DTV_VOLTAGE

  • DTV_TONE

さらに、以下の DTV QoS統計 も有効です。

今後の実装では、この2つの欠けているパラメータが追加される可能性があります:

  • DTV_DISEQC_MASTER

  • DTV_DISEQC_SLAVE_REPLY

2.3.5.2. DVB-S2 配信システム¶

DVB-S に有効なすべてのパラメータに加えて、DVB-S2 は次のパラメータをサポートしています:

  • DTV_MODULATION

  • DTV_PILOT

  • DTV_ROLLOFF

  • DTV_STREAM_ID

  • DTV_SCRAMBLING_SEQUENCE_INDEX

さらに、以下の DTV QoS統計 も有効です。

2.3.5.3. Turbo コード配信システム¶

DVB-S に有効なすべてのパラメータに加えて、Turbo コードは次のパラメータをサポートしています:

  • DTV_MODULATION

2.3.5.4. ISDB-S 配信システム¶

ISDB-S に有効なパラメータは次の通りです:

  • DTV_API_VERSION

  • DTV_DELIVERY_SYSTEM

  • DTV_TUNE

  • DTV_CLEAR

  • DTV_FREQUENCY

  • DTV_INVERSION

  • DTV_SYMBOL_RATE

  • DTV_INNER_FEC

  • DTV_VOLTAGE

  • DTV_STREAM_ID
