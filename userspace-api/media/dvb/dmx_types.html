struct dmx_filter（デムックフィルタ）¶

セクションヘッダーフィルタを指定します。

定義

struct dmx_filter {
  __u8 filter[DMX_FILTER_SIZE];
  __u8 mask[DMX_FILTER_SIZE];
  __u8 mode[DMX_FILTER_SIZE];
};

メンバ

filter

セクションヘッダーで一致するビットを含むビット配列。

mask

フィルタービット配列で有効なビット。

mode

一致モード: ビットがゼロの場合、等しい場合に一致します（正規一致）；ビットが1の場合、ビットが否定された場合に一致します。

注意

この構造体のすべての配列はDMX_FILTER_SIZE（16バイト）のサイズを持ちます。

struct dmx_sct_filter_params¶

セクションフィルタを指定します。

定義

struct dmx_sct_filter_params {
  __u16 pid;
  struct dmx_filter filter;
  __u32 timeout;
  __u32 flags;
#define DMX_CHECK_CRC       1;
#define DMX_ONESHOT         2;
#define DMX_IMMEDIATE_START 4;
};

メンバ

pid

フィルタリングされるPIDです。

filter

セクションヘッダーフィルタ、定義に従って struct dmx_filter.

timeout

フィルタリングの最大時間（ミリ秒単位）。

flags

セクションフィルタの追加フラグ。

説明

MPEG-TSセクションフィルタの設定を保持します。

以下の フラグ 可能です:

  • DMX_CHECK_CRC - CRCチェックが成功したセクションのみ配信します；

  • DMX_ONESHOT - 1つのセクションが配信された後、セクションフィルタを無効化します；

  • DMX_IMMEDIATE_START - 事前にリクエストを待たずにフィルタを即座に開始します DMX_START.

input

output

デマルチプレクサ出力、指定に従って enum dmx_output.

flags

struct dmx_stc¶

システムタイムカウンタ（STC）情報を保持します。

定義

struct dmx_stc {

メンバ

num

入力データ: STCの番号、0からNまで。

base

出力: STCを90kHzクロックに変換するための除数。

stc

出力: stc in base * 90kHz単位。

enum dmx_buffer_flags¶

DMXメモリマップバッファフラグ

定数

DMX_BUFFER_FLAG_HAD_CRC32_DISCARD

カーネルが誤ったCRC32チェックサムのため、1つ以上のフレームを破棄したことを示します。

DMX_BUFFER_FLAG_TEI

カーネルがフィルタリングされたpidでトランスポートエラーインジケーター（TEI）を検出したことの示します。

DMX_BUFFER_PKT_COUNTER_MISMATCH

カーネルがフィルタリングされたpidでパケットカウンタの不一致を検出したことの示します。

DMX_BUFFER_FLAG_DISCONTINUITY_DETECTED

カーネルが1つ以上のフレーム不連続性を検出したことの示します。

DMX_BUFFER_FLAG_DISCONTINUITY_INDICATOR

フレーム不連続性インジケーターを持つパケットを少なくとも1つ受信しました。

struct dmx_buffer¶

dmxバッファ情報

定義

struct dmx_buffer {
  __u32 index;
  __u32 bytesused;
  __u32 offset;
  __u32 length;
  __u32 flags;
  __u32 count;
};

メンバ

index

バッファのID番号

bytesused

バッファ内のデータ（ペイロード）で占めるバイト数；

offset

メモリ == DMX_MEMORY_MMAPのバッファの場合；この平面のデバイスメモリの開始位置からのオフセット（またはmmap()に渡すオフセットとして使用すべき「クッキー」）

length

バッファのバイト数

flags

定義に従ったバッファフラグのビット配列 enum dmx_buffer_flagsのみに設定されます。 DMX_DQBUF.

count

埋められたバッファの単調カウンター。データストリームのロスを特定するのに役立ちます。のみに設定されます。 DMX_DQBUF.

説明

ストリーミングI/Oメソッドの1つを使用してアプリケーションとドライバーでやり取りされるデータを保持します。

注意してください、以下の通りで DMX_QBUF、のみ index 埋め込まれるべきです。On DMX_DQBUF 呼び出しでは、すべてのフィールドがカーネルによって埋め込まれます。

struct dmx_requestbuffers¶

dmxバッファ情報のリクエスト

定義

struct dmx_requestbuffers {
  __u32 count;
  __u32 size;
};

メンバ

count

リクエストされたバッファの数、

size

要求されたバッファのバイト数

説明

DMXバッファを要求するために使用されるデータを含みます。すべての予約済みフィールドはゼロに設定する必要があります。

struct dmx_exportbuffer¶

DMABUFファイル記述子としてのDMXバッファのエクスポート

定義

struct dmx_exportbuffer {
  __u32 index;
  __u32 flags;
  __s32 fd;
};

メンバ

index

バッファのID番号

flags

新規に作成されたファイルのフラグ、現在はO_CLOEXECのみがサポートされています。詳細については、openシステムコールのマニュアルを参照してください

fd

DMABUFに関連付けられたファイル記述子（ドライバによって設定されます）

説明

DMXバッファをDMABUFファイル記述子としてエクスポートするために使用されるデータを含みます。バッファはDMX_QUERYBUFによって返される'cookie'で識別されます（ユーザー空間へのバッファのマッピングに使用されるcookieと同じです）。すべての予約済みフィールドはゼロに設定する必要があります。reserved0フィールドは、構造体の内容の代替レイアウトを可能にする'型'構造体になる予定です。したがって、このフィールドは他の拡張には使用しないでください。
