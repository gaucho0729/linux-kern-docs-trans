3.2.14. DMX_ADD_PID¶

3.2.14.1. 名前¶

DMX_ADD_PID

3.2.14.2. 概要¶

DMX_ADD_PID¶

int ioctl(fd, DMX_ADD_PID, __u16 *pid)

3.2.14.3. 引数¶

fd

返されるファイル記述子 open().

pid

フィルタリング対象のPID番号

3.2.14.4. 説明¶

このioctlコールは、以前にDMX_SET_PES_FILTERで設定されたトランスポートストリームフィルタに複数のPIDを追加する機能を提供します DMX_SET_PES_FILTER および出力が DMX_OUT_TSDEMUX_TAP.

3.2.14.5. 戻り値¶

成功した場合、0が返されます。

エラーの場合、-1が返され、 errno 変数が適切に設定されます。

一般的なエラー コードは次のページで説明されています。 汎用エラーコード 章。
