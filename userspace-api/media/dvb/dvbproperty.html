2.3. プロパティの種類¶

デジタルTVの物理チャンネルにチューニングし、デコードを開始するには、チューナー、デモジュレータ、線形ローノイズ増幅器（LNA）を制御し、衛星機器制御（SEC）を介してアンテナサブシステムを設定するためのパラメータを変更する必要があります。実際のパラメータは、各デジタルTV規格に固有であり、デジタルTV仕様が進化するにつれて変化する可能性があります。

過去（DVB APIバージョン3 - DVBv3まで）、DVB-S、DVB-C、DVB-TおよびATSC配信システムのチューニングに必要なパラメータをまとめたユニオンを使用していました。問題は、第二世代規格が登場した際、そのユニオンのサイズが新しい規格に必要な構造体を含むには十分ではなかったことです。また、拡張を行うとユーザー空間が破壊される可能性がありました。

そのため、ユニオン/構造体ベースのアプローチは廃止され、プロパティセットアプローチが採用されました。このアプローチでは、 FE_GET_PROPERTY および FE_SET_PROPERTY を用いてフロントエンドを設定し、その状態を読み取ります。

実際の動作は、dtv_propertyコマンド/データペアのセットによって決定されます。1つのioctlで最大64のプロパティを取得/設定することが可能です。

このセクションでは、すべてのデジタルTV配信システムをサポートする新しいおよび推奨されるフロントエンドの設定方法について説明します。

注意

  1. Linux DVB APIバージョン3では、フロントエンドの設定は構造体 dvb_frontend_parameters.

  2. DVB APIバージョン3の呼び出しは、新しい規格をサポートするハードウェアでは使用しないでください。このAPIは新しい規格や新しいハードウェアへのサポートが極めて限られています。

  3. 現在、ほとんどのフロントエンドは複数の配信システムをサポートしています。複数の配信システムをサポートするフロントエンドで切り替えるには、DVB APIバージョン5の呼び出しを使用する必要があります。

  4. DVB APIバージョン5はまた S2APIと呼ばれます。最初に追加された新しい規格はDVB-S2でした。

例: デジタルTVのフロントエンドをDVB-Cチャンネルにチューニングするには、651kHzで256-QAMでモジュレーションされ、FEC 3/4、シンボルレート5.217 Mbaudsのチャンネルを設定するため、これらのプロパティを FE_SET_PROPERTY ioctl:

DTV_DELIVERY_SYSTEM = SYS_DVBC_ANNEX_A

DTV_FREQUENCY = 651000000

DTV_MODULATION = QAM_256

DTV_INVERSION = INVERSION_AUTO

DTV_SYMBOL_RATE = 5217000

DTV_INNER_FEC = FEC_3_4

DTV_TUNE

上記の動作を行うコードは 例: デジタルTVフロントエンドプロパティの設定.

例: デジタルTVフロントエンドプロパティの設定¶
#include <stdio.h>
#include <fcntl.h>
#include <sys/ioctl.h>
#include <linux/dvb/frontend.h>

static struct dtv_property props[] = {
    { .cmd = DTV_DELIVERY_SYSTEM, .u.data = SYS_DVBC_ANNEX_A },
    { .cmd = DTV_FREQUENCY,       .u.data = 651000000 },
    { .cmd = DTV_MODULATION,      .u.data = QAM_256 },
    { .cmd = DTV_INVERSION,       .u.data = INVERSION_AUTO },
    { .cmd = DTV_SYMBOL_RATE,     .u.data = 5217000 },
    { .cmd = DTV_INNER_FEC,       .u.data = FEC_3_4 },
    { .cmd = DTV_TUNE }
};

static struct dtv_properties dtv_prop = {
    .num = 6, .props = props
};

int main(void)
{
    int fd = open("/dev/dvb/adapter0/frontend0", O_RDWR);

    if (!fd) {
        perror ("open");
        return -1;
    }
    if (ioctl(fd, FE_SET_PROPERTY, &dtv_prop) == -1) {
        perror("ioctl");
        return -1;
    }
    printf("Frontend set\\n");
    return 0;
}

注意

上記の例のようにカーネルコードを直接呼び出すことは可能です。ただし、強く推奨されるのは libdvbv5これはサポートされているデジタルTV基準と作業を行うための抽象化を提供し、プログラムスキャンやチャネル記述ファイルの読み書きなどの通常操作に必要なメソッドを提供します。
