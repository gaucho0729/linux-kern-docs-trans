2.3.3.3. ISDB-T デリバリー・システム¶

ISDB-T/ISDB-Tsb API 拡張は、すべての ISDB-T/ISDB-Tsb ハードウェアをチューニングするために必要な情報を反映する必要があります。もちろん、非常に高度なデバイスでは、特定のパラメータをチューニングに必要としない可能性もあります。

ここに示す情報は、Linux デジタルTV API を使って ISDB-T および ISDB-Tsb ハードウェアを扱う方法をアプリケーション開発者に理解させるために役立ちます。

ここに示す ISDB-T および ISDB-Tsb に関する詳細は、必要なパラメータ値間の依存関係を基本的に示す程度であり、確実に一部の情報は省略されています。より詳細な情報については、次のドキュメントを参照してください:

ARIB STD-B31 - 「デジタル地上テレビ放送用送信システム」および

ARIB TR-B14 - 「デジタル地上テレビ放送の運用ガイドライン」。

ISDB 特有のパラメータを理解するには、ISDB-T および ISDB-Tsb のチャンネル構造についての知識が必要です。つまり、読者には ISDB-T チャンネルが13セグメントから構成され、最大で3層がそれらのセグメントを共有できるということが理解されている必要があります。

ISDB-T に有効なパラメータは次の通りです:

  • DTV_API_VERSION

  • DTV_DELIVERY_SYSTEM

  • DTV_TUNE

  • DTV_CLEAR

  • DTV_FREQUENCY

  • DTV_BANDWIDTH_Hz

  • DTV_INVERSION

  • DTV_GUARD_INTERVAL

  • DTV_TRANSMISSION_MODE

  • DTV_ISDBT_LAYER_ENABLED

  • DTV_ISDBT_PARTIAL_RECEPTION

  • DTV_ISDBT_SOUND_BROADCASTING

  • DTV_ISDBT_SB_SUBCHANNEL_ID

  • DTV_ISDBT_SB_SEGMENT_IDX

  • DTV_ISDBT_SB_SEGMENT_COUNT

  • DTV_ISDBT_LAYERA_FEC

  • DTV_ISDBT_LAYERA_MODULATION

  • DTV_ISDBT_LAYERA_SEGMENT_COUNT

  • DTV_ISDBT_LAYERA_TIME_INTERLEAVING

  • DTV_ISDBT_LAYERB_FEC

  • DTV_ISDBT_LAYERB_MODULATION

  • DTV_ISDBT_LAYERB_SEGMENT_COUNT

  • DTV_ISDBT_LAYERB_TIME_INTERLEAVING

  • DTV_ISDBT_LAYERC_FEC

  • DTV_ISDBT_LAYERC_MODULATION

  • DTV_ISDBT_LAYERC_SEGMENT_COUNT

  • DTV_ISDBT_LAYERC_TIME_INTERLEAVING

さらに、以下の DTV QoS統計 も有効です。
