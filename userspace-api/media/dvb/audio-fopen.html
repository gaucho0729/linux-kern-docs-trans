6.3.2.1. デジタルTVオーディオ open()¶

6.3.2.1.1. 名前¶

デジタルTVオーディオ open()

注意

このioctlは非推奨です

6.3.2.1.2. 概要¶

int open(const char *deviceName, int フラグ)¶

6.3.2.1.3. 引数¶

const char *deviceName

特定のオーディオデバイスの名前。

int flags

以下のフラグのビットごとのORです：

O_RDONLY 読み取り専用アクセス

O_RDWR 読み込み/書き込みアクセス

O_NONBLOCK 非ブロッキングモードで開く

(ブロッキングモードがデフォルトです)

6.3.2.1.4. 説明¶

このシステムコールは、指定されたオーディオデバイス（例：/dev/dvb/adapter0/audio0）を開き、その後の使用を可能にします。open()コールが成功すると、デバイスは使用可能になります。ブロッキングモードと非ブロッキングモードの違いは、関連する関数のドキュメントで説明されています。open()コール自体のセマンティクスには影響を与えません。ブロッキングモードで開いたデバイスは、fcntlシステムコールのF_SETFLコマンドを使用して後に非ブロッキングモードに変更（逆も可能）できます。これは標準のシステムコールであり、Linuxマニュアルページのfcntlドキュメントに記載されています。オーディオデバイスはO_RDWRモードで1つのユーザーだけが開くことができます。他のユーザーがこのモードで開こうとすると失敗し、エラーコードが返されます。オーディオデバイスがO_RDONLYモードで開かれると、使用可能なioctlコールはAUDIO_GET_STATUSのみです。他のコールはすべてエラーコードで終了します。

6.3.2.1.5. 戻り値¶

ENODEV

デバイスドライバがロードされていない/利用不可。

EBUSY

デバイスまたはリソースがビジー。

EINVAL

無効な引数。
