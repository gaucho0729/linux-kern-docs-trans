2.3.1. デジタルTVプロパティパラメータ¶

いくつかの異なるデジタルTVパラメータがあり、これらは FE_SET_PROPERTYおよびFE_GET_PROPERTY ioctls。このセクションではこれらをそれぞれ説明します。ただし、フロントエンドを設定するために必要なのはこれらの中の一部です。

2.3.1.1. DTV_UNDEFINED¶

内部的に使用されます。GET/SET操作は変更または返却値をもたらしません。

2.3.1.2. DTV_TUNE¶

キャッシュデータを解釈し、伝統的なフロントエンドチューナーリクエストを構築して、次の検証を通過できるようにします FE_SET_FRONTEND ioctl.

2.3.1.3. DTV_CLEAR¶

フロントエンド固有のキャッシュデータをリセットします。これはハードウェアには影響しません。

2.3.1.4. DTV_FREQUENCY¶

デジタルTVトランスポンダー/チャンネルの周波数。

注意

  1. 衛星配信システムでは、周波数はkHz単位です。

  2. ケーブルおよび地上配信システムでは、周波数はHz単位です。

  3. ほとんどの配信システムでは、周波数はトランスポンダー/チャンネルの中心周波数です。例外はISDB-Tで、メインキャリアが中心から1/7のオフセットを持つ場合です。

  4. ISDB-Tでは、チャンネルは通常、約143kHzのオフセットで送信されます。例えば、有効な周波数は474,143kHzです。ステッピングはチャンネルの帯域幅に依存し、通常は6MHzです。

  5. ISDB-Tsbでは、チャンネルは1つまたは3つのセグメントのみからなり、周波数ステップは429kHz、3*429kHzです。

2.3.1.5. DTV_MODULATION¶

複数の変調をサポートする配信システムのフロントエンド変調タイプを指定します。

変調は、enumで定義されたタイプのいずれかです。 fe_modulation.

ほとんどのデジタルTV規格は、複数の変調タイプをサポートしています。

2.3.1.21. DTV_ISDBT_SB_SUBCHANNEL_ID¶

ISDB専用です。

このフィールドは、 DTV_ISDBT_SOUND_BROADCASTING 1の場合。

(著者の注: この説明が完全に正確であるとは限りませんが、 SUBCHANNEL-ID 詳細には正確ではありませんが、デバイスをプログラミングするために必要な技術的背景を理解したものです。)

ISDB-Tsbチャンネル（1セグメントまたは3セグメント）は、単独でまたは複数の接続されたISDB-Tsbチャンネルのセットで放送できます。このセット内の各チャンネルは独立して受信可能です。接続されたISDB-Tsbセグメントの数は、利用可能な周波数帯域幅に応じて変化します。

例: 8つのISDB-Tsb接続セグメントが放送されているとします。放送局はこれらのチャンネルを放送するためのいくつかの選択肢があります。通常の13セグメントISDB-Tスペクトルを仮定すると、8セグメントを位置1-8から5-13に、またはその間のどこかに配置できます。

セグメントの下層にはサブチャンネルがあります。各セグメントは、事前に定義されたIDを持つ複数のサブチャンネルで構成されています。サブチャンネルは、デモジュレータがチャンネルに同期するのを助けるために使用されます。

ISDB-Tチャンネルは常にすべてのサブチャンネルの中心に位置します。上記の例のように、ISDB-Tsbではこれほど単純ではありません。

The DTV_ISDBT_SB_SUBCHANNEL_ID このパラメータは、デモジュレーションするセグメントのサブチャンネルIDを指定します。

可能な値: 0 .. 41, -1 (AUTO)

このフィールドは、 DTV_ISDBT_SOUND_BROADCASTING 1の場合。

DTV_ISDBT_SB_SEGMENT_IDX 複数のセグメントが接続して送信されるISDB-Tsbチャンネルにおいて、デモジュレーションするセグメントのインデックスを指定します。

2.3.1.24. DTV-ISDBT-LAYER[A-C] パラメータ¶

ISDB専用です。

ISDB-Tチャンネルは階層的に符号化できます。DVB-Tとは異なり、ISDB-Tでは階層的な層が同時に復号可能です。そのため、ISDB-Tデモジュレータには3つのViterbiおよび3つのReed-Solomon復号器が搭載されています。

ISDB-Tには3つの階層的な層があり、それぞれが利用可能なセグメントの一部を使用できます。ISDB-Tでは、すべての層のセグメントの総数は13にしなければなりません。

レイヤーA、B、Cそれぞれに3つのパラメータセットがあります。

2.3.1.24.1. DTV_ISDBT_LAYER_ENABLED¶

ISDB専用です。

ISDB-Tにおける階層受信は、復号プロセスでのレイヤーの有効/無効により実現されます。すべてのビットを DTV_ISDBT_LAYER_ENABLED 1に設定すると、すべてのレイヤー（適用可能な場合）が復調されます。これはデフォルトの設定です。

チャンネルが部分受信モード（DTV_ISDBT_PARTIAL_RECEPTION = 1）の場合、中央セグメントは他の12セグメントとは独立して復号可能です。このモードではレイヤーAの SEGMENT_COUNT 値が1でなければなりません。

ISDB-TsbではレイヤーAのみが使用され、ISDB-TsbではレイヤーAが1または3に設定されることが可能です（ DTV_ISDBT_PARTIAL_RECEPTION. SEGMENT_COUNT に従って）。

最初の3ビットの値のみが使用されます。他のビットは無視されます：

DTV_ISDBT_LAYER_ENABLED ビット0: レイヤーAを有効にする

DTV_ISDBT_LAYER_ENABLED ビット1: レイヤーBを有効にする

DTV_ISDBT_LAYER_ENABLED ビット2: レイヤーCを有効にする

DTV_ISDBT_LAYER_ENABLED ビット3〜31: 未使用

2.3.1.24.2. DTV_ISDBT_LAYER[A-C]_FEC¶

注意

  1. レイヤーCが DQPSKの場合、レイヤーBは DQPSK.

  2. レイヤーBが DQPSK および DTV_ISDBT_PARTIAL_RECEPTION= 0の場合、レイヤーは DQPSK.

2.3.1.31. DTV_STREAM_ID¶

DVB-S2、DVB-T2およびISDB-Sで使用されます。

DVB-S2、DVB-T2およびISDB-Sは、単一のトランスポートストリーム上で複数のストリームを送信することをサポートしています。このプロパティにより、デジタルTVドライバーがハードウェアがサポートする場合にサブストリームフィルタリングを処理できます。デフォルトではサブストリームフィルタリングは無効です。

DVB-S2およびDVB-T2では、有効なサブストリームIDの範囲は0から255です。

ISDBでは、有効なサブストリームIDの範囲は1から65535です。

無効にするには、特別なマクロNO_STREAM_ID_FILTERを使用してください。

注意: ID範囲外の値もフィルタリングを無効にします。

2.3.1.33. DTV_ENUM_DELSYS¶

マルチ標準フロントエンドは提供する配信システムを宣伝する必要があります。アプリケーションは他の操作を使用する前に、フロントエンドが提供する配信システムを列挙する必要があります。FE_GET_INFOが導入される前は、フロントエンドのタイプを決定するために使用されていました。複数の配信システムを提供するフロントエンドではFE_GET_INFOはあまり役立ちません。マルチ標準フロントエンドを使用する意図があるアプリケーションは、FE_GET_INFOを使用するのではなく、それに関連する配信システムを列挙する必要があります。レガシーフロントエンドの場合、FE_GET_INFOと同じ結果が得られますが、より構造化された形式になります。

許容される値は fe_delivery_system.

2.3.1.34. DTV_INTERLEAVING¶

使用する時間間隔

許容される値は fe_interleaving.

2.3.1.35. DTV_LNA¶

低ノイズ増幅器

ハードウェアが制御可能なLNAが提供される場合があります。このパラメータを使用して手動で設定できます。通常、LNAは地上デバイスからしか見つけられない場合があります。

可能な値: 0、1、LNA_AUTO

0、LNAオフ

1、LNAオン

LNA_AUTOという特別なマクロを使用してLNAを自動設定してください

2.3.1.36. DTV_SCRAMBLING_SEQUENCE_INDEX¶

DVB-S2で使用されます。

この18ビットのフィールドは、存在する場合、EN 302 307の第5章5.5.4節で定義されたDVB-S2物理層スクランブルシーケンスのインデックスを運ぶ。受信機にスクランブルシーケンスインデックスを伝達する明示的な信号伝達方法は存在しない。S2衛星配信システム記述子が利用可能であれば、スクランブルシーケンスインデックスを読み取るのに使用できる（EN 300 468表41）。

デフォルトでは、goldスクランブルシーケンスインデックス0が使用される。

有効なスクランブルシーケンスインデックスの範囲は0から262142である。
