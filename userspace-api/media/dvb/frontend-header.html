struct dtv_stats¶

DTVステータスプロパティを読み取るために使用します

定義

struct dtv_stats {
  __u8 scale;
  union {
    __u64 uvalue;
    __s64 svalue;
  };
};

メンバ

scale

満たされています enum fecap_scale_params - そのパラメータの使用スケール

{unnamed_union}

匿名

uvalue

測定値の符号なし整数値で、以下の条件が満たされる場合に使用します スケール は以下のいずれか FE_SCALE_RELATIVE または FE_SCALE_COUNTER.

svalue

測定値の整数値で、以下の条件が満たされる場合に使用します FE_SCALE_DECIBEL、dB測定に使用されます。単位は0.001 dBです。

説明

ほとんどの配信システムでは、このプロパティは各パラメータに対して単一の値を返します。

ただし、新しいOFDM配信システム（例: ISDB）では、キャリアグループごとに異なる変調タイプを使用する場合があります。このような規格では、最大8つの統計グループが提供され、それぞれのキャリアグループ（ISDBでは「レイヤー」と呼ばれます）ごとに1つずつ提供されます。

他の配信システムと整合性を保つため、最初の値はすべてのキャリアセット（「グローバル」）を指します。

スケール キャリアグループ全体または特定のレイヤーの値がハードウェアによって提供されない場合に、この値を使用する必要があります。 FE_SCALE_NOT_AVAILABLE その値が提供されない場合にこの値を使用する必要があります。

len 最新の埋め込まれたステータス＋1で埋める必要があります。

言い換えれば、ISDBの場合、これらの値は以下のように埋める必要があります：

u.st.stat.svalue[0] = global statistics;
u.st.stat.scale[0] = FE_SCALE_DECIBEL;
u.st.stat.value[1] = layer A statistics;
u.st.stat.scale[1] = FE_SCALE_NOT_AVAILABLE (if not available);
u.st.stat.svalue[2] = layer B statistics;
u.st.stat.scale[2] = FE_SCALE_DECIBEL;
u.st.stat.svalue[3] = layer C statistics;
u.st.stat.scale[3] = FE_SCALE_DECIBEL;
u.st.len = 4;
struct dtv_fe_stats¶

デジタルTVフロントエンドの統計を保存します。

定義

struct dtv_fe_stats {
  __u8 len;
  struct dtv_stats stat[MAX_DTV_STATS];
};

メンバ

len

統計の長さ - 0の場合は統計が無効になります。

stat

デジタルTV統計の配列。

説明

ほとんどの標準では、 len 0または1のどちらかになります。ただし、ISDBの場合、各レイヤーは別々にモジュレーションされます。したがって、各レイヤーが独自の統計を持つ可能性があります。その場合、stat[0]はプロパティのグローバルな値を保持します。インデックス1〜3はレイヤーA〜Bを表します。
