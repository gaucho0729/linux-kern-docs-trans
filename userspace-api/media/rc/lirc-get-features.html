6.4.3. ioctl LIRC_GET_FEATURES¶

6.4.3.1. 名前¶

LIRC_GET_FEATURES - 基盤となるハードウェアデバイスの機能を取得します

6.4.3.2. 概要¶

LIRC_GET_FEATURES¶

int ioctl(int fd, LIRC_GET_FEATURES, __u32 *features)

6.4.3.3. 引数¶

fd

open()関数によって返されるファイルディスクリプタ

features

LIRCの機能を表すビットマスク

6.4.3.4. 説明¶

基盤となるハードウェアデバイスの機能を取得します。ドライバが特定の機能のサポートを宣言していない場合、対応するioctlの呼び出しは未定義です

6.4.3.5. LIRC機能¶

LIRC_CAN_REC_RAW

未使用。uAPIの破壊を防ぐためのみ保持しています

LIRC_CAN_REC_PULSE

未使用。uAPIの破壊を防ぐためのみ保持しています LIRC_MODE_PULSE 送信専用で使用できます

LIRC_CAN_REC_MODE2

これは受信用のRAW IRドライバです。これはつまり LIRC_MODE_MODE2 が使用されます。これもまた LIRC_MODE_SCANCODE がサポートされています（カーネルが十分新しい場合に限ります）。送信モードの切り替えには ioctls LIRC_GET_REC_MODE と LIRC_SET_REC_MODE を使用してください

LIRC_CAN_REC_LIRCCODE

未使用。uAPIの破壊を防ぐためのみ保持しています

LIRC_CAN_REC_SCANCODE

これは受信用のスキャンコードドライバです。これはつまり LIRC_MODE_SCANCODE が使用されます。

LIRC_CAN_SET_SEND_CARRIER

ドライバが modulation frequency（変調周波数）を変更可能で、 ioctl LIRC_SET_SEND_CARRIER.

LIRC_CAN_SET_SEND_DUTY_CYCLE

ドライバが duty cycle（デューティー比）を変更可能で、 ioctl LIRC_SET_SEND_DUTY_CYCLE.

LIRC_CAN_SET_TRANSMITTER_MASK

ドライバがアクティブな送信機（トランシーバー）を変更可能で、 ioctl LIRC_SET_TRANSMITTER_MASK.

LIRC_CAN_SET_REC_CARRIER

ドライバが受信用のキャリア周波数を設定可能で、 ioctl LIRC_SET_REC_CARRIER.

LIRC_CAN_SET_REC_DUTY_CYCLE_RANGE

未使用。uAPIの破壊を防ぐためのみ保持しています

LIRC_CAN_SET_REC_CARRIER_RANGE

ドライバが ioctl LIRC_SET_REC_CARRIER_RANGE.

LIRC_CAN_GET_REC_RESOLUTION

ドライバが ioctl LIRC_GET_REC_RESOLUTION.

LIRC_CAN_SET_REC_TIMEOUT

ドライバが ioctl LIRC_SET_REC_TIMEOUT.

LIRC_CAN_SET_REC_FILTER

未使用。uAPIの破壊を防ぐためのみ保持しています

LIRC_CAN_MEASURE_CARRIER

ドライバが変調周波数の測定をサポートしており、 ioctl LIRC_SET_MEASURE_CARRIER_MODE.

LIRC_CAN_USE_WIDEBAND_RECEIVER

ドライバが学習モードをサポートしており、 ioctl LIRC_SET_WIDEBAND_RECEIVER.

LIRC_CAN_NOTIFY_DECODE

未使用。uAPIの破壊を防ぐためのみ保持しています

LIRC_CAN_SEND_RAW

未使用。uAPIの破壊を防ぐためのみ保持しています

LIRC_CAN_SEND_PULSE

ドライバが送信（IRブースティングまたはIR TXと呼ばれる）をサポートしており、 LIRC_MODE_PULSE。これはつまり LIRC_MODE_SCANCODE が送信にもサポートされています（カーネルが十分新しい場合に限ります）。送信モードの切り替えには ioctls LIRC_GET_SEND_MODE と LIRC_SET_SEND_MODE を使用してください

LIRC_CAN_SEND_MODE2

未使用。uAPIの破壊を防ぐためのみ保持しています LIRC_MODE_MODE2 受信専用で使用できます

LIRC_CAN_SEND_LIRCCODE

未使用。uAPIの破壊を防ぐためのみ保持しています

6.4.3.6. 戻り値¶

成功した場合、0 が返されます。エラーの場合、-1 が返され、変数が適切に設定されます。 errno 一般的なエラーコードは、 汎用エラーコード 章。
