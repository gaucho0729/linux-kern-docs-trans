6.4.1. LIRC read()¶

6.4.1.1. 名前¶

lirc-read - LIRCデバイスから読み込む

6.4.1.2. 概要¶

#include <unistd.h>
ssize_t 読み取り(int fd, void *buf, size_t コピーする文字数)¶

6.4.1.3. 引数¶

fd

返されるファイル記述子 open().

buf

埋めるバッファ

count

読み込むバイト数の最大値

6.4.1.4. 説明¶

read() 最大で読み込む試みを行う count ファイルディスクリプタからバイトを読み込む fd バッファの開始位置から buf. count がゼロであれば、 read() ゼロを返し、他の結果は持ちません。もし count はより大きい SSIZE_MAX結果は未定義です

データの正確な形式は、ドライバが使用する LIRC モード 使用するドライバに依存します。使用 ioctl LIRC_GET_FEATURES サポートされているモードを取得するには、および使用 ioctls LIRC_GET_REC_MODE と LIRC_SET_REC_MODE 現在のアクティブモードを設定します。

モード LIRC_MODE_MODE2 はraw IR用で、chardevからIR信号を記述する無符号整数値を含むパケットが読み取られます。

代替として、 LIRC_MODE_SCANCODE このモードではソフトウェアデコーダーやハードウェアデコーダーによってデコードされるスキャンコードが利用可能です。The rc_proto メンバが設定されます。 IR プロトコル 送信用に使用され、 scancode デコードされたスキャンコードに設定され、 keycode キーコードに設定されます。 KEY_RESERVED.

6.4.1.5. 戻り値¶

成功した場合、読み取ったバイト数が返されます。この数値が要求されたバイト数よりも小さかったり、1フレーム分のデータ量よりも小さかったりしてもエラーではありません。エラーの場合、-1が返され、 errno 変数が適切に設定されます。
