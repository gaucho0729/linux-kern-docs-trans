4. リモコンテーブル¶

残念ながら、数年間、異なるデバイス用に統一されたIRキーコードを作成するための取り組みは行われていませんでした。これにより、同じIRキー名が異なるIRデバイスで完全に異なる方法でマッピングされ、結果として同じIRキー名が異なるIRで完全に異なるマッピングとなっていました。その結果、V4L2 APIは現在、メディアキーのマッピングに標準を指定しています。

この標準は、V4L/DVBドライバーやユーザー空間アプリケーションの両方で使用する必要があります。

モジュールはLinux入力レイヤー内でリモコンをキーボードとして登録します。これは、IRキー入力が通常のキーボードキー入力のように見えることになります（CONFIG_INPUT_KEYBOARDが有効の場合）。イベントデバイス（CONFIG_INPUT_EVDEV）を使用することで、アプリケーションは/dev/input/eventデバイス経由でリモコンにアクセスできます。

備考¶

単純なIR（チャンネルキーが別途ない場合）では、UPを KEY_CHANNELUP

単純なIR（チャンネルキーが別途ない場合）では、DOWNを KEY_CHANNELDOWN

単純なIR（ボリュームキーが別途ない場合）では、LEFTを KEY_VOLUMEDOWN
