2.2. cec close()¶

2.2.1. 名前¶

cec-close - cecデバイスを閉じる

2.2.2. 概要¶

#include <unistd.h>
int close(int fd)¶

2.2.3. 引数¶

fd

返されるファイル記述子 open().

2.2.4. 説明¶

cecデバイスを閉じます。ファイル記述子に関連するリソースが解放されます。デバイスの設定は変更されません。

2.2.5. 戻り値¶

close() 成功時は0を返します。エラーの場合、-1が返され、 errno 適切に設定されます。可能なエラー コードは:

EBADF

fd 有効なオープンファイル記述子ではありません。
