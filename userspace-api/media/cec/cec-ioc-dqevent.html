2.9. ioctl CEC_DQEVENT¶

2.9.1. 名前¶

CEC_DQEVENT - CECイベントをキューから取得する

2.9.2. 概要¶

CEC_DQEVENT¶

int ioctl(int fd, CEC_DQEVENT, struct cec_event *argp)

2.9.3. 引数¶

fd

返されるファイル記述子 open().

argp

2.9.4. 説明¶

CECデバイスは非同期イベントを送信できます。これらは呼び出しによって取得できます CEC_DQEVENT()ファイルディスクリプタが非ブロッキングモードで、待機中のイベントがない場合、-1を返し、errnoをエラー コードに設定します。 EAGAIN エラー コードに設定します。

内部イベントキューはファイルハンドルとイベントタイプごとに設定されます。キューに容量がなくなった場合、最後のイベントが新しいイベントで上書きされます。これは中間結果を無視できるが、最新のイベントは常に利用可能であることを意味します。また、連続する同じ値を持つイベントを読み取ることが可能であることを意味します（例：同じ状態を持つ2つのイベント） CEC_EVENT_STATE_CHANGE その場合、中間の状態変化は失われますが、2つのイベントの間に状態が変化したことは保証されています。

type cec_event_state_change¶
struct cec_event_state_change¶

__u16

phys_addr

現在の物理アドレス。これは CEC_PHYS_ADDR_INVALID 有効な物理アドレスが設定されていない場合です。

__u16

log_addr_mask

現在の要求された論理アドレスのセット。論理アドレスが要求されていない場合または phys_addr 通常のRCU読み込み側クリティカルセクションは、条件付きでスリープロックを取得することが許容されます（例として CEC_PHYS_ADDR_INVALID。ビット15が設定されている場合（1 << CEC_LOG_ADDR_UNREGISTERED）このデバイスは未登録の論理アドレスを持っています。その場合、他のすべてのビットは0です。

__u16

have_conn_info

非ゼロの場合、HDMIコネクタ情報が利用可能です。このフィールドは、 CEC_CAP_CONNECTOR_INFO が設定されています。この機能が設定されており、 have_conn_info がゼロの場合、HDMIコネクタデバイスがインスタンス化されていないことを示します。これはHDMIドライバがまだデバイスを設定しているか、またはHDMIデバイスがアンバインドされたためです。
type cec_event_lost_msgs¶
struct cec_event_lost_msgs¶

__u32

lost_msgs

ファイルハンドルが開かれた以来またはこのファイルハンドルでこのイベントが最後にキューから取得された以来に失われたメッセージの数に設定されます。失われたメッセージは最も古いメッセージです。新しいメッセージが到着し、さらに容量がない場合、最も古いメッセージが削除されて新しいメッセージのためのスペースを確保します。メッセージキューの内部サイズは、過去2秒間に受信したすべてのメッセージを保存することを保証しています。CEC仕様ではメッセージは1秒以内に応答する必要がありますので、これ以上は十分です。

CECイベントの種類¶

CEC_EVENT_STATE_CHANGE

1

CECアダプターの状態が変化したときに生成されます。open()が呼び出された際には、そのファイルハンドルに対してその時点のCECアダプターの状態で初期イベントが生成されます。

CEC_EVENT_LOST_MSGS

2

アプリケーションがCECメッセージを十分に速くデキューイングできなかったため、1つ以上のCECメッセージが失われた場合に生成されます。

CEC_EVENT_PIN_CEC_LOW

3

CECピンが高電圧から低電圧への変化があったときに生成されます。このイベントは、キャパビリティが設定されているアダプターにのみ適用されます。 CEC_CAP_MONITOR_PIN キャパビリティが設定されているアダプターにのみ適用されます。

CEC_EVENT_PIN_CEC_HIGH

4

CECピンが低電圧から高電圧への変化があったときに生成されます。このイベントは、キャパビリティが設定されているアダプターにのみ適用されます。 CEC_CAP_MONITOR_PIN キャパビリティが設定されているアダプターにのみ適用されます。

CEC_EVENT_PIN_HPD_LOW

5

HPDピンが高電圧から低電圧への変化があったときに生成されます。このイベントは、キャパビリティが設定されているアダプターにのみ適用されます。 CEC_CAP_MONITOR_PIN キャパビリティが設定されているアダプターにのみ適用されます。open()が呼び出された際にはHPDピンの状態を読み取ることができ、HPDが低電圧の場合にはそのファイルハンドルに対して初期イベントが生成されます。

CEC_EVENT_PIN_HPD_HIGH

6

HPDピンが低電圧から高電圧への変化があったときに生成されます。このイベントは、キャパビリティが設定されているアダプターにのみ適用されます。 CEC_CAP_MONITOR_PIN キャパビリティが設定されているアダプターにのみ適用されます。open()が呼び出された際にはHPDピンの状態を読み取ることができ、HPDが高電圧の場合にはそのファイルハンドルに対して初期イベントが生成されます。

CEC_EVENT_PIN_5V_LOW

6

5Vピンが高電圧から低電圧への変化があったときに生成されます。このイベントは、キャパビリティが設定されているアダプターにのみ適用されます。 CEC_CAP_MONITOR_PIN キャパビリティが設定されているアダプターにのみ適用されます。open()が呼び出された際には5Vピンの状態を読み取ることができ、5Vが低電圧の場合にはそのファイルハンドルに対して初期イベントが生成されます。

CEC_EVENT_PIN_5V_HIGH

7

5Vピンが低電圧から高電圧への変化があったときに生成されます。このイベントは、キャパビリティが設定されているアダプターにのみ適用されます。 CEC_CAP_MONITOR_PIN キャパビリティが設定されているアダプターにのみ適用されます。open()が呼び出された際には5Vピンの状態を読み取ることができ、5Vが高電圧の場合にはそのファイルハンドルに対して初期イベントが生成されます。
CECイベントフラグ¶

CEC_EVENT_FL_INITIAL_STATE

1

デバイスがオープンされる際の初期イベントに設定されます。上記の表を参照してください。これによりアプリケーションは、open()のタイミングでのCECアダプターの初期状態を把握できます。

CEC_EVENT_FL_DROPPED_EVENTS

2

指定されたイベントタイプのイベントが1つ以上ドロップされた場合に設定されます。これはアプリケーションが追いつかないことを示すインジケーターです。

2.9.5. 戻り値¶

成功した場合、0 が返されます。エラーの場合、-1 が返され、変数が適切に設定されます。 errno 一般的なエラーコードは、 汎用エラーコード 章。

以下の ioctl CEC_DQEVENT 次のエラーコードを返すことができます：

EAGAIN

ファイルハンドルがノンブロッキングモードで待機中のイベントがなければ返されます。

ERESTARTSYS (システムコールが中断された)

ブロッキングモードでイベント待機中に割り込み（例: Ctrl-C）が到達した場合に発生します。
