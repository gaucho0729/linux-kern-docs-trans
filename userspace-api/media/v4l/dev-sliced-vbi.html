4.7. Sliced VBI Data Interface¶

VBIとはVertical Blanking Interval（垂直消去期間）の略で、アナログビデオ信号のラインシーケンスにおけるギャップを指します。VBI期間中は画像情報が送信されず、陰極管テレビの電子ビームが画面の上部に戻る間に一時的な空き時間を作り出します。

スライスドVBIデバイスは、ハードウェアを用いてVBIで送信されたデータを復調します。V4L2ドライバはソフトウェアでこれを実行する必要があります。参照： ではありません raw VBI interface 。データは固定サイズの短いパケットとして送信され、それぞれ1スキャンラインをカバーします。1ビデオフレームあたりのパケット数は可変です。スライスドVBIキャプチャおよび出力デバイスは、raw VBIデバイスと同じキャラクタースペシャルファイルを介してアクセスされます。ドライバが両インターフェースをサポートする場合、デバイスのデフォルト機能はVBIキャプチャまたは出力であり、スライスドVBI機能は以下のioctlを呼び出した後からのみ利用可能です。同様に、デバイスがスライスドVBI APIをサポートしていても、ここでのデフォルト機能はビデオキャプチャまたは出力です。このドライバがサポートする場合、raw VBIデータとスライスドVBIデータを同時に送信するには異なるファイル記述子を使用する必要があります。

スライスドVBIキャプチャまたは出力APIをサポートするデバイスは、以下のioctlでそれぞれフラグを設定します。読み取り/書き込み、ストリーミング、または非同期のいずれかのI/Oメソッドを少なくとも1つ使用する必要があります。 /dev/vbi device is raw VBI capturing or output, and the sliced VBI function is only available after calling the VIDIOC_S_FMT ioctl as defined below. Likewise a /dev/video device may support the sliced VBI API, however the default function here is video capturing or output. Different file descriptors must be used to pass raw and sliced VBI data simultaneously, if this is supported by the driver.

Devices supporting the sliced VBI capturing or output API set the V4L2_CAP_SLICED_VBI_CAPTURE または V4L2_CAP_SLICED_VBI_OUTPUT flag respectively, in the capabilities 構造体の v4l2_capability は ioctl VIDIOC_QUERYCAP ioctl. At least one of the read/write, streaming or asynchronous I/O methods サポートが必要です。スライスVBIデバイスはチューナーやモデュレータを搭載している可能性があります。
