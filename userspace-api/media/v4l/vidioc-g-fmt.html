7.31. ioctl VIDIOC_G_FMT, VIDIOC_S_FMT, VIDIOC_TRY_FMT¶

7.31.1. 名前¶

VIDIOC_G_FMT - VIDIOC_S_FMT - VIDIOC_TRY_FMT - データ形式の取得または設定、形式の試行

7.31.2. 概要¶

VIDIOC_G_FMT¶

int ioctl(int fd, VIDIOC_G_FMT, struct v4l2_format *argp)

VIDIOC_S_FMT¶

int ioctl(int fd, VIDIOC_S_FMT, struct v4l2_format *argp)

VIDIOC_TRY_FMT¶

int ioctl(int fd, VIDIOC_TRY_FMT, struct v4l2_format *argp)

7.31.3. 引数¶

fd

返されるファイル記述子 open().

argp

struct mem_ctl_info v4l2_format.

7.31.4. 説明¶

これらのioctlは、ドライバとアプリケーション間でやり取りされるデータ（通常は画像形式）のフォーマットを交渉するために使用されます。

現在のパラメータを照会するには、アプリケーションが type フィールドを設定します。 v4l2_format をそれぞれのバッファ（ストリーム）タイプに設定します。例えば動画キャプチャデバイスは V4L2_BUF_TYPE_VIDEO_CAPTURE または V4L2_BUF_TYPE_VIDEO_CAPTURE_MPLANEを使用します。アプリケーションがこの構造体へのポインタを VIDIOC_G_FMT ioctlで呼び出すと、ドライバがこの構造体の fmt ユニオンの該当メンバに値を埋め込みます。動画キャプチャデバイスの場合、これは v4l2_pix_format pix または構造体 v4l2_pix_format_mplane pix_mp メンバです。リクエストされたバッファタイプがサポートされていない場合、ドライバは EINVAL エラー コードに設定します。

を返します。現在のフォーマットパラメータを変更するには、アプリケーションが type フィールドと該当する fmt ユニオンメンバのすべてのフィールドを初期化します。詳細は、 インターフェースに記載されている各種デバイスタイプのドキュメンテーションを参照してください。現在のパラメータをまず照会し、アプリケーションに不適切なパラメータのみを変更するのが良い実装です。アプリケーションが VIDIOC_S_FMT ioctlを呼び出し、struct v4l2_framebufferへのポインタを渡します。 v4l2_format 構造体を呼び出すと、ドライバがハードウェアの能力に基づきパラメータを検証・調整します。ドライバがエラーを返すのは、 type フィールドが無効な場合のみです。これはデバイスの能力を把握し、アプリケーションとドライバ双方で受け入れ可能なパラメータに近づくメカニズムです。成功した場合、ドライバはハードウェアをプログラミングし、リソースを確保してデータ交換の準備を行います。最後に、 VIDIOC_S_FMT ioctlは現在のフォーマットパラメータを VIDIOC_G_FMT と同じように返します。非常に単純で柔軟性のないデバイスは、すべての入力を無視して常にデフォルトパラメータを返す場合もあります。ただし、アプリケーションとデータ交換を行うすべてのV4L2デバイスは、 VIDIOC_G_FMT および VIDIOC_S_FMT ioctlを実装しなければなりません。リクエストされたバッファタイプがサポートされていない場合、ドライバは VIDIOC_S_FMT 呼び出し時にEINVALエラー コードを返します。I/Oが既に進行中であるか、他の理由でリソースが利用不可な場合、ドライバは EBUSY エラー コードに設定します。

以下の VIDIOC_TRY_FMT ioctlは VIDIOC_S_FMT と同等ですが、1つの例外があります：ドライバの状態を変更しません。また、いつでも呼び出すことができ、エラーを返さない EBUSYです。この関数はI/Oを無効化したり、時間がかかるハードウェアの準備を避けてパラメータの交渉やハードウェアの制限を学習するためのものです。強く推奨されますが、ドライバはこのioctlを実装する義務はありません。

7.31.5. 戻り値¶

成功した場合、0 が返されます。エラーの場合、-1 が返され、変数が適切に設定されます。 errno 一般的なエラーコードは、 汎用エラーコード 章。

EINVAL

構造体 v4l2_format type フィールドが無効、または要求されたバッファタイプがサポートされていません。

EBUSY

デバイスがビジーで、形式の変更ができません。これはデバイスがストリーミング中、またはバッファがドライバに割り当てられたりキューイングされているためかもしれません。以下の項目に関連します。 VIDIOC_S_FMT のみです。
