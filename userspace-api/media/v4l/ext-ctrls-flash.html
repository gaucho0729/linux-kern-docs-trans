1.12. Flash Control Reference¶

V4L2フラッシュ制御は、フラッシュコントローラー機器への一般的なアクセスを提供することを目的としています。フラッシュコントローラー機器は、デジタルカメラで一般的に使用されます。

インターフェースはLEDおよび氙灯（けんとう）フラッシュ機器のサポートが可能です。執筆時点では、このインターフェースを使用した氙灯フラッシュドライバは存在していません。

1.12.1. サポートされる使用ケース¶

1.12.1.1. 非同期LEDフラッシュ（ソフトウェアストローブ）¶

非同期LEDフラッシュは、センサーとしてホストによって直接制御されます。画像の露出開始前にホストがフラッシュを有効化し、露出終了後に無効化する必要があります。フラッシュのタイミングはホストが完全に責任を負います。

このようなデバイスの例: Nokia N900。

1.12.1.2. 同期LEDフラッシュ（ハードウェアストローブ）¶

同期LEDフラッシュはホストによって事前に設定（電源とタイムアウト）され、センサーからのストローブ信号によって制御されます。

センサーがフラッシュの持続時間とタイミングを制御します。この情報は通常センサーに提供される必要があります。

1.12.1.3. LEDフラッシュとしてのランタン機能¶

LEDフラッシュはカメラに関連する他の使用ケースと併用して、または個別にランタンとして使用できます。

1.12.1.4. フラッシュ制御ID¶

V4L2_CID_FLASH_CLASS (class)

FLASHクラスディスクリプター。

V4L2_CID_FLASH_LED_MODE (menu)

フラッシュLEDのモードを定義します。高電力ホワイトLEDがフラッシュコントローラーに接続されている場合、この制御の設定が一部の障害の存在下では不可能となる可能性があります。V4L2_CID_FLASH_FAULTを参照してください。

V4L2_FLASH_LED_MODE_NONE

オフ。

V4L2_FLASH_LED_MODE_FLASH

フラッシュモード。

V4L2_FLASH_LED_MODE_TORCH

ランタンモード。V4L2_CID_FLASH_TORCH_INTENSITYを参照してください。
V4L2_CID_FLASH_STROBE_SOURCE (menu)

フラッシュLEDストローブのソースを定義します。

V4L2_FLASH_STROBE_SOURCE_SOFTWARE

フラッシュストローブはV4L2_CID_FLASH_STROBE制御を使用してトリガーされます。

V4L2_FLASH_STROBE_SOURCE_EXTERNAL

フラッシュストローブは外部ソースによってトリガーされます。通常これはセンサーであり、フラッシュストローブの開始を露出開始と同期させることが可能になります。
V4L2_CID_FLASH_STROBE (button)

ストローブフラッシュ。V4L2_CID_FLASH_LED_MODEがV4L2_FLASH_LED_MODE_FLASHに設定され、V4L2_CID_FLASH_STROBE_SOURCEがV4L2_FLASH_STROBE_SOURCE_SOFTWAREに設定されている場合に有効です。一部の障害の存在下ではこの制御の設定が不可能となる可能性があります。V4L2_CID_FLASH_FAULTを参照してください。

V4L2_CID_FLASH_STROBE_STOP (button)

フラッシュストローブをすぐに停止します。

V4L2_CID_FLASH_STROBE_STATUS (boolean)

ストローブ状態: 現在フラッシュがストローブしているかどうかを示します。この制御は読み取り専用です。

V4L2_CID_FLASH_TIMEOUT (integer)

フラッシュのハードウェアタイムアウト。ストローブ開始からこの期間が経過するとフラッシュストローブが停止します。

V4L2_CID_FLASH_INTENSITY (integer)

フラッシュLEDがフラッシュモード（V4L2_FLASH_LED_MODE_FLASH）にあるときに発生するフラッシュストローブの強度。可能な限り単位はミリアンペア（mA）とします。

V4L2_CID_FLASH_TORCH_INTENSITY (integer)

トーチモードにおけるフラッシュLEDの強度 (V4L2_FLASH_LED_MODE_TORCH)。可能であれば単位はミリアンペア (mA) で指定してください。この制御の設定が、一部の故障が発生している場合では不可能になる可能性があります。V4L2_CID_FLASH_FAULT を参照してください。

V4L2_CID_FLASH_INDICATOR_INTENSITY (integer)

インジケータLEDの強度。インジケータLEDはフラッシュLEDとは完全に独立している可能性があります。可能であれば単位はマイクロアンペア (uA) で指定してください。

V4L2_CID_FLASH_FAULT (bitmask)

フラッシュに関するエラー。これらのエラーは、フラッシュチップ自体やそれに接続されたLEDに発生する特定の問題を示します。エラーは、一部のフラッシュ制御の使用を妨げる可能性があります。特に、エラーがフラッシュLEDに影響を及ぼしている場合、V4L2_CID_FLASH_LED_MODE は V4L3_FLASH_LED_MODE_NONE に設定されます。どのエラーがこのような影響を及ぼすかはチップに依存します。エラーを読み取ることで制御がリセットされ、チップが使用可能状態に戻る場合があります。

V4L2_FLASH_FAULT_OVER_VOLTAGE

フラッシュLEDへのフラッシュコントローラー電圧が、フラッシュコントローラー固有の限界を超えました。

V4L2_FLASH_FAULT_TIMEOUT

ユーザーが設定したタイムアウト (V4L2_CID_FLASH_TIMEOUT 制御) が経過した際、フラッシュストロボがまだオンの状態でした。すべてのフラッシュコントローラーがこのような状況で必ずこの状態を設定するわけではありません。

V4L2_FLASH_FAULT_OVER_TEMPERATURE

フラッシュコントローラーが過熱しました。

V4L2_FLASH_FAULT_SHORT_CIRCUIT

フラッシュコントローラーの短絡保護が作動しました。

V4L2_FLASH_FAULT_OVER_CURRENT

LED電源の電流が、フラッシュコントローラー固有の限界を超えました。

V4L2_FLASH_FAULT_INDICATOR

フラッシュコントローラーがインジケータLEDに短絡またはオープン回路の状態を検出しました。

V4L2_FLASH_FAULT_UNDER_VOLTAGE

フラッシュLEDへのフラッシュコントローラー電圧が、フラッシュコントローラー固有の最小限界を下回りました。

V4L2_FLASH_FAULT_INPUT_VOLTAGE

フラッシュコントローラーの入力電圧が、フル電流でのストロボが不可能になる限界を下回っています。このフラグが設定されている間、この状態は継続します。

V4L2_FLASH_FAULT_LED_OVER_TEMPERATURE

LEDの温度が許容される上限を超過しました。
V4L2_CID_FLASH_CHARGE (boolean)

キセノンフラッシュコンデンサの充電を有効にするか無効にするか。

V4L2_CID_FLASH_READY (boolean)

フラッシュがストロボを実行可能ですか？キセノンフラッシュはストロボを実行する前にコンデンサを充電する必要があります。LEDフラッシュはストロボ後、クーラダウン期間があり、その間はもう一度ストロボを実行できません。これは読み取り専用の制御です。
