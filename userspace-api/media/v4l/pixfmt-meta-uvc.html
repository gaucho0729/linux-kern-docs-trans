2.13.4. V4L2_META_FMT_UVC (‘UVCH’)¶

UVCペイロードヘッダーデータ

2.13.4.1. 説明¶

このフォーマットは、UVCパケットヘッダーから抽出された標準的なUVCメタデータを記述しており、UVCドライバーがメタデータビデオノードを通じて提供します。このデータには、UVCペイロードヘッダーの標準部分の正確なコピーと、タイムスタンプの正確な解釈に必要な補助的なタイミング情報が含まれます。詳細は、「UVC 1.5 クラス仕様」の「2.4.3.3 ビデオおよび静止画ペイロードヘッダー」セクションを参照してください。

各UVCペイロードヘッダーのサイズは2〜12バイトです。バッファには、カメラがフレームごとに複数のこのようなヘッダーを送信した場合、複数のヘッダーが含まれることがあります。ただし、バッファが満杯になった場合、有用な情報が含まれていない（例: SCRフィールドがないか、前のヘッダーと同じ値を持つ）場合、またはデバイスが多数のヘッダーを送信する際のレート制限を行うためなど、ドライバーはヘッダーを無視することがあります。

各個別ブロックには次のフィールドが含まれます：

UVCメタデータブロック¶

フィールド

説明

__u64 ts;

ホストバイトオーダーで測定されたシステムタイムスタンプ（ペイロードの受信時にドライバーが取得）

__u16 sof;

USBフレーム番号（ホストバイトオーダーで表記、上記タイムスタンプにできるだけ近いタイミングでドライバーが取得し、それらの相関を可能にする）

残りの部分はUVCペイロードヘッダーの標準部分の正確なコピーです：

__u8 length;

このフィールドを含むブロックの残り部分の長さ

__u8 flags;

他の標準的なUVCフィールドの存在を示すフラグ

__u8 buf[];

ヘッダーの残り部分（UVC PTSおよびSCRフィールドを含む可能性あり）
