7.16. ioctl VIDIOC_ENUM_FRAMEINTERVALS¶

7.16.1. 名前¶

VIDIOC_ENUM_FRAMEINTERVALS - フレーム間隔を列挙する

7.16.2. 概要¶

VIDIOC_ENUM_FRAMEINTERVALS¶

int ioctl(int fd, VIDIOC_ENUM_FRAMEINTERVALS, struct v4l2_frmivalenum *argp)

7.16.3. 引数¶

fd

返されるファイル記述子 open().

argp

struct mem_ctl_info v4l2_frmivalenum ピクセル形式とサイズを含み、フレーム間隔を受信します。

7.16.4. 説明¶

このioctlは、指定されたピクセル形式とフレームサイズに対応するデバイスがサポートするすべてのフレーム間隔をアプリケーションに列挙させます。

サポートされているピクセル形式とフレームサイズは、以下のを使用することで取得できます。 ioctl VIDIOC_ENUM_FMT および ioctl VIDIOC_ENUM_FRAMESIZES 関数の終わりを注釈する必要があります。

戻り値と以下の内容は v4l2_frmivalenum.type フィールドは、デバイスがサポートするフレーム間隔のタイプに依存します。以下に、さまざまなケースにおける関数のセマンティクスを示します。

  • 離散的: 指定されたインデックス値（ゼロベース）が有効な場合、関数は成功を返します。アプリケーションは、成功を返すまでインデックスを1ずつ増やして呼び出します。 EINVAL が返されるまで v4l2_frmivalenum.type フィールドがドライバによって V4L2_FRMIVAL_TYPE_DISCRETE に設定される場合、ユニオンのうちのみ discrete メンバが有効です。

  • 段階的: 指定されたインデックス値がゼロの場合、関数は成功を返します。その他のインデックス値については、 EINVAL が返されます。 v4l2_frmivalenum.type フィールドがドライバによって V4L2_FRMIVAL_TYPE_STEPWISE に設定される場合、ユニオンのうちのみ stepwise メンバが有効です。

  • 連続的: これは上記の段階的タイプの特別なケースです。指定されたインデックス値がゼロの場合、関数は成功を返します。その際、 EINVAL が返されます。 v4l2_frmivalenum.type フィールドがドライバによって V4L2_FRMIVAL_TYPE_CONTINUOUS に設定される場合、ユニオンのうちのみ stepwise メンバが有効であり、 step 値が1に設定されている必要があります。

アプリケーションがインデックスゼロで関数を呼び出す際、ドライバがサポートするフレーム間隔列挙タイプを確認するために、 type フィールドを確認する必要があります。アプリケーションがフレーム間隔をさらに取得するには、のみインデックス値を増やす必要があります。 V4L2_FRMIVAL_TYPE_DISCRETE タイプ

注意

フレーム間隔の順序は特別な意味を持ちません。特に、潜在的なデフォルトフレーム間隔についての情報も提供しません。

アプリケーションは、自身の操作なしに列挙データが変化しないと想定できます。これは、アプリケーションがフレーム間隔列挙を実行中に他のioctlコールを行わない限り、列挙データが一貫していることを意味します。

注意

フレーム間隔とフレームレート: V4L2 APIはフレームレートではなくフレーム間隔を使用します。フレーム間隔が与えられた場合、フレームレートは以下の式で計算できます:

frame_rate = 1 / frame_interval
