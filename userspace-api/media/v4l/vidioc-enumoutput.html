7.19. ioctl VIDIOC_ENUMOUTPUT¶

7.19.1. 名前¶

VIDIOC_ENUMOUTPUT - ビデオ出力の列挙

7.19.2. 概要¶

VIDIOC_ENUMOUTPUT¶

int ioctl(int fd, VIDIOC_ENUMOUTPUT, struct v4l2_output *argp)

7.19.3. 引数¶

fd

返されるファイル記述子 open().

argp

struct mem_ctl_info v4l2_output.

7.19.4. 説明¶

ビデオ出力の属性を照会するには、アプリケーションは index 構造体の v4l2_output を初期化し、 ioctl VIDIOC_ENUMOUTPUT ドライバはインデックスが範囲外の場合、構造体の残り部分を埋めたり、エラー コードを返したりします。 EINVAL インデックスが範囲外の場合のエラーコード。すべての出力を列挙するには、アプリケーションはインデックスゼロから開始し、ドライバが EINVAL.

type v4l2_output¶
struct v4l2_output¶

__u32

index

出力を識別し、アプリケーションが設定します。

__u8

name[32]

ビデオ出力の名前、NULL終端のASCII文字列、例えば「Vout」。この情報はユーザー向けで、デバイス自体のコネクタラベルが好ましいです。

__u32

type

出力のタイプ、詳しくは 出力タイプ.

__u32

audioset

ドライバは最大32のビデオおよびオーディオ出力を列挙できます。このフィールドは、このビデオ出力が現在選択されている場合に選択可能なオーディオ出力を示します。ビットマスクです。LSBはオーディオ出力0、MSBは出力31に対応します。任意のビットを設定するか、設定しない場合もあります。

ドライバがオーディオ出力を列挙しない場合、ビットは設定されません。アプリケーションはこれをオーディオサポートの欠如と解釈してはいけません。ドライバは列挙せずにオーディオ出力を自動的に選択する場合があります。

オーディオ出力の詳細および現在の出力の選択方法については、詳しくは オーディオ入出力.

__u32

modulator

ビデオ出力はゼロ個以上のRFモデュレータを持つことができます。この type 通常のRCU読み込み側クリティカルセクションは、条件付きでスリープロックを取得することが許容されます（例として V4L2_OUTPUT_TYPE_MODULATOR これはRFコネクタであり、このフィールドはモデュレータを識別します。これはstruct v4l2_modulator フィールド index. モデュレータの詳細については、詳しくは チューナーとモジュレータ.

v4l2_std_id

std

すべてのビデオ出力は1つ以上の異なるビデオ標準をサポートします。このフィールドはサポートされているすべての標準を示します。ビデオ標準の詳細および切り替え方法については、詳しくは ビデオ標準.

__u32

capabilities

このフィールドは出力の機能を示します。詳しくは 出力機能 フラグについては。

__u32

reserved[3]

今後の拡張用に予約されています。ドライバは配列をゼロに設定する必要があります。
出力タイプ¶

V4L2_OUTPUT_TYPE_MODULATOR

1

この出力はアナログTVモデュレータです。

V4L2_OUTPUT_TYPE_ANALOG

2

モデュレータでないビデオ出力、例えばコンポジットビデオ、S-Video、HDMI。名称は _TYPE_ANALOG は歴史的です。今日ではこれを _TYPE_VIDEO.

V4L2_OUTPUT_TYPE_ANALOGVGAOVERLAY

3

ビデオ出力は ビデオオーバーレイ.
出力機能¶

V4L2_OUT_CAP_DV_TIMINGS

0x00000002

この出力は VIDIOC_S_DV_TIMINGS.

V4L2_OUT_CAP_STD

0x00000004

この出力は VIDIOC_S_STD.

V4L2_OUT_CAP_NATIVE_SIZE

0x00000008

この出力は V4L2_SEL_TGT_NATIVE_SIZE 選択対象を参照してください 一般的な選択定義.

7.19.5. 戻り値¶

成功した場合、0 が返されます。エラーの場合、-1 が返され、変数が適切に設定されます。 errno 一般的なエラーコードは、 汎用エラーコード 章。

EINVAL

構造体 v4l2_output index 範囲外です。
