7.25. ioctl VIDIOC_G_CTRL, VIDIOC_S_CTRL¶

7.25.1. 名前¶

VIDIOC_G_CTRL − VIDIOC_S_CTRL − コントロールの値を取得または設定します

7.25.2. 概要¶

VIDIOC_G_CTRL¶

int ioctl(int fd, VIDIOC_G_CTRL, struct v4l2_control *argp)

VIDIOC_S_CTRL¶

int ioctl(int fd, VIDIOC_S_CTRL, struct v4l2_control *argp)

7.25.3. 引数¶

fd

返されるファイル記述子 open().

argp

struct mem_ctl_info v4l2_control.

7.25.4. 説明¶

コントロールの現在の値を取得するには、アプリケーションはこの構造体へのポインタを持つioctlを初期化します。コントロールの値を変更するには、アプリケーションはこの構造体へのポインタを持つioctlを初期化します。 id フィールドを設定します。 v4l2_control を初期化し、 VIDIOC_G_CTRL 入力が無効な場合、ドライバは id および value 構造体のフィールドを初期化する必要があります。 v4l2_control を初期化し、 VIDIOC_S_CTRL ioctl.

When the id is invalid drivers return an EINVAL エラー コード。値が範囲外の場合、ドライバーは最も近い有効な値を採用するか、適切と思われるエラー コードを返すことができます。 value エラー コード、 whichever seems more appropriate. However, ERANGE これは書き込み専用のioctlであり、実際の新しい値を返しません。もし VIDIOC_S_CTRL 制御に不適切な場合（たとえば、メニュー制御のサポートされていないメニューインデックスを参照している場合など）、EINVALエラー コードが返されます。 value 制御に不適切な場合（たとえば、メニュー制御のサポートされていないメニューインデックスを参照している場合など）、EINVALエラー コードが返されます。

これらのioctlはユーザー制御専用で、他の制御クラスについては VIDIOC_G_EXT_CTRLS, VIDIOC_S_EXT_CTRLS または VIDIOC_TRY_EXT_CTRLS must be used.

type v4l2_control¶
struct v4l2_control¶

__u32

id

アプリケーションによって設定される制御を識別します。

__s32

value

新しい値または現在の値。

7.25.5. 戻り値¶

成功した場合、0 が返されます。エラーの場合、-1 が返され、変数が適切に設定されます。 errno 一般的なエラーコードは、 汎用エラーコード 章。

EINVAL

構造体 v4l2_control id 無効です。または、 value 指定された制御に対して不適切です（例: ドライバがサポートしていないメニュー項目を選択した場合）。 VIDIOC_QUERYMENU).

ERANGE

構造体 v4l2_control value 範囲外です。

EBUSY

制御は一時的に変更できません。これは、他のアプリケーションがこの制御に属するデバイス機能の制御を取得した可能性があります。

EACCES

読み取り専用制御を設定しようとしたり、書き込み専用制御を取得しようとしたりしました。
