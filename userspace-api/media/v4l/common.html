1. 共通API要素¶

V4L2デバイスのプログラミングには以下の手順があります:

  • デバイスのオープン

  • デバイスのプロパティの変更、ビデオおよびオーディオ入力の選択、ビデオ標準、画像の明るさなど

  • データフォーマットの協議

  • 入出力方法の協議

  • 実際の入出力ループ

  • デバイスのクローズ

実際には、ほとんどの手順はオプションであり、順序を問わず実行できます。V4L2デバイスの種類によって異なります。詳細については インターフェースこの章では、すべてのデバイスに適用可能な基本的な概念について説明します。
