2.5. RGB形式¶

2.5.1. 説明¶

これらの形式は、一般的なPCグラフィックフレームバッファのピクセル形式に合わせて設計されています。1ピクセルあたり8、16、24、または32ビットを占有します。これらはすべてパッケージドピクセル形式であり、1ピクセルのすべてのデータがメモリ内において隣接しています。

注意

ビット7は最上位ビットです。

ARGBおよびABGR形式（総称してアルファ形式）におけるアルファビット（a）の使用方法と値は、デバイスタイプとハードウェア操作に依存します。 キャプチャ デバイス（メモリ対メモリデバイスのキャプチャキューを含む）はメモリ内にアルファコンポーネントを埋め込みます。デバイスがアルファチャネルを出力する場合、アルファコンポーネントは意味のある値を持ちます。逆に、デバイスがアルファチャネルを出力しないが、ユーザー設定可能な値としてアルファビットを設定できる場合、 V4L2_CID_ALPHA_COMPONENT コントロールを使用してアルファ値を指定し、すべてのピクセルのアルファコンポーネントをそのコントロールで指定された値に設定します。それ以外の場合は、アルファコンポーネントを持たないフォーマット（XRGBまたはXBGR）を使用する必要があります。

出力 デバイス（メモリ対メモリデバイスの出力キューを含む ビデオ出力オーバーレイ デバイスはメモリからアルファチャンネルのアルファコンポーネントを読み込みます。デバイスがアルファチャンネルを処理する際には、アプリケーションがアルファコンポーネントに意味のある値を埋め込む必要があります。それ以外の場合、アルファコンポーネントを持たないフォーマット（XRGBまたはXBGR）を使用する必要があります。

XRGBおよびXBGRフォーマットは未定義のビット（-）を含んでいます。アプリケーション、デバイス、ドライバーはこれらを無視する必要があります。 Video Capture Interface および Video Output Interface デバイスと同じキャラクタースペシャルファイルを通してアクセスされる。
