1.20. FM受信機制御参照¶

FM受信機（FM_RX）クラスは、FM受信可能なデバイスの一般的な機能の制御を含みます。

1.20.1. FM_RX制御ID¶

V4L2_CID_FM_RX_CLASS (class)

FM_RXクラスの記述子。呼び出し ioctls VIDIOC_QUERYCTRL、VIDIOC_QUERY_EXT_CTRL および VIDIOC_QUERYMENU この制御クラスの説明が返されます。

V4L2_CID_RDS_RECEPTION (boolean)

ラジオチューナーによるRDS受信を有効/無効にします

V4L2_CID_RDS_RX_PTY (integer)

RDSプログラムタイプフィールドを取得します。これは最大31種類の予め定義されたプログラムタイプを符号化します

V4L2_CID_RDS_RX_PS_NAME (string)

プログラムサービス名（PS_NAME）を取得します。これは受信機での静的な表示に使用される予定です。これは、リスナーがプログラムサービスの識別と選択を行うための主な手段です。Annex Eの IEC 62106、RDS仕様書ではプログラムサービス名文字列の正しい文字エンコードの詳細な説明があります。またRDS仕様書ではPSは通常8文字のテキストですが、8×N文字の文字列をスクロール可能な受信機も存在します。そのためこの制御は8文字単位で設定する必要があります。結果として常に8の倍数のサイズの文字列を含まなければなりません

V4L2_CID_RDS_RX_RADIO_TEXT (string)

ラジオテキスト情報を取得します。これは放送されている内容のテキスト的な説明です。放送局がより長いPS名、プログラム関連情報、または他のテキストを送信したい場合にRDSラジオテキストが使用されます。このような場合、RadioTextは V4L2_CID_RDS_RX_PS_NAMEに追加で使用できます。ラジオテキスト文字列のエンコード方法もAnnex Eの IEC 62106で完全に記述されています。ラジオテキスト文字列の長さは使用しているRDSブロックによって異なります。32（2Aブロック）または64（2Bブロック）文字ですが、32×N文字または64×N文字の文字列をスクロール可能な受信機も存在します。そのためこの制御は32または64文字単位で設定する必要があります。結果として常に32または64の倍数のサイズの文字列を含まなければなりません

V4L2_CID_RDS_RX_TRAFFIC_ANNOUNCEMENT (boolean)

交通情報放送が進行中であることを示します

V4L2_CID_RDS_RX_TRAFFIC_PROGRAM (boolean)

チューニングされた番組が交通情報放送を含んでいることを示します

V4L2_CID_RDS_RX_MUSIC_SPEECH (boolean)

このチャンネルが音楽を放送していることを示します。クリアにすると話す放送になります。送信側がこの区別をしない場合、自動的に設定されます

V4L2_CID_TUNE_DEEMPHASIS

(enum)

enum v4l2_deemphasis -

受信時の減衰値を設定します。減衰フィルタが適用され、高音域を強調します。地域によっては50または75マイクロ秒の時間定数が使用されます。enum v4l2_deemphasisは減衰の可能な値を定義しています。以下がその値です

V4L2_DEEMPHASIS_DISABLED

減衰は適用されません

V4L2_DEEMPHASIS_50_uS

50マイクロ秒の減衰が使用されます

V4L2_DEEMPHASIS_75_uS

75マイクロ秒の減衰が使用されます
