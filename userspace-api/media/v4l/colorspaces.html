2.15. カラースペース¶

「色」は非常に複雑な概念であり、物理、化学、生物学に依存しています。ピクセルの色の「赤」「緑」「青」成分を表す3つの数値を持っているからといって、その色を正確に表示できるとは限りません。カラースペースとは、実際に を意味します どの色が完全に校正された環境で画面に再現されるべきかを定義します。たとえばRGB値が(255, 0, 0)であることを意味します。つまり、どの色が画面で再現されるべきかを示します。

これを実現するには、まず色を正確に定義する必要があります。つまり、誰かがその色を再現できるように、色を一意かつ明確に定義する方法が必要です。人間の色覚は三色視であり、人間の目には3つの異なる波長の光に敏感な色受容体があります。そのため、色を3つの数値で表現する必要があります。マントイシャrimp（マントイシャrimp）のように12種類の波長に敏感な生物であれば、RGBではなくABCDEFGHIJKLカラースペースを使用する必要があるでしょう…

色は目と脳にしか存在せず、色受容体がどれだけ刺激されているかによって生じます。これは光の波長範囲（可視光線）における光の強度（放射エネルギー）をグラフで示すスペクトルパワー分布（SPD）に基づいています。色度学とは、SPDと人間の脳が色として認識する関係性を研究する学問です。

人間の目には3つの色受容体しかないので、異なるSPDでも同じ受容体の刺激を引き起こし、同じ色として認識される可能性があります。つまり、光のSPDが異なるにもかかわらず、同じ色として感じられることがあります。

1920年代にSPDと認識される色の関係を調べる実験が行われ、その結果としてCIE 1931標準が制定されました。この標準は色の認識をモデル化するスペクトル加重関数を定義しています。具体的には、SPDを入力として色受容体の刺激を計算する関数を定義しています。その後、いくつかの数学的変換を経て、これらの刺激は CIE XYZ 三刺激値 と呼ばれます。これらのX、Y、Z値はすべて範囲[0…1]に含まれます。

CIE XYZカラースペースにおけるY値は輝度に対応します。通常、CIE XYZカラースペースは正規化されたCIE xyYカラースペースに変換されます：

x = X / (X + Y + Z)

y = Y / (X + Y + Z)

xとyの値は色度座標であり、明るさ成分Yを除いた色を定義するために使用できます。このような色空間に似た名前が使われていることは非常に混乱します。注意点として、色が小文字の「x」と「y」で指定されている場合、CIE xyY色空間が使用されます。大文字の「X」と「Y」はCIE XYZ色空間を指します。また、「y」は明るさとは関係ありません。xとyは色を指定し、Yは明るさを表します。実用的な観点から覚えるべきことはこれだけです。このセクションの最後に、より詳細な情報が記載された読み物リソースを掲載しています。

モニターまたはテレビは、3つの異なる波長の光を発光させることで色を再現します。これらの波長の組み合わせは、目の中の色受容体を刺激し、色の認識を引き起こします。歴史的には、ディスプレイで使用される赤、緑、青のリン光がこれらの波長を定義していました。 color primaries はカラースペースを定義する要素の一つです。

異なるディスプレイ機器は異なるカラープライマリを持ち、一部のカラープライマリは特定のディスプレイ技術により適しています。これにより、さまざまなディスプレイ技術や用途に応じたカラースペースが作成されました。カラースペースを定義するには、3つのカラープライマリ（これらは通常CIE xyY色空間からのx、y色度座標で定義されます）を定義する必要がありますが、白参照（すべての3つのカラープライマリが最大出力時に得られる色）も定義する必要があります。これはカラープライマリの相対的な出力またはエネルギーを決定します。通常、昼光に近い色が選ばれ、これはCIE D65 Illuminantとして定義されています。

まとめると：CIE XYZカラースペースは色を一意に識別します。他のカラースペースは、CIE xyYカラースペースで定義された3つの色度座標によって定義されます。これらを基に3×3行列を構築し、CIE XYZ色を新しいカラースペースの色に変換できます。

CIE XYZ色空間および特定の色度原色から導出されたRGB色空間は、線形色空間です。しかし、目やディスプレイ技術は線形ではありません。線形色空間のすべての成分値を倍にしても、色の明るさが2倍に感じられません。そのため、各色空間は、線形色成分値を非線形成分値に変換するトランスファー関数を定義しています。これは、目やディスプレイの非線形特性に近い値になります。線形成分値はRGBで表され、非線形成分値はR’G’B’で表されます。グラフィックスで使用される色は通常R’G’B’ですが、OpenGLでは線形RGBが使用されます。OpenGLを扱う際には、線形RGB色を提供するか、または組み込みのOpenGLサポートを活用して逆トランスファー関数を適用する必要があります。

色空間を定義する最後の要素は、非線形R’G’B’を非線形Y’CbCrに変換する関数です。この関数はルーマ係数（luma coefficients）によって決まります。同じ色空間でも複数のY’CbCr符号化が許可されることがあります。多くの色符号化では、ルーマ（Y’）とクロマ（CbCr）をR’G’B’よりも使用する傾向があります。人間の目は輝度の違いに対して色の違いよりも敏感であるため、この符号化により、ルーマデータに比べて色情報量を減らすことができます。注意点として、ルーマ（Y’）はCIE XYZ色空間のYとは関係ありません。また、Y’CbCrはしばしばYCbCrまたはYUVと呼ばれることがありますが、これは厳密には誤りです。

時折、Y’CbCrが色空間であると誤解されることがあります。これは誤りで、R’G’B’色をルーマとクロマ値に符号化するだけのものです。R’G’B’色に関連する基盤となる色空間は、Y’CbCr色にも関連付けられます。

最後のステップはRGB、R’G’B’またはY’CbCr値の量子化方法です。X、Y、Zが[0…1]範囲にあるCIE XYZ色空間は、人間が認識可能なすべての色を表しますが、他の色空間への変換では[0…1]範囲外の色が生成されることがあります。[0…1]範囲にクランプ（制限）された後、その色空間では再現できなくなります。このクランプ処理が色空間の範囲（ガマート）を狭める原因になります。[0…1]範囲を[0…255]（色深度によってはより大きい値）の整数値に変換する処理を量子化と呼びます。これは ではありません カラースペースの定義の一部です。実際にはRGBまたはR’G’B’値はフルレンジ、つまり[0…255]の範囲をすべて使用します。一方、Y’CbCr値は制限されたレンジで、Y’は[16…235]、CbおよびCrは[16…240]の範囲を使用します。

残念ながら、一部のケースでは制限されたレンジのRGBも使用され、その成分は[16…235]の範囲を使用します。また、フルレンジのY’CbCrも存在し、[0…255]の範囲を使用します。

色を正しく解釈するには、量子化範囲、R’G’B’かY’CbCrか、使用されているY’CbCr符号化方法、カラースペースを把握する必要があります。この情報から対応するCIE XYZ色を計算し、それを表示デバイスが使用するカラースペースに再マッピングできます。

カラースペースの定義自体は、3つの色度主波長、白参照色度、トランスファー関数、R’G’B’をY’CbCrに変換するためのルミナ係数から構成されます。一部のカラースペース標準はすべての4つの要素を正しく定義していますが、多くの場合、カラースペース標準は一部しか定義せず、欠けている部分は他の標準に依拠する必要があります。カラースペースが異なる標準の組み合わせであることが多いため、非常に混乱を招く命名規則が生じました。標準の名前をカラースペースの名前に使用する場合がありましたが、実際にはその標準は他のカラースペースにも含まれていたのです。
