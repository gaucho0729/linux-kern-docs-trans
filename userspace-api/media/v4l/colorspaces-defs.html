2.16. V4L2におけるカラースペースの定義¶

V4L2ではカラースペースは4つの値で定義されます。最初の値はカラースペース識別子（enum v4l2_colorspace）で、色の色調、デフォルトのトランスファー関数、デフォルトのY’CbCr符号化、デフォルトの量子化方法を定義します。2番目の値はトランスファー関数識別子（enum v4l2_xfer_func）で、非標準のトランスファー関数を指定します。3番目の値はY’CbCr符号化識別子（enum v4l2_ycbcr_encoding）で、非標準のY’CbCr符号化を指定します。4番目の値は量子化識別子（enum v4l2_quantization）で、非標準の量子化方法を指定します。ほとんどの場合、struct v4l2_pix_format またはstruct v4l2_pix_format_mplane のカラースペースフィールドのみを埋め込む必要があります。

オン HSV形式 、そして 色相（Hue） は円筒的色表現における角度として定義されます。通常この角度は度数で表され、0-360の範囲です。この角度値を8ビットにマッピングするには2つの基本的な方法があります：角度値を2で割る（0-179）か、0-255の範囲全体を使用し角度値を1.41で割る。enum v4l2_hsv_encoding はどの符号化が使用されるかを指定します。

注意

デフォルトのR’G’B’量子化はすべてのカラースペースでフルレンジです。HSV形式は常にフルレンジです。

type v4l2_quantization¶
V4L2 量子化方法¶

識別子

詳細

V4L2_QUANTIZATION_DEFAULT

色空間によって定義されたデフォルトの量子化符号化を使用してください。R’G’B’およびHSVでは常にフルレンジ、Y’CbCrでは通常リミットレンジです。

V4L2_QUANTIZATION_FULL_RANGE

フルレンジ量子化符号化を使用してください。つまり、[0…1]の範囲は[0…255]にマッピングされ（0x00および0xffの値を避けるために[1…254]にクリッピングされる可能性あり）、CbおよびCrは[-0.5…0.5]から[0…255]にマッピングされます（同様に[1…254]にクリッピングされる可能性あり）。

V4L2_QUANTIZATION_LIM_RANGE

リミットレンジ量子化符号化を使用してください。つまり、[0…1]の範囲は[16…235]にマッピングされます。CbおよびCrは[-0.5…0.5]から[16…240]にマッピングされます。リミットレンジはHSVと併用できません。
