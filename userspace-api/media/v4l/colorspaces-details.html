トランスファー関数。通常Lは[0…1]の範囲ですが、拡張色域xvYCC符号化ではその範囲外の値も許容されます。

L' = -1.099(-L)^{0.45} + 0.099 \text{, for } L \le -0.018 L' = 4.5L \text{, for } -0.018 < L < 0.018 L' = 1.099L^{0.45} - 0.099 \text{, for } L \ge 0.018

L = -\left( \frac{L' - 0.099}{-1.099} \right)^\frac{1}{0.45} \text{, for } L' \le -0.081 L = \frac{L'}{4.5}\text{, for } -0.081 < L' < 0.081 L = \left(\frac{L' + 0.099}{1.099}\right)^{\frac{1}{0.45} } \text{, for } L' \ge 0.081

以下に示す式で輝度（Y’）と色差（CbおよびCr）を取得します V4L2_YCBCR_ENC_709 符号化:

Y' = 0.2126R' + 0.7152G' + 0.0722B' Cb = -0.1146R' - 0.3854G' + 0.5B' Cr = 0.5R' - 0.4542G' - 0.0458B'

Y’は[0…1]の範囲にクリッピングされ、CbおよびCrは[-0.5…0.5]の範囲にクリッピングされます。

デフォルトの量子化は制限範囲ですが、フルレンジは可能です（ただし非常にまれです）。

以下の V4L2_YCBCR_ENC_709 上記のエンコーディングはこのカラースペースのデフォルトですが、 V4L2_YCBCR_ENC_601を指定することで上書きできます。

このカラースペースでは、さらに2つの拡張ガンマ Y’CbCr エンコーディングも可能です：

xvYCC 709 エンコーディング（V4L2_YCBCR_ENC_XV709, xvYCC）は Rec. 709 エンコーディングに似ていますが、R’、G’、B’ の値が [0…1] の範囲外でも許容されます。結果として得られる Y’、Cb、Cr の値は、制限された範囲の式に従ってスケーリングおよびオフセットされます：

Y' = \frac{219}{256} * (0.2126R' + 0.7152G' + 0.0722B') + \frac{16}{256} Cb = \frac{224}{256} * (-0.1146R' - 0.3854G' + 0.5B') Cr = \frac{224}{256} * (0.5R' - 0.4542G' - 0.0458B')

xvYCC 601 エンコーディング（V4L2_YCBCR_ENC_XV601, xvYCC）は BT.601 エンコーディングに似ていますが、R’、G’、B’ の値が [0…1] の範囲外でも許容されます。結果として得られる Y’、Cb、Cr の値は、制限された範囲の式に従ってスケーリングおよびオフセットされます：

Y' = \frac{219}{256} * (0.2990R' + 0.5870G' + 0.1140B') + \frac{16}{256} Cb = \frac{224}{256} * (-0.1687R' - 0.3313G' + 0.5B') Cr = \frac{224}{256} * (0.5R' - 0.4187G' - 0.0813B')

Y’ は [0…1] の範囲にクリッピングされ、Cb と Cr は [-0.5…0.5] の範囲にクリッピングされ、さらにスケーリングやオフセットなしで量子化されます。非標準の xvYCC 709 や xvYCC 601 エンコーディングは、 V4L2_YCBCR_ENC_XV709 または V4L2_YCBCR_ENC_XV601を選択することで使用できます。xvYCC の式から明らかなように、これらのエンコーディングは常に制限された範囲の量子化を使用します。フルレンジの変体は存在しません。拡張ガンマエンコーディングの目的は、制限された範囲外の値が依然として有効であることです。ただし、それらは R’、G’、B’ の値が [0…1] の範囲外になるため、Rec. 709 カラースペースのガンマに含まれない可能性があります。

2.17.10. カラースペース JPEG（V4L2_COLORSPACE_JPEG）¶

このカラースペースはほとんどの(Motion-)JPEGフォーマットで使用されるカラースペースを定義しています。主色の色度およびホワイトリファレンスはsRGBと同一です。トランスファー関数の使用は V4L2_XFER_FUNC_SRGB. Y’CbCr符号化は V4L2_YCBCR_ENC_601 フルレンジクォンタイズで、Y’は[0…255]にスケーリングされ、Cb/Crは[-128…128]にスケーリングされてから[-128…127]にクリップされます。

注意

JPEG標準は実際にカラースペース情報を保存していません。したがってsRGB以外のカラースペースを使用する場合、ドライバーはその情報を明示的に設定する必要があります。実質的に V4L2_COLORSPACE_JPEG はsRGBの略語と見なせます V4L2_COLORSPACE_SRGB, V4L2_XFER_FUNC_SRGB, V4L2_YCBCR_ENC_601 および V4L2_QUANTIZATION_FULL_RANGE.

2.18. 詳細なトランスファー関数の説明¶

2.18.1. トランスファー関数 SMPTE 2084（V4L2_XFER_FUNC_SMPTE2084）¶

以下の SMPTE ST 2084 標準は、高動的範囲（HDR）コンテンツで使用される変換関数を定義します。

定数:

m1 = (2610 / 4096) / 4

m2 = (2523 / 4096) * 128

c1 = 3424 / 4096

c2 = (2413 / 4096) * 32

c3 = (2392 / 4096) * 32

トランスファー関数:

L’ = ((c1 + c2 * Lm1) / (1 + c3 * Lm1))m2

逆トランスファー関数：

L = (max(L’1/m2 - c1, 0) / (c2 - c3 * L’1/m2))1/m1

この変換関数と非HDR変換関数の間で変換する際は注意が必要です。HDRコンテンツの線形RGB値[0…1]は、輝度範囲0〜10000 cd/m²にマッピングされます。2 非HDR（標準動的範囲またはSDR）の線形RGB値は、輝度範囲0〜100 cd/m²にマッピングされます。2.

SDRからHDRへの変換にはまずLを100で割る必要があります。逆にHDRからSDRへの変換にはLを100倍する必要があります。もちろん、これにより100 cd/m²を超えるすべての輝度値が100 cd/m²にクリップされます。2 to 100 cd/m2.
