1.17. デジタルビデオ制御リファレンス¶

デジタルビデオ制御クラスは、受信機および送信機を制御するために設計されています。 VGA, DVI （デジタルビジュアルインターフェース）、HDMI（HDMI）およびDisplayPort（DP）です。これらの制御は、実装している受信機または送信機サブデバイスにプライベートであることが一般的に期待されるため、これらは /dev/v4l-subdev* デバイスノードにのみ露出されます。

注意

これらのデバイスは、複数の入力または出力パッドを持つ場合があり、これらはたとえばHDMIコネクタに接続されています。サブデバイスがこれらのパッドのうち1つだけから/へビデオを受信または送信する場合でも、EDID（拡張ディスプレイ識別データ、 EDID）およびHDCP（高帯域幅デジタルコンテンツ保護システム、 HDCP）処理において他のパッドもアクティブになることがあります。これにより、デバイスがEDID/HDCPの比較的遅い処理を事前に実行できるようになり、コネクタ間の迅速な切り替えが可能になります。

これらのパッドは、このセクションのいくつかの制御でビットマスクとして現れ、各パッドに対応する1ビットが割り当てられます。ビット0はパッド0に対応し、ビット1はパッド1に対応します。制御の最大値は有効なパッドの集合です。

1.17.1. デジタルビデオ制御ID¶

V4L2_CID_DV_CLASS (class)

デジタルビデオクラスの記述子。

V4L2_CID_DV_TX_HOTPLUG (bitmask)

多くのコネクタは、EDID情報がソースから利用可能であれば高電位になるホットプラグピンを持っています。この制御は、送信機が確認するホットプラグピンの状態を示します。各ビットは送信機の出力パッドに対応し、出力パッドにホットプラグピンが関連付けされていない場合、そのパッドのビットは0になります。この読み取り専用制御はDVI-D、HDMIおよびDisplayPortコネクタに適用されます。

V4L2_CID_DV_TX_RXSENSE (bitmask)

Rx Senseは、TMDSクロックライン上のプルアップの検出を指します。これは通常、シンクがスタンバイ状態から抜けた/入り（つまり、送信機が受信機がビデオを受信する準備ができていることを感知できる）ことを意味します。各ビットは送信機の出力パッドに対応し、出力パッドにRx Senseが関連付けされていない場合、そのパッドのビットは0になります。この読み取り専用制御はDVI-DおよびHDMIデバイスに適用されます。

V4L2_CID_DV_TX_EDID_PRESENT (bitmask)

送信機が受信機からのホットプラグ信号を検出すると、EDIDを読み取るよう試みます。設定されている場合、送信機は少なくとも1番目のブロック（= 128バイト）を読み取ったことを意味します。各ビットは送信機の出力パッドに対応し、出力パッドがEDIDをサポートしない場合、そのパッドのビットは0になります。この読み取り専用制御はVGA、DVI-A/D、HDMIおよびDisplayPortコネクタに適用されます。

V4L2_CID_DV_TX_MODE

(enum)

enum v4l2_dv_tx_mode -

HDMI送信機はDVI-Dモード（動画のみ）またはHDMIモード（動画＋音声＋補助データ）で送信できます。この制御は使用するモードを選択します：V4L2_DV_TX_MODE_DVI_DまたはV4L2_DV_TX_MODE_HDMI。この制御はHDMIコネクタに適用されます。

V4L2_CID_DV_TX_RGB_RANGE

(enum)

enum v4l2_dv_rgb_range -

RGB出力の量子化範囲を選択します。V4L2_DV_RANGE_AUTOは、動画インターフェース（例：HDMI）の標準で指定されたRGB量子化範囲を自動的に追随します。V4L2_DV_RANGE_LIMITEDおよびV4L2_DV_RANGE_FULLは標準を上書きし、標準を正しく実装していないシンクとの互換性を確保します（HDMIおよびDVI-Dでは残念ながら非常に一般的です）。フルレンジはすべての可能な値を使用可能にし、リミテッドレンジは（16 << (N-8)) - (235 << (N-8))の範囲を設定します（Nは各コンポーネントのビット数）。この制御はVGA、DVI-A/D、HDMIおよびDisplayPortコネクタに適用されます。 CEA-861-E RGB入力の量子化範囲を選択します。V4L2_DV_RANGE_AUTOは、動画インターフェース（例：

V4L2_CID_DV_TX_IT_CONTENT_TYPE

(enum)

enum v4l2_dv_it_content_type -

送信する動画のITコンテンツタイプを設定します。この情報はHDMIおよびDisplayPortコネクタを介してAVI InfoFrameの一部として送信されます。'ITコンテンツ'という用語は、コンピュータから出発するコンテンツを指し、テレビ放送やアナログソースからのコンテンツとは異なります。enum v4l2_dv_it_content_typeは可能なコンテンツタイプを定義します：

V4L2_DV_IT_CONTENT_TYPE_GRAPHICS

グラフィックスコンテンツ。ピクセルデータはフィルタリングせずに、アナログ再構成なしで通過させるべきです。

V4L2_DV_IT_CONTENT_TYPE_PHOTO

フォトコンテンツ。コンテンツはデジタル静止画から導出されます。コンテンツは最小限のスケーリングと画像補正を伴って通過させるべきです。

V4L2_DV_IT_CONTENT_TYPE_CINEMA

シネマコンテンツ。

V4L2_DV_IT_CONTENT_TYPE_GAME

ゲームコンテンツ。音声および動画のレイテンシーを最小化する必要があります。

V4L2_DV_IT_CONTENT_TYPE_NO_ITC

ITコンテンツ情報が利用できず、AVI InfoFrameのITCビットが0に設定されています。
V4L2_CID_DV_RX_POWER_PRESENT (bitmask)

受信機がソースから電力を受けるかどうかを検出します（例：HDMIはピンの一つで5Vを供給します）。これはEDID情報が含まれるeepromを電源供給するためによく使用され、シンクがスタンバイ/電源オフ状態であってもソースがEDIDを読み取れるようにします。各ビットは受信機の入力ピンに対応し、電源が存在するかどうかを検出できない場合、そのピンのビットは0になります。この読み取り専用制御はDVI-D、HDMIおよびDisplayPortコネクタに適用されます。

V4L2_CID_DV_RX_RGB_RANGE

(enum)

enum v4l2_dv_rgb_range -

RGB入力の量子化範囲を選択します。V4L2_DV_RANGE_AUTOは、動画インターフェース（例： CEA-861-E HDMI用). V4L2_DV_RANGE_LIMITEDおよびV4L2_DV_RANGE_FULLは標準を上書きし、HDMIおよびDVI-Dでよく見られる標準実装が不完全なソースとの互換性を確保します。フルレンジはすべての可能な値を許容するのに対し、リミットレンジはNビットごとの値を(16 << (N-8)) - (235 << (N-8))に設定します(Nは各コンポーネントのビット数を表します)。この制御はVGA、DVI-A/D、HDMIおよびDisplayPortコネクタに適用されます。

V4L2_CID_DV_RX_IT_CONTENT_TYPE

(enum)

enum v4l2_dv_it_content_type -

受信したビデオのITコンテンツタイプを読み込みます。この情報はHDMIおよびDisplayPortコネクタ経由でAVI InfoFrameとして送信されます。'ITコンテンツ'とはコンピュータから出発するコンテンツを指し、テレビ放送やアナログソースからのコンテンツとは異なります。参照 V4L2_CID_DV_TX_IT_CONTENT_TYPE 利用可能なコンテンツタイプについては。
