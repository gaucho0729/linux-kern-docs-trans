7.42. ioctl VIDIOC_G_TUNER, VIDIOC_S_TUNER¶

7.42.1. 名前¶

VIDIOC_G_TUNER - VIDIOC_S_TUNER - チューナー属性の取得または設定

7.42.2. 概要¶

VIDIOC_G_TUNER¶

int ioctl(int fd, VIDIOC_G_TUNER, struct v4l2_tuner *argp)

VIDIOC_S_TUNER¶

int ioctl(int fd, VIDIOC_S_TUNER, const struct v4l2_tuner *argp)

7.42.3. 引数¶

fd

返されるファイル記述子 open().

argp

struct mem_ctl_info v4l2_tuner.

7.42.4. 説明¶

チューナーの属性を照会するには、アプリケーションは index フィールドを初期化し、インデックスが範囲外の場合のエラーコードをゼロに設定する必要があります。 reserved 配列をゼロにします。 v4l2_tuner を初期化し、 VIDIOC_G_TUNER ioctlを実行する際には、この構造体へのポインタを指定します。ドライバは構造体の残りの部分を埋めたり、エラー コードを返したりします。 EINVAL インデックスが範囲外の場合のエラーコード。すべてのチューナーを列挙するには、アプリケーションはインデックスゼロから開始し、ドライバが返すまでインデックスを1ずつ増やします EINVAL.

チューナーには2つの書き込み可能なプロパティがあり、オーディオモードとラジオ周波数です。オーディオモードを変更するには、アプリケーションは index, audmode および reserved フィールドを初期化し、ioctlを呼び出します VIDIOC_S_TUNER ioctlを呼び出します。これにより ではありません 現在のチューナーが現在のビデオ入力によって決定されるため、現在のチューナーを変更します。要求されたモードが無効またはサポートされていない場合、ドライバは別のオーディオモードを選択できます。これは書き込み専用のioctlであるため、実際に選択されたオーディオモードは返されません

SDR 特定のチューナータイプは V4L2_TUNER_SDR および V4L2_TUNER_RFです。SDRデバイスの場合、 audmode フィールドはゼロに初期化する必要があります。この文脈では、「チューナー」という用語はSDR受信機を指します

ラジオ周波数を変更するには、 VIDIOC_S_FREQUENCY ioctlが利用可能です。

type v4l2_tuner¶
struct v4l2_tuner¶

__u32

index

チューナーを識別し、アプリケーションによって設定されます

__u8

name[32]

チューナーの名前、NULL終端のASCII文字列です

この情報はユーザー向けです。

__u32

type

チューナーのタイプ、参照: v4l2_tuner_type.

__u32

capability

チューナーの機能フラグ、参照: チューナーおよび変調器のキャパビリティフラグ。オーディオフラグはオーディオサブプログラムをデコードする能力を示します。これらは ではありません 現在のビデオ標準に応じて変化します

構造体がラジオチューナーを参照する場合、 V4L2_TUNER_CAP_LANG1, V4L2_TUNER_CAP_LANG2 および V4L2_TUNER_CAP_NORM フラグは使用できません

複数の周波数帯域がサポートされている場合、 capability はすべての capability の各フィールドを初期化する必要があります。文字列制御については、またもやフィールドを設定する必要があります。 v4l2_frequency_band.

__u32

rangelow

この周波数帯域の最低チューン可能な周波数を62.5kHz単位で表します。ただし、 capability フラグ V4L2_TUNER_CAP_LOW が設定されている場合、1 Hz単位で。 capability フラグ V4L2_TUNER_CAP_1HZ が設定され、1 Hz単位です。複数の周波数帯域がサポートされている場合、 rangelow はすべての周波数帯域の最低周波数です

__u32

rangehigh

この周波数帯域の最高チューン可能な周波数を62.5kHz単位で表します。ただし、 capability フラグ V4L2_TUNER_CAP_LOW が設定されている場合、1 Hz単位で。 capability フラグ V4L2_TUNER_CAP_1HZ が設定され、1 Hz単位です。複数の周波数帯域がサポートされている場合、 rangehigh はすべての周波数帯域の最高周波数です

__u32

rxsubchans

一部のチューナーやオーディオデコーダーは、オーディオキャリア、パイロットトーン、その他の指標を分析して受信したオーディオサブプログラムを特定できます。この情報を渡すには、ドライバは チューナーオーディオ受信フラグ このフィールドに設定します。例えば:

V4L2_TUNER_SUB_MONO

モノラルオーディオを受信中

STEREO | SAP

ステレオオーディオと二次オーディオプログラムを受信中

MONO | STEREO

モノラルまたはステレオオーディオを受信中、ハードウェアは区別できません

LANG1 | LANG2

バイリンガルオーディオを受信中

MONO | STEREO | LANG1 | LANG2

モノラル、ステレオ、またはバイリンガルオーディオを受信中

When the V4L2_TUNER_CAP_STEREO, _LANG1, _LANG2 または _SAP フラグがこのフィールドでクリアされています、 capability フィールドでは、対応する V4L2_TUNER_SUB_ フラグはここでは設定できません

このフィールドは、現在のビデオ入力のチューナーである場合、または構造体がラジオチューナーを参照する場合にのみ有効です

__u32

audmode

選択されたオーディオモード、参照: チューナーオーディオモード 有効な値については参照してください。オーディオモードはオーディオサブプログラムの検出に影響を与えず、 ユーザー制御 要求されたモードが無効またはサポートされていない場合を除き、自動的に変更されません。参照: チューナーオーディオマトリクス 選択された音声プログラムと受信した音声プログラムが一致しない場合の可能性のある結果。

現在、これはstruct structの唯一のフィールドです v4l2_tuner アプリケーションはこのフィールドを変更できます。

__u32

signal

信号強度がわかっている場合。

0から65535までの範囲。高い値は信号が良好を示します。

__s32

afc

自動周波数制御。

When the afc 値が負の場合、周波数が低すぎる、正の場合、周波数が高すぎる。

__u32

reserved[4]

ドライバーおよびアプリケーションは、配列をゼロに設定する必要があります。

BT.656/1120タイミングキャパビリティ。

チューナーおよび変調器のキャパビリティフラグ¶

V4L2_TUNER_CAP_LOW

0x0001

設定されている場合、チューニング周波数は62.5 Hz単位で表示されます（62.5 kHz単位ではなく）。

V4L2_TUNER_CAP_NORM

0x0002

これはマルチ標準チューナーです。ビデオ標準は変更可能または必須です。（B/G PALチューナーなどは通常、ビデオ標準が周波数帯域から自動的に決定されるため、マルチ標準とみなされません。）サポートするビデオ標準のセットは、struct v4l2_input このチューナーを指す構造体から取得できます。ioctlの説明を参照してください ioctl VIDIOC_ENUMINPUT 詳細については、 V4L2_TUNER_ANALOG_TV のみチューナーがこの機能を持つことができます。

V4L2_TUNER_CAP_HWSEEK_BOUNDED

0x0004

設定されている場合、このチューナーはハードウェアシーク機能をサポートし、周波数範囲の終わりに達したときにシークが停止します。

V4L2_TUNER_CAP_HWSEEK_WRAP

0x0008

設定されている場合、このチューナーはハードウェアシーク機能をサポートし、周波数範囲の終わりに達したときにシークが巻き戻します。

V4L2_TUNER_CAP_STEREO

0x0010

ステレオオーディオ受信がサポートされています。

V4L2_TUNER_CAP_LANG1

0x0040

bilingualオーディオプログラムの主要言語の受信がサポートされています。bilingualオーディオは2チャンネルシステムの特徴であり、主要言語のモノラルをメインオーディオキャリアで、副言語のモノラルを2番目のキャリアで送信します。のみ V4L2_TUNER_ANALOG_TV のみチューナーがこの機能を持つことができます。

V4L2_TUNER_CAP_LANG2

0x0020

bilingualオーディオプログラムの副言語の受信がサポートされています。のみ V4L2_TUNER_ANALOG_TV のみチューナーがこの機能を持つことができます。

V4L2_TUNER_CAP_SAP

0x0020

副音声プログラムの受信がサポートされています。これはNTSCビデオ標準に付随するBTSCシステムの特徴です。主要言語のモノラルまたはステレオ送信には2つのオーディオキャリアが利用可能で、副言語のモノラルには独立した3番目のキャリアが利用可能です。のみ V4L2_TUNER_ANALOG_TV のみチューナーがこの機能を持つことができます。

注意

以下の V4L2_TUNER_CAP_LANG2 および V4L2_TUNER_CAP_SAP フラグは同義語です。 V4L2_TUNER_CAP_SAP チューナーがサポートする V4L2_STD_NTSC_M ビデオ標準の場合に適用されます。

V4L2_TUNER_CAP_RDS

0x0080

RDSキャプチャがサポートされています。この機能はラジオチューナー専用です。

V4L2_TUNER_CAP_RDS_BLOCK_IO

0x0100

RDSデータは未解析のRDSブロックとして渡されます。

V4L2_TUNER_CAP_RDS_CONTROLS

0x0200

RDSデータはハードウェアによって解析され、制御経由で設定されます。

V4L2_TUNER_CAP_FREQ_BANDS

0x0400

以下の ioctl VIDIOC_ENUM_FREQ_BANDS ioctlを使用して利用可能な周波数帯域を列挙できます。

V4L2_TUNER_CAP_HWSEEK_PROG_LIM

0x0800

ハードウェアシーク機能を使用する際の検索範囲はプログラマブルです。参照してください ioctl VIDIOC_S_HW_FREQ_SEEK 詳しくは以下をご参照ください。

V4L2_TUNER_CAP_1HZ

0x1000

設定されている場合、チューニング周波数は1 Hz単位で表示されます（62.5 kHz単位ではなく）。
チューナーオーディオ受信フラグ¶

V4L2_TUNER_SUB_MONO

0x0001

チューナーはモノラルのオーディオ信号を受信します。

V4L2_TUNER_SUB_STEREO

0x0002

チューナーはステレオ音声信号を受信します。

V4L2_TUNER_SUB_LANG1

0x0008

チューナーはバイリンガル音声信号の主要言語を受信します。ドライバーは現在のビデオ標準が V4L2_STD_NTSC_M.

V4L2_TUNER_SUB_LANG2

0x0004

チューナーはバイリンガル音声信号の次要言語を受信します（または第二音声プログラム）。

V4L2_TUNER_SUB_SAP

0x0004

チューナーは第二音声プログラムを受信します。

注意

以下の V4L2_TUNER_SUB_LANG2 および V4L2_TUNER_SUB_SAP フラグは同義語です。The V4L2_TUNER_SUB_SAP フラグは現在のビデオ標準が V4L2_STD_NTSC_M.

V4L2_TUNER_SUB_RDS

0x0010

チューナーはRDSチャンネルを受信します。
チューナーオーディオモード¶

V4L2_TUNER_MODE_MONO

0

モノラル音声を再生します。チューナーがステレオ信号を受信した場合、これは左右チャンネルのダウンミックスです。チューナーがバイリンガルまたはSAP信号を受信した場合、このモードは主要言語を選択します。

V4L2_TUNER_MODE_STEREO

1

ステレオ音声を再生します。チューナーがバイリンガル音声を受信した場合、左チャンネルと右チャンネルで異なる言語を再生するか、主要言語を両チャンネルで再生するかを選択できます。

このモードでの異なる言語の再生は非推奨です。新しいドライバーはこの操作をのみ MODE_LANG1_LANG2.

チューナーがステレオ信号を受信しない場合またはステレオ受信をサポートしない場合、ドライバーは MODE_MONO.

V4L2_TUNER_MODE_LANG1

3

主要言語、モノラルまたはステレオを再生します。のみ V4L2_TUNER_ANALOG_TV チューナーのみこのモードをサポートします。

V4L2_TUNER_MODE_LANG2

2

次要言語、モノラルを再生します。チューナーがバイリンガル音声またはSAPを受信しない場合、またはその受信がサポートされていない場合、ドライバーはモノラルまたはステレオモードに戻ります。のみ V4L2_TUNER_ANALOG_TV チューナーのみこのモードをサポートします。

V4L2_TUNER_MODE_SAP

2

第二音声プログラムを再生します。チューナーがバイリンガル音声またはSAPを受信しない場合、またはその受信がサポートされていない場合、ドライバーはモノラルまたはステレオモードに戻ります。のみ V4L2_TUNER_ANALOG_TV チューナーのみこのモードをサポートします。

注意

以下の V4L2_TUNER_MODE_LANG2 および V4L2_TUNER_MODE_SAP は同義語です。

V4L2_TUNER_MODE_LANG1_LANG2

4

左チャンネルで主要言語、右チャンネルで次要言語を再生します。チューナーがバイリンガル音声またはSAPを受信しない場合、 MODE_LANG1 または MODE_MONO。のみ V4L2_TUNER_ANALOG_TV チューナーのみこのモードをサポートします。

7.42.5. 戻り値¶

成功した場合、0 が返されます。エラーの場合、-1 が返され、変数が適切に設定されます。 errno 一般的なエラーコードは、 汎用エラーコード 章。

EINVAL

構造体 v4l2_tuner index 範囲外です。

1

このモードはLinux 2.6.17で導入され、古いドライバーではサポートされていない可能性があります。

2

両方の言語の再生は MODE_STEREO は非推奨です。今後、ドライバーはこのモードで主要言語のみを再生する必要があります。アプリケーションは MODE_LANG1_LANG2 両方の言語またはステレオ信号を録音するようにリクエストする必要があります。
