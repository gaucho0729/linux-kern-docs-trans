7.17. ioctl VIDIOC_ENUM_FREQ_BANDS¶

7.17.1. 名前¶

VIDIOC_ENUM_FREQ_BANDS - サポートされている周波数帯域を列挙する

7.17.2. 概要¶

VIDIOC_ENUM_FREQ_BANDS¶

int ioctl(int fd, VIDIOC_ENUM_FREQ_BANDS, struct v4l2_frequency_band *argp)

7.17.3. 引数¶

fd

返されるファイル記述子 open().

argp

struct mem_ctl_info v4l2_frequency_band.

7.17.4. 説明¶

チューナーやモデュレータがサポートする周波数帯域を列挙します。これを行うには、アプリケーションは tuner, type および index フィールドを初期化し、構造体の reserved 配列をゼロにします。 v4l2_frequency_band を初期化し、 ioctl VIDIOC_ENUM_FREQ_BANDS この構造体へのポインタでioctlを実行します。

このioctlは、対応するチューナー/モデュレータの V4L2_TUNER_CAP_FREQ_BANDS キャパビリティが設定されている場合にのみサポートされます。

type v4l2_frequency_band¶
struct v4l2_frequency_band¶

__u32

tuner

チューナーまたはモデュレータのインデックス番号。これは構造体 v4l2_input tuner のフィールドおよび構造体 v4l2_tuner index のフィールド、または構造体 v4l2_output modulator のフィールドおよび構造体 v4l2_modulator index フィールドによって保護されています。

__u32

type

のフィールドです。タイプは v4l2_tuner type に設定する必要があります。 V4L2_TUNER_RADIO のために、 /dev/radioX デバイスノード、および V4L2_TUNER_ANALOG_TV すべての他の場合。このフィールドを V4L2_TUNER_RADIO モデュレータに設定してください（現在はラジオモデュレータのみがサポートされています）。参照 v4l2_tuner_type

__u32

index

アプリケーションによって設定される周波数帯域を特定します。

__u32

capability

この周波数帯域のチューナー/変調器のキャパビリティフラグ、詳細は チューナーおよび変調器のキャパビリティフラグの部分で、 V4L2_TUNER_CAP_LOW または V4L2_TUNER_CAP_1HZ キャパビリティは選択されたチューナー/変調器のすべての周波数帯域で同じでなければなりません。つまり、すべての帯域がそのキャパビリティを設定しているか、あるいはすべての帯域がそのキャパビリティを設定していないかのどちらかです。

__u32

rangelow

この周波数帯域の最低チューン可能な周波数を62.5kHz単位で表します。ただし、 capability フラグ V4L2_TUNER_CAP_LOW が設定されている場合は62.5Hz単位で表します。1Hz単位が使用されるのは capability フラグ V4L2_TUNER_CAP_1HZ が設定される前。

__u32

rangehigh

この周波数帯域の最高チューン可能な周波数を62.5kHz単位で表します。ただし、 capability フラグ V4L2_TUNER_CAP_LOW が設定されている場合は62.5Hz単位で表します。1Hz単位が使用されるのは capability フラグ V4L2_TUNER_CAP_1HZ が設定される前。

__u32

modulation

この周波数帯域でサポートされる変調システム。詳細は 帯域変調システム.

注意

現在は1つの変調システムのみが各周波数帯域でサポートされています。複数の変調システムが可能である場合、追加の作業が必要になります。このような機能が必要な場合は、linux-mediaメーリングリスト（https://linuxtv.org/lists.php)にご連絡ください。

__u32

reserved[9]

ドライバーおよびアプリケーションは、配列をゼロに設定する必要があります。

アプリケーションおよびドライバは配列をゼロに設定しなければなりません。
帯域変調システム¶

V4L2_BAND_MODULATION_VSB

0x02

残留側帯変調、アナログテレビ用に使用されます。

V4L2_BAND_MODULATION_FM

0x04

周波数変調、アナログラジオで一般的に使用されます。

V4L2_BAND_MODULATION_AM

0x08

振幅変調、アナログラジオで一般的に使用されます。

7.17.5. 戻り値¶

成功した場合、0 が返されます。エラーの場合、-1 が返され、変数が適切に設定されます。 errno 一般的なエラーコードは、 汎用エラーコード 章。

EINVAL

以下の tuner または index が範囲外か、 type フィールドが正しくありません。
