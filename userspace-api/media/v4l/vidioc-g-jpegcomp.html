7.34. ioctl VIDIOC_G_JPEGCOMP, VIDIOC_S_JPEGCOMP¶

7.34.1. 名前¶

VIDIOC_G_JPEGCOMP - VIDIOC_S_JPEGCOMP

7.34.2. 概要¶

VIDIOC_G_JPEGCOMP¶

int ioctl(int fd, VIDIOC_G_JPEGCOMP, v4l2_jpegcompression *argp)

VIDIOC_S_JPEGCOMP¶

int ioctl(int fd, VIDIOC_S_JPEGCOMP, const v4l2_jpegcompression *argp)

7.34.3. 引数¶

fd

返されるファイル記述子 open().

argp

struct mem_ctl_info v4l2_jpegcompression.

7.34.4. 説明¶

これらはioctlです 非推奨. 新しいドライバとアプリケーションでは使用すべきです JPEGクラスの制御 画像品質とJPEGマーカーの制御に使用されます。

ロナルド・バルテの説明:

APPはアプリケーション固有の情報です。アプリケーション自身で設定でき、JPEG符号化されたフィールドに保存されます（例：AVIなどのインターレース情報など）。COMも同様ですが、コメントです。例えば「私によって符号化されました」などです。

jpeg_markersは、ハフマンテーブル、量子化テーブル、および再開間隔情報（すべてJPEG固有の情報）がJPEG符号化されたフィールドに保存されるかどうかを記述します。これらはJPEGフィールドの符号化方法を定義します。これらを省略すると、アプリケーションは標準符号化を使用していると仮定します。通常はこれらを追加することをお勧めします。

7.34.5. 戻り値¶

成功した場合、0 が返されます。エラーの場合、-1 が返され、変数が適切に設定されます。 errno 一般的なエラーコードは、 汎用エラーコード 章。
