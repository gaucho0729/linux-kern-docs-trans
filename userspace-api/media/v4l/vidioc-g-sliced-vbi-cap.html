7.40. ioctl VIDIOC_G_SLICED_VBI_CAP¶

7.40.1. 名前¶

VIDIOC_G_SLICED_VBI_CAP - スライスされたVBIの機能を照会する

7.40.2. 概要¶

VIDIOC_G_SLICED_VBI_CAP¶

int ioctl(int fd, VIDIOC_G_SLICED_VBI_CAP, struct v4l2_sliced_vbi_cap *argp)

7.40.3. 引数¶

fd

返されるファイル記述子 open().

argp

struct mem_ctl_info v4l2_sliced_vbi_cap.

7.40.4. 説明¶

スライスされたVBIキャプチャまたは出力デバイスがサポートするデータサービスを確認するには、アプリケーションは type フィールドを設定します。 v4l2_sliced_vbi_cap, クリアする reserved 現在のチューナーやモデュレータのラジオ周波数を変更するには、アプリケーションはこの構造体を初期化し VIDIOC_G_SLICED_VBI_CAP ioctl. ドライバが残りのフィールドを埋めたり、スライスされたVBI APIがサポートされていない場合のエラーコードを返したりします EINVAL error code if the sliced VBI API is unsupported or type が無効な場合。

注意

以下の type フィールドが追加され、ioctlが読み取り専用から読み書き可能に変更されたのは、Linux 2.6.19からです。
