6.2. V4L2 APIの変更点¶

V4L APIがカーネルに追加された直後に、柔軟性が足りないとして批判されました。1998年8月、ビル・ディルクスはいくつかの改善点を提案し、ドキュメンテーション、例ドライバー、アプリケーションの作成を開始しました。他のボランティアの協力により、最終的にはV4L2 APIとなりました。これはV4L APIの拡張ではなく、置き換えとなるものでした。しかし、新しいAPIが現在の形でカーネルに採用されるまでには、さらに4年間と2つの安定版カーネルリリースが必要となりました。

6.2.56. V4L2 とその他の Linux マルチメディア API の関係¶

6.2.56.1. X Video Extension¶

X Video Extension（XVideo または Xv と略称される）は X Window システムの拡張機能で、XFree86 プロジェクトなどで実装されています。その範囲は V4L2 と似ており、X クライアント向けのビデオキャプチャおよび出力デバイスの API です。Xv はアプリケーションがウィンドウ内でライブビデオを表示したり、ウィンドウの内容をテレビ出力に送信したり、XPixmaps で静止画をキャプチャまたは出力したりする機能を提供します 1。XFree86 による実装により、この拡張機能は多くのオペレーティングシステムとアーキテクチャで利用可能になります

ドライバが X サーバーに埋め込まれているため、Xv は V4L2 に比べていくつかの利点があります ビデオオーバーレイインターフェース。ドライバはオーバーレイ対象を簡単に判定できます（例：表示されるグラフィックメモリまたはオフスクリーンバッファ）。非破壊的なオーバーレイでは RAMDAC をプログラミングし、スケーリングやカラーキー処理、またはビデオキャプチャハードウェアのクリッピング機能を制御できます。常に描画操作やウィンドウの移動、スタック順序の変更と同期して動作します

Xv と V4L の利点を組み合わせるために、XFree86 と XOrg には特別な Xv ドライバが存在し、見つかったすべてのオーバーレイ可能な Video4Linux デバイスを操作します。これを有効にするには /etc/X11/XF86Config 以下の行を含める必要があります:

Section "Module"
    Load "v4l"
EndSection

XFree86 4.2 以降ではこのドライバは V4L ioctls にのみ対応していますが、V4L2 バックワード互換レイヤーを通じてすべての V4L2 デバイスで動作するはずです。V4L2 は複数のオープンを許可しているため、V4L2 ドライバがサポートする場合、X クライアントがビデオオーバーレイを要求している間にビデオキャプチャが可能です。同時キャプチャとオーバーレイの制限については Video Overlay Interface 適用されます。

V4L2 とは僅かに関連するが、XFree86 は Xv を拡張し、ハードウェアによる YUV から RGB への変換とスケーリングをサポートして高速なビデオ再生を可能にし、MPEG-2 解码ハードウェアへのインターフェースを追加しました。この API は V4L2 デバイスでキャプチャした画像を表示するために役立ちます

6.2.56.2. デジタルビデオ¶

V4L2 はデジタル地上波、ケーブル、衛星放送をサポートしていません。別途存在するデジタル受信機用プロジェクトがあります。そのホームページは https://linuxtv.orgです。Linux DVB API は V4L2 API と直接的な関係はありませんが、ハイブリッドハードウェア用のドライバが両方をサポートする場合があります

6.2.58. 非推奨のAPI要素¶

以下のV4L2 API要素は新しいインターフェースによって置き換えられ、新規ドライバで実装すべきではありません。

  • VIDIOC_G_MPEGCOMP および VIDIOC_S_MPEGCOMP ioctls。拡張制御を使用してください、 拡張コントロールAPI.

  • VIDIOC_G_DV_PRESET、VIDIOC_S_DV_PRESET、VIDIOC_ENUM_DV_PRESETS および VIDIOC_QUERY_DV_PRESET ioctls。DVタイミングAPIを使用してください（デジタルビデオ（DV）タイミング).

  • VIDIOC_SUBDEV_G_CROP および VIDIOC_SUBDEV_S_CROP ioctls。使用してください VIDIOC_SUBDEV_G_SELECTION および VIDIOC_SUBDEV_S_SELECTION, ioctl VIDIOC_SUBDEV_G_SELECTION, VIDIOC_SUBDEV_S_SELECTION.

1

これはXFree86では実装されていません。
