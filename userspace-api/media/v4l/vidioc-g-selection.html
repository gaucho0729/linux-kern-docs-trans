7.39. ioctl VIDIOC_G_SELECTION, VIDIOC_S_SELECTION¶

7.39.1. 名前¶

VIDIOC_G_SELECTION - VIDIOC_S_SELECTION - 選択矩形の取得または設定

7.39.2. 概要¶

VIDIOC_G_SELECTION¶

int ioctl(int fd, VIDIOC_G_SELECTION, struct v4l2_selection *argp)

VIDIOC_S_SELECTION¶

int ioctl(int fd, VIDIOC_S_SELECTION, struct v4l2_selection *argp)

7.39.3. 引数¶

fd

返されるファイル記述子 open().

argp

struct mem_ctl_info v4l2_selection.

7.39.4. 説明¶

これらのioctlは、選択矩形を照会および構成するために使用されます。

クロッピング（コンポジット）矩形を照会するには、structを該当するバッファタイプに設定します。 v4l2_selection type 次に、structの値を設定するステップに進みます。 v4l2_selection target フィールドに渡して V4L2_SEL_TGT_CROP (V4L2_SEL_TGT_COMPOSE). 以下の表を参照してください 一般的な選択定義 または クロッピング、コンポジット、スケーリング – SELECTION API の追加ターゲットについては flags および reserved に移動されました。 v4l2_selection は無視され、ゼロで埋めなければなりません。ドライバが不正確なバッファタイプまたはターゲットが使用された場合、構造体の残りを埋めるか、EINVALエラーを返します。クロッピング（コンポジット）がサポートされていない場合、アクティブ矩形は変更不可能であり、常に境界矩形と等しくなります。最後に、struct v4l2_rect r 矩形は現在のクロッピング（コンポジット）座標で埋められます。座標はドライバ依存の単位で表現されます。ただし、raw形式の画像の矩形については、座標は常にピクセルで表現されます。

クロッピング（コンポジット）矩形を変更するには、structを該当するターゲットに設定します。 v4l2_selection type 次に、structの値を設定するステップに進みます。 v4l2_selection target に（木の下から葉に向かって） V4L2_SEL_TGT_CROP (V4L2_SEL_TGT_COMPOSE). 以下の表を参照してください 一般的な選択定義 または クロッピング、コンポジット、スケーリング – SELECTION API の追加ターゲットについては v4l2_rect r 矩形は望ましいアクティブエリアに設定する必要があります。struct v4l2_selection reserved は無視され、ゼロで埋めなければなりません。ドライバが要求された矩形の座標を調整する可能性があります。アプリケーションは丸め動作を制御するための制約を導入できます。struct v4l2_selection flags は次のいずれかに設定する必要があります:

  • 0 - ドライバは矩形サイズを自由に調整でき、要求されたものに最も近いクロッピング/コンポジット矩形を選択する必要があります。

  • V4L2_SEL_FLAG_GE - ドライバは矩形を縮小してはなりません。元の矩形は調整後の矩形内に含まれなければなりません。

  • V4L2_SEL_FLAG_LE - ドライバは矩形を拡大してはなりません。調整後の矩形は元の矩形内に含まれなければなりません。

  • V4L2_SEL_FLAG_GE | V4L2_SEL_FLAG_LE - ドライバは要求された矩形のサイズと完全に一致させる必要があります。

参照してください サイズ調整と制約フラグ.

ドライバはハードウェアの制限やパイプラインの他の部分（キャプチャ/出力ウィンドウやTVディスプレイの境界など）に応じて要求された寸法を調整する必要があります。水平および垂直オフセットとサイズの最も近い値は、以下の優先順位に従って選択されます:

  1. struct v4l2_selection flags.

  2. の制約を満たす

  3. 幅、高さ、左、上をハードウェアの制限とアライメントに合わせて調整する。

  4. 調整後の矩形の中心を元のものにできるだけ近づける。

  5. 幅と高さを元のものにできるだけ近づける。

成功した場合、struct v4l2_rect r フィールドには調整後の矩形が含まれます。パラメータが不適切な場合、アプリケーションはクロッピング（コンポジング）または画像パラメータを変更し、満足できるパラメータが協議されるまでサイクルを繰り返します。制約フラグを違反しなければならない場合 ERANGE エラーが返されます。このエラーは 制約を満たす矩形が存在しない場合 です。

注意

残念なことに、マルチプレーンバッファタイプ（V4L2_BUF_TYPE_VIDEO_CAPTURE_MPLANE および V4L2_BUF_TYPE_VIDEO_OUTPUT_MPLANE) においてこのAPIは、フィールドの入力方法について誤って作成されてしまいました。一部のドライバはバッファタイプのみを受け入れ、他のドライバはマルチプレーンバッファタイプ以外（つまり、 v4l2_selection type のないバッファタイプのみ）を受け入れていました。 _MPLANE バッファタイプのみを受け入れていました。一部のドライバはバッファタイプのみを受け入れ、他のドライバはマルチプレーンバッファタイプ以外（つまり、 _MPLANE のないバッファタイプのみ）を受け入れていました。

カーネル4.13以降では、両方のバッファタイプが許可されます。

7.39.5. 戻り値¶

成功した場合、0 が返されます。エラーの場合、-1 が返され、変数が適切に設定されます。 errno 一般的なエラーコードは、 汎用エラーコード 章。

EINVAL

指定されたバッファータイプ type または選択対象 target サポートされていません、または flags 引数が無効です。

ERANGE

構造体を調整することはできません。 v4l2_rect r 矩形をすべての制約を満たすように調整することはできません。 flags 引数。

ENODATA

この入力または出力では選択がサポートされていません。

EBUSY

現在、選択矩形の変更を適用することはできません。通常、ストリーミングが進行中であるためです。
