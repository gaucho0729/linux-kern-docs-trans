7.9. ioctl VIDIOC_DV_TIMINGS_CAP, VID.MIOC_SUBDEV_DV_TIMINGS_CAP¶

7.9.1. 名前¶

VIDIOC_DV_TIMINGS_CAP - VIDIOC_SUBDEV_DV_TIMINGS_CAP - デジタルビデオ受信/送信装置のキャパビリティ

7.9.2. 概要¶

VIDIOC_DV_TIMINGS_CAP¶

int ioctl(int fd, VIDIOC_DV_TIMINGS_CAP, struct v4l2_dv_timings_cap *argp)

VIDIOC_SUBDEV_DV_TIMINGS_CAP¶

int ioctl(int fd, VIDIOC_SUBDEV_DV_TIMINGS_CAP, struct v4l2_dv_timings_cap *argp)

7.9.3. 引数¶

fd

返されるファイル記述子 open().

argp

struct mem_ctl_info v4l2_dv_timings_cap.

7.9.4. 説明¶

DV受信/送信装置のキャパビリティを照会するには、アプリケーションがフィールドを0に初期化し、structの予約済み配列をゼロに設定します。 pad ビデオノードに対してioctlを実行すると、ドライバーが構造体を埋めます。 v4l2_dv_timings_cap を初期化し、 VIDIOC_DV_TIMINGS_CAP ドライバーは、ビデオ入力または出力の切り替え後に異なる値を返すことがあります。

注意

ドライバーが実装している場合、サブデバイスのDVキャパビリティは、サブデバイスノードに対して直接ioctlを呼び出すことで照会できます。

キャパビリティは、DV受信装置の場合には入力（for DV receivers）または出力（for DV transmitters）に特有です。アプリケーションはstructのフィールドに望ましいpad番号を指定し、配列をゼロに設定します。 VIDIOC_SUBDEV_DV_TIMINGS_CAP padがサポートしていない場合のキャパビリティ照会は、エラーを返します。 v4l2_dv_timings_cap pad v4l2_bt_timings_cap reserved struct v4l2_bt_timings_cap EINVAL エラー コードに設定します。
