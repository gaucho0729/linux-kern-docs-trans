7.53. ioctl VIDIOC_S_HW_FREQ_SEEK¶

7.53.1. 名前¶

VIDIOC_S_HW_FREQ_SEEK - ハードウェア周波数検索を実行します

7.53.2. 概要¶

VIDIOC_S_HW_FREQ_SEEK¶

int ioctl(int fd, VIDIOC_S_HW_FREQ_SEEK, struct v4l2_hw_freq_seek *argp)

7.53.3. 引数¶

fd

返されるファイル記述子 open().

argp

struct mem_ctl_info v4l2_hw_freq_seek.

7.53.4. 説明¶

現在の周波数からハードウェア周波数検索を開始します。これを行うには、アプリケーションが tuner, type, seek_upward, wrap_around, spacing, rangelow および rangehigh フィールドを初期化し、構造体の reserved 配列をゼロにします。 v4l2_hw_freq_seek を初期化し、 VIDIOC_S_HW_FREQ_SEEK この構造体へのポインタでioctlを実行します。

以下の rangelow および rangehigh フィールドをゼロ以外の値に設定することで、ドライバーに特定のバンドを検索するように指示できます。struct v4l2_tuner capability フィールドが V4L2_TUNER_CAP_HWSEEK_PROG_LIM フラグが設定されている場合、これらの値は、 ioctl VIDIOC_ENUM_FREQ_BANDS。もし V4L2_TUNER_CAP_HWSEEK_PROG_LIM フラグが設定されていない場合、これらの値は、 ioctl VIDIOC_ENUM_FREQ_BANDSによって返されたバンドのいずれかに含まれなければなりません。 tuner の現在の周波数が選択されたバンド内にない場合、検索を開始する前にそのバンドに合わせて調整されます。

エラーが返された場合、元の周波数に戻されます。

このioctlは、対応するチューナー/モデュレータの V4L2_CAP_HW_FREQ_SEEK キャパビリティが設定されている場合

この ioctl が非ブロッキングファイルハンドルから呼び出された場合、 EAGAIN エラー コードが返され、検索は行われません。

type v4l2_hw_freq_seek¶
struct v4l2_hw_freq_seek¶

__u32

tuner

チューナーのインデックス番号。これは struct v4l2_input tuner のフィールドおよび構造体 v4l2_tuner index フィールドによって保護されています。

__u32

type

のフィールドです。タイプは v4l2_tuner type のフィールドと同じです。詳しくは v4l2_tuner_type

__u32

seek_upward

ゼロ以外の場合は、現在の周波数から上向きに検索します。それ以外は下向きに検索します。

__u32

wrap_around

ゼロ以外の場合は、周波数範囲の終わりで巻き戻しを行います。それ以外は検索を停止します。struct v4l2_tuner capability フィールドがハードウェアがサポートする内容を教えてくれます。

__u32

spacing

ゼロ以外の場合は、ハードウェアの検索分解能を Hz 単位で定義します。ドライバーはデバイスがサポートする最も近い値を選択します。spacing がゼロの場合、適切なデフォルト値が使用されます。

__u32

rangelow

ゼロ以外の場合は、検索対象のバンドの最低可変周波数を 62.5 kHz 単位で指定します。struct v4l2_tuner capability フィールドが V4L2_TUNER_CAP_LOW フラグが設定されている場合、62.5 Hz 単位で、または struct v4l2_tuner capability フィールドが V4L2_TUNER_CAP_1HZ フラグが設定されている場合、1 Hz 単位で。もし rangelow ゼロの場合、適切なデフォルト値が使用されます。

__u32

rangehigh

ゼロ以外の場合は、検索対象のバンドの最高可変周波数を 62.5 kHz 単位で指定します。struct v4l2_tuner capability フィールドが V4L2_TUNER_CAP_LOW フラグが設定されている場合、62.5 Hz 単位で、または struct v4l2_tuner capability フィールドが V4L2_TUNER_CAP_1HZ フラグが設定されている場合、1 Hz 単位で。もし rangehigh ゼロの場合、適切なデフォルト値が使用されます。

__u32

reserved[5]

今後の拡張用に予約されています。アプリケーションは配列をゼロに設定しなければなりません。

7.53.5. 戻り値¶

成功した場合、0 が返されます。エラーの場合、-1 が返され、変数が適切に設定されます。 errno 一般的なエラーコードは、 汎用エラーコード 章。

EINVAL

以下の tuner インデックスが範囲外の場合、 wrap_around 値がサポートされていないか、配列内の値のいずれかが不正です。 type, rangelow または rangehigh フィールドが誤っています。

EAGAIN

呼び出そうとしたが、 VIDIOC_S_HW_FREQ_SEEK ファイルハンドルが非ブロッキングモードで使用されていたためです。

ENODATA

ハードウェアの検索でチャンネルが見つかりませんでした。

EBUSY

別のハードウェアの検索が既に進行中です。
