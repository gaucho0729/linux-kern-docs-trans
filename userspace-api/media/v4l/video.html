1.4. ビデオ入力と出力¶

ビデオ入出力はデバイスの物理的なコネクタです。これらはたとえばRFコネクタ（アンテナ/ケーブル）、CVBS（コンポジットビデオ）、S-Video、RGBコネクタなどです。カメラセンサーもビデオ入力として扱われます。ビデオおよびVBIキャプチャデバイスには入力があり、ビデオおよびVBI出力デバイスには出力があります（それぞれ少なくとも1つずつ）。ラジオデバイスにはビデオ入出力はありません。

利用可能な入力と出力の数と属性を学ぶには、アプリケーションは ioctl VIDIOC_ENUMINPUT および ioctl VIDIOC_ENUMOUTPUT ioctlでそれらを列挙できます。struct v4l2_input は ioctl VIDIOC_ENUMINPUT ioctlは、現在のビデオ入力が照会される際のシグナル状態情報を含みます。

以下の VIDIOC_G_INPUT および VIDIOC_G_OUTPUT ioctlは現在のビデオ入力または出力のインデックスを返します。異なる入力または出力に切り替えるには、アプリケーションは以下のioctlを呼び出します。 VIDIOC_S_INPUT および VIDIOC_S_OUTPUT デバイスに1つ以上の入力がある場合、ドライバーはすべての入力ioctlを実装する必要があります。デバイスに1つ以上の出力がある場合、すべての出力ioctlを実装する必要があります。

1.4.1. 例: 現在のビデオ入力に関する情報¶

struct v4l2_input input;
int index;

if (-1 == ioctl(fd, VIDIOC_G_INPUT, &index)) {
    perror("VIDIOC_G_INPUT");
    exit(EXIT_FAILURE);
}

memset(&input, 0, sizeof(input));
input.index = index;

if (-1 == ioctl(fd, VIDIOC_ENUMINPUT, &input)) {
    perror("VIDIOC_ENUMINPUT");
    exit(EXIT_FAILURE);
}

printf("Current input: %s\\n", input.name);

1.4.2. 例: 1番目のビデオ入力に切り替え¶

int index;

index = 0;

if (-1 == ioctl(fd, VIDIOC_S_INPUT, &index)) {
    perror("VIDIOC_S_INPUT");
    exit(EXIT_FAILURE);
}
