7.18. ioctl VIDIOC_ENUMINPUT¶

7.18.1. 名前¶

VIDIOC_ENUMINPUT - ビデオ入力の列挙

7.18.2. 概要¶

VIDIOC_ENUMINPUT¶

int ioctl(int fd, VIDIOC_ENUMINPUT, struct v4l2_input *argp)

7.18.3. 引数¶

fd

返されるファイル記述子 open().

argp

struct mem_ctl_info v4l2_input.

7.18.4. 説明¶

ビデオ入力の属性を照会するには、アプリケーションはこの構造体へのポインタを初期化します。 index 構造体の v4l2_input を初期化し、 ioctl VIDIOC_ENUMINPUT ドライバはインデックスが範囲外の場合、構造体の残り部分を埋めたり、エラー コードを返したりします。 EINVAL すべての入力を列挙するには、アプリケーションはインデックスゼロから開始し、ドライバがエラーを返すまでインデックスを1ずつ増やします。 EINVAL.

type v4l2_input¶
struct v4l2_input¶

__u32

index

入力を識別します。アプリケーションが設定します。

__u8

name[32]

ビデオ入力の名前。NULL終端のASCII文字列で、例: 「Vin (Composite 2)」です。この情報はユーザー向けで、できればデバイス自体のコネクタラベルを示します。

__u32

type

入力のタイプ、詳しくは 入力タイプ.

__u32

audioset

ドライバは最大32のビデオおよびオーディオ入力を列挙できます。このフィールドは、このビデオ入力が現在選択されている場合に選択可能なオーディオ入力を示します。ビットマスクです。LSBはオーディオ入力0に対応し、MSBは入力31に対応します。任意のビットを設定するか、それとも何も設定しないか可能です。

ドライバがオーディオ入力を列挙しない場合、ビットは設定しない必要があります。アプリケーションはこれをオーディオサポートの欠如と解釈してはいけません。一部のドライバはオーディオソースを自動的に選択し、選択肢がないため列挙しません。

オーディオ入力の詳細および現在の入力の選択方法については、 オーディオ入出力.

__u32

tuner

キャプチャデバイスはゼロ個または複数のチューナー（RFデモジュレータ）を持つことができます。このフィールドは、 type が V4L2_INPUT_TYPE_TUNER これはRFコネクタであり、このフィールドはチューナーを識別します。これはstruct v4l2_tuner フィールド index. チューナーの詳細については、 チューナーとモジュレータ.

v4l2_std_id

std

すべてのビデオ入力は1つまたは複数の異なるビデオ標準をサポートします。このフィールドはすべてのサポートされている標準を示します。ビデオ標準の詳細および切り替え方法については、 ビデオ標準.

__u32

status

このフィールドは入力の状態情報を提供します。詳しくは 入力状態フラグ センサーの向きに関するビットを除き status このフィールドは、この入力が現在の入力である場合にのみ有効です。

__u32

capabilities

このフィールドは入力の機能を提供します。詳しくは 入力機能 フラグについては。

__u32

reserved[3]

今後の拡張用に予約されています。ドライバは配列をゼロに設定する必要があります。
入力タイプ¶

V4L2_INPUT_TYPE_TUNER

1

この入力はチューナー（RFデモジュレータ）を使用します。

V4L2_INPUT_TYPE_CAMERA

2

チューナー以外のビデオ入力、例えばコンポジットビデオ、S-ビデオ、HDMI、カメラセンサー。この命名は _TYPE_CAMERA は歴史的です。今日ではこれを _TYPE_VIDEO.

V4L2_INPUT_TYPE_TOUCH

3

この入力は、素直なタッチデータをキャプチャするためのタッチデバイスです。

入力機能¶

0x00000002

この入力は、選択対象を使用してビデオタイミングを設定することをサポートしています VIDIOC_S_DV_TIMINGS.

V4L2_IN_CAP_STD

0x00000004

この入力は、選択対象を使用してテレビ標準を設定することをサポートしています VIDIOC_S_STD.

V4L2_IN_CAP_NATIVE_SIZE

0x00000008

この入力は、選択対象を使用してネイティブサイズを設定することをサポートしています V4L2_SEL_TGT_NATIVE_SIZE 選択対象を参照してください 一般的な選択定義.

7.18.5. 戻り値¶

成功した場合、0 が返されます。エラーの場合、-1 が返され、変数が適切に設定されます。 errno 一般的なエラーコードは、 汎用エラーコード 章。

EINVAL

構造体 v4l2_input index 範囲外です。
