1.19. FM送信機制御リファレンス¶

FM送信機（FM_TX）クラスは、FM送信可能なデバイスの一般的な機能に対する制御を含みます。現在このクラスには、オーディオ圧縮、パイロットトーン生成、オーディオ偏差リミッタ、RDS送信およびチューニング電力などのパラメータが含まれています。

1.19.1. FM_TX制御ID¶

V4L2_CID_FM_TX_CLASS (class)

FM_TXクラスの記述子。呼び出し ioctls VIDIOC_QUERYCTRL、VIDIOC_QUERY_EXT_CTRL および VIDIOC_QUERYMENU この制御クラスの説明が返されます。

V4L2_CID_RDS_TX_DEVIATION (integer)

RDS信号の周波数偏差レベル（Hz）を設定します。範囲とステップはドライバ固有です。

V4L2_CID_RDS_TX_PI (integer)

送信用RDS放送識別フィールドを設定します。

V4L2_CID_RDS_TX_PTY (integer)

送信用RDS放送タイプフィールドを設定します。これは最大31種類の事前定義された放送タイプをエンコードします。

V4L2_CID_RDS_TX_PS_NAME (string)

送信用の放送サービス名（PS_NAME）を設定します。これは受信機での静的な表示に使用され、聴取者にとって放送サービスの識別と選択の主な補助手段です。この情報は、 IEC 62106、RDS仕様書ではプログラムサービス名文字列の正しい文字エンコードの詳細な説明があります。またRDS仕様書ではPSは通常8文字のテキストですが、8×N文字の文字列をスクロール可能な受信機も存在します。そのためこの制御は8文字単位で設定する必要があります。結果として常に8の倍数のサイズの文字列を含まなければなりません

V4L2_CID_RDS_TX_RADIO_TEXT (string)

送信用のラジオテキスト情報を設定します。これは放送されているコンテンツのテキスト説明です。放送局がより長いPS名や放送関連情報、または他のテキストを送信したい場合、ラジオテキストをPS_NAMEとともに使用する必要があります。このような場合、 V4L2_CID_RDS_TX_PS_NAMEに追加で使用できます。ラジオテキスト文字列のエンコード方法もAnnex Eの IEC 62106で完全に記述されています。ラジオテキスト文字列の長さは使用しているRDSブロックによって異なります。32（2Aブロック）または64（2Bブロック）文字ですが、32×N文字または64×N文字の文字列をスクロール可能な受信機も存在します。そのためこの制御は32または64文字単位で設定する必要があります。結果として常に32または64の倍数のサイズの文字列を含まなければなりません

V4L2_CID_RDS_TX_MONO_STEREO (boolean)

デコーダー識別コードのモノラル/ステレオビットを設定します。設定されている場合、オーディオはステレオで録音されています。

V4L2_CID_RDS_TX_ARTIFICIAL_HEAD (boolean)

設定します Artificial Head デコーダー識別コードのビット。設定されている場合、オーディオは人工ヘッドを使用して録音されています。

V4L2_CID_RDS_TX_COMPRESSED (boolean)

デコーダー識別コードの圧縮ビットを設定します。設定されている場合、オーディオは圧縮されています。

V4L2_CID_RDS_TX_DYNAMIC_PTY (boolean)

デコーダー識別コードの動的PTYビットを設定します。設定されている場合、PTYコードは動的に切り替えられます。

V4L2_CID_RDS_TX_TRAFFIC_ANNOUNCEMENT (boolean)

交通情報放送が進行中であることを示します

V4L2_CID_RDS_TX_TRAFFIC_PROGRAM (boolean)

チューニングされた番組が交通情報放送を含んでいることを示します

V4L2_CID_RDS_TX_MUSIC_SPEECH (boolean)

設定されている場合、このチャンネルは音楽を放送します。クリアされている場合、スピーチを放送します。送信機がこの区別をしない場合は、設定する必要があります。

V4L2_CID_RDS_TX_ALT_FREQS_ENABLE (boolean)

代替周波数を送信するかどうかを設定します。

V4L2_CID_RDS_TX_ALT_FREQS (__u32 array)

代替周波数（kHz単位）。RDS標準では最大25の周波数を定義できます。ドライバがサポートする周波数は少ない場合がありますので、配列サイズを確認してください。

V4L2_CID_AUDIO_LIMITER_ENABLED (boolean)

オーディオ偏差リミッタ機能を有効にするか無効にするかを設定します。リミッタはオーディオボリュームを最大化し、受信機による歪みを最小限に抑え、過度な変調を防ぐのに役立ちます。

V4L2_CID_AUDIO_LIMITER_RELEASE_TIME (integer)

オーディオ偏差リミッタ機能の解放時間（マイクロ秒単位）を設定します。ステップと範囲はドライバ固有です。

V4L2_CID_AUDIO_LIMITER_DEVIATION (integer)

オーディオ周波数偏差レベル（Hz）を設定します。範囲とステップはドライバ固有です。

V4L2_CID_AUDIO_COMPRESSION_ENABLED (boolean)

オーディオ圧縮機能を有効にするか無効にすることができます。この機能は、しきい値以下の信号を固定ゲインで増幅し、しきい値以上のオーディオ信号はしきい値/(ゲイン + しきい値)の比率で圧縮します。

V4L2_CID_AUDIO_COMPRESSION_GAIN (integer)

オーディオ圧縮機能のゲインを設定します。単位はdBです。範囲とステップはドライバ固有です。

V4L2_CID_AUDIO_COMPRESSION_THRESHOLD (integer)

オーディオ圧縮機能のしきい値レベルを設定します。単位はdBです。範囲とステップはドライバ固有です。

V4L2_CID_AUDIO_COMPRESSION_ATTACK_TIME (integer)

オーディオ圧縮機能のアタック時間（信号がしきい値を超えるまでの時間）を設定します。単位はマイクロ秒です。範囲とステップはドライバ固有です。

V4L2_CID_AUDIO_COMPRESSION_RELEASE_TIME (integer)

オーディオ圧縮機能のリリース時間（信号がしきい値以下になるまでの時間）を設定します。単位はマイクロ秒です。範囲とステップはドライバ固有です。

V4L2_CID_PILOT_TONE_ENABLED (boolean)

パイロットトーン生成機能を有効にするか無効にすることができます。

V4L2_CID_PILOT_TONE_DEVIATION (integer)

パイロットトーン周波数の偏差レベルを設定します。単位はHzです。範囲とステップはドライバ固有です。

V4L2_CID_PILOT_TONE_FREQUENCY (integer)

パイロットトーン周波数値を設定します。単位はHzです。範囲とステップはドライバ固有です。

V4L2_CID_TUNE_PREEMPHASIS

(enum)

enum v4l2_preemphasis -

放送用のプレアンプ値を設定します。プレアンプフィルタが適用され、高域のオーディオ周波数を強調します。地域によっては50マイクロ秒または75マイクロ秒の時間定数が使用されます。enum v4l2_preemphasisはプレアンプの可能な値を定義しており、以下に示します。

V4L2_PREEMPHASIS_DISABLED

プレアンプは適用されません。

V4L2_PREEMPHASIS_50_uS

50マイクロ秒のプレアンプが使用されます。

V4L2_PREEMPHASIS_75_uS

75マイクロ秒のプレアンプが使用されます。
V4L2_CID_TUNE_POWER_LEVEL (integer)

信号送信時の出力電力レベルを設定します。単位はdBuVです。範囲とステップはドライバ固有です。

V4L2_CID_TUNE_ANTENNA_CAPACITOR (integer)

アンテナチューニングキャパシタの値を手動またはゼロに設定して自動で選択します。単位、範囲、ステップはドライバ固有です。

RDS仕様の詳細については、 IEC 62106 ドキュメントを参照してください。CENELECから提供されています。
