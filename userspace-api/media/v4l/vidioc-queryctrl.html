7.49. ioctls VIDIOC_QUERYCTRL、VIDIOC_QUERY_EXT_CTRL および VIDIOC_QUERYMENU¶

7.49.1. 名前¶

VIDIOC_QUERYCTRL - VIDIOC_QUERY_EXT_CTRL - VIDIOC_QUERYMENU - コントロールとメニュー コントロール項目を列挙する

7.49.2. 概要¶

int ioctl(int fd, int VIDIOC_QUERYCTRL, struct v4l2_queryctrl *argp)

VIDIOC_QUERY_EXT_CTRL¶

int ioctl(int fd, VIDIOC_QUERY_EXT_CTRL, struct v4l2_query_ext_ctrl *argp)

VIDIOC_QUERYMENU¶

コントロール フラグ¶

V4L2_CTRL_FLAG_DISABLED

0x0001

このコントロールは永久的に無効化されており、アプリケーションは無視する必要があります。コントロールの値を変更する試みは、 EINVAL エラー コードに設定します。

V4L2_CTRL_FLAG_GRABBED

0x0002

このコントロールは一時的に変更不可能です。たとえば他のアプリケーションがリソースの制御を取得したためです。このようなコントロールはユーザーインターフェースで特別に表示されることがあります。コントロールの値を変更する試みは、 EBUSY エラー コードに設定します。

V4L2_CTRL_FLAG_READ_ONLY

0x0004

このコントロールは永久的に読み取り専用です。コントロールの値を変更する試みは、 EINVAL エラー コードに設定します。

V4L2_CTRL_FLAG_UPDATE

0x0008

このコントロールの値を変更すると、同じコントロールクラス内の他のコントロールの値に影響を与える可能性があるというヒントです。アプリケーションはユーザーインターフェースを適切に更新する必要があります。

V4L2_CTRL_FLAG_INACTIVE

0x0010

このコントロールは現在の設定には適用されず、ユーザーインターフェースで適切に表示する必要があります。たとえば、MPEGオーディオレベル1が別のコントロールで選択された場合、MPEGオーディオレベル2ビットレートコントロールにフラグが設定されることがあります。

V4L2_CTRL_FLAG_SLIDER

0x0020

このコントロールはユーザーインターフェースでスライダーのような要素として表示するのが最適ですというヒントです。

V4L2_CTRL_FLAG_WRITE_ONLY

0x0040

V4L2_CTRL_FLAG_VOLATILE

0x0080

このコントロールは一時的な値であり、コントロールの値は連続的に変化します。典型的な例は、デバイスがオートゲインモードにある場合の現在のゲイン値です。このような場合、ハードウェアは照明条件に基づいてゲイン値を計算しますが、時間とともに変化する可能性があります。

注意

不揮発性の制御の新しい値を設定しても無視されるのは、 V4L2_CTRL_FLAG_EXECUTE_ON_WRITE が同時に設定されていない場合です。不揮発性の制御の新しい値を設定すると、 更新処理が完了した後でも新しい読者が即座に開始する可能性があるため、以下のコードは読者がいないと信頼してはならない。 イベントが発生します。 V4L2_EVENT_CTRL_CH_VALUE イベント。

0x0200
