2.7. YUV形式¶

YUVはテレビ放送および合成ビデオ信号の本質的なフォーマットです。このフォーマットは明るさ情報（Y）と色情報（UおよびVまたはCbおよびCr）を分離します。色情報は赤と青の色差信号から構成され、このようにして緑成分は明るさ成分から減算することで再構成できます。参照 色差 信号により、緑成分は明るさ成分から減算することで再構成できます。変換例については カラースペース をご参照ください。YUVが選ばれた理由は、早期のテレビ放送が明るさ情報のみを送信していたためです。既存の受信機と互換性を保ちながら色を追加するため、新たな信号キャリアが追加され色差信号を送信するようになりました。YUVフォーマットでは、UおよびV成分は通常Y成分よりも低い解像度を持ちます。これは人間の視覚システムが明るさ情報により敏感であるという特性を活用したアナログビデオ圧縮技術です。
