1.15. コードックコントロールリファレンス¶

コントロールクラス内のすべてのコントロールについて説明します。まず一般的なコントロール、次に特定のハードウェア用のコントロールを説明します。

注意

これらのコントロールはすべてのコーデックに適用でき、MPEGに限ったものではありません。これらの定義はV4L2_CID_MPEG/V4L2_MPEGでプレフィックスが付けられており、元々はMPEGコーデック用に作成され、その後すべてのエンコーディング形式をカバーするように拡張されました。

1.15.2. MFC 5.1 MPEGコントロール¶

以下のMPEGクラスコントロールは、SamsungのS5PファミリSoCに搭載されたマルチフォーマットコーデック5.1デバイスに特有のMPEGデコードおよびエンコード設定を扱います。

1.15.2.1. MFC 5.1 コントロールID¶

V4L2_CID_MPEG_MFC51_VIDEO_DECODER_H264_DISPLAY_DELAY_ENABLE (boolean)

表示遅延が有効化されている場合、デコーダーは特定の数のOUTPUTバッファを処理した後にCAPTUREバッファ（デコード済みフレーム）を返さなければなりません。この遅延は V4L2_CID_MPEG_MFC51_VIDEO_DECODER_H264_DISPLAY_DELAYこの機能は、たとえば動画のサムネイル生成などに使用できます。H264デコーダーに適用されます。

注意

このコントロールは非推奨です。標準 V4L2_CID_MPEG_VIDEO_DEC_DISPLAY_DELAY_ENABLE 代わりに使用してください。

V4L2_CID_MPEG_MFC51_VIDEO_DECODER_H264_DISPLAY_DELAY (integer)

V4L2_CID_MPEG_VIDEO_HEVC_DECODE_MODE (enum)

使用するデコードモードを指定します。現在はスライスベースとフレームベースのデコードが公開されていますが、今後新たなモードが追加される可能性があります。この制御はV4L2_PIX_FMT_HEVC_SLICEピクセル形式のmodifierとして使用され、V4L2_PIX_FMT_HEVC_SLICEをサポートするアプリケーションは、バッファに期待されるデコードモードを指定するためにこの制御を設定する必要があります。ドライバはサポート可能な機能に応じて単一または複数のデコードモードを公開することがあります。

注意

type v4l2_mpeg_video_hevc_start_code¶

V4L2_MPEG_VIDEO_HEVC_START_CODE_NONE

0

この値を選択すると、HEVCスライスは開始コードなしでドライバに渡されます。

V4L2_MPEG_VIDEO_HEVC_START_CODE_ANNEX_B

1

この値を選択すると、HEVCスライスはAnnex B開始コードで前処理されることが期待されます。参照 ITU H.265/HEVC 有効な開始コードは、3バイトの0x000001または4バイトの0x00000001です。
V4L2_CID_MPEG_VIDEO_BASELAYER_PRIORITY_ID (integer)

NALユニットの優先識別子を指定し、これによりベースレイヤーに適用されます。デフォルトではベースレイヤーにこの値が0に設定され、次のレイヤーには1、2、3などと優先IDが割り当てられます。ビデオエンコーダーはレイヤーに適用される優先IDを決定できないため、クライアントから提供する必要があります。これはH264に適用され、有効範囲は0〜63です。ソース Rec. ITU-T H.264 (06/2019); G.7.4.1.1, G.8.8.1。

V4L2_CID_MPEG_VIDEO_LTR_COUNT (integer)

エンコーダーが同時に保持できる最大の長期参照（LTR）フレーム数を指定します。これはH264およびHEVCエンコーダーに適用されます。

V4L2_CID_MPEG_VIDEO_FRAME_LTR_INDEX (integer)

この制御を設定した後、次のキューイングされるフレームは長期参照（LTR）フレームとしてマークされ、LTRインデックス（0〜LTR_COUNT-1の範囲）が割り当てられます。これはH264およびHEVCエンコーダーに適用されます。ソース Rec. ITU-T H.264 (06/2019); Table 7.9

V4L2_CID_MPEG_VIDEO_USE_LTR_FRAMES (bitmask)

次のフレームを符号化する際に使用するLong Term Reference (LTR)フレーム（複数可）を指定します。これは、ビット[0, LTR_COUNT-1]からなるビットマスクを提供し、H264およびHEVCエンコーダーに適用されます。
