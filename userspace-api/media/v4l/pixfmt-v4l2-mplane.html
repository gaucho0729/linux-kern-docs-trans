2.2. マルチプレナールフォーマット構造¶

構造体 v4l2_plane_pix_format 構造体は、マルチプレーン形式の各プレーンのサイズとレイアウトを定義します。struct v4l2_pix_format_mplane 構造体は、すべてのプレーンに共通する情報（画像の幅や高さなど）を含み、struct の配列を含みます v4l2_plane_pix_format 構造体で、その形式のすべてのプレーンを記述します。

type v4l2_plane_pix_format¶
struct v4l2_plane_pix_format¶

__u32

sizeimage

このプレーンの画像データに必要な最大バイト数で、ドライバーが設定します。画像が可変長圧縮データで構成されている場合、これはコーデックが最悪の圧縮シナリオをサポートするために必要なバイト数です。

ドライバーが非圧縮画像の値を設定します。

可変長圧縮データでフラグが設定されている場合、クライアントは sizeimage フィールドを設定できます V4L2_FMT_FLAG_COMPRESSED に ioctl VIDIOC_ENUM_FMTただし、ドライバーはこれを無視して自身で値を設定するか、アライメント要件や最小/最大サイズ要件に基づいて提供された値を変更する可能性があります。クライアントがドライバーに任せる場合は、sizeimage を 0 に設定する必要があります。

__u32

bytesperline

隣接する2行の左端ピクセル間のバイト距離です。struct を参照してください v4l2_pix_format.

reserved[6]
