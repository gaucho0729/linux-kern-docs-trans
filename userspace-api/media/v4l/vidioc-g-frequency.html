7.32. ioctl VIDIOC_G_FREQUENCY, VIDIOC_S_FREQUENCY¶

7.32.1. 名前¶

VIDIOC_G_FREQUENCY - VIDIOC_S_FREQUENCY - チューナーやモデュレータのラジオ周波数を取得または設定します

7.32.2. 概要¶

VIDIOC_G_FREQUENCY¶

int ioctl(int fd, VIDIOC_G_FREQUENCY, struct v4l2_frequency *argp)

VIDIOC_S_FREQUENCY¶

int ioctl(int fd, VIDIOC_S_FREQUENCY, const struct v4l2_frequency *argp)

7.32.3. 引数¶

fd

返されるファイル記述子 open().

argp

struct mem_ctl_info v4l2_frequency.

7.32.4. 説明¶

現在のチューナーやモデュレータのラジオ周波数を取得するには、アプリケーションは tuner フィールドを設定します。 v4l2_frequency それぞれのチューナーやモデュレータ番号（入力デバイスにはチューナーが、出力デバイスにはモデュレータが存在します）を設定し、配列をゼロに初期化し、この構造体へのポインタを用いてioctlを呼び出します。ドライバが現在の周波数をこの構造体のフィールドに保存します reserved 現在のチューナーやモデュレータのラジオ周波数を変更するには、アプリケーションはこの構造体を初期化し VIDIOC_G_FREQUENCY 配列をゼロに初期化し、この構造体へのポインタを用いてioctlを呼び出します。ドライバが現在の周波数をこの構造体のフィールドに保存します frequency フィールドによって保護されています。

現在のチューナーやモデュレータのラジオ周波数を変更するには、アプリケーションはこの構造体を初期化し tuner, type および frequency フィールドを初期化し、 reserved 配列をゼロにします。 v4l2_frequency を初期化し、 VIDIOC_S_FREQUENCY この構造体へのポインタを用いたioctl。要求された周波数が実現不可能な場合、ドライバは最も近い可能な値を採用する。ただし VIDIOC_S_FREQUENCY これは書き込み専用のioctlであり、実際の新しい周波数を返却しない。

type v4l2_frequency¶
struct v4l2_frequency¶

__u32

tuner

チューナーまたはモデュレータのインデックス番号。これは構造体 v4l2_input tuner のフィールドおよび構造体 v4l2_tuner index のフィールド、または構造体 v4l2_output modulator のフィールドおよび構造体 v4l2_modulator index フィールドによって保護されています。

__u32

type

のフィールドです。タイプは v4l2_tuner type に設定する必要があります。 V4L2_TUNER_RADIO のために、 /dev/radioX デバイスノード、および V4L2_TUNER_ANALOG_TV すべての他の場合。このフィールドを V4L2_TUNER_RADIO モデュレータに設定してください（現在はラジオモデュレータのみがサポートされています）。参照 v4l2_tuner_type

__u32

frequency

チューニング周波数は62.5 kHz単位で指定し、構造体が設定されている場合は62.5 Hz単位で指定する。インデックスが範囲外であるか、構造体の値が v4l2_tuner またはstruct v4l2_modulator capability フラグ V4L2_TUNER_CAP_LOW 1 Hz単位が使用される。ハードウェアのシークが進行中です。 capability フラグ V4L2_TUNER_CAP_1HZ が設定される前。

__u32

reserved[8]

Reserved for future extensions. Drivers and applications must set the array to zero.

7.32.5. 戻り値¶

成功した場合、0 が返されます。エラーの場合、-1 が返され、変数が適切に設定されます。 errno 一般的なエラーコードは、 汎用エラーコード 章。

EINVAL

以下の tuner index is out of bounds or the value in the type フィールドが正しくありません。

EBUSY

A hardware seek is in progress.
