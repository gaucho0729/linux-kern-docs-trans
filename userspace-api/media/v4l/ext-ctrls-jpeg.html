1.16. JPEG制御参照¶

JPEGクラスには、JPEGエンコーダーおよびデコーダーの一般的な機能に対する制御が含まれています。現在は、プログレッシブベースラインDCT圧縮プロセスを実装するコーデック向けの機能が含まれています。

1.16.1. JPEG Control IDs¶

V4L2_CID_JPEG_CLASS (class)

JPEGクラスの記述。呼び出し ioctls VIDIOC_QUERYCTRL、VIDIOC_QUERY_EXT_CTRL および VIDIOC_QUERYMENU この制御クラスの説明が返されます。

V4L2_CID_JPEG_CHROMA_SUBSAMPLING (menu)

クロマサブサンプリングファクターは、入力画像の各コンポーネントが空間次元ごとの最大サンプリングレートに対してどのようにサンプリングされるかを記述します。詳しくは ITU-T.81, A.1.1節をご参照ください。この V4L2_CID_JPEG_CHROMA_SUBSAMPLING 制御は、RGBからY’CbCr色空間へ変換した入力画像のCbおよびCrコンポーネントがどのようにダウンサンプリングされるかを決定します。

V4L2_JPEG_CHROMA_SUBSAMPLING_444

クロマサブサンプリングを行わず、各ピクセルにY、Cr、Cbの値があります。

V4L2_JPEG_CHROMA_SUBSAMPLING_422

Cr、Cbコンポーネントを水平方向に2倍のファクターでサブサンプリングします。

V4L2_JPEG_CHROMA_SUBSAMPLING_420

Cr、Cbコンポーネントを水平方向および垂直方向に2倍のファクターでサブサンプリングします。

V4L2_JPEG_CHROMA_SUBSAMPLING_411

Cr、Cbコンポーネントを水平方向に4倍のファクターでサブサンプリングします。

V4L2_JPEG_CHROMA_SUBSAMPLING_410

Cr、Cbコンポーネントを水平方向に4倍、垂直方向に2倍のファクターでサブサンプリングします。

V4L2_JPEG_CHROMA_SUBSAMPLING_GRAY

輝度コンポーネントのみを使用します。
V4L2_CID_JPEG_RESTART_INTERVAL (integer)

再開間隔はRSTmマーカー（m = 0..7）を挿入する間隔を決定します。これらのマーカーは、画像のブロックを独立して処理するため、エンコーダーのプロセスを再初期化する目的があります。損失のある圧縮プロセスでは、再開間隔の単位はMCU（Minimum Coded Unit）であり、その値はDRI（Define Restart Interval）マーカーに含まれます。もし V4L2_CID_JPEG_RESTART_INTERVAL 制御が0に設定されると、DRIおよびRSTmマーカーが挿入されません。

V4L2_CID_JPEG_COMPRESSION_QUALITY (integer)

V4L2_CID_JPEG_COMPRESSION_QUALITY 制御は画像品質とサイズのトレードオフを決定します。アプリケーションが輝度およびクロマの量子化テーブルを直接再構成することなく、画像品質を制御するための簡易な方法を提供します。ドライバがアプリケーションが直接設定した量子化テーブルを使用する場合、インターフェースは他の場所で定義されており、 V4L2_CID_JPEG_COMPRESSION_QUALITY 制御をドライバが0に設定する必要があります。

この制御の値範囲はドライバ固有です。意味のある値は正の非ゼロ値のみです。推奨範囲は1〜100で、値が大きいほど画像品質が向上します。

V4L2_CID_JPEG_ACTIVE_MARKER (bitmask)

圧縮ストリームに含まれるJPEGマーカーを指定します。この制御はエンコーダー専用です。

V4L2_JPEG_ACTIVE_MARKER_APP0

アプリケーションデータセグメント APP0.

V4L2_JPEG_ACTIVE_MARKER_APP1

アプリケーションデータセグメント APP1.

V4L2_JPEG_ACTIVE_MARKER_COM

コメントセグメント。

V4L2_JPEG_ACTIVE_MARKER_DQT

量子化テーブルセグメント。

V4L2_JPEG_ACTIVE_MARKER_DHT

ハフマンテーブルセグメント。

JPEG仕様の詳細については ITU-T.81, JFIF, W3C JPEG JFIF.
