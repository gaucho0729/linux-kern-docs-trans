1.14. 画像処理制御参照¶

画像処理制御クラスは、画像処理機能の低レベル制御を目的としています。このクラスの制御は、画像の処理に影響を与えるものの、画像のキャプチャには関与しません。 V4L2_CID_IMAGE_SOURCE_CLASSデータバス周波数。メディアバスピクセルコード、バスタイプ（サンプルごとのクロックサイクル）、データバス周波数は、ピクセル配列（または、デバイスが画像センサーでない場合の他の場所）におけるピクセルレート（

1.14.1. 画像処理制御ID¶

V4L2_CID_IMAGE_PROC_CLASS (class)

IMAGE_PROC クラス記述子。

V4L2_CID_LINK_FREQ (integer menu)

データバス周波数。メディアバスピクセルコード、バスタイプ（サンプルごとのクロックサイクル）、データバス周波数は、ピクセル配列（または、デバイスが画像センサーでない場合の他の場所）におけるピクセルレート（V4L2_CID_PIXEL_RATE)を定義します。フレームレートは、ピクセルクロック、画像幅・高さ、水平および垂直ブランクから計算できます。ピクセルレート制御は、ピクセル配列を含むサブデバイス以外の場所でも定義される可能性がありますが、フレームレートはその情報から得られません。これは、垂直および水平ブランク情報がピクセル配列においてのみ正確とみなせるためです。ピクセル配列では他のブランクは許容されません。フレームレートの選択は、望ましい水平および垂直ブランクを選択することで行われます。この制御の単位はHzです。

V4L2_CID_PIXEL_RATE (64-bit integer)

サブデバイスのソースパッドにおけるピクセルレート。この制御は読み取り専用であり、単位はピクセル/秒です。

V4L2_CID_TEST_PATTERN (menu)

一部のキャプチャ/ディスプレイ/センサー機器は、テストパターン画像を生成する機能を持っています。これらのハードウェア固有のテストパターンは、機器が正常に動作しているかをテストするために使用できます。

V4L2_CID_DEINTERLACING_MODE (menu)

ビデオデインターレースモード（例：Bob、Weave、…）。メニュー項目はドライバ固有であり、ドキュメンテーションに記載されています。 Video4Linux (V4L) ドライバ固有のドキュメンテーション.

V4L2_CID_DIGITAL_GAIN (integer)

デジタルゲインは、すべてのカラーコンポーネントに掛かる値です。通常、デジタルゲインは制御値を例えば0x100で割った値として適用されます。つまり、デジタルゲインをゼロにするには制御値を0x100に設定する必要があります。ノーゲイン設定は通常デフォルトです。
