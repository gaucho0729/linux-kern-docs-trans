2.11.7. V4L2_SDR_FMT_PCU18BE (‘PC18’)¶

ビッグエンディアンの複素数符号なし18ビットIQサンプル

2.11.7.1. 説明¶

このフォーマットは複素数のサンプルを連続して格納しています。各複素数はIn-phase（I）とQuadrature（Q）の2つの部分から構成され、IとQはともに18ビットの符号なしビッグエンディアン数として32ビット空間に格納されます。32ビット空間内に未使用のビットがある場合は0で埋められます。I値は先頭から開始し、Q値はバッファサイズの半分に相当するオフセット位置から開始します（つまり、オフセット = バッファサイズ/2）。18ビットのうち、ビット17:2（16ビット）がデータで、ビット1:0（2ビット）は任意の値を取ることができます。

バイト順序。 各セルは1バイトです。

オフセット:

Byte B0

Byte B1

Byte B2

Byte B3

start + 0:

I’0[17:10]

I’0[9:2]

I’0[1:0]; B2[5:0]=pad

パッド

start + 4:

I’1[17:10]

I’1[9:2]

I’1[1:0]; B2[5:0]=pad

パッド

…

開始位置 + オフセット:

Q’0[17:10]

Q’0[9:2]

Q’0[1:0]; B2[5:0]=pad

パッド

開始位置 + オフセット + 4:

Q’1[17:10]

Q’1[9:2]

Q’1[1:0]; B2[5:0]=pad

パッド
