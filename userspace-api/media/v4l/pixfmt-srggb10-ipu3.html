2.6.1.6. V4L2_PIX_FMT_IPU3_SBGGR10 (‘ip3b’), V4L2_PIX_FMT_IPU3_SGBRG10 (‘ip3g’), V4L2_PIX_FMT_IPU3_SGRBG10 (‘ip3G’), V4L2_PIX_FMT_IPU3_SRGGB10 (‘ip3r’)¶

10ビットバヤー形式

2.6.1.6.1. 説明¶

これら4つのピクセル形式はIntel IPU3ドライバで使用され、10ビット毎のサンプルを持つraw sRGB/バヤー形式です。25ピクセルを32バイトにパッケージングし、最後のバイトに6ビットのパディングを残します。形式はリトルエンディアンです。

他の点では、この形式は以下のように似ています V4L2_PIX_FMT_SRGGB10 (‘RG10’), V4L2_PIX_FMT_SGRBG10 (‘BA10’), V4L2_PIX_FMT_SGBRG10 (‘GB10’), V4L2_PIX_FMT_SBGGR10 (‘BG10’),。以下はV4L2_PIX_FMT_IPU3_SBGGR10形式の小さな画像の例です。
