V4L2_PIX_FMT_S5C_UYVY_JPG

‘S5CI’

サムスンS5C73MXカメラで使用される2平面形式。最初の平面にはJPEGとUYVY画像データが交互に配置され、メタデータとしてUYVYデータブロックへのオフセット配列が続く。実際のポインタ配列は交互に配置されたJPEG/UYVYデータの直後に即座に続く。この配列のエントリ数はUYVY画像の高さに等しい。各エントリはビッグエンディアン順の4バイトの符号なし整数であり、UYVY画像の単一ピクセルラインへのオフセットを示す。最初の平面はJPEGデータまたはUYVYデータチャンクで開始することができる。単一のUYVYブロックのサイズはUYVY画像の幅を2倍した値に等しい。JPEGチャンクのサイズは画像に依存し、各行で変化する可能性がある。

2番目の平面は4084バイトのオフセット位置にあり、1番目の平面のポインタ配列への4バイトのオフセットを含む。このオフセットの後には、ポインタ配列のサイズを示す4バイトの値が続く。2番目の平面のすべての数値もビッグエンディアン順で表される。2番目の平面の残りのデータは未定義である。2番目の平面の情報により、ポインタ配列の位置を簡単に特定できる。この位置は各フレームごとに異なる可能性がある。ポインタ配列のサイズは、与えられたUYVY画像の高さに対して一定である。

UYVYおよびJPEGフレームを抽出するには、アプリケーションが最初に1番目の平面の開始位置をデータポインタに設定し、その後ポインタテーブルの最初のエントリからのオフセットを加算する。このようなポインタはUYVY画像ピクセルラインの開始位置を示す。全体のUYVYラインは別個のバッファにコピーできる。これらのステップはポインタ配列のエントリ数分繰り返す必要がある。UYVYラインの間に存在するデータはJPEGデータであり、JPEGストリームを形成するために連結する必要がある。

V4L2_PIX_FMT_MT21C

‘MT21’

MediaTek MT8173で使用される圧縮された2平面YVU420形式。圧縮は無圧縮である。これはオパケな中間形式であり、MDPハードウェアを使用して変換する必要がある V4L2_PIX_FMT_MT21C に（木の下から葉に向かって） V4L2_PIX_FMT_NV12M, V4L2_PIX_FMT_YUV420M または V4L2_PIX_FMT_YVU420.

V4L2_PIX_FMT_SUNXI_TILED_NV12

‘ST12’

全志（sunxi）プラットフォームに搭載されたビデオエンジンで使用される、2プランナーNV12ベースの形式。輝度平面には32x32タイル、色度平面には32x64タイルが使用され、各タイル内のデータはタイルの境界内で線形順に保存されます。メモリ内では左から右、上から下に線形に続きます。

関連するバッファの寸法は整数倍のタイル数に合わせて整列しており、輝度平面には32倍の解像度、色度平面には16倍の解像度（2x2サブサンプリング）が採用されています。
