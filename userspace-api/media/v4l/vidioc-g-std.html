7.41. ioctl VIDIOC_G_STD, VIDIOC_S_STD, VIDIOC_SUBDEV_G_STD, VIDIOC_SUBDEV_S_STD¶

7.41.1. 名前¶

VIDIOC_G_STD - VIDIOC_S_STD - VIDIOC_SUBDEV_G_STD - VIDIOC_SUBDEV_S_STD - 現在の入力のビデオ標準を照会または選択します

7.41.2. 概要¶

VIDIOC_G_STD¶

int ioctl(int fd, VIDIOC_G_STD, v4l2_std_id *argp)

VIDIOC_S_STD¶

int ioctl(int fd, VIDIOC_S_STD, const v4l2_std_id *argp)

VIDIOC_SUBDEV_G_STD¶

int ioctl(int fd, VIDIOC_SUBDEV_G_STD, v4l2_std_id *argp)

VIDIOC_SUBDEV_S_STD¶

int ioctl(int fd, VIDIOC_SUBDEV_S_STD, const v4l2_std_id *argp)

7.41.3. 引数¶

fd

返されるファイル記述子 open().

argp

ポインタ先 v4l2_std_id.

7.41.4. 説明¶

現在のビデオ標準を照会および選択するには、アプリケーションは以下の ioctls を使用します VIDIOC_G_STD および VIDIOC_S_STD ioctls は、ポインタを引数として受け取ります v4l2_std_id type を引数として受け取ります VIDIOC_G_STD struct に記載されているように、1 つのフラグまたは複数のフラグを返すことができます v4l2_standard フィールド idフラグは、1 つの列挙型 struct にのみ出現するように明確でなければなりません v4l2_standard 何らかの理由で、木構造を配列形状ではなく木形状で描くと、平面的な表現を簡単に描くことができます:

VIDIOC_S_STD 1 つまたは複数のフラグを受け取り、書き込み専用 ioctls であるため、実際に新しい標準を返しません VIDIOC_G_STD does. フラグが指定されていない場合、または現在の入力が要求された標準をサポートしていない場合、ドライバーはエラー コードを返します EINVAL エラー コードを返します。標準のセットが曖昧な場合、ドライバーは EINVAL 任意の要求された標準を返すか、選択します。現在の入力または出力が標準のビデオタイミングをサポートしない場合（例: if ioctl VIDIOC_ENUMINPUT が V4L2_IN_CAP_STD フラグを設定していない場合）、 ENODATA error code is returned.

呼び出し VIDIOC_SUBDEV_S_STD 読み取り専用モードで登録されたサブデバイスのioctlは許可されません。エラーが返され、errno変数が -EPERM.

7.41.5. 戻り値¶

成功した場合、0 が返されます。エラーの場合、-1 が返され、変数が適切に設定されます。 errno 一般的なエラーコードは、 汎用エラーコード 章。

EINVAL

以下の VIDIOC_S_STD パラメータが不適切です。

ENODATA

この入力または出力では、標準的な映像タイミングがサポートされていません。

EPERM

VIDIOC_SUBDEV_S_STD 読み取り専用サブデバイスでioctlが呼び出されました。
