4.10. ソフトウェア定義ラジオインターフェース（SDR）¶

SDR は、アプリケーションソフトウェアを用いて変調または変復調を行うラジオ機器を指し、このインターフェースはそのような機器の制御およびデータストリーミングを目的としています。

SDR 機器は、主装置番号 81 で名前が付けられたキャラクタデバイス専用ファイルを通じてアクセスされます /dev/swradio0 に（木の下から葉に向かって） /dev/swradio255 、動的に割り当てられたサブ装置番号 0 から 255 までの範囲で使用されます。

4.10.1. キャパビリティの照会¶

SDR 受信機インターフェースをサポートする機器は、 V4L2_CAP_SDR_CAPTURE および V4L2_CAP_TUNER フラグを含めます。以下のようにします： capabilities 構造体の v4l2_capability は ioctl VIDIOC_QUERYCAP ioctl を設定します。このフラグは、機器にアナログからデジタルへの変換器 (ADC) が搭載されていることを意味し、SDR 受信機では必須要素です。

SDR 送信機インターフェースをサポートする機器は、 V4L2_CAP_SDR_OUTPUT および V4L2_CAP_MODULATOR フラグを含めます。以下のようにします： capabilities 構造体の v4l2_capability は ioctl VIDIOC_QUERYCAP ioctl を設定します。このフラグは、機器にデジタルからアナログへの変換器 (DAC) が搭載されていることを意味し、SDR 送信機では必須要素です。

読み取り/書き込み、ストリーミング、または非同期 I/O のいずれか少なくとも 1 つの方法をサポートする必要があります。

4.10.2. 補助機能¶

SDR 機器は、 controls、およびサポートしなければならない チューナーとモジュレータ ioctl をサポートする場合があります。チューナー ioctls は、ADC/DAC のサンプリングレート (サンプリング周波数) および可能な無線周波数 (RF) を設定するために使用されます。

以下の V4L2_TUNER_SDR チューナーの種類は SDR 機器の ADC/DAC 周波数を設定するために使用され、 V4L2_TUNER_RF チューナーの種類は無線周波数を設定するために使用されます。RF チューナー (存在する場合) のチューナーインデックスは常に SDR チューナーインデックスの後に続きます。通常、SDR チューナーは #0 で、RF チューナーは #1 です。

以下の ioctl VIDIOC_S_HW_FREQ_SEEK ioctl はサポートされていません。

4.10.3. データフォーマットのネゴシエーション¶

SDR 機器は、 データフォーマット ioctl を使用してキャプチャおよび出力形式を選択します。サンプリング分解能およびデータストリーミング形式は、選択可能な形式にバインドされています。さらに、基本的な データフォーマット ioctlに加えて、 ioctl VIDIOC_ENUM_FMT ioctlもサポートされている必要があります。

この データフォーマット ioctlを使用するには、アプリケーションは type フィールドを設定します。 v4l2_format に（木の下から葉に向かって） V4L2_BUF_TYPE_SDR_CAPTURE または V4L2_BUF_TYPE_SDR_OUTPUT および必要な操作に応じて struct v4l2_sdr_format sdr 構造体の fmt union を使用します。現在、struct のフィールドは pixelformat および buffersize、 v4l2_sdr_format が使用されています。の内容はデータ形式の V4L2 FourCC コードです。のフィールドはデータ転送に必要な最大バッファサイズ（バイト単位）で、ドライバがアプリケーションに情報を伝達するために設定します。 pixelformat v4l2_sdr_format buffersize struct v4l2_sdr_format
