1.7. ビデオ標準¶

ビデオデバイスは通常、1つ以上の異なるビデオ標準またはその変種をサポートします。各ビデオ入力および出力は、別の標準セットをサポートする場合があります。このセットは、 std 構造体の v4l2_input および struct v4l2_output は ioctl VIDIOC_ENUMINPUT および ioctl VIDIOC_ENUMOUTPUT ioctlsを用いて報告されます。

V4L2は、世界中で現在使用されているアナログビデオ標準ごとに1ビットを定義し、ドライバで定義された標準用のビットを確保しています。例えば、NTSCビデオテープをPALテレビで視聴するハイブリッド標準や、逆も然りです。アプリケーションは、事前に定義されたビットを使用して特定の標準を選択できますが、ユーザーにサポートされている標準のメニューを提示することが推奨されます。サポートされている標準の属性を列挙し、照会するには、アプリケーションは にリネームされました。コードAPIの初稿がリリースされました。 ioctl.

定義された標準の多くは、少数の主要な標準の変種にすぎません。ハードウェアは実際にはそれらを区別しない場合があり、内部で区別して自動的に切り替える場合もあります。したがって、列挙された標準にも、1つ以上の標準ビットを含むセットが含まれます。

仮想のチューナーを想定します。これはB/PAL、G/PAL、I/PAL信号を復調できるものとします。最初の列挙された標準は、選択されたUHFまたはVHF帯域のラジオ周波数に応じて自動的に切り替わるBとG/PALのセットです。列挙によって「PAL-B/G」または「PAL-I」の選択肢が得られます。同様に、コンポジット入力は標準を統合し、「PAL-B/G/H/I」、「NTSC-M」、「SECAM-D/K」を列挙します。 1

現在のビデオ入力または出力で使用されている標準を照会し、選択するには、アプリケーションは VIDIOC_G_STD および VIDIOC_S_STD ioctlを呼び出します。それぞれの received 標準は ioctlが ioctl.

注意

すべてのこれらのioctlのパラメータは、 v4l2_std_id 型（標準セット）へのポインタです。 ではありません 標準列挙へのインデックスです。デバイスに1つ以上のビデオ入力または出力がある場合、ドライバはすべてのビデオ標準ioctlを実装しなければなりません。

USBカメラなどのデバイスでは、ビデオ標準という概念はあまり意味を持たないため、特別なルールが適用されます。より一般的に、キャプチャまたは出力デバイスで次の条件を満たす場合:

  • ビデオ標準の名義上のレートでフィールドまたはフレームをキャプチャできない、または

  • ビデオ標準フォーマットをまったくサポートしない場合です。

ここではドライバは std 構造体の v4l2_input および struct v4l2_output ゼロに設定し、 VIDIOC_G_STD, VIDIOC_S_STD, ioctlが および にリネームされました。コードAPIの初稿がリリースされました。 ioctlは ENOTTY エラー コードまたは EINVAL エラー コードに設定します。

アプリケーションは以下の 入力機能 および 出力機能 フラグを用いて、指定された入力または出力でビデオ標準ioctlが使用可能かどうかを判断します。

1.7.1. 例: 現在のビデオ標準に関する情報¶

v4l2_std_id std_id;
struct v4l2_standard standard;

if (-1 == ioctl(fd, VIDIOC_G_STD, &std_id)) {
    /* Note when VIDIOC_ENUMSTD always returns ENOTTY this
       is no video device or it falls under the USB exception,
       and VIDIOC_G_STD returning ENOTTY is no error. */

    perror("VIDIOC_G_STD");
    exit(EXIT_FAILURE);
}

memset(&standard, 0, sizeof(standard));
standard.index = 0;

while (0 == ioctl(fd, VIDIOC_ENUMSTD, &standard)) {
    if (standard.id & std_id) {
           printf("Current video standard: %s\\n", standard.name);
           exit(EXIT_SUCCESS);
    }

    standard.index++;
}

/* EINVAL indicates the end of the enumeration, which cannot be
   empty unless this device falls under the USB exception. */

if (errno == EINVAL || standard.index == 0) {
    perror("VIDIOC_ENUMSTD");
    exit(EXIT_FAILURE);
}

1.7.2. 例: 現在の入力でサポートされているビデオ標準の一覧¶

struct v4l2_input input;
struct v4l2_standard standard;

memset(&input, 0, sizeof(input));

if (-1 == ioctl(fd, VIDIOC_G_INPUT, &input.index)) {
    perror("VIDIOC_G_INPUT");
    exit(EXIT_FAILURE);
}

if (-1 == ioctl(fd, VIDIOC_ENUMINPUT, &input)) {
    perror("VIDIOC_ENUM_INPUT");
    exit(EXIT_FAILURE);
}

printf("Current input %s supports:\\n", input.name);

memset(&standard, 0, sizeof(standard));
standard.index = 0;

while (0 == ioctl(fd, VIDIOC_ENUMSTD, &standard)) {
    if (standard.id & input.std)
        printf("%s\\n", standard.name);

    standard.index++;
}

/* EINVAL indicates the end of the enumeration, which cannot be
   empty unless this device falls under the USB exception. */

if (errno != EINVAL || standard.index == 0) {
    perror("VIDIOC_ENUMSTD");
    exit(EXIT_FAILURE);
}

1.7.3. 例: 新しいビデオ標準の選択¶

struct v4l2_input input;
v4l2_std_id std_id;

memset(&input, 0, sizeof(input));

if (-1 == ioctl(fd, VIDIOC_G_INPUT, &input.index)) {
    perror("VIDIOC_G_INPUT");
    exit(EXIT_FAILURE);
}

if (-1 == ioctl(fd, VIDIOC_ENUMINPUT, &input)) {
    perror("VIDIOC_ENUM_INPUT");
    exit(EXIT_FAILURE);
}

if (0 == (input.std & V4L2_STD_PAL_BG)) {
    fprintf(stderr, "Oops. B/G PAL is not supported.\\n");
    exit(EXIT_FAILURE);
}

/* Note this is also supposed to work when only B
   or G/PAL is supported. */

std_id = V4L2_STD_PAL_BG;

if (-1 == ioctl(fd, VIDIOC_S_STD, &std_id)) {
    perror("VIDIOC_S_STD");
    exit(EXIT_FAILURE);
}
