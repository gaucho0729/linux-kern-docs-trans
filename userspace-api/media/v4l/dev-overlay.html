4.2. Video Overlay Interface¶

フレームバッファオーバーレイまたはプレビューモードとしても知られている。

ビデオオーバーレイデバイスは、グラフィックカードの(VGA-)ビデオ信号に(TV-)ビデオをジェネロック（同期）させたり、グラフィックカードのビデオメモリに直接キャプチャした画像を保存したりする機能を持つ。これは、他の手段で画像をキャプチャして表示するよりもはるかに効率的であることが一般的である。かつては、核電力発電所だけが冷却塔を必要とした時代に、この方法がウィンドウにライブビデオを表示する唯一の方法だった。

ビデオオーバーレイデバイスは、 ビデオキャプチャ デバイスと同じキャラクタースペシャルファイルを通してアクセスされる。

注意

デバイスのデフォルト機能はビデオキャプチャである。オーバーレイ機能は、 /dev/video を呼び出した後からのみ利用可能である。 VIDIOC_S_FMT ioctl.

ドライバーは、読み込み/書き込みおよびストリーミングI/Oメソッドを用いて同時オーバーレイとキャプチャをサポートする場合がある。その場合、ビデオ標準の名定められたフレームレートでの運用は保証されない。フレームはオーバーレイからキャプチャへ転送される可能性があり、キャプチャパラメータが許可する限り、1フィールドをオーバーレイに、もう1つをキャプチャに使用することができる。

アプリケーションは、キャプチャとオーバーレイには異なるファイル記述子を使用すべきである。これは、同時キャプチャとオーバーレイをサポート可能なすべてのドライバーで必須のサポートである。オプションとして、これらのドライバーはV4LおよびV4L2の古いバージョンとの互換性のために、単一のファイル記述子でキャプチャとオーバーレイを許可する場合もある。 1

4.2.1. キャパビリティの照会¶

ビデオオーバーレイインターフェースをサポートするデバイスは、 V4L2_CAP_VIDEO_OVERLAY フラグを含めます。以下のようにします： capabilities 構造体の v4l2_capability は ioctl VIDIOC_QUERYCAP ioctlを設定する。以下のオーバーレイI/Oメソッドはサポートしなければならない。チューナーおよびオーディオ入力はオプションである。

4.2.2. 補助機能¶

ビデオオーバーレイデバイスは、 オーディオ入力, チューナーとモジュレータ, controls, クロッピングおよびスケーリング および ストリーミングパラメータ 必要に応じてioctlをサポートしなければなりません。 ビデオ入力 および ビデオ標準 ioctlはすべてのビデオオーバーレイデバイスでサポートしなければならない。

4.2.3. 設定¶

オーバーレイを開始する前に、アプリケーションはドライバーにフレームバッファパラメータを設定しなければならない。これはフレームバッファのアドレスとサイズ、および画像形式（例：RGB 5:6:5）である。 VIDIOC_G_FBUF および VIDIOC_S_FBUF ioctlはこれらのパラメータを取得および設定するために利用可能である。 VIDIOC_S_FBUF ioctlは特権を持つため、物理メモリへのDMA設定を許可し、カーネルのメモリ保護メカニズムをバイパスする。フレームバッファのアドレスとサイズを変更できるのはスーパーユーザーのみである。ユーザーはTVアプリケーションをrootとして実行したり、SUIDビットを設定したりすべきではない。小さなヘルパーアプリケーションで適切な特権を取得し、グラフィックシステムを照会して、適切なタイミングでV4L2ドライバーをプログラミングすべきである。

一部のデバイスは、グラフィックカードの出力信号にビデオオーバーレイを追加します。この場合、ビデオデバイスがフレームバッファを変更せず、ドライバがフレームバッファのアドレスやピクセル形式を必要としません。The VIDIOC_S_FBUF ioctlは権限がありません。アプリケーションはこの種のデバイスを確認するため、 VIDIOC_G_FBUF ioctl.

ドライバがサポートするクリッピング/ブレンド方法は最大5種類（または0種類）あります：

  1. クロマキーは、プライマリグラフィックス表面のピクセルが特定の色をとる場所にのみオーバーレイ画像を表示します。

  2. ビットマップを指定できます。各ビットはオーバーレイ画像のピクセルに対応し、ビットが設定されている場合、対応するビデオピクセルが表示され、それ以外の場合はグラフィックス表面のピクセルが表示されます。

  3. クリッピング矩形のリストを指定できます。これらの領域では no ビデオが表示されるため、グラフィックス表面がここに見えることがあります。

  4. フレームバッファにはアルファチャネルがあり、これを用いてフレームバッファとビデオをクリップまたはブレンドできます。

  5. グローバルアルファ値を指定して、フレームバッファの内容とビデオ画像をブレンドできます。

同時キャプチャとオーバーレイがサポートされており、ハードウェアが異なる画像およびフレームバッファ形式を禁止する場合、最初に要求された形式が優先されます。キャプチャ（VIDIOC_S_FMT)またはオーバーレイ（VIDIOC_S_FBUF)の試行は、 EBUSY エラー コードで失敗するか、適切に修正されたパラメータを返します。
