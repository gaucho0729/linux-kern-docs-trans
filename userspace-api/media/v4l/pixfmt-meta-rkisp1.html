2.13.3. V4L2_META_FMT_RK_ISP1_PARAMS (‘rk1p’), V4L2_META_FMT_RK_ISP1_STAT_3A (‘rk1s’)¶

2.13.3.1. 設定パラメータ¶

設定パラメータは、 rkisp1_params メタデータ出力ビデオノードに渡されます。インターフェースを使用して。 v4l2_meta_format インターフェース。 rkisp1_params_cfg で定義されています rkisp1-config.hバッファには、C構造体の単一のインスタンスが含まれています。

struct rkisp1_params_cfg *params = (struct rkisp1_params_cfg*) buffer;

2.13.3.2. 。したがって、構造体はバッファから以下のように取得できます。¶

3A およびヒストグラム統計 ISP1 デバイスは、入力されたバエヤーフレームに対してさまざまな統計を収集します。これらの統計は、 rkisp1_stats v4l2_meta_format インターフェース。 rkisp1_stat_buffer で定義されています rkisp1-config.hバッファには、C構造体の単一のインスタンスが含まれています。

struct rkisp1_stat_buffer *stats = (struct rkisp1_stat_buffer*) buffer;

メタデータキャプチャビデオノードを使用して取得されます。収集された統計は、露出（Exposure）、AWB（オートホワイトバランス）、ヒストグラム、AF（オートフォーカス）です。詳細については、 rkisp1_stat_buffer 統計の詳細についてはこちらをご覧ください。

ここで説明する3A統計および設定パラメータは、通常、ソフトウェア制御ループを使用した重要なチューニングツールを含む専用ユーザースペースライブラリによって消費および生成されます。
