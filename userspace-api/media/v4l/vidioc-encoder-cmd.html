7.10. struct v4l2_dv_timings_cap¶

7.10.1. 名前¶

VIDIOC_ENCODER_CMD - VIDIOC_TRY_ENCODER_CMD - エンコーダー コマンドを実行する

7.10.2. 概要¶

VIDIOC_ENCODER_CMD¶

int ioctl(int fd, VIDIOC_ENCODER_CMD, struct v4l2_encoder_cmd *argp)

VIDIOC_TRY_ENCODER_CMD¶

int ioctl(int fd, VIDIOC_TRY_ENCODER_CMD, struct v4l2_encoder_cmd *argp)

7.10.3. 引数¶

fd

返されるファイル記述子 open().

argp

struct mem_ctl_info v4l2_encoder_cmd.

7.10.4. 説明¶

これらのioctlはオーディオ/ビデオ（通常はMPEG）エンコーダーを制御します。 VIDIOC_ENCODER_CMD エンコーダーにコマンドを送信します。 VIDIOC_TRY_ENCODER_CMD 実際に実行せずにコマンドを試すために使用できます。

コマンドを送信するには、アプリケーションはstructのすべてのフィールドを初期化する必要があります。 v4l2_encoder_cmd を埋めます VIDIOC_ENCODER_CMD または VIDIOC_TRY_ENCODER_CMD この構造体へのポインタを指定する必要があります。

以下の cmd フィールドにはコマンドコードを含める必要があります。一部のコマンドでは、 flags フィールドで追加の情報を使用します。

STOPコマンドの後、 read() 呼び出しはドライバによってバッファリングされた残りのデータを読み込みます。バッファが空になると、 read() ゼロを返し、次の read() 呼び出しがエンコーダーを再開します。

A read() または VIDIOC_STREAMON エンコーダーがまだ起動していない場合、呼び出しは暗黙のSTARTコマンドを送信します。これはmem2memエンコーダーの両方のキューに適用されます。

A close() または VIDIOC_STREAMOFF ストリーミングファイル記述子の呼び出しはエンコーダーに暗黙の即時STOPを送信し、すべてのバッファリングされたデータを破棄します。これはmem2memエンコーダーの両方のキューに適用されます。

これらのioctlはオプションであり、すべてのドライバがサポートするとは限りません。Linux 2.6.21で導入されました。ただし、stateful mem2memエンコーダーでは必須です（詳しくは以下のドキュメントを参照してください）。 メモリ対メモリ ステートフル ビデオ エンコーダー インターフェース).

エンコーダー コマンド¶

V4L2_ENC_CMD_START

0

エンコーダーを開始します。エンコーダーがすでに動作中または一時停止している場合、このコマンドは無視されます。このコマンドにはフラグは定義されていません。

デバイスが以下を実装している場合、 メモリ対メモリ ステートフル ビデオ エンコーダー インターフェースドレインシーケンスが以下コマンドで開始された場合、 V4L2_ENC_CMD_STOP コマンドを実行する前に、ドレインシーケンスを完了させる必要があります。ドレインシーケンスが進行中である場合にコマンドを実行しようとすると、エラー コードが発生します。このコマンドは、デコーダーが自身で明示的に停止を開始した場合にも、デコーダーを再起動するために使用できます。 EBUSY エラー コード。参照 メモリ対メモリ ステートフル ビデオ エンコーダー インターフェース 詳細についてはこちら。

V4L2_ENC_CMD_STOP

1

エンコーダーを停止します。 V4L2_ENC_CMD_STOP_AT_GOP_END フラグが設定されている場合、エンコードは現在の Group Of Picturesの終わりまで続きます。それ以外の場合、エンコードは直ちに停止します。エンコーダーがすでに停止している場合、このコマンドは無視されます。

デバイスが以下を実装している場合、 メモリ対メモリ ステートフル ビデオ エンコーダー インターフェースこのコマンドは、ドキュメントに記載されているようにドレインシーケンスを開始します。 メモリ対メモリ ステートフル ビデオ エンコーダー インターフェースこの場合、フラグや他の引数は受け付けられません。シーケンスが完了するまでコマンドを再度呼び出すと、エラーが発生します。 EBUSY エラー コードに設定します。

V4L2_ENC_CMD_PAUSE

2

エンコーダーを一時停止します。エンコーダーがまだ起動していない場合、ドライバは EPERM エラー コードを返します。エンコーダーがすでに一時停止している場合、このコマンドは無視されます。このコマンドにはフラグは定義されていません。

V4L2_ENC_CMD_RESUME

3

PAUSEコマンド後にエンコードを再開します。エンコーダーがまだ起動していない場合、ドライバは EPERM エラー コードを返します。エンコーダーがすでに動作している場合、このコマンドは無視されます。このコマンドにはフラグは定義されていません。
エンコーダー コマンド フラグ¶

V4L2_ENC_CMD_STOP_AT_GOP_END

0x0001

現在の Group Of Picturesの終わりにエンコードを停止します。

適用されません。 メモリ対メモリ ステートフル ビデオ エンコーダー インターフェース.

成功した場合、0 が返されます。エラーの場合、-1 が返され、変数が適切に設定されます。 errno 一般的なエラーコードは、 汎用エラーコード 章。

EBUSY

デバイスが実装するドレインシーケンスは メモリ対メモリ ステートフル ビデオ エンコーダー インターフェース まだ進行中です。完了するまで他のエンコーダー コマンドを送信することはできません。

EINVAL
