7.20.1. 名前¶

VIDIOC_ENUMSTD - VIDIOC_SUBDEV_ENUMSTD - サポートされているビデオ標準を列挙する

7.20.2. 概要¶

VIDIOC_ENUMSTD¶

int ioctl(int fd, VIDIOC_ENUMSTD, struct v4l2_standard *argp)

VIDIOC_SUBDEV_ENUMSTD¶

int ioctl(int fd, VIDIOC_SUBDEV_ENUMSTD, struct v4l2_standard *argp)

7.20.3. 引数¶

fd

返されるファイル記述子 open().

argp

struct mem_ctl_info v4l2_standard.

7.20.4. 説明¶

ビデオ標準（特にカスタム（ドライバで定義された）標準）の属性を照会するには、アプリケーションは index 構造体の v4l2_standard を初期化し、 にリネームされました。コードAPIの初稿がリリースされました。 ioctlを実行する際には、この構造体へのポインタを指定します。ドライバは構造体の残りの部分を埋めたり、エラー コードを返したりします。 EINVAL インデックスが範囲外の場合のエラーコードを返します。すべての標準を列挙するには、アプリケーションはインデックス0から開始し、ドライバが返す EINVALまでインデックスを1ずつ増やします。ドライバは、ビデオ入力または出力の切り替え後に異なる標準を列挙することができる。 1

struct v4l2_standard¶

__u32

v4l2_std_id

id

このフィールドのビットは、以下のリストに記載されている一般的な標準の1つとして標準を識別します typedef v4l2_std_id、またはビット32〜63が設定されている場合、カスタム標準です。ハードウェアがこれらの標準を区別しない場合、複数のビットを設定できますが、別個のインデックスは逆を示しません。この id は一意でなければなりません。この入力または出力に関係なく、他の列挙されたstruct v4l2_standard 構造体には同じビットのセットを含むことはできません。

__u8

標準の名前、NULL終端のASCII文字列、例えば「PAL-B/G」、「NTSC Japan」など。この情報はユーザー向けです。

__u32

ブランキングを含むフレームあたりの総ライン数、例えばB/PALの場合625です。

__u32

typedef v4l2_std_id¶

__u64

v4l2_std_id

この型はセットであり、各ビットが以下のリストおよび ビデオ標準（itu470に基づく）に記載されているビデオ標準を表します。32ビットの上位ビットはカスタム（ドライバで定義された）ビデオ標準のために予約されています。

 
#define V4L2_STD_PAL_B          ((v4l2_std_id)0x00000001)
#define V4L2_STD_PAL_B1         ((v4l2_std_id)0x00000002)
#define V4L2_STD_PAL_G          ((v4l2_std_id)0x00000004)
#define V4L2_STD_PAL_H          ((v4l2_std_id)0x00000008)
#define V4L2_STD_PAL_I          ((v4l2_std_id)0x00000010)
#define V4L2_STD_PAL_D          ((v4l2_std_id)0x00000020)
#define V4L2_STD_PAL_D1         ((v4l2_std_id)0x00000040)
#define V4L2_STD_PAL_K          ((v4l2_std_id)0x00000080)

#define V4L2_STD_PAL_M          ((v4l2_std_id)0x00000100)
#define V4L2_STD_PAL_N          ((v4l2_std_id)0x00000200)
#define V4L2_STD_PAL_Nc         ((v4l2_std_id)0x00000400)
#define V4L2_STD_PAL_60         ((v4l2_std_id)0x00000800)

V4L2_STD_PAL_60 は525ライン、60Hzリフレッシュレート、PALカラー変調で4.43MHzのカラーサブキャリアを持つハイブリッド標準です。一部のPALビデオレコーダーは、このモードでNTSCテープを再生し、50/60Hzに無関係なPALテレビに表示できます。

#define V4L2_STD_NTSC_M         ((v4l2_std_id)0x00001000)
#define V4L2_STD_NTSC_M_JP      ((v4l2_std_id)0x00002000)
#define V4L2_STD_NTSC_443       ((v4l2_std_id)0x00004000)

V4L2_STD_NTSC_443 は525ライン、60Hzリフレッシュレート、NTSCカラー変調で4.43MHzのカラーサブキャリアを持つハイブリッド標準です。

7.20.5. 戻り値¶

成功した場合、0 が返されます。エラーの場合、-1 が返され、変数が適切に設定されます。 errno 一般的なエラーコードは、 汎用エラーコード 章。

EINVAL

構造体 v4l2_standard index 範囲外です。

ENODATA

この入力または出力では、標準的な映像タイミングがサポートされていません。

1

サポートされる標準は重複する可能性があるため、現在の標準を特定するには明確なセットが必要です。 VIDIOC_G_STD.

2

日本はM/NTSCに似た標準を使用しています (V4L2_STD_NTSC_M_JP)。

3

括弧内の値は組み合わせ N/PAL（通称N）に適用されます。C アルゼンチンで使用される (V4L2_STD_PAL_Nc)。

4

ドイツ連邦共和国、オーストリア、イタリア、オランダ、スロバキア、スイスでは、二つの音声搬送波を用いたシステムが使用されています。第二搬送波の周波数は第一搬送波の周波数より242.1875 kHz高いです。オーストラリアではステレオ音声送信にも同様のシステムが使用されています。

5

ニュージーランドでは、映像搬送波から5.4996 ± 0.0005 MHzずらした音声搬送波が使用されています。

6

デンマーク、フィンランド、ニュージーランド、スウェーデン、スペインでは二つの音声搬送波を用いたシステムが使用されています。アイスランド、ノルウェイ、ポーランドでは同様のシステムが導入されています。第二搬送波は映像搬送波より5.85 MHz高く、728 kbit/sの音声およびデータ多重化をDQPSKで変調します。(NICAMシステム)

7

イギリスでは二つの音声搬送波を用いたシステムが使用されています。第二音声搬送波は映像搬送波より6.552 MHz高く、728 kbit/sの音声およびデータ多重化をDQPSKで変調します。この多重化は二つの音声チャネルを伝送できます。(NICAMシステム)

8

フランスでは、映像搬送波から5.85 MHz離れたデジタル搬送波を主な音声搬送波に加えて使用する可能性があります。これは差分符号化QPSKで728 kbit/sの音声およびデータ多重化を変調します。この多重化は二つの音声チャネルを伝送できます。(NICAMシステム)
