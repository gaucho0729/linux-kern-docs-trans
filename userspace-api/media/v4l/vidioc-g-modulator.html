7.35. ioctl VIDIOC_G_MODULATOR, VIDIOC_S_MODULATOR¶

7.35.1. 名前¶

VIDIOC_G_MODULATOR - VIDIOC_S_MODULATOR - モジュレータ属性の取得または設定

7.35.2. 概要¶

VIDIOC_G_MODULATOR¶

int ioctl(int fd, VIDIOC_G_MODULATOR, struct v4l2_modulator *argp)

VIDIOC_S_MODULATOR¶

int ioctl(int fd, VIDIOC_S_MODULATOR, const struct v4l2_modulator *argp)

7.35.3. 引数¶

fd

返されるファイル記述子 open().

argp

struct mem_ctl_info v4l2_modulator.

7.35.4. 説明¶

モジュレータの属性を照会するには、アプリケーションは index フィールドを初期化し、インデックスが範囲外の場合のエラーコードをゼロに設定する必要があります。 reserved 配列をゼロにします。 v4l2_modulator を初期化し、 VIDIOC_G_MODULATOR ioctlを実行する際には、この構造体へのポインタを指定します。ドライバは構造体の残りの部分を埋めたり、エラー コードを返したりします。 EINVAL インデックスが範囲外の場合のエラーコードを確認します。すべてのモジュレータを列挙するには、アプリケーションはインデックス0から開始し、ドライバーがEINVALを返すまでインデックスを1ずつ増やします。

モジュレータには2つの書き込み可能なプロパティがあります。オーディオ変調セットとラジオ周波数です。オーディオサブプログラムを変更するには、アプリケーションは index および txsubchans フィールドと reserved 現在のチューナーやモデュレータのラジオ周波数を変更するには、アプリケーションはこの構造体を初期化し VIDIOC_S_MODULATOR ioctlを初期化します。ドライバーが要請を満たせない場合、異なるオーディオ変調を選択できるかもしれませんが、これは読み取り専用ioctlであり、実際に選択されたオーディオ変調は返されません。

SDR 特定のモジュレータタイプは V4L2_TUNER_SDR および V4L2_TUNER_RFです。SDRデバイスの場合、 txsubchans フィールドはゼロに初期化する必要があります。この文脈では、「モジュレータ」という用語はSDR送信機を指します。

ラジオ周波数を変更するには、 VIDIOC_S_FREQUENCY ioctlが利用可能です。

type v4l2_modulator¶
struct v4l2_modulator¶

__u32

index

モジュレータを識別し、アプリケーションによって設定されます。

__u8

name[32]

モジュレータの名前、NULL終端のASCII文字列。

この情報はユーザー向けです。

__u32

capability

モジュレータキャパビリティフラグ。このフィールドにはフラグが定義されていません。 tunerフラグはstruct v4l2_tuner に記載されている通りに使用されます。オーディオフラグはオーディオサブプログラムを符号化できるかどうかを示します。これらは、現在のビデオ標準に応じて変化します。 ではありません 62.5 KHz単位での最低可変周波数、または

__u32

rangelow

が設定されている場合、62.5 Hz単位で、または capability フラグ V4L2_TUNER_CAP_LOW が設定されている場合、1 Hz単位で。 capability フラグ V4L2_TUNER_CAP_1HZ 62.5 KHz単位での最高可変周波数、または

__u32

rangehigh

このフィールドを使用して、アプリケーションはオーディオサブキャリアがどのように変調されるかを決定できます。これは、 capability フラグ V4L2_TUNER_CAP_LOW が設定されている場合、1 Hz単位で。 capability フラグ V4L2_TUNER_CAP_1HZ 62.5 KHz単位での最高可変周波数、または

__u32

txsubchans

に定義されたフラグのセットを含みます。 モジュレータオーディオ送信フラグ.

注意

tuner rxsubchans フラグは再利用されますが、セマンティクスは異なります。ビデオ出力デバイスは、1〜3チャンネルのアナログまたはPCMオーディオ入力を持つと仮定されます。 txsubchans フラグは、1つまたは複数のチャンネルを変調するために選択され、いくつかのオーディオサブプログラムインジケーターと組み合わせます。たとえば、ステレオパイロットトーンです。

__u32

type

モジュレータのタイプ、参照 v4l2_tuner_type.

__u32

reserved[3]

ドライバーおよびアプリケーションは、配列をゼロに設定する必要があります。

BT.656/1120タイミングキャパビリティ。
モジュレータオーディオ送信フラグ¶

V4L2_TUNER_SUB_MONO

0x0001

チャンネル1をモノラルオーディオとして変調し、入力がより多くのチャンネルを持つ場合、チャンネル1と2のダウンミックス。このフラグは、 V4L2_TUNER_SUB_STEREO または V4L2_TUNER_SUB_LANG1.

V4L2_TUNER_SUB_STEREO

0x0002

チャンネル1と2をステレオオーディオ信号の左と右チャンネルとして変調します。入力が1チャンネルまたは2チャンネルのみの場合、 V4L2_TUNER_SUB_SAP が設定されている場合、チャンネル1は左と右チャンネルとして符号化されます。このフラグは、 V4L2_TUNER_SUB_MONO または V4L2_TUNER_SUB_LANG1です。ドライバーがステレオオーディオをサポートしない場合、モノラルに戻ります。

V4L2_TUNER_SUB_LANG1

0x0008

バイリンガルオーディオ信号の主語と副語としてチャンネル1と2をモジュレーションします。入力が1つのチャンネルのみの場合、そのチャンネルは両方の言語に使用されます。主語または副語のみをエンコードすることはできません。このフラグは他のフラグと組み合わせることはできません V4L2_TUNER_SUB_MONO, V4L2_TUNER_SUB_STEREO または V4L2_TUNER_SUB_SAPハードウェアが対応するオーディオマトリクスをサポートしない、または現在のビデオ規格がバイリンガルオーディオを許可しない場合、 VIDIOC_S_MODULATOR ioctlはエラー コードを返し、ドライバーはモノラルまたはステレオモードにフォールバックします EINVAL エラー コードを返し、ドライバーはモノラルまたはステレオモードにフォールバックします

V4L2_TUNER_SUB_LANG2

0x0004

同じ効果があります V4L2_TUNER_SUB_SAP.

V4L2_TUNER_SUB_SAP

0x0004

このフラグと組み合わせた場合、 V4L2_TUNER_SUB_MONO 最初のチャンネルはモノラルオーディオとしてエンコードされ、最後のチャンネルはSecond Audio Programとしてエンコードされます。入力が1つのチャンネルのみの場合、そのチャンネルは両方のオーディオトラックに使用されます。入力が3つのチャンネルの場合、モノラルトラックはチャンネル1と2のダウンミキスです。このフラグと組み合わせた場合、 V4L2_TUNER_SUB_STEREO チャンネル1と2は左と右のステレオオーディオとしてエンコードされ、チャンネル3はSecond Audio Programとしてエンコードされます。入力が2つのチャンネルのみの場合、最初のチャンネルは左と右のチャンネルとしてエンコードされ、2番目のチャンネルはSAPとしてエンコードされます。入力が1つのチャンネルのみの場合、そのチャンネルはすべてのオーディオトラックに使用されます。Second Audio Programのみをエンコードすることはできません。このフラグは他のフラグと組み合わせなければなりません V4L2_TUNER_SUB_MONO または V4L2_TUNER_SUB_STEREOハードウェアが対応するオーディオマトリクスをサポートしない、または現在のビデオ規格がSAPを許可しない場合、 VIDIOC_S_MODULATOR ioctlはエラー コードを返し、ドライバーはモノラルまたはステレオモードにフォールバックします EINVAL エラー コードを返し、ドライバーはモノラルまたはステレオモードにフォールバックします

V4L2_TUNER_SUB_RDS

0x0010

ラジオFM送信機用のRDSエンコーダーを有効にします

7.35.5. 戻り値¶

成功した場合、0 が返されます。エラーの場合、-1 が返され、変数が適切に設定されます。 errno 一般的なエラーコードは、 汎用エラーコード 章。

EINVAL

構造体 v4l2_modulator index 範囲外です。
