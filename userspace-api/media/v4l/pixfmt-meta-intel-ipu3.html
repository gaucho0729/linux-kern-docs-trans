2.13.2.1. 3A統計情報¶

IPU3 ImgU 3A統計処理加速器は、入力されたバエイヤーフレームに対してさまざまな統計情報を収集します。これらの統計情報は、「ipu3-imgu [01] 3a stat」メタデータキャプチャビデオノードを使用して取得され、 v4l2_meta_format インターフェースを通じて取得されます。これらは、以下の記述に従ってフォーマットされます。 ipu3_uapi_stats_3a 何らかの理由で、木構造を配列形状ではなく木形状で描くと、平面的な表現を簡単に描くことができます:

収集された統計情報は、AWB（オートホワイトバランス）RGBS（赤、緑、青、彩度測定）セル、AWBフィルタ応答、AF（オートフォーカス）フィルタ応答、AE（オート露出）ヒストグラムです。

構造体 ipu3_uapi_4a_config すべての設定可能なパラメータを保存します。

struct ipu3_uapi_stats_3a {
        struct ipu3_uapi_awb_raw_buffer awb_raw_buffer;
        struct ipu3_uapi_ae_raw_buffer_aligned ae_raw_buffer[IPU3_UAPI_MAX_STRIPES];
        struct ipu3_uapi_af_raw_buffer af_raw_buffer;
        struct ipu3_uapi_awb_fr_raw_buffer awb_fr_raw_buffer;
        struct ipu3_uapi_4a_config stats_4a_config;
        __u32 ae_join_buffers;
        __u8 padding[28];
        struct ipu3_uapi_stats_3a_bubble_info_per_stripe stats_3a_bubble_per_stripe;
        struct ipu3_uapi_ff_status stats_3a_status;
};

2.13.2.2. パイプラインパラメータ¶

パイプラインパラメータは、「ipu3-imgu [01] パラメータ」メタデータ出力ビデオノードを通じて渡され、 v4l2_meta_format インターフェースを通じて取得されます。これらは、以下の記述に従ってフォーマットされます。 ipu3_uapi_params 何らかの理由で、木構造を配列形状ではなく木形状で描くと、平面的な表現を簡単に描くことができます:

ここに記載されている3A統計情報およびパイプラインパラメータは、基盤となるカメラサブシステム（CSS）APIと密接に関連しており、通常は重要なチューニングツールを含む専用ユーザースペースライブラリによって消費・生成されます。これにより、開発者は低レベルハードウェアやアルゴリズムの詳細に悩むことなくなります。

struct ipu3_uapi_params {
        /* Flags which of the settings below are to be applied */
        struct ipu3_uapi_flags use;

        /* Accelerator cluster parameters */
        struct ipu3_uapi_acc_param acc_param;

        /* ISP vector address space parameters */
        struct ipu3_uapi_isp_lin_vmem_params lin_vmem_params;
        struct ipu3_uapi_isp_tnr3_vmem_params tnr3_vmem_params;
        struct ipu3_uapi_isp_xnr3_vmem_params xnr3_vmem_params;

        /* ISP data memory (DMEM) parameters */
        struct ipu3_uapi_isp_tnr3_params tnr3_dmem_params;
        struct ipu3_uapi_isp_xnr3_params xnr3_dmem_params;

        /* Optical black level compensation */
        struct ipu3_uapi_obgrid_param obgrid_param;
};

注意

コンフィギュレーションユニットの各インスタンスは、ドライバがカリブレーションパラメータに基づいて計算した点間のスロープA係数とn点のX座標を必要とします。
