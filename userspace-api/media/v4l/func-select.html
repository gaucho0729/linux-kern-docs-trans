7.69. V4L2 select()¶

7.69.1. 名前¶

v4l2-select - 同期I/O多重化

7.69.2. 概要¶

#include <sys/time.h>
#include <sys/types.h>
#include <unistd.h>
int 選択(int nfds, fd_set *readfds, fd_set *writefds, fd_set *exceptfds, struct timeval *タイムアウト)¶

7.69.3. 引数¶

nfds

いずれかの3つのセットにある最高番号のファイル記述子に1を加えた値。

readfds

read()呼び出しがブロックしない場合に監視するファイル記述子。

writefds

write()呼び出しがブロックしない場合に監視するファイル記述子。

exceptfds

V4L2イベントを監視するファイル記述子。

timeout

最大待機時間。

7.69.4. 説明¶

With the select() 関数アプリケーションは、ドライバーがデータをキャプチャしたか、または出力用データを受け入れる準備ができているまで実行を一時停止します

ストリーミングI/Oが設定された場合、この関数はバッファが満たされたり表示されたりした後、ioctlでデキューできるまで待機します。 VIDIOC_DQBUF ioctl。ドライバの送出キューにバッファがすでに存在する場合、関数はすぐに返します。

成功した場合 select() が設定されているビットの総数を返します。 fd_set関数がタイムアウトした場合、ゼロを返します。失敗した場合は-1を返し、 errno 関数を呼び出していなかった場合、 ioctl VIDIOC_QBUF, VIDIOC_DQBUF または ioctl VIDIOC_STREAMON, VIDIOC_STREAMOFF yet the select() 関数が成功すると、ファイル記述子のビットを設定します。 readfds または writefds, ただし後続の VIDIOC_DQBUF 呼び出しが失敗します。 1

When use of the read() function has been negotiated and the driver does not capture yet, the select() 関数がキャプチャを開始します。その場合失敗した場合、 select() 成功を返し、後続の read() 呼び出し、キャプチャを開始しようとする後続の呼び出しが適切なエラーコードを返します。ドライバが連続的にキャプチャ（例として静止画とは対照的に）し、データがすでに利用可能であれば、 select() 関数はすぐに返します。

When use of the write() 関数が交渉された場合、 select() 関数は非ブロック的な準備が整うまで待機します。 write() 呼び出し時にkdumpが発生します。

All drivers implementing the read() または write() function or streaming I/O must also support the select() function.

詳細については、 select() マニュアルページ。

7.69.5. 戻り値¶

成功した場合、 select() 3つの返されたディスクリプタセットに含まれるディスクリプタの数を返します。タイムアウトが発生した場合、ゼロになります。エラーの場合、-1が返され、 errno 変数が適切に設定されます。セットと timeout は未定義です。可能なエラーコードは次の通りです：

EBADF

1つ以上のファイルディスクリプタセットが開いていないファイルディスクリプタを指定しています。

EBUSY

The driver does not support multiple read or write streams and the device is already in use.

EFAULT

以下の readfds, writefds, exceptfds または timeout ポインタがアクセスできないメモリ領域を参照しています。

EINTR

呼び出しがシグナルによって中断されました。

EINVAL

以下の nfds 引数がゼロ未満または FD_SETSIZE.

1

Linuxカーネルは select() のように、 poll() 関数、ただし select() 返すことはできません POLLERR.
