汎用エラーコード¶

汎用エラー コード¶

EAGAIN (aka EWOULDBLOCK)

デバイスがその操作を実行できない状態にあるため、ioctl が処理できません。たとえば、デバイスがスリープ状態で ioctl が統計情報を照会するために実行された場合など、このような状況が発生します。また、ioctl がイベントを待機する必要があるが、デバイスが非ブロッキングモードで開かれた場合にもこのエラーが返されます。

EBADF

ファイルディスクリプタが有効ではありません。

EBUSY

デバイスがビジー状態です。これは、ストリーミング中に ioctl がストリームに影響を与える変更を試行した場合などに通常返されます。ioctl は、問題を解決するための別のアクション（通常はストリームを停止した後）を実行するまで再試行してはいけません。

EFAULT

ユーザー空間とのデータコピー中に失敗しました。おそらく無効なポインタ参照が原因です。

EINVAL

1つ以上の ioctl パラメータが無効または許可範囲外です。これは一般的なエラー コードです。特定の原因については、個々の ioctl 要求を参照してください。

ENODEV

デバイスが見つからないか、すでに削除されました。

ENOMEM

十分なメモリがありません。

ENOTTY

ドライバーが ioctl をサポートしていません。これは、必要な機能が利用不可であるか、ファイルディスクリプタがメディアデバイスでないことを意味します。

ENOSPC

USB デバイスでは、このエラーが返されることがあります。これは、このリクエストが定期的な転送に割り当てられた USB バンド幅（最大で USB バンド幅の 80%）を過剰に使用する可能性があるためです。

EPERM

アクセス権がありません。デバイスが書き込み権限が必要な場合、または特別な能力（例: root）が必要な場合に返されます。

EIO

I/O エラー。ハードウェアデバイスと通信する際の問題が発生した場合に通常使用されます。これは壊れたまたは不安定なハードウェアを示す「何かが間違っている、あきらめます！」タイプのエラーです。

ENXIO

このデバイス専用ファイルに対応するデバイスがありません。

注意

  1. このリストは網羅的ではありません。ioctl は他のエラー コードを返す場合があります。エラーがドライバーのリセットなどの副作用を引き起こす可能性があるため、アプリケーションは予期せぬエラーの場合は中止する必要があります。

  2. リクエスト固有のエラーコードは、個々のリクエストの記述に記載されています。
