Speculation Control¶

いくつかのCPUは、スペキュレーション関連の不具合（misfeature）を持ち、これにより権限領域を超えてデータ漏洩を引き起こす脆弱性があります。

カーネルはこのような脆弱性に対して様々な形で緩和策を提供しています。一部の緩和策はコンパイル時に設定可能で、一部はカーネルコマンドラインで指定できます。

また、パフォーマンスに大きな影響を与える緩和策も存在しますが、制御された環境において特定のプロセスやタスクにのみ適用可能です。この緩和策を制御するメカニズムは prctl(2).

以下の2つのprctlオプションに関連しています：

  • PR_GET_SPECULATION_CTRL

  • PR_SET_SPECULATION_CTRL

PR_GET_SPECULATION_CTRL¶

PR_GET_SPECULATION_CTRLは、prctl(2)のarg2で選択されたスペキュレーション不具合の状態を返します。返却値はビット0〜3を使用し、以下のような意味を持ちます：

ビット

定義

説明

0

PR_SPEC_PRCTL

タスクごとにスペキュレーション不具合の制御がPR_SET_SPECULATION_CTRLで可能です。

1

PR_SPEC_ENABLE

スペキュレーション機能を有効にし、緩和策を無効にします。

2

PR_SPEC_DISABLE

スペキュレーション機能を無効にし、緩和策を有効にします。

3

PR_SPEC_FORCE_DISABLE

PR_SPEC_DISABLEと同様ですが、元に戻すことはできません。その後のprctl(…, PR_SPEC_ENABLE)は失敗します。

4

PR_SPEC_DISABLE_NOEXEC

PR_SPEC_DISABLEと同様ですが、 execve(2)で状態がクリアされます。.

すべてのビットが0の場合、CPUはスペキュレーション不具合の影響を受けません。

PR_SPEC_PRCTLが設定されている場合、タスクごとの緩和策制御が可能です。設定されていない場合、prctl(PR_SET_SPECULATION_CTRL)は失敗します。

PR_SET_SPECULATION_CTRL¶

PR_SET_SPECULATION_CTRLは、arg2で選択されたスペキュレーション不具合の制御を可能にします。 prctl(2) タスクごとにarg3で制御値（PR_SPEC_ENABLE、PR_SPEC_DISABLE、PR_SPEC_FORCE_DISABLEのいずれか）を指定します。

一般的なエラーコード¶

値

意味

EINVAL

prctlはアーキテクチャによって実装されていないか、未使用のprctl(2)引数は0でない場合があります。

ENODEV

arg2で選択されたスペキュレーション不具合がサポートされていません。

PR_SET_SPECULATION_CTRL エラーコード¶

値

意味

0

成功

ERANGE

arg3が不正です（PR_SPEC_ENABLE、PR_SPEC_DISABLE、PR_SPEC_FORCE_DISABLEのいずれでもありません）。

ENXIO

選択されたスペキュレーション不具合の制御が不可能です。PR_GET_SPECULATION_CTRLを参照してください。

EPERM

PR_SPEC_FORCE_DISABLEでスペキュレーションが無効化され、呼び出し元が再度有効化を試みた場合。

推測ミスフィーチャー制御¶

  • PR_SPEC_STORE_BYPASS: スペキュレーティブストアバイパス

    呼び出し例：

    • prctl(PR_GET_SPECULATION_CTRL, PR_SPEC_STORE_BYPASS, 0, 0, 0);

    • prctl(PR_SET_SPECULATION_CTRL, PR_SPEC_STORE_BYPASS, PR_SPEC_ENABLE, 0, 0);

    • prctl(PR_SET_SPECULATION_CTRL, PR_SPEC_STORE_BYPASS, PR_SPEC_DISABLE, 0, 0);

    • prctl(PR_SET_SPECULATION_CTRL, PR_SPEC_STORE_BYPASS, PR_SPEC_FORCE_DISABLE, 0, 0);

    • prctl(PR_SET_SPECULATION_CTRL, PR_SPEC_STORE_BYPASS, PR_SPEC_DISABLE_NOEXEC, 0, 0);

  • PR_SPEC_INDIR_BRANCH: Indirect Branch Speculation in User Processes

    (ユーザープロセスに対するSpectre V2スタイルの攻撃を緩和する)

    呼び出し例：

    • prctl(PR_GET_SPECULATION_CTRL, PR_SPEC_INDIRECT_BRANCH, 0, 0, 0);

    • prctl(PR_SET_SPECULATION_MIXED_CTRL, PR_SPEC_INDIRECT_BRANCH, PR_SPEC_ENABLE, 0, 0);

    • prctl(PR_SET_SPECULATION_MIXED_CTRL, PR_SPEC_INDIRECT_BRANCH, PR_SPEC_DISABLE, 0, 0);

    • prctl(PR_SET_SPECULATION_MIXED_CTRL, PR_SPEC_INDIRECT_BRANCH, PR_SPEC_FORCE_DISABLE, 0, 0);
