kunit_tool ガイド¶

kunit_toolとは？¶

kunit_tool はスクリプト（tools/testing/kunit/kunit.py）で、Linux カーネルを UML（User Mode Linux）としてビルドし、KUnit テストを実行し、テスト結果を解析してユーザーにわかりやすく表示するスクリプトです。

kunit_tool は、仮想マシンや実際のハードウェアを必要とせずにテストを実行できる問題を解決します。User Mode Linux は ARM や x86 などの Linux アーキテクチャの一つですが、他のアーキテクチャとは異なり、カーネルをスタンドアロンの Linux 実行ファイルとしてコンパイルし、ホスト操作システム内で他のプログラムと同様に実行できます。要するに、仮想化サポートは必要ありません。単なる通常のプログラムです。

.kunitconfigとは？¶

これは kunit_tool がベースディレクトリで探す defconfig です。kunit_tool はこれを用いて .config を生成します。さらに、生成された .config が .kunitconfig に含まれる CONFIG オプションを含んでいるかを確認します。これは、テストを有効にする CONFIG が実際に .config に含まれていることを確認しやすくするためです。

kunit_toolはどのように使用しますか？¶

ルートディレクトリに kunitconfig が存在する場合、必要なのは次のステップだけです：

./tools/testing/kunit/kunit.py run

ただし、以下のオプションを使用することをお勧めします：

./tools/testing/kunit/kunit.py run --timeout=30 --jobs=`nproc --all`

  • --timeout テストの実行に許容する最大時間の設定。

  • --jobs カーネルのビルドに使用するスレッド数の設定。

注意

このコマンドは .kunitconfig ファイルがなくても動作します。.kunitconfig が存在しない場合、デフォルトのものを代わりに使用します。

kunit_tool がサポートするすべてのフラグの一覧を表示するには、以下を実行してください：

./tools/testing/kunit/kunit.py run --help
