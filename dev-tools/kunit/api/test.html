テストAPI¶

このファイルは、モックやモック関連の機能を除いた標準的なテストAPIについて記述しています。

struct kunit_resource¶

は テストで管理されるリソース

定義

struct kunit_resource {
  void *data;
  const char *name;
  kunit_resource_free_t free;
};

メンバ

data

を表し、ユーザーが任意のデータを保存するために使用されます。

name

オプションの名前

free

ユーザーが提供するリソースを解放する関数です。kunit_resource_alloc()によって設定されます。

説明

は テストで管理されるリソース、テストケースの終わりに自動的にクリーンアップされるリソースです。

リソースは参照カウントされるため、kunit_alloc_and_get_resource()や kunit_find_resource()を介して取得した場合、使用が終わったら kunit_put_resource() を呼び出す必要があります。注意として、 kunit_alloc_resource() はリソース自体を取得しないのでkunit_resource_put()は必要ありません。

struct kunit_kmalloc_params {
        size_t size;
        gfp_t gfp;
};

static int kunit_kmalloc_init(struct kunit_resource *res, void *context)
{
        struct kunit_kmalloc_params *params = context;
        res->data = kmalloc(params->size, params->gfp);

        if (!res->data)
                return -ENOMEM;

        return 0;
}

static void kunit_kmalloc_free(struct kunit_resource *res)
{
        kfree(res->data);
}

void *kunit_kmalloc(struct kunit *test, size_t size, gfp_t gfp)
{
        struct kunit_kmalloc_params params;

        params.size = size;
        params.gfp = gfp;

        return kunit_alloc_resource(test, kunit_kmalloc_init,
                kunit_kmalloc_free, &params);
}

リソースは名前を指定することもでき、名前を基にした検索/削除も可能です。 kunit_add_named_resource(), kunit_find_named_resource() kunit_destroy_named_resource()。リソース名はテストインスタンス内で一意でなければなりません。

struct kunit_case¶

は個々のテストケースを表します。

定義

struct kunit_case {
  void (*run_case)(struct kunit *test);
  const char *name;
};

メンバ

run_case

テストケースを表す関数です。

name

テストケースの名前です。

説明

テストケースは、次のシグネチャを持つ関数です、 void (*)(struct kunit *) テスト対象コードについての期待値とアサーションを設定します（参照 KUNIT_EXPECT_TRUE() および KUNIT_ASSERT_TRUE())。各テストケースは、 struct kunit_suite に関連付けられ、スイートの初期化関数の後に実行され、スイートの終了関数の前に実行されます。

テストケースは静的でなければなりませんし、 KUNIT_CASE() マクロのみで作成する必要があります。さらに、すべてのテストケースの配列は空のテストケースで終了する必要があります。

void add_test_basic(struct kunit *test)
{
        KUNIT_EXPECT_EQ(test, 1, add(1, 0));
        KUNIT_EXPECT_EQ(test, 2, add(1, 1));
        KUNIT_EXPECT_EQ(test, 0, add(-1, 1));
        KUNIT_EXPECT_EQ(test, INT_MAX, add(0, INT_MAX));
        KUNIT_EXPECT_EQ(test, -1, add(INT_MAX, INT_MIN));
}

static struct kunit_case example_test_cases[] = {
        KUNIT_CASE(add_test_basic),
        {}
};

struct kunit_suite¶

は、関連する struct kunit_case

定義

struct kunit_suite {
  const char name[256];
  int (*init)(struct kunit *test);
  void (*exit)(struct kunit *test);
  struct kunit_case *test_cases;
};

メンバ

name

テストの名前です。情報的なものです。

init

すべてのテストケースの前に呼び出されます。

exit

すべてのテストケースの後に呼び出されます。

test_cases

NULL終端のテストケース配列です。

説明

kunit_suiteは、関連する struct kunit_case のコレクションであり、 init テストケースの前に行われる関数で、exit は 終了処理として呼ばれます テストケースの後に行われる関数で、テストフィクチャの概念に似ています テストフィクチャ または テストクラス JUnit や Googletest などの他のユニットテストフレームワークにおける概念です

すべての struct kunit_case kunit_suite と関連付けなければなりません

struct kunit¶

テストの実行中のインスタンスを表します

定義

struct kunit {
  void *priv;
};

メンバ

priv

ユーザーが任意のデータを保存するために使用されます。初期化関数で生成されたデータを渡すために一般的に使用されます（参照 struct kunit_suite).

説明

テストが実行されているコンテキストに関する情報を保存します。このデータの大部分はプライベートで、公開関数を通じて間接的にアクセスする必要があります。例外は priv であり、テストライターが任意のデータを保存するために使用できます
