はじめに¶

依存関係のインストール¶

KUnitはLinuxカーネルと同じ依存関係を持っています。カーネルをビルドできる限り、KUnitも実行できます。

KUnit Wrapperを使用したテストの実行¶

KUnitには、テストをUser Mode Linuxの下で実行し、テスト結果をフォーマットするためのシンプルなPythonラッパーが含まれています。

ラッパーは以下のように実行できます:

./tools/testing/kunit/kunit.py run

このラッパー（kunit_toolとも呼ばれます）に関する詳しい情報は、 kunit_tool ガイド ページをご覧ください。

Creating a .kunitconfig¶

特定のテストセット（KUnit defconfigにリストされているものではなく）を実行したい場合、Kconfigオプションを .kunitconfig ファイルに指定できます。このファイルは通常のカーネル構成に加え、特定のテストターゲットを含んでいます。また、 .kunitconfig ファイルにはテストに必要な他の構成オプションも含める必要があります。

の良い出発点はKUnit defconfigです: .kunitconfig 次に、

cd $PATH_TO_LINUX_REPO
cp arch/um/configs/kunit_defconfig .kunitconfig

に設定したすべての構成オプションを

CONFIG_LIST_KUNIT_TEST=y

カーネルの構成¶

Kconfigオプションを有効にします（menuconfigではKernel Hacking/Kernel Testing and Coverageの下にあります）。ここから、使用したいKUnitテストを有効にできます。通常、テストのコンフィギュレーションオプションは CONFIG_KUNIT で終わる名前を持っています。 _KUNIT_TEST.

KUnitとKUnitテストはモジュールとしてコンパイルできます。この場合、モジュールがロードされるときにそのモジュール内のテストが実行されます。

テストの実行（KUnitラッパーなしで）¶

通常通りカーネルをビルドし、テスト出力はカーネルログに記録されます。 TAP 形式。

注意

TAP出力には他の行やデータが混在している可能性があります。

あなたの最初のテストの作成¶

カーネルリポジトリにテスト用のコードを追加しましょう。ファイルを作成してください。 drivers/misc/example.h 以下のような内容で作成してください：

int misc_example_add(int left, int right);

ファイルを作成してください drivers/misc/example.c:

#include <linux/errno.h>

#include "example.h"

int misc_example_add(int left, int right)
{
        return left + right;
}

以下のような行を追加してください。 drivers/misc/Kconfig:

config MISC_EXAMPLE
        bool "My example"

以下のような行を追加してください。 drivers/misc/Makefile:

obj-$(CONFIG_MISC_EXAMPLE) += example.o

テストを書く準備が整いました。テストは以下にあります。 drivers/misc/example-test.c:

#include <kunit/test.h>
#include "example.h"

/* Define the test cases. */

static void misc_example_add_test_basic(struct kunit *test)
{
        KUNIT_EXPECT_EQ(test, 1, misc_example_add(1, 0));
        KUNIT_EXPECT_EQ(test, 2, misc_example_add(1, 1));
        KUNIT_EXPECT_EQ(test, 0, misc_example_add(-1, 1));
        KUNIT_EXPECT_EQ(test, INT_MAX, misc_example_add(0, INT_MAX));
        KUNIT_EXPECT_EQ(test, -1, misc_example_add(INT_MAX, INT_MIN));
}

static void misc_example_test_failure(struct kunit *test)
{
        KUNIT_FAIL(test, "This test never passes.");
}

static struct kunit_case misc_example_test_cases[] = {
        KUNIT_CASE(misc_example_add_test_basic),
        KUNIT_CASE(misc_example_test_failure),
        {}
};

static struct kunit_suite misc_example_test_suite = {
        .name = "misc-example",
        .test_cases = misc_example_test_cases,
};
kunit_test_suite(misc_example_test_suite);

以下を追加してください。 drivers/misc/Kconfig:

config MISC_EXAMPLE_TEST
        bool "Test for my example"
        depends on MISC_EXAMPLE && KUNIT=y

以下を追加してください。 drivers/misc/Makefile:

obj-$(CONFIG_MISC_EXAMPLE_TEST) += example-test.o

これをあなたの .kunitconfig:

CONFIG_MISC_EXAMPLE=y
CONFIG_MISC_EXAMPLE_TEST=y

テストを実行できます：

./tools/testing/kunit/kunit.py run

以下のような失敗が表示されます：

...
[16:08:57] [PASSED] misc-example:misc_example_add_test_basic
[16:08:57] [FAILED] misc-example:misc_example_test_failure
[16:08:57] EXPECTATION FAILED at drivers/misc/example-test.c:17
[16:08:57]      This test never passes.
...

おめでとうございます！初めてのKUnitテストを書きました！
