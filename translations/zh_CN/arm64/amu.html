AArch64 Linuxにおけるアクティビティモニターユニット（AMU）拡張機能

翻訳者: Bailu Lin <bailu.lin@vivo.com>

AArch64 Linux における拡張された活動モニタリングユニット¶

著者: Ionela Voinescu <ionela.voinescu@arm.com>

日期: 2019-09-10

このドキュメントでは、AArch64 Linux がサポートする活動モニタリングユニットの仕様を簡潔に説明します。

架构总述¶

活動モニタリングは、ARMv8.4 CPU アーキテクチャで導入されたオプションの拡張機能です。

活動モニタリングユニット（各CPUで実装）は、システム管理にパフォーマンスカウンタを提供します。カウンタはシステムレジスタ経由でアクセス可能であり、外部メモリマッピング経由でのアクセスもサポートされています。

AMUv1 アーキテクチャは、4つの固定された64ビットイベントカウンタからなるカウンタグループを実装しています。

  • CPU サイクルカウンタ：CPU の周波数の増加に伴って増加します。

  • 常量计数器：同固定的系统时钟频率增长

  • 淘汰指令计数器: 同每次架构指令执行增长

  • 内存停顿周期计数器：计算由在时钟域内的最后一级缓存中未命中而引起 的指令调度停顿周期数

WFI または WFE 状態にある場合、カウンタは増加しません。

AMU アーキテクチャは、最大16ビットのイベントカウンタ空間を提供し、今後の新しい AMU バージョンでは新たなイベントカウンタの実装に利用される可能性があります。

さらに、AMUv1 は最大16個の64ビットの補助イベントカウンタを含むカウンタグループを実装しています。

冷复位时所有的计数器会清零。

基本支持¶

カーネルは、AMU をサポートするCPUとサポートしないCPUの組み合わせで安全に動作できます。したがって、CONFIG_ARM64_AMU_EXTN を設定した後は、後続の（secondary または hotplugged）CPU の検出およびこの機能の使用を無条件に有効にします。

CPU でこの機能を検出すると、機能が利用可能であるとマークしますが、カウンタの機能は保証されず、拡張属性があることを示すにとどまります。

ファームウェア（コードが高例外レベルで実行される、例えば arm-tf など）は以下の機能をサポートする必要があります：

  • EL2 および EL1 の低例外レベルでの AMU レジスタへのアクセスを提供する。

  • 使能计数器。如果未使能，它的值应为 0。

  • CPU の電源オフ状態から起動する前後でカウンタを保存または復元する。

この機能を有効にしたカーネルで起動したがファームウェアが破損している場合、カウンタレジスタへのアクセスで panic またはデッドロックが発生する可能性があります。これらの症状が見つからなくても、カウンタレジスタが返すデータは現実を反映していない可能性があります。通常、カウンタは0を返し、有効になっていないことを示します。

ファームウェアが適切なサポートを提供しない場合、CONFIG_ARM64_AMU_EXTN を無効にすることをお勧めします。安全上の理由から、EL0（ユーザー空間）からの EL1（カーネル空間）へのアクセスを AMUSERRENR_EL0 の設定を無視して捕獲しないでください。したがって、ファームウェアは AMU レジスタへのアクセスが EL2 または EL3 にとどまらないことを保証する必要があります。

AMUv1 の固定カウンタは以下のシステムレジスタを通じてアクセスできます：

  • SYS_AMEVCNTR0_CORE_EL0

  • SYS_AMEVCNTR0_CONST_EL0

  • SYS_AMEVCNTR0_INST_RET_EL0

  • SYS_AMEVCNTR0_MEM_STALL_EL0

特定の補助カウンタは SYS_AMEVCNTR1_EL0(n) でアクセスできます。ここで n は 0 から 15 の範囲です。

詳細情報はディレクトリ：arch/arm64/include/asm/sysreg.h に定義されています。

用户空间访问¶

以下の理由により、現在はユーザー空間から AMU のレジスタへのアクセスが禁止されています：

  • 安全因数：可能会暴露处于安全模式执行的代码信息。

  • 目的：AMU はシステム管理に使用されます。

同样，该功能对用户空间不可见。

虚拟化¶

以下の理由により、現在は KVM クライアントのユーザー空間（EL0）およびカーネル空間（EL1）から AMU のレジスタへのアクセスが禁止されています：

  • 安全因数：可能会暴露给其他客户端或主机端执行的代码信息。

AMU レジスタへのアクセスを試みる行為は、クライアントに登録された未定義例外をトリガーします。
