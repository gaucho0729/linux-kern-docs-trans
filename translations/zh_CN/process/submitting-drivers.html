Linuxカーネルにドライバを提出する方法¶

このドキュメントでは、さまざまな内核ソースツリーにデバイスドライバを提出する方法を説明します。注意として、グラフィックカードドライバに興味がある場合は、XFree86プロジェクト(https://www.xfree86.org/) および／または X.org プロジェクト(https://x.org)。

另请参阅 如何让你的改动进入内核 文档。

分配设备号¶

ブロックデバイスおよびキャラクタデバイスの主デバイス番号とサブデバイス番号は、Linuxの命名された番号割当権限であるLANANA（現在はTorben Mathiasen）が割当します。申請先のURLは https://www.lanana.org/。 即使不准备提交到主流内核的设备驱动也需要在这里分配设备号。有关详细信息， 请参阅 Linux で割り当てられたデバイス（4.x 以降のバージョン）。

如果你使用的不是已经分配的设备号，那么当你提交设备驱动的时候，它将会被强 制分配一个新的设备号，即便这个设备号和你之前发给客户的截然不同。

设备驱动的提交对象¶

Linux 2.0:

此内核源码树不接受新的驱动程序。

Linux 2.2:

此内核源码树不接受新的驱动程序。

Linux 2.4:

内核のMAINTAINERSファイルに所属するコード分野の総メンテナがいる場合は、ドライバをそのメンテナに提出してください。メンテナが返信しなかったり、適切なメンテナが見つからない場合は、Willy Tarreau <w@1wt.eu>。

Linux 2.6:

2.4版内核と同じルールに加えて、linux-kernelメールリストで最新のAPI変更を追跡する必要があります。Linux 2.6内核にドライバを提出するための主要連絡先はAndrew Morton <akpm@linux-foundation.org>。

著作権：著作権者はGPLライセンスの使用に同意する必要があります。提出者と著作権者が同じ個人または法人であることが望ましいです。それ以外の場合は、GPLライセンスを許可した著作権者または法人を明記してください。

電源管理：Linuxはモバイル機器やデスクトップシステムで幅広く使用されているため、あなたのドライバもこれらのデバイスで使用される可能性があります。基本的な電源管理をサポートすべきです。つまり、システムレベルでのスリープと wakeup に必要な .suspend と .resume 関数を実装する必要があります。ドライバがスリープと wakeup を正しく処理できるか確認してください。確認できない場合は、少なくとも .suspend 関数を -ENOSYS（機能未実装）エラーで返すようにしてください。また、ドライバが何もしない状態で消費電力を最小限に抑えることも確認してください。ドライバのテストに関するガイドは

不影响设备驱动能否被接受的条件¶

供应商： 由硬件供应商来维护驱动程序通常是一件好事。不过，如果源码

树里已经有其他人提供了可稳定工作的驱动程序，那么请不要期 望“我是供应商”会成为内核改用你的驱动程序的理由。理想的情 况是：供应商与现有驱动程序的作者合作，构建一个统一完美的 驱动程序。

响其是否能被内核接受。没有人对内核源码树享有特权。只要你 充分了解内核社区，你就会发现这一点。
