Linuxマジックナンバー¶

这个文件是有关当前使用的魔术值注册表。当你给一个结构添加了一个魔术值，你也应该把这个魔术值添加到这个文件，因为我们最好把用于各种结构的魔术值统一起来。

内核データ構造をマジック値で保護するというのは非常に良いアイデアです。これにより、実行時において(a)構造体が攻撃を受けたか、あるいは(b)誤った構造体をルーチンに渡したかを確認できます。後者のケースは特に有用です—特に空ポインタで構造体を指している場合に。たとえばttyソースコードでは、特定のドライバでこの方法を頻繁に使用し、特定の側面の構造体を繰り返し並べています。

使用魔术值的方法是在结构的开始处声明的，如下:

struct tty_ldisc {
        int     magic;
        ...
};

当你以后给内核添加增强功能的时候，请遵守这条规则！这样就会节省数不清的调试时间，特别是一些古怪的情况，例如，数组超出范围并且重新写了超出部分。遵守这个规则，‪这些情况可以被快速地，安全地避免。

Theodore Ts’o
