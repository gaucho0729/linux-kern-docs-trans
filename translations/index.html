免責事項¶

翻訳の目的は、英語以外の言語で読みやすく理解しやすくすることです。その目的は、英語を理解できない人や、その解釈に疑問を持つ人々を助けることです。また、一部の人々は、自国の言語でドキュメンテーションを読むことを好むかもしれませんが、 のみ 公式ドキュメンテーションは英語のものです： The Linux Kernel documentation.

更新がすべての翻訳に即座に伝播される可能性は非常に低いです。 The Linux Kernel documentation 翻訳のメンテナーラーおよび貢献者たちは、公式ドキュメンテーションの進化を追跡し、できるだけ翻訳を一致させています。そのため、翻訳が最新であるという保証はありません。翻訳で読んだ内容がコードで読んだ内容と比べて不自然に感じられる場合は、翻訳のメンテナーラーにご連絡ください。できれば、英語のドキュメンテーションも確認してください。

翻訳は公式ドキュメンテーションのフォークではなく、そのため翻訳のユーザーが公式英語ドキュメンテーションと異なる情報を見つけることはありません。コンテンツの追加、削除、更新はまず英語のドキュメントに適用され、その後可能であれば翻訳にも同じ変更を適用する必要があります。翻訳のメンテナーラーは、翻訳関連のみの貢献（例: 新しい翻訳、更新、修正）のみを受け入れます。

翻訳はできるだけ正確になるよう努力していますが、1つの言語をすべての他の言語に直接マッピングすることはできません。各言語には独自の文法と文化がありますので、英語の文を他の言語に翻訳する際には、その言語に合わせて調整する必要があります。そのため、翻訳を確認する際には、同じメッセージを異なる形式で伝えるためにわずかな違いがある場合があります。

Linuxコミュニティとコミュニケーションを取る必要があるが、英語で書くのが苦手な場合は、翻訳のメンテナーラーに相談してください。
