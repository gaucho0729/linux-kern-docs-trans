この翻訳の目的は、英語が理解できない人やその意味に疑問を抱く人、あるいは単にイタリア語で読むことを好む人のための読みやすさと理解のしやすさを提供することです。ただし、以下の点を十分に理解しておく必要があります。唯一 公式ドキュメンテーションは英語版です： The Linux Kernel documentation

ある変更がすべての翻訳に同時に適用される可能性は極めて低いです。翻訳のメンテナおよび貢献者は公式ドキュメンテーションの進化に追随し、可能な限りそれぞれの翻訳を一致させる努力を行っています。そのため、翻訳が最新の変更に完全に対応しているとは限りません。翻訳で読んだ内容がコードで読んだ内容と異なる場合は、該当の翻訳のメンテナに報告し、できれば英語版のドキュメンテーションも確認してください。 The Linux Kernel documentation 翻訳は公式ドキュメンテーションの

フォーク ではありませんため、ユーザーは公式版と同様の情報しか得られません。コンテンツの追加・削除・変更は英語版ドキュメンテーションでまず行い、その後可能であれば翻訳にも同じ変更を適用する必要があります。翻訳のメンテナは、翻訳活動に特化した貢献（例：新しい翻訳、更新、修正）を受け入れます。 翻訳はできる限り正確ですが、言語間の直接的なマッピングは不可能です。各言語には独自の文法と文化があり、英語の文章をイタリア語に翻訳する際には文脈に応じて調整されることがあります。そのため、この翻訳を読む際には、形式の違いがあるかもしれませんが、元のメッセージは正確に伝えられていることが確認できます。口語では英語由来語が広く使われていますが、可能な限りそれらをイタリア語の対応語に置き換えます。

Linux コミュニティとコミュニケーションを取る必要があるが英語での文章作成に不安がある場合は、翻訳のメンテナに助けを求めることが可能です。
