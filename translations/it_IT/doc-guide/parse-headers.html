uAPIヘッダーファイルを含める¶

ユーザー空間のAPIを説明するためには、ヘッダーファイルやC言語のサンプルコードを含めることが有効です。ユーザー空間APIのドキュメントとコードとの間の参照を生成するためにも役立ちます。ユーザー空間APIのドキュメントに、カーネルの変更を反映させるための参照を追加する利点があります。Sphinxはドキュメントに記述されていないシンボルに対して警告メッセージを出力します。これにより、uAPI（ユーザー空間API）のドキュメントとカーネルの変更を常に一致させることができます。このプログラム parse_headers.pl が生成する参照を生成します。ドキュメンテーション生成時にMakefileを通じて呼び出さなければなりません。カーネル内での使用例については、 Documentation/userspace-api/media/Makefile.

parse_headers.pl¶

NOME¶

parse_headers.pl - C言語ファイルを解析し、関数、構造体、列挙型、定義を識別し、Sphinx用の参照を生成するスクリプト

SINTASSI¶

parse_headers.pl [<オプション>] <Cファイル> <出力ファイル> [<例外ファイル>]

ここで<options>は–debug、–usage、–helpのいずれかです。

OPZIONI¶

–debug

スクリプトを詳細モードに設定します。デバッグに有用です。

–usage

短いヘルプメッセージを表示して終了します。

–help

詳細なヘルプメッセージを表示して終了します。

DESCRIZIONE¶

C言語のヘッダーファイルまたはソースファイル（C_FILE）をReStructuredText形式のテキストに変換し、..parsed-literalブロックで包含します。これにより、APIのドキュメントに参照が追加されます。オプションで、例外ファイル（EXCEPTIONS_FILE）を指定して、無視すべき要素や、デフォルト以外の参照先を指定することも可能です。

生成されたファイルは（OUT_FILE）に保存されます。

このプログラムは、 define関数、構造体、データ型、列挙型、列挙値を識別し、それぞれの参照を生成します。また、Linuxのioctlコマンドを指定する#defineを区別する機能も備えています。

EXCEPTIONS_FILEには、2種類の宣言が含まれます： 無視 o replace.

ignoreの構文は：

無視 タイプ 名前

の宣言は、シンボル 無視 の参照が生成されません。 名前 のタイプ タイプ.

replaceの構文は：

replace タイプ 名前 新しい値

の宣言は、シンボル replace のシンボル 名前のタイプ タイプの参照が生成されますが、デフォルト値ではなく、値 新しい値.

が使用されます。どちらの宣言でも、 タイプ は次のいずれかです：

ioctl

ignoreまたはreplaceの宣言は、以下のioctlの定義に適用されます：

#define VIDIOC_DBG_S_REGISTER _IOW(‘V’, 79, struct v4l2_dbg_register)

define

ignoreまたはreplaceの宣言は、C_FILE内のすべての#defineに適用されます。

typedef

typedef宣言に無視または置き換え宣言が適用されます。

struct

構造体名に無視または置き換え宣言が適用されます。

enum

列挙型名に無視または置き換え宣言が適用されます。

symbol

列挙型値名に無視または置き換え宣言が適用されます。

置き換え型の宣言では、フィールド new_value 自動的に:c:type:の参照を使用します typedef, enum e struct。代わりに、:ref: の参照を使用します ioctl, define e symbol。参照の型は宣言自体で明示的に定義できます。

例¶

ignore define _VIDEODEV2_H

C_FILEファイル内の#define _VIDEODEV2_Hの定義を無視します。

ignore symbol PRIVATE

次の例のような列挙型では:

enum foo { BAR1, BAR2, PRIVATE };

参照を生成しません。 PRIVATE.

replace symbol BAR1 :c:type:`foo` replace symbol BAR2 :c:type:`foo`

次の例のような列挙型では:

enum foo { BAR1, BAR2, PRIVATE };

CドメインのシンボルfooからBAR1とBAR2の値に参照を生成します。
