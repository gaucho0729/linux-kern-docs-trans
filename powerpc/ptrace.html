Ptrace¶

GDBはBookEプロセッサの以下のハードウェアデバッグ機能をサポートすることを目的としています:

4つのハードウェアブレイクポイント (IAC) 2つのハードウェアウォッチポイント (読み取り、書き込みおよび読み取り書き込み) (DAC) 2つの値条件付きハードウェアウォッチポイント (DVC)

そのため、ptraceを拡張してGDBがこれらのリソースを照会・設定できるようにする必要があります。拡張を行うため、BookEとサーバープロセッサ双方をカバーする拡張可能なインターフェースを作成しています。GDBがそれぞれに特殊な処理を加える必要がないようにするためです。以下に3つの新しいptraceリクエストを追加しました。

1. PTRACE_PPC_GETHWDEBUGINFO¶

GDBがハードウェアデバッグ機能を発見するための照会。ここでは主にハードウェアウォッチポイントの最小アライメント情報を返す必要があります。BookEプロセッサはここに制限がありませんが、サーバープロセッサではハードウェアウォッチポイントに8バイトアライメント制限があります。AUXVで見つける内容に基づいてGDBに特殊なケースを追加することを避けたいです。

今回は、カーネルがGDBに返すことができる他の有用な情報を追加しました。この照会はハードウェアブレイクポイントの数、ハードウェアウォッチポイントの数、およびアドレス範囲や条件のサポート状況を返します。照会は要求プロセスが提供した以下の構造体に情報を詰めます:

struct ppc_debug_info {
     unit32_t version;
     unit32_t num_instruction_bps;
     unit32_t num_data_bps;
     unit32_t num_condition_regs;
     unit32_t data_bp_alignment;
     unit32_t sizeof_condition; /* size of the DVC register */
     uint64_t features; /* bitmask of the individual flags */
};

機能にはビットが設定され、サポート状況を示します:

#define PPC_DEBUG_FEATURE_INSN_BP_RANGE               0x1
#define PPC_DEBUG_FEATURE_INSN_BP_MASK                0x2
#define PPC_DEBUG_FEATURE_DATA_BP_RANGE               0x4
#define PPC_DEBUG_FEATURE_DATA_BP_MASK                0x8
#define PPC_DEBUG_FEATURE_DATA_BP_DAWR                0x10
#define PPC_DEBUG_FEATURE_DATA_BP_ARCH_31             0x20

  1. PTRACE_SETHWDEBUG

提供された構造体に基づいてハードウェアブレイクポイントまたはウォッチポイントを設定します:

 struct ppc_hw_breakpoint {
       uint32_t version;
 #define PPC_BREAKPOINT_TRIGGER_EXECUTE  0x1
 #define PPC_BREAKPOINT_TRIGGER_READ     0x2
#define PPC_BREAKPOINT_TRIGGER_WRITE    0x4
       uint32_t trigger_type;       /* only some combinations allowed */
 #define PPC_BREAKPOINT_MODE_EXACT               0x0
 #define PPC_BREAKPOINT_MODE_RANGE_INCLUSIVE     0x1
 #define PPC_BREAKPOINT_MODE_RANGE_EXCLUSIVE     0x2
 #define PPC_BREAKPOINT_MODE_MASK                0x3
       uint32_t addr_mode;          /* address match mode */

 #define PPC_BREAKPOINT_CONDITION_MODE   0x3
 #define PPC_BREAKPOINT_CONDITION_NONE   0x0
 #define PPC_BREAKPOINT_CONDITION_AND    0x1
 #define PPC_BREAKPOINT_CONDITION_EXACT  0x1   /* different name for the same thing as above */
 #define PPC_BREAKPOINT_CONDITION_OR     0x2
 #define PPC_BREAKPOINT_CONDITION_AND_OR 0x3
 #define PPC_BREAKPOINT_CONDITION_BE_ALL 0x00ff0000    /* byte enable bits */
 #define PPC_BREAKPOINT_CONDITION_BE(n)  (1<<((n)+16))
       uint32_t condition_mode;     /* break/watchpoint condition flags */

       uint64_t addr;
       uint64_t addr2;
       uint64_t condition_value;
 };

リクエストは1つのイベントを指定し、必ずしも1つのレジスタを設定する必要はありません。例えば、条件付きウォッチポイントのリクエストでは、DACとDVCレジスタの両方が同じリクエストで設定されます。

これにより、GDBがBookEがサポートするさまざまなハードウェアブレイクポイントとウォッチポイントを問い合わせることができます。サーバープロセッサで利用可能なCOMEFROMブレイクポイントは考慮されていませんが、これはこの作業の範囲外です。

ptraceは作成されたブレイクポイントまたはウォッチポイントを一意に識別する整数（ハンドル）を返します。この整数はPTRACE_DELHWDEBUGリクエストで削除を依頼する際に使用します。レジスタに割り当てられない場合、-ENOSPCを返します。

構造体を用いた使用例:

  • 最初のブレイクポイントレジスタにブレイクポイントを設定:

    p.version         = PPC_DEBUG_CURRENT_VERSION;
p.trigger_type    = PPC_BREAKPOINT_TRIGGER_EXECUTE;
p.addr_mode       = PPC_BREAKPOINT_MODE_EXACT;
p.condition_mode  = PPC_BREAKPOINT_CONDITION_NONE;
p.addr            = (uint64_t) address;
p.addr2           = 0;
p.condition_value = 0;

  • 2番目のウォッチポイントレジスタで読み取り時にトリガーするウォッチポイントを設定:

    p.version         = PPC_DEBUG_CURRENT_VERSION;
p.trigger_type    = PPC_BREAKPOINT_TRIGGER_READ;
p.addr_mode       = PPC_BREAKPOINT_MODE_EXACT;
p.condition_mode  = PPC_BREAKPOINT_CONDITION_NONE;
p.addr            = (uint64_t) address;
p.addr2           = 0;
p.condition_value = 0;

  • 特定の値でのみトリガーするウォッチポイントを設定:

    p.version         = PPC_DEBUG_CURRENT_VERSION;
p.trigger_type    = PPC_BREAKPOINT_TRIGGER_READ;
p.addr_mode       = PPC_BREAKPOINT_MODE_EXACT;
p.condition_mode  = PPC_BREAKPOINT_CONDITION_AND | PPC_BREAKPOINT_CONDITION_BE_ALL;
p.addr            = (uint64_t) address;
p.addr2           = 0;
p.condition_value = (uint64_t) condition;

  • 範囲指定のハードウェアブレイクポイントを設定:

    p.version         = PPC_DEBUG_CURRENT_VERSION;
p.trigger_type    = PPC_BREAKPOINT_TRIGGER_EXECUTE;
p.addr_mode       = PPC_BREAKPOINT_MODE_RANGE_INCLUSIVE;
p.condition_mode  = PPC_BREAKPOINT_CONDITION_NONE;
p.addr            = (uint64_t) begin_range;
p.addr2           = (uint64_t) end_range;
p.condition_value = 0;

  • サーバープロセッサ (BookS) でのウォッチポイントを設定:

    p.version         = 1;
p.trigger_type    = PPC_BREAKPOINT_TRIGGER_RW;
p.addr_mode       = PPC_BREAKPOINT_MODE_RANGE_INCLUSIVE;
or
p.addr_mode       = PPC_BREAKPOINT_MODE_EXACT;

p.condition_mode  = PPC_BREAKPOINT_CONDITION_NONE;
p.addr            = (uint64_t) begin_range;
/* For PPC_BREAKPOINT_MODE_RANGE_INCLUSIVE addr2 needs to be specified, where
 * addr2 - addr <= 8 Bytes.
 */
p.addr2           = (uint64_t) end_range;
p.condition_value = 0;

  1. PTRACE_DELHWDEBUG

既存のブレイクポイントまたはウォッチポイントを識別する整数（つまり、PTRACE_SETHWDEBUGから返された値）を引数として受け取り、該当のブレイクポイントまたはウォッチポイントを削除します。
