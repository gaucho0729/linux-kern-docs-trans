VCPU ディスパッチ統計¶

共有プロセッサLPARの場合、POWERハイパーバイザはLPARプロセッサ（vcpu）を物理プロセッサチップ（「ホームノード」を表す）に相対的に静的なマッピングを維持し、常にvcpuを関連する物理プロセッサチップ上でディスパッチしようとします。ただし、特定のシナリオでは、vcpuがホームノードとは異なるプロセッサチップ上でディスパッチされることがあります。

/proc/powerpc/vcpudispatch_statsは、vcpuディスパッチ動作に関する統計情報を取得するために使用できます。このファイルに'1'を書き込むことで統計情報の収集を有効化し、'0'を書き込むことで無効化します。デフォルトでは、各vcpuのDTLBログを秒あたり50回処理して、エントリを漏らさないようにしています。この処理頻度は/proc/powerpc/vcpudispatch_stats_freqを通じて変更可能です。

統計情報自体は、procfsファイル/proc/powerpc/vcpudispatch_statsを読み込むことで取得できます。出力の各行は、最初のフィールドで表されるvcpuに対応し、その後に8つの数字が続きます。

最初の数字は以下の通りです：

  1. 統計収集開始以来のトータルのVCPUディスパッチ回数

次の4つの数字はVCPUディスパッチの分散を表します：

  1. 前回と同じプロセッサチップ上でディスパッチされた回数

  2. 前回のプロセッサコアとは異なるが、同じチップ内でのディスパッチ回数

  3. 前回のチップとは異なるチップでのディスパッチ回数

  4. 前回のディスパッチとは異なるソケット/ドローイング（次のNUMA境界）でのディスパッチ回数

最後の3つの数字は、vcpuのホームノードに関する統計を表します：

  1. ホームノード（チップ）上でディスパッチされた回数

  2. ホームノードとは異なるノードでのディスパッチ回数

  3. ホームノードより遠いノード（NUMA距離）でのディスパッチ回数

例としての出力:

$ sudo cat /proc/powerpc/vcpudispatch_stats
cpu0 6839 4126 2683 30 0 6821 18 0
cpu1 2515 1274 1229 12 0 2509 6 0
cpu2 2317 1198 1109 10 0 2312 5 0
cpu3 2259 1165 1088 6 0 2256 3 0
cpu4 2205 1143 1056 6 0 2202 3 0
cpu5 2165 1121 1038 6 0 2162 3 0
cpu6 2183 1127 1050 6 0 2180 3 0
cpu7 2193 1133 1052 8 0 2187 6 0
cpu8 2165 1115 1032 18 0 2156 9 0
cpu9 2301 1252 1033 16 0 2293 8 0
cpu10 2197 1138 1041 18 0 2187 10 0
cpu11 2273 1185 1062 26 0 2260 13 0
cpu12 2186 1125 1043 18 0 2177 9 0
cpu13 2161 1115 1030 16 0 2153 8 0
cpu14 2206 1153 1033 20 0 2196 10 0
cpu15 2163 1115 1032 16 0 2155 8 0

上記の出力では、vcpu0に対して統計が有効になった後で6839回のディスパッチが行われました。そのうち4126回は前回と同じ物理CPUでディスパッチされ、2683回は同じチップ内の異なるコアで、30回はチップが異なる場所でディスパッチされました。

また、総計6839回のディスパッチの中から、vcpuのホームノード（チップ）で6821回ディスパッチされ、18回はホームノード外の隣接チップで行われました。
