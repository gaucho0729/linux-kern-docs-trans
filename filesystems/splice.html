pipes API¶

パイプインターフェースはすべてカーネル内（ビルトインイメージ）での使用に限られます。モジュールによる使用にはエクスポートされません。

struct pipe_buffer¶

Linuxカーネルのパイプバッファ

定義

struct pipe_buffer {
  struct page *page;
  unsigned int offset, len;
  const struct pipe_buf_operations *ops;
  unsigned int flags;
  unsigned long private;
};

メンバ

page

パイプバッファのデータを含むページ

offset

データのオフセット（内部の） page

len

データの長さ（内部の） page

ops

このバッファに関連する操作。上記を参照してください。 pipe_buf_operations.

flags

パイプバッファフラグ。上記を参照してください。

private

ops によって所有されるプライベートデータ。
