ISO9660ファイルシステム¶

msdos および vfat パーティションと同じマウントオプションです。

gid=nnn

パーティション内のすべてのファイルはグループ nnnに属する。

uid=nnn

パーティション内のすべてのファイルはユーザーID nnnにより所有される。

umask=nnn

パーティションのパーミッションマスク（umask(1) を参照）

vfat パーティションと同じマウントオプションです。これらは、Microsoft の Joliet 拡張機能でエンコードされたディスクを使用する場合にのみ役立ちます。

iocharset=name

Unicode を ASCII に変換するための文字セット。Joliet ファイル名は Unicode 形式で保存されていますが、Unix は Unicode を扱う方法をほとんど知りません。utf8 オプションを使用して UTF-8 への変換を行うオプションもあります。

utf8

Unicode 名前を UTF-8 形式でエンコードします。デフォルトは no です。

isofs ファイルシステムに特有のマウントオプションです。

block=512

ディスクのブロックサイズを 512 バイトに設定します

block=1024

ディスクのブロックサイズを 1024 バイトに設定します

block=2048

ディスクのブロックサイズを 2048 バイトに設定します

check=relaxed

ファイル名のケースを無視します

check=strict

ファイル名のケースを厳密に一致させます

cruft

不良フォーマットの CD を処理しようとします

map=off

非 Rock Ridge ファイル名を小文字にマッピングしない

map=normal

非 Rock Ridge ファイル名を小文字にマッピングします

map=acorn

map=normal と同じですが、Acorn 拡張機能があれば適用します

mode=xxx

Rock Ridge 拡張機能が設定しない場合、ファイルのパーミッションを xxx に設定します

dmode=xxx

Rock Ridge 拡張機能が設定しない場合、ディレクトリのパーミッションを xxx に設定します

overriderockperm

Rock Ridge 拡張機能が存在しても、mode と dmode でファイルとディレクトリのパーミッションを設定します

nojoliet

Joliet 拡張機能を無視します

norock

Rock Ridge 拡張機能を無視します

hide

隠しファイルを完全に削除します

showassoc

関連付けられたビットでマークされたファイルを表示

非表示を解除

非推奨; 隠しファイルの表示は現在デフォルトになっています。指定された場合、'showassoc' と同義であり、以前の 'unhide' 行為を再現します

session=x (複数セッションCDの場合、セッション番号を指定します)

複数セッションCDの場合、セッション番号を選択します

sbsector=xxx (セッションの開始セクターを指定します)

セッションはセクター xxx から開始します

ISO 9660 標準に関する推奨ドキュメントは以下のURLにあります:

  • http://www.y-adagio.com/

  • ftp://ftp.ecma.ch/ecma-st/Ecma-119.pdf

PDFから引用すると、「この第2版の標準 ECMA-119 は技術的に ISO 9660 と同一です。」ため、公式な ISO 標準の有料代替として有効です
