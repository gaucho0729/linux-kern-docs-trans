Acorn Disc Filing System - ADFS¶

ADFSがサポートするファイルシステム¶

ADFSモジュールは、以下のFilecore形式をサポートしており、これらは以下の特徴を持ちます:

  • 新しいマップ

  • 新しいディレクトリまたは大容量ディレクトリ

名前付き形式に関しては、これは以下の形式をサポートすることを意味します:

  • EおよびE+、ブートブロックありまたはなし

  • FおよびF+

これらファイルシステムからのファイルの読み出しは完全にサポートされており、既存ファイルへの書き込みも可能です。ただし、ファイルシステムのメタデータの変更はサポートしていません。

これはRISC OS Filecoreファイルシステム上にループバックマウントされたLinuxネイティブファイルシステムをサポートするためのものですが、ファイル内のデータの変更は可能です。

書き込みサポート（ADFS_FS_RW）が設定されている場合、ディレクトリの基本的な更新を許可します。具体的には、アクセスモードとタイムスタンプの更新です。

ADFSのマウントオプション¶

uid=nnn

パーティション内のすべてのファイルはユーザーID nnnに所有されます。デフォルトは0（root）です。

gid=nnn

パーティション内のすべてのファイルはグループID nnnに所属します。デフォルトは0（root）です。

ownmask=nnn

ADFSの「所有者」権限のパーミッションマスクはnnnです。デフォルトは0700です。

othmask=nnn

ADFSの「他者」権限のパーミッションマスクはnnnです。デフォルトは0077です。

ftsuffix=n

ftsuffix=0の場合はファイルタイプサフィックスが適用されません。ftsuffix=1の場合はRISC OSファイルタイプに応じた16進数のサフィックスが追加されます。デフォルトは0です。

ADFS権限とLinux権限のマッピング¶

ADFS権限は以下の要素から構成されます:

  • 所有者読み取り

  • 所有者書き込み

  • 他者読み取り

  • 他者書き込み

(古いバージョンでは「実行」権限が存在しましたが、これはLinuxの「実行」権限とは意味が異なり、現在は非推奨です）。

マッピングは以下の通り行われます:

    Owner read                              -> -r--r--r--
    Owner write                             -> --w--w---w
    Owner read and filetype UnixExec        -> ---x--x--x
These are then masked by ownmask, eg 700    -> -rwx------
    Possible owner mode permissions         -> -rwx------

    Other read                              -> -r--r--r--
    Other write                             -> --w--w--w-
    Other read and filetype UnixExec        -> ---x--x--x
These are then masked by othmask, eg 077    -> ----rwxrwx
    Possible other mode permissions         -> ----rwxrwx

したがって、デフォルトのマスクでは、ファイルが所有者読み取り/書き込みであり、UnixExecファイルタイプでない場合、権限は以下のようになります:

-rw-------

ただし、ownmask=0770、othmask=0007のマスクを設定した場合、以下のようになります:

-rw-rw----

これらのマスクで何をすることも可能です。すべてのユーザーに読み取りアクセスを許可したいが、デフォルトの書き込み保護を維持したい場合は（ownmask=0755、othmask=0577）:

-rw-r--r--

したがって、Linuxにおいて希望する権限に応じて、権限の翻訳をカスタマイズすることが可能です。

RISC OSファイルタイプサフィックス¶

RISC OSファイルタイプは、ファイルロードアドレスのビット19..8に格納されます。

非RISC OSシステムでもファイルタイプ情報を失うことなくファイルを保存できるようにするため、NFSで使用するためのファイル名規則が考案されました。この規則では、ファイルタイプを表す16進数のサフィックス（例: BasicFile,ffb は BASIC（0xffb）ファイル）が使用されます。この命名規則は現在、RPCEmuなどのRISC OSエミュレータでも使用されています。

ADFSディスクをマウントする際、ftsuffix=1 オプションを指定すると、ディレクトリから読み取ったファイル名に適切なファイルタイプサフィックスが追加されます。ftsuffixオプションが0または省略されている場合、ファイルタイプサフィックスは追加されません。
