このドライバとは何ですか？¶

このモジュールはBeOSのネイティブファイルシステムを実装しています http://www.beincorporated.com/ linux 2.4.1以降のカーネル向けに作成され、現在は読み取り専用の実装です。

BFSかBEFSのどちらですか？¶

Be, Incは、「BeOS Filesystemは公式にはBFSと呼ばれ、BeFSではありません」と述べています。しかしUnixware Boot Filesystemもbfsと呼ばれており、すでにカーネルに組み込まれています。この名前衝突のため、LinuxではBeOSファイルシステムはbefsと呼ばれます。

インストール方法¶

ステップ1. BeFSパッチをLinuxのソースコードツリーにインストールします。

パッチファイルをカーネルソースツリーに適用してください。カーネルソースが/foo/bar/linuxにあり、パッチファイルがpatch-befs-xxxと呼ばれていると仮定すると、以下のようにします:

cd /foo/bar/linux patch -p1 < /path/to/patch-befs-xxx

パッチ適用が失敗した場合（つまり、拒否されたhunkがある場合）、自分で解決しようと試みてください（これは難しいとは思われません）、またはメンテナ（Will Dyson <will_dyson@pobox.com>) にメールでご相談ください。

ステップ2. 設定とカーネルのビルド

Linuxカーネルには多くのコンパイル時オプションがあります。これらの大半はこのドキュメントの範囲外です。Kernel-HOWTOドキュメントを参考にしてください。 http://www.linuxdocs.org/HOWTOs/Kernel-HOWTO-4.html

ただし、BeFSモジュールを使用するには、コンフィギュレーション時に有効にする必要があります:

cd /foo/bar/linux
make menuconfig (or xconfig)

BeFSモジュールはLinuxカーネルの標準的な一部ではありません。そのため、まず「コードの熟度レベル」メニューで実験的コードのサポートを有効にする必要があります。

その後、「ファイルシステム」メニューで「BeFSファイルシステム（実験的）」というオプションが表示されます。このオプションを有効にしてください（モジュールとして作成しても問題ありません）。

カーネルのコンフィギュレーションを保存し、その後カーネルをビルドします。

ステップ3. インストール

カーネルのHOWTO <http://www.linux.com/howto/Kernel-HOWTO.html> を参照してください。

BFSの使用方法¶

BeOSファイルシステムを使用するには、ファイルシステムタイプを‘befs’に設定してください。

例:

mount -t befs /dev/fd0 /beos

マウントオプション¶

uid=nnn

パーティション内のすべてのファイルはユーザーID nnnにより所有される。

gid=nnn

パーティション内のすべてのファイルはグループ nnnに属する。

iocharset=xxx

NLS翻訳テーブルの名前としてxxxを使用する。

debug

ドライバーはsyslogにデバッグ情報を出力します。
