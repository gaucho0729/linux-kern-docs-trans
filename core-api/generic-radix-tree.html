汎用的な radix tree / 稀疏配列¶

非常にシンプルで最小限の設計で、PAGE_SIZE までの任意のサイズのエントリをサポートしています。

genradix は、保存する型を指定して定義します。以下のようにします：

static GENRADIX(struct foo) foo_genradix;

主な操作は以下の通りです：

  • genradix_init(radix) - 空の genradix を初期化する

  • genradix_free(radix) - genradix が所有するメモリを解放し、再初期化する

  • genradix_ptr(radix, idx) - idx のエントリへのポインタを取得し、存在しない場合は NULL を返す

  • genradix_ptr_alloc(radix, idx, gfp) - idx のエントリへのポインタを取得し、必要に応じて割り当てる

  • genradix_for_each(radix, iter, p) - genradix 内のすべてのエントリを反復処理する

radix tree は一度に1ページのエントリを割り当てるので、明示的に割り当てられなかったエントリも存在する可能性があります。これらはすべてゼロで初期化されます。

内部的には、genradix はページの radix tree であり、インデックスはバイトオフセットで動作します。このヘッダーファイルのラッパーは、radix が含む型の sizeof を使ってインデックスからバイトオフセットを計算します - __idx_to_offset を参照してください。
