printkを使用したメッセージログ¶

printk() Linuxカーネルで最もよく知られている関数の一つです。メッセージを印刷する標準的なツールで、トレースやデバッグの基本的な方法として通常使用されます。printf(3)に familier であれば理解できるでしょう printk() printf(3)に基づいていますが、いくつか機能的な違いがあります:

  • printk() メッセージはログレベルを指定できます。

  • フォーマット文字列はC99とほぼ互換性がありますが、正確な仕様に従っていません。いくつか拡張があり、制限もあります（変数や浮動小数点の変換指定子はサポートされません）。詳しくは %n メッセージはカーネルログバッファに印刷されます。これは/userspaceにエクスポートされるリングバッファで、/dev/kmsgを通じてアクセスできます。通常は printkのフォーマット指定子を正しく使用する方法.

すべて printk() で読み取るのが一般的です。 dmesg.

printk() は通常次のように使用されます:

printk(KERN_INFO "Message: %s\n", arg);

オプションを指定する必要があります。形式は以下の通りです： KERN_INFO ログレベル（注意：これはフォーマット文字列に連結されるため、別な引数ではありません）。利用可能なログレベルは以下の通りです:

ログレベルはメッセージの重要度を示します。カーネルはログレベルと現在の console_loglevel (カーネル変数)に基づいてメッセージを即座に表示するかどうかを決定します。メッセージの優先度がより高い（ログレベル値が小さい）場合、 console_loglevel メッセージがコンソールに表示されます。

ログレベルが省略されている場合、メッセージは KERN_DEFAULT レベルで印刷されます。

現在の console_loglevel 以下のように変更してください：

$ cat /proc/sys/kernel/printk
4        4        1        7

を確認できます。 現在の, デフォルト, 最小値 および ブートタイムデフォルト ログレベルを表示します。

現在のコンソールログレベルを変更するには、望むレベルを /proc/sys/kernel/printkに書き込みます。例えば、すべてのメッセージをコンソールに表示するには:

# echo 8 > /proc/sys/kernel/printk

別の方法として、 dmesg:

# dmesg -n 5

を使用してコンソールログレベルを設定します。KERN_WARNING (4) やより深刻なメッセージをコンソールに表示します。詳しくは dmesg(1) 詳しくは

の代わりに printk() を使用できます。このロギング用のマクロ群はマクロ名にログレベルを埋め込んでいます。例えば: pr_*() は

pr_info("Info message no. %d\n", msg_num);

を印刷します KERN_INFO メッセージ。

同等の呼び出しよりもコンパクトで、フォーマット文字列の共通定義をマクロを通じて使用できます。 printk() また、フォーマット文字列を共通の定義で使用できるため、 pr_fmt() マクロを通じて、ソースファイルの先頭（任意のディレクティブの前に）でこの定義を追加する場合、 #include そのファイル内のすべてのpr_*()メッセージに、メッセージを生成したモジュールと関数名をプレフィックスとして追加します。

#define pr_fmt(fmt) "%s:%s: " fmt, KBUILD_MODNAME, __func__

デバッグ目的には、2つの条件付きコンパイルマクロもあります：

これらは、 pr_debug() および pr_devel()が定義されている場合にのみコンパイルされます。 DEBUG （または CONFIG_DYNAMIC_DEBUG の場合にも） pr_debug()が定義されている場合にのみコンパイルされます。

__visible int printk(const char *fmt, ...)¶

カーネルメッセージを出力する

パラメータ

const char *fmt

フォーマット文字列

...

可変引数

説明

これは printk()です。任意のコンテキストから呼び出すことができます。動作を確認したいです。

コンソールロックを取得しようとします。成功すれば、出力をログに記録しコンソールドライバを呼び出すだけです。セマフォの取得に失敗した場合は、出力をログバッファに保存して戻ります。コンソールセマフォを保持している現在の所有者は、 console_unlock()で新しい出力を認識し、ロックを解放する前にコンソールに送信します。

この遅延出力の効果として、 printk() を呼び出し、その後console_loglevelを変更するコードが破損する可能性があります。これは、実際の出力が発生する際にconsole_loglevelが確認されるためです。

pr_fmt¶

pr_fmt (fmt)

pr_*()マクロから渡されたフォーマット文字列

説明

#define pr_fmt(fmt) KBUILD_MODNAME "": "" fmt
