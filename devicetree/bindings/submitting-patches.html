devicetree (DT)バインディングのパッチを送信する¶

I. パッチ送信者向け¶

  1. 通常のパッチ送信ルールは以下の通りです。 パッチの送信: コードをカーネルに取り込むためのエッセンシャルガイド 適用されます。

  2. パッチのDocumentation/およびinclude/dt-bindings/部分は別個のパッチとして提出する必要があります。バインディングパッチの推奨されたサブジェクトプレフィックスは次の通りです：

    "dt-bindings: <binding dir>: ..."

    サブジェクトの80文字は貴重です。'Documentation'や'doc'はすでに含まれているため、使用を避けることが推奨されます。すべてのバインディングはドキュメンテーションです。'binding'を繰り返すことも避けてください。

  3. DTバインディングファイルは、json-schema語彙を使用したDTスキーマ形式とYAMLファイル形式で記述されます。DTバインディングファイルは、以下のコマンドを実行して検証を通過する必要があります：

    make dt_binding_check

    スキーマおよびツールの設定に関する詳細は、../writing-schema.rstを参照してください。

  4. DTバインディングファイルは二重ライセンスで提供する必要があります。推奨されるライセンスタグは (GPL-2.0-only OR BSD-2-Clause) です。

  5. すべてのシリーズをdevicetreeメールリストに送信してください

    devicetree@vger.kernel.org

    Cc: DTメンテナにも送信してください。DTメンテナを特定するには、scripts/get_maintainer.plスクリプトを使用してください。

  6. パッチのDocumentation/部分は、バインディングを実装するコードよりもシリーズ内で先に配置する必要があります。

  7. チップまたはボードDTSファイルで使用されるすべての互換性文字列は、Documentation/devicetree/bindingsにある対応するDTバインディングテキストファイルで事前にドキュメンテーションされる必要があります。このルールは、Linuxデバイスドライバがまだ互換性文字列にマッチしていない場合でも適用されます。[commit bff5da4335256513497cc8c79f9a9d1665e09864（「checkpatch: add DT compatible string documentation checks」）以降、このステップを実施しない場合、checkpatchは警告を発します。]

  8. ワイルドカード「<chip>」は、互換性文字列に使用できます。次の例のように：

    • compatible: 「nvidia,<chip>-pcie」、「nvidia,tegra20-pcie」を含む必要があります。ここで<chip>はtegra30、tegra132、…です。

    上記の例のように、<chip>が使用される場合、その既知の値はドキュメンテーションされる必要があります。

  9. ドキュメンテーションされた互換性文字列がまだドライバによってマッチされていない場合、ドキュメンテーションにもドライバによってマッチされる互換性文字列を含める必要があります（上記の「nvidia,tegra20-pcie」例のように）。

II. カーネルメンテナ向け¶

  1. 特定のバインディングをレビューするのが不確実な場合は、そのパッチに返信し、devicetreeメンテナにアドバイスを依頼してください。これにより、彼らがどのバインディングをレビューすべきか、どのバインディングは放置しても良いかを優先順位付けやすくなります。

  2. ドライバ（サブシステムではない）バインディングの場合：バインディングに自信がある場合、かつ数週間経ってもdevicetreeメンテナからAcked-byが届いていない場合は、そのまま採用してください。

    サブシステムバインディング（複数のデバイスに影響を与えるもの）については、devicetreeメンテナによるレビューが必要です。

  3. 複数のツリーを経るシリーズでは、バインディングのパッチをそのバインディングを使用するドライバと一緒におさめてください。

III. 注意事項¶

  1. devicetree ABIに関する詳細は、…bindings/ABI.txtを参照してください。

  2. このドキュメントは、2013年のカーネルサミットで決定されたプロセスの一般的な紹介を目的としています。疑問がある場合は、現在のdevicetreeメンテナの意見がこのドキュメントを上書きします。その場合、このドキュメントを更新するパッチを送信していただけますか。
