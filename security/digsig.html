デジタル署名検証API¶

著者

Dmitry Kasatkin

日付

06.10.2011

はじめに¶

デジタル署名検証APIは、デジタル署名を検証する方法を提供します。現在、デジタル署名はIMA/EVMの整合性保護サブシステムで使用されています。

デジタル署名検証は、GnuPGのマルチ精度整数（MPI）ライブラリのカットダウン版をLinuxカーネルに移植した実装を用いています。カーネル移植版はメモリ割当エラーの処理を提供し、カーネルのコーディングスタイルに再構築されており、checkpatch.plが報告したエラーおよび警告も修正されています。

公開鍵および署名はヘッダーとMPIから構成されています：

struct pubkey_hdr {
        uint8_t         version;        /* key format version */
        time_t          timestamp;      /* key made, always 0 for now */
        uint8_t         algo;
        uint8_t         nmpi;
        char            mpi[0];
} __packed;

struct signature_hdr {
        uint8_t         version;        /* signature format version */
        time_t          timestamp;      /* signature made */
        uint8_t         algo;
        uint8_t         hash;
        uint8_t         keyid[8];
        uint8_t         nmpi;
        char            mpi[0];
} __packed;

keyidは、全体の鍵コンテンツのSHA1[12-19]に基づいています。署名ヘッダーは署名生成の入力として使用され、このようなアプローチにより、鍵または署名ヘッダーが変更できないようにし、タイムスタンプの変更を防ぎ、ロールバック保護として利用できます。

API¶

APIは現在、1つの関数のみを含んでいます：

digsig_verify() - digital signature verification with public key


/**
* digsig_verify() - digital signature verification with public key
* @keyring:     keyring to search key in
* @sig: digital signature
* @sigen:       length of the signature
* @data:        data
* @datalen:     length of the data
* @return:      0 on success, -EINVAL otherwise
*
* Verifies data integrity against digital signature.
* Currently only RSA is supported.
* Normally hash of the content is used as a data for this function.
*
*/
int digsig_verify(struct key *keyring, const char *sig, int siglen,
                  const char *data, int datalen);

ユーザー空間ユーティリティ¶

署名および鍵管理ユーティリティevm-utilsは、署名の生成および鍵をカーネルのキー輪にロードする機能を提供します。鍵はPEM形式か、カーネル形式に変換できます。鍵がカーネルキー輪に追加されると、keyidが鍵の名前を定義します。下記の例では、5D2B05FC633EE3E8が使用されます。
