eCryptfs ファイルシステム用の暗号化キー¶

ECryptfsは、ランダムに生成されたファイル暗号化キー（FEK）を使用して、各ファイルを透明に暗号化および復号するスタック型ファイルシステムです。

各FEKは、ファイル暗号化キー暗号化キー（FEKEK）で暗号化され、カーネル空間またはユーザー空間で実行されます。後者は「ecryptfsd」と呼ばれるデーモンを使用して外部ライブラリを介して実行され、公開鍵暗号、PKCS#11、TPMベースの操作などの他のメカニズムをサポートします。

eCryptfsが定義するFEK復号に必要な情報を含むデータ構造は「認証トークン」と呼ばれ、現在は「user」タイプのカーネルキーに保存され、ユーザーのセッション固有のキーリングに「mount.ecryptfs」というユーザー空間ユーティリティで挿入されます。

「encrypted」キー型は、新しい形式「ecryptfs」の導入により拡張され、eCryptfsファイルシステムと併用されるようになりました。新たに導入された形式の暗号化されたキーは、カーネルがランダムに生成したFEKEKで保護された認証トークンをペイロードに保存します。

知られている平文攻撃を回避するため、「keyctl print」または「keyctl pipe」コマンドで取得したデータブロブには、内容がよく知られている認証トークン全体は含まれず、暗号化されたFEKEKのみが含まれます。

eCryptfsファイルシステムは暗号化されたキーの使用により、管理者がセキュアに生成したキーをブート時に「信頼された」キーの復封後に提供することで制御された環境でのマウントが可能になります。また、キーリングレベルでのみ明文形式で利用されるため、マルウェアへの暴露がありません。

使用方法:

keyctl add encrypted name "new ecryptfs key-type:master-key-name keylen" ring
keyctl add encrypted name "load hex_blob" ring
keyctl update keyid "update key-type:master-key-name"

以下では:

name:= '<16 hexadecimal characters>'
key-type:= 'trusted' | 'user'
keylen:= 64

eCryptfsファイルシステムでの暗号化されたキーの使用例:

形式「ecryptfs」で長さ64バイトの暗号化されたキー「1000100010001000」を作成し、事前にロードされたユーザーキー「test」で保存する:

$ keyctl add encrypted 1000100010001000 "new ecryptfs user:test 64" @u
19184530

$ keyctl print 19184530
ecryptfs user:test 64 490045d4bfe48c99f0d465fbbbb79e7500da954178e2de0697
dd85091f5450a0511219e9f7cd70dcd498038181466f78ac8d4c19504fcc72402bfc41c2
f253a41b7507ccaa4b2b03fff19a69d1cc0b16e71746473f023a95488b6edfd86f7fdd40
9d292e4bacded1258880122dd553a661

$ keyctl pipe 19184530 > ecryptfs.blob

作成した暗号化されたキー「1000100010001000」でeCryptfsファイルシステムを「/secret」ディレクトリにマウントする:

$ mount -i -t ecryptfs -oecryptfs_sig=1000100010001000,\
  ecryptfs_cipher=aes,ecryptfs_key_bytes=32 /secret /secret
