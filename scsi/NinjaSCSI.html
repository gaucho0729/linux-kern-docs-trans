ワークビット NinjaSCSI-3/32Bi ドライバ for Linux¶

1. コメント¶

これは Workbit corp. の(http://www.workbit.co.jp/) NinjaSCSI-3 for Linux。

2. 私の Linux 環境¶

Linux カーネル

2.4.7 / 2.2.19

pcmcia-cs

3.1.27

gcc

gcc-2.95.4

PC カード

I-O data PCSC-F (NinjaSCSI-3), I-O data CBSC-II 16 ビットモード (NinjaSCSI-32Bi)

SCSIデバイス

I-O data CDPS-PX24 (CD-ROM ドライブ), Media Intelligent MMO-640GT (光学ディスクドライブ)

3. インストール¶

  1. PC カードが真の「NinjaSCSI-3」カードであることを確認してください。

    pcmcia-cs をすでにインストールしている場合、pcmcia はカードを UNKNOWN カードとして報告し、コンソールまたはログファイルに [「WBT」, 「NinjaSCSI-3」, 「R1.0」] などの文字列を書き込みます。

    「cardctl」プログラム（このプログラムは pcmcia-cs ソースコードに含まれます）を使用して、より多くの情報を取得することもできます。

    # cat /var/log/messages
...
Jan  2 03:45:06 lindberg cardmgr[78]: unsupported card in socket 1
Jan  2 03:45:06 lindberg cardmgr[78]:   product info: "WBT", "NinjaSCSI-3", "R1.0"
...
# cardctl ident
Socket 0:
  no product info available
Socket 1:
  product info: "IO DATA", "CBSC16       ", "1"

  2. Linux カーネルソースを取得し、/usr/src に展開してください。NinjaSCSI ドライバは Linux カーネルソース内の SCSI ヘッダーファイルが必要なので、カーネルを再構築することをお勧めします。これにより、バージョン管理の問題を回避できます。

    $ cd /usr/src
$ tar -zxvf linux-x.x.x.tar.gz
$ cd linux
$ make config
...

  3. Kernel 2.2 でこのドライバを使用する場合、pcmcia-cs をあるディレクトリに展開し、make と install を実行してください。このドライバは pcmcia-cs ヘッダーファイルを必要とします。

    $ cd /usr/src
$ tar zxvf cs-pcmcia-cs-3.x.x.tar.gz
...

  4. このドライバのアーカイブをどこかに展開し、Makefile を編集した後、make を実行してください：

    $ tar -zxvf nsp_cs-x.x.tar.gz
$ cd nsp_cs-x.x
$ emacs Makefile
...
$ make

  5. nsp_cs.ko を適切な場所（例：/lib/modules/<Kernel バージョン>/pcmcia/）にコピーしてください。

  6. /etc/pcmcia/config に次の行を追加してください。

    pcmcia-cs-3.1.8 またはそれ以降を使用する場合、nsp_cs.conf ファイルを使用できます。したがって、ファイルを編集する必要はありません。単に /etc/pcmcia/ にコピーしてください。

    device "nsp_cs"
  class "scsi" module "nsp_cs"

card "WorkBit NinjaSCSI-3"
  version "WBT", "NinjaSCSI-3", "R1.0"
  bind "nsp_cs"

card "WorkBit NinjaSCSI-32Bi (16bit)"
  version "WORKBIT", "UltraNinja-16", "1"
  bind "nsp_cs"

# OEM
card "WorkBit NinjaSCSI-32Bi (16bit) / IO-DATA"
  version "IO DATA", "CBSC16       ", "1"
  bind "nsp_cs"

# OEM
card "WorkBit NinjaSCSI-32Bi (16bit) / KME-1"
  version "KME    ", "SCSI-CARD-001", "1"
  bind "nsp_cs"
card "WorkBit NinjaSCSI-32Bi (16bit) / KME-2"
  version "KME    ", "SCSI-CARD-002", "1"
  bind "nsp_cs"
card "WorkBit NinjaSCSI-32Bi (16bit) / KME-3"
  version "KME    ", "SCSI-CARD-003", "1"
  bind "nsp_cs"
card "WorkBit NinjaSCSI-32Bi (16bit) / KME-4"
  version "KME    ", "SCSI-CARD-004", "1"
  bind "nsp_cs"

  1. pcmcia-cs を開始（または再起動）してください：

    # /etc/rc.d/rc.pcmcia start        (BSD style)

    または:

    # /etc/init.d/pcmcia start         (SYSV style)

4. 歴史¶

README.nin_cs を参照してください。

5. 注意¶

SCSI デバイスの操作中やコンピュータをサスペンド中にカードを挿抜すると、 BAD のようなディスククラッシュなどのエラーが発生する可能性があります。

このドライバを正しく使用すれば問題なく動作しますが、データの安全性は保証できません。このドライバを使用する際は、データのバックアップを必ず行ってください。

6. 既知のバグ¶

2.4 カーネルでは 640MB の光学ディスクを使用できません。このエラーは上位 SCSI ドライバから発生します。

7. テスト¶

このソフトウェアの報告（バグ報告など）を送ってください。報告を送る際は、以下の情報を教えてください：

  • カード名

  • カーネルバージョン

  • SCSI デバイス名（ハードディスク、CD-ROM など）
