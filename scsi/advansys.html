AdvanSysドライバノート¶

AdvanSys（Advanced System Products, Inc.）は、ISA、EISA、VL、PCIバスおよびPCIバス用のRISCベースのバスマスター型SCSIホストアダプターを製造しています。このアダプターは、Fast（10 MHz）およびUltra（20 MHz）のNarrow（8ビット転送）SCSIホストアダプターと、Ultra（20 MHz）のWide（16ビット転送）SCSIホストアダプターです。

以下のCDBカウントは、RISCチップキャッシュおよびボードのLRAMに保存可能なSCSI CDB（コマンドディスクリプタブロック）リクエストの数を示しています。CDBは単一のSCSIコマンドを指します。ドライバの検出ルーチンは、検出された各アダプターごとに利用可能なCDB数を表示します。ドライバが使用するCDB数は、BIOSで「ホストキュー サイズ」アダプター設定を変更することで減らすことができます。

ドライバのコンパイル時オプションとデバッグ¶

ソースファイルで次の定数を定義できます。

  1. ADVANSYS_ASSERT - ドライバのアサーションを有効にする (デフォルト: 有効)

    このオプションを有効にすると、ドライバにアサーション論理ステートメントが追加されます。アサーションが失敗した場合、コンソールにメッセージが表示されますが、システムは継続して動作します。アサーションが発生した場合は、ドライバを担当する人に報告してください。アサーションステートメントはドライバの問題を積極的に検出し、それらの問題を修正するのに役立ちます。アサーションを有効にすると、ドライバの実行に小さなオーバーヘッドが追加されます。

  2. ADVANSYS_DEBUG - ドライバのデバッグを有効にする (デフォルト: 無効)

    このオプションを有効にすると、ドライバにトレース機能が追加され、起動時にドライバのトレースレベルを設定できるようになります。このオプションはドライバのデバッグに非常に役立ちますが、ドライバ実行イメージのサイズを大きくし、実行にオーバーヘッドを追加します。

    デバッグ出力量はグローバル変数 'asc_dbglvl' で制御できます。数字が大きいほど出力量が増えます。デフォルトではデバッグレベルが 0 です。

    ドライバが起動時にロードされ、システムに LILO ドライバオプションが含まれている場合、5番目の (ASC_NUM_IOPORT_PROBE + 1) I/O ポートを指定することでデバッグレベルを変更できます。擬似I/Oポートの最初の3つの16進数字を 'deb' に設定し、4番目の16進数字でデバッグレベル (0 - F) を指定します。次のコマンドラインは、0x330 にアダプターを検索し、デバッグレベルを 2 に設定します:

    linux advansys=0x330,0,0,0,0xdeb2

    ドライバがロード可能なモジュールとしてビルドされている場合、ドライバをロード時にこの変数を定義できます。次の insmod コマンドでデバッグレベルを 1 に設定します:

    insmod advansys.o asc_dbglvl=1

    デバッグメッセージレベル:

    0

    エラーメッセージのみ

    1

    ハイレベルトレース

    2-N

    詳細トレース

    コンソールにデバッグ出力を有効にするには、以下の点を確認してください:

    1. システムおよびカーネルログが有効になっている (syslogd, klogd が実行中)

    2. カーネルメッセージがコンソール出力にルーティングされている。/etc/syslog.conf に以下の記述があるか確認してください:

      kern.*                  /dev/console

    3. klogd は適切な -c パラメータで起動されている (例: klogd -c 8)

    これにより printk() 現在のコンソールにメッセージが表示されます。詳細は klogd(8) および syslogd(8) の man ページを参照してください。

    代替として、このプログラムを使用して printk() コンソールに有効にすることができます。ただし、これは「公式」な方法ではありません。

    デバッグ出力は /var/log/messages にログ出力されます。

    main()
{
        syscall(103, 7, 0, 0);
}

    kernel/printk.cのLOG_BUF_LENを40960などに増やすことで、カーネル内でバッファリングされるデバッグメッセージの量を増やし、コンソールやログファイルに書き出すことが可能になります。

  3. ADVANSYS_STATS - 統計情報の収集を有効にする（デフォルト: 有効）

    このオプションを有効にすると、/procを通じてドライバの統計情報の収集と表示が可能になります。この情報はドライバおよびデバイスのパフォーマンスのモニタリングに役立ちます。ただし、ドライバの実行イメージサイズが増加し、ドライバの実行に若干のオーバーヘッドが生じます。

    統計情報はアダプターごとに維持され、ドライバのエントリポイント呼び出し回数や転送サイズのカウントが記録されます。統計情報はv1.3.0以上かつCONFIG_PROC_FS (/proc) ファイルシステムが構成されているカーネルでのみ利用可能です。

    AdvanSys SCSIアダプターファイルのパス名形式は以下の通りです：

    /proc/scsi/advansys/{0,1,2,3,...}

    この情報はcatコマンドで表示できます。例えば：

    cat /proc/scsi/advansys/0

    ADVANSYS_STATSが定義されていない場合、AdvanSysの/procファイルにはアダプターやデバイスの設定情報のみが含まれます。

ドライバ LILO オプション¶

init/main.cを「AdvanSysドライバをLinuxに追加する方法」（B.4.）セクションに記載されている通りに変更した場合、ドライバは「advansys」LILOコマンドラインおよび/etc/lilo.confオプションを認識します。このオプションはISAおよびVLボードのI/Oポートスキャンを無効化するか、1〜4ポートまで制限するのに使用できます。オプションの設定に関係なく、EISAおよびPCIボードは検出されます。このオプションはISAおよびVLボードの検出にのみ影響します。

例:

  1. I/Oポートスキャンを無効化する：

    boot:

    linux advansys=

    または:

    boot: linux advansys=0x0

  2. I/Oポートスキャンを1ポートまで制限する：

    boot:

    linux advansys=0x110

  3. I/Oポートスキャンを4ポートまで制限する：

    boot:

    linux advansys=0x110,0x210,0x230,0x330

ロード可能なモジュールの場合、ドライバをロードする際に'asc_iopflag'変数と'asc_ioport'配列を設定することで同じ効果を得られます。例えば：

insmod advansys.o asc_iopflag=1 asc_ioport=0x110,0x330

ADVANSYS_DEBUGが定義されている場合、5番目の（ASC_NUM_IOPORT_PROBE + 1）I/Oポートが追加され、ドライバのデバッグレベルを指定できます。詳細は上記の「ドライバコンパイル時のオプションとデバッグ」セクションを参照してください。
