VIA インテグレーション グラフィックチップ コンソール フレームバッファドライバー¶

プラットフォーム¶

コンソールフレームバッファドライバーは、VIA ユニクロームファミリー（CLE266、PM800 / CN400 / CN300、P4M800CE / P4M800Pro / CN700 / VN800、CX700 / VX700、K8M890、P4M890、CN896 / P4M900、VX800、VX855）のグラフィックチップ用です

ドライバの特徴¶

デバイス: CRT、LCD、DVI

viafb_mode のサポート:

CRT:
    640x480(60, 75, 85, 100, 120 Hz), 720x480(60 Hz),
    720x576(60 Hz), 800x600(60, 75, 85, 100, 120 Hz),
    848x480(60 Hz), 856x480(60 Hz), 1024x512(60 Hz),
    1024x768(60, 75, 85, 100 Hz), 1152x864(75 Hz),
    1280x768(60 Hz), 1280x960(60 Hz), 1280x1024(60, 75, 85 Hz),
    1440x1050(60 Hz), 1600x1200(60, 75 Hz), 1280x720(60 Hz),
    1920x1080(60 Hz), 1400x1050(60 Hz), 800x480(60 Hz)

カラーデプス: 8 bpp、16 bpp、32 bpp のサポート。

2D ハードウェアアクセラレータのサポート。

viafb モジュールの使用¶

デフォルト設定で viafb を起動:

#modprobe viafb

ユーザー設定で viafb を起動:

#modprobe viafb viafb_mode=800x600 viafb_bpp=16 viafb_refresh=60
          viafb_active_dev=CRT+DVI viafb_dvi_port=DVP1
          viafb_mode1=1024x768 viafb_bpp=16 viafb_refresh1=60
          viafb_SAMM_ON=1
viafb_mode:

  • 640x480（デフォルト）

  • 720x480

  • 800x600

  • 1024x768

viafb_bpp:

  • 8、16、32（デフォルト:32）

viafb_refresh:

  • 60、75、85、100、120（デフォルト:60）

viafb_lcd_dsp_method:

  • 0: 拡張（デフォルト）

  • 1: 中心合わせ

viafb_lcd_mode:

0: LSB データ形式入力の LCD パネル（デフォルト） 1: MSB データ形式入力の LCD パネル

viafb_lcd_panel_id:

  • 0: 解像度: 640x480、チャネル: シングル、ディザリング: 有効

  • 1: 解像度: 800x600、チャネル: シングル、ディザリング: 有効

  • 2: 解像度: 1024x768、チャネル: シングル、ディザリング: 有効（デフォルト）

  • 3: 解像度: 1280x768、チャネル: シングル、ディザリング: 有効

  • 4: 解像度: 1280x1024、チャネル: ダブル、ディザリング: 有効

  • 5: 解像度: 1400x1050、チャネル: ダブル、ディザリング: 有効

  • 6: 解像度: 1600x1200、チャネル: ダブル、ディザリング: 有効

  • 8: 解像度: 800x480、チャネル: シングル、ディザリング: 有効

  • 9: 解像度: 1024x768、チャネル: ダブル、ディザリング: 有効

  • 10: 解像度: 1024x768、チャネル: シングル、ディザリング: 無効

  • 11: 解像度: 1024x768、チャネル: ダブル、ディザリング: 無効

  • 12: 解像度: 1280x768、チャネル: シングル、ディザリング: 無効

  • 13: 解像度: 1280x1024、チャネル: ダブル、ディザリング: 無効

  • 14: 解像度: 1400x1050、チャネル: ダブル、ディザリング: 無効

  • 15: 解像度: 1600x1200、チャネル: ダブル、ディザリング: 無効

  • 16: 解像度: 1366x768、チャネル: シングル、ディザリング: 無効

  • 17: 解像度: 1024x600、チャネル: シングル、ディザリング: 有効

  • 18: 解像度: 1280x768, チャネル: デュアル, ディザリング: 有効

  • 19: 解像度: 1280x800, チャネル: シングル, ディザリング: 有効

viafb_accel:

  • 0 : 2Dハードウェアアクセラレーションなし

  • 1 : 2Dハードウェアアクセラレーション (デフォルト)

viafb_SAMM_ON:

  • 0 : viafb_SAMM_ON 無効 (デフォルト)

  • 1 : viafb_SAMM_ON 有効

viafb_mode1: (セカンドディスプレイデバイス)

  • 640x480（デフォルト）

  • 720x480

  • 800x600

  • 1024x768

viafb_bpp1: (セカンドディスプレイデバイス)

  • 8、16、32（デフォルト:32）

viafb_refresh1: (セカンドディスプレイデバイス)

  • 60、75、85、100、120（デフォルト:60）

viafb_active_dev:

このオプションはアクティブなデバイスを指定するために使用されます。(CRT, DVI, CRT+LCD…) DVIはDVIまたはHDMIを指します。例として、HDMIを有効にする場合はviafb_active_dev=DVIと設定してください。SAMMの場合、viafb_active_devの前の値がプライマリデバイス、後の値がセカンドデバイスとなります。

例:

DVIのみを有効にする場合は以下のようになります:

modprobe viafb viafb_active_dev=DVI

CRT+DVIを有効にする場合は以下のようになります:

modprobe viafb viafb_active_dev=CRT+DVI;

DuoViewの場合、以下のようになります:

modprobe viafb viafb_active_dev=CRT+DVI

OR:

modprobe viafb viafb_active_dev=DVI+CRT...

SAMMの場合:

CRTがプライマリでDVIがセカンドの場合、以下のようになります:

modprobe viafb viafb_active_dev=CRT+DVI viafb_SAMM_ON=1...

DVIがプライマリでCRTがセカンドの場合、以下のようになります:

modprobe viafb viafb_active_dev=DVI+CRT viafb_SAMM_ON=1...
viafb_display_hardware_layout:

このオプションはCX700チップのディスプレイハードウェアレイアウトを指定するために使用されます。

  • 1 : LCDのみ

  • 2 : DVIのみ

  • 3 : LCD+DVI (デフォルト)

  • 4 : LCD1+LCD2 (内部 + 内部)

  • 16: LCD1+外部LCD2 (内部 + 外部)

viafb_second_size:

このオプションはSAMMの場合にセカンドデバイスのメモリサイズ(MB)を設定するために使用されます。最小サイズは16です。

viafb_platform_epia_dvi:

このオプションはEPIA - MでDVIを有効にするために使用されます

  • 0 : EPIA - MでDVIなし (デフォルト)

  • 1 : EPIA - MでDVI有効

viafb_bus_width:

24ビットバス幅デジタルインターフェースを使用する場合、このオプションを設定する必要があります。

  • 12: 12ビットLVDSまたは12ビットTMDS (デフォルト)

  • 24: 24ビットLVDSまたは24ビットTMDS

viafb_device_lcd_dualedge:

デュアルエッジパネルを使用する場合、このオプションを設定する必要があります。

  • 0 : デュアルエッジパネルなし (デフォルト)

  • 1: デュアルエッジパネル

viafb_lcd_port:

このオプションはLCD出力ポートを指定するために使用され、利用可能な値は「DVP0」「DVP1」「DFP_HIGHLOW」「DFP_HIGH」「DFP_LOW」です。

CX700で外部LCD＋外部DVIを使用する場合（外部LCDはDVP0に接続）、以下を使用してください:

modprobe viafb viafb_lcd_port=DVP0...
注意：

  1. DVIオーバースキャンが有効な「640x480」PALモードでDuoView CRT&DVI表示を行うと、CRTが正しく表示されない可能性があります。

  2. SAMMはシングルアダプターマルチモニタの略で、マルチヘッドとは異なり、SAMMはドライバ層でマルチモニタをサポートするため、fbcon層はその存在を認識しません。SAMMの2番目のスクリーンにはデバイスノードファイルが存在しないため、ユーザーモードアプリケーションから直接アクセスできません。SAMMが有効な場合、viafb_modeとviafb_mode1、viafb_bppとviafb_bpp1、viafb_refreshとviafb_refresh1はそれぞれ異なってもよいです。

  3. コンソールがviafbinfo1に依存している場合、動的に解像度とbppを変更するには、VIAFB指定のioctlインターフェースVIAFB_SET_DEVICEを呼び出す必要があります。通常のioctl関数FBIOPUT_VSCREENINFOを呼び出すと、viafbがマルチヘッドをサポートしていないため画面が破損する可能性があります。

fbsetツールを使用してviafbを設定する¶

fbsetはLinuxの標準ユーティリティです。

  1. 現在のviafb情報を確認するには、以下を入力してください:

    # fbset -i

  2. さまざまな解像度とviafb_refreshレートを設定する:

    # fbset <resolution-vertical_sync>

    例:

    # fbset "1024x768-75"

    または:

    # fbset -g 1024 768 1024 768 32

    表示モードが利用可能なファイル「/etc/fb.modes」を確認してください。

  3. カラーデプスを設定する:

    # fbset -depth <value>

    例:

    # fbset -depth 16

procを介してviafbを設定する¶

以下のファイルが/proc/viafbに存在します

supported_output_devices

この読み取り専用ファイルには、プラットフォームで利用可能なすべての出力デバイスがカンマで区切られたリスト形式で含まれています。ハードウェアにすべての接続端子が存在するとは限りませんが、実際の接続端子と一致する名前を特定するための良い出発点になります。

例:

# cat /proc/viafb/supported_output_devices
iga1/output_devices, iga2/output_devices

これらの2つのファイルは読み取り可能かつ書き込み可能です。iga1とiga2は2つの独立したユニットで、スクリーン画像を生成します。これらの画像は1つまたは複数の出力デバイスに転送できます。これらのファイルを読み込むことで、igaが現在使用している出力デバイスを確認できます。

例:

# cat /proc/viafb/iga1/output_devices

出力デバイスがなければ、このIGAの出力は失われます。たとえば、どちらか一方のIGAのみを使用する場合など、このような状況が発生します。これらのファイルへの書き込みにより、実行時において出力デバイスを調整することが可能です。新しいデバイスを追加したり、既存のデバイスを削除したり、IGA間を切り替えることができます。本質的に、これらのファイルに、出力先のデバイス名を「、」で区切ったリスト（または単一のデバイス名）を同じ形式で記述することで、出力デバイスを設定できます。加えて、「+」または「-」を前につけることで、簡単な追加や削除が可能です。「+」はリスト内のデバイスを既存のデバイスに追加し、「-」はリスト内のデバイスを既存のデバイスから削除し、前につきない場合はすべての既存デバイスをリスト内のデバイスに置き換えます。デバイスを削除した場合は、それらがオフになることが期待されます。また、他のIGAに既に含まれているデバイスを追加した場合、それらはそのIGAから削除され、新しいIGAに追加されます。

例:

CRTを出力デバイスとしてiga1に追加:

# echo +CRT > /proc/viafb/iga1/output_devices

DVP1およびLVDS1をiga2の出力デバイスから削除（オフに）:

# echo -DVP1,LVDS1 > /proc/viafb/iga2/output_devices

すべてのiga1出力デバイスをCRTに置き換える:

# echo CRT > /proc/viafb/iga1/output_devices

viafbで起動する¶

grub.confに以下の行を追加:

append = "video=viafb:viafb_mode=1024x768,viafb_bpp=32,viafb_refresh=85"
