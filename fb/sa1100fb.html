sa1100fbとは何ですか？¶

これはSA-1100 LCDコントローラー用のグラフィックフレームバッファドライバです。

設定¶

ほとんどの一般的なパッシブディスプレイでは、オプションを指定することで

video=sa1100fb:bpp:<value>,lccr0:<value>,lccr1:<value>,lccr2:<value>,lccr3:<value>

カーネルコマンドラインに指定するだけでコントローラーを設定できます。ピクセルあたりのビット数（bpp）は4、8、12、または16のいずれかにしてください。LCCR値はディスプレイ固有であり、SA-1100 Developer’s Manual、セクション11.7に記載されているように計算する必要があります。LCCR0のSDSビットが設定されている限り、ダブルパネルディスプレイもサポートされます。GPIO<9:2>は下位パネルに使用されます。

アクティブディスプレイや追加の設定が必要なディスプレイ（バックライトの制御、LCDの電源ONなど）では、コマンドラインオプションだけではディスプレイを設定できません。sa1100fb_init_fbinfo()、sa1100fb_activate_var()、sa1100fb_disable_lcd_controller()、sa1100fb_enable_lcd_controller()にセクションを追加する必要があります。

受け入れ可能なオプション：

bpp:<value>     Configure for <value> bits per pixel
lccr0:<value>   Configure LCD control register 0 (11.7.3)
lccr1:<value>   Configure LCD control register 1 (11.7.4)
lccr2:<value>   Configure LCD control register 2 (11.7.5)
lccr3:<value>   Configure LCD control register 3 (11.7.6)
