SH7760/SH7763統合LCDC フレームバッファドライバ¶

0. 概要¶

SH7760/SH7763はSTN、DSTNおよびTFTパネルに対応するLCDディスプレイコントローラー（LCDC）を統合しており、理論上1x1から1024x1024までの解像度、1〜16ビットのカラーデプスをサポートしています。

注意点:

  • フレームバッファメモリはArea3の上部に大きな領域を確保する必要があります（ハードウェア要件）。このため、ドライバーをモジュール化してはいけません。実行時において十分な連続メモリを確保できない可能性があるからです。

  • ドライバーはロード中に解像度の変更をサポートしていません（ディスプレイはホットプラグ可能ではありません）

  • 以下の条件で重いフリッカリングが観測されることがあります：a) 640x480ピクセル以上の解像度で15/16ビットカラーモードを使用している場合、b) PCMCIA（または他の遅いバス）のアクティビティ中。

  • 回転は時計回り90度のみサポートされ、かつ水平解像度が320ピクセル以下である必要があります。

ファイル:

  • drivers/video/sh7760fb.c

  • include/asm-sh/sh7760fb.h

1. プラットフォーム設定¶

SH7760:

ビデオデータはDMABRG DMAエンジンを介して取得されるため、SH DMACをDMABRGモードに設定する必要があります（ブート時にDMARSRAレジスタに0x94808080を書き込みます）。

PFCレジスタのPCCRおよびPCDRはペリフェラルモードに設定する必要があります（両方のレジスタにゼロを書き込みます）。

ドライバーは上記の設定を行いません。ボード設定はボード設定コードの責任です。

2. パネル定義¶

LCDCは接続されたLCDパネルのタイプを明示的に指定する必要があります。データは「struct sh7760fb_platdata」構造体にまとめられ、ドライバーにplatform_dataとして渡します。

SH7760マニュアルのセクション30を詳しく確認することを推奨します（http://documentation.renesas.com/eng/products/mpumcu/e602291_sh7760.pdf)

以下のコードは、640x480 TFTでフレームバッファを動作させるために必要な処理を示しています：

#include <linux/fb.h>
#include <asm/sh7760fb.h>

/*
 * NEC NL6440bc26-01 640x480 TFT
 * dotclock 25175 kHz
 * Xres                640     Yres            480
 * Htotal      800     Vtotal          525
 * HsynStart   656     VsynStart       490
 * HsynLenn    30      VsynLenn        2
 *
 * The linux framebuffer layer does not use the syncstart/synclen
 * values but right/left/upper/lower margin values. The comments
 * for the x_margin explain how to calculate those from given
 * panel sync timings.
 */
static struct fb_videomode nl6448bc26 = {
       .name           = "NL6448BC26",
       .refresh        = 60,
       .xres           = 640,
       .yres           = 480,
       .pixclock       = 39683,        /* in picoseconds! */
       .hsync_len      = 30,
       .vsync_len      = 2,
       .left_margin    = 114,  /* HTOT - (HSYNSLEN + HSYNSTART) */
       .right_margin   = 16,   /* HSYNSTART - XRES */
       .upper_margin   = 33,   /* VTOT - (VSYNLEN + VSYNSTART) */
       .lower_margin   = 10,   /* VSYNSTART - YRES */
       .sync           = FB_SYNC_HOR_HIGH_ACT | FB_SYNC_VERT_HIGH_ACT,
       .vmode          = FB_VMODE_NONINTERLACED,
       .flag           = 0,
};

static struct sh7760fb_platdata sh7760fb_nl6448 = {
       .def_mode       = &nl6448bc26,
       .ldmtr          = LDMTR_TFT_COLOR_16,   /* 16bit TFT panel */
       .lddfr          = LDDFR_8BPP,           /* we want 8bit output */
       .ldpmmr         = 0x0070,
       .ldpspr         = 0x0500,
       .ldaclnr        = 0,
       .ldickr         = LDICKR_CLKSRC(LCDC_CLKSRC_EXTERNAL) |
                       LDICKR_CLKDIV(1),
       .rotate         = 0,
       .novsync        = 1,
       .blank          = NULL,
};

/* SH7760:
 * 0xFE300800: 256 * 4byte xRGB palette ram
 * 0xFE300C00: 42 bytes ctrl registers
 */
static struct resource sh7760_lcdc_res[] = {
       [0] = {
             .start  = 0xFE300800,
             .end    = 0xFE300CFF,
             .flags  = IORESOURCE_MEM,
       },
       [1] = {
             .start  = 65,
             .end    = 65,
             .flags  = IORESOURCE_IRQ,
       },
};

static struct platform_device sh7760_lcdc_dev = {
       .dev    = {
             .platform_data = &sh7760fb_nl6448,
       },
       .name           = "sh7760-lcdc",
       .id             = -1,
       .resource       = sh7760_lcdc_res,
       .num_resources  = ARRAY_SIZE(sh7760_lcdc_res),
};
