EP93xx LCDコントローラー用ドライバ¶

EP93xx LCD コントローラーは、標準的なデスクトップモニターおよび埋め込み型LCDディスプレイの両方を駆動できます。標準的なデスクトップモニターをお持ちの場合、標準的なLinuxビデオモードデータベースを使用できます。ボードファイルにおいて:

static struct ep93xxfb_mach_info some_board_fb_info = {
        .num_modes      = EP93XXFB_USE_MODEDB,
        .bpp            = 16,
};

埋め込み型LCDディスプレイをお持ちの場合、以下の通りでそのディスプレイ用のビデオモードを定義する必要があります:

static struct fb_videomode some_board_video_modes[] = {
        {
                .name           = "some_lcd_name",
                /* Pixel clock, porches, etc */
        },
};

ピクセルクロック値はピコ秒単位で指定されます。ピクセルクロック値を変換するにはKHZ2PICOSマクロを使用できます。他のほとんどの値はピクセルクロック単位で指定されます。参照: フレームバッファデバイス を参照してください。

ボード用のep93xxfb_mach_info構造体は以下のようになります:

static struct ep93xxfb_mach_info some_board_fb_info = {
        .num_modes      = ARRAY_SIZE(some_board_video_modes),
        .modes          = some_board_video_modes,
        .default_mode   = &some_board_video_modes[0],
        .bpp            = 16,
};

フレームバッファデバイスは、ボード初期化関数に以下のコードを追加することで登録できます:

ep93xx_register_fb(&some_board_fb_info);

ビデオ属性フラグ¶

ep93xxfb_mach_info構造体にはflagsフィールドがあり、コントローラーの設定に使用できます。ビデオ属性フラグについては、EP93xxユーザーズガイドの第7章に詳細に記載されています。利用可能なフラグは以下の通り:

EP93XXFB_PCLK_FALLING

ピクセルクロックの降下エッジでクロックデータを送信します。デフォルトではピクセルクロックの上昇エッジでクロックデータを送信します。

EP93XXFB_SYNC_BLANK_HIGH

ブランク信号がハイアクティブです。デフォルトではブランク信号がローアクティブです。

EP93XXFB_SYNC_HORIZ_HIGH

水平同期信号がハイアクティブです。デフォルトでは水平同期信号がローアクティブです。

EP93XXFB_SYNC_VERT_HIGH

垂直同期信号がハイアクティブです。デフォルトでは垂直同期信号がハイアクティブです。

フレームバッファの物理アドレスは以下のフラグを使用して制御できます:

EP93XXFB_USE_SDCSN0

フレームバッファにSDCSn[0]を使用します。これはデフォルトの設定です。

EP93XXFB_USE_SDCSN1

フレームバッファにSDCSn[1]を使用します。

EP93XXFB_USE_SDCSN2

フレームバッファにSDCSn[2]を使用します。

EP93XXFB_USE_SDCSN3

フレームバッファにSDCSn[3]を使用します。

プラットフォームコールバック¶

EP93xxフレームバッファドライバーは、setup、teardown、blankの3つのオプションプラットフォームコールバックをサポートしています。setupおよびteardown関数は、フレームバッファドライバーがインストールまたはアンインストールされるときに呼び出されます。blank関数はディスプレイがブランクまたはアンブランクされるたびに呼び出されます。

setupおよびteardownデバイスは、プラットフォームデバイス構造体を引数として受け取ります。fb_infoおよびep93xxfb_mach_info構造体は以下の通り取得できます:

static int some_board_fb_setup(struct platform_device *pdev)
{
        struct ep93xxfb_mach_info *mach_info = pdev->dev.platform_data;
        struct fb_info *fb_info = platform_get_drvdata(pdev);

        /* Board specific framebuffer setup */
}

ビデオモードの設定¶

ビデオモードは以下の構文で設定されます:

video=XRESxYRES[-BPP][@REFRESH]

EP93xxビデオドライバーが内蔵されている場合、ビデオモードはLinuxカーネルコマンドラインで設定されます。例えば:

video=ep93xx-fb:800x600-16@60

EP93xxビデオドライバーがモジュールとして構築されている場合、ビデオモードはモジュールがインストールされるときに設定されます:

modprobe ep93xx-fb video=320x240

スクリーンページバグ¶

少なくともEP9315では、VIDSCRNPAGE（フレームバッファ物理オフセット）のビット27が低電位に固定されるシリコンバグが存在します。このバグに関する非公式なエラタは以下のURLで確認できます：

https://marc.info/?l=linux-arm-kernel&m=110061245502000&w=2

デフォルトではEP93xxのフレームバッファドライバは、割り当てられた物理アドレスにビット27が設定されているかを確認します。設定されている場合、メモリが解放されエラーが返されます。この確認を無効化するには、ドライバをロードする際には以下のオプションを追加することで可能です：

ep93xx-fb.check_screenpage_bug=0

一部のケースでは、このバグを回避するためにSDRAMレイアウトを再構成することが可能です。詳細はEP93xxユーザーズガイドのセクション13を参照してください。
