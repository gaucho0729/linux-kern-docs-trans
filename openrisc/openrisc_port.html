OpenRISC Linux¶

これはOpenRISCクラスのマイクロプロセッサ向けにLinuxが移植されたもので、具体的には32ビットのOpenRISC 1000ファミリ（or1k）が最初のターゲットアーキテクチャです。

OpenRISCプロセッサに関する情報や開発状況については以下をご覧ください:

ウェブサイト

https://openrisc.io

email

openrisc@lists.librecores.org

OpenRISCツールチェーンとLinuxのビルド手順¶

OpenRISC向けLinuxをビルドして実行するには、少なくとも基本的なツールチェーンと、おそらくアーキテクチャシミュレータが必要です。以下にこれらのツールを準備する手順を示します。

  1. ツールチェーン

ツールチェーンバイナリはopenrisc.ioまたはGitHubリリースページから取得できます。異なるツールチェーンのビルド方法についてはopenrisc.ioやStaffordのツールチェーンビルドおよびリリーススクリプトをご参照ください。

バイナリ

https://github.com/openrisc/or1k-gcc/releases

ツールチェーン

https://openrisc.io/software

ビルド

https://github.com/stffrdhrn/or1k-toolchain-build

  1. ビルド

Linuxカーネルを通常通りビルドしてください:

make ARCH=openrisc CROSS_COMPILE="or1k-linux-" defconfig
make ARCH=openrisc CROSS_COMPILE="or1k-linux-"

  1. FPGAでの実行（オプション）

OpenRISCコミュニティでは通常、FuseSoCを使用してSoCをFPGAに組み込み管理しています。以下はDe0 Nano開発ボードにOpenRISC SoCをプログラミングする例です。ビルド中にFPGA RTLはFuseSoC IPコアリポジトリからダウンロードされ、FPGAベンダーのツールで構築され、openocdを介してボードにバイナリがロードされます。

git clone https://github.com/olofk/fusesoc
cd fusesoc
sudo pip install -e .

fusesoc init
fusesoc build de0_nano
fusesoc pgm de0_nano

openocd -f interface/altera-usb-blaster.cfg \
        -f board/or1k_generic.cfg

telnet localhost 4444
> init
> halt; load_image vmlinux ; reset

  1. シミュレータでの実行（オプション）

QEMUはプロセッサエミュレータであり、OpenRISCプラットフォームのシミュレーションには推奨されます。QEMUウェブサイトのOpenRISCインストラクションに従ってLinuxをQEMU上で実行してください。QEMU自体をビルドすることもできますが、LinuxディストリビューションにはOpenRISCをサポートするバイナリパッケージが提供されている可能性があります。

qemu openrisc

https://wiki.qemu.org/Documentation/Platforms/OpenRISC

用語¶

コードでは、以下のシンボルにパラメータを指定して、スコープをより特定のプロセッサ実装に限定しています:

openrisc:

OpenRISCクラスのプロセッサ

or1k:

OpenRISC 1000ファミリのプロセッサ

or1200:

OpenRISC 1200プロセッサ
