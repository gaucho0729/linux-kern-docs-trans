カーネルドライバ fam15h_power¶

サポートされているチップ:

  • AMD Family 15h プロセッサ

  • AMD Family 16h プロセッサ

    プレフィックス: ‘fam15h_power’

    スキャン対象アドレス: PCI領域

    データシート:

    • BIOS and Kernel Developer’s Guide (BKDG) For AMD Family 15h プロセッサ

    • BIOS and Kernel Developer’s Guide (BKDG) For AMD Family 16h プロセッサ

    • AMD64 Architecture Programmer’s Manual Volume 2: System Programming

Author: Andreas Herrmann <herrmann.der.user@googlemail.com>

説明¶

  1. プロセッサ TDP (Thermal design power)

固定周波数と電圧の下では、プロセッサの消費電力は実行中のワークロードによって変化します。定格電力は特定アプリケーションを実行時の消費電力を指します。熱設計電力（TDP）は定格電力の例です。

このドライバは、TDPアルゴリズムを介してAMD Family 15hおよび16hプロセッサの電力情報を読み取るレジスタを提供します。

AMD Family 15hおよび16hプロセッサでは、以下の電力値を異なるプロセッサノースブリッジ機能レジスタを用いて計算できます:

  • BasePwrWatts:

    NBおよびコア外のロジックの最大消費電力をワット単位で指定します。

  • ProcessorPwrWatts:

    プロセッサがサポート可能な最大消費電力をワット単位で指定します。

  • CurrPwrWatts:

    現在のプロセッサの消費電力をワット単位で指定します。

このドライバはProcessorPwrWattsおよびCurrPwrWattsを提供します:

  • power1_crit (ProcessorPwrWatts)

  • power1_input (CurrPwrWatts)

マルチノードプロセッサでは計算値は全体のパッケージを対象とし、単一ノードではありません。そのため、ドライバはマルチノードプロセッサの内部ノード0のみにsysfs属性を生成します。

  1. 累積電力メカニズム

このドライバは、測定期間Tmにおけるプロセッサの平均消費電力を計算するためのアルゴリズムも導入しています。累積電力メカニズムの特徴はCPUID Fn8000_0007_EDX[12]で示されます。

  • Tsample:

    コンピュートユニット電力累積サンプリング周期

  • Tref:

    PTSCカウンタ周期

  • PTSC:

    パフォーマンスタイムスタンプカウンタ

  • N:

    コンピュートユニット電力累積サンプリング周期とPTSC周期の比率

  • Jmax:

    MaxCpuSwPwrAcc MSR C001007bで示される最大コンピュートユニット累積電力

  • Jx/Jy:

    CpuSwPwrAcc MSR C001007aで示されるコンピュートユニット累積電力

  • Tx/Ty:

    CU_PTSC MSR C0010280で示されるパフォーマンスタイムスタンプカウンタの値

  • PwrCPUave:

    CPUの平均消費電力

  1. CPUID Fn8000_0007を実行して、TsampleとTrefの比率を決定します。

    N = CPUID Fn8000_0007_ECX[CpuPwrSampleTimeRatio[15:0]]の値。

  2. 新しいMSR MaxCpuSwPwrAccから累積エネルギー値の全範囲を読み取ります。

    Jmax = 返却された値。

  3. 時刻xにおいて、SWがCpuSwPwrAcc MSRを読み取り、PTSCをサンプリングします。

    Jx = CpuSwPwrAccから読み取った値、Tx = PTSCから読み取った値。

  4. 時刻yにおいて、SWがCpuSwPwrAcc MSRを読み取り、PTSCをサンプリングします。

    Jy = CpuSwPwrAccから読み取った値、Ty = PTSCから読み取った値。

  5. 計算期間(y-x)におけるコンピュートユニットの平均消費電力を求めます。結果の単位はuWattです：

    if (Jy < Jx) // Rollover has occurred
        Jdelta = (Jy + Jmax) - Jx
else
        Jdelta = Jy - Jx
PwrCPUave = N * Jdelta * 1000 / (Ty - Tx)

このドライバーはPwrCPUaveとインターバル（デフォルトは10ミリ秒、最大は1秒）を提供します：

  • power1_average (PwrCPUave)

  • power1_average_interval (インターバル)

power1_average_intervalは以下のように/etc/sensors3.confファイルで更新できます：

チップ fam15h_power-*

set power1_average_interval 0.01

その後、'sensors -s'で保存します。
