HP SIO の検出方法と dc7100 における熱データの読み取り方法

dc7100 の熱情報は SIO ハードウェアモニタ（HWM）に含まれています。情報はインデックス/データペアを通じてアクセスされます。インデックス/データペアは HWM ベースアドレス + 0 および HWM ベースアドレス + 1 に位置します。HWM ベースアドレスは論理デバイス8、レジスタ0x60（MSB）および0x61（LSB）から取得できます。現在は HWM ベースアドレスとして 0x480 を使用し、インデックス/データペアとして 0x480 および 0x481 を使用しています。¶

MOV     DX,480H
MOV     AX,25H
OUT     DX,AL

IN      AL,DX

ALには16進数でデータが格納されており、摂氏温度はその10進数の等価値です。

例: ALが0x2Aを含む場合、温度は42℃です。

ターボLSBの読み取りはターボMSBをロックします。LSBを最初に読み取る必要があります。

ターボ読み取りをRPMに変換する方法¶

ターボ読み取り値（TCount）は以下の式で求められます: (Tach MSB × 256) + (Tach LSB) SIOは1回転あたりの90kHz（11.111μs）パルス数をカウントします。RPM = 60 / (TCount × 11.111μs)

例:

Reg 0x28 = 0x9B
Reg 0x29 = 0x08

TCount = 0x89B = 2203

RPM = 60 / (2203 × 11.11111 × 10^-6) = 2451 RPM

設定シーケンス¶

設定レジスタをプログラミングするには以下の手順を実行する必要があります: 1. 設定モードに移行 2. 設定レジスタを設定 3. 設定モードから抜ける。

設定モードに移行¶

チップを設定状態にするには、設定キー（0x55）をCONFIG PORT（0x2E）に書き込みます。

設定モード¶

設定モードでは、INDEX PORTはCONFIG PORTアドレスに位置し、DATA PORTはINDEX PORTアドレス＋1に位置します。

目的の設定レジスタにアクセスするには、2段階の手順が必要です:

  1. 論理デバイス番号設定レジスタ（つまり、0x07）のインデックスをINDEX PORTに書き込み、次に望む論理デバイスの番号をDATA PORTに書き込みます。

  2. 論理デバイス内の望む設定レジスタのアドレスをINDEX PORTに書き込み、次にDATA PORTを通じて設定レジスタを読み書きします。

注意:

グローバル設定レジスタにアクセスする場合は、ステップ(a)は不要です。

設定モードを終了する¶

設定状態から抜け出すには、CONFIG PORT（0x2E）に0xAAを書き込みます。チップはRUN状態に戻ります。（これは重要です）。

プログラミング例¶

以下の例は、0x20に位置するSIOデバイスIDを読み取る方法です:

; 設定モードに移行 MOV DX,02EH MOV AX,055H OUT DX,AL ; グローバル設定レジスタ MOV DX,02EH MOV AL,20H OUT DX,AL ; データを読み取る MOV DX,02FH IN AL,DX ; 設定モードを終了 MOV DX,02EH MOV AX,0AAH OUT DX,AL

dc7100上のSIOを特定するには、デバイスID（0x20）とデバイスRev（0x21）が関心の対象です。

デバイスIDは0x6Fを読み取ります（SCH5307-NSでは0x81、SCH5317では0x85）。デバイスRevは現在0x01を読み取ります。

HWMベースアドレスの取得¶

以下の例は、論理デバイス8に位置するHWMベースアドレスを読み取る方法です:

; ENTER CONFIGURATION MODE
MOV     DX,02EH
MOV     AX,055H
OUT     DX,AL
; CONFIGURE REGISTER CRE0,
; LOGICAL DEVICE 8
MOV     DX,02EH
MOV     AL,07H
OUT     DX,AL ;Point to LD# Config Reg
MOV     DX,02FH
MOV     AL, 08H
OUT     DX,AL;Point to Logical Device 8
;
MOV     DX,02EH
MOV     AL,60H
OUT     DX,AL   ; Point to HWM Base Addr MSB
MOV     DX,02FH
IN      AL,DX   ; Get MSB of HWM Base Addr
; EXIT CONFIGURATION MODE
MOV     DX,02EH
MOV     AX,0AAH
OUT     DX,AL
