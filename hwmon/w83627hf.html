カーネルドライバー w83627hf¶

サポートされているチップ:

  • Winbond W83627HF (ISA アクセスのみ) プレフィックス: ‘w83627hf’ スキャンアドレス: ISA アドレスは Super I/O レジスタから取得

  • Winbond W83627THF プレフィックス: ‘w83627thf’ スキャンアドレス: ISA アドレスは Super I/O レジスタから取得

  • Winbond W83697HF プレフィックス: ‘w83697hf’ スキャンアドレス: ISA アドレスは Super I/O レジスタから取得

  • Winbond W83637HF プレフィックス: ‘w83637hf’ スキャンアドレス: ISA アドレスは Super I/O レジスタから取得

  • Winbond W83687THF プレフィックス: ‘w83687thf’ スキャンアドレス: ISA アドレスは Super I/O レジスタから取得 データシート: 要求時に Winbond から提供(http://www.winbond.com/hq/enu)

著者:

フロド ロイアールド <frodol@dds.nl>, Philip Edelbrock <phil@netroedge.com>, Mark Studebaker <mdsxyz123@yahoo.com>, Bernhard C. Schrenk <clemy@clemy.org>

モジュールパラメータ¶

  • force_i2c: int センサーの I2C アドレスを初期化

  • init: int (デフォルトは 1) ‘init=0’ を指定してチップの初期化をバイパスする。コンピュータがモジュールをロード時にクラッシュする場合、このオプションを試してみてください。

説明¶

このドライバーは ISA アクセスのサポートを実装しています のみ Winbond W83627HF、W83627THF、W83697HF および W83637HF の Super I/O チップをサポートしています。これらをまとめて Winbond チップと呼びます。

このドライバーは ISA アクセスをサポートしており、I2C アクセスより信頼性が高いです。また、Super I/O チップと I2C 唯独の Winbond チップ（しばしば W83782D）を含む Tyan ボードでは、このドライバーを使用することで I2C アドレスの競合や w83781d ドライバーで必要だった複雑な初期化を回避できます。

これらの Super I/O チップに I2C アクセスを使用したい場合は w83781d ドライバーを使用してください。ただし、この ISA ドライバーが開発された現在では、この方法は推奨されません。

以下の w83627_HF_ はピン 110-106 を VID0-VID4 として使用します。The w83627_THF_ は GPIO[0:4] と同じピンを使用します。技術的には、 w83627_THF_ は VID リードをサポートしていません。しかし、2つのチップは同一の128ピンパッケージを持っています。そのため、w83627thf が VID シグナルをこれらのピンにルーティングしている可能性があり、それらが VID として扱われます。ボードの VID が動作しない場合はまず lm_sensors パッケージの doc/vid を確認してください[1]。それでも解決しない場合は、偽の VID リードを無視しても問題ありません。

このドライバーに関する詳細情報は w83781d ドライバーのドキュメンテーションをご参照ください。

[1] http://www.lm-sensors.org/browser/lm-sensors/trunk/doc/vid

アドレスを強制的に設定¶

ドライバは以前、ハードウェアモニタリングブロックのベースI/Oアドレスを強制的に設定するためのモジュールパラメータforce_addrを持っていました。これは、壊れたBIOSを持つマザーボードの対処手段として意図されていました。このモジュールパラメータは技術的な理由により削除されました。この機能が必要な場合は、ドライバをロードする前にisasetツール（lm-sensorsの一部）を使用して同じ結果を得ることができます:

# スーパーアイーオー構成領域に移動する:

isaset -y -f 0x2e 0x87
isaset -y -f 0x2e 0x87

# hwmon論理デバイスを選択する:

isaset -y 0x2e 0x2f 0x07 0x0b

# ベースI/Oアドレスを設定する（この例では0x290に設定）:

isaset -y 0x2e 0x2f 0x60 0x02
isaset -y 0x2e 0x2f 0x61 0x90

# スーパーアイーオー構成領域から退出する:

isaset -y -f 0x2e 0xaa

上記の手順はスーパーアイーオー構成領域が0x2e/0x2fにあることを前提としていますが、0x4e/0x4fも可能です。
