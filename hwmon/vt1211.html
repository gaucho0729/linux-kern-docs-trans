カーネルドライバー vt1211¶

サポートされているチップ:

  • VIA VT1211

    プレフィックス: ‘vt1211’

    スキャンされるアドレス: なし、Super-I/O コンフィギュレーション領域から読み取ったアドレス

    データシート: VIAから要請により提供され、NDAの下で提供されます

著者: Juerg Haefliger <juergh@gmail.com>

このドライバーは、Mark D. Studebakerによるカーネル2.4用ドライバーおよびLars Ekmanによるカーネル2.6への移植に基づいています。

VIAのJoseph Chan氏およびFiona Gatt氏にドキュメンテーションおよび技術サポートを提供していただき感謝します。

モジュールパラメータ¶

  • uch_config: int

    チャンネル1-5のBIOSデフォルトの汎用チャンネル（UCH）構成を上書きします。有効な値の範囲は0-31です。ビット0はUCH1に、ビット1はUCH2に、といったようにマッピングされます。ビットを1に設定するとそのUCHの温度入力が有効になり、0に設定すると電圧入力が有効になります。

  • int_mode: int

    BIOSデフォルトの温度割込みモードを上書きします。可能な値は0のみで、これにより割込みモード0が強制されます。このモードでは、ステータスレジスタが読み込まれるたびに待機中の割込みがクリアされますが、温度がヒステリシス限界以上に維持されている限り再生成されます。

BIOSデフォルトを上書きすると、不都合な副作用が発生する可能性があります！

説明¶

VIA VT1211 Super-I/Oチップには完全なハードウェアモニタリング機能が含まれています。2つの専用温度センサ入力（temp1およびtemp2）、1つの専用電圧（in5）、2つのファンを監視します。さらに、このチップは5つの汎用入力チャネル（UCH1-5）を実装しており、それぞれが電圧または温度を監視するように個別にプログラミング可能です。

このチップは、データシートに記載されているようにファン速度の手動および自動制御も提供します。ドライバーは自動制御のみをサポートしています（手動モードはデータシートに記載されているように動作しないと思われます）。実際には手動モードをまったく動作させることができませんでした！自動モードは私のEPIA M10000にはPWM出力がファンに接続されていないため、十分にテストされていません（:-（）。

電圧モニタリング¶

電圧は8ビットADCでサンプリングされ、LSBは約10mVです。サポートされる入力範囲は0〜2.60Vです。この範囲外の電圧値には外部スケーリング抵抗が必要です。この外部スケーリングはsensors.confの計算ラインで補正する必要があります。例:

compute inx @*(1+R1/R2), @/(1+R1/R2)

温度モニタリング¶

温度はミリデグリーセルシウスで報告されます。測定された各温度には、閾値を超えたときにアラームをトリガーする高限があります。温度ごとにヒステリシス値が関連付けられており、アラームを解除するにはこの値以下まで温度が下がる必要があります（これは割り込みモード0の場合にのみ適用されます）。割り込みモードを0に強制的に設定する場合、BIOSが自動で行わない場合があります。詳細は「モジュールパラメータ」セクションを参照してください。

temp2を除くすべての温度チャネルは外部です。temp2はVT1211の内部サーモダイオードで、ドライバがtemp2のスケーリングを行い、ミリデグリーセルシウスで温度を返します。外部チャネルtemp1およびtemp3-temp7については、ボード実装に依存し、userspaceでsensors.confを介してスケーリングを行う必要があります。

temp1はIntel型サーモダイオードで、sysfsの読み取り値と実際の温度を変換するためには以下の式を使用します：

compute temp1 (@-Offset)/Gain, (@*Gain)+Offset

VIA VT1211 BIOS移植ガイドによると、以下のゲインとオフセット値を使用する必要があります：

temp3-temp7はNTCサーモスタットをサポートしています。これらのチャネルでは、ドライバがUCH1-UCH5の個々のピンにおける電圧を返します。ピンの電圧（Vpin）は、サーモスタット（Rth）とスケーリング抵抗（Rs）で構成される分圧によって形成されます：

Vpin = 2200 * Rth / (Rs + Rth)   (2200 is the ADC max limit of 2200 mV)

サーモスタットの式は以下の通りです（詳しく知りたい場合はグーグルで検索してください）：

Rth = Ro * exp(B * (1 / T - 1 / To))   (To is 298.15K (25C) and Ro is the
                                        nominal resistance at 25C)

上記の2つの式を組み合わせ、Rs = RoとB = 3435を仮定すると、sensors.conf用の以下の式が得られます：

compute tempx 1 / (1 / 298.15 - (` (2200 / @ - 1)) / 3435) - 273.15,
              2200 / (1 + (^ (3435 / 298.15 - 3435 / (273.15 + @))))

ファン速度制御¶

VT1211は、2つのファンの速度を制御するための2つのプログラマブルPWM出力を持っています。pwm[1-2]_enable sysfsノードのいずれかに2を書き込むと、PWMコントローラーが自動モードに移行します。2つのPWM出力の両方を制御する単一のコントローラーが存在しますが、それぞれのPWM出力は個別に有効化および無効化できます。

各PWMには、フル、ハイ、ロウ、オフの4つの異なる出力デューティー比があります。フルとオフは内部的に255（100%）と0（0%）にハードワイヤードされています。ハイとロウはpwm[1-2]_auto_point[2-3]_pwmを介してプログラミング可能です。各PWM出力は異なる熱入力と関連付けることができますが、ここに注意すべき点があります - 両方のPWM出力デューティー比を制御するための1つのセットの熱閾値しか存在しません。熱閾値はpwm[1-2]_auto_point[1-4]_tempを介してアクセス可能です。注意点として、2つの4つの自動ポイントセットがあるにもかかわらず、これらはVT1211内の同じレジスタにマッピングされており、1つのセットをプログラミングするだけで十分です（実際には最初のセットpwm1_auto_point[1-4]_tempのみ書き込み可能で、2番目のセットは読み取り専用です）。
