説明¶

このドライバーは、さまざまなPMBus準拠デバイスのハードウェアモニタリングをサポートしています。デバイスがサポートする電圧、電流、電力、温度センサーをサポートしています。

各モニタリングチャンネルには、それぞれ高/低限値とクリティカル限値があります。

ファンのサポートはこのドライバーの後続バージョンで追加される予定です。

使用注意事項¶

このドライバーはPMBusデバイスのプローブを行いません。なぜなら、チップを識別するための安全なレジスタが存在しないからです（MFG_IDレジスタはすべてのチップでサポートされていない）、またPMBusデバイスの明確なアドレス範囲もありません。デバイスは明示的にインスタンス化する必要があります。

例: 次のコマンドは、I2Cバス#1上のアドレス0x60にあるLTC2978デバイス用のドライバーをロードします:

$ modprobe pmbus
$ echo ltc2978 0x60 > /sys/bus/i2c/devices/i2c-1/new_device

プラットフォームデータサポート¶

追加のPMBusチップのサポートは、新しいチップ固有ドライバーファイルでチップパラメータを定義することで追加できます。例えば、(未検証) エンゼルモ DS1200電源モジュールのサポートを追加するコードは以下のようになります:

static struct pmbus_driver_info ds1200_info = {
      .pages = 1,
      /* Note: All other sensors are in linear mode */
      .direct[PSC_VOLTAGE_OUT] = true,
      .direct[PSC_TEMPERATURE] = true,
      .direct[PSC_CURRENT_OUT] = true,
      .m[PSC_VOLTAGE_IN] = 1,
      .b[PSC_VOLTAGE_IN] = 0,
      .R[PSC_VOLTAGE_IN] = 3,
      .m[PSC_VOLTAGE_OUT] = 1,
      .b[PSC_VOLTAGE_OUT] = 0,
      .R[PSC_VOLTAGE_OUT] = 3,
      .m[PSC_TEMPERATURE] = 1,
      .b[PSC_TEMPERATURE] = 0,
      .R[PSC_TEMPERATURE] = 3,
      .func[0] = PMBUS_HAVE_VIN | PMBUS_HAVE_IIN | PMBUS_HAVE_STATUS_INPUT
                 | PMBUS_HAVE_VOUT | PMBUS_HAVE_STATUS_VOUT
                 | PMBUS_HAVE_IOUT | PMBUS_HAVE_STATUS_IOUT
                 | PMBUS_HAVE_PIN | PMBUS_HAVE_POUT
                 | PMBUS_HAVE_TEMP | PMBUS_HAVE_STATUS_TEMP
                 | PMBUS_HAVE_FAN12 | PMBUS_HAVE_STATUS_FAN12,
};

static int ds1200_probe(struct i2c_client *client)
{
      return pmbus_do_probe(client, &ds1200_info);
}

static int ds1200_remove(struct i2c_client *client)
{
      return pmbus_do_remove(client);
}

static const struct i2c_device_id ds1200_id[] = {
      {"ds1200", 0},
      {}
};

MODULE_DEVICE_TABLE(i2c, ds1200_id);

/* This is the driver that will be inserted */
static struct i2c_driver ds1200_driver = {
      .driver = {
                 .name = "ds1200",
                 },
      .probe_new = ds1200_probe,
      .remove = ds1200_remove,
      .id_table = ds1200_id,
};

static int __init ds1200_init(void)
{
      return i2c_add_driver(&ds1200_driver);
}

static void __exit ds1200_exit(void)
{
      i2c_del_driver(&ds1200_driver);
}

Sysfsエントリ¶

チップをプローブする際、ドライバーはサポートされるPMBusレジスタを特定し、その情報を基に利用可能なセンサーを決定します。属性ファイルは、チップが対応しているセンサーにのみ存在します。ラベルは、sysfsエントリに関連するセンサーをユーザーに示します。

サポートされる属性は以下の通りです。制限値は読み書き可能で、他の属性は読み取り専用です。

inX_input

測定電圧。READ_VINまたはREAD_VOUTレジスタから。

inX_min

最小電圧。VIN_UV_WARN_LIMITまたはVOUT_UV_WARN_LIMITレジスタから。

inX_max

最大電圧。VIN_OV_WARN_LIMITまたはVOUT_OV_WARN_LIMITレジスタから。

inX_lcrit

クリティカル最小電圧。VIN_UV_FAULT_LIMITまたはVOUT_UV_FAULT_LIMITレジスタから。

inX_crit

クリティカル最大電圧。VIN_OV_FAULT_LIMITまたはVOUT_OV_FAULT_LIMITレジスタから。

inX_min_alarm

電圧低めのアラーム。VOLTAGE_UV_WARNING ステータスから取得。

inX_max_alarm

電圧高めのアラーム。VOLTAGE_OV_WARNING ステータスから取得。

inX_lcrit_alarm

電圧クリティカル低めのアラーム。VOLTAGE_UV_FAULT ステータスから取得。

inX_crit_alarm

電圧クリティカル高めのアラーム。VOLTAGE_OV_FAULT ステータスから取得。

inX_label

「vin」、「vcap」、または「voutY」

inX_rated_min

最小定格電圧。MFR_VIN_MINまたはMFR_VOUT_MINレジスタから。

inX_rated_max

最大定格電圧。MFR_VIN_MAXまたはMFR_VOUT_MAXレジスタから。

currX_input

測定電流。READ_IINまたはREAD_IOUTレジスタから。

currX_max

最大電流。IIN_OC_WARN_LIMITまたはIOUT_OC_WARN_LIMITレジスタから。

currX_lcrit

クリティカル最小出力電流。IOUT_UC_FAULT_LIMITレジスタから。

currX_crit

クリティカル最大電流。IIN_OC_FAULT_LIMITまたはIOUT_OC_FAULT_LIMITレジスタから。

currX_alarm

電流高警報。IIN_OC_WARNINGまたはIOUT_OC_WARNINGステータスから。

currX_max_alarm

電流高警報。IIN_OC_WARN_LIMITまたはIOUT_OC_WARN_LIMITステータスから。

currX_lcrit_alarm

出力電流クリティカル低警報。IOUT_UC_FAULTステータスから。

currX_crit_alarm

電流クリティカル高警報。IIN_OC_FAULTまたはIOUT_OC_FAULTステータスから。

currX_label

「iin」「iinY」「iinY.Z」「ioutY」「またはioutY.Z」、Yはページ番号、Zは相を表します。

currX_rated_max

最大定格電流。MFR_IIN_MAXまたはMFR_IOUT_MAXレジスタから。

powerX_input

測定電力。READ_PINまたはREAD_POUTレジスタから。

powerX_cap

出力電力制限。POUT_MAXレジスタから。

powerX_max

電力制限。PIN_OP_WARN_LIMITまたはPOUT_OP_WARN_LIMITレジスタから。

powerX_crit

クリティカル出力電力制限。POUT_OP_FAULT_LIMITレジスタから。

powerX_alarm

電力高警報。PIN_OP_WARNINGまたはPOUT_OP_WARNINGステータスから。

powerX_crit_alarm

出力電力クリティカル高警報。POUT_OP_FAULTステータスから。

powerX_label

「pin」「pinY」「pinY.Z」「poutY」「またはpoutY.Z」、Yはページ番号、Zは相を表します。

powerX_rated_max

最大定格電力。MFR_PIN_MAXまたはMFR_POUT_MAXレジスタから。

tempX_input

測定温度。READ_TEMPERATURE_Xレジスタから。

tempX_min

最小温度。UT_WARN_LIMITレジスタから。

tempX_max

最大温度。OT_WARN_LIMIT レジスタから取得。

tempX_lcrit

クリティカル低温。UT_FAULT_LIMITレジスタから。

tempX_crit

クリティカル高温。OT_FAULT_LIMIT レジスタから取得。

tempX_min_alarm

チップ温度低警報。TEMP_UT_WARNINGステータスが設定されている場合、READ_TEMPERATURE_XとUT_WARN_LIMITを比較して設定します。

tempX_max_alarm

チップ温度高警報。TEMP_OT_WARNINGステータスが設定されている場合、READ_TEMPERATURE_XとOT_WARN_LIMITを比較して設定します。

tempX_lcrit_alarm

チップ温度クリティカル低警報。TEMP_UT_FAULTステータスが設定されている場合、READ_TEMPERATURE_XとUT_FAULT_LIMITを比較して設定します。

tempX_crit_alarm

チップ温度の危険な高温アラーム。TEMP_OT_FAULT ステータスが設定されている場合、READ_TEMPERATURE_X と OT_FAULT_LIMIT を比較して設定します。

tempX_rated_min

最小定格温度。MFR_TAMBIENT_MIN レジスタから取得します。

tempX_rated_max

最大定格温度。MFR_TAMBIENT_MAX、MFR_MAX_TEMP_1、MFR_MAX_TEMP_2、または MFR_MAX_TEMP_3 レジスタから取得します。
