ヌルブロックデバイスドライバー¶

概要¶

The null block device (/dev/nullb*) is used for benchmarking the various block-layer implementations. It emulates a block device of X gigabytes in size. It does not execute any read/write operation, just mark them as complete in the request queue. The following instances are possible:

マルチキュー ブロックレイヤー

  • リクエストベース。

  • 各デバイスごとの設定可能なサブミットキュー。

ブロックレイヤーなし（bioベースと呼ばれる）

  • bioベース。IOリクエストは直接デバイスドライバーに送信されます。

  • bioデータ構造を直接受け入れ、返します。

すべてのデバイスはシステム内の各コアごとに完了キューを持ちます。

モジュールパラメータ¶

queue_mode=[0-2]: デフォルト: 2-マルチキュー

モジュールがインスタンス化するブロックレイヤーを選択します。

0

bioベース

1

シングルキュー（非推奨）

2

マルチキュー
home_node=[0–nr_nodes]: デフォルト: NUMA_NO_NODE

データ構造が割り当てられるCPUノードを選択します。

gb=[GB単位のサイズ]: デフォルト: 250GB

システムに報告されるデバイスのサイズ。

bs=[ブロックサイズ（バイト単位）]: デフォルト: 512バイト

システムに報告されるブロックサイズ。

nr_devices=[デバイス数]: デフォルト: 1

インスタンス化されるブロックデバイスの数。/dev/nullb0などとしてインスタンス化されます。

irqmode=[0-2]: デフォルト: 1-ソフトIRQ

ブロックレイヤーへのIO完了に使用される完了モード。

0

なし。

1

ソフトIRQ。CPUノード間でIPIを用いてIOを完了します。デバイスが接続されているノードとは異なるノードからIOが発行される際のオーバーヘッドをシミュレートします。

2

タイマー: 各IOに対して特定の期間（completion_nsec）を待って完了します。
completion_nsec=[ns]: デフォルト: 10,000ns

irqmode=2（タイマー）と組み合わせて使用。各完了イベントが待機する時間。

submit_queues=[1..nr_cpus]: デフォルト: 1

デバイスドライバーに接続されたサブミットキューの数。未設定の場合はデフォルトで1。マルチキューの場合はuse_per_node_hctxモジュールパラメータが1のときには無視されます。

hw_queue_depth=[0..qdepth]: デフォルト: 64

デバイスのハードウェアキュー深さ。

マルチキュー固有のパラメータ¶

use_per_node_hctx=[0/1]: デフォルト: 0

ハードウェアコンテキストキューの数。

0

サブミットキューの数はsubmit_queuesパラメータの値に設定されます。

1

マルチキューブロックレイヤーはシステム内の各CPUノードごとにハードウェアディスパッチキューでインスタンス化されます。
no_sched=[0/1]: デフォルト: 0

I/Oスケジューラを有効/無効にします。

0

nullb* はデフォルトの blk-mq I/O スケジューラを使用します

1

nullb* は I/O スケジューラを使用しません
blocking=[0/1]: デフォルト: 0

要求キューのブロッキング動作。

0

ノンブロッキング blk-mq ドライバデバイスとして登録します。

1

ブロッキング blk-mq ドライバデバイスとして登録します。null_blk は BLK_MQ_F_BLOCKING フラグを設定し、->queue_rq() 関数で時折/常にブロッキングが必要であることを示します。
shared_tags=[0/1]: デフォルト: 0

デバイス間でのタグの共有。

0

タグセットは共有されません。

1

blk-mq 用のデバイス間でのタグセットの共有。nr_devices > 1 の場合にのみ意味があります。それ以外の場合は、共有するタグセットがありません。
zoned=[0/1]: デフォルト: 0

デバイスはランダムアクセスまたはゾーンブロックデバイスです。

0

ブロックデバイスはランダムアクセスブロックデバイスとして公開されます。

1

ブロックデバイスはホスト管理ゾーンブロックデバイスとして公開されます。CONFIG_BLK_DEV_ZONED が必要です。
zone_size=[MB]: デフォルト: 256

ゾーンブロックデバイスとして公開される際の各ゾーンサイズ。2 の累乗でなければなりません。

zone_nr_conv=[nr_conv]: デフォルト: 0

ブロックデバイスがゾーン化されている場合に作成する従来型ゾーンの数。zone_nr_conv >= nr_zones の場合、nr_zones - 1 に減らされます。
