ユーザースペースからの DSA スイッチ設定¶

現在、DSAスイッチの設定は主なユーザースペースネットワーク設定ツールに統合されておらず、手動で行う必要があります。

Configuration showcases¶

DSAスイッチを設定するには複数のコマンドを実行する必要があります。このドキュメントでは、一般的な設定シナリオをいくつか紹介します。

single port

すべてのスイッチポートは、設定可能なイーサネットポートとして動作します

bridge

すべてのスイッチポートは、1つの設定可能なイーサネットブリッジに属します

gateway

すべてのスイッチポート（1つの上流ポートを除く）は設定可能なイーサネットブリッジに属します。上流ポートは設定可能なイーサネットポートとして動作します。

すべての設定はiproute2から提供されるツールを使用して行われます。iproute2は以下から入手可能です https://www.kernel.org/pub/linux/utils/net/iproute2/

DSAを通じて、スイッチのすべてのポートは通常のLinuxイーサネットインターフェースとして扱われます。CPUポートはイーサネットMACチップに接続されたスイッチポートです。対応するLinuxイーサネットインターフェースは「マスターアイテルフェース」と呼ばれます。他のすべての対応するLinuxインターフェースは「スレーブインターフェース」と呼ばれます。

スレーブインターフェースはマスターアイテルフェースに依存しており、マスターアイテルフェースがアップしているときにのみアップできます。

このドキュメントでは以下のイーサネットインターフェースを使用します:

eth0

マスターアイテルフェース

lan1

スレーブインターフェース

lan2

別のスレーブインターフェース

lan3

第三のスレーブインターフェース

wan

上流トラフィック専用のスレーブインターフェース

他のイーサネットインターフェースも同様に設定可能です。設定されたIPアドレスとネットワークは:

single port

  • lan1: 192.0.2.1/30 (192.0.2.0 - 192.0.2.3)

  • lan2: 192.0.2.5/30 (192.0.2.4 - 192.0.2.7)

  • lan3: 192.0.2.9/30 (192.0.2.8 - 192.0.2.11)

bridge

  • br0: 192.0.2.129/25 (192.0.2.128 - 192.0.2.255)

gateway

  • br0: 192.0.2.129/25 (192.0.2.128 - 192.0.2.255)

  • wan: 192.0.2.1/30 (192.0.2.0 - 192.0.2.3)

タグ付けサポートのある設定¶

タグベースの設定が望ましく、DSAスイッチの大多数でサポートされています。これらのスイッチはVLANベースの設定を使わずに、流入および流出トラフィックをタグ付けできます。

single port¶

# configure each interface
ip addr add 192.0.2.1/30 dev lan1
ip addr add 192.0.2.5/30 dev lan2
ip addr add 192.0.2.9/30 dev lan3

# The master interface needs to be brought up before the slave ports.
ip link set eth0 up

# bring up the slave interfaces
ip link set lan1 up
ip link set lan2 up
ip link set lan3 up

bridge¶

# The master interface needs to be brought up before the slave ports.
ip link set eth0 up

# bring up the slave interfaces
ip link set lan1 up
ip link set lan2 up
ip link set lan3 up

# create bridge
ip link add name br0 type bridge

# add ports to bridge
ip link set dev lan1 master br0
ip link set dev lan2 master br0
ip link set dev lan3 master br0

# configure the bridge
ip addr add 192.0.2.129/25 dev br0

# bring up the bridge
ip link set dev br0 up

gateway¶

# The master interface needs to be brought up before the slave ports.
ip link set eth0 up

# bring up the slave interfaces
ip link set wan up
ip link set lan1 up
ip link set lan2 up

# configure the upstream port
ip addr add 192.0.2.1/30 dev wan

# create bridge
ip link add name br0 type bridge

# add ports to bridge
ip link set dev lan1 master br0
ip link set dev lan2 master br0

# configure the bridge
ip addr add 192.0.2.129/25 dev br0

# bring up the bridge
ip link set dev br0 up

タグ付けサポートのない設定¶

一部のスイッチはタグプロトコル（DSA_TAG_PROTO_NONE）を使用できません。このようなスイッチはVLANベースの設定で構成できます。

single port¶

設定はVLANタグ付けとブリッジ設定を通じてのみ行えます。

# tag traffic on CPU port
ip link add link eth0 name eth0.1 type vlan id 1
ip link add link eth0 name eth0.2 type vlan id 2
ip link add link eth0 name eth0.3 type vlan id 3

# The master interface needs to be brought up before the slave ports.
ip link set eth0 up
ip link set eth0.1 up
ip link set eth0.2 up
ip link set eth0.3 up

# bring up the slave interfaces
ip link set lan1 up
ip link set lan2 up
ip link set lan3 up

# create bridge
ip link add name br0 type bridge

# activate VLAN filtering
ip link set dev br0 type bridge vlan_filtering 1

# add ports to bridges
ip link set dev lan1 master br0
ip link set dev lan2 master br0
ip link set dev lan3 master br0

# tag traffic on ports
bridge vlan add dev lan1 vid 1 pvid untagged
bridge vlan add dev lan2 vid 2 pvid untagged
bridge vlan add dev lan3 vid 3 pvid untagged

# configure the VLANs
ip addr add 192.0.2.1/30 dev eth0.1
ip addr add 192.0.2.5/30 dev eth0.2
ip addr add 192.0.2.9/30 dev eth0.3

# bring up the bridge devices
ip link set br0 up

bridge¶

# tag traffic on CPU port
ip link add link eth0 name eth0.1 type vlan id 1

# The master interface needs to be brought up before the slave ports.
ip link set eth0 up
ip link set eth0.1 up

# bring up the slave interfaces
ip link set lan1 up
ip link set lan2 up
ip link set lan3 up

# create bridge
ip link add name br0 type bridge

# activate VLAN filtering
ip link set dev br0 type bridge vlan_filtering 1

# add ports to bridge
ip link set dev lan1 master br0
ip link set dev lan2 master br0
ip link set dev lan3 master br0
ip link set eth0.1 master br0

# tag traffic on ports
bridge vlan add dev lan1 vid 1 pvid untagged
bridge vlan add dev lan2 vid 1 pvid untagged
bridge vlan add dev lan3 vid 1 pvid untagged

# configure the bridge
ip addr add 192.0.2.129/25 dev br0

# bring up the bridge
ip link set dev br0 up

gateway¶

# tag traffic on CPU port
ip link add link eth0 name eth0.1 type vlan id 1
ip link add link eth0 name eth0.2 type vlan id 2

# The master interface needs to be brought up before the slave ports.
ip link set eth0 up
ip link set eth0.1 up
ip link set eth0.2 up

# bring up the slave interfaces
ip link set wan up
ip link set lan1 up
ip link set lan2 up

# create bridge
ip link add name br0 type bridge

# activate VLAN filtering
ip link set dev br0 type bridge vlan_filtering 1

# add ports to bridges
ip link set dev wan master br0
ip link set eth0.1 master br0
ip link set dev lan1 master br0
ip link set dev lan2 master br0

# tag traffic on ports
bridge vlan add dev lan1 vid 1 pvid untagged
bridge vlan add dev lan2 vid 1 pvid untagged
bridge vlan add dev wan vid 2 pvid untagged

# configure the VLANs
ip addr add 192.0.2.1/30 dev eth0.2
ip addr add 192.0.2.129/25 dev br0

# bring up the bridge devices
ip link set br0 up
