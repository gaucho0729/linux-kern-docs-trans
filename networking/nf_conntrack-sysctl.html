Netfilter Conntrack Sysfs変数¶

/proc/sys/net/netfilter/nf_conntrack_* 変数:¶

nf_conntrack_acct - BOOLEAN

  • 0 - 無効 (デフォルト)

  • 0以外 - 有効

接続トラッキングフローのアカウント管理を有効にする。各フローごとに64ビットのバイトおよびパケットカウンターが追加されます。

nf_conntrack_buckets - INTEGER

ハッシュテーブルのサイズ。モジュールロード時にパラメータとして指定されない場合、総メモリを16384で割った値を基数として計算しますが、バケット数は32以上に制限され、最大で16384バケットまでとなります。4GB以上のメモリを持つシステムでは65536バケットになります。このsysctlは初期ネットネームスペースでのみ書き込み可能です。

nf_conntrack_checksum - BOOLEAN

  • 0 - 無効

  • 0以外 - 有効（デフォルト）

到達するパケットのチェックサムを検証します。チェックサムが不正なパケットはINVALID状態になります。この機能が有効な場合、そのようなパケットは接続トラッキングの対象外とされます。

nf_conntrack_count - INTEGER (読み取り専用)

現在割り当てられているフローのエントリ数。

nf_conntrack_events - BOOLEAN

  • 0 - 無効

  • 0以外 - 有効（デフォルト）

このオプションが有効な場合、接続トラッキングコードはctnetlink経由でユーザー空間に接続トラッキングイベントを提供します。

nf_conntrack_expect_max - INTEGER

期待テーブルの最大サイズ。デフォルト値はnf_conntrack_buckets / 256です。最小値は1です。

nf_conntrack_frag6_high_thresh - INTEGER

default 262144

IPv6フラグメントの再構築に使用する最大メモリ。nf_conntrack_frag6_high_threshバイトのメモリがこの目的に割り当てられると、フラグメントハンドラはnf_conntrack_frag6_low_threshに達するまでパケットを破棄します。

nf_conntrack_frag6_low_thresh - INTEGER

default 196608

nf_conntrack_frag6_low_threshを参照

nf_conntrack_frag6_timeout - INTEGER (秒)

default 60

IPv6フラグメントをメモリに保持する時間。

nf_conntrack_generic_timeout - INTEGER (秒)

default 600

一般的なタイムアウト時間。これはレイヤー4の未サポートプロトコルを指します。

nf_conntrack_helper - BOOLEAN

  • 0 - 無効 (デフォルト)

  • 0以外 - 有効

自動的な接続トラッキングヘルパー割当を有効にする。無効な場合、iptablesルールを設定してヘルパーを接続に割当てる必要があります。詳細はiptables-extensions(8)マニュアルのCTターゲット説明を参照してください。

nf_conntrack_icmp_timeout - INTEGER (秒)

default 30

ICMPタイムアウト時間のデフォルト。

nf_conntrack_icmpv6_timeout - INTEGER (秒)

default 30

ICMPv6タイムアウト時間のデフォルト。

nf_conntrack_log_invalid - INTEGER

  • 0 - 無効（デフォルト）

  • 1 - ICMPパケットをログ出力

  • 6 - TCPパケットをログ出力

  • 17 - UDPパケットをログ出力

  • 33 - DCCPパケットをログ出力

  • 41 - ICMPv6パケットをログ出力

  • 136 - UDPLITEパケットをログ出力

  • 255 - 任意のプロトコルのパケットをログに記録する

値によって指定されたタイプの無効なパケットをログに記録する。

nf_conntrack_max - 整数

接続トラッキングテーブルのサイズ。デフォルト値はnf_conntrack_bucketsの値を4倍した値。

nf_conntrack_tcp_be_liberal - ブール値

  • 0 - 無効 (デフォルト)

  • 0以外 - 有効

他者から受け取るものは幅広く受け入れる。値がゼロでない場合、ウィンドウ外のRSTセグメントのみを無効とします。

nf_conntrack_tcp_loose - ブール値

  • 0 - 無効

  • 0以外 - 有効（デフォルト）

ゼロに設定されている場合、既に確立された接続を拾うのを無効にします。

nf_conntrack_tcp_max_retrans - 整数

デフォルト 3

宛先から(受け入れ可能な)ACKを受信せずに再送できる最大のパケット数。この数に達した場合、短いタイマが開始されます。

nf_conntrack_tcp_timeout_close - セカンド単位の整数

デフォルト 10

nf_conntrack_tcp_timeout_close_wait - セカンド単位の整数

default 60

nf_conntrack_tcp_timeout_established - セカンド単位の整数

デフォルト 432000 (5日間)

nf_conntrack_tcp_timeout_fin_wait - セカンド単位の整数

デフォルト 120

nf_conntrack_tcp_timeout_last_ack - セカンド単位の整数

default 30

nf_conntrack_tcp_timeout_max_retrans - セカンド単位の整数

デフォルト 300

nf_conntrack_tcp_timeout_syn_recv - セカンド単位の整数

default 60

nf_conntrack_tcp_timeout_syn_sent - セカンド単位の整数

デフォルト 120

nf_conntrack_tcp_timeout_time_wait - セカンド単位の整数

デフォルト 120

nf_conntrack_tcp_timeout_unacknowledged - セカンド単位の整数

デフォルト 300

nf_conntrack_timestamp - ブール値

  • 0 - 無効 (デフォルト)

  • 0以外 - 有効

接続トラッキングフローのタイムスタンプの記録を有効にする。

nf_conntrack_udp_timeout - セカンド単位の整数

default 30

nf_conntrack_udp_timeout_stream - セカンド単位の整数

デフォルト 120

UDPストリームが検出された場合に使用される拡張タイムアウト。

nf_conntrack_gre_timeout - セカンド単位の整数

default 30

nf_conntrack_gre_timeout_stream - セカンド単位の整数

デフォルト 180

GREストリームが検出された場合に使用される拡張タイムアウト。
