ARCnetの紹介¶

ARCnetは、一般的なイーサネットネットワークと似た仕組みですが、いくつか重要な点で異なります。

まず、ARCnetカードは少なくとも2つの速度で入手可能です：2.5 Mbps（イーサネットより遅い）と100 Mbps（通常のイーサネットより速い）。他にもありますが、それらはあまり一般的ではありません。私が知る限り、異なるハードウェアタイプは互換性がなく、100 Mbpsカードを2.5 Mbpsカードと接続することはできません。私が聞いた話では、私のドライバは100 Mbpsカードにも動作するようです。ただし、私は2.5 Mbpsのタイプしか持っていないため、確認できていません。おそらく100 Mbpsカードを満載にはしません。文句は止めてください。: )

ARCnetカードをイーサネットカードに接続しても動作しません。

ARCnetには2つの「タイプ」があります：スター topology とバス topology。これはカードをどのように接続すべきかを指します。多くのドキュメンテーションでは、スター型カードはスター型カードと、バス型カードはバス型カードと接続する必要があります。これは理にかなっていますよね？ただし、完全ではありません。以下の「ケーブル接続」セクションをご参照ください。

トークンパスの改良版を採用しており、トークンリングカードとは完全に互換性がありませんが、転送がイーサネットよりずっと信頼性が高いです。実際、ARCnetはパケットが安全に目的地に届くことを保証します。たとえ届けられない場合でも（ケーブルの断線や、宛先コンピュータが存在しないなど）、少なくとも送信者に通知します。

トークンの厳密に定義された動作により、リング内を最大時間内で必ず一周します。これはリアルタイムネットワークに適しています。

さらに、すべての既知のARCnetカードは（ほぼ）同一のプログラミングインターフェースを持っています。これは、1つのARCnetドライバーでどのカードもサポートできるということを意味します。一方、イーサネットでは各メーカーがしばしば完全に異なるプログラミングインターフェースを使用しており、これにより多くの異なる、時には非常に似たようなイーサネットドライバーが存在します。もちろん、常に同じプログラミングインターフェースを使用するということは、PCIバスマスタリングDMAなどの高性能ハードウェア機能が登場した際、それらを活用するのが難しいという意味もあります。詳しく説明は省略します。

しかし、ARCnetカードをプログラミングする際の課題となるのは、パケットサイズの制限です。標準のARCnetは最大508バイトのパケットしか送信できません。これはインターネットの「最低限の要件」である576バイトを下回り、イーサネットのMTUである1500バイトに比べてもはるかに小さく、補償するためにはRFC1201で定義された追加のエンカプスレーションレベル（私が「パケット分割」と呼ぶ）が導入されています。これにより、「仮想パケット」は最大64Kまで成長できますが、一般的にはイーサネットスタイルの1500バイト程度に抑えられます。

ARCnetネットワークの利点と欠点（主に利点）についての詳細情報が必要であれば、「ARCnet Trade Association」のWWWページを試してみてください：

http://www.arcnet.com

ARCnet（クラシックな2.5 Mbpsバージョン）は、ケーブルの種類としてコアックとツイストペアの2種類で接続できます。他のARCnetタイプのネットワーク（100 Mbps TCNSと320 kbps - 32 Mbps ARCnet Plus）は、それぞれ異なるケーブル（Type1、ファイバー、C1、C4、C5）を使用します。

コアックネットワークでは、93オームのRG-62ケーブルを使用するのが「推奨されます」。しかし、ARCnetは非常に安定したネットワークなので、他のケーブルも問題なく動作します。私自身は75オームのTVアンテナケーブルを使用しています。

コアックケーブル用のカードは、BUSとSTARのネットワーク構造用の2種類の変体で出荷されます。これらはほぼ同じですが、ハイブリッドチップの違いがあります。BUSカードは高インピーダンス出力、STARカードは低インピーダンス出力です。低インピーダンスカード（STAR）は、終端子を装着した高インピーダンスカードと電気的に同等です。

通常、ARCnetネットワークはSTARカードとハブから構成されます。ハブには2種類があります：アクティブ型とパッシブ型。パッシブハブは4つのBNCコネクタを備えた小さな箱で、4つの47オーム抵抗が含まれています：

   |         | wires
   R         + junction
-R-+-R-      R 47 Ohm resistors
   R
   |

シールドは接続されています。アクティブなハブははるかに複雑で、電源が接続されており、信号を増幅してネットワークの他のセグメントに送る電子機器を含んでいます。通常、8つのコネクタを持つのが特徴です。アクティブなハブには「ドム」型と「スマート」型の2種類があります。「ドム」型は単に増幅するだけであり、「スマート」型は通過するすべてのパケットをデジタルに変換して再送信します。ネットワークに複数のハブがある場合、この機能は信号品質を大幅に向上させます。

では、ケーブル接続について説明します。接続可能な組み合わせは以下の通りです：

  1. カード同士の接続。これは2台のコンピュータを接続する最も簡単な方法です。

  2. カードとパッシブハブの接続。ハブの未使用コネクタはすべて93オーム（または適切な終端子がなければ他の値）の終端子で適切に終端処理する必要があります。

    (アveryの注：うっかり忘れていました。私の場合は（TVケーブル）でも動作します。)

  3. カードとアクティブハブの接続。未使用のコネクタは見た目のためだけに終端処理する必要はありませんが、2台のコンピュータの間には最大で11つのアクティブハブしか接続できません。もちろん、ネットワーク全体のアクティブハブの数には制限はありません。

  4. アクティブハブと別のアクティブハブの接続。

  5. アクティブハブとパッシブハブの接続。

2つのパッシブハブを接続することはできません。その接続によって発生する電力損失がネットワークの信頼性を損なうためです。

典型的なARCnetネットワークの例：

       R                     S - STAR type card
S------H--------A-------S    R - Terminator
       |        |            H - Hub
       |        |            A - Active hub
       |   S----H----S
       S        |
                |
                S

バス topology はイーサネットで使用されるものと非常に似ています。違いはケーブルと終端子にあり、93オームのケーブルと終端子を使用する必要があります。イーサネットは50オームのインピーダンスを使用します。コンピュータを単一のケーブルラインに接続するにはT型コネクタを使用します。ケーブルの両端に終端子を設置する必要があります。典型的なバス型ARCnetネットワークは以下のようになります：

  RT----T------T------T------T------TR
   B    B      B      B      B      B

B - BUS type card
R - Terminator
T - T connector

しかし、これだけではありません！2つのタイプは接続可能です。公式ドキュメンテーションによると、接続する唯一の方法はアクティブハブを使用することです：

    A------T------T------TR
    |      B      B      B
S---H---S
    |
    S

公式ドキュメンテーションには、BUSネットワークの両端にSTARカードを使用してBUSカードと終端子の代わりにすることも可能と記載されています：

S------T------T------S
       B      B

ただし、私の実験によると、STAR topologyネットワークのケーブルの中間部分にBUS型カードを接続するだけで十分です。さらに、終端子を使用すれば、バスカードをSTARカードの代わりに使用することも可能です。これにより、すべてのニーズを満たす非常に複雑なネットワークを構築できます！例：

                              S
                              |
       RT------T-------T------H------S
        B      B       B      |
                              |       R
S------A------T-------T-------A-------H------TR
       |      B       B       |       |      B
       |   S                 BT       |
       |   |                  |  S----A-----S
S------H---A----S             |       |
       |   |      S------T----H---S   |
       S   S             B    R       S

Twisted Pairケーブルでは、基本的に異なる配線方式が使用されます。各TPカードには2つのRJ（電話線スタイル）コネクタがあります。その後、隣接するカードごとにケーブルでダaisyチェーン状態に接続します。両端はRJ 93オームの終端器で終端し、チェーンの両端にあるカードの空きコネクタに挿すことで接続します。例:

     ___________   ___________
 _R_|_         _|_|_         _|_R_
|     |       |     |       |     |
|Card |       |Card |       |Card |
|_____|       |_____|       |_____|

TPトポロジーにもハブがあります。ハブを使用するには特に難しいことはありません。TPチェーンをハブの両端に接続するだけで、ほぼ任意のネットワーク構成を作成できます。ネットワーク上の2台のコンピュータ間で最大11台のハブを接続する制限もここでは適用されます。例:

RP-------P--------P--------H-----P------P-----PR
                           |
  RP-----H--------P--------H-----P------PR
         |                 |
         PR                PR

R - RJ Terminator
P - TP Card
H - TP Hub

パッシブハブに接続されたすべてのケーブルの最大長さはRG-62ケーブルで65メートルに制限され、他のケーブルではさらに短くなります。これにより、大規模なネットワークでパッシブハブを使用する考えは良くありません。単一の「BUS Trunk」の最大長さはRG-62で約300メートルです。ネットワークの2つの最も遠いポイント間の最大距離は3000メートルに制限されます。カード/ハブ間のTPケーブルの最大長さは650メートルです。

ジャンパの設定¶

すべてのARCnetカードには合計4または5つの異なる設定が必要です:

  • I/Oアドレス: これはARCnetカードが接続されている「ポート」です。Linux ARCnetドライバーがスキャンする値は0x200から0x3F0の範囲です。(カードに追加の値がある場合は、お知らせください。) これはシステム内の他のデバイスと重複しないようにする必要があります。Novellから入手したドキュメントによると、MS Windowsは0x300以上の値を好むため、私のシステムではネットワーク接続が破壊されることがあります。(少なくとも)。私の推測では、カードが0x2E0に配置されている場合、シリアルポートのスキャンが0x2E8で行われるとカードがリセットされ、システムが大混乱になる可能性があります。

    • アveryの好ましい設定: 0x300。

  • IRQ: 8ビットカードでは2（9）、3、4、5、または7のいずれかです。

    16ビットカードでは2（9）、3、4、5、7、または10-15のいずれかです。

    • アVERYの好きなのは0xD0000

  • ステーションアドレス：すべてのARCnetカードには0〜255の独自のネットワークアドレスがあります。イーサネットとは異なり、ジャンパーやスイッチ（一部のカードでは特殊なソフトウェアでも）でこのアドレスを自分で設定できます。8ビットのため、ネットワーク上に最大254台のARCnetカードを接続できます。0や255は予約されていますので使用しないでください（ただし、これらを使用すると面白いことが起こるかもしれません）。ちなみに、まだ気づいていなければ、ネットワーク上の他のARCnetカードと同じアドレスを設定しないでください。

    • アVERYの好きなのは3と4。それほど重要ではありません。

  • ETS1およびETS2の設定がある場合があります。これらはあなたのカードで動作に影響を与えるかどうかは不明ですが（多くのマニュアルでは「予約済み」と呼ばれます）、ネットワーク上のコンピュータを電源投入時に使用するディレイを変更するために使用されます。これは非常に長い範囲のARCnetネットワークを配線する場合にのみ必要です（4km程度の範囲）。いずれにしても、ネットワーク上のすべてのカードでETS1およびETS2ジャンパを同じ位置に設定する必要があります。Chris Hindy <chrish@io.org> が実際の値を含むチャートを送信しました：

ETS1, ETS2は非常に長い距離のネットワークでのタイミング制御に使用されます。このファイルの上部にある一般的な情報も参照してください。

J2ジャンパは2ピンのジャンパがあります。このジャンパにはすでに設置されており、私がカードを入手した時点で存在していました。しかし、このジャンパの用途は私にはわかりません。

J3には2つのジャンパが設置されています。用途は不明ですが、私がカードを入手した時点で2つのジャンパがすでに設置されていました。これは2行3列の6ピングリッドです。ジャンパの設定は以下の通りです:

  .-------.
o | o   o |
  :-------:    ------> Accessible end of card with connectors
o | o   o |             in this direction ------->
  `-------'

  • ツイストペアケーブルでバス topologyを使用する場合、J3ジャンパを中間ピンとRJ11コネクタに近いピンを接続するように移動してください。また、J4ジャンパを外してJ4ジャンパの1つのピンに設置してください。

  • ツイストペアケーブルでスター topologyを使用する場合、J3ジャンパを中間ピンとRJ11コネクタに近いピンを接続するように移動してください。
