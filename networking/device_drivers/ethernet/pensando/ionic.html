アダプタの特定¶

ホストに1つ以上Pensando PCI イーサネットデバイスがインストールされているか確認するには、PCIデバイスを確認してください。

$ lspci -d 1dd8:
b5:00.0 Ethernet controller: Device 1dd8:1002
b6:00.0 Ethernet controller: Device 1dd8:1002

上記のようにリストされている場合、ionic.koドライバがそれらを検出し、使用可能に設定する必要があります。カーネルメッセージにこのようなログエントリがあるはずです。

$ dmesg | grep ionic
ionic 0000:b5:00.0: 126.016 Gb/s available PCIe bandwidth (8.0 GT/s PCIe x16 link)
ionic 0000:b5:00.0 enp181s0: renamed from eth0
ionic 0000:b5:00.0 enp181s0: Link up - 100 Gbps
ionic 0000:b6:00.0: 126.016 Gb/s available PCIe bandwidth (8.0 GT/s PCIe x16 link)
ionic 0000:b6:00.0 enp182s0: renamed from eth0
ionic 0000:b6:00.0 enp182s0: Link up - 100 Gbps

ドライバおよびファームウェアのバージョン情報は、ethtoolまたはdevlinkツールのいずれかを使用して取得できます。

$ ethtool -i enp181s0
driver: ionic
version: 5.7.0
firmware-version: 1.8.0-28
...

$ devlink dev info pci/0000:b5:00.0
pci/0000:b5:00.0:
  driver ionic
  serial_number FLM18420073
  versions:
      fixed:
        asic.id 0x0
        asic.rev 0x0
      running:
        fw 1.8.0-28

参照 ionic devlinkサポート devlink dev infoデータについての詳細情報は、以下をご参照ください。

ドライバーの有効化¶

ドライバーは、makeコマンドを使用して標準のカーネル構成システムを介して有効になります：

make oldconfig/menuconfig/etc.

ドライバーは、メニュー構造内の以下に位置しています：

→ デバイスドライバー
→ ネットワークデバイスサポート (NETDEVICES [=y])
→ イーサネットドライバーサポート
-> Pensandoデバイス

-> Pensando イーサネットIONICサポート

ドライバーの設定¶

MTU¶

ジャンボフレームのサポートは、最大9194バイトのサイズで利用可能です。

割り込みのコールセイング¶

割り込みのコールセイングは、「ethtool -C」コマンドでrx-usecs値を変更することで設定できます。rx-usecsの範囲は0〜190です。tx-usecs値は、同じ割り込みで結びつけられているため、rx-usecs値を反映します。

SR-IOV¶

現在、SR-IOVの最小限のサポートが提供されており、ファームウェアの設定に応じてsysfsの’sriov_numvfs’値を設定することで有効化できます。

統計¶

基本的なハードウェア統計情報¶

コマンド netstat -i, ip -s link show, and ifconfig ファームウェアから直接取得された制限された統計情報を表示します。例えば：

$ ip -s link show enp181s0
7: enp181s0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc mq state UP mode DEFAULT group default qlen 1000
    link/ether 00:ae:cd:00:07:68 brd ff:ff:ff:ff:ff:ff
    RX: bytes  packets  errors  dropped overrun mcast
    414        5        0       0       0       0
    TX: bytes  packets  errors  dropped carrier collsns
    1384       18       0       0       0       0

ethtool -S¶

コマンドで表示される統計情報には、ドライバーカウンタとファームウェアカウンタの組み合わせが含まれます。 ethtool -S ドライバーカウンタはドライバーサイドで計算された値であり、ファームウェアカウンタはファームウェアがポートハードウェアから取得した値をドライバーサイドで無加工で通過させるものです。

サポート¶

一般的なLinuxネットワーキングサポートが必要な場合は、Pensando社員が監視しているnetdevメーリングリストをご利用ください：

netdev@vger.kernel.org

より特定のサポートが必要な場合は、Pensandoドライバサポート用メールアドレスをご利用ください：

drivers@pensando.io
