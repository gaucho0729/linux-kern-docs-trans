D-Link DL2000ベースのギガビットイーサネットアダプターのインストール¶

2002年5月23日

互換性リスト¶

アダプターのサポート:

  • D-Link DGE-550Tギガビットイーサネットアダプター。

  • D-Link DGE-550SXギガビットイーサネットアダプター。

  • D-Link DL2000ベースのギガビットイーサネットアダプター。

ドライバーはLinuxカーネル2.4.7以降をサポートしています。以下環境でテスト済みです。

. Red Hat v6.2（カーネルを2.4.7にアップデート） . Red Hat v7.0（カーネルを2.4.7にアップデート） . Red Hat v7.1（カーネル2.4.7） . Red Hat v7.2（カーネル2.4.7-10）

クイックインストール¶

Linuxドライバーを以下のコマンドでインストールしてください:

1. make all
2. insmod dl2k.ko
3. ifconfig eth0 up 10.xxx.xxx.xxx netmask 255.0.0.0
                    ^^^^^^^^^^^^^^^\            ^^^^^^^^\
                                    IP                   NETMASK

eth0がアクティブになるはずです。pingコマンドでテストできます。またはifconfigコマンドで詳細情報を取得できます。テストが完了した場合は次のステップに進んでください。

  1. cp dl2k.ko /lib/modules/`uname -r`/kernel/drivers/net

  2. /etc/modprobe.d/dl2k.confに以下の行を追加してください:

    alias eth0 dl2k

  3. 実行 depmod モジュールインデックスを更新します。

  4. 実行 netconfig または netconf ifcfg-eth0という名前の設定スクリプトを/etc/sysconfig/network-scriptsに作成します。または手動で作成してください。

    [参照 - 設定スクリプトのサンプル]

  5. ドライバーは次の起動時に自動的にロードされ、設定されます。

ドライバーのコンパイル¶

LinuxではNICドライバーは通常ロード可能なモジュールとして構成されます。単一カーネル（monolithic kernel）の構成方法は古くなりましたが、ドライバーを単一カーネルに組み込むことは可能です。ただし強く推奨されません。このセクションの残りはドライバーがロード可能なモジュールとして構成されていると仮定しています。Linux環境では、事前にコンパイルされたバージョンに依存せず、ソースコードからドライバーを再コンパイルすることをお勧めします。これにより、より信頼性が高まります。事前にコンパイルされたドライバーは、特定のLinuxインストールに必要なライブラリやカーネル機能が存在しない可能性があるためです。

Linuxデバイスドライバーを構築するにはdl2k.c、dl2k.h、Makefileの3つのファイルが必要です。コンパイルにはLinuxインストールにgccコンパイラ、カーネルソース、カーネルヘッダーが含まれている必要があります。LinuxドライバーはLinuxカーネル2.4.7をサポートしています。ファイルをディレクトリにコピーし、以下のコマンドでドライバーをコンパイルおよびリンクしてください:

CD-ROMドライブ¶

[root@XXX /] mkdir cdrom
[root@XXX /] mount -r -t iso9660 -o conv=auto /dev/cdrom /cdrom
[root@XXX /] cd root
[root@XXX /root] mkdir dl2k
[root@XXX /root] cd dl2k
[root@XXX dl2k] cp /cdrom/linux/dl2k.tgz /root/dl2k
[root@XXX dl2k] tar xfvz dl2k.tgz
[root@XXX dl2k] make all

フロッピーディスクドライブ¶

[root@XXX /] cd root
[root@XXX /root] mkdir dl2k
[root@XXX /root] cd dl2k
[root@XXX dl2k] mcopy a:/linux/dl2k.tgz /root/dl2k
[root@XXX dl2k] tar xfvz dl2k.tgz
[root@XXX dl2k] make all

ドライバのインストール¶

手動インストール¶

ドライバーがコンパイルされた後、モジュールをロードし、有効化し、プロトコルスタックにバインドする必要があります。モジュールをロードするには以下のコマンドを入力してください:

insmod dl2k.o

または:

insmod dl2k.o <optional parameter>  ; add parameter

例:

 insmod dl2k.o media=100mbps_hd

or::

 insmod dl2k.o media=3

or::

 insmod dl2k.o media=3,2     ; for 2 cards

Linuxデバイスドライバーがサポートするコマンドラインパラメータの一覧を参照してください。

insmodコマンドはドライバーをロードし、eth0、eth1などの名前を付与します。NICを運用状態にするには、以下のコマンドを実行する必要があります。

ifconfig eth0 up

最後に、ドライバーをアクティブなプロトコル（例: Linux 用の TCP/IP）にバインドするには、次のコマンドを入力してください:

ifup eth0

システムが必要なネットワーク情報を持つ構成スクリプトを見つけることができない限り、この情報は意味を持ちません。次の段落でサンプルを示します。

ドライバーをアンロードするコマンドは以下の通りです:

ifdown eth0
ifconfig eth0 down
rmmod dl2k.o

現在ロードされているモジュールを一覧表示し、現在のネットワーク構成を確認するコマンドは以下の通りです:

lsmod
ifconfig

自動化されたインストール¶

このセクションでは、起動時に自動的にロードおよび設定されるようにドライバーをインストールする方法を説明します。以下の説明は Red Hat 6.0/7.0 ディストリビューションに基づいていますが、他のディストリビューションにも簡単に適用可能です。

Red Hat v6.x/v7.x¶

  1. dl2k.o をネットワークモジュールディレクトリにコピーします。通常は /lib/modules/2.x.x-xx/net または /lib/modules/2.x.x/kernel/drivers/net です。

  2. ブートモジュール構成ファイルを確認します。一般的には /etc/modprobe.d/ ディレクトリに存在します。以下の行を追加してください:

    alias ethx dl2k
options dl2k <optional parameters>

    ethx は NIC が唯一のイーサネットアダプターである場合 eth0、1 つの他のイーサネットアダプターがインストールされている場合は eth1 などになります。前のセクションの表を参照してください。

  3. ネットワーク構成スクリプトを確認します。通常は /etc/sysconfig/network-scripts ディレクトリに存在し、ifcfg-ethx という名前の構成スクリプトを作成してネットワーク情報を含めてください。

  4. ほとんどの Linux ディストリビューション（Red Hat 含む）では、ステップ 2 と 3 を実行するためのグラフィカルユーザーインターフェースを持つ構成ユーティリティが提供されています。

パラメータ説明¶

このドライバーをインストールする際には追加パラメータを指定する必要はありません。ただし、広範な機能を使用する場合は、追加パラメータを設定する必要があります。以下に、Linux デバイスドライバーでサポートされるコマンドラインパラメータの一覧を示します。

mtu=パケットサイズ

最大パケットサイズを指定します。デフォルトは 1500 です。

media=メディアタイプ

NIC が動作するメディアタイプを指定します。autosense でアクティブなメディアを自動検出します。

10mbps_hd

10Mbps 半二重モード。

10mbps_fd

10Mbps 全二重モード。

100mbps_hd

100Mbps 半二重モード。

100mbps_fd

100Mbps 全二重モード。

1000mbps_fd

1000Mbps 全二重モード。

1000mbps_hd

1000Mbps 半二重モード。

0

アクティブなメディアを自動検出します。

1

10Mbps 半二重モード。

2

10Mbps 全二重モード。

3

100Mbps 半二重モード。

4

100Mbps 全二重モード。

5

1000Mbps 半二重モード。

6

1000Mbps 全二重モード。

デフォルトでは NIC は autosense モードで動作します。1000mbps_fd および 1000mbps_hd タイプはファイバーアダプター専用です。

vlan=n

VLAN ID を指定します。vlan=0 の場合、仮想ローカルエリアネットワーク（VLAN）機能は無効になります。

jumbo=[0|1]

ジャンボフレームのサポートを指定します。jumbo=1の場合は、NICがジャンボフレームを受け入れます。デフォルトではこの機能は無効です。ジャンボフレームはギガビットネットワークのパフォーマンス向上に一般的に役立ちます。この機能はジャンボフレームをサポートするリモートデバイスが必要です。

rx_coalesce=m

割り込みごとの受信フレーム数を指定します。

rx_timeout=n

Rx DMAが割り込みを待つ時間（ナノ秒単位）を指定します。rx_coalesce > 0に設定した場合、ハードウェアはmフレームが受信されるか、n * 640ナノ秒のタイムアウトが発生するまで割り込みを発生させません。適切なrx_coalesceとrx_timeoutの設定により、高スループットネットワークでのコンゴレーション崩壊やオーバーロードを軽減できます。

例えば、rx_coalesce=10 rx_timeout=800の場合、ハードウェアは10フレームが受信されるか、512マイクロ秒のタイムアウトが発生するまで1つの割り込みを発生させます。

tx_coalesce=n

割り込みごとの送信フレーム数を指定します。n > 1に設定すると、高スループットネットワークカードのパフォーマンス低下を防ぐため、割り込みのコンゴレーションを軽減できます。デフォルトは16です。

tx_flow=[1|0]

送信フロー制御を指定します。tx_flow=0の場合は送信フロー制御を無効にし、それ以外はドライバが自動検出します。

rx_flow=[1|0]

受信フロー制御を指定します。rx_flow=0の場合は受信フロー制御を有効にし、それ以外はドライバが自動検出します。

設定スクリプトの例¶

簡単な設定スクリプトの例は以下の通りです：

DEVICE=eth0
USERCTL=no
ONBOOT=yes
POOTPROTO=none
BROADCAST=207.200.5.255
NETWORK=207.200.5.0
NETMASK=255.255.255.0
IPADDR=207.200.5.2

トラブルシューティング¶

Q1. ソースファイルには各行の末尾に^ Mが含まれています。

すべてのファイルがUnix形式（LFなし）であることを確認してください。以下のシェルコマンドでファイルを変換できます：

cat dl2k.c | col -b > dl2k.tmp
mv dl2k.tmp dl2k.c

OR:

cat dl2k.c | tr -d "\r" > dl2k.tmp
mv dl2k.tmp dl2k.c

Q2: ヘッダーファイルが見つからない（*.h)?

ドライバをコンパイルするには、カーネルヘッダーファイルが必要です。カーネルソースをインストールした後、ヘッダーファイルは通常/usr/src/linux/includeに配置され、これはMakefileで設定されたデフォルトのインクルードディレクトリです。一部のディストリビューションでは、/usr/src/include/linuxおよび/usr/src/include/asmにヘッダーファイルのコピーが存在するため、MakefileのINCLUDEDIRを/usr/includeに変更することも可能です（カーネルソースをインストールせずに）。

RH 7.0では/usr/includeに正しいヘッダーファイルが提供されていないため、これらのファイルを含めると誤ったバージョンのドライバが生成される可能性があります。
