Texas Instruments CPSW switchdevベースのイーサネットディライバー¶

バージョン

2.0

ポートのリネーミング¶

古いudevバージョンではethXをswXpYにリネームする自動サポートは行われません

udevを介してリネームするには:

ip -d link show dev sw0p1 | grep switchid

SUBSYSTEM=="net", ACTION=="add", ATTR{phys_switch_id}==<switchid>, \
        ATTR{phys_port_name}!="", NAME="sw0$attr{phys_port_name}"

デュアルマックモード¶

  • 新しい(cpsw_new.c)ドライバーはデフォルトでデュアルエマックモードで動作し、2つの個別ネットワークインターフェースとして動作します。主な違いは以下の通りです:

  • 最適化されたプロミスカuousモード: P0_UNI_FLOOD（両ポート）がALLMULTI（現在のポート）に加えて有効化され、ALE_BYPASSではなく使用されます。プロミスカuousモードのポートはマルチキャストおよびVLANフィルタリングの可能性を保持し、ポートが同じブリッジに接続されている場合でも「switch」モードを有効化せずに、または異なるブリッジに接続されている場合でも大きな利点を提供します。

  • セグレゲートポートでは学習が無効化されています - ハードウェアでのフォワーディングが意味をなさないためです。

  • devlinkへの基本的なサポートが有効化されています。

    devlink dev show
        platform/48484000.switch

devlink dev param show
platform/48484000.switch:
name switch_mode type driver-specific
values:
        cmode runtime value false
name ale_bypass type driver-specific
values:
        cmode runtime value false

Devlink設定パラメータ¶

参照 ti-cpsw-switch devlinkサポート

デュアルマックモードでのブリッジング¶

デュアルマックモードでは内部用途に2つのVLAN IDが予約される必要があります。デフォルトではCPSWポート番号と等しくなります。結果として、ブリッジはVLAN無関心モードで構成されるか、default_pvidを調整する必要があります:

ip link add name br0 type bridge
ip link set dev br0 type bridge vlan_filtering 0
echo 0 > /sys/class/net/br0/bridge/default_pvid
ip link set dev sw0p1 master br0
ip link set dev sw0p2 master br0

または:

ip link add name br0 type bridge
ip link set dev br0 type bridge vlan_filtering 0
echo 100 > /sys/class/net/br0/bridge/default_pvid
ip link set dev br0 type bridge vlan_filtering 1
ip link set dev sw0p1 master br0
ip link set dev sw0p2 master br0

「switch」の有効化¶

switchモードはdevlinkドライバパラメータ「switch_mode」を1/trueに設定することで有効化できます:

devlink dev param set platform/48484000.switch \
name switch_mode value 1 cmode runtime

ポートのnetdevデバイスの状態（UP/DOWN）に関係なく実行できますが、ブリッジに接続する前にポートのnetdevデバイスがUPになっている必要があります。CPSWスイッチドライバーは最初のポートがUP状態に変化したときに構成を完全に再ロードするため、ブリッジ構成の上書きを防ぐためです。

両インターフェースがブリッジに接続された場合、CPSWスイッチドライバーは「offload_fwd_mark」フラグでパケットをラベル付けします（「ale_bypass=0」の場合は除きます）

すべての設定はswitchdev APIを通じて実行されます。

ブリッジ設定¶

devlink dev param set platform/48484000.switch \
name switch_mode value 1 cmode runtime

ip link add name br0 type bridge
ip link set dev br0 type bridge ageing_time 1000
ip link set dev sw0p1 up
ip link set dev sw0p2 up
ip link set dev sw0p1 master br0
ip link set dev sw0p2 master br0

[*] bridge vlan add dev br0 vid 1 pvid untagged self

[*] if vlan_filtering=1. where default_pvid=1

Note. Steps [*] are mandatory.

STPのオン/オフ¶

ip link set dev BRDEV type bridge stp_state 1/0

VLAN設定¶

bridge vlan add dev br0 vid 1 pvid untagged self <---- add cpu port to VLAN 1

注意. ブリッジ/default_pvidのためこのステップは必須です。

追加のVLANを追加¶

  1. タグなし:

    bridge vlan add dev sw0p1 vid 100 pvid untagged master
bridge vlan add dev sw0p2 vid 100 pvid untagged master
bridge vlan add dev br0 vid 100 pvid untagged self <---- Add cpu port to VLAN100

  2. タグあり:

    bridge vlan add dev sw0p1 vid 100 master
bridge vlan add dev sw0p2 vid 100 master
bridge vlan add dev br0 vid 100 pvid tagged self <---- Add cpu port to VLAN100

FDB¶

FDBは検出時に適切なスイッチポートに自動的に追加されます

手動でのFDB追加:

bridge fdb add aa:bb:cc:dd:ee:ff dev sw0p1 master vlan 100
bridge fdb add aa:bb:cc:dd:ee:fe dev sw0p2 master <---- Add on all VLANs

MDB¶

MDBは検出時に適切なスイッチポートに自動的に追加されます

手動でのMDB追加:

bridge mdb add dev br0 port sw0p1 grp 239.1.1.1 permanent vid 100
bridge mdb add dev br0 port sw0p1 grp 239.1.1.1 permanent <---- Add on all VLANs

マルチキャストフロoding¶

CPUポートのマルチキャストフローリングは常に有効です

スイッチポートのフローリングのオン/オフ: bridge link set dev sw0p1 mcast_flood on/off

アクセスおよびトラクションポート¶

bridge vlan add dev sw0p1 vid 100 pvid untagged master
bridge vlan add dev sw0p2 vid 100 master


bridge vlan add dev br0 vid 100 self
ip link add link br0 name br0.100 type vlan id 100

注意. ブリッジデバイス自体にPVIDを設定する操作はデフォルトVLAN（default_pvid）にのみ適用されます。

NFS¶

NFSが動作する唯一の方法は、スイッチ構成が接続性に影響を与える場合に最小限の環境にchrootする事です。仮にeth1インターフェースでNFSを起動していると仮定します（スクリプトはハッキングしており、NFSが実行可能であることを示すためです）。

setup.sh:

#!/bin/sh
mkdir proc
mount -t proc none /proc
ifconfig br0  > /dev/null
if [ $? -ne 0 ]; then
        echo "Setting up bridge"
        ip link add name br0 type bridge
        ip link set dev br0 type bridge ageing_time 1000
        ip link set dev br0 type bridge vlan_filtering 1

        ip link set eth1 down
        ip link set eth1 name sw0p1
        ip link set dev sw0p1 up
        ip link set dev sw0p2 up
        ip link set dev sw0p2 master br0
        ip link set dev sw0p1 master br0
        bridge vlan add dev br0 vid 1 pvid untagged self
        ifconfig sw0p1 0.0.0.0
        udhchc -i br0
fi
umount /proc

run_nfs.sh::

#!/bin/sh
mkdir /tmp/root/bin -p
mkdir /tmp/root/lib -p

cp -r /lib/ /tmp/root/
cp -r /bin/ /tmp/root/
cp /sbin/ip /tmp/root/bin
cp /sbin/bridge /tmp/root/bin
cp /sbin/ifconfig /tmp/root/bin
cp /sbin/udhcpc /tmp/root/bin
cp /path/to/setup.sh /tmp/root/bin
chroot /tmp/root/ busybox sh /bin/setup.sh

run ./run_nfs.sh
