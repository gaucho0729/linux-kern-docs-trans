アダプターの特定¶

コマンドラインパラメータ¶

ドライバがモジュールとして構築されている場合、以下のオプションパラメータはmodprobeコマンドを使用してコマンドラインに入力することで使用されます。

modprobe igb [<option>=<VAL1>,<VAL2>,...]

このドライバがサポートするシステム内の各ネットワークポートには<VAL#>が必要です。値はファンクション順に各インスタンスに適用されます。例えば：

modprobe igb max_vfs=2,4

この場合、システムには igb がサポートする 2 つのネットワークポートがあります。

注意：デスクリプターはデータバッファとその関連する属性を記述します。この情報はハードウェアによってアクセスされます。

max_vfs¶

有効な範囲

0-7

このパラメータは SR-IOV のサポートを追加します。これにより、ドライバーが max_vfs に相当する仮想関数を生成します。値が 0 より大きい場合、VMDq パラメータが 1 またはそれ以上になるように強制します。

ドライバーのパラメータは位置によって参照されます。したがって、システムにデュアルポートアダプタや複数のアダプタがあり、各ポートごとに N 個の仮想関数を希望する場合、各ポートに対して数字を指定し、各パラメータをコンマで区切ってください。たとえば：

modprobe igb max_vfs=4

これは最初のポートに 4 個の VF を生成します。

modprobe igb max_vfs=2,4

これは最初のポートに 2 個の VF を生成し、2 番目のポートに 4 個の VF を生成します。

注意: これらのパラメータでドライバーをロードする際には注意が必要です。システムの構成、スロット数などに応じて、コマンドラインでの位置がすべての場合で予測できない可能性があります。

注意: デバイスもしくはドライバーがVFがコンフィギュレーションスペースにマッピングされる方法を制御しません。バスレイアウトはオペレーティングシステムによって異なります。サポートしているOSではsysfsを確認してマッピングを確認できます。

注意: SR-IOV モードまたは VMDq モードが有効になっている場合、ハードウェア VLAN フィルタリングおよび VLAN タグの除去/挿入は有効のままです。新しい VLAN フィルタを追加する前に、古い VLAN フィルタを削除してください。たとえば：

ip link set eth0 vf 0 vlan 100      // set vlan 100 for VF 0
ip link set eth0 vf 0 vlan 0        // Delete vlan 100
ip link set eth0 vf 0 vlan 200      // set a new vlan 200 for VF 0

Debug¶

有効な範囲

0-16（0=なし,…,16=すべて）

デフォルト値

0

このパラメータは、システムログに表示されるデバッグメッセージのレベルを調整します。

追加の機能と設定¶

ジャンボフレーム¶

ジャンボフレームのサポートは、最大送信ユニット（MTU）をデフォルト値1500より大きい値に変更することで有効になります。

ifconfigコマンドを使用してMTUサイズを増やすことができます。例えば、<x>はインターフェース番号で、以下のコマンドを入力してください:

ifconfig eth<x> mtu 9000 up

代わりに、ipコマンドを使用することもできます:

ip link set mtu 9000 dev eth<x>
ip link set up dev eth<x>

この設定は再起動時に保持されません。設定変更を永続化するには、以下のファイルに'MTU=9000'を追加してください:

  • RHELの場合: /etc/sysconfig/network-scripts/ifcfg-eth<x>

  • SLESの場合: /etc/sysconfig/network/<config_file>

注意: ジャンボフレームの最大 MTU 設定は 9216 です。この値は、最大ジャンボフレームサイズの 9234 バイトと一致します。

注意: 10または100Mbpsでジャンボフレームを使用することはサポートされておらず、パフォーマンス低下やリンク喪失を引き起こす可能性があります。

ethtool¶

ドライバーはethtoolインターフェースを使用してドライバーの設定および診断、統計情報の表示を行います。この機能には最新のethtoolバージョンが必要です。ダウンロードはこちら:

https://www.kernel.org/pub/software/network/ethtool/

Wake on LAN（WoL）の有効化¶

WoLはethtoolユーティリティを通じて設定されます。

次のシャットダウンまたは再起動時にシステムで WoL が有効になります。このドライバーのバージョンでは、WoL を有効にするには、シャットダウンまたはスリープする前に igb ドライバーをロードする必要があります。

注意: Wake on LAN はマルチポートデバイスのポート A でのみサポートされます。また、次のデバイスではサポートされていません: - Intel(R) ギガビット VT クォッドポートサーバー アダプター

マルチキュー¶

このモードでは、各キューに対して個別の MSI-X ベクターが割り当てられ、リンクステータスの変更やエラーなどの「その他の」割込みにも 1 つ割り当てられます。すべての割込みは割込みモデレーションを通じて制御されます。割込みモデレーションを使用して、ドライバーが 1 つの割込みを処理している間の割込みストームを回避する必要があります。モデレーション値は、ドライバーが割込みを処理するのに必要な時間以上になる必要があります。マルチキューはデフォルトでオフです。

要件: マルチキューには MSI-X のサポートが必要です。MSI-X が見つからない場合、システムは MSI またはレガシーアクセスにフォールバックします。このドライバーは、MSI-X をサポートするすべてのカーネルで受信マルチキューをサポートします。

注意: 一部のカーネルでは、シングルキューモードとマルチキューモードの切り替えには再起動が必要です。

MACおよびVLANアンチスプーフィング機能¶

悪意のあるドライバーがスプーフィングパケットを送信しようとした場合、ハードウェアによってパケットが破棄され、送信されません。

PFドライバーに割り込みが送られ、スプーフィングの試行を通知します。スプーフィングパケットが検出された場合、PFドライバーはシステムログに以下のメッセージを出力します（"dmesg"コマンドで表示されます）："VF(n)でスプーフィングイベントが検出されました"、ここでnはスプーフィングを試みたVFです。

MACアドレス、VLANおよびレート制限の設定（IProute2ツールを使用して）¶

IProute2ツールを使用して、仮想ファンクション（VF）のMACアドレス、デフォルトVLANおよびレート制限を設定できます。必要な機能がすべて含まれていない場合は、Sourceforgeから最新版のIProute2ツールをダウンロードしてください。

クレジットベースのシャーパー（Qavモード）¶

ハードウェアオフロードモードでCBS qdiscを有効にすると、IEEE 802.1Q-2018 Section 8.6.8.2およびAnnex Lで説明されているCBSアルゴリズムがi210コントローラー内で動作し、より正確でCPU使用率も低くなります。

オフロードされたCBSを使用する場合、トラフィックレートが設定されたレートを越えない限り、レイテンシーにほとんど影響を与えません。

オフロード版のアルゴリズムには、アダプタのレジスタでアイドルスロープが表現される仕様の制限があります。アイドルスロープは16.38431 kbps単位でしか表現できず、2576kbpsのアイドルスロープが要求された場合、コントローラーは2589kbps程度の値に設定されます（ドライバーが値を四捨五入しているため）。詳細については、以下のコメントを参照してください igb_config_tx_modes().

注意: この機能はi210モデル専用です。
