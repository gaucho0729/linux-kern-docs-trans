ページプールAPI¶

page_pool アロケータは、1ページあたり1フレームを使用する XDP モードに最適化されていますが、通常のページ アロケータ API にフォールバックすることも可能です。

基本的な使用方法は、alloc_pages() 呼び出しを page_pool_alloc_pages() 呼び出しに置き換えることです。ドライバでは、dev_alloc_pages() を page_pool_dev_alloc_pages() に置き換える必要があります。

API は進行中のページを追跡し、API ユーザーがページプールオブジェクトを安全に解放できるタイミングを通知します。そのため、API ユーザーは、ページが page_pool から離れる際には page_pool_release_page() を呼び出し、必要に応じて page_pool_put_page() を呼び出して正しく会計を維持する必要があります。

API ユーザーは、ページに対して page_pool_put_page() を1回呼び出す必要があります。これは、ページを再利用するか、参照カウントが1より大きい場合、DMA マッピングと進行中の状態の会計を解放します。

アーキテクチャ概要¶

+------------------+
|       Driver     |
+------------------+
        ^
        |
        |
        |
        v
+--------------------------------------------+
|                request memory              |
+--------------------------------------------+
    ^                                  ^
    |                                  |
    | Pool empty                       | Pool has entries
    |                                  |
    v                                  v
+-----------------------+     +------------------------+
| alloc (and map) pages |     |  get page from cache   |
+-----------------------+     +------------------------+
                                ^                    ^
                                |                    |
                                | cache available    | No entries, refill
                                |                    | from ptr-ring
                                |                    |
                                v                    v
                      +-----------------+     +------------------+
                      |   Fast cache    |     |  ptr-ring cache  |
                      +-----------------+     +------------------+

APIインターフェース¶

作成されたプールの数 grace periodsを尊重しなければなりませんし、 ハードウェア キューの数に一致させる必要があります（ハードウェアの制限で不可能な場合を除く）。これは、ページプールの目的であるロックなしでキャッシュからページを高速に割り当てるためのものです。このロックなしの保証は、NAPI ソフティルクで実行されることで自然に得られます。保護は厳密には NAPI である必要はなく、ページの割り当てがレース条件を引き起こさないことを保証するだけで十分です。

  • page_pool_create(): プールを作成します。

    • flags: PP_FLAG_DMA_MAP, PP_FLAG_DMA_SYNC_DEV

    • order: 割り当て時に 2^order ページを使用します

    • pool_size: ptr_ring のサイズ

    • nid: 割り当てのための推奨 NUMA ノード

    • dev: struct device. DMA 操作で使用されます

    • dma_dir: DMA 方向

    • max_len: 最大 DMA 同期メモリサイズ

    • offset: DMA アドレスオフセット

  • page_pool_put_page(): この結果はページの参照カウントに依存します。ドライバが参照カウントを1より大きくする場合、この関数はページをアンマップします。参照カウントが1の場合、アロケータがページを所有しており、プールキャッシュのいずれかで再利用を試みます。PP_FLAG_DMA_SYNC_DEV が設定されている場合、dma_sync_single_range_for_device() を使用してデバイス用に同期されます。

  • page_pool_put_full_page(): page_pool_put_page() と同様ですが、area プール->max_len で設定されたメモリ領域全体を DMA 同期します。

  • page_pool_recycle_direct(): page_pool_put_full_page() と同様ですが、呼び出し元が安全なコンテキスト（例: NAPI）を保証しなければならないため、プールの高速キャッシュに直接ページを再利用します。

  • page_pool_release_page(): ページをアンマップ（マップされている場合）し、進行中のカウンターに記録します。

  • page_pool_dev_alloc_pages(): ページ アロケータまたはページプール キャッシュからページを取得します。

  • page_pool_get_dma_addr(): 保存された DMA アドレスを取得します。

  • page_pool_get_dma_dir(): 保存された DMA 方向を取得します。

コーディング例¶

登録¶

/* Page pool registration */
struct page_pool_params pp_params = { 0 };
struct xdp_rxq_info xdp_rxq;
int err;

pp_params.order = 0;
/* internal DMA mapping in page_pool */
pp_params.flags = PP_FLAG_DMA_MAP;
pp_params.pool_size = DESC_NUM;
pp_params.nid = NUMA_NO_NODE;
pp_params.dev = priv->dev;
pp_params.dma_dir = xdp_prog ? DMA_BIDIRECTIONAL : DMA_FROM_DEVICE;
page_pool = page_pool_create(&pp_params);

err = xdp_rxq_info_reg(&xdp_rxq, ndev, 0);
if (err)
    goto err_out;

err = xdp_rxq_info_reg_mem_model(&xdp_rxq, MEM_TYPE_PAGE_POOL, page_pool);
if (err)
    goto err_out;

NAPI ポoller¶

/* NAPI Rx poller */
enum dma_data_direction dma_dir;

dma_dir = page_pool_get_dma_dir(dring->page_pool);
while (done < budget) {
    if (some error)
        page_pool_recycle_direct(page_pool, page);
    if (packet_is_xdp) {
        if XDP_DROP:
            page_pool_recycle_direct(page_pool, page);
    } else (packet_is_skb) {
        page_pool_release_page(page_pool, page);
        new_page = page_pool_dev_alloc_pages(page_pool);
    }
}

ドライバのアンロード¶

/* Driver unload */
page_pool_put_full_page(page_pool, page, false);
xdp_rxq_info_unreg(&xdp_rxq);
