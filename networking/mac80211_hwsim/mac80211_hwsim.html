はじめに¶

mac80211_hwsimは、mac80211で動作するIEEE 802.11無線を任意の数シミュレートできるLinuxカーネルモジュールです。リアルなWLANハードウェアを使用する場合と同様に、mac80211の機能やユーザー空間ツール（例: hostapdやwpa_supplicant）をテストできます。mac80211の観点では、mac80211_hwsimは別のハードウェアドライバとみなされ、mac80211の変更は必要ありません。

mac80211_hwsimの主な目的は、開発者がコードをテストし、mac80211、hostapd、wpa_supplicantの新機能と取り組みやすくなることです。シミュレートされた無線は実機の制限を持たないため、任意のテスト環境を簡単に構築し、将来のテストでも同じ環境を再現できます。また、すべての無線操作がシミュレートされるため、規制規則に関係なく任意のチャネルをテストできます。

mac80211_hwsimカーネルモジュールには「radios」というパラメータがあり、シミュレートする無線の数を指定できます（デフォルトは2）。これにより、単純な設定（例: 単一のアクセスポイントとステーション）から大規模なテスト（複数のアクセスポイントと数百のステーション）まで構成できます。

mac80211_hwsimは、仮想無線の現在のチャネルを追跡し、送信フレームをすべての有効な無線にコピーすることで動作します。ソフトウェアによる暗号化を活用し、仮想空インターフェースでの暗号化を実現することで、より完全な暗号テストが可能になります。

グローバルなモニタリングネットワークデバイス（hwsim#）がmac80211とは独立して作成されます。このインターフェースは、チャネルに関係なくすべての送信フレームをモニタリングできます。

シンプルな例¶

この例では、mac80211_hwsimを使用して2つの無線をシミュレートする方法を示します。1つはアクセスポイントとして動作し、もう1つはAPに接続するステーションとして動作します。WPA2-PSK認証はhostapdとwpa_supplicantで処理され、hostapdはアクセスポイント側の接続処理も担当します。

# Build mac80211_hwsim as part of kernel configuration

# Load the module
modprobe mac80211_hwsim

# Run hostapd (AP) for wlan0
hostapd hostapd.conf

# Run wpa_supplicant (station) for wlan1
wpa_supplicant -Dnl80211 -iwlan1 -c wpa_supplicant.conf

さらに多くのテストケースはhostap.gitリポジトリにあります: git://w1.fi/srv/git/hostap.git および mac80211_hwsim/testsサブディレクトリ（http://w1.fi/gitweb/gitweb.cgi?p=hostap.git;a=tree;f=mac80211_hwsim/tests）
