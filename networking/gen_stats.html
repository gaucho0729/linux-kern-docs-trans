ネットリンクユーザー向けジェネリックネットワーキング統計¶

統計カウンタは構造体にグループ化されています:

構造体

TLVタイプ

説明

gnet_stats_basic

TCA_STATS_BASIC

基本統計情報

gnet_stats_rate_est

TCA_STATS_RATE_EST

レート推定器

gnet_stats_queue

TCA_STATS_QUEUE

キュー統計情報

none

TCA_STATS_APP

アプリケーション固有

収集:¶

必要な統計構造体を宣言してください:

struct mystruct {
        struct gnet_stats_basic bstats;
        struct gnet_stats_queue qstats;
        ...
};

デキュー()メソッドでのみ統計情報を更新してください (qdisc->runningを保持している間):

mystruct->tstats.packet++;
mystruct->qstats.backlog += skb->pkt_len;

ユーザー空間へのエクスポート (ダンプ):¶

my_dumping_routine(struct sk_buff *skb, ...)
{
        struct gnet_dump dump;

        if (gnet_stats_start_copy(skb, TCA_STATS2, &mystruct->lock, &dump,
                                TCA_PAD) < 0)
                goto rtattr_failure;

        if (gnet_stats_copy_basic(&dump, &mystruct->bstats) < 0 ||
            gnet_stats_copy_queue(&dump, &mystruct->qstats) < 0 ||
                gnet_stats_copy_app(&dump, &xstats, sizeof(xstats)) < 0)
                goto rtattr_failure;

        if (gnet_stats_finish_copy(&dump) < 0)
                goto rtattr_failure;
        ...
}

TCA_STATS/TCA_XSTATSの後方互換性:¶

以前のtc_stats構造体とxstatsを使用していたユーザーは、既存のTLVタイプを保持するために互換性用ラッパーを呼び出すことで後方互換性を維持できます:

my_dumping_routine(struct sk_buff *skb, ...)
{
    if (gnet_stats_start_copy_compat(skb, TCA_STATS2, TCA_STATS,
                                    TCA_XSTATS, &mystruct->lock, &dump,
                                    TCA_PAD) < 0)
                goto rtattr_failure;
        ...
}

tc_stats構造体はgnet_stats_copy_*呼び出し中に自動的に埋められ、skbに追加されます。gnet_stats_copy_appが呼び出された場合、TCA_XSTATSが提供されます。

ロック:¶

ロックは書き込み前に取得され、すべての統計情報が書き込まれた後には解放されます。エラーが発生した場合でも常にロックが解放されます。ロックが初期化されていることをあなたが責任をもって確認してください。

レート推定器:¶

  1. 推定器属性を準備してください。これはおそらくユーザー空間にあります。このTLVの値にはtc_estimator構造体を含める必要があります。通常、このようなTLVは32ビットアライメントが必要であり、長さが適切に設定されている必要があります。推定器のインターバルとewmaログは適切な値に変換する必要があります。tc_estimator.c::tc_setup_estimator()を変換ルーチンとして使用することをお勧めします。これはいくつかの巧妙な処理を行います。マイクロ秒単位の時間間隔、時間定数もマイクロ秒単位で、埋め込むtc_estimator構造体を引数として受け取ります。返されたtc_estimator構造体はカーネルに転送できます。このような構造体をカーネル内のコードにTCA_RATEタイプのTLVとして転送してください。

カーネルで設定を行う際:

  1. まず基本統計情報とレート統計情報を設定してください。

  2. 統計情報の設定に使用するstatsロックを初期化していることを確認してください。

  3. 新しい推定器を初期化してください:

    int ret = gen_new_estimator(my_basicstats,my_rate_est_stats,
    mystats_lock, attr_with_tcestimator_struct);

if ret == 0
    success
else
    failed

これ以降、毎回my_rate_est_statsをダンプすると最新の情報が含まれます。

完了後、gen_kill_estimator(my_basicstats, my_rate_est_stats)を呼び出してください。my_basicstatsとmy_rate_est_statsが呼び出し時点でも有効であることを確認してください (つまり、まだ存在していること)。
