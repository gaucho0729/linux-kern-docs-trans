3.1. 概要¶

3.1.1. SR-IOVとは¶

単一ルートI/O仮想化（SR-IOV）は、PCI Express拡張機能の一つで、1つの物理デバイスが複数の仮想デバイスとして見えるようにします。この物理デバイスはPhysical Function（PF）と呼ばれ、仮想デバイスはVirtual Function（VF）と呼ばれます。VFの割当は、PFがキャパビリティ内に格納されたレジスタを介して動的に制御できます。デフォルトではこの機能は無効で、PFは従来のPCIeデバイスとして動作します。有効化されると、各VFのPCI構成空間は自身のバス、デバイス、ファンクション番号（ルーティングID）でアクセス可能になります。また、各VFにはPCIメモリ空間があり、これによりレジスタセットをマッピングします。VFデバイスドライバーはこのレジスタセットを操作するため、実在するPCIデバイスとして機能します。

3.2. ユーザー向けガイド¶

3.2.1. SR-IOV機能を有効にするには¶

SR-IOVの有効化には複数の方法があります。第一の方法では、デバイスドライバー（PFドライバー）がSR-IOVコアが提供するAPIを介して機能の有効化/無効化を制御します。ハードウェアがSR-IOV機能をサポートしている場合、そのPFドライバーをロードすることで機能が有効になり、関連するすべてのVFも有効になります。一部のPFドライバーでは、VFの数を指定するモジュールパラメータを設定する必要があります。第二の方法では、sysfsファイルsriov_numvfsへの書き込みで、PCIe PFに関連するVFの有効化/無効化を行います。この方法では、第一の方法とは異なり、各PFごとにVFの有効化/無効化を個別に設定できます。さらに、PCI SRIOVコアは有効化/無効化操作の正当性を保証し、複数のドライバーで同じチェックを繰り返すことを防ぎます（例：VFを有効化する際にはnumvfs == 0を確認、numvfs <= totalvfsを確保）。第二の方法は新規/今後のVFデバイスの有効化に推奨されます。

3.2.2. Virtual Functionを使用するには¶

VFはカーネル内でホットプラグされたPCIデバイスとして扱われるため、実際のPCIデバイスと同様に動作する必要があります。VFには、通常のPCIデバイスと同じドライバーが必要です。

3.3. 開発者向けガイド¶

3.3.1. SR-IOV API¶

SR-IOV機能を有効にするには:

  1. 第一の方法ではドライバー内で:

    int pci_enable_sriov(struct pci_dev *dev, int nr_virtfn);

nr_virtfnは有効にするVFの数です。

  1. 第二の方法ではsysfsから:

    echo 'nr_virtfn' > \
/sys/bus/pci/devices/<DOMAIN:BUS:DEVICE.FUNCTION>/sriov_numvfs

SR-IOV機能を無効にするには:

  1. 第一の方法ではドライバー内で:

    void pci_disable_sriov(struct pci_dev *dev);

  2. 第二の方法ではsysfsから:

    echo  0 > \
/sys/bus/pci/devices/<DOMAIN:BUS:DEVICE.FUNCTION>/sriov_numvfs

ホスト上で互換性のあるドライバーでVFを自動的にプローブするには、SR-IOV機能を有効化する前に以下のコマンドを実行してください。これはデフォルトの動作です。

echo 1 > \
/sys/bus/pci/devices/<DOMAIN:BUS:DEVICE.FUNCTION>/sriov_drivers_autoprobe

ホスト上の互換性のあるドライバーによるVFの自動プローブを無効にするには、SR-IOV機能を有効にする前に以下のコマンドを実行してください。このエントリの更新は、すでにプローブされたVFには影響を与えません。

echo  0 > \
/sys/bus/pci/devices/<DOMAIN:BUS:DEVICE.FUNCTION>/sriov_drivers_autoprobe

3.3.2. 使用例¶

以下のコード例はSR-IOV APIの使用方法を示しています。

static int dev_probe(struct pci_dev *dev, const struct pci_device_id *id)
{
        pci_enable_sriov(dev, NR_VIRTFN);

        ...

        return 0;
}

static void dev_remove(struct pci_dev *dev)
{
        pci_disable_sriov(dev);

        ...
}

static int dev_suspend(struct pci_dev *dev, pm_message_t state)
{
        ...

        return 0;
}

static int dev_resume(struct pci_dev *dev)
{
        ...

        return 0;
}

static void dev_shutdown(struct pci_dev *dev)
{
        ...
}

static int dev_sriov_configure(struct pci_dev *dev, int numvfs)
{
        if (numvfs > 0) {
                ...
                pci_enable_sriov(dev, numvfs);
                ...
                return numvfs;
        }
        if (numvfs == 0) {
                ....
                pci_disable_sriov(dev);
                ...
                return 0;
        }
}

static struct pci_driver dev_driver = {
        .name =         "SR-IOV Physical Function driver",
        .id_table =     dev_id_table,
        .probe =        dev_probe,
        .remove =       dev_remove,
        .suspend =      dev_suspend,
        .resume =       dev_resume,
        .shutdown =     dev_shutdown,
        .sriov_configure = dev_sriov_configure,
};
