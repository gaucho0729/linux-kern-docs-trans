9.5. PCI Test User Guide¶

著者

Kishon Vijay Abraham I <kishon@ti.com>

このドキュメントは、ユーザーがpci-epf-testファンクションドライバーおよびpci_endpoint_testホストドライバーを使用してPCIをテストする際のガイドです。ホスト側およびEP側で実行すべき手順の一覧が以下に記載されています。

9.5.1. エンドポイントデバイス¶

9.5.1.1. エンドポイントコントローラーデバイス¶

システム内のエンドポイントコントローラーデバイスの一覧を確認するには:

# ls /sys/class/pci_epc/
  51000000.pcie_ep

PCI_ENDPOINT_CONFIGFSが有効化されている場合:

# ls /sys/kernel/config/pci_ep/controllers
  51000000.pcie_ep

9.5.1.2. エンドポイントファンクションドライバー¶

システム内のエンドポイントファンクションドライバーの一覧を確認するには:

# ls /sys/bus/pci-epf/drivers
  pci_epf_test

PCI_ENDPOINT_CONFIGFSが有効化されている場合:

# ls /sys/kernel/config/pci_ep/functions
  pci_epf_test

9.5.1.3. pci-epf-testデバイスの作成¶

PCIエンドポイントファンクションデバイスはconfigfsを使用して作成できます。pci-epf-testデバイスを作成するには、以下のコマンドを使用できます:

# mount -t configfs none /sys/kernel/config
# cd /sys/kernel/config/pci_ep/
# mkdir functions/pci_epf_test/func1

上記の「mkdir func1」は、pci_epf_testドライバーによって検出されるpci-epf-testファンクションデバイスを作成します。

PCIエンドポイントフレームワークは、以下の設定可能なフィールドでディレクトリを埋め込みます:

# ls functions/pci_epf_test/func1
  baseclass_code        interrupt_pin   progif_code     subsys_id
  cache_line_size       msi_interrupts  revid           subsys_vendorid
  deviceid              msix_interrupts subclass_code   vendorid

PCIエンドポイントファンクションドライバーは、デバイスがドライバーにバインドされたときにこれらのエントリをデフォルト値で埋め込みます。pci-epf-testドライバーはvendoridを0xffff、interrupt_pinを0x0001で埋め込みます:

# cat functions/pci_epf_test/func1/vendorid
  0xffff
# cat functions/pci_epf_test/func1/interrupt_pin
  0x0001

9.5.1.4. pci-epf-testデバイスの設定¶

ユーザーはconfigfsエントリを使用してpci-epf-testデバイスを設定できます。ファンクションデバイスが使用するvendoridやMSI割込みの数を変更するには、以下のコマンドを使用できます:

# echo 0x104c > functions/pci_epf_test/func1/vendorid
# echo 0xb500 > functions/pci_epf_test/func1/deviceid
# echo 16 > functions/pci_epf_test/func1/msi_interrupts
# echo 8 > functions/pci_epf_test/func1/msix_interrupts

9.5.1.5. pci-epf-testデバイスをEPコントローラーにバインドする¶

エンドポイントファンクションデバイスが役に立つためには、PCIエンドポイントコントローラードライバーにバインドする必要があります。以下のコマンドを使用して、configfsでファンクションデバイスをシステム内のコントローラードライバーのいずれかにバインドできます:

# ln -s functions/pci_epf_test/func1 controllers/51000000.pcie_ep/

上記の手順が完了すると、PCIエンドポイントがホストとリンクを確立する準備ができています。

9.5.1.6. リンクの開始¶

エンドポイントデバイスがホストとリンクを確立するには、_start_フィールドに'1'を設定する必要があります:

# echo 1 > controllers/51000000.pcie_ep/start

9.5.2. RootComplexデバイス¶

9.5.2.1. lspci出力¶

以下のデバイス一覧は、1.4で設定された値に対応しています:

00:00.0 PCI bridge: Texas Instruments Device 8888 (rev 01)
01:00.0 Unassigned class [ff00]: Texas Instruments Device b500

9.5.2.2. エンドポイントテストファンクションデバイスの使用¶

tools/pci/に追加されたpcitest.shは、すべてのデフォルトPCIエンドポイントテストを実行するために使用できます。このツールをコンパイルするには、以下のコマンドを使用してください:

# cd <kernel-dir>
# make -C tools/pci

または、システムにコンパイルしてインストールしたい場合は:

# cd <kernel-dir>
# make -C tools/pci install

ツールとスクリプトは<rootfs>/usr/bin/に配置されます。
