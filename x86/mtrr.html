12. MTRR (メモリタイプ範囲レジスタ)制御¶

著者

  • Richard Gooch <rgooch@atnf.csiro.au> - 1999年6月3日

  • Luis R. Rodriguez <mcgrof@do-not-panic.com> - 2015年4月9日

12.1. MTRRの使用を段階的に廃止する¶

現代のx86ハードウェアでは、MTRRの使用はPATによって置き換えられています。Linuxのドライバが直接MTRRを使用することは現在完全に廃止され、デバイスドライバはioremap_wc()と組み合わせて使用する必要があります。 arch_phys_wc_add() 非PATシステムではMTRRの効果を発揮させながら、PATが有効なシステムでは無効ですが同等の効果を発揮します。

Linuxが直接MTRRを使用しなくても、一部のx86プラットフォームファームウェアはOSの起動前にMTRRを初期設定することがあります。これは、一部のプラットフォームファームウェアがMTRRへのアクセスを実装しているためで、プラットフォームファームウェアが直接制御・処理を行うためです。プラットフォームでのMTRRの使用例はSMIハンドラを通じたものです。例えばファン制御では、プラットフォームコードがファン制御レジスタへの非キャッシュ可能なアクセスを必要とする場合があります。このようなプラットフォームアクセスには、mtrr_type_lookup()を除けばOS側のMTRRコードは必要ありません。MTRRはプラットフォームファームウェアコードのみで設定され、OSが特定のMTRRマッピングを要求しなければmtrr_type_lookup()は常にMTRR_TYPE_INVALIDを返します。

For details refer to PAT (Page Attribute Table).

ヒント

Intel P6ファミリプロセッサ（Pentium Pro、Pentium II以降）では、メモリタイプレンジレジスタ（MTRR）を使用してプロセッサのメモリ範囲へのアクセスを制御できます。これはPCIまたはAGPバスに接続されたビデオ（VGA）カードがある場合に特に有用です。ライトコンビンを有効にすると、バスのライト転送がPCI/AGPバスでのブースト前に大きな転送に統合されるため、画像のライト操作のパフォーマンスが2.5倍以上向上します。

Cyrix 6x86、6x86MXおよびM IIプロセッサはアドレスレンジレジスタ（ARR）を持ち、MTRRと同様の機能を提供します。これらではARRをMTRRをエミュレートするために使用します。

AMD K6-2（ステッピング8以上）およびK6-3プロセッサは2つのMTRRを持ち、これらはサポートされています。AMD Athlonファミリは8つのIntelスタイルのMTRRを提供します。

Centaur C6（WinChip）は8つのMCRを持ち、ライトコンビンを可能にします。これらはサポートされています。

VIA Cyrix IIIおよびVIA C3 CPUは8つのIntelスタイルのMTRRを提供します。

CONFIG_MTRRオプションは/proc/mtrrファイルを生成し、MTRRの操作に使用できます。通常、Xサーバーはこのファイルを使用します。このインターフェースは他のプロセッサの類似した制御レジスタを容易にサポートできるように、比較的一般的なインターフェースであるべきです。

/proc/mtrr には2つのインターフェースがあります。1つはASCIIインターフェースで、読み書きが可能です。もう1つはioctl()インターフェースです。ASCIIインターフェースは管理用に設計されており、ioctl()インターフェースはCプログラム（つまりXサーバー）用に設計されています。以下にインターフェースの説明を示します。サンプルコマンドとC言語のコードも含まれます。

12.2. シェルからMTRRを読み取る¶

% cat /proc/mtrr
reg00: base=0x00000000 (   0MB), size= 128MB: write-back, count=1
reg01: base=0x08000000 ( 128MB), size=  64MB: write-back, count=1

CシェルからMTRRを作成する:

# echo "base=0xf8000000 size=0x400000 type=write-combining" >! /proc/mtrr

bashを使用している場合、

# echo "base=0xf8000000 size=0x400000 type=write-combining" >| /proc/mtrr

その結果は以下の通り:

% cat /proc/mtrr
reg00: base=0x00000000 (   0MB), size= 128MB: write-back, count=1
reg01: base=0x08000000 ( 128MB), size=  64MB: write-back, count=1
reg02: base=0xf8000000 (3968MB), size=   4MB: write-combining, count=1

これはベースアドレス0xf8000000で4メガバイトのビデオRAMです。ベースアドレスを確認するには、Xサーバーの出力結果を確認する必要があります。これはラインフレームバッファのアドレスを示しています。得られる典型的な行は以下の通りです:

(--) S3: PCI: 968 rev 0, Linear FB @ 0xf8000000

注意: Xサーバーからの値のみを使用してください。フレームバッファベースアドレスが動く可能性があるため、信頼できる値はXサーバーが報告するものです。

フレームバッファのサイズ（あなたが実際に知らない？）を確認するには、以下の行が役立ちます:

(--) S3: videoram:  4096k

これは4メガバイトで、0x400000バイト（16進数）です。XFree86向けのパッチが作成されており、これにより自動化されます。つまりXサーバーはioctl()インターフェースを使用して/proc/mtrrを操作するため、ユーザーは何もしなくて済みます。商用Xサーバーを使用している場合は、ベンダーにMTRRのサポートを追加してもらうよう要請してください。

12.3. 重なったMTRRを作成する¶

%echo "base=0xfb000000 size=0x1000000 type=write-combining" >/proc/mtrr
%echo "base=0xfb000000 size=0x1000 type=uncachable" >/proc/mtrr

その結果は以下の通り:

% cat /proc/mtrr
reg00: base=0x00000000 (   0MB), size=  64MB: write-back, count=1
reg01: base=0xfb000000 (4016MB), size=  16MB: write-combining, count=1
reg02: base=0xfb000000 (4016MB), size=   4kB: uncachable, count=1

一部のカード（特にVoodoo Graphicsボード）では、この4キロバイトの領域を領域の開始部から除外する必要があります。これはレジスタに使用されるためです。

注意: 最初に作成した領域がtype=write-combiningの場合のみ、type=uncachableの領域を作成できます。

12.4. CシェルからMTRRを削除する¶

% echo "disable=2" >! /proc/mtrr

bashを使用して:

% echo "disable=2" >| /proc/mtrr

/*
    This program will use an ioctl() on /proc/mtrr to show the current MTRR
    settings. This is an alternative to reading /proc/mtrr.


    Written by      Richard Gooch   17-DEC-1997

    Last updated by Richard Gooch   2-MAY-1998


*/
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/types.h>
#include <sys/stat.h>
#include <fcntl.h>
#include <sys/ioctl.h>
#include <errno.h>
#include <asm/mtrr.h>

#define TRUE 1
#define FALSE 0
#define ERRSTRING strerror (errno)

static char *mtrr_strings[MTRR_NUM_TYPES] =
{
    "uncachable",               /* 0 */
    "write-combining",          /* 1 */
    "?",                        /* 2 */
    "?",                        /* 3 */
    "write-through",            /* 4 */
    "write-protect",            /* 5 */
    "write-back",               /* 6 */
};

int main ()
{
    int fd;
    struct mtrr_gentry gentry;

    if ( ( fd = open ("/proc/mtrr", O_RDONLY, 0) ) == -1 )
    {
  if (errno == ENOENT)
  {
      fputs ("/proc/mtrr not found: not supported or you don't have a PPro?\n",
      stderr);
      exit (1);
  }
  fprintf (stderr, "Error opening /proc/mtrr\t%s\n", ERRSTRING);
  exit (2);
    }
    for (gentry.regnum = 0; ioctl (fd, MTRRIOC_GET_ENTRY, &gentry) == 0;
  ++gentry.regnum)
    {
  if (gentry.size < 1)
  {
      fprintf (stderr, "Register: %u disabled\n", gentry.regnum);
      continue;
  }
  fprintf (stderr, "Register: %u base: 0x%lx size: 0x%lx type: %s\n",
    gentry.regnum, gentry.base, gentry.size,
    mtrr_strings[gentry.type]);
    }
    if (errno == EINVAL) exit (0);
    fprintf (stderr, "Error doing ioctl(2) on /dev/mtrr\t%s\n", ERRSTRING);
    exit (3);
}   /*  End Function main  */

/*
    This programme will use an ioctl() on /proc/mtrr to add an entry. The first
    available mtrr is used. This is an alternative to writing /proc/mtrr.


    Written by      Richard Gooch   17-DEC-1997

    Last updated by Richard Gooch   2-MAY-1998


*/
#include <stdio.h>
#include <string.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/types.h>
#include <sys/stat.h>
#include <fcntl.h>
#include <sys/ioctl.h>
#include <errno.h>
#include <asm/mtrr.h>

#define TRUE 1
#define FALSE 0
#define ERRSTRING strerror (errno)

static char *mtrr_strings[MTRR_NUM_TYPES] =
{
    "uncachable",               /* 0 */
    "write-combining",          /* 1 */
    "?",                        /* 2 */
    "?",                        /* 3 */
    "write-through",            /* 4 */
    "write-protect",            /* 5 */
    "write-back",               /* 6 */
};

int main (int argc, char **argv)
{
    int fd;
    struct mtrr_sentry sentry;

    if (argc != 4)
    {
  fprintf (stderr, "Usage:\tmtrr-add base size type\n");
  exit (1);
    }
    sentry.base = strtoul (argv[1], NULL, 0);
    sentry.size = strtoul (argv[2], NULL, 0);
    for (sentry.type = 0; sentry.type < MTRR_NUM_TYPES; ++sentry.type)
    {
  if (strcmp (argv[3], mtrr_strings[sentry.type]) == 0) break;
    }
    if (sentry.type >= MTRR_NUM_TYPES)
    {
  fprintf (stderr, "Illegal type: \"%s\"\n", argv[3]);
  exit (2);
    }
    if ( ( fd = open ("/proc/mtrr", O_WRONLY, 0) ) == -1 )
    {
  if (errno == ENOENT)
  {
      fputs ("/proc/mtrr not found: not supported or you don't have a PPro?\n",
      stderr);
      exit (3);
  }
  fprintf (stderr, "Error opening /proc/mtrr\t%s\n", ERRSTRING);
  exit (4);
    }
    if (ioctl (fd, MTRRIOC_ADD_ENTRY, &sentry) == -1)
    {
  fprintf (stderr, "Error doing ioctl(2) on /dev/mtrr\t%s\n", ERRSTRING);
  exit (5);
    }
    fprintf (stderr, "Sleeping for 5 seconds so you can see the new entry\n");
    sleep (5);
    close (fd);
    fputs ("I've just closed /proc/mtrr so now the new entry should be gone\n",
    stderr);
}   /*  End Function main  */
