レギュレータマシンドライバインターフェース¶

レギュレータ マシンドライバ インターフェースは、ボード/マシン固有の初期化コードを使用してレギュレータサブシステムを構成するためのインターフェースです。

以下のマシンを考慮してください:

Regulator-1 -+-> Regulator-2 --> [Consumer A @ 1.8 - 2.0V]
             |
             +-> [Consumer B @ 3.3V]

消費者AとBのドライバが正しいレギュレータにマッピングされる必要があります。これにより、電源供給を制御できます。このマッピングは、マシン初期化コードで以下のように構造を作成することで実現できます。 struct regulator_consumer_supply 各レギュレータに対して:

struct regulator_consumer_supply {
      const char *dev_name;   /* consumer dev_name() */
      const char *supply;     /* consumer supply - e.g. "vcc" */
};

例えば、上のマシンの場合:

static struct regulator_consumer_supply regulator1_consumers[] = {
      REGULATOR_SUPPLY("Vcc", "consumer B"),
};

static struct regulator_consumer_supply regulator2_consumers[] = {
      REGULATOR_SUPPLY("Vcc", "consumer A"),
};

これは、Regulator-1を消費者Bの‘Vcc’電源に、Regulator-2を消費者Aの‘Vcc’電源にマッピングします。

制約は以下の構造を定義することで登録できます。 struct regulator_init_data 各レギュレータ電源ドメインに対して。この構造は、消費者をその電源レギュレータにマッピングすることもできます:

static struct regulator_init_data regulator1_data = {
      .constraints = {
              .name = "Regulator-1",
              .min_uV = 3300000,
              .max_uV = 3300000,
              .valid_modes_mask = REGULATOR_MODE_NORMAL,
      },
      .num_consumer_supplies = ARRAY_SIZE(regulator1_consumers),
      .consumer_supplies = regulator1_consumers,
};

nameフィールドは、他のレギュレータの電源設定やログ出力などの診断出力に役立つ説明的な名前をボードに設定する必要があります。通常、回路図で使用される電源ラインの名前が良い選択です。名前が指定されていない場合、サブシステムが自動的に選択します。

Regulator-1はRegulator-2に電力を供給します。この関係をコアに登録する必要があります。消費者Aがその電源（Regulator-2）を有効にするときに、Regulator-1も同時に有効になります。電源レギュレータは以下のsupply_regulatorフィールドで設定されます。co:

static struct regulator_init_data regulator2_data = {
      .supply_regulator = "Regulator-1",
      .constraints = {
              .min_uV = 1800000,
              .max_uV = 2000000,
              .valid_ops_mask = REGULATOR_CHANGE_VOLTAGE,
              .valid_modes_mask = REGULATOR_MODE_NORMAL,
      },
      .num_consumer_supplies = ARRAY_SIZE(regulator2_consumers),
      .consumer_supplies = regulator2_consumers,
};

最後に、レギュレータデバイスは通常通り登録する必要があります:

static struct platform_device regulator_devices[] = {
      {
              .name = "regulator",
              .id = DCDC_1,
              .dev = {
                      .platform_data = &regulator1_data,
              },
      },
      {
              .name = "regulator",
              .id = DCDC_2,
              .dev = {
                      .platform_data = &regulator2_data,
              },
      },
};
/* register regulator 1 device */
platform_device_register(&regulator_devices[0]);

/* register regulator 2 device */
platform_device_register(&regulator_devices[1]);
