CPUアカウントコントローラー（CPU Accounting Controller）¶

CPU アカウントコントローラーは、cgroups を使ってタスクをグループ化し、これらのタスクグループの CPU 使用量を記録するためのコントローラーです。

CPU アカウントコントローラーはマルチ階層グループをサポートしています。アカウントグループは、すべての子グループおよびそのグループに直接含まれるタスクの CPU 使用量を累積します。

アカウントグループは、最初に cgroup ファイルシステムをマウントすることで作成できます:

# mount -t cgroup -ocpuacct none /sys/fs/cgroup

上記の手順により、/sys/fs/cgroup に初期または親アカウントグループが表示されます。システム起動時にこのグループにはシステム内のすべてのタスクが含まれます。/sys/fs/cgroup/tasks はこの cgroup のタスク一覧を、/sys/fs/cgroup/cpuacct.usage はこのグループが取得した CPU 時間（ナノ秒単位）を示します。

親グループ /sys/fs/cgroup の下に新しいアカウントグループを作成できます:

# cd /sys/fs/cgroup
# mkdir g1
# echo $$ > g1/tasks

上記の手順により、新しいグループ g1 が作成され、現在のシェルプロセス（bash）がその中に移動します。この bash とその子プロセスが消費した CPU 時間は g1/cpuacct.usage から取得でき、同じく /sys/fs/cgroup/cpuacct.usage にも累積されます。

cpuacct.stat ファイルには、CPU 時間をユーザー時間とシステム時間に分けるためのいくつかの統計情報が記録されています。現在、以下の統計情報がサポートされています:

user: cgroup のタスクがユーザーモードで使用した時間。system: cgroup のタスクがカーネルモードで使用した時間。

user および system は USER_HZ 単位で表示されます。

cpuacct コントローラーは percpu_counter インターフェースを使用してユーザー時間とシステム時間を収集します。これには2つの副作用があります:

  • これは、32ビットシステムでは percpu_counter_read() が並行して書き込まれる場合に安全でないため、ユーザー時間とシステム時間の値が理論的に正しくない可能性があるからです。

  • これは、percpu_counter のバッチ処理の性質により、ユーザー時間とシステム時間の値がやや古くなったものになる可能性があるからです。
