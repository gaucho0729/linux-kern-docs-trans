Intel Wireless Wimax Connection 2400m ドライバ¶

著作権

© 2008 Intel Corporation < linux-wimax@intel.com >

これはIntel Wireless WiMAX Connection 2400m ドライバと、基本的なLinuxカーネル WiMAXスタックを提供します。

1. 要件¶

  • Linuxインストール（Linuxカーネル2.6.22以上、別個のツリーからビルドする場合）

  • Intel i2400m Echo PeakまたはBaxter Peak; これはIntel Wireless WiMAX/WiFi Link 5x50シリーズを含みます。

  • ビルドツール:

    • ターゲットカーネル用のLinuxカーネル開発パッケージ; 現在動作中のカーネルに対してビルドする場合は、そのカーネルイメージに対応する開発パッケージがインストールされている必要があります（通常、カーネルがlinux-VERSIONと名付けられている場合、開発パッケージはlinux-dev-VERSIONまたはlinux-headers-VERSIONと呼ばれます）。

    • GNU Cコンパイラ、make

2. コンパイルとインストール¶

2.1. カーネルに含まれるドライバのコンパイル¶

カーネルを構成してください; WiMAXドライバを有効にするには、ドライバ > ネットワークドライバ > WiMAXデバイスサポートを選択してください。すべてをモジュールとして有効化してください（より簡単です）。

USBまたはSDIOがカーネル構成で無効になっている場合、i2400m USBまたはSDIOドライバのビルドオプションは表示されません。これらのサブシステムを有効にして、再びWiMAXメニューに戻ってドライバを有効にしてください。

通常通りカーネルをコンパイルしてインストールしてください。

2.2. 独立したモジュールとして配布されるドライバのコンパイル¶

コンパイルするには:

$ cd source/directory
$ make

ビルド後、提供されたload.shスクリプトを使用してロードおよびアンロードできます; load.shはモジュールをロードし、load.sh uはアンロードします。

デフォルトのカーネルディレクトリにインストールし（デバイスが接続されたときに自動ロードを有効にするには）:

$ make install
$ depmod -a

カーネル開発ファイルが非標準のディレクトリに配置されている場合、または現在動作中のカーネル以外のカーネルをビルドする場合、KDIRを正しい場所に設定してください:

$ make KDIR=/path/to/kernel/dev/tree

詳細については、下記までお問い合わせください linux-wimax@intel.com.

3. ファームウェアのインストール¶

ファームウェアは以下から入手できます http://linuxwimax.org またはハードウェアに同梱されている可能性があります。

これはターゲットシステムにインストールする必要があります:

   $ cp FIRMWAREFILE.sbcf /lib/firmware/i2400m-fw-BUSTYPE-1.3.sbcf

* NOTE: if your firmware came in an .rpm or .deb file, just install
  it as normal, with the rpm (rpm -i FIRMWARE.rpm) or dpkg
  (dpkg -i FIRMWARE.deb) commands. No further action is needed.
* BUSTYPE will be usb or sdio, depending on the hardware you have.
  Each hardware type comes with its own firmware and will not work
  with other types.

4. デザイン¶

このパッケージには2つの主要な部分があります: WiMAXカーネルスタックとIntel i2400mドライバ。

WiMAXスタックは、現在および将来のすべてのベンダーのWiMAXデバイスに共通のWiMAX制御サービスを提供することを目的としています; 詳細についてはREADME.wimaxをご覧ください。

i2400mのカーネルドライバは、主に2つの部分に分かれています：バス汎用ドライバとバス固有のドライバです。バス汎用ドライバはドライバコアを形成し、実際にデバイスに接続する方法に関する知識は持ちません。バス固有のドライバは、バス汎用ドライバとデバイスを接続するための「グルー（接続部）」です。現在はUSBとSDIOのみがサポートされています。詳細については、drivers/net/wimax/i2400m/i2400m.h を参照してください。

バス汎用ドライバは論理的に2つの部分に分かれています：OSグルーとハードウェアグルーです。OSグルーはLinuxとインターフェースを取るためのもので、ハードウェアグルーはバス固有ドライバが提供するインターフェースを通じてデバイスとインターフェースを取るためのものです。この分割の理由は、ハードウェアグルーを他のOS向けドライバの作成に再利用しやすいようにするためです。注意：ハードウェアグルー部分はネイティブのLinuxドライバとして書かれているため、抽象化レイヤーは使用されていません。そのため、他のOSに移植する際には、LinuxカーネルAPI呼び出しをターゲットOSのそれに置き換える必要があります。

5. 使い方¶

ドライバをロードするには、インストールセクションの指示に従ってください。ドライバがロードされると、デバイスを接続してください（常に接続されている場合は除く）。ドライバはデバイスを列挙し、ファームウェアをアップロードし、カーネルログ（dmesg、/var/log/messages または /var/log/kern.log）に出力メッセージを出力します。例えば以下のようになります：

...
i2400m_usb 5-4:1.0: firmware interface version 8.0.0
i2400m_usb 5-4:1.0: WiMAX interface wmx0 (00:1d:e1:01:94:2c) ready

この時点でデバイスは動作可能になっています。

現在のバージョンでは、Intel WiMAX Network Service（ユーザー空間での実行）が必要です。ネットワークサービスのREADMEを参照し、スキャン、接続、切断の方法を確認してください。

5.1. モジュールパラメータ¶

モジュールパラメータはカーネル起動時やモジュールロード時に設定できます。また、値をエコーバックする方法もあります：

$ echo VALUE > /sys/module/MODULENAME/parameters/PARAMETERNAME

設定を永続化するには、例えばi2400mモジュールの場合、/etc/modprobe.d/i2400m という名前のファイルを作成して以下の内容を記述してください：

options i2400m idle_mode_disabled=1

モジュールがサポートするパラメータを確認するには、以下を実行してください：

$ modinfo path/to/module.ko

カーネル起動時に（ドライバがカーネルにリンクされている場合）、カーネルコマンドラインに以下を指定してください：

i2400m.PARAMETER=VALUE

5.1.1. i2400m: idle_mode_disabled¶

i2400mモジュールは、アイドルモードを無効にするパラメータをサポートしています。このパラメータは設定された後、ドライバによってデバイスが再初期化される（例：リセットや再接続後）ときにのみ有効になります。

5.2. デバッグ操作: debugfsエントリ¶

ドライバはユーザーがデバッグ設定を調整できるdebugfsエントリを登録します。エントリは3つの主要なコンテナディレクトリに配置され、これはi2400m WiMAXドライバが持つ3つのブロックに対応しています：

  • /sys/kernel/debug/wimax:DEVNAME/ は汎用WiMAXスタックの制御に使用されます

  • /sys/kernel/debug/wimax:DEVNAME/i2400m は i2400m ジェネリックドライバーの制御設定です。

  • /sys/kernel/debug/wimax:DEVNAME/i2400m-usb (または -sdio) はバス固有の i2400m-usb または i2400m-sdio の制御設定です。

もちろん、debugfs が /sys/kernel/debug 以外のディレクトリにマウントされている場合、これらのパスは変化します。

5.2.1. デバッグ出力の増加¶

ファイル名 dl_ これは、さまざまなサブモジュールのデバッグ出力の制御パラメータを示します。

# find /sys/kernel/debug/wimax\:wmx0 -name \*dl_\*
/sys/kernel/debug/wimax:wmx0/i2400m-usb/dl_tx
/sys/kernel/debug/wimax:wmx0/i2400m-usb/dl_rx
/sys/kernel/debug/wimax:wmx0/i2400m-usb/dl_notif
/sys/kernel/debug/wimax:wmx0/i2400m-usb/dl_fw
/sys/kernel/debug/wimax:wmx0/i2400m-usb/dl_usb
/sys/kernel/debug/wimax:wmx0/i2400m/dl_tx
/sys/kernel/debug/wimax:wmx0/i2400m/dl_rx
/sys/kernel/debug/wimax:wmx0/i2400m/dl_rfkill
/sys/kernel/debug/wimax:wmx0/i2400m/dl_netdev
/sys/kernel/debug/wimax:wmx0/i2400m/dl_fw
/sys/kernel/debug/wimax:wmx0/i2400m/dl_debugfs
/sys/kernel/debug/wimax:wmx0/i2400m/dl_driver
/sys/kernel/debug/wimax:wmx0/i2400m/dl_control
/sys/kernel/debug/wimax:wmx0/wimax_dl_stack
/sys/kernel/debug/wimax:wmx0/wimax_dl_op_rfkill
/sys/kernel/debug/wimax:wmx0/wimax_dl_op_reset
/sys/kernel/debug/wimax:wmx0/wimax_dl_op_msg
/sys/kernel/debug/wimax:wmx0/wimax_dl_id_table
/sys/kernel/debug/wimax:wmx0/wimax_dl_debugfs

ファイルを読み取ることで、現在のデバッグレベルの値を取得でき、書き込むことでそのレベルを設定できます。

たとえば、i2400m のジェネリック TX エンジンのデバッグレベルを増やすには、次のように書き込みます：

$ echo 3 > /sys/kernel/debug/wimax:wmx0/i2400m/dl_tx

数字が大きいほどデバッグ情報が詳細になります。詳細な出力内容や利用可能なレベルについてはソースコードを確認してください。コードでは 0 で無効化され、8 まで増加します。

5.2.2. RX と TX の統計情報¶

i2400m/rx_stats および i2400m/tx_stats は、デバイスからのデータ受信/配信に関する統計情報を提供します：

$ cat /sys/kernel/debug/wimax:wmx0/i2400m/rx_stats
45 1 3 34 3104 48 480

報告される数値は：

  • パケット/RXバッファ：総数、最小値、最大値

  • RXバッファ：受信した総 RX バッファ数、累積 RX バッファサイズ（バイト）、受信した最小サイズ、受信した最大サイズ

したがって、受信した平均バッファサイズを求めるには、累積 RX バッファ / 総 RX バッファ数を計算してください。

統計情報を 0 に戻すには、rx_stats ファイルに何でも書き込みます：

$ echo 1 > /sys/kernel/debug/wimax:wmx0/i2400m_rx_stats

TX についても同様です。

このデバッグファイルが参照するパケットはネットワークパケットではなく、デバイス固有のプロトコルでホストとの通信に使用されるパケットです。drivers/net/wimax/i2400m/tx.c を参照してください。

5.2.3. ユーザースペースから受信したメッセージのトレース¶

ユーザースペースから受信したメッセージを、i2400m ドライバーが作成するトレースパイプにエコーするには、i2400m/trace_msg_from_user ファイルを 1 に設定します：

$ echo 1 > /sys/kernel/debug/wimax:wmx0/i2400m/trace_msg_from_user

5.2.4. デバイスのリセット¶

ファイル /sys/kernel/debug/wimax:wmx0/reset に 0、1、または 2 を書き込むことで、ドライバーはデバイスにウォームリセット（バスから切断せずに）、コールドリセット（バスから切断して）、またはバスリセット（バス固有）を実行します。

5.2.5. デバイスに省電力モードへの移行を依頼¶

ファイル /sys/kernel/debug/wimax:wmx0 に任意の値を書き込むことで、デバイスが省電力モードに移行を試みます。

6. トラブルシューティング¶

6.1. ドライバが～について警告を出します i2400m-fw-usb-1.2.sbcf: request failed¶

デバイスを接続した際に、カーネルログに以下が出力される場合：

i2400m_usb 5-4:1.0: fw i2400m-fw-usb-1.3.sbcf: request failed: -2

これは、ドライバが firmware ファイル /lib/firmware/i2400m-fw-usb-1.2.sbcf を見つけることができないことを意味します。このファイルが正しい場所にあるか確認してください。
