GPIO Aggregator¶

GPIO Aggregator は、GPIO を統合し、新しい gpio_chip として公開するメカニズムを提供します。これにより、以下の使用例がサポートされます。

Sysfs を使用した GPIO の統合¶

GPIO コントローラーは、/dev/gpiochip* キャラクタデバイスを通じてユーザースペースにエクスポートされます。これらのデバイスへのアクセス制御は、標準 UNIX ファイルシステムの権限によって提供され、すべてまたはなしの原則に基づいています。つまり、ユーザーが GPIO コントローラーにアクセスできるかできないかが明確です。

GPIO Aggregator は、複数の GPIO を新しい gpio_chip に統合することで、標準 UNIX ファイル所有権と権限を用いてグループやユーザーに割り当てることで、アクセス制御を提供します。さらに、仮想マシンへの GPIO のエクスポートを簡素化・強化します。VM は全体の GPIO コントローラーを取得するだけで、どの GPIO を取得すべきかを気にする必要がなくなり、攻撃面を減らします。

統合された GPIO コントローラーは、sysfs 内の読み取り専用属性ファイルに書き込むことでインスタンス化および破棄されます。

/sys/bus/platform/drivers/gpio-aggregator/

new_device …

ユーザースペースは、'new_device' ファイルに GPIO を統合するための文字列を書き込むことで、カーネルに統合された GPIO コントローラーのインスタンス化を依頼できます。この際、次の形式を使用します。

[<gpioA>] [<gpiochipB> <offsets>] ...

以下では:

<gpioA> …

は GPIO ライン名です、

<gpiochipB> …

は GPIO チップのラベルです、そして

<offsets> …

はコンマで区切られた GPIO オフセットと/またはハイフンで表されるオフセット範囲のリストです。

例: 「e6052000.gpio」の GPIO ライン 19 と、「e6050000.gpio」の GPIO ライン 20-21 を統合して、新しい gpio_chip を作成する新しい GPIO アグレゲータをインスタンス化します:

$ echo 'e6052000.gpio 19 e6050000.gpio 20-21' > new_device
delete_device …

ユーザースペースは、使用後に統合された GPIO コントローラーを破棄するため、'delete_device' ファイルにデバイス名を書き込むことでカーネルに依頼できます。

例: 以前に作成された統合された GPIO コントローラー（'gpio-aggregator.0' と仮定）を破棄します:

$ echo gpio-aggregator.0 > delete_device

汎用 GPIO ドライバー¶

GPIO Aggregator は、DT で記述された単純な GPIO 操作デバイスに汎用ドライバーとして使用することもできます。専用の内核ドライバーが不要です。これは産業制御において有用で、spidev などと同様に、ユーザースペースから SPI デバイスと通信できるようにします。

デバイスを GPIO Aggregator にバインディングする方法は、gpio-aggregator ドライバーを変更するか、Sysfs 内の 'driver_override' ファイルに書き込むことで行います。

例: 「door」は DT で記述された GPIO 操作デバイスで、独自の compatible 値を使用しています:

door {
        compatible = "myvendor,mydoor";

        gpios = <&gpio2 19 GPIO_ACTIVE_HIGH>,
                <&gpio2 20 GPIO_ACTIVE_LOW>;
        gpio-line-names = "open", "lock";
};

これは GPIO Aggregator にバインディングできます。以下のようにします:

  1. 自身の compatible 値を追加することで gpio_aggregator_dt_ids[],

  2. 手動で「driver_override」を使用してバインディング:

$ echo gpio-aggregator > /sys/bus/platform/devices/door/driver_override
$ echo door > /sys/bus/platform/drivers/gpio-aggregator/bind

その後、新しい gpiochip 「ドア」が作成されました:

$ gpioinfo door
gpiochip12 - 2 lines:
        line   0:       "open"       unused   input  active-high
        line   1:       "lock"       unused   input  active-high
