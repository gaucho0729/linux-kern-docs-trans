ノートパソコンモードを活用したバッテリー電力の節約方法¶

ドキュメント作成者: Bart Samwel (bart@samwel.tk)

作成日: 2004年1月2日

最終更新日: 2004年12月6日

はじめに¶

ラップトップモードは、ハードディスクをスピンアップする時間を最小限に抑え、ラップトップのバッテリー電力を節約するために使用されます。この機能は、大幅な電力節約効果があると報告されています。

インストール¶

ラップトップモードを使用するには、カーネルの設定オプションを設定する必要はなく、単にこのドキュメントに含まれるすべてのファイルをインストールするだけで、バッテリー電源で起動時に自動的にラップトップモードが開始されます。ご利便のため、インストーラーを含むtarballは以下からダウンロードできます:

http://www.samwel.tk/laptop_mode/laptop_mode/

ラップトップモードを設定するには、設定ファイルを編集する必要があります。Debianベースのシステムでは /etc/default/laptop-mode、他のシステムでは /etc/sysconfig/laptop-mode に配置されています。

残念ながら、ACPIを搭載していないラップトップでは自動的にラップトップモードを有効にすることができません。そのようなラップトップでは手動でラップトップモードを開始する必要があります。ラップトップモードを開始するには「laptop_mode start」を、停止するには「laptop_mode stop」を実行してください。(注: ラップトップモードツールパッケージは現在、APMに対する実験的なサポートを提供しており、まずはその方法を試してみることをおすすめします。)

注意事項¶

  • ラップトップモードのデメリットは、最大で10分間の作業を失う可能性があることです。これを受け入れられない場合は、使用しないでください！提供されたACPIスクリプトはバッテリーがほぼ枯渇する前にラップトップモードを自動的にオフにしますので、バッテリー寿命の終わりにデータを失うことはありません。

  • ほとんどのデスクトップハードディスクはスピンダウンサイクルで寿命が測定され、通常約50,000回（スペックシートに記載されています）です。ドライブの寿命を確認し、必要以上に寿命を短くしないようにしてください。

  • ext3/reiserfs ファイルシステムを -n オプションでマウントしている場合、制御スクリプトが正しく再マウントできない可能性があります。制御スクリプトで DO_REMOUNTS=0 を設定しなければなりません。それ以外の場合、間違ったオプションで再マウントされたり、/etc/mtab に書き込めないため失敗する可能性があります。

  • fstab でファイルシステムを「auto」タイプで指定している場合（私はそのようにしていました）、制御スクリプトは再マウントが必要なファイルシステムとして認識しません。ファイルシステムを真のタイプで明示的に指定する必要があります。

  • 一部のmuttメールクライアントのバージョンでは、フォルダに新しいメールがあるかを判定するためにファイルアクセス時刻を使用していると報告されています。muttを使用していてこの挙動を経験する場合は、設定ファイルでDO_REMOUNT_NOATIMEオプションを0に設定してnoatime再マウントを無効化する必要があります。

詳細¶

ラップトップモードは/proc/sys/vm/laptop_modeというノブで制御されます。このノブはラップトップモードパッチを搭載したすべてのカーネルに存在し、設定オプションに関係なく常に表示されます。ノブが設定されている場合、物理ディスクI/O（ハードディスクをスピンアップさせる可能性のある操作）が発生するとLinuxがすべての汚染ブロックをフラッシュします。その結果、ディスクがスピンダウンした後は、汚染ブロックを書き込むためにディスクが再びスピンアップしなくなるため、最新の読み取り操作直後にこれらのブロックはすでに書き込まれています。ラップトップモードのノブの値は、ディスクI/Oの発生とフラッシュがトリガーされるまでの時間を決定します。ノブの適切な値は5秒です。ノブを0に設定するとラップトップモードが無効になります。

ラップトップモード戦略の効果を高めるために、ラップトップモード制御スクリプトは/proc/sys/vmのdirty_expire_centisecsとdirty_writeback_centisの値を約10分（デフォルトでは）に設定します。これにより、汚染されたページがディスクに頻繁に強制的に書き込まれるのを防ぎます。制御スクリプトはまた、バックグラウンドでの汚染ページの書き戻しを停止するようにdirty_background_ratioを変更します。これは、ext3またはReiserFSファイルシステムのcommit値（同様に制御スクリプトが自動で行う）を10分に設定することで、ディスクアクティビティが10分ごとに一度だけ集中して発生するようになります。ディスクは無駄なスピンアップを防ぎ、非活動期間にスピンダウンできます。

ディスクがスピンアップした原因を特定したい場合は、/proc/sys/vm/block_dumpフラグを設定して情報を収集できます。このフラグが設定されていると、Linuxがすべてのディスク読み取り・書き込み操作とファイルへのブロック汚染を報告します。これにより、ディスクがスピンアップする理由をデバッグし、バッテリー寿命をさらに向上させることが可能です。block_dumpの出力はカーネル出力に書き込まれ、"dmesg"コマンドで取得できます。block_dumpを使用し、カーネルログレベルにデバッグメッセージも含まれている場合、klogdを無効化することを推奨します。そうしないとblock_dumpの出力がログに記録され、通常は存在しないディスクアクティビティが発生します。

設定¶

Debianベースのシステムでは、ラップトップモードの設定ファイルは/etc/default/laptop-modeに、その他のシステムでは/etc/sysconfig/laptop-modeにあります。このファイルには以下のオプションが含まれています:

MAX_AGE:

ハードドライブのスピンダウン時間（秒単位）の最大値で、あなたが許容できる範囲を指定します。最悪の場合、バッテリーが切れてしまってラップトップモード中に作業が中断された場合、この時間分の作業が失われる可能性があります。

MINIMUM_BATTERY_MINUTES:

残りバッテリー時間（分単位）がこの値よりも少ない場合、自動的にラップトップモードを無効にします。デフォルトは10分です。

AC_HD/BATT_HD:

ラップトップモードが有効（BATT_HD）または無効（AC_HD）の際、ハードドライブに設定すべきアイドルタイムアウト時間です。デフォルトではBATT_HDは20秒（値4）、AC_HDは2時間（値244）です。可能な値は「hdparm」のマニュアルページで「-S」オプションに記載されている値です。

HD:

ラップトップモードによってスピンダウンタイムアウトを調整するデバイスを指定します。デフォルトは/dev/hdaです。複数のデバイスを指定する場合はスペースで区切ります。

READAHEAD:

ラップトップモードが有効な間、ディスクの読み込みを先読みするサイズ（512バイトセクタ単位）です。大きな読み込み先読みは、実行可能ページ（アプリケーション実行中に必要に応じてロードされる）や順序的にアクセスされるデータ（MP3など）のディスクアクセスを防ぐことができます。

DO_REMOUNTS:

制御スクリプトは、ジャーナル化されたファイルシステムを適切なコミットインターバルオプションで再マウントします。このオプションを0に設定すると、この機能が無効になります。

DO_REMOUNT_NOATIME:

再マウント時にファイルシステムをnoatimeオプションで再マウントすべきですか？通常は「1」（有効）ですが、アクセス時間の記録が必要なプログラムがある場合があります。

DIRTY_RATIO:

ラップトップモードが有効な間、書き戻しが強制されるまでにメモリに許容される「汚い」または未保存データの割合（パーセント）です。これは/proc/sys/vm/dirty_ratio sysctlに該当します。

DIRTY_BACKGROUND_RATIO:

DIRTY_RATIOの超過により強制的に書き戻しが行われた後、メモリに許容される「汚い」または未保存データの割合（パーセント）です。この値は低めに設定してください。これは/proc/sys/vm/dirty_background_ratio sysctlに該当します。

ラップトップモードが有効になっているか、無効になっているかで、dirty_background_ratioの挙動は大きく異なります。ラップトップモードが無効になっている場合、dirty_background_ratioはバックグラウンドの書き込みが開始されるしきい値のパーセンテージです。一方、ラップトップモードが有効になっている場合、バックグラウンドの書き込みは無効化され、dirty_background_ratioはdirty_ratioが到達したときにどの程度の書き戻しが行われるかを決定します。

DO_CPU:

ラップトップモード時にCPUの周波数スケーリングを有効にする。(CPUFreqを設定する必要があります。詳しくは CPUパフォーマンススケーリング をご覧ください。デフォルトでは無効です。)

CPU_MAXFREQ:

バッテリーで動作している場合、システムが使用する最大CPU速度はどれですか？有効な値は、「slowest」（CPUが動作できる最速の速度）または /sys/devices/system/cpu/cpu0/cpufreq/scaling_available_frequencies に記載されている値です。

Tips & Tricks¶

  • バートェク・カニアは、スピンダウン時間を5秒に設定したことで、通常の3〜3.5時間に加えて最大50分のバッテリー寿命を達成したと報告しています（BATT_HD=1）。

  • MP3を再生している間にもディスクをスピンダウンできるようにするには、ディスク読み込みを8MBに設定します（READAHEAD=16384）。これにより、ディスクは一度にMP3全体を読み込み、その後MP3が再生されている間スピンダウンします。（バートェク・カニア氏の提案によります。）

  • ドレイ・スコット・ダンニエルズは観察しました：「理由は分からないのですが、私のディスプレイが使用する色数を減らすとバッテリー消費が減ります。これはパワーブックでも確認しています。この情報がラップトップモードのパッチやそのユーザーにとって役立つものであることを願っています。」

  • syslog.confでは、エントリにダッシュを付けることで - ログごとにファイルを同期しないようにできます。ラップトップモードを使用していてディスクがスピンダウンしない場合、この設定が原因である可能性が高いです。

  • リチャード・アッテラーは、ラップトップモードがnoflushdと併用すると動作しないと観察しました（http://noflushd.sourceforge.net/）、noflushdがラップトップモードの動作を妨げているようです。

  • データの安全性を心配している場合は、USBメモリやそれに類するものを「作業領域」として使用することを検討してください。（ただし、フラッシュメモリは限られた回数しか書き込みができず、過度な使用でメモリースティックが迅速に劣化する可能性があります。フラッシュメモリスティックにはジャーナリングファイルシステムを使用しないでください。）

制御およびACPIバッテリースクリプト用の設定ファイル¶

これにより、外部の設定ファイルを介してスクリプトのチューニングパラメータを変更できます

Debianでは/etc/default/laptop-mode、Red Hat、SUSE、Mandrake、およびその他の互換OSでは/etc/sysconfig/laptop-modeにインストールする必要があります。

Control script¶

この制御スクリプトは、Linux 2.4および2.6シリーズで動作します（Kiko Piris氏の貢献により）。

制御スクリプト:

#!/bin/bash

# start or stop laptop_mode, best run by a power management daemon when
# ac gets connected/disconnected from a laptop
#
# install as /sbin/laptop_mode
#
# Contributors to this script:   Kiko Piris
#                              Bart Samwel
#                              Micha Feigin
#                              Andrew Morton
#                              Herve Eychenne
#                              Dax Kelson
#
# Original Linux 2.4 version by: Jens Axboe

#############################################################################

# Source config
if [ -f /etc/default/laptop-mode ] ; then
      # Debian
      . /etc/default/laptop-mode
elif [ -f /etc/sysconfig/laptop-mode ] ; then
      # Others
        . /etc/sysconfig/laptop-mode
fi

# Don't raise an error if the config file is incomplete
# set defaults instead:

# Maximum time, in seconds, of hard drive spindown time that you are
# comfortable with. Worst case, it's possible that you could lose this
# amount of work if your battery fails you while in laptop mode.
MAX_AGE=${MAX_AGE:-'600'}

# Read-ahead, in kilobytes
READAHEAD=${READAHEAD:-'4096'}

# Shall we remount journaled fs. with appropriate commit interval? (1=yes)
DO_REMOUNTS=${DO_REMOUNTS:-'1'}

# And shall we add the "noatime" option to that as well? (1=yes)
DO_REMOUNT_NOATIME=${DO_REMOUNT_NOATIME:-'1'}

# Shall we adjust the idle timeout on a hard drive?
DO_HD=${DO_HD:-'1'}

# Adjust idle timeout on which hard drive?
HD="${HD:-'/dev/hda'}"

# spindown time for HD (hdparm -S values)
AC_HD=${AC_HD:-'244'}
BATT_HD=${BATT_HD:-'4'}

# Dirty synchronous ratio.  At this percentage of dirty pages the process which
# calls write() does its own writeback
DIRTY_RATIO=${DIRTY_RATIO:-'40'}

# cpu frequency scaling
# See Documentation/admin-guide/pm/cpufreq.rst for more info
DO_CPU=${CPU_MANAGE:-'0'}
CPU_MAXFREQ=${CPU_MAXFREQ:-'slowest'}

#
# Allowed dirty background ratio, in percent.  Once DIRTY_RATIO has been
# exceeded, the kernel will wake flusher threads which will then reduce the
# amount of dirty memory to dirty_background_ratio.  Set this nice and low,
# so once some writeout has commenced, we do a lot of it.
#
DIRTY_BACKGROUND_RATIO=${DIRTY_BACKGROUND_RATIO:-'5'}

# kernel default dirty buffer age
DEF_AGE=${DEF_AGE:-'30'}
DEF_UPDATE=${DEF_UPDATE:-'5'}
DEF_DIRTY_BACKGROUND_RATIO=${DEF_DIRTY_BACKGROUND_RATIO:-'10'}
DEF_DIRTY_RATIO=${DEF_DIRTY_RATIO:-'40'}
DEF_XFS_AGE_BUFFER=${DEF_XFS_AGE_BUFFER:-'15'}
DEF_XFS_SYNC_INTERVAL=${DEF_XFS_SYNC_INTERVAL:-'30'}
DEF_XFS_BUFD_INTERVAL=${DEF_XFS_BUFD_INTERVAL:-'1'}

# This must be adjusted manually to the value of HZ in the running kernel
# on 2.4, until the XFS people change their 2.4 external interfaces to work in
# centisecs. This can be automated, but it's a work in progress that still needs
# some fixes. On 2.6 kernels, XFS uses USER_HZ instead of HZ for external
# interfaces, and that is currently always set to 100. So you don't need to
# change this on 2.6.
XFS_HZ=${XFS_HZ:-'100'}

#############################################################################

KLEVEL="$(uname -r |
             {
             IFS='.' read a b c
             echo $a.$b
           }
)"
case "$KLEVEL" in
      "2.4"|"2.6")
              ;;
      *)
              echo "Unhandled kernel version: $KLEVEL ('uname -r' = '$(uname -r)')" >&2
              exit 1
              ;;
esac

if [ ! -e /proc/sys/vm/laptop_mode ] ; then
      echo "Kernel is not patched with laptop_mode patch." >&2
      exit 1
fi

if [ ! -w /proc/sys/vm/laptop_mode ] ; then
      echo "You do not have enough privileges to enable laptop_mode." >&2
      exit 1
fi

# Remove an option (the first parameter) of the form option=<number> from
# a mount options string (the rest of the parameters).
parse_mount_opts () {
      OPT="$1"
      shift
      echo ",$*," | sed               \
       -e 's/,'"$OPT"'=[0-9]*,/,/g'   \
       -e 's/,,*/,/g'                 \
       -e 's/^,//'                    \
       -e 's/,$//'
}

# Remove an option (the first parameter) without any arguments from
# a mount option string (the rest of the parameters).
parse_nonumber_mount_opts () {
      OPT="$1"
      shift
      echo ",$*," | sed               \
       -e 's/,'"$OPT"',/,/g'          \
       -e 's/,,*/,/g'                 \
       -e 's/^,//'                    \
       -e 's/,$//'
}

# Find out the state of a yes/no option (e.g. "atime"/"noatime") in
# fstab for a given filesystem, and use this state to replace the
# value of the option in another mount options string. The device
# is the first argument, the option name the second, and the default
# value the third. The remainder is the mount options string.
#
# Example:
# parse_yesno_opts_wfstab /dev/hda1 atime atime defaults,noatime
#
# If fstab contains, say, "rw" for this filesystem, then the result
# will be "defaults,atime".
parse_yesno_opts_wfstab () {
      L_DEV="$1"
      OPT="$2"
      DEF_OPT="$3"
      shift 3
      L_OPTS="$*"
      PARSEDOPTS1="$(parse_nonumber_mount_opts $OPT $L_OPTS)"
      PARSEDOPTS1="$(parse_nonumber_mount_opts no$OPT $PARSEDOPTS1)"
      # Watch for a default atime in fstab
      FSTAB_OPTS="$(awk '$1 == "'$L_DEV'" { print $4 }' /etc/fstab)"
      if echo "$FSTAB_OPTS" | grep "$OPT" > /dev/null ; then
              # option specified in fstab: extract the value and use it
              if echo "$FSTAB_OPTS" | grep "no$OPT" > /dev/null ; then
                      echo "$PARSEDOPTS1,no$OPT"
              else
                      # no$OPT not found -- so we must have $OPT.
                      echo "$PARSEDOPTS1,$OPT"
              fi
      else
              # option not specified in fstab -- choose the default.
              echo "$PARSEDOPTS1,$DEF_OPT"
      fi
}

# Find out the state of a numbered option (e.g. "commit=NNN") in
# fstab for a given filesystem, and use this state to replace the
# value of the option in another mount options string. The device
# is the first argument, and the option name the second. The
# remainder is the mount options string in which the replacement
# must be done.
#
# Example:
# parse_mount_opts_wfstab /dev/hda1 commit defaults,commit=7
#
# If fstab contains, say, "commit=3,rw" for this filesystem, then the
# result will be "rw,commit=3".
parse_mount_opts_wfstab () {
      L_DEV="$1"
      OPT="$2"
      shift 2
      L_OPTS="$*"
      PARSEDOPTS1="$(parse_mount_opts $OPT $L_OPTS)"
      # Watch for a default commit in fstab
      FSTAB_OPTS="$(awk '$1 == "'$L_DEV'" { print $4 }' /etc/fstab)"
      if echo "$FSTAB_OPTS" | grep "$OPT=" > /dev/null ; then
              # option specified in fstab: extract the value, and use it
              echo -n "$PARSEDOPTS1,$OPT="
              echo ",$FSTAB_OPTS," | sed \
               -e 's/.*,'"$OPT"'=//'  \
               -e 's/,.*//'
      else
              # option not specified in fstab: set it to 0
              echo "$PARSEDOPTS1,$OPT=0"
      fi
}

deduce_fstype () {
      MP="$1"
      # My root filesystem unfortunately has
      # type "unknown" in /etc/mtab. If we encounter
      # "unknown", we try to get the type from fstab.
      cat /etc/fstab |
      grep -v '^#' |
      while read FSTAB_DEV FSTAB_MP FSTAB_FST FSTAB_OPTS FSTAB_DUMP FSTAB_DUMP ; do
              if [ "$FSTAB_MP" = "$MP" ]; then
                      echo $FSTAB_FST
                      exit 0
              fi
      done
}

if [ $DO_REMOUNT_NOATIME -eq 1 ] ; then
      NOATIME_OPT=",noatime"
fi

case "$1" in
      start)
              AGE=$((100*$MAX_AGE))
              XFS_AGE=$(($XFS_HZ*$MAX_AGE))
              echo -n "Starting laptop_mode"

              if [ -d /proc/sys/vm/pagebuf ] ; then
                      # (For 2.4 and early 2.6.)
                      # This only needs to be set, not reset -- it is only used when
                      # laptop mode is enabled.
                      echo $XFS_AGE > /proc/sys/vm/pagebuf/lm_flush_age
                      echo $XFS_AGE > /proc/sys/fs/xfs/lm_sync_interval
              elif [ -f /proc/sys/fs/xfs/lm_age_buffer ] ; then
                      # (A couple of early 2.6 laptop mode patches had these.)
                      # The same goes for these.
                      echo $XFS_AGE > /proc/sys/fs/xfs/lm_age_buffer
                      echo $XFS_AGE > /proc/sys/fs/xfs/lm_sync_interval
              elif [ -f /proc/sys/fs/xfs/age_buffer ] ; then
                      # (2.6.6)
                      # But not for these -- they are also used in normal
                      # operation.
                      echo $XFS_AGE > /proc/sys/fs/xfs/age_buffer
                      echo $XFS_AGE > /proc/sys/fs/xfs/sync_interval
              elif [ -f /proc/sys/fs/xfs/age_buffer_centisecs ] ; then
                      # (2.6.7 upwards)
                      # And not for these either. These are in centisecs,
                      # not USER_HZ, so we have to use $AGE, not $XFS_AGE.
                      echo $AGE > /proc/sys/fs/xfs/age_buffer_centisecs
                      echo $AGE > /proc/sys/fs/xfs/xfssyncd_centisecs
                      echo 3000 > /proc/sys/fs/xfs/xfsbufd_centisecs
              fi

              case "$KLEVEL" in
                      "2.4")
                              echo 1                                  > /proc/sys/vm/laptop_mode
                              echo "30 500 0 0 $AGE $AGE 60 20 0"     > /proc/sys/vm/bdflush
                              ;;
                      "2.6")
                              echo 5                                  > /proc/sys/vm/laptop_mode
                              echo "$AGE"                             > /proc/sys/vm/dirty_writeback_centisecs
                              echo "$AGE"                             > /proc/sys/vm/dirty_expire_centisecs
                              echo "$DIRTY_RATIO"                     > /proc/sys/vm/dirty_ratio
                              echo "$DIRTY_BACKGROUND_RATIO"          > /proc/sys/vm/dirty_background_ratio
                              ;;
              esac
              if [ $DO_REMOUNTS -eq 1 ]; then
                      cat /etc/mtab | while read DEV MP FST OPTS DUMP PASS ; do
                              PARSEDOPTS="$(parse_mount_opts "$OPTS")"
                              if [ "$FST" = 'unknown' ]; then
                                      FST=$(deduce_fstype $MP)
                              fi
                              case "$FST" in
                                      "ext3"|"reiserfs")
                                              PARSEDOPTS="$(parse_mount_opts commit "$OPTS")"
                                              mount $DEV -t $FST $MP -o remount,$PARSEDOPTS,commit=$MAX_AGE$NOATIME_OPT
                                              ;;
                                      "xfs")
                                              mount $DEV -t $FST $MP -o remount,$OPTS$NOATIME_OPT
                                              ;;
                              esac
                              if [ -b $DEV ] ; then
                                      blockdev --setra $(($READAHEAD * 2)) $DEV
                              fi
                      done
              fi
              if [ $DO_HD -eq 1 ] ; then
                      for THISHD in $HD ; do
                              /sbin/hdparm -S $BATT_HD $THISHD > /dev/null 2>&1
                              /sbin/hdparm -B 1 $THISHD > /dev/null 2>&1
                      done
              fi
              if [ $DO_CPU -eq 1 -a -e /sys/devices/system/cpu/cpu0/cpufreq/cpuinfo_min_freq ]; then
                      if [ $CPU_MAXFREQ = 'slowest' ]; then
                              CPU_MAXFREQ=`cat /sys/devices/system/cpu/cpu0/cpufreq/cpuinfo_min_freq`
                      fi
                      echo $CPU_MAXFREQ > /sys/devices/system/cpu/cpu0/cpufreq/scaling_max_freq
              fi
              echo "."
              ;;
      stop)
              U_AGE=$((100*$DEF_UPDATE))
              B_AGE=$((100*$DEF_AGE))
              echo -n "Stopping laptop_mode"
              echo 0 > /proc/sys/vm/laptop_mode
              if [ -f /proc/sys/fs/xfs/age_buffer -a ! -f /proc/sys/fs/xfs/lm_age_buffer ] ; then
                      # These need to be restored, if there are no lm_*.
                      echo $(($XFS_HZ*$DEF_XFS_AGE_BUFFER))           > /proc/sys/fs/xfs/age_buffer
                      echo $(($XFS_HZ*$DEF_XFS_SYNC_INTERVAL))        > /proc/sys/fs/xfs/sync_interval
              elif [ -f /proc/sys/fs/xfs/age_buffer_centisecs ] ; then
                      # These need to be restored as well.
                      echo $((100*$DEF_XFS_AGE_BUFFER))       > /proc/sys/fs/xfs/age_buffer_centisecs
                      echo $((100*$DEF_XFS_SYNC_INTERVAL))    > /proc/sys/fs/xfs/xfssyncd_centisecs
                      echo $((100*$DEF_XFS_BUFD_INTERVAL))    > /proc/sys/fs/xfs/xfsbufd_centisecs
              fi
              case "$KLEVEL" in
                      "2.4")
                              echo "30 500 0 0 $U_AGE $B_AGE 60 20 0" > /proc/sys/vm/bdflush
                              ;;
                      "2.6")
                              echo "$U_AGE"                           > /proc/sys/vm/dirty_writeback_centisecs
                              echo "$B_AGE"                           > /proc/sys/vm/dirty_expire_centisecs
                              echo "$DEF_DIRTY_RATIO"                 > /proc/sys/vm/dirty_ratio
                              echo "$DEF_DIRTY_BACKGROUND_RATIO"      > /proc/sys/vm/dirty_background_ratio
                              ;;
              esac
              if [ $DO_REMOUNTS -eq 1 ] ; then
                      cat /etc/mtab | while read DEV MP FST OPTS DUMP PASS ; do
                              # Reset commit and atime options to defaults.
                              if [ "$FST" = 'unknown' ]; then
                                      FST=$(deduce_fstype $MP)
                              fi
                              case "$FST" in
                                      "ext3"|"reiserfs")
                                              PARSEDOPTS="$(parse_mount_opts_wfstab $DEV commit $OPTS)"
                                              PARSEDOPTS="$(parse_yesno_opts_wfstab $DEV atime atime $PARSEDOPTS)"
                                              mount $DEV -t $FST $MP -o remount,$PARSEDOPTS
                                              ;;
                                      "xfs")
                                              PARSEDOPTS="$(parse_yesno_opts_wfstab $DEV atime atime $OPTS)"
                                              mount $DEV -t $FST $MP -o remount,$PARSEDOPTS
                                              ;;
                              esac
                              if [ -b $DEV ] ; then
                                      blockdev --setra 256 $DEV
                              fi
                      done
              fi
              if [ $DO_HD -eq 1 ] ; then
                      for THISHD in $HD ; do
                              /sbin/hdparm -S $AC_HD $THISHD > /dev/null 2>&1
                              /sbin/hdparm -B 255 $THISHD > /dev/null 2>&1
                      done
              fi
              if [ $DO_CPU -eq 1 -a -e /sys/devices/system/cpu/cpu0/cpufreq/cpuinfo_min_freq ]; then
                      echo `cat /sys/devices/system/cpu/cpu0/cpufreq/cpuinfo_max_freq` > /sys/devices/system/cpu/cpu0/cpufreq/scaling_max_freq
              fi
              echo "."
              ;;
      *)
              echo "Usage: $0 {start|stop}" 2>&1
              exit 1
              ;;

esac

exit 0

ACPI統合機能¶

Dax Kelson氏がこのスクリプトを提出し、ACPI acpidデーモンがラップトップモードスクリプトを起動し、hdparmを実行します。バッテリーが低くなるとラップトップモードを自動的に無効にする機能はJan Topinski氏が記述しました。

/etc/acpi/events/ac_adapter:

event=ac_adapter
action=/etc/acpi/actions/ac.sh %e

/etc/acpi/events/battery:

event=battery.*
action=/etc/acpi/actions/battery.sh %e

/etc/acpi/actions/ac.sh:

#!/bin/bash

# ac on/offline event handler

status=`awk '/^state: / { print $2 }' /proc/acpi/ac_adapter/$2/state`

case $status in
        "on-line")
                /sbin/laptop_mode stop
                exit 0
        ;;
        "off-line")
                /sbin/laptop_mode start
                exit 0
        ;;
esac

/etc/acpi/actions/battery.sh:

#! /bin/bash

# Automatically disable laptop mode when the battery almost runs out.

BATT_INFO=/proc/acpi/battery/$2/state

if [[ -f /proc/sys/vm/laptop_mode ]]
then
   LM=`cat /proc/sys/vm/laptop_mode`
   if [[ $LM -gt 0 ]]
   then
     if [[ -f $BATT_INFO ]]
     then
        # Source the config file only now that we know we need
        if [ -f /etc/default/laptop-mode ] ; then
                # Debian
                . /etc/default/laptop-mode
        elif [ -f /etc/sysconfig/laptop-mode ] ; then
                # Others
                . /etc/sysconfig/laptop-mode
        fi
        MINIMUM_BATTERY_MINUTES=${MINIMUM_BATTERY_MINUTES:-'10'}

        ACTION="`cat $BATT_INFO | grep charging | cut -c 26-`"
        if [[ ACTION -eq "discharging" ]]
        then
           PRESENT_RATE=`cat $BATT_INFO | grep "present rate:" | sed  "s/.* \([0-9][0-9]* \).*/\1/" `
           REMAINING=`cat $BATT_INFO | grep "remaining capacity:" | sed  "s/.* \([0-9][0-9]* \).*/\1/" `
        fi
        if (($REMAINING * 60 / $PRESENT_RATE < $MINIMUM_BATTERY_MINUTES))
        then
           /sbin/laptop_mode stop
        fi
     else
       logger -p daemon.warning "You are using laptop mode and your battery interface $BATT_INFO is missing. This may lead to loss of data when the battery runs out. Check kernel ACPI support and /proc/acpi/battery folder, and edit /etc/acpi/battery.sh to set BATT_INFO to the correct path."
     fi
   fi
fi
