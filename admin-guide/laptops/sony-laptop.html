ソニーノートブックコントロールドライバー (SNC) Readme¶

  • Copyright (C) 2004- 2005 Stelian Pop <stelian@popies.net>

  • Copyright (C) 2007 Mattia Dongili <malattia@linux.it>

このミニドライバーは、ソニーヴァイオラップトップのACPI BIOSに搭載されているSNCおよびSPICデバイスを制御します。このドライバーは、同じ（ hopefully 一貫した）インターフェースを通じて両方のデバイスの機能を統合しています。これにより、sonypiドライバーは現在、sony-laptopドライバーによって代替されています。

Fnキー（ホットキー）:¶

一部のモデルでは、SNCまたはSPICデバイスを通じてホットキーを報告します。このようなイベントは、ACPIサブシステムを通じてacpiイベントとして、およびINPUTサブシステムを通じて報告されます。/proc/bus/input/devicesのログを確認することで、これらのイベントが何であるか、およびドライバーによって作成された入力デバイスを特定できます。さらに、デバッグオプションでドライバーをロードすると、すべてのイベントがカーネルログに報告されます。

入力システムに渡される「スキャンコード」（udevで再マッピング可能）は、sony-laptop.cモジュール内の「sony_laptop_input_keycode_map」テーブルのインデックスです。たとえば、「FN/E」キーの組み合わせ（一部のモデルではEJECTCD）はスキャンコード20（0x14）を生成します。

バックライト制御:¶

ラップトップモデルがサポートする場合、/sys/class/backlight/sony/ ディレクトリにsysfsファイルが存在します。現在の画面明るさを照会および設定できます:

brightness

画面明るさの取得/設定（0〜7の整数）

actual_brightness

このファイルから読み込むと、HWからリアルな明るさ値を取得します

max_brightness

最大明るさ値

プラットフォーム固有:¶

sony-laptopモジュールをロードすると、/sys/devices/platform/sony-laptop/ ディレクトリが作成され、いくつかのファイルが生成されます。

標準のUNIXツールを使用して、これらのファイルに整数値を読み書きできます。

ファイルは:

brightness_default

ラップトップが再起動されるときに設定される画面明るさ

cdpower

内部CDドライブの電源のオン/オフ

audiopower

内部サウンドカードの電源のオン/オフ

lanpower

内部イーサネットカードの電源のオン/オフ（デバッグモードのみ）

bluetoothpower

内部ブルートゥースデバイスの電源のオン/オフ

fanspeed

ファン速度の取得/設定

一部のファイルは、特定のラップトップモデルでサポートされていない場合に存在しない可能性があります。

使用例:

# echo "1" > /sys/devices/platform/sony-laptop/brightness_default

次の再起動以降の最低画面明るさを設定

# echo "8" > /sys/devices/platform/sony-laptop/brightness_default

次の再起動以降の最高画面明るさを設定

# cat /sys/devices/platform/sony-laptop/brightness_default

値を取得

# echo "0" > /sys/devices/platform/sony-laptop/audiopower

サウンドカードをオフにします

# echo "1" > /sys/devices/platform/sony-laptop/audiopower

サウンドカードをオンにします。

RFkill制御:¶

より新しいVaioモデルでは、無線周波数発信機器を制御するための一貫したACPIメソッドが公開されています。このようなノートPCをお持ちの場合は、/sys/class/rfkill配下に必要なrfkillデバイスが存在します。以下にsony-*で始まる項目を確認してください:

# grep . /sys/class/rfkill/*/{state,name}

開発:¶

このドライバの開発に協力したい場合は（ACPI BIOSと遊ぶことによる副作用を恐れないのであれば）、ドライバをロードし、'debug=1'というオプションを渡してください。

繰り返します:

リスクの高い行為を好まない場合は、これを実行しないでください。

カーネルログには、あなたのノートPCでSNCデバイスが持つすべてのACPIメソッドの一覧が表示されます。

  • 新しいモデルでは、意味のないメソッド名の長いリストが表示されます。DSDTテーブルソースを読むと、以下のことがわかります:

  1. SNCデバイスは内部のキャパビリティ検索テーブルを使用しています

  2. SN00は検索テーブル内の値を検索するために使用されます

  3. SN06とSN07は、SN00を使用してテーブルを反復処理して取得したオフセットに基づいて、実際のメソッドを呼び出すために使用されます

  4. SN02はイベントを有効にするために使用されます。

キャパビリティ検索テーブル内の一部の値はある程度分かっていますが、他の値は不明です。すべてのsony_call_snc_handle呼び出しのコードを確認してください。

  • 古いモデルでは、CDドライブの電源をオン/オフするためのGCDP/GCDPメソッドが見られますが、他のメソッドも存在し、モデルによって異なります。

私はこれらのメソッドが何をするのか全く分かりません。

sony-laptopドライバは、いくつかのメソッド（複数のVaioモデルで見られる最新のメソッド）に対して、/sys/devices/platform/sony-laptop配下にエントリを生成します（'cdpower'と同様です）。さらにソースを編集して、'sony_nc_values'テーブルに自分のノートPCのメソッド名を追加し、SNC_HANDLE_NAMESマクロを使用して新しいエントリを追加することで、自分のノートPCのメソッドに対応するエントリを追加できます。

あなたのミッション（受け入れるなら）は、これらのエントリが何のためのものかを特定することです。これらのファイルにランダムな値を読み書きし、ノートPCへの影響を確認してください。

何か面白い発見があれば、私に報告してください。あなたの行動について私は一切責任を否定しません :)

バグ/制限事項:¶

  • このドライバはソニーの公式ドキュメントに基づいていません（存在しません）ので、動作する保証や正しい動作を保証するものではありません。私自身には問題が起きていないものの、このドライバはあなたのノートPCに重大な損害を及ぼす可能性があります（永久的な破壊を含む）

  • sony-laptopとsonypiドライバは全く相互作用しません。今後、sonypiは削除され、sony-laptopに置き換えられます。

  • spicctrlは、sonypiドライバと通信するユーザー空間のツール（/dev/sonypiを通じて）ですが、すべての機能が今ではsony-laptopを介してsysfsツリーで利用可能になったため、spicctrlも非推奨となりました。
