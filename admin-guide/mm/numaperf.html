NUMAローカルティ¶

一部のプラットフォームでは、計算ノードに複数のタイプのメモリが接続されていることがあります。これらの異なるメモリ範囲は、CPUキャッシュの整合性などの一部の特性を共有するかもしれませんが、パフォーマンスは異なります。たとえば、異なるメディアタイプやバスは帯域幅とレイテンシーに影響を与えます。

システムは、ローカリティとパフォーマンス特性に基づき、各メモリタイプを異なるドメイン、または「ノード」としてグループ化して異質なメモリをサポートしています。一部のメモリはCPUと同じノードに配置され、他のメモリはメモリ専用ノードとして提供されます。メモリ専用ノードはCPUを提供しないものの、他のノードに対して計算ノードに対してローカルである場合があります。以下の図は、2つの計算ノードとそれぞれのローカルメモリ、およびメモリ専用ノードの例を示しています。

+------------------+     +------------------+
| Compute Node 0   +-----+ Compute Node 1   |
| Local Node0 Mem  |     | Local Node1 Mem  |
+--------+---------+     +--------+---------+
         |                        |
+--------+---------+     +--------+---------+
| Slower Node2 Mem |     | Slower Node3 Mem |
+------------------+     +--------+---------+

「メモリ起動ノード」は、CPUや分離されたメモリI/Oデバイスなどの1つ以上のデバイスを含むノードで、メモリリクエストを起動できます。「メモリターゲットノード」は、1つ以上のメモリ起動ノードからアクセス可能な物理アドレス範囲を含むノードです。

複数のメモリ起動ノードが存在する場合、特定のメモリターゲットへのアクセスパフォーマンスはすべて同じとは限りません。各起動ノードとターゲットのペアは、この関係を表すために異なるアクセスクラスに分類されます。特定のターゲットに対して最も高いパフォーマンスを示す起動ノードは、そのターゲットのローカル起動ノードとされ、最高のアクセスクラス（0）が割り当てられます。任意のターゲットは1つ以上のローカル起動ノードを持ち、任意の起動ノードは複数のローカルメモリターゲットを持つことができます。

アプリケーションがメモリターゲットと起動ノードを一致させるのを支援するため、カーネルは相互にシンボリックリンクを提供します。以下の例は、アクセスクラス「0」のメモリ起動ノードとターゲットの関係を示しています。

# symlinks -v /sys/devices/system/node/nodeX/access0/targets/
relative: /sys/devices/system/node/nodeX/access0/targets/nodeY -> ../../nodeY

# symlinks -v /sys/devices/system/node/nodeY/access0/initiators/
relative: /sys/devices/system/node/nodeY/access0/initiators/nodeX -> ../../nodeX

メモリ起動ノードは同じアクセスクラスに複数のメモリターゲットを持つことができます。特定のクラス内のターゲットメモリの起動ノードは、他のリンクされた起動ノードに対して同じパフォーマンス特性を共有していることを示します。ただし、起動ノードのアクセスクラス内の各ターゲットは、他のターゲットと必ずしも同じパフォーマンスを示すとは限りません。

アクセスクラス「1」は、CPUとIO起動ノード（例: GPUやNIC）を区別し、汎用タスクスケジューリングに適した起動ノードを識別するため使用されます。アクセスクラス0とは異なり、のみCPUを含むノードが考慮されます。

NUMAパフォーマンス¶

アプリケーションは、ノードのパフォーマンス特性に基づいて、メモリを割り当てるノードを考慮するかもしれません。システムがこれらの属性を提供する場合、カーネルは、メモリノードのアクセスクラス0の初期化子の下に属性ディレクトリを追加して、sysfs階層の下でそれらをエクスポートします。

/sys/devices/system/node/nodeY/access0/initiators/

これらの属性は、このアクセスの初期化子の下でリンクされているノードからアクセスされる場合にのみ適用されます。

ローカル初期化子のパフォーマンス特性として、カーネルが提供する属性は以下のようにエクスポートされます。

# tree -P "read*|write*" /sys/devices/system/node/nodeY/access0/initiators/
/sys/devices/system/node/nodeY/access0/initiators/
|-- read_bandwidth
|-- read_latency
|-- write_bandwidth
`-- write_latency

帯域幅属性はMiB/秒単位で提供されます。

レイテンシー属性はナノ秒単位で提供されます。

ここに報告される値は、プラットフォームの定格レイテンシーおよび帯域幅に対応します。

アクセスクラス1は同じ形式を取るが、CPUからメモリへの活動にのみ値を含みます。

NUMAキャッシュ¶

システムメモリは、遅いパフォーマンスを持つメモリを小さな高速メモリでキャッシュすることで、大容量のアドレス空間を提供する階層構造で構成されることがあります。システム物理アドレスは、階層の最後のメモリレベルによって提供され、システムは高速メモリを用いて段階的に遅いレベルへのアクセスを透過的にキャッシュします。

「遠方メモリ（far memory）」という用語は、階層構造の最後のメモリレベルを指します。各増加するキャッシュレベルは、より高速な初期化子アクセスを提供し、「近接メモリ（near memory）」はシステムが提供する最も高速なキャッシュを表します。

この番号付けはCPUキャッシュとは異なります。CPU側の視点では、キャッシュレベル（例: L1、L2、L3）で各増加レベルが低パフォーマンスとなるのに対し、メモリキャッシュレベルは最後のメモリレベルに焦点を当てており、高い番号のキャッシュレベルはCPUに近いメモリ、つまり遠方メモリから遠いメモリを表します。

メモリ側のキャッシュはソフトウェアによって直接アドレス指定できません。ソフトウェアがシステムアドレスにアクセスすると、そのアドレスが近接メモリキャッシュに存在する場合、システムはそれを返します。存在しない場合は、次のメモリレベルにアクセスし、そのキャッシュレベルでヒットするか、遠方メモリに到達するまで続きます。

アプリケーションは、システムを使用する際にキャッシュ属性について知る必要はありません。ソフトウェアは、この設定を最大限に活用するため、メモリキャッシュ属性をオプションで照会することが可能です。システムがカーネルがこの情報を発見できる方法を提供する場合（例: ACPI HMAT（Heterogeneous Memory Attribute Table））、カーネルはこれらの属性をNUMAノードのメモリターゲットに追加します。

カーネルがノードにメモリキャッシュを最初に登録する際、カーネルは以下のディレクトリを作成します:

/sys/devices/system/node/nodeX/memory_side_cache/

このディレクトリが存在しない場合、システムはメモリサイドキャッシュを提供していないか、またはカーネルにその情報がアクセスできない状態です。

各キャッシュレベルの属性は、そのキャッシュレベルインデックスの下に提供されます:

/sys/devices/system/node/nodeX/memory_side_cache/indexA/
/sys/devices/system/node/nodeX/memory_side_cache/indexB/
/sys/devices/system/node/nodeX/memory_side_cache/indexC/

各キャッシュレベルのディレクトリは、その属性を提供します。例えば、以下は単一のキャッシュレベルと、ソフトウェアが照会できる属性の例です:

# tree sys/devices/system/node/node0/memory_side_cache/
/sys/devices/system/node/node0/memory_side_cache/
|-- index1
|   |-- indexing
|   |-- line_size
|   |-- size
|   `-- write_policy

「インデックスング」は、ダイレクトマップキャッシュの場合は0となり、その他のインデックスベースのマルチウェイアソシエイティビティの場合はゼロ以外の値になります。

「ラインサイズ」は、ミス時に次のキャッシュレベルからアクセスされるバイト数です。

「サイズ」は、このキャッシュレベルが提供するバイト数です。

「ライトポリシー」は、ライトバックの場合は0、ライトスルーの場合はゼロ以外の値になります。
