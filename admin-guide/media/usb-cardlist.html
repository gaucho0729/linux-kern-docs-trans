5.1. USBドライバ¶

USBボードはUSB IDという識別番号によって識別されます。

以下の lsusb コマンドはUSB IDを識別するために使用できます:

$ lsusb
...
Bus 001 Device 015: ID 046d:082d Logitech, Inc. HD Pro Webcam C920
Bus 001 Device 074: ID 2040:b131 Hauppauge
Bus 001 Device 075: ID 2013:024f PCTV Systems nanoStick T2 290e
...

新しいカメラデバイスはUSB Video Classを介して標準的な方法で自身を公開します。これらのカメラは自動的にサポートされています。 uvc-driver.

古いカメラとTV USBデバイスはUSB Vendor Classesを使用します。各ベンダーがデバイスにアクセスする方法を独自に定義しています。このセクションには、このようなベンダークラスデバイス用のカードリストが含まれています。

これはPCIよりも一般的ではありませんが、同じUSB IDが異なる製品で使用されることがあります。そのため、いくつかのメディアドライバは、パラメータを渡す機能を提供しています。 card= パラメータを使用して、特定の製品タイプに合った正しい設定に対応するカード番号を設定できます。
