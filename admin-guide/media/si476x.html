6.21.1. ドライバのTODO¶

  • SiLabsのデータシートによると、ラジオチップのファームウェアを実行時において更新することが可能で、最新バージョンに更新できます。残念ながら、私がドライバをテストした古いチップにおいてはファームウェア更新に関する記述は見つからなかったため、そのようなチップではドライバは古い機能のみを提供します。

6.21.2. debugfsを介して公開されるパラメータ¶

SI476xはユーザーが複数の特性を取得でき、寿命試験やRF性能の推定に非常に有用です。これらのパラメータはV4L2サブシステムとは関係が少なく、debugfsを介して公開され、通常のファイルI/O操作でアクセス可能です。

ドライバが公開するファイルは以下の通りです:

  • /sys/kernel/debug/<device-name>/acf このファイルはACF（Automatically Controlled Features）の状態情報を含み、ファイルの内容は以下のレイアウトを持つバイナリデータです:

    オフセット

    名前

    説明

    0x00

    blend_int

    ステレオ分離がブレンドしきい値を下回ったときに設定されるフラグ

    0x01

    hblend_int

    HiBlendカットオフ周波数がしきい値を下回ったときに設定されるフラグ

    0x02

    hicut_int

    HiCutカットオフ周波数がしきい値を下回ったときに設定されるフラグ

    0x03

    chbw_int

    チャンネルフィルタの帯域幅がしきい値を下回ったときに設定されるフラグ

    0x04

    softmute_int

    ソフトミュートの減衰レベルがソフトミュートしきい値を上回ったことを示すフラグ

    0x05

    smute

    0 - 音声がソフトミュートされていない 1 - 音声がソフトミュートされている

    0x06

    smattn

    ソフトミュートの減衰レベル（dB）

    0x07

    chbw

    チャンネルフィルタの帯域幅（kHz）

    0x08

    hicut

    HiCutカットオフ周波数（100Hz単位）

    0x09

    hiblend

    HiBlendカットオフ周波数（100Hz単位）

    0x10

    pilot

    0 - ステレオパイロットが存在しない 1 - ステレオパイロットが存在する

    0x11

    stblend

    ステレオブレンド（％）

  • /sys/kernel/debug/<device-name>/rds_blckcnt このファイルはRDS受信に関する統計情報を含み、バイナリデータのレイアウトは以下の通りです:

    オフセット

    名前

    説明

    0x00

    expected

    予期されるRDSブロック数

    0x02

    received

    受信したRDSブロック数

    0x04

    uncorrectable

    訂正不能なRDSブロックの数

  • /sys/kernel/debug/<device-name>/agc このファイルにはAGC（自動ゲイン制御）に関するパラメータ情報が含まれています

    レイアウトは次の通りです：

    オフセット

    名前

    説明

    0x00

    mxhi

    0 - FMミキサPDの高閾値がトリップされていない 1 - FMミキサPDの高閾値がトリップされている

    0x01

    mxlo

    FMミキサPDの低閾値について同様です

    0x02

    lnahi

    FM LNA PDの高閾値について同様です

    0x03

    lnalo

    FM LNA PDの低閾値について同様です

    0x04

    fmagc1

    FMAGC1のアタenuレータ抵抗値（詳細はデータシートを参照）

    0x05

    fmagc2

    FMAGC2について同様です

    0x06

    pgagain

    PGAのゲイン（dB）

    0x07

    fmwblang

    FM/WB LNAゲイン（dB）

  • /sys/kernel/debug/<device-name>/rsq このファイルにはRSQ（受信信号品質）に関するパラメータ情報が含まれています

    レイアウトは次の通りです：

    オフセット

    名前

    説明

    0x00

    multhint

    0 - マルチパス値がマルチパス高閾値を越えていない 1 - マルチパス値がマルチパス高閾値を越えている

    0x01

    multlint

    マルチパス低閾値について同様です

    0x02

    snrhint

    0 - 受信信号のSNRが高閾値を越えていない 1 - 受信信号のSNRが高閾値を越えている

    0x03

    snrlint

    SNR低閾値について同様です

    0x04

    rssihint

    RSSI高閾値について同様です

    0x05

    rssilint

    RSSI低閾値について同様です

    0x06

    bltf

    シークコマンドがシークバンドの限界に到達/巻き戻したかどうかを示すフラグ

    0x07

    snr_ready

    SNRメトリクスが準備完了していることを示します

    0x08

    rssiready

    RSSIメトリクスについて同様です

    0x09

    injside

    0 - ロー側インジェクションが使用中 1 - ハイ側インジェクションが使用中

    0x10

    afcrl

    AFCレールの有無を示すフラグ

    0x11

    有効

    チャネルが有効かどうかを示すフラグ

    0x12

    readfreq

    現在のチューニング周波数

    0x14

    freqoff

    符号化された周波数オフセット（単位：2ppm）

    0x15

    rssi

    dBuV単位でのRSSIの符号化された値

    0x16

    snr

    dB単位でのRF SNRの符号化された値

    0x17

    issi

    符号化された画像強度信号インジケーター

    0x18

    lassi

    符号化された低周波隣接チャネル強度インジケーター

    0x19

    hassi

    高周波側の同様の値

    0x20

    mult

    マルチパスインジケーター

    0x21

    dev

    周波数偏差

    0x24

    assi

    隣接チャネルSSI

    0x25

    usn

    超音波ノイズインジケーター

    0x26

    pilotdev

    100 Hz単位でのパイロット偏差

    0x27

    rdsdev

    RDS同様の値

    0x28

    assidev

    ASSI同様の値

    0x29

    strongdev

    周波数偏差

    0x30

    rdspi

    RDS PIコード

  • /sys/kernel/debug/<device-name>/rsq_primary このファイルは、プライマリチューナー専用のRSQ（受信信号品質）に関するパラメータ情報を含みます。レイアウトは上記と同じです。
