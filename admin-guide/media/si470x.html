6.19. Silicon Labs Si470x FMラジオ受信機ドライバ¶

著作権 © 2009 Tobias Lorenz <tobias.lorenz@gmx.net>

6.19.1. シリコンラボズからの情報¶

シリコンラボラトリーズは、現在の携帯電話で最も広く使用されているラジオICのメーカーです。通常はI2Cで接続されていますが、SiLabsはこのICを小型マイクロコントローラーC8051F321とともに統合したリファレンスデザインも提供しています。これによりUSBラジオが形成されます。このリファレンスデザインには、バイナリおよびソースコード形式のラジオアプリケーションも含まれています。ソフトウェアには、最新バージョンへの自動ファームウェアアップグレード機能も含まれています。これらの情報は以下からダウンロードできます: http://www.silabs.com/usbradio

6.19.2. サポートされているIC¶

以下のICは非常に似たレジスタセットを持ち、ドライバーによってサポートされているか、またはいつかサポートされる予定です:

  • Si4700: FMラジオ受信機

  • Si4701: FMラジオ受信機、RDSサポート

  • Si4702: FMラジオ受信機

  • Si4703: FMラジオ受信機、RDSサポート

  • Si4704: FMラジオ受信機、外部アンテナ不要

  • Si4705: FMラジオ受信機、外部アンテナ不要、RDSサポート、ディジタルI/O

  • Si4706: エンハンスドFM RDS/TMCラジオ受信機、外部アンテナ不要、RDS

    サポート

  • Si4707: ウェザーバンド専用ラジオ受信機（SAMEデコーダー搭載）、RDSサポート

  • Si4708: 最小サイズのFM受信機

  • Si4709: 最小サイズのFM受信機、RDSサポート

これらの情報は以下からダウンロードできます: http://www.silabs.com/products/mcu/Pages/USBFMRadioRD.aspx

6.19.3. サポートされているUSBデバイス¶

現在、以下のUSBラジオ（ベンダー:製品）がシリコンラボズ si470xチップを使用して動作することが確認されています:

  • 10c4:818a: シリコンラボズ USB FMラジオリファレンスデザイン

  • 06e1:a155: ADS/Tech FMラジオ受信機（以前はInstant FM Musicと呼ばれていた）（RDX-155-EF）

  • 1b80:d700: KWorld USB FMラジオ SnapMusic Mobile 700 (FM700)

  • 10c5:819a: Sanei Electric, Inc. FM USBラジオ（DealExtreme.com PCearとして販売）

6.19.4. ソフトウェア¶

テストは通常、Debian/testing環境でのほとんどのアプリケーションで行われます:

  • fmtools - FMチューナーカードの管理ユーティリティ

  • gnomeradio - GNOMEデスクトップ用FMラジオチューナー

  • gradio - GTK FMラジオチューナー

  • kradio - KDE用の使いやすいラジオアプリケーション

  • radio - ncursesベースのラジオアプリケーション

  • mplayer - Linux用の究極の動画プレイヤー

  • v4l2-ctl - コマンドライン用video4linuxユーティリティのコレクション

例えば、以下のように使用できます:

v4l2-ctl -d /dev/radio0 --set-ctrl=volume=10,mute=0 --set-freq=95.21 --all

また、libv4lというライブラリも利用可能です。これは、radio-si470xのようにハードウェア機能を使用するか、または現在の各記載プログラムで使用している関数を実装することで、周波数検索機能を提供します。いつかラジオプログラムはlibv4lを使用する必要があります。

RDS情報の処理には、以下のプロジェクトが進行中です: http://rdsd.berlios.de/

TMC文を人間が読める形式に変換するプロジェクトは現在ありません。

6.19.5. オーディオリスト¶

USBオーディオはALSAのsnd_usb_audioモジュールで提供されます。ラジオから音声を取得するにはSND_USB_AUDIOも選択することをお勧めします。リスト作成には音声をリダイレクトする必要があります。たとえば以下のコマンドのいずれかを使用してください。必要に応じてオーディオデバイスを調整してください（/dev/dsp* および hw:x,x）。

オーディオをテストするだけ（非常に低品質）の場合:

cat /dev/dsp1 > /dev/dsp

sox + OSSを使用する場合:

sox -2 --endian little -r 96000 -t oss /dev/dsp1 -t oss /dev/dsp

sox + alsaを使用する場合:

sox --endian little -c 2 -S -r 96000 -t alsa hw:1 -t alsa -r 96000 hw:0

artsを使用する場合:

arecord -D hw:1,0 -r96000 -c2 -f S16_LE | artsdsp aplay -B -

mplayerを使用する場合:

mplayer -radio adevice=hw=1.0:arate=96000 \
        -rawaudio rate=96000 \
        radio://<frequency>/capture

6.19.6. モジュールパラメータ¶

モジュールをロード後も、/sys/module/radio_si470x/parameters以下のsysfsマウントポイントで一部のパラメータにアクセスできます。読み取り専用ファイル（0444）の内容は、プライベートビデオコントロールでspace、band、deを変更しても更新されません。他のパラメータは実行時変更可能です。

6.19.7. エラー¶

-EIOエラーが頻繁に発生する場合はtune_timeoutを増やしてください。

タイムアウトまたはバンド制限が達成された場合、hw_freq_seekは-EAGAINを返します。

snd_usb_audioからエラーが発生した場合は、ALSAの人々に報告してください。

6.19.8. 未解決の問題¶

V4Lのマイノーデバイス割当およびパラメータ設定は完全ではありません。解決策について現在議論中です。

新しいファームウェアイメージをダウンロード/アップロードするためのUSBインターフェースがあります。これはrequest_firmwareインターフェースを使用して実装可能です。

RDS割込みモードがあります。ドライバーはすでにRDS情報をポーリングするための同じインターフェースを使用していますが、現在は割込みモードを使用していません。

LEDインターフェースがあり、ファームウェアでプログラムされたLED制御を上書きできます。これはカーネル内のLEDサポート関数を使用して提供可能です。
