6.20. Silicon Labs Si4713 FMラジオトランシーバードライバー¶

著作権 © 2009 ノキア株式会社

連絡先: Eduardo Valentin <eduardo.valentin@nokia.com>

6.20.1. デバイスに関する情報¶

このチップはシリコンラボズ製の製品です。I2Cデバイスで、現在のアドレスは0x63です。基本的に、送信機能と信号ノイズレベルの測定機能を持っています。

Si4713はFM放送ステレオ送信のための送信機能を統合しています。このチップは、低信号電力FMチャンネルを識別するための受信電力スキャン機能も統合しています。

このチップはコマンドと応答を用いてプログラミングされます。また、このチップの動作を変更するためのいくつかのプロパティもあります。

ユーザーは無線周波数（RF）送信に関する現地の規制に従う必要があります。

6.20.2. デバイスドライバの説明¶

このデバイスを処理するためには2つのモジュールが必要です。1つはI2Cデバイスドライバで、もう1つはプラットフォームドライバです。

I2Cデバイスドライバはカーネルにv4l2-subdevインターフェースをエクスポートします。すべてのプロパティはv4l2拡張コントロールインターフェースを用いてアクセス可能で、v4l2-subdevコール（g_ext_ctrls、s_ext_ctrls）を使用します。

プラットフォームデバイスドライバはユーザー空間にv4l2ラジオデバイスインターフェースをエクスポートします。そのため、I2Cデバイスドライバをサブデバイスとして利用してユーザーからのコマンドを実際にデバイスに送信します。基本的にこれはI2Cデバイスドライバのラッパーです。

アプリケーションはv4l2ラジオAPIを使用して動作周波数、ミュート状態などを指定できます。ただし、ほとんどのプロパティは拡張コントロールに含まれています。

v4l2ミュートプロパティが1（true）に設定されている場合、ドライバはチップをオフにします。

これらを要約すると以下の通りです:

  • ピロットはデバイスが送信する可聴音のトーンです。

  • pilot_frequency - ステレオピロットトーンの周波数を設定します。

  • pilot_deviation - ピロットトーンの周波数偏差レベルを設定します。

  • pilot_enabled - ピロットトーン機能を有効または無効にします。

  • si4713デバイスは送信信号にオーディオ圧縮を適用できる機能を持っています。

  • acomp_enabled - オーディオダイナミックレンジ制御機能を有効または無効にします。

  • acomp_gain - オーディオダイナミックレンジ制御のゲインを設定します。

  • acomp_threshold - オーディオダイナミックレンジ制御のしきい値レベルを設定します。

  • acomp_attack_time - オーディオダイナミックレンジ制御のアタックタイムを設定します。

  • acomp_release_time - オーディオダイナミックレンジ制御のリリースタイムを設定します。

  • リミッタの設定オーディオ偏差リミッタ機能。オーバーディベーションが発生した場合、オーディオ入力のフロントエンドゲインを調整し、常にオーバーディベーションを防ぐことが可能です。

  • limiter_enabled - リミッタ機能を有効にするか無効にするかを設定します。

  • limiter_deviation - オーディオ周波数偏差レベルを設定します。

  • limiter_release_time - リミッタリリース時間を設定します。

  • チューニング電力

  • power_level - 信号送信の出力電力レベルを設定します。antenna_capacitor - アンテナ調整キャパシタの値を手動または自動で選択します（ゼロに設定した場合）。

  • RDS関連

  • rds_ps_name - 送信用RDS PS名フィールドを設定します。

  • rds_radio_text - 送信用RDSラジオテキストを設定します。

  • rds_pi - 送信用RDS PIフィールドを設定します。

  • rds_pty - 送信用RDS PTYフィールドを設定します。

  • 地域関連

  • preemphasis - 送信に適用するプレエマッセスを設定します。

6.20.4. RNL¶

このデバイスは受信ノイズレベルを測定するインターフェースも備えています。これを実行するには、デバイスノードにioctlを実行してください。以下に例のコードを示します：

int main (int argc, char *argv[])
{
        struct si4713_rnl rnl;
        int fd = open("/dev/radio0", O_RDWR);
        int rval;

        if (argc < 2)
                return -EINVAL;

        if (fd < 0)
                return fd;

        sscanf(argv[1], "%d", &rnl.frequency);

        rval = ioctl(fd, SI4713_IOC_MEASURE_RNL, &rnl);
        if (rval < 0)
                return rval;

        printf("received noise level: %d\n", rnl.rnl);

        close(fd);
}

struct si4713_rnlとSI4713_IOC_MEASURE_RNLは、include/linux/platform_data/media/si4713.hに定義されています。

6.20.5. ステレオ/モノラルおよびRDSサブチャンネル¶

このデバイスは、利用可能なサブチャンネルを使用して設定することもできます。これを実行するにはS/G_MODULATOR ioctlを使用し、txsubchansを適切に設定してください。V4L2 API仕様書を参照してください。

6.20.6. テスト¶

テストは通常、FMチューナーカードを管理するv4l2-ctlユーティリティで行います。このツールはv4l-dvbリポジトリ内のv4l2-apps/utilディレクトリにあります。

RDS PS名を設定する例：

# v4l2-ctl -d /dev/radio0 --set-ctrl=rds_ps_name="Dummy"
