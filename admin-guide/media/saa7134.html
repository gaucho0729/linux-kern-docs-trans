6.18. saa7134ドライバ¶

著者 Gerd Hoffmann

これは、saa7130/33/34/35ベースのキャプチャ/テレビボード用のv4l2/ossデバイスドライバです。

6.18.1. Status¶

ほぼすべての機能が動作しています。ビデオ、音声、チューナー、ラジオ、MPEG TS、…

bttvと同様に、カード固有の調整が必要です。既知のテレビボード一覧はCARDLISTを確認し、ドライバのカード設定情報はsaa7134-cards.cを参照してください。

6.18.2. ビルド¶

カーネルソースを入手したら、構成、ビルド、インストール、新しいカーネルの起動を行います。必要な構成オプションは次の通りです：

./scripts/config -e PCI
./scripts/config -e INPUT
./scripts/config -m I2C
./scripts/config -m MEDIA_SUPPORT
./scripts/config -e MEDIA_PCI_SUPPORT
./scripts/config -e MEDIA_ANALOG_TV_SUPPORT
./scripts/config -e MEDIA_DIGITAL_TV_SUPPORT
./scripts/config -e MEDIA_RADIO_SUPPORT
./scripts/config -e RC_CORE
./scripts/config -e MEDIA_SUBDRV_AUTOSELECT
./scripts/config -m VIDEO_SAA7134
./scripts/config -e SAA7134_ALSA
./scripts/config -e VIDEO_SAA7134_RC
./scripts/config -e VIDEO_SAA7134_DVB
./scripts/config -e VIDEO_SAA7134_GO7007

ビルドおよびインストールには、次のコマンドを実行してください：

make && make modules_install && make install

新しいカーネルが起動した後、saa7134ドライバが自動的にロードされるはずです。

カードによっては、次のパラメータを渡す必要があります： card=<nr> insmodオプションとして。その場合は、以下の選択肢を確認してください： SAA7134 カード一覧 有効な選択肢を確認してください。

カードタイプ番号を取得したら、ファイルを介してモジュールの設定を渡すことができます（通常は、以下のいずれかの場所にあります）： /etc/modules.conf または以下のようなファイル /etc/modules-load.d/、ただし、実際の場所はディストリビューションにより異なります）。以下の内容を含むファイルを作成してください：

options saa7134 card=13 # Assuming that your card type is #13

6.18.3. 変更 / 修正¶

linux-media AT vger.kernel.org にメールを送信し、linux media git ツリーに対する統一差分（unified diffs）を添付してください：

https://git.linuxtv.org/media_tree.git/

これは、git ツリーのクローンにパッチをコミットし、パッチを送信することで実行されます： git send-email。変更内容や解決する問題、有益な用途などを詳しく記述してください…

6.18.4. 既知の問題¶

  • flyvideos用のチューナーが自動的に検出されず、使用しているバージョンによってはデフォルトの設定が動作しない場合があります。以下のオプションでドライバのデフォルトを上書きできます： tuner= insmodオプションでドライバのデフォルトを上書きできます。
