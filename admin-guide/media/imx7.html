6.8. i.MX7 Video Capture Driver¶

6.8.1. はじめに¶

i.MX7 は i.MX5/6 ファミリーよりも Image Processing Unit (IPU) を搭載していないため、キャプチャフレームの操作や処理を行う機能は限定的です。

ビデオキャプチャには、以下の 3 つのユニットが使用されます：- CMOS センサインターフェース (CSI) - ビデオ多重器 - MIPI CSI-2 受信機

MIPI Camera Input ---> MIPI CSI-2 --- > |\
                                        | \
                                        |  \
                                        | M |
                                        | U | ------>  CSI ---> Capture
                                        | X |
                                        |  /
Parallel Camera Input ----------------> | /
                                        |/

追加情報が必要な場合は、最新版の i.MX7 リファレンスマニュアルを参照してください 1.

6.8.2. エンティティ¶

6.8.3. imx7-mipi-csi2¶

これは MIPI CSI-2 受信機エンティティです。MIPI CSI-2 カメラセンサからピクセルデータを受信するための 1 つのシンクパッドと、仮想チャネル 0 に該当する 1 つのソースパッドを持っています。このモジュールは以前のバージョンの Samsung D-phy と互換性があり、2 つの D-PHY Rx データレーンをサポートしています。

6.8.4. csi-mux¶

これはビデオ多重器です。パラレルインターフェースのカメラセンサまたは MIPI CSI-2 仮想チャネル 0 から選択するための 2 つのシンクパッドを持ち、CSI にルーティングする 1 つのソースパッドを持っています。

6.8.5. csi¶

CSI はチップが外部 CMOS イメージセンサに直接接続できるようにします。CSI はパラレルバスおよび MIPI CSI-2 バスと直接インターフェースできます。受信した画像ピクセルデータを保存するための 256 x 64 FIFO と、FIFO を AHB バス経由でデータを転送する組み込み DMA コントローラーを持っています。

このエンティティは csi-mux エンティティからデータを受信する 1 つのシンクパッドと、ビデオフレームをメモリバッファに直接ルーティングする 1 つのソースパッドを持っています。このパッドはキャプチャデバイスノードに接続されています。

6.8.6. 使用注意事項¶

設定を容易にするため、V4L2 アプリケーションがビデオデバイスノードのみからコントロールを取得する場合の後方互換性を確保するため、キャプチャデバイスインターフェースは現在のパイプライン内のアクティブなエンティティからコントロールを継承します。したがって、サブデバイスまたはアクティブなキャプチャデバイスインターフェースからコントロールを取得できます。たとえば、センサコントロールはセンササブデバイスまたはアクティブなキャプチャデバイスから取得できます。

6.8.7. Warp7 と OV2680¶

このプラットフォームでは OV2680 MIPI CSI-2 モジュールが内部 MIPI CSI-2 受信機に接続されています。以下の例は、出力が 800x600 で BGGR 10 ビットバヤー形式のビデオキャプチャパイプラインの設定です：

# Setup links
media-ctl -l "'ov2680 1-0036':0 -> 'imx7-mipi-csis.0':0[1]"
media-ctl -l "'imx7-mipi-csis.0':1 -> 'csi-mux':1[1]"
media-ctl -l "'csi-mux':2 -> 'csi':0[1]"
media-ctl -l "'csi':1 -> 'csi capture':0[1]"

# Configure pads for pipeline
media-ctl -V "'ov2680 1-0036':0 [fmt:SBGGR10_1X10/800x600 field:none]"
media-ctl -V "'csi-mux':1 [fmt:SBGGR10_1X10/800x600 field:none]"
media-ctl -V "'csi-mux':2 [fmt:SBGGR10_1X10/800x600 field:none]"
media-ctl -V "'imx7-mipi-csis.0':0 [fmt:SBGGR10_1X10/800x600 field:none]"
media-ctl -V "'csi':0 [fmt:SBGGR10_1X10/800x600 field:none]"
