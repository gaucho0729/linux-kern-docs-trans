DM統計情報¶

Device Mapperは、DMデバイスのユーザー定義の領域におけるI/O統計の収集をサポートしています。領域が定義されていない場合、統計が収集されずパフォーマンスへの影響はありません。現在はbioベースのDMデバイスのみがサポートされています。

各ユーザー定義の領域は開始セクタ、長さ、ステップを指定します。指定された範囲内にステップサイズの領域ごとに個別に統計が収集されます。

領域の各ステップサイズの領域のI/O統計カウンタは、 /sys/block/*/stat または /proc/diskstats (参照： I/O 統計項目). ただし、2つの追加カウンタ（12番と13番）が提供されています。これらは読み込みと書き込みに費やした合計時間です。ヒストグラム引数が使用される場合、14番目のパラメータとして遅延のヒストグラムが報告されます。すべてのカウンタは、dmsetupを介して適切なDMデバイスに@stats_printメッセージを送信することでアクセス可能です。

報告される時間はミリ秒単位で、粒度はカーネルのティックに依存します。precise_timestampsオプションを使用すると、報告される時間はナノ秒単位になります。

各領域には作成時に割り当てられる一意の識別子、region_idがあります。領域の統計を照会する際や領域を削除する際など、region_idを指定する必要があります。一意のregion_idにより、複数のユーザー空間プログラムが同じDMデバイスの統計を要求・処理してもデータが衝突することを防げます。

DM統計の作成はkmallocを介してメモリを割り当て、それが失敗した場合はvmalloc領域を使用します。DM統計によって最大で全体のシステムメモリの1/4が割り当てられる可能性があります。管理者は以下から使用メモリ量を確認できます：

/sys/module/dm_mod/parameters/stats_current_allocated_bytes

メッセージ¶

@stats_create <range> <step> [<number_of_optional_arguments> <optional_arguments>…] [<program_id> [<aux_data>]]

新しい領域を作成し、region_idを返します。

<range>
“-”

全体デバイス

“<start_sector>+<length>”

<start_sector>から始まる<length>セクタ（512バイト単位）の範囲

<step>
“<area_size>”

範囲が<area_size>セクタを含む領域に分割されます。

“/<number_of_areas>”

範囲が指定された数の領域に分割されます。

<number_of_optional_arguments>

オプション引数の数

<optional_arguments>

サポートされるオプション引数は以下の通りです：

precise_timestamps

「jiffies」変数ではなく、ナノ秒分解能を持つ正確なタイマーアクセスを使用します。この引数を使用した場合、結果として得られる時間はナノ秒単位になります。正確なタイムスタンプは、jiffiesベースのタイムスタンプに比べてやや遅くなります。

ヒストグラム:n1,n2,n3,n4,…

レイテンシーのヒストグラムを収集します。n1、n2などの数値はヒストグラムの境界を表します。precise_timestampsが使用されていない場合、時間単位はミリ秒となり、使用されている場合、ナノ秒になります。各範囲に対して、カーネルはその範囲内で完了したリクエスト数を報告します。たとえば「histogram:10,20,30」を使用した場合、カーネルは4つの数値a:b:c:dを報告します。aは0〜10ミリ秒で完了したリクエスト数、bは10〜20ミリ秒で完了したリクエスト数、cは20〜30ミリ秒で完了したリクエスト数、dは30ミリ秒以上で完了したリクエスト数を表します。

<program_id>

オプションのパラメータです。この範囲を所有するユーザースペースの所有者を一意に識別する名前です。このパラメータにより、範囲がグループ化され、ユーザースペースのプログラムが自身が作成した範囲を識別し、他のプログラムが作成した範囲を無視できるようになります。カーネルは@stats_listメッセージの出力でこの文字列を返しますが、それ以外の用途には使用しません。オプションの引数の数を省略した場合、program_idは数値であってはなりません。数値であると解釈されるためです。

<aux_data>

オプションのパラメータです。範囲を作成したクライアントプログラムにとって有用な補助データを提供する文字列です。カーネルは@stats_listメッセージの出力でこの文字列を返しますが、それ以外の用途には使用しません。

@stats_delete <region_id>

指定されたIDの領域を削除します。

<region_id>

@stats_createから返されたregion_id

@stats_clear <region_id>

インフライトのI/Oカウンタを除き、すべてのカウンタをクリアします。

<region_id>

@stats_createから返されたregion_id

@stats_list [<program_id>]

@stats_createで登録されたすべてのリージョンを一覧表示します。

<program_id>

オプションパラメータです。このパラメータを指定した場合、一致するリージョンのみが返されます。指定しない場合は、すべてのリージョンが返されます。

出力形式:
<region_id>: <start_sector>+<length> <step> <program_id> <aux_data>

precise_timestamps histogram:n1,n2,n3,…

「precise_timestamps」および「histogram」という文字列は、リージョンを作成時に指定されていなければ表示されません。

@stats_print <region_id> [<starting_line> <number_of_lines>]

リージョンの各ステップサイズのエリアごとのカウンタを表示します。

<region_id>

@stats_createから返されたregion_id

<starting_line>

出力の開始行のインデックス。省略するとすべての行が返されます。

<number_of_lines>

出力に含める行数。省略するとすべての行が返されます。

領域の各ステップサイズのエリアの出力形式:

<start_sector>+<length>

カウンタ

最初の11つのカウンタは以下の通りです /sys/block/*/stat または /proc/diskstats.

参照してください I/O 統計項目 詳しくは以下をご参照ください。

  1. 完了した読み込み数

  2. マージされた読み込み数

  3. 読み込んだセクタ数

  4. 読み込みに費やしたミリ秒数

  5. 完了した書き込み数

  6. マージされた書き込み数

  7. 書き込んだセクタ数

  8. 書き込みに費やしたミリ秒数

  9. 現在進行中のI/O数

  10. I/Oに費やしたミリ秒数

  11. I/Oに費やした加重ミリ秒数

追加のカウンタ:

  1. 読み込みに費やした総時間（ミリ秒）

  2. 書き込みに費やした総時間（ミリ秒）

@stats_print_clear <region_id> [<starting_line> <number_of_lines>]

インフライトI/Oカウンタを除き、すべてのカウンタを印刷してからクリアします。これは、統計を消費するクライアントが印刷とクリアの間に更新された統計を失わないようにする場合に役立ちます。

<region_id>

@stats_createから返されたregion_id

<starting_line>

出力の開始行のインデックス。省略するとすべての行が印刷され、その後クリアされます。

<number_of_lines>

処理する行数。省略するとすべての行が印刷され、その後クリアされます。

@stats_set_aux <region_id> <aux_data>

指定された領域に補助データaux_dataを保存します。

<region_id>

@stats_createから返されたregion_id

<aux_data>

クライアントプログラムが作成した範囲に有用なデータを識別する文字列。カーネルはこの文字列を@stats_listメッセージの出力に返しますが、この値を何らかの用途に使用しません。

例¶

DMデバイス'vol'を100分割し、それらに統計を収集を開始します:

dmsetup message vol 0 @stats_create - /100

補助データ文字列を「foo bar baz」に設定します（各スペースのエスケープも必要です、それ以外の場合シェルがこれらを消費します）:

dmsetup message vol 0 @stats_set_aux 0 foo\\ bar\\ baz

統計を一覧表示します:

dmsetup message vol 0 @stats_list

統計を印刷します:

dmsetup message vol 0 @stats_print 0

統計を削除します:

dmsetup message vol 0 @stats_delete 0
