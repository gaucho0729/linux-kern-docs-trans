協働プロセッサパフォーマンス制御（CPPC）¶

CPPC¶

ACPI仕様で定義されるCPPCは、OSが連続的かつ抽象的なパフォーマンススケール上で論理プロセッサのパフォーマンスを管理するメカニズムを説明しています。CPPCは抽象的なパフォーマンススケールを記述するレジスタセットを公開し、パフォーマンスレベルのリクエストを処理し、各CPUのデリバリーされたパフォーマンスを測定します。

CPPCに関する詳細情報については、以下に記載されているACPI仕様をご参照ください:

http://uefi.org/specifications

一部のCPPCレジスタはsysfs経由で以下に公開されています:

/sys/devices/system/cpu/cpuX/acpi_cppc/

各CPU Xに対して:

$ ls -lR  /sys/devices/system/cpu/cpu0/acpi_cppc/
/sys/devices/system/cpu/cpu0/acpi_cppc/:
total 0
-r--r--r-- 1 root root 65536 Mar  5 19:38 feedback_ctrs
-r--r--r-- 1 root root 65536 Mar  5 19:38 highest_perf
-r--r--r-- 1 root root 65536 Mar  5 19:38 lowest_freq
-r--r--r-- 1 root root 65536 Mar  5 19:38 lowest_nonlinear_perf
-r--r--r-- 1 root root 65536 Mar  5 19:38 lowest_perf
-r--r--r-- 1 root root 65536 Mar  5 19:38 nominal_freq
-r--r--r-- 1 root root 65536 Mar  5 19:38 nominal_perf
-r--r--r-- 1 root root 65536 Mar  5 19:38 reference_perf
-r--r--r-- 1 root root 65536 Mar  5 19:38 wraparound_time

  • highest_perf : このプロセッサの最高パフォーマンス（抽象スケール）

  • nominal_perf : このプロセッサの標準的な持続パフォーマンス（抽象スケール）

  • lowest_nonlinear_perf : 非線形電力節約を持つプロセッサの最低パフォーマンス（抽象スケール）

  • lowest_perf : このプロセッサの最低パフォーマンス（抽象スケール）

  • lowest_freq : lowest_perfに対応するCPU周波数（MHz）

  • nominal_freq : nominal_perfに対応するCPU周波数（MHz）。上記の周波数は抽象スケールではなく周波数でプロセッサパフォーマンスを報告するためにのみ使用するべきです。これらの値は機能的な決定には使用しないでください。

  • feedback_ctrs : 参照カウンタとデリバリーされたパフォーマンスカウンタを含みます。参照カウンタはプロセッサの参照パフォーマンスに比例して増加し、デリバリーされたカウンタはプロセッサのデリバリーされたパフォーマンスに比例して増加します。

  • wraparound_time: フィードバックカウンタがラップアラウンドするまでの最小時間（秒）

  • reference_perf : 参照パフォーマンスカウンタが累積するパフォーマンスレベル（抽象スケール）

平均デリバリーパフォーマンスの計算¶

以下は、フィードバックカウンタの2つのスナップショット（T1とT2）を取得して平均パフォーマンスを計算する手順です。

T1: feedback_ctrsをfbc_t1として読み込み

待機またはワークロードを実行

T2: feedback_ctrsをfbc_t2として読み込み

delivered_counter_delta = fbc_t2[del] - fbc_t1[del]
reference_counter_delta = fbc_t2[ref] - fbc_t1[ref]

delivered_perf = (refernce_perf x delivered_counter_delta) / reference_counter_delta
