Freescale i.MX8 DDR Performance Monitoring Unit (PMU)¶

DRAM コントローラー内にはパフォーマンスカウンタが存在しないため、パフォーマンス信号はコントローラーのエッジに引き出され、4 x 32 ビットのカウンタが実装されています。これはカウンタ制御レジスタに設定された CSV モードによって制御され、多数の PERF シグナルが生成されます。

各カウンタの値の選択はコンフィグレジスタを通じて行われます。各カウンタには1つのレジスタが割り当てられています。カウンタ 0 は特殊で、常に「時間」をカウントし、期限切れになると自身と他のカウンタにロックをかけ、割り込みが発生します。他のカウンタがオーバーフローした場合でも、カウントを継続し、割り込みは発生しません。

「format」ディレクトリは perf_event_attr 構造体のコンフィグ（イベントID）およびコンフィグ1（AXIフィルタリング）フィールドの形式を説明しています。/sys/bus/event_source/devices/imx8_ddr0/format/ を参照してください。「events」ディレクトリは、perf ツールで使用可能なハードウェアがサポートするイベントタイプを説明しています。/sys/bus/event_source/devices/imx8_ddr0/events/ を参照してください。「caps」ディレクトリは DDR PMU で実装されたフィルタ機能を説明しています。/sys/bus/events_source/devices/imx8_ddr0/caps/ を参照してください。

perf stat -a -e imx8_ddr0/cycles/ cmd
perf stat -a -e imx8_ddr0/read/,imx8_ddr0/write/ cmd

AXI フィルタリングは CSV モード 0x41（axid-read）および 0x42（axid-write）のみで使用され、読み込みまたは書き込みがフィルタ設定に一致する場合をカウントします。フィルタ設定は DRAM コントローラーの実装によって異なり、ドライバの quirks で区別されます。ユーザー空間から情報をダンプすることも可能で、「caps」ディレクトリのフィルタは PMU が AXI ID フィルタをサポートするかどうかを示し、「enhanced_filter」は PMU が強化された AXI ID フィルタをサポートするかどうかを示します。サポートされていない場合は 0、サポートされている場合は 1 です。

  • DDR_CAP_AXI_ID_FILTER quirks（フィルタ: 1、enhanced_filter: 0）。フィルタは2つの設定部で定義されます：–AXI_ID は AxID の一致値を定義します。–AXI_MASKING は AxID のどのビットが一致判定に意味を持つかを定義します。

    • 0: 対応するビットはマスクされます。

    • 1: 対応するビットはマスクされません。つまり、一致判定に使用されます。

    AXI_ID および AXI_MASKING はパフォーマンスカウンタの DPCR1 レジスタにマッピングされています。マスクされていないビットが対応する AXI_ID ビットと一致する場合、カウンタがインクリメントされます。パフォーマンスカウンタは以下の条件でインクリメントされます：

    AxID && AXI_MASKING == AXI_ID && AXI_MASKING

    このフィルタは、axid-read と axid-write イベントで異なる AXI ID を同時にフィルタするサポートは行いません。このフィルタはカウンタ間で共有されているためです。

    perf stat -a -e imx8_ddr0/axid-read,axi_mask=0xMMMM,axi_id=0xDDDD/ cmd
perf stat -a -e imx8_ddr0/axid-write,axi_mask=0xMMMM,axi_id=0xDDDD/ cmd

    注意

    axi_maskはユーザースペースで反転しており（つまり、設定されたビットはマスクするビットを示します）、ドライバで自動的に元に戻されます。これにより、ユーザーはaxi_idを指定するだけで特定のIDを監視できるようになり、axi_maskを指定する必要がなくなるためです。

    perf stat -a -e imx8_ddr0/axid-read,axi_id=0x12/ cmd, which will monitor ARID=0x12

  • DDR_CAP_AXI_ID_FILTER_ENHANCEDのクイック（フィルタ: 1、強化フィルタ: 1）。これはDDR_CAP_AXI_ID_FILTERのクイックを拡張したもので、DDR読み込みおよび書き込みトランザクションでバイト数（バースト数ではなく）を同時に別のデータカウンターと併せてカウントすることが可能です。
