Linux における miscellaneous Binary Formats（binfmt_misc）のカーネルサポート¶

このカーネル機能により、シェルでプログラム名を入力するだけでほぼ（以下に記載の制限を参照）すべてのプログラムを実行できます。たとえば、コンパイルされた Java(TM)、Python、Emacs プログラムなどが含まれます。

これを実現するには、binfmt_misc にどのインタプリタがどのバイナリに対応するかを指定する必要があります。binfmt_misc は、ファイルの先頭にあるバイトを、提供したマジックバイトシーケンス（指定されたビットをマスク処理）と照合してバイナリタイプを認識します。binfmt_misc はファイル名拡張子も認識できます。 .com または .exe.

まず、binfmt_misc をマウントする必要があります:

mount binfmt_misc -t binfmt_misc /proc/sys/fs/binfmt_misc

新しいバイナリタイプを実際に登録するには、以下の形式の文字列を設定する必要があります: :name:type:offset:magic:mask:interpreter:flags (あなたのニーズに応じて選択できます) と、これを : にエコーバックします。ここに何を書くかは /proc/sys/fs/binfmt_misc/register.

    O - オープンバイナリ

    binfmt_miscのレガシー動作は、バイナリのフルパスをインタープリタに引数として渡します。このフラグが設定されている場合、binfmt_miscはファイルを開き、そのディスクリプタを引数として渡します。これにより、インタープリタが読み取り不可なバイナリを実行できるようになります。この機能は注意深く使用する必要があります。インタープリタが読み取り不可なバイナリの内容を漏らさないことを信頼する必要があります

    C - 資格情報

    現在、binfmt_miscの動作はインタープリタに従って新しいプロセスの資格情報とセキュリティトークンを計算します。このフラグが設定されている場合、これらの属性はバイナリに従って計算されます。また、 O フラグも含みます。この機能は注意深く使用する必要があります。root所有のsetuidバイナリがbinfmt_miscで実行される場合、インタープリタがroot権限で実拡張されます

    F - フィックスバイナリ

    通常、binfmt_miscはmiscフォーマットファイルが呼び出されるときにバイナリをラジカルに生成します。しかし、マウント名前空間やchangerootsの前にはうまく動作しないため、 F モードはエミュレーションがインストールされた直ちにバイナリを開き、開いたイメージを使ってエミュレータを生成します。これにより、インストール後は環境の変化に関係なく常に利用可能になります

いくつかの制限があります：

  • レジスタ文字列全体は1920文字を超えてはなりません

  • マジックはファイルの最初の128バイト内に存在する必要があります。つまり、オフセット＋マジックのサイズが128未満である必要があります

  • インタープリタ文字列は127文字を超えてはなりません

binfmt_miscを使用するにはまずマウントする必要があります。マウントは mount -t binfmt_misc none /proc/sys/fs/binfmt_misc コマンドで行えます。または、 none  /proc/sys/fs/binfmt_misc binfmt_misc defaults 0 0 に以下を追加 /etc/fstab で自動マウントされます

起動時に自分の /etc/rc スクリプトでバイナリ形式を追加したい場合があります。初期化プログラムのマニュアルを読み、正しい方法を確認してください

エントリの追加順序を考慮してください！後から追加したエントリが優先されます！

    echo ':i386:M::\x7fELF\x01\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x02\x00\x03:\xff\xff\xff\xff\xff\xfe\xfe\xff\xff\xff\xff\xff\xff\xff\xff\xff\xfb\xff\xff:/bin/em86:' > register
echo ':i486:M::\x7fELF\x01\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x02\x00\x06:\xff\xff\xff\xff\xff\xfe\xfe\xff\xff\xff\xff\xff\xff\xff\xff\xff\xfb\xff\xff:/bin/em86:' > register

  • パックされたDOSアプリケーションのサポートを有効にする（事前に設定されたdosemu hdimages）：

    echo ':DEXE:M::\x0eDEX::/usr/bin/dosexec:' > register

  • Wineを使用してWindows実行ファイルのサポートを有効にする：

    echo ':DOSWin:M::MZ::/usr/local/bin/wine:' > register

Javaサポートについては Java(tm) バイナリーカーネルサポート for Linux v1.03

binfmt_miscを有効/無効にするか、1つのバイナリタイプを有効/無効にするには、 /proc/sys/fs/binfmt_misc/status または /proc/.../the_nameに0（無効）または1（有効）をエコーします。ファイルをカットすると、現在の状態が確認できます binfmt_misc/the_entry.

1つのエントリまたはすべてのエントリを削除するには、 /proc/.../the_name または /proc/sys/fs/binfmt_misc/status.
