ページオーナー：各ページを割り当てた責任者を追跡する¶

はじめに¶

ページ所有者は、各ページを誰が割り当てたかを追跡するための機能です。メモリリークのデバッグやメモリhogger（メモリを大量に消費するプロセス）の特定に利用できます。割り当てが発生する際、呼び出しスタックやページの順序などの割り当て情報が各ページごとに特定のストレージに保存されます。すべてのページの状態を把握する必要がある場合、この情報を取得・分析できます。

すでにページ割り当て/解放をトレースするためのtracepointが存在していますが、各ページの責任者を特定するための分析は複雑です。ユーザー空間のプログラムが起動するまでトレースバッファを拡大する必要があります。また、起動したプログラムがトレースバッファを継続的にダンプして後処理するため、システムの挙動に影響を与える可能性が高く、デバッグに悪影響を及ぼします。

ページ所有者はさまざまな用途に利用できます。たとえば、各ページのgfpフラグ情報から正確なフラグメンテーション統計を取得できます。ページ所有者が有効になっている場合、すでに実装され有効化されています。その他の用途も幅広く歓迎されています。

ページ所有者はデフォルトで無効になっています。使用する場合は、ブートコマンドラインに"page_owner=on"を追加する必要があります。ページ所有者が実装されていても、ブートオプションで無効にされている場合、ランタイムオーバーヘッドは最小限です。ランタイムで無効な場合、所有者情報の保存にメモリを必要としないため、ランタイムメモリオーバーヘッドはありません。また、ページ所有者はページアロケータのホットパスに2つのunlikelyブランチを挿入します。ページ所有者が無効な場合、通常のカーネルと同様にアロケーションが行われます。これらの2つのunlikelyブランチは、静的キージャンプラベルパッチング機能が利用可能であれば、アロケーションパフォーマンスに影響を与えません。以下に、この機能によりカーネルのコードサイズに生じる変化を示します。

  • ページ所有者なし:

    text    data     bss     dec     hex filename
48392   2333     644   51369    c8a9 mm/page_alloc.o

  • ページ所有者あり:

    text    data     bss     dec     hex filename
48800   2445     644   51889    cab1 mm/page_alloc.o
6662     108      29    6799    1a8f mm/page_owner.o
1025       8       8    1041     411 mm/page_ext.o

全体で約8KBのコードが追加されるものの、page_alloc.oは520バイト増加し、そのうち半分未満がホットパスに含まれます。ページ所有者でカーネルをビルドし、必要に応じて有効化することで、カーネルのメモリ問題のデバッグに最適な選択肢です。

実装の詳細によって引き起こされる注意点があります。ページオーナーは、struct page extensionから情報をメモリに保存します。このメモリは、スパースメモリシステムにおいてページアロケータが開始するよりも後に初期化されるため、初期化までに多くのページが割り当てられ、それらにはオーナー情報がありません。これを修正するため、初期割り当てされたページは初期化フェーズで調査され、割り当て済みとしてマークされます。これらが正しいオーナー情報を持つとは限りませんが、少なくともページが割り当てられたかどうかをより正確に判定できます。2GBメモリのx86-64 VMボックスでは、13343の初期割り当てページが検出されマークされました（これらはほぼすべてstruct page extension機能から割り当てられています）。いずれにしても、その後は未追跡状態のページは残りません。

使い方¶

  1. ユーザースペースの補助ツールを構築:

    cd tools/vm
make page_owner_sort

  2. ページオーナーを有効化: ブートコマンドラインに「page_owner=on」を追加。

  3. デバッグしたい作業を行います

  4. ページオーナーからの情報を分析:

    cat /sys/kernel/debug/page_owner > page_owner_full.txt
./page_owner_sort page_owner_full.txt sorted_page_owner.txt

    各ページが誰によって割り当てられたかについての結果を、the sorted_page_owner.txt.
