IBM 3270 ディスプレイシステムのサポート¶

このファイルは、IBM 3270デバイスのローカルチャネル接続をサポートするドライバーについて説明しています。これは3つのセクションから構成されています:

  • はじめに

  • インストール

  • 操作

はじめに¶

この資料は、Linux/390環境での3270デバイスのインストールおよび運用方法について説明しています。3270デバイスはブロックモードの行と列を持つターミナルで、IBMやクローンメーカーが20〜30年前に数億台販売したことが確実です。

あなたが自社内に3270デバイスを所有していることに気づいていない可能性があります。VM-ESAオペレーティングシステムを使用している場合、仮想マシンに3270デバイスを定義するには、「DEF GRAF <hex-address>」というコマンドを使用します。この資料では、CP/CMSコマンドを使用して4つの3270デバイスを定義することを前提としています:

  • DEF GRAF 620

  • DEF GRAF 621

  • DEF GRAF 622

  • DEF GRAF 623

VM-ESAのネットワーク接続により、PCやワークステーションのxtermウィンドウからx3270、tn3270、または他の3270エミュレータを使用できます。DEF GRAFコマンドとxtermなどのアプリケーション、およびこのLinux-390用3270ドライバーを使用することで、Linuxボックスとの通信方法が新たに得られます。

この資料では、ドライバーのインストールとダイヤルインしたx3270の運用について説明します。

インストール¶

ドライバーをインストールするには、パッチを適用し、カーネルをビルドし、構成スクリプト（このディレクトリにあるconfig3270.sh）を実行します。

警告: 3270コンソールサポートを使用している場合、コンソールのアドレスを変更するたびに（例: siloの/boot/parmfile内のcondev=パラメータを使用して）構成スクリプトを再実行しなければなりません。より正確には、3270デバイスのセット（コンソールを含む）がお互いに対するサブチャネル識別子が変化するたびに構成スクリプトを再実行してください。構成スクリプトと結果の/tmp/mkdev3270を実行した後、すぐにReIPLを実行してください。

tub3270をモジュールとして選択した場合、/etc/modprobe.d/以下の構成ファイルに1行を追加します。VM仮想マシンを使用している場合は、DEF GRAFコマンドで仮想の3270デバイスを定義できます。

3270と3215のコンソールサポートの両方、またはどちらか一方、またはどちらも生成しない場合があります。両方生成した場合でも、VMでのコンソールタイプは変更されません。#CP Q TERMを使用して現在のコンソールタイプを確認し、#CP TERM CONMODE 3270で3270に変更できます。3270コンソールサポートのみ生成した場合、ドライバーは起動時に3215のコンソールを3270に自動変換します。

要約すると、以下の手順になります:

  1. tub3270パッチをインストール

  2. (モジュールの場合) 構成ファイルに1行を追加 /etc/modprobe.d/*.conf

  3. (VMの場合) DEF GRAFでデバイスを定義

  4. 再起動

  5. 構成

すべてが正常に動作しているかテストするには、VMとx3270を前提として、

  1. x3270ウィンドウを起動します。

  2. そのウィンドウでDIALコマンドを使用してください。

  3. すぐにLinuxログイン画面が表示されます。

インストール手順の詳細は以下の通りです：

1. 3270ドライバーは公式のLinuxカーネルソースの一部です。カーネルソースと必要なパッチを含むツリーを構築してください。その後、以下の手順を行ってください：

make oldconfig
(If you wish to disable 3215 console support, edit
.config; change CONFIG_TN3215's value to "n";
and rerun "make oldconfig".)
make image
make modules
make modules_install

2. (tub3270をモジュールとして構成している場合のみ実行してください。) ファイルに1行を追加してください /etc/modprobe.d/*.conf ドライバーを必要に応じて自動的にロードするようにします。この行を追加すると、起動が完了した時点で3270にログインプロンプトが表示されます（またはエミュレートされた3270を使用してvmゲストに接続した時点で、コマンド「DIAL <vmguestname>」を使用して）。ラインモードのメジャーナンバーが227であるため、追加する行は以下の通りです：

alias char-major-227 tub3270

3. まだ行っていない場合は、vmゲストマシンにグラフィックデバイスを定義してください。再起動（reipl）する前に以下の手順を行ってください：

  • DEFINE GRAF 620

  • DEFINE GRAF 621

  • DEFINE GRAF 622

  • DEFINE GRAF 623

4. 再起動してください。再起動プロセスはハードウェアデバイス、包括して3270を含むをスキャンし、tub3270ドライバーがロードされた後、次の手順の設定要求に正しく応答できるようにします。3270コンソールサポートを選択した場合、コンソールは3270として動作し、3215として動作しなくなります。

5. 3270設定スクリプトconfig3270を実行してください。このスクリプトは同じディレクトリ、Documentation/s390にconfig3270.shとして配布されています。生成される出力スクリプト/tmp/mkdev3270を確認し、その後そのスクリプトを実行してください。これにより必要なキャラクタースペシャルデバイスファイルが作成され、/etc/inittabへの必要な変更が行われます。

次に、/sbin/initに/etc/inittabが変更されたことを通知するため、telinitコマンドにqオペランドを指定して実行してください：

cd Documentation/s390
sh config3270.sh
sh /tmp/mkdev3270
telinit q

これは初めての実行には十分です。3270設定が変更され、config3270を再利用する場合、以下の手順を実行してください：

Change 3270 configuration
Reboot
Run config3270 and /tmp/mkdev3270
Reboot

テスト手順の詳細は以下の通りです：

1. x3270ウィンドウを起動するか、実際のハードウェア3278または3279を使用するか、または選択した3270エミュレータを使用してください。エミュレータはPCまたはワークステーション上で実行します。例えば、以下のコマンドを使用します：

x3270 vm-esa-domain-name &

43行80列の3278モデル4（デフォルトモデル番号）を指定したい場合です。ドライバーは拡張属性を活用しません。

今後表示される画面には、下部に入力ラインが表示されたVMロゴが含まれています。TABキーを押して下部のラインに移動してください（おそらく「COMMAND ===>」と表示されています）。

2. LOGINコマンドではなく、DIALコマンドを使用して、DEF GRAFコマンドで定義した仮想3270に接続してください：

dial my-vm-guest-name

3. Linux-390 オペレーティングシステムからログインプロンプトがすぐに表示されるはずです。表示されない場合は、「DIALED TO my-vm-guest-name 0620」という行が表示されます。

トラブルシューティングの手順

A. ドライバがロードされていますか？ lsmod コマンド（オペランドなし）を使用して確認してください。おそらくロードされていません。手動でロードするには、「insmod tub3270」というコマンドを使用してください。このコマンドはエラーを表示しますか？ハ！問題の原因がここにあります。

B. /etc/inittab ファイルがインストール手順3で記述されているように変更されていますか？ grep コマンドを使用して確認してください。たとえば、「grep 3270 /etc/inittab」と入力します。何も見つからない？問題の原因がここにあります！

C. デバイス専用ファイルがインストール手順2で記述されているように作成されていますか？ ls -l コマンドを使用して確認してください。たとえば、「ls -l /dev/3270/tty620」と入力します。出力はデバイス名の左に「227, 1」という文字列を含み、最初の文字が「c」で始まる必要があります（キャラクターデバイスを表します）。そのようなファイルが見つからない？「c」がない？マジョール番号が間違っている？マイノール番号が間違っている？問題の原因がここにあります！

  1. メッセージが表示されますか？

    "HCPDIA047E my-vm-guest-name 0620 does not exist"?

そうであれば、VM 3215 コンソールから「DEF GRAF 620」というコマンドを実行し、その後システムを再起動する必要があります。

運用。¶

ドライバは3270画面に3つのエリアを定義しています：ログエリア、入力エリア、ステータスエリア。

ログエリアは画面の下から2行を除いたすべての領域を占めます。ドライバはターミナル出力をこのエリアに書き込み、上から下へと順に表示します。このエリアが満杯になると、ステータスエリアは「Linux Running」から「Linux More…」に変わります。スクロールタイムアウト（デフォルトでは5秒）が経過すると、画面がクリアされ、再度上から下へ出力が書き込まれます。

入力エリアは、2番目に最後の画面行からステータスエリアの開始位置までの領域です。このエリアでコマンドを入力し、ENTERキーを押して実行します。

ステータスエリアは初期状態で「Linux Running」と表示され、安心感を与えるように設定されています。ログエリアが満杯になり出力が待機している場合、ステータスエリアは「Linux More…」に変わります。このとき、いくつかの操作を行うか、何もしないことができます。何もしない場合、画面は（デフォルトでは5秒）経過後にクリアされ、さらに出力が表示されます。入力エリアに何も入力せずにENTERキーを押すと、「Linux More…」と「Linux Holding」の間で切り替わり、スクロールが行われないことを示します。（「Linux Running」の状態で何も入力せずにENTERキーを押すと、アプリケーションに改行が送信されます。）

スクロールタイムアウト値を変更できます。たとえば、次のコマンドライン：

echo scrolltime=60 > /proc/tty/driver/tty3270

スクロールタイムアウト値を60秒に変更します。スクロールを完全に停止するには、scrolltimeを0に設定してください。

ログエリアが満たされるときに実行できる他の操作は、PA2を押してログエリアをクリアし、その中にさらに出力を行ったり、CLEARを押してログエリアと入力エリアをクリアし、ログエリアにさらに出力を行ったりするものです。

一部のプログラム機能（PF）およびプログラム注意（PA）キーは特殊な機能が事前に割り当てられています。割り当てられていないキーは押すとアラームが鳴ります。

PA1は現在実行中のアプリケーションにSIGINTを送信します。入力エリアから同じ操作を行うには、「^C」を入力してENTERを押してください。

PA2はログエリアをクリアします。出力が待機している場合は、その後ログエリアにその出力を書き込みます。

PF3はアプリケーションにEOFを入力として受信させます。また、「^D」を入力してENTERを押すことで同じようにEOFを発生させることもできます。

PFキーにはジョブの中断を引き起こす機能が事前に割り当てられていませんが、「^Z」を入力してENTERを押すことでジョブの中断を引き起こすことができます。この機能をPFキーに割り当てることを検討してください。PF7にジョブの中断を割り当てるには、次のコマンドを実行してください：

echo pf7=^z > /proc/tty/driver/tty3270

入力した文字列が「^n」という2つの文字で終わらない場合、ドライバーは改行文字を追加してttyドライバーに送信します。逆に「^n」で終わる場合は、ドライバーは「^n」を除去して改行文字を追加しません。IBM 3215ドライバーも同様の動作を行います。

PF10はチューブのコマンドスタック（デフォルトの深さは20）から最も最近のコマンドを取得して入力エリアに表示します。PF10を再度押すと次に最近のコマンドが表示され、この操作を繰り返すことができます。入力エリアが非表示になっていない（パスワード入力などではない）場合にのみコマンドがスタックに保存され、現在のトップの項目と同一でない場合に限ります。PF10はコマンのスタックを後ろに回転させ、PF11は前に回転させます。後ろへの回転機能を任意のPFキー（PAキーでも同様に）に割り当てたい場合は、次のコマンドでPA3などに割り当てることができます：

echo -e pa3=\\033k > /proc/tty/driver/tty3270

このコマンドによりPA3に文字列ESC-kが割り当てられます。同様に、文字列ESC-jは前向きの機能を実行します。（理由：bashのviモードの行編集ではESC-kとESC-jが後ろと前向きの履歴を取得します。ご提案があればお待ちしています。）

20コマンドのスタックサイズで満足しない場合は、実行中でも変更可能です。最後の100コマンドを保存するように変更するには、次のコマンドを実行してください：

echo recallsize=100 > /proc/tty/driver/tty3270

頻繁に実行するコマンドがある場合は、PFまたはPAキーに割り当てましょう！次のコマンドを使用してください：

echo pf24="mkdir foobar; cd foobar" > /proc/tty/driver/tty3270

PF24を押すと即座にmkdir foobarとcd foobarというコマンドを実行します。実行前にコマンドラインを確認したい場合は、echoコマンドの-nオプションを使用してください：

echo -n pf24="mkdir foo; cd foo" > /proc/tty/driver/tty3270
