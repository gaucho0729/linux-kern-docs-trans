1. はじめに¶

新規メンテナ（1998年10月19日） ide-cdドライバは、IDEインターフェースに接続されたATAPI 1.2からATAPI 2.6準拠のCD-ROMドライブすべてで動作します。注意点として、一部のCD-ROMメーカー（ミツミ、ソニー、クリエイティブ、Aztech、ゴールドスターなど）がATAPI準拠ドライブと独自インターフェースを備えたドライブを同時に製造しているため、独自インターフェースを採用しているドライブではこのドライバは動作しません（ただし他のCD-ROMドライバの一つは動作する可能性があります）。また、パラレルポートに接続されたATAPIドライブには対応していません。さらに、少なくとも1台のドライブ（CyCDROM CR520ie）はIDEポートに接続されていますがATAPI準拠ではありません。このようなドライブにはこのドライバは動作しません（ただしaztcdドライバをご参照ください）。 ATAPI

以下の機能を提供します：

  • データトラックからの読み込みとISO 9660ファイルシステムのマウント。

  • オーディオトラックの再生。ほとんどのCD-ROMプレイヤーは動作するはずです。私は通常Workmanを使用します。

  • マルチセッションサポート。

  • ATAPI準拠のドライブでは、オーディオトラックからデジタルオーディオデータを直接読み込む機能があります。cdda2wavというプログラムでこの機能を実行できます。ただし、実際にこの機能をサポートしているドライブは一部です。

  • ATAPI 2.6ドラフト標準に準拠したCD-ROMチェンジャーのサポートが追加されました（例：NEC CDR-251）。この拡張機能には、現在選択中のスロットを確認する関数呼び出しや、CDが挿さっているスロットを確認する関数呼び出しが含まれます。この機能を示すサンプルプログラムはこのファイルの末尾に添付されています。また、標準に準拠していないSanyo 3ディスクチェンジャーもサポートされています。注意点として、ドライバは最初のCDをスロット番号#0と見なします。

2. インストール¶

  1. ide-cdはideディスクドライバに依存しています。参照してください Enhanced IDEドライブに関する情報 ideドライバに関する最新情報です。

  2. 使用しているカーネルにideおよびide-cdドライバがコンパイルされていることを確認してください。カーネルの構成設定で、「フロッピーディスク、IDE、およびその他のブロックデバイス」セクションで、以下のいずれかを選択してください： Y (カーネル内に直接コンパイル) M (モジュールとしてコンパイルし、ロード/アンロード可能にする)

    ATA/ATAPI/MFM/RLL support
Include IDE/ATAPI CDROM support

    IDEインターフェースの種類によっては追加の設定オプションが必要になる場合があります。参照してください Enhanced IDEドライブに関する情報.

  3. iso9660ファイルシステムがカーネルに組み込まれているか、またはロード可能なモジュールとして利用可能であることを確認してください。カーネルがファイルシステムを認識しているか確認するには、/proc/filesystemsをcatコマンドで表示してください。

  4. CDROMドライブは、ホストにIDEインターフェースで接続する必要があります。システムの各インターフェースは、I/OポートアドレスとIRQ番号で定義され、標準的な割り当てはプライマリインターフェースが0x1f0と14、セカンダリインターフェースが0x170と15です。各インターフェースは最大2台のデバイスを制御でき、それぞれのデバイスはハードディスク、CDROMドライブ、フロッピーディスク、テープドライブのいずれかです。インターフェース上の2台のデバイスは マスター および スレーブと呼ばれます。これは通常、ドライブ上のジャンパによって選択可能です。

    Linuxはこれらのデバイスを以下のように名前付けます。プライマリIDEインターフェース上のマスターおよびスレーブデバイスはそれぞれ hda および hdbと呼ばれます。セカンダリインターフェース上のドライブは hdc および hddと呼ばれます。(他の場所にあるインターフェースは、第三位の文字が異なるため、別の文字が使用されます。詳しくは Enhanced IDEドライブに関する情報.)

    を参照してください。CDROMドライブがドライバーによって自動的に検出されるようにするには、IDEインターフェースが上記のプライマリまたはセカンダリアドレスのいずれかを使用していることを確認してください。さらに、CDROMドライブがIDEインターフェース上の唯一のデバイスである場合、ジャンパを マスターに設定する必要があります。(何らかの理由でシステムをこのように設定できない場合でも、ドライバーを使用できる可能性がありますが、ブート時にカーネルに追加の設定情報を渡す必要があります。詳しくは Enhanced IDEドライブに関する情報 を参照してください。)

  5. システムを起動してください。ドライブが認識されている場合、以下のようなメッセージが表示されます:

    hdb: NEC CD-ROM DRIVE:260, ATAPI CDROM drive

    このようなメッセージが表示されない場合は、以下のセクション5を参照してください。

  6. CDROMドライブの実際のデバイスへのシンボリックリンク(/dev/cdrom)を作成することを検討してください。以下のコマンドで実行できます:

    ln -s  /dev/hdX  /dev/cdrom

    ここで、Xはドライブがインストールされている場所を示す文字に置き換えてください。

  7. ドライバーからのエラーメッセージは、以下のコマンドで確認できます: dmesg Sometimes

3. 基本的な使い方¶

ISO 9660形式のCDROMは、ディスクをドライブに挿して以下のコマンドを実行することでマウントできます（root権限が必要です）:

mount -t iso9660 /dev/cdrom /mnt/cdrom

ここで、/dev/cdromが実際のデバイスへのリンクであると想定され（前のセクションのステップ5で説明）、/mnt/cdromが空のディレクトリであるとします。これで、/mnt/cdromディレクトリ以下にCDROMの内容が表示されるはずです。CDROMを eject するには、まず以下のコマンドでディスミントする必要があります:

umount /mnt/cdrom

注意：オーディオCDはマウントできません。

一部のディストリビューションでは、/etc/fstabを設定して起動時にCDROMファイルシステムを常にマウントしようとします。ただし、このようにCDROMをマウントする必要はなく、CDROMを頻繁に交換する場合は邪魔になる可能性があります。ご自身の環境に合えば、/etc/fstabからcdrom行を削除して手動でマウントするのもよいでしょう。

マルチセッションおよびフォトCDは特別な処理を必要とせず動作します。hpcdtoppmパッケージ（ftp.gwdg.de:/pub/linux/hpcdtoppm/）はフォトCDを読み込むのに役立つかもしれません。

オーディオCDを再生するには、まずデータCDROMをアンマウントし、取り外してください。その後、workman、workbone、cdplayerなどのCDROMプレイヤーのプログラムであれば動作するはずです。

一部のドライブでは、cdda2wavなどのプログラムを用いてデジタルオーディオを直接読み込むことができます。私はソニーおよびトシバのドライブのみがこの機能をサポートしていると聞きました。サポートしていないドライブでこの機能を使用するとエラーが発生します。

サポートされているチェンジャーでは、 cdchange プログラム（このファイル末尾に記載）を用いてチェンジャースロットを切り替えることができます。注意点として、ドライブをアンマウントした状態でこの操作を行ってください。このプログラムは2つの引数を取るため、CDROMデバイスと変更したいスロット番号を指定します。スロット番号が-1の場合はドライブがロード解除されます。

4. 一般的な問題¶

このセクションではドライバを使用する際に遭遇する一般的な問題とその解決策について説明します。問題が発生している場合は、以下の情報も確認することをお勧めします。 Enhanced IDEドライブに関する情報 IDEサポートコードに関する最新情報。一部の項目は古いドライババージョンにのみ適用されるものの、完全性のためここに記載しています。

ほとんどの場合、ドライバからのエラーを確認することをお勧めします。 dmesg ドライブが起動時に検出されない。

      これはドライバがドライブを正しく検出していることを意味するわけではありません。むしろ、ドライバがドライブを検出できていないにもかかわらず、あなたがそう指定したため、ドライブがあると仮定しているだけです。実際に非存在するまたは応答しないI/OアドレスでドライブにI/O操作を試みると、ステータス値が0xffのエラーが発生する可能性があります。

      一部のインターフェースの追加初期化が必要なサポートは、後の1.3.xカーネルで提供されています。動作させるには追加のカーネル構成オプションを有効にする必要があります；参照してください Enhanced IDEドライブに関する情報.

      インターフェースのサポートがなくても、以下の手順で動作させることが可能です。まずMS-DOSを起動し、適切なドライバーをロードします。その後、電源を切らずにLinuxを再起動します(ウォームブート)。この手順が成功すれば、MS-DOSのautoexecからloadlinを実行することで自動化できます。

  2. タイムアウト/IRQエラー。

  • タイムアウトエラーが常に発生する場合は、ドライブからの割込みがホストに届いていない可能性があります。

  • IRQの問題は以下のメッセージでも示されることがあります IRQプローブ失敗 (<n>) 起動中に表示されます。<n>がゼロの場合、システムは予想していたIRQでドライブからの割込みを検知できていません。(どのIRQでも可能であれば) <n>が負数の場合、システムは1つのCDROMドライブからの割込みを期待していたにもかかわらず、複数のIRQラインで割込みを検知しました。

  • ハードウェア設定を再確認し、IDEインターフェースのIRQ番号がドライバが期待するものと一致しているか確認してください。(通常の割り当ては、プライマリ(0x1f0)インターフェースが14、セカンダリ(0x170)インターフェースが15です。) また、使用しているIRQと競合する他のハードウェアがないか確認してください。BIOS設定も確認してください。一部のBIOSは個々のIRQレベルを無効化できる機能があり、あるシステムではデフォルトでIRQ 15が無効化されているという報告があります。

  • 多くのMS-DOS CDROMドライバーは、割込み設定のハードウェア問題があっても動作することがあります。これらは割込みを使用しないようにしているためです。

  • Pioneer DR-A24X を所有している場合、起動時に「irq timeout: status=0x50 { DriveReady SeekComplete }」などの不快なエラーメッセージが表示されます。Pioneer DR-A24X CDROM ドライブは現在非常に人気があります。しかし、これらのドライブは標準的な Linux ATA ディスクドライブのプローブを行うと非常に混乱してしまいます。このようなドライブを所有している場合、ATA プローブをバイパスしてこれらの CDROM ドライブの混乱を回避するには、 append="hdX=noprobe hdX=cdrom" を lilo.conf ファイルに追加し、lilo を実行してください（X はドライブがインストールされている場所に対応するドライブ文字に置き換えてください）。

  1. システムがフリーズする。

  • CDROM にアクセスしようとするとシステムがフリーズする場合、最も可能性が高い原因は、同時に行われる複数インターフェースのトランザクションを正しく処理できない不完全な IDE アダプタを搭載していることです。このような問題の最も有名な例は CMD640B チップです。この問題は、ブート時に serialize オプションを指定することで回避できます。最近のカーネルではほとんどの場合自動的にこの必要性を検出できるようになっていますが、検出は完全ではありません。詳しくは Enhanced IDEドライブに関する情報 を参照してください。 serialize オプションと CMD640B について

  • 多くの MS-DOS CDROM ドライバーは、このような不完全なハードウェアでも動作するようです。これは、CDROM 操作を他のディスク活動と重ねないためかもしれません。

  1. CDROM をマウントできません。

  • mount でエラーが発生した場合、以下のコマンドでより具体的なエラーを確認してください。 dmesg ドライバーまたはファイルシステムからのエラーが表示される可能性があります。

  • ドライブに CDROM が挿さっているか確認してください。また、ISO 9660 ディスクであることを確認してください。オーディオCDはマウントできません。

  • CDROM が挿さっており、マウントされていない状態で以下のコマンドを試してください：

    cat /dev/cdrom | od | more

    ダンプが表示される場合、ドライブとドライバーは正常に動作している可能性が高く、問題はファイルシステムレベルにある（つまり、CDROM が ISO 9660 でないか、ファイルシステム構造にエラーがある）。

  • 以下のエラーが表示される場合、 not a block device エラーが表示される場合、デバイス特殊ファイルの定義が正しいか確認してください。以下のようになっている必要があります：

    brw-rw----   1 root     disk       3,   0 Nov 11 18:48 /dev/hda
brw-rw----   1 root     disk       3,  64 Nov 11 18:48 /dev/hdb
brw-rw----   1 root     disk      22,   0 Nov 11 18:48 /dev/hdc
brw-rw----   1 root     disk      22,  64 Nov 11 18:48 /dev/hdd

    早期の Slackware リリースではこれらの定義が誤って定義されていたことがあります。誤っている場合は、scripts/MAKEDEV.ide スクリプトを実行して再作成できます（実行権限を付与するには chmod で変更してください）。

    /dev/cdrom シンボリックリンクがある場合、正しいデバイスファイルを指しているか確認してください。

    人々が「 hd1a および hd1b」というデバイスについて話す場合、これらはもともと hdc と hdd と呼ばれるもので、古い名前です。これらの名前は現在は非推奨です。

  • mountがiso9660ファイルシステムが利用できないと警告しているが、実際には利用可能である（/proc/filesystemsを確認してください）、その場合はおそらく最新版のmountが必要です。早期のバージョンは常に意味のあるエラー メッセージを表示しなかった可能性があります。

  1. ディレクトリ一覧は予測不能に切断されることがあります、 dmesg shows バッファのエラー ドライバからのエラー メッセージ。

  • 1.2.xカーネルのドライババージョンにバグがあり、この問題を引き起こす可能性がありました。1.3.0で修正されました。アップグレードできない場合は、マウント時にブロックサイズを2048に指定することで問題を回避できる可能性があります。（その場合、CDROMから直接バイナリを実行することはできません。）

    1.3.0以降のカーネルでこの現象を確認した場合は、バグとして報告してください。

  1. データの破損。

  • Hitachi CDR-7730 CDROMでは、ランダムなデータの破損がたまに観測されました。データの破損が発生した場合は、「hdx=slow」をコマンドラインパラメータとして指定することで問題を回避できる可能性がありますが、システム性能が低下する代償を伴います。

5. cdchange.c¶

/*
 * cdchange.c  [-v]  <device>  [<slot>]
 *
 * This loads a CDROM from a specified slot in a changer, and displays
 * information about the changer status.  The drive should be unmounted before
 * using this program.
 *
 * Changer information is displayed if either the -v flag is specified
 * or no slot was specified.
 *
 * Based on code originally from Gerhard Zuber <zuber@berlin.snafu.de>.
 * Changer status information, and rewrite for the new Uniform CDROM driver
 * interface by Erik Andersen <andersee@debian.org>.
 */

#include <stdio.h>
#include <stdlib.h>
#include <errno.h>
#include <string.h>
#include <unistd.h>
#include <fcntl.h>
#include <sys/ioctl.h>
#include <linux/cdrom.h>


int
main (int argc, char **argv)
{
      char *program;
      char *device;
      int fd;           /* file descriptor for CD-ROM device */
      int status;       /* return status for system calls */
      int verbose = 0;
      int slot=-1, x_slot;
      int total_slots_available;

      program = argv[0];

      ++argv;
      --argc;

      if (argc < 1 || argc > 3) {
              fprintf (stderr, "usage: %s [-v] <device> [<slot>]\n",
                       program);
              fprintf (stderr, "       Slots are numbered 1 -- n.\n");
              exit (1);
      }

     if (strcmp (argv[0], "-v") == 0) {
              verbose = 1;
              ++argv;
              --argc;
      }

      device = argv[0];

      if (argc == 2)
              slot = atoi (argv[1]) - 1;

      /* open device */
      fd = open(device, O_RDONLY | O_NONBLOCK);
      if (fd < 0) {
              fprintf (stderr, "%s: open failed for `%s`: %s\n",
                       program, device, strerror (errno));
              exit (1);
      }

      /* Check CD player status */
      total_slots_available = ioctl (fd, CDROM_CHANGER_NSLOTS);
      if (total_slots_available <= 1 ) {
              fprintf (stderr, "%s: Device `%s` is not an ATAPI "
                      "compliant CD changer.\n", program, device);
              exit (1);
      }

      if (slot >= 0) {
              if (slot >= total_slots_available) {
                      fprintf (stderr, "Bad slot number.  "
                               "Should be 1 -- %d.\n",
                               total_slots_available);
                      exit (1);
              }

              /* load */
              slot=ioctl (fd, CDROM_SELECT_DISC, slot);
              if (slot<0) {
                      fflush(stdout);
                              perror ("CDROM_SELECT_DISC ");
                      exit(1);
              }
      }

      if (slot < 0 || verbose) {

              status=ioctl (fd, CDROM_SELECT_DISC, CDSL_CURRENT);
              if (status<0) {
                      fflush(stdout);
                      perror (" CDROM_SELECT_DISC");
                      exit(1);
              }
              slot=status;

              printf ("Current slot: %d\n", slot+1);
              printf ("Total slots available: %d\n",
                      total_slots_available);

              printf ("Drive status: ");
              status = ioctl (fd, CDROM_DRIVE_STATUS, CDSL_CURRENT);
              if (status<0) {
                perror(" CDROM_DRIVE_STATUS");
              } else switch(status) {
              case CDS_DISC_OK:
                      printf ("Ready.\n");
                      break;
              case CDS_TRAY_OPEN:
                      printf ("Tray Open.\n");
                      break;
              case CDS_DRIVE_NOT_READY:
                      printf ("Drive Not Ready.\n");
                      break;
              default:
                      printf ("This Should not happen!\n");
                      break;
              }

              for (x_slot=0; x_slot<total_slots_available; x_slot++) {
                      printf ("Slot %2d: ", x_slot+1);
                      status = ioctl (fd, CDROM_DRIVE_STATUS, x_slot);
                      if (status<0) {
                           perror(" CDROM_DRIVE_STATUS");
                      } else switch(status) {
                      case CDS_DISC_OK:
                              printf ("Disc present.");
                              break;
                      case CDS_NO_DISC:
                              printf ("Empty slot.");
                              break;
                      case CDS_TRAY_OPEN:
                              printf ("CD-ROM tray open.\n");
                              break;
                      case CDS_DRIVE_NOT_READY:
                              printf ("CD-ROM drive not ready.\n");
                              break;
                      case CDS_NO_INFO:
                              printf ("No Information available.");
                              break;
                      default:
                              printf ("This Should not happen!\n");
                              break;
                      }
                if (slot == x_slot) {
                status = ioctl (fd, CDROM_DISC_STATUS);
                if (status<0) {
                      perror(" CDROM_DISC_STATUS");
                }
                switch (status) {
                      case CDS_AUDIO:
                              printf ("\tAudio disc.\t");
                              break;
                      case CDS_DATA_1:
                      case CDS_DATA_2:
                              printf ("\tData disc type %d.\t", status-CDS_DATA_1+1);
                              break;
                      case CDS_XA_2_1:
                      case CDS_XA_2_2:
                              printf ("\tXA data disc type %d.\t", status-CDS_XA_2_1+1);
                              break;
                      default:
                              printf ("\tUnknown disc type 0x%x!\t", status);
                              break;
                      }
                      }
                      status = ioctl (fd, CDROM_MEDIA_CHANGED, x_slot);
                      if (status<0) {
                              perror(" CDROM_MEDIA_CHANGED");
                      }
                      switch (status) {
                      case 1:
                              printf ("Changed.\n");
                              break;
                      default:
                              printf ("\n");
                              break;
                      }
              }
      }

      /* close device */
      status = close (fd);
      if (status != 0) {
              fprintf (stderr, "%s: close failed for `%s`: %s\n",
                       program, device, strerror (errno));
              exit (1);
      }

      exit (0);
}
