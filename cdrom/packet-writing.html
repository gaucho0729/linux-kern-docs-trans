パケット書き込み¶

簡単な開始方法¶

  • ブロックデバイスセクションでパケットサポートを選択し、ファイルシステムセクションでUDFサポートを選択してください。

  • カーネルとモジュールをコンパイルしてインストールし、再起動してください。

  • udftoolsパッケージ（pktsetup、mkudffs、cdrwtool）が必要です。ダウンロードはこちらから http://sourceforge.net/projects/linux-udf/

  • 新しいCD-RWディスクを入手し、フォーマットしてください（CD-RWがhdcであると仮定しています。必要に応じて置き換えてください）：

    # cdrwtool -d /dev/hdc -q

  • ライターを設定してください：

    # pktsetup dev_name /dev/hdc

  • 今後、/dev/pktcdvd/dev_nameをマウントし、ファイルをコピーできます。楽しんでください：

    # mount /dev/pktcdvd/dev_name /cdrom -t udf -o rw,noatime

DVD-RWメディアのパケット書き込み¶

DVD-RWディスクは、「制限された上書き」モードであればCD-RWディスクと同様に書き込みが可能です。ディスクを制限された上書きモードに設定するには、以下を実行してください：

# dvd+rw-format /dev/hdc

その後、CD-RWディスクと同じようにディスクを使用できます：

# pktsetup dev_name /dev/hdc
# mount /dev/pktcdvd/dev_name /cdrom -t udf -o rw,noatime

DVD+RWメディアのパケット書き込み¶

DVD+RW仕様によると、DVD+RWディスクをサポートするドライブは、「2KB単位での真のランダム書き込み」を実装しなければなりません。これは、ブロックサイズが2KB以上である任意のファイルシステムをそのディスクに配置できるということを意味します。例えば、以下のような操作が可能です：

# dvd+rw-format /dev/hdc   (only needed if the disc has never
                            been formatted)
# mkudffs /dev/hdc
# mount /dev/hdc /cdrom -t udf -o rw,noatime

ただし、一部のドライブは仕様に準拠せず、ホストが32KB境界でのアライメントされた書き込みを行うことを期待しています。他のドライブは仕様に準拠していますが、書き込みが32KB境界でアライメントされていない場合、パフォーマンスが悪化します。

これらの問題は、pktcdvdドライバを使用することで解決できます。このドライバは常にアライメントされた書き込みを行います：

# dvd+rw-format /dev/hdc
# pktsetup dev_name /dev/hdc
# mkudffs /dev/pktcdvd/dev_name
# mount /dev/pktcdvd/dev_name /cdrom -t udf -o rw,noatime

DVD-RAMメディアのパケット書き込み¶

DVD-RAMディスクはランダムに書き込み可能なので、pktcdvdドライバを使用する必要はありません。ただし、pktcdvdドライバを使用することでDVD+RWメディアと同じようにパフォーマンスが向上します。

備考¶

  • CD-RWメディアは通常1000回程度しか上書きできません。メディアの不要な摩耗を防ぐため、常にnoatimeマウントオプションを使用してください。

  • 不良セクタの自動リマッピング（デフekt管理）はまだ実装されていません。ディスクが摩耗した場合、少なくとも一部のファイルシステムの破損が発生する可能性があります。

  • pktcdvdドライバにより、ディスクが2KBブロックサイズの通常のブロックデバイスとして表示されるため、好きなファイルシステムをディスクに配置できます。例えば、以下を実行してください：

    # /sbin/mke2fs /dev/pktcdvd/dev_name

    ディスクにext2ファイルシステムを作成します。

pktcdvd sysfsインターフェースの使用方法¶

Linux 2.6.20以降、pktcdvdモジュールはsysfsインターフェースを持ち、これにより制御できます。例えば、「pktcdvd」ツールはこのインターフェースを使用します。(参照 http://tom.ist-im-web.de/download/pktcdvd )

「pktcdvd」は「pktsetup」と同様に動作します。例えば：

# pktcdvd -a dev_name /dev/hdc
# mkudffs /dev/pktcdvd/dev_name
# mount -t udf -o rw,noatime /dev/pktcdvd/dev_name /dvdram
# cp files /dvdram
# umount /dvdram
# pktcdvd -r dev_name

sysfsインターフェースの説明については、以下のファイルを参照してください：

Documentation/ABI/testing/sysfs-class-pktcdvd

pktcdvd debugfsインターフェースの使用方法¶

pktcdvdデバイスの情報を人間が読みやすい形式で表示するには、以下を実行してください:

# cat /sys/kernel/debug/pktcdvd/pktcdvd[0-7]/info

debugfsインターフェースの説明については、次のファイルを参照してください:

Documentation/ABI/testing/debugfs-pktcdvd
