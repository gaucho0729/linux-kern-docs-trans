産業用IIO configfsサポート¶

1. 概要¶

Configfsは、カーネルオブジェクトをファイルシステムベースで管理するマネージャーです。IIOは、configfsで簡単に設定可能なオブジェクト（例：デバイス、トリガーなど）を使用しています。

参照 Configfs - ユーザー空間駆動型カーネルオブジェクト設定 configfsの仕組みについて詳しくは、

2. 使用方法¶

IIOでconfigfsサポートを使用するには、コンパイル時にCONFIG_IIO_CONFIGFSというコンフィグオプションを選択する必要があります。

次に、configfsファイルシステムをマウントします（通常は/configディレクトリ下）：

$ mkdir /config
$ mount -t configfs none /config

この時点で、すべてのデフォルトIIOグループが作成され、/config/iio以下でアクセス可能になります。次の章では、利用可能なIIO設定オブジェクトについて説明します。

3. ソフトウェアトリガー¶

IIOのデフォルトconfigfsグループの一つが「トリガー」グループです。configfsがマウントされると自動的にアクセス可能で、/config/iio/triggers以下にあります。

IIOソフトウェアトリガーの実装は、複数のトリガー種別の作成をサポートしています。新しいトリガー種類は、include/linux/iio/sw_trigger.hに記載されたインターフェースに従って、通常は別個のカーネルモジュールとして実装されます：

/*
 * drivers/iio/trigger/iio-trig-sample.c
 * sample kernel module implementing a new trigger type
 */
#include <linux/iio/sw_trigger.h>


static struct iio_sw_trigger *iio_trig_sample_probe(const char *name)
{
      /*
       * This allocates and registers an IIO trigger plus other
       * trigger type specific initialization.
       */
}

static int iio_trig_sample_remove(struct iio_sw_trigger *swt)
{
      /*
       * This undoes the actions in iio_trig_sample_probe
       */
}

static const struct iio_sw_trigger_ops iio_trig_sample_ops = {
      .probe          = iio_trig_sample_probe,
      .remove         = iio_trig_sample_remove,
};

static struct iio_sw_trigger_type iio_trig_sample = {
      .name = "trig-sample",
      .owner = THIS_MODULE,
      .ops = &iio_trig_sample_ops,
};

module_iio_sw_trigger_driver(iio_trig_sample);

各トリガー種類は、/config/iio/triggers以下に独自のディレクトリを持ちます。iio-trig-sampleモジュールをロードすると、'trig-sample'というトリガー種類のディレクトリが /config/iio/triggers/trig-sample に作成されます。

サポートしている割込みソース（トリガー種類）は以下の通りです：

  • hrtimer、高解像度タイマを割込みソースとして使用します

3.1 hrtimerトリガーの作成と破壊¶

iio-trig-hrtimerモジュールをロードすると、hrtimerトリガー種類が登録され、ユーザーが /config/iio/triggers/hrtimer 以下でhrtimerトリガーを作成できるようになります。

e.g:

$ mkdir /config/iio/triggers/hrtimer/instance1
$ rmdir /config/iio/triggers/hrtimer/instance1

各トリガーは、そのトリガー種類に固有の属性を1つ以上持ちます。

3.2 「hrtimer」トリガー種類の属性¶

「hrtimer」トリガー種類は、/configディレクトリから設定可能な属性を持っていません。ただし、トリガーディレクトリに sampling_frequency という属性を導入しています。
