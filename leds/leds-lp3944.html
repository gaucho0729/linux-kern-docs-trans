lp3944用カーネルドライバ¶

  • National Semiconductor LP3944 Fun-light チップ

    プレフィックス: ‘lp3944’

    スキャンされるアドレス: なし（以下のお知らせセクションを参照）

    データシート:

    National Semiconductor ウェブサイトで公開されています http://www.national.com/pf/LP/LP3944.html

著者:

Antonio Ospite <ospite@studenti.unina.it>

説明¶

LP3944 は最大 8 個の LED を駆動できる補助チップで、2 つのプログラマブル DIM モードを備えています。GPIO エクスパンドャーとしても使用可能ですが、このドライバは LED コントローラーとして使用されることを想定しています。

DIM モードは LED に _blink_ パターンを設定するために使用され、パターンは以下の 2 つのパラメータを指定して定義されます：

  • 周期:

    0 秒から 1.6 秒

  • デューティー比:

    LED がオンになる周期の割合、0 から 100 まで

DIM0 または DIM1 モードで LED を設定すると、そのパターンに従って点滅します。詳細はデータシートを参照してください。

Motorola A910 スマートフォンで LP3944 は RGB LED、カメラフラッシュライト、LCD の電源を駆動しています。

備考¶

このチップは主に埋め込み環境で使用されるため、このドライバは i2c_board_info メカニズムで登録されていることを想定しています。

アダプター 0 のアドレス 0x60 でチップを登録するには、include/linux/leds-lp3944.h に従ってプラットフォームデータを設定し、i2c ボード情報の設定を行います：

static struct i2c_board_info a910_i2c_board_info[] __initdata = {
        {
                I2C_BOARD_INFO("lp3944", 0x60),
                .platform_data = &a910_lp3944_leds,
        },
};

プラットフォーム初期化関数で登録します：

i2c_register_board_info(0, a910_i2c_board_info,
                ARRAY_SIZE(a910_i2c_board_info));
