lm3556用カーネルドライバ¶

  • Texas Instruments: 1.5 A 同步昇圧LEDフラッシュドライバ（High-Side Current Source搭載）

  • データシート: http://www.national.com/ds/LM/LM3556.pdf

著者:

  • Daniel Jeong

    Contact:Daniel Jeong(daniel.jeong-at-ti.com, gshark.jeong-at-gmail.com)

説明¶

LM3556にはフラッシュ、トーチ、インジケータの3つの機能があります。

フラッシュモード¶

フラッシュモードでは、LED電流源（LED）が93.75 mAから1500 mAまでの16段階の目標電流を提供します。フラッシュ電流はCURRENT CONTROL REGISTER(0x09)で調整します。フラッシュモードはENABLE REGISTER(0x0A)で有効化され、またはSTROBEピンをHIGHにすることでアクティブになります。

LM3556のフラッシュはsys/class/leds/flash/brightnessファイルを通じて制御できます

  • STROBEピンが有効な場合、以下の例は明るさの制御のみを行い、ON/OFFはSTROBEピンで制御されます。

フラッシュ例:

オフ:

#echo 0 > sys/class/leds/flash/brightness

93.75 mA:

#echo 1 > sys/class/leds/flash/brightness

…

1500 mA:

#echo 16 > sys/class/leds/flash/brightness

トーチモード¶

トーチモードでは、CURRENT CONTROL REGISTER(0x09)で電流源（LED）が設定されます。トーチモードはENABLE REGISTER(0x0A)で有効化され、またはハードウェアのTORCH入力によってアクティブになります。

LM3556のトーチはsys/class/leds/torch/brightnessファイルを通じて制御できます。* TORCHピンが有効な場合、以下の例は明るさの制御のみを行い、ON/OFFはTORCHピンで制御されます。

トーチ例:

オフ:

#echo 0 > sys/class/leds/torch/brightness

46.88 mA:

#echo 1 > sys/class/leds/torch/brightness

…

375 mA:

#echo 8 > sys/class/leds/torch/brightness

インジケータモード¶

インジケータパターンはsys/class/leds/indicator/patternファイルを通じて設定でき、indicator_pattern配列に4つのパターンが事前に定義されています。

N-blank、パルス時間、N周期の値に応じて異なるパターンが生成されます。独自のデバイス用に新しいパターンが必要な場合は、indicator_pattern配列を独自の値に変更し、INDIC_PATTERN_SIZEを設定してください。

N-Blank、パルス時間、N周期についての詳細はデータシートを参照してください。

インジケータパターン例:

パターン0:

#echo 0 > sys/class/leds/indicator/pattern

…

パターン3:

#echo 3 > sys/class/leds/indicator/pattern

インジケータの明るさはsys/class/leds/indicator/brightnessファイルを通じて制御できます。

例:

オフ:

#echo 0 > sys/class/leds/indicator/brightness

5.86 mA:

#echo 1 > sys/class/leds/indicator/brightness

…

46.875mA:

#echo 8 > sys/class/leds/indicator/brightness

備考¶

ドライバはi2c_board_infoメカニズムで登録されていると想定しています。特定のアダプターのアドレス0x63でチップを登録するには、include/linux/platform_data/leds-lm3556.hに従ってプラットフォームデータを設定し、i2cボード情報を設定し、プラットフォーム初期化関数で登録してください

例:

static struct i2c_board_info board_i2c_ch4[] __initdata = {
        {
                 I2C_BOARD_INFO(LM3556_NAME, 0x63),
                 .platform_data = &lm3556_pdata,
         },
};

and register it in the platform init function

例:

board_register_i2c_bus(4, 400,
                        board_i2c_ch4, ARRAY_SIZE(board_i2c_ch4));
