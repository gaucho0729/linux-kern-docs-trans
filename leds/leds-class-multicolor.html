LinuxにおけるマルチカラーLEDの処理¶

説明¶

マルチカラークラスはモノクロームLEDをグループ化し、最終的な合成色の2つの側面である色相と明るさを制御可能にします。前者はmulti_intensity配列ファイルを介して制御され、後者はbrightnessファイルを介して制御されます。

マルチカラークラスの制御¶

マルチカラークラスは、配列内のインデックスとして色をグループ化するファイルを提供します。これらのファイルは、led_classフレームワークによって作成されたLED親ノードの下に子として存在します。led_classフレームワークのドキュメンテーションは、このドキュメンテーションディレクトリ内のled-class.rstに記載されています。

各カラーレッドはmulti_*ファイルの下にインデックスされます。色の順序は任意です。multi_indexファイルを読み込むことで、インデックス値に対応する色名を確認できます。

multi_indexファイルは、各multi_*配列ファイルで定義された色の文字列リストを含む配列です。

multi_intensityは、個々の色の明るさを読み込みまたは書き込むことができる配列です。この配列内のすべての要素を順番に書き込む必要があります、色LEDの明るさを更新するためには。

ディレクトリレイアウトの例¶

root:/sys/class/leds/multicolor:status# ls -lR -rw-r–r– 1 root root 4096 Oct 19 16:16 brightness -r–r–r– 1 root root 4096 Oct 19 16:16 max_brightness -r–r–r– 1 root root 4096 Oct 19 16:16 multi_index -rw-r–r– 1 root root 4096 Oct 19 16:16 multi_intensity

マルチカラークラスの明るさ制御¶

各LEDの明るさレベルは、色LEDの明るさ設定をグローバルmax_brightness設定で割った値に、要求された明るさを乗じた結果として計算されます。

led_brightness = brightness × multi_intensity / max_brightness

例: ユーザーはまず、multi_intensityファイルに各LEDの明るさレベルを書き込み、特定の色出力を持つマルチカラーLEDグループを実現します。

cat /sys/class/leds/multicolor:status/multi_index green blue red

echo 43 226 138 > /sys/class/leds/multicolor:status/multi_intensity

red -

intensity = 138 max_brightness = 255

green -

intensity = 43 max_brightness = 255

blue -

intensity = 226 max_brightness = 255

ユーザーはグローバルな「brightness」制御を書き込むことで、そのマルチカラーLEDグループの明るさを制御できます。max_brightnessが255の場合、ユーザーはLED色グループを半分に暗くしたいと考えるかもしれません。その場合は、グローバルbrightnessファイルに128という値を書き込み、各LEDに書き込まれる値をこの値に基づいて調整します。

cat /sys/class/leds/multicolor:status/max_brightness 255 echo 128 > /sys/class/leds/multicolor:status/brightness

adjusted_red_value = 128 × 138/255 = 69 adjusted_green_value = 128 × 43/255 = 21 adjusted_blue_value = 128 × 226/255 = 113

グローバル明るさファイルを読み込むと、カラーレッドグループの現在の明るさ値が返されます。

cat /sys/class/leds/multicolor:status/brightness 128
