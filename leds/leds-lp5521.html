lp5521用カーネルドライバ¶

  • National Semiconductor LP5521 LEDドライバーチップ

  • データシート: http://www.national.com/pf/LP/LP5521.html

著者: Mathias Nyman, Yuri Zaporozhets, Samu Onkalo

連絡先: Samu Onkalo (samu.p.onkalo-at-nokia.com)

説明¶

LP5521は最大3チャンネルを駆動できます。LEDはledクラス制御インターフェースを介して直接制御可能です。チャンネルの一般的な名前はlp5521:channelxで、xは0〜2です。

すべての3チャンネルはエンジンマイクロプログラムを使用して制御可能です。詳細なインストラクションについては、公開データシートを参照してください。

LP5521はさまざまなLEDパターンを実行するための内部プログラムメモリを持っています。LEDパターンを実行する方法は2通りあります。

  1. レガシーアイテフェース - enginex_modeおよびenginex_load エンジン用制御インターフェース:

    xは1〜3です。

    enginex_mode:

    無効, ロード, 実行

    enginex_load:

    プログラムを保存 (エンジンロードモードでのみ表示されます)

例 (チャンネル2のLEDを点滅開始):

cd   /sys/class/leds/lp5521:channel2/device
echo "load" > engine3_mode
echo "037f4d0003ff6000" > engine3_load
echo "run" > engine3_mode

エンジンを停止するには:

echo "disabled" > engine3_mode

  1. ファームウェアインターフェース - LP55xx共通インターフェース

詳細については、leds-lp55xx.txtの‘firmware’セクションを参照してください。

sysfsには自己テストエントリが含まれています。

テストはチップと通信し、クロックモードが要求されたものに自動的に設定されていることを確認します。

各チャンネルには独自のLED電流設定があります。

  • /sys/class/leds/lp5521:channel0/led_current - RW

  • /sys/class/leds/lp5521:channel0/max_current - RO

形式: 10x mA つまり10は1.0 mAを意味します

例: プラットフォームデータ:

static struct lp55xx_led_config lp5521_led_config[] = {
        {
              .name = "red",
                .chan_nr        = 0,
                .led_current    = 50,
              .max_current    = 130,
        }, {
              .name = "green",
                .chan_nr        = 1,
                .led_current    = 0,
              .max_current    = 130,
        }, {
              .name = "blue",
                .chan_nr        = 2,
                .led_current    = 0,
              .max_current    = 130,
        }
};

static int lp5521_setup(void)
{
      /* setup HW resources */
}

static void lp5521_release(void)
{
      /* Release HW resources */
}

static void lp5521_enable(bool state)
{
      /* Control of chip enable signal */
}

static struct lp55xx_platform_data lp5521_platform_data = {
        .led_config     = lp5521_led_config,
        .num_channels   = ARRAY_SIZE(lp5521_led_config),
        .clock_mode     = LP55XX_CLOCK_EXT,
        .setup_resources   = lp5521_setup,
        .release_resources = lp5521_release,
        .enable            = lp5521_enable,
};
注意:

chan_nrは0〜2の値を持つことができます。各チャンネルの名前は設定可能です。名前フィールドが定義されていない場合、デフォルト名は‘xxxx:channelN’に設定されます (XXXX : pdata->labelまたはi2cクライアント名、N : チャンネル番号)

プラットフォームデータで電流が0に設定されている場合、そのチャンネルは無効になり、sysfsには表示されません。
