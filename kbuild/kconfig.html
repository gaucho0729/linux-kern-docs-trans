Kconfig make config¶

このファイルには、make *config を使用する際の補助情報が含まれています make *config.

「make help」を使用して、すべての可能な構成ターゲットを一覧表示できます

xconfig（'qconf'）、menuconfig（'mconf'）、nconfig（'nconf'）プログラムにも埋め込まれたヘルプテキストがあります。ナビゲーションや検索、その他の一般的なヘルプテキストについては必ず確認してください

一般¶

新しいカーネルリリースでは、新しい構成シンボルがしばしば導入されます。より重要なのは、新しいカーネルリリースで構成シンボルがリネームされる可能性があることです。このような場合、以前に動作していた.config ファイルを使用して「make oldconfig」を実行しても、必ずしも新しいカーネルが動作するとは限りません。そのため、新たに導入されたカーネルシンボルを確認する必要があります

新しい構成シンボルの一覧を表示するには、以下を使用してください：

cp user/some/old.config .config
make listnewconfig

そして、config プログラムが1行ごとに新しいシンボルを表示します

代わりに、以下のブリートフォース方法を使用できます：

make oldconfig
scripts/diffconfig .config.old .config | less

環境変数で *config

KCONFIG_CONFIG¶

この環境変数は、デフォルトの「.config」名を上書きして、デフォルトのカーネル構成ファイル名を指定するのに使用できます

KCONFIG_OVERWRITECONFIG¶

環境変数に KCONFIG_OVERWRITECONFIG を設定すると、.config が別の場所へのシンボリックリンクである場合でも、Kconfig がシンボリックリンクを壊すことはありません。

CONFIG_¶

環境変数に設定すると CONFIG_ 、Kconfig は設定ファイルを保存する際、すべてのシンボルにその値をプレフィックスとして付けるようになり、デフォルトを使用するのではなく、 CONFIG_.

‘{allyes/allmod/allno/rand}config’ 用の環境変数

KCONFIG_ALLCONFIG¶

(lkmlメールからRob Landleyによる部分的な参考により、miniconfigに関するものです)

allyesconfig/allmodconfig/allnoconfig/randconfigなどの変異形でも、環境変数KCONFIG_ALLCONFIGをフラグまたは、ユーザーが特定の値に設定する必要のあるコンフィギュレーションシンボルを含むファイル名として使用できます。KCONFIG_ALLCONFIGがファイル名なしで使用される場合、KCONFIG_ALLCONFIGが空文字列（""）または"1"の場合に該当します。 make *config 使用されたコマンドに対応する「all{yes/mod/no/def/random}.config」というファイルを確認します（シンボル値を強制的に設定するためのもの）。 *config このファイルが見つからない場合、「all.config」というファイルを確認し、強制的に設定する値を含むかチェックします。

これにより、「ミニチュア」な構成（miniconfig）や、関心のある構成シンボルのみを含むカスタム構成ファイルを作成できます。その後、カーネルの構成システムが完全な .config ファイルを生成し、miniconfig ファイルのシンボルも含めます。

'KCONFIG_ALLCONFIG' ファイルは、（通常はすべてのシンボルのサブセットである）事前に設定された構成シンボルを含む構成ファイルです。これらの変数設定は依然として通常の依存関係チェックに適用されます。

例:

KCONFIG_ALLCONFIG=custom-notebook.config make allnoconfig

または:

KCONFIG_ALLCONFIG=mini.config make allnoconfig

または:

make KCONFIG_ALLCONFIG=mini.config allnoconfig

これらの例は、ほとんどのオプションを無効化する(allnoconfig)が、指定されたmini-configファイルに明示的にリストされているオプションを有効化または無効化します。

randconfig用の環境変数

KCONFIG_SEED¶

RNGに使用する整数値を設定したい場合は、この変数をその値に設定できます。設定しない場合、現在の時刻が使用されます。

KCONFIG_PROBABILITY¶

この変数は確率を歪ませるためのものです。この変数は未設定または空欄でも、以下の3つの形式のいずれかに設定できます：

KCONFIG_PROBABILITY

y:n分割

y:m:n分割

未設定または空欄

50 : 50

33 : 33 : 34

N

N : 100-N

N/2 : N/2 : 100-N

[1] N:M

N+M : 100-(N+M)

N : M : 100-(N+M)

[2] N:M:L

N : 100-N

M : L : 100-(M+L)

ここでN、M、Lは10進数の整数で[0,100]の範囲にあり、以下の条件を満たします：

[1] N+Mは[0,100]の範囲にあります

[2] M+Lは[0,100]の範囲にあります

例:

KCONFIG_PROBABILITY=10
        10% of booleans will be set to 'y', 90% to 'n'
        5% of tristates will be set to 'y', 5% to 'm', 90% to 'n'
KCONFIG_PROBABILITY=15:25
        40% of booleans will be set to 'y', 60% to 'n'
        15% of tristates will be set to 'y', 25% to 'm', 60% to 'n'
KCONFIG_PROBABILITY=10:15:15
        10% of booleans will be set to 'y', 90% to 'n'
        15% of tristates will be set to 'y', 15% to 'm', 70% to 'n'

syncconfig用の環境変数

KCONFIG_NOSILENTUPDATE¶

この変数が空白でない場合、静かなカーネル構成の更新を防ぎます（明示的な更新が必要です）。

KCONFIG_AUTOCONFIG¶

この環境変数を設定することで、「auto.conf」ファイルのパスと名前を指定できます。デフォルト値は「include/config/auto.conf」です。

KCONFIG_AUTOHEADER¶

この環境変数を設定することで、「autoconf.h」（ヘッダーファイル）のパスと名前を指定できます。デフォルト値は「include/generated/autoconf.h」です。

menuconfig¶

CONFIGシンボルの検索

menuconfigでの検索：

検索機能はカーネル構成シンボル名を検索しますので、探しているものに近い文字列を知っている必要があります。

例:

/hotplug
This lists all config symbols that contain "hotplug",
e.g., HOTPLUG_CPU, MEMORY_HOTPLUG.

検索のヘルプについては、/ を入力し、TAB-TABを押して（<Help>をハイライト）Enterを押します。これにより、検索文字列に正規表現（regex）を使用できることがわかります。MEMORY_HOTPLUGに興味がない場合は、以下のように試すこともできます：

/^hotplug

検索時にシンボルは以下の順序で並びます：

  • まず、完全一致するシンボルがアルファベット順に並び（完全一致とは検索文字列がシンボル名全体に一致する場合）、

  • 次に、他の一致するシンボルがアルファベット順に並びます。

例えば：^ATH.K は以下のシンボルに一致します：

ATH5K ATH9K ATH5K_AHB ATH5K_DEBUG […] ATH6KL ATH6KL_DEBUG […] ATH9K_AHB ATH9K_BTCOEX_SUPPORT ATH9K_COMMON […]

このうち、ATH5KとATH9Kのみが完全一致し、最初に並び（アルファベット順）、その後はすべての他のシンボルがアルファベット順に並びます。

menuconfigのユーザーインターフェースオプション

MENUCONFIG_COLOR¶

MENUCONFIG_COLOR変数を使用して、異なるカラーテーマを選択できます。テーマを選択するには：

make MENUCONFIG_COLOR=<theme> menuconfig

利用可能なテーマは：

- mono       => selects colors suitable for monochrome displays
- blackbg    => selects a color scheme with black background
- classic    => theme with blue background. The classic look
- bluetitle  => a LCD friendly version of classic. (default)

MENUCONFIG_MODE¶

このモードでは、すべてのサブメニューが1つの大きなツリーとして表示されます。

例:

make MENUCONFIG_MODE=single_menu menuconfig

nconfig¶

nconfigはテキストベースの代替設定ツールです。ターミナル（ウィンドウ）の下部にコマンドを実行するファンクションキーの一覧を表示します。データ入力ウィンドウ以外では、対応する数字キーを押すだけでコマンドを実行できます。例として、保存にはF6ではなく6を押すだけで済みます。

グローバルヘルプにはF1、ショートヘルプメニューにはF3を使用してください。

nconfigでの検索:

メニュー項目の「prompt」文字列や設定シンボルの中から検索できます。

メニュー項目を検索するには/を使用してください。正規表現はサポートしていません。次ヒットには<Down>、前ヒットには<Up>を使用します。検索モードを終了するには<Esc>を押してください。

F8（SymSearch）は、指定された文字列または正規表現（regex）に基づいて設定シンボルを検索します。

NCONFIG_MODE¶

このモードでは、すべてのサブメニューが1つの大きなツリーとして表示されます。

例:

make NCONFIG_MODE=single_menu nconfig

xconfig¶

xconfigでの検索:

検索機能はカーネル構成シンボル名を検索しますので、探しているものに近い文字列を知っている必要があります。

例:

Ctrl-F hotplug

または:

Menu: File, Search, hotplug

シンボル名に「hotplug」を含むすべての設定シンボル項目を一覧表示します。この検索ダイアログでは、灰色になっていない項目の設定を変更できます。また、メインメニューに戻る必要なく、別の検索文字列を入力することも可能です。

gconfig¶

gconfigでの検索:

gconfigには検索コマンドはありません。ただし、いくつかの表示オプションやモード、設定が用意されています。
