ユーザー空間で使用するカーネルヘッダのエクスポート¶

「make headers_install」コマンドは、ユーザースペースプログラムで使用するのに適した形式でカーネルのヘッダーファイルをエクスポートします。

Linux カーネルのエクスポートされたヘッダーファイルは、ユーザースペースプログラムがカーネルサービスを使用する際のAPIを記述しています。これらのカーネルヘッダーファイルは、システムのCライブラリ（glibcやuClibcなど）がシステムコールを定義する際に使用され、これらのシステムコールで使用する定数や構造体も定義されます。Cライブラリのヘッダーファイルは、「linux」サブディレクトリからカーネルヘッダーファイルをインクルードします。システムのlibcヘッダーファイルは通常、デフォルトの場所 /usr/include にインストールされ、その下のサブディレクトリ（特に /usr/include/linux と /usr/include/asm）にカーネルヘッダーが配置されます。

カーネルヘッダーは後方互換性がありますが、前方互換性はありません。これは、古いカーネルヘッダーを使用してビルドされたプログラムが新しいカーネルでも動作する（ただし新しい機能にアクセスできない場合がある）ものの、新しいカーネルヘッダーを使用してビルドされたプログラムが古いカーネルでは動作しない可能性があることを意味します。

「make headers_install」コマンドは、カーネルソースコードのトップレベルディレクトリ（または標準的なアウトオブツリー構築を使用）で実行できます。このコマンドには2つのオプション引数があります:

make headers_install ARCH=i386 INSTALL_HDR_PATH=/usr

ARCH はエクスポートするアーキテクチャを指定し、現在のアーキテクチャにデフォルトします。エクスポートされたカーネルヘッダーの linux/asm ディレクトリはプラットフォーム固有であり、サポートされているアーキテクチャの一覧を確認するには次のコマンドを使用します:

ls -d include/asm-* | sed 's/.*-//'

INSTALL_HDR_PATH はヘッダーをインストールする場所を指定し、デフォルトは「./usr」です。

INSTALL_HDR_PATH 内に自動的に「include」ディレクトリが作成され、ヘッダーは「INSTALL_HDR_PATH/include」にインストールされます。

カーネルヘッダーエクスポートインフラストラクチャは David Woodhouse <dwmw2@infradead.org>.
