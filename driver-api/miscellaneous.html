int parport_yield(struct pardevice *dev)¶

パラレルポートを一時的に放棄する

パラメータ

struct pardevice *dev

パラレルポートに接続されたデバイス

説明

他のドライバが利用するのに有益な場合、この関数はポートを放棄します。その後、以下の関数を使用してポートを再取得しようと試みます parport_claim()、および戻り値は parport_claim()と同じです。失敗した場合、ポートは未取得のままとなり、ドライバの責任でポートを再取得する必要があります。

以下の parport_yield() および parport_yield_blocking() これらの関数は、ドライバ内で他のドライバがポートを取得できるポイントを示すために使用されます。ポートの放棄は、ポートを解放して再取得するのと似ていますが、他のデバイスがポートを必要としていない場合に何も実行しないためより効率的です。実際には、他のデバイスが待機しているにもかかわらず、現在のデバイスが「タイムスライス」内にある限り何も実行されません。デフォルトのタイムスライスは0.5秒ですが、/procインターフェースを使用して調整可能です。

int parport_wait_peripheral(struct parport *port, unsigned char mask, unsigned char 結果)¶

35ミリ秒以内にステータスラインが変化するのを待機する

パラメータ

struct parport *port

監視するポート

unsigned char mask

監視するステータスライン

unsigned char result

選択したステータスラインの望ましい値

この関数は、マスクされたステータスラインが望ましい値になるか、または35ミリ秒経過するまで待機します（IEEE 1284-1994のページ24〜25を参照するとこの値がハードコードされている理由が説明されています）。 mask および 結果 パラメータはビットマスクで、parport.hに定義された定数のビットで構成されます： PARPORT_STATUS_BUSYなど。

ポートは、外設機から速い応答を期待して最初に迅速にポーリングされます。この高速ポーリング時間は/procインターフェースを使用して設定可能で、デフォルトは500マイクロ秒です。このポートのタイムアウト（ parport_set_timeout()）がゼロの場合、高速ポーリング時間は35ミリ秒となり、この関数はschedule()を呼びません。

このポートのタイムアウトがゼロでない場合、高速ポーリングが失敗した後は、 parport_wait_event() を使用して最大10ミリ秒待機し、割り込みが発生した場合は起動します。

起動（「kick」）コールバック関数、 wakeupは、ポートが排他アクセスのために利用可能になったときに呼び出されます。つまり、 parport_claim() は、起動コールバック関数内で呼び出される際には成功することが保証されています。ドライバーがポートを主張したい場合は実行する必要があります。そうでない場合は、何も行動する必要はありません。この関数は割り込みコンテキストから呼び出される可能性があるため、ブロックすることはできません。デバイスドライバーがこのようにしてポートの主張を明示的に招待されたくない場合、 wakeup can be NULL.

パラレルポート（ローコード）ドライバは、このハンドラが最初に呼ばれるドライバです。 request_irq() このハンドラはハードウェアに対して割込みを確認する処理を行います（PCスタイルのポートでは特別な処理は必要ありません）。その後、IEEE 1284コードに割込みを通知します。これは現在のIEEE 1284フェーズに応じてIEEE 1284イベントに反応する可能性があります。これ以降、 irq_funcNeedless to say, irq_func 割込みコンテキストから呼ばれるため、ブロック操作は行えません。

パルス幅変調 (PWM)¶

PWMフレームワークはPWM信号の提供者および消費者に対する抽象化を提供します。1つ以上のPWM信号を提供するコントローラーは

登録されます。提供者は、ドライバ固有の構造体にこの構造体を埋め込む必要があります。この構造体は特定のチップを記述するフィールドを含みます。 struct pwm_chipチップは1つ以上のPWM信号ソースを露出し、それぞれが

a として露出されます struct pwm_devicePWMデバイスに対して、信号の周期、デューティー比、極性、およびアクティブ状態を制御する操作が可能です。

PWMデバイスは排他リソースであり、常に1つの消費者のみが使用可能です。

enum pwm_polarity¶

PWM信号の極性

定数

PWM_POLARITY_NORMAL

デューティー比の期間にハイレベル信号を出力し、その後残りのパルス周期にロー信号を出力します。

PWM_POLARITY_INVERSED

デューティー比の期間にロー信号を出力し、その後残りのパルス周期にハイレベル信号を出力します。
