struct i3c_ibi_setup¶

IBI設定オブジェクト

定義

struct i3c_ibi_setup {
  unsigned int max_payload_len;
  unsigned int num_slots;
  void (*handler)(struct i3c_device *dev, const struct i3c_ibi_payload *payload);
};

メンバ

max_payload_len

IBIに関連するペイロードの最大長。IBIがこの数より大きいペイロードを含む場合、IBIは拒否されます。

num_slots

事前に割り当てられたIBIスロットの数。システムがIBIスロット不足になることを防ぐため、この数を適切に選択してください。それ以外の場合、IBIが失われる可能性があります。

handler

IBIが受信されるたびに呼ばれるハンドラ。このハンドラはワークキューのコンテキストで呼ばれます。スリープやバス上の新しいメッセージ送信は許可されていますが、同じワークキューにキューイングされた他の処理を遅らせるのを避けるため、ここでの処理はできるだけ速やかに終了させることが推奨されます。

説明

情報を渡すために使用される一時的な構造体 i3c_device_request_ibi()。このオブジェクトはスタック上に割り当てられるため、 i3c_device_request_ibi() すべてのビットの情報をコピーし、 i3c_device_request_ibi() が返却した後には使用しません。
