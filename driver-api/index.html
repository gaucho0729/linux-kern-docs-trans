Linuxドライバ実装者向けAPIガイド¶

カーネルはデバイスドライバの開発をサポートするため、幅広いインターフェースを提供しています。このドキュメントは、その一部のインターフェースをある程度整理されたコレクションとしてまとめたもので、今後はさらに改善されていく予定です。利用可能なサブセクションは以下に示されています。
