GPMC (汎用メモリコントローラ)¶

GPMCは、外部メモリデバイス（例として）とのインターフェースに特化した統合型メモリ制御器です

  • 非同期SRAMなどのメモリおよびアプリケーション固有の集積回路デバイスです

  • 非同期、同期、およびページモードバースト NORフラッシュデバイス、NANDフラッシュデバイス

  • 擬似SRAMデバイス

GPMCは、テキサスインSTRUMENTSのSoC（OMAPベース）に搭載されており、IP詳細については https://www.ti.com/lit/pdf/spruh73 セクション7.1

GPMC ジェネリックタイミング計算:¶

GPMC にはペリフェラルの正常動作に必要な特定のタイミング設定が必要ですが、ペリフェラルには別のタイミング設定があります。GPMC とペリフェラルが協働するためには、ペリフェラルのタイミング設定を GPMC が理解できる形式に変換する必要があります。変換方法は接続されているペリフェラルによって異なり、また GPMC クロック周波数に応じて GPMC のタイミング設定に依存する場合があります。そのため、上述の要件を満たすためのジェネリックタイミングルーチンが開発されました。

ジェネリックルーチンは、GPMC ペリフェラルのタイミング設定から GPMC のタイミングを計算するための一般的な方法を提供します。struct gpmc_device_timings のフィールドには、GPMC に接続されているペリフェラルのデータシートから取得したタイミング設定を更新する必要があります。一部のペリフェラルタイミングは時間単位またはサイクル単位で入力される場合があり、そのシナリオを処理するための仕様が提供されています（struct gpmc_device_timings の定義を参照）。ペリフェラルデータシートに指定されたタイミングがタイミング構造に存在しない場合もあるため、そのような場合はペリフェラルタイミングを既存のタイミングと関連付ける必要があります。関連付けができない場合は、ペリフェラルが要求する新しいフィールドを追加し、ジェネリックタイミングルーチンにその処理を教える必要があります。既存の処理が破壊されないよう注意してください。また、ペリフェラルデータシートに struct gpm,device_timings の一部のフィールドが記載されていない場合、その項目をゼロにします。

ジェネリックタイミングルーチンは、複数の onenand および tusb6010 ペリフェラルで正しく動作することを確認されています。

注意点: ジェネリックタイミングルーチンは、GPMC タイミング、ペリフェラルタイミング、利用可能なカスタムタイミングルーチン、およびデータシートやハードウェア（正確には、mainline でサポートされているカスタムタイミングルーチンを持つものがない状態）を理解した上で、逆工学的な方法で開発されました。

多くのGPMCタイミングは他のGPMCタイミングに依存しており（一部のGPMCタイミングは他のGPMCタイミングに純粋に依存するため、上記に記載されていないGPMCタイミングが存在する理由）、周辺機器のタイミングが間接的にGPMCタイミングに依存することになります。詳細についてはタイミングルーチンを参照してください。これらの周辺機器タイミングが対応する項目については、struct gpmc_device_timingsの定義説明を参照してください。GPMCタイミングについてはIP詳細（上記リンク）を参照してください。
