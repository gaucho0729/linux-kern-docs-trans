u8 mpt_register(MPT_CALLBACK cbfunc, MPT_DRIVER_CLASS dclass, char *func_name)¶

プロトコル固有のメインコールバックハンドラを登録します。

パラメータ

MPT_CALLBACK cbfunc

コールバック関数ポインタ

MPT_DRIVER_CLASS dclass

プロトコルドライバーのクラス（MPT_DRIVER_CLASS enum値）

char *func_name

コール関数の名前

このルーチンは、プロトコル固有のドライバー（SCSIホスト、LAN、SCSIターゲット）が自身の応答コールバックルーチンを登録するために呼び出されます。各プロトコル固有のドライバーは、IOCリソース（例：リクエストフレームの取得）を使用する前にこのルーチンを実行する必要があります。

ノート

SCSIプロトコルドライバーは現在、このルーチンを3回呼び出します

、「通常」のSCSI IO用、MptScsiTaskMgmtリクエスト用、スキャン/DVリクエスト用のそれぞれに別個のコールバックを登録するためです。

成功した場合、範囲（およびS.O.D.順序）{N,…,7,6,5,…,1}内のu8型の「ハンドル」を返します。返却値がMPT_MAX_PROTOCOL_DRIVERS（ゼロを含む！）となった場合は、呼び出し元がエラーとみなすべきです。
