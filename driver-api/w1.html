struct w1_bus_master¶

バスマスターで利用可能な操作

定義

struct w1_bus_master {
  void *data;
  u8 (*read_bit)(void *);
  void (*write_bit)(void *, u8);
  u8 (*touch_bit)(void *, u8);
  u8 (*read_byte)(void *);
  void (*write_byte)(void *, u8);
  u8 (*read_block)(void *, u8 *, int);
  void (*write_block)(void *, const u8 *, int);
  u8 (*triplet)(void *, u8);
  u8 (*reset_bus)(void *);
  u8 (*set_pullup)(void *, int);
  void (*search)(void *, struct w1_master *, u8, w1_slave_found_callback);
  char *dev_id;
};

メンバ

data

以下のすべての関数で最初のパラメータ

read_bit

ラインレベルをサンプリング return 読み取ったレベル (0 または 1)

write_bit

ラインレベルを設定

touch_bit

1-wireプロトコルをサポートするデバイス用の最低レベルの関数。touch_bit(0) = 書き込み0サイクル、touch_bit(1) = 書き込み1/読み込みサイクル return 読み取ったビット (0 または 1)

read_byte

1バイトを読み込みます。8回のtouch_bit(1)呼び出しと同じです return 読み取ったバイト

write_byte

バイトを書き込みます。8回のtouch_bit(x)呼び出しと同じです

read_block

read_byte()呼び出しの連続と同じです return 読み取ったバイト数

write_block

write_byte()呼び出しの連続と同じです

triplet

ROM検索用に2つの読み込みとスマートな書き込みを組み合わせます return bit0=Id, bit1=comp_id, bit2=dir_taken

reset_bus

存在パルス検出用の長時間の書き込み0と読み込み return -1=エラー, 0=デバイスが存在する, 1=デバイスが存在しない

set_pullup

指定された期間の強いプルアップパルスを出力してください。 return -1=エラー, 0=完了

search

高性能なハードウェアは、ROM検索のさまざまなタイプを処理できます。w1_master*はslave foundコールバックに渡されます。u8はsearch_typeで、W1_SEARCHまたはW1_ALARM_SEARCHです。

dev_id

w1スレーブが名前を作成するために使用できるオプションのデバイスID文字列で、これによりw1マスターへの接続が得られます。

注意

read_bitとwrite_bitは非常に低レベルの関数であり、1-wire操作をサポートしていないハードウェア（例：パラレル/シリアルポート）でのみ使用すべきです。read_bitとwrite_bitを定義するか、touch_bitとreset_busを少なくとも定義する必要があります。

void w1_search(struct w1_master *dev, u8 search_type, w1_slave_found_callback cb)¶

ROM検索を実行し、見つかったデバイスを登録します。

パラメータ

struct w1_master *dev

検索するマスターデバイス

u8 search_type

すべてのデバイスを検索するにはW1_SEARCH、アラーム状態のデバイスのみを返すにはW1_ALARM_SEARCHを指定します

w1_slave_found_callback cb

デバイスが見つかったときに呼び出す関数

説明

1-Wire検索は単純な二分木検索です。アドレスの各ビットごとに2ビットを読み、1ビットを書き込みます。書き込まれるビットは、そのビットと一致しないすべてのデバイスをスリープ状態にします。2つの読み込み結果が異なる場合、方向の選択は明らかです。両方のビットが0の場合、どの経路を選択するか決めなければなりません。64ビットすべてをスキャンすることができ、経路を選ばなくても済む場合、検索は完了します。

www.maxim-ic.comで「Application note 187 1-wire search algorithm」を参照してください

int w1_reset_resume_command(struct w1_master *dev)¶

別のmatch ROMではなく再開します。

パラメータ

struct w1_master *dev

マスターデバイス

説明

多数のslaveの中での1つのslaveを操作するワークフローで、複数の連続するコマンドが必要な場合、この関数は最後のマッチしたROMに対してリセットを実行した後にマッチROMを実行するのと同様です。利点は、マッチROMステップをスキップして再開コマンドを使用することです。slaveは当然ながらこのコマンドをサポートする必要があります。

バスにslaveが1つだけの場合、伝統的にマッチROMはスキップされ、効率のためSKIP ROMが実行されます。複数のslaveを持つバスでは当然この方法は機能しませんが、再開コマンドが次善の選択肢です。

w1マスターロックを保持する必要があります。

void w1_next_pullup(struct w1_master *dev, int 遅延)¶

強いプルアップを要求します。

パラメータ

struct w1_master *dev

マスターデバイス

int delay

ミリ秒単位の時間

説明

次の書き込み操作の後に指定された時間の強いプルアップを実行します。すべてのハードウェアが強いプルアップをサポートしているわけではありません。強いプルアップをサポートしないハードウェアでは、書き込み操作後に指定された時間だけ待機します。これは次の書き込み用のワンショットのリクエストです。ゼロを指定すると以前のリクエストをクリアします。w1マスターロックを保持する必要があります。

戻り値

0=成功、それ以外=エラー
