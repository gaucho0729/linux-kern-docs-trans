GSM 0710 tty マルチプレクサ HOWTO¶

このラインディスパッチは、以下の3GPPドキュメントで詳細に説明されているGSM 07.10のマルチプレクシングプロトコルを実装しています：

https://www.3gpp.org/ftp/Specs/archive/07_series/07.10/0710-720.zip

このドキュメントは、物理的なシリアルポートに接続されたGPRSおよび3Gモデムとこのドライバーを使用する方法についてのヒントを提供しています。

使い方¶

  1. モデムをシリアルポートを通じて0710マックスモードで初期化します（通常はAT+CMUX=コマンド）。使用するモデムによって、このコマンドに渡すパラメータは異なります、

  2. TIOCSETD ioctlを使用してシリアルラインをn_gsmラインディスパッチに切り替えます、

  3. GSMIOC_GETCONF / GSMIOC_SETCONF ioctlを使用してマックスを設定します、

  4. 使用中のシリアルポートのベースgsmtty番号を取得します、

初期化プログラムの主要な部分: （良い出発点はutil-linux-ng/sys-utils/ldattach.cです）：

#include <stdio.h>
#include <stdint.h>
#include <linux/gsmmux.h>
#include <linux/tty.h>
#define DEFAULT_SPEED B115200
#define SERIAL_PORT   /dev/ttyS0

      int ldisc = N_GSM0710;
      struct gsm_config c;
      struct termios configuration;
      uint32_t first;

      /* open the serial port connected to the modem */
      fd = open(SERIAL_PORT, O_RDWR | O_NOCTTY | O_NDELAY);

      /* configure the serial port : speed, flow control ... */

      /* send the AT commands to switch the modem to CMUX mode
         and check that it's successful (should return OK) */
      write(fd, "AT+CMUX=0\r", 10);

      /* experience showed that some modems need some time before
         being able to answer to the first MUX packet so a delay
         may be needed here in some case */
      sleep(3);

      /* use n_gsm line discipline */
      ioctl(fd, TIOCSETD, &ldisc);

      /* get n_gsm configuration */
      ioctl(fd, GSMIOC_GETCONF, &c);
      /* we are initiator and need encoding 0 (basic) */
      c.initiator = 1;
      c.encapsulation = 0;
      /* our modem defaults to a maximum size of 127 bytes */
      c.mru = 127;
      c.mtu = 127;
      /* set the new configuration */
      ioctl(fd, GSMIOC_SETCONF, &c);
      /* get first gsmtty device node */
      ioctl(fd, GSMIOC_GETFIRST, &first);
      printf("first muxed line: /dev/gsmtty%i\n", first);

      /* and wait for ever to keep the line discipline enabled */
      daemon(0,0);
      pause();

  1. これらのデバイスを通常のシリアルポートとして使用します。

    例えば、以下のように可能です：

    • gnokiiを使用してttygsm1でSMSを送受信する

    • pppを使用してttygsm2でデータリンクを確立する

  2. 物理ポートを閉じる前に、すべての仮想ポートを閉じます。

    物理ポートを閉じた後でもモデムはマルチプレクシングモードのままです。これにより、後続のポートの再開が失敗する可能性があります。この状況を避けるには、ハードウェアが許可する場合、モデムを再起動するか、マルチプレクシングモードを2回目の初期化前に手動で切断コマンドフレームを送信してください。切断コマンドフレームのバイトシーケンスは次の通りです：

    0xf9, 0x03, 0xef, 0x03, 0xc3, 0x16, 0xf9.
