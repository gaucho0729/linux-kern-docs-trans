バスの種類¶

定義¶

struct bus_type に関する kerneldoc を参照してください。

int bus_register(struct bus_type * bus);

宣言¶

カーネル内の各バス種類（PCI、USB など）は、この型の静的オブジェクトを1つ宣言する必要があります。name フィールドを初期化し、match コールバックをオプションで初期化する必要があります。

struct bus_type pci_bus_type = {
       .name = "pci",
       .match        = pci_bus_match,
};

構造体はヘッダーファイルにドライバにエクスポートされる必要があります：

extern struct bus_type pci_bus_type;

登録¶

バスドライバが初期化される際、bus_register を呼び出します。これにより、バスオブジェクトの残りのフィールドが初期化され、グローバルなバス種類リストに挿入されます。バスオブジェクトが登録されると、バスドライバがそのフィールドを使用できるようになります。

コールバック¶

match(): ドライバのデバイスへのアタッチ¶

デバイスID構造体の形式と、それらを比較するセマンティクスは、バス固有です。ドライバは、バス固有のドライバ構造体に存在する、サポートするデバイスのデバイスID配列を宣言します。

match コールバックの目的は、バスが特定のドライバが特定のデバイスをサポートするかどうかを判断する機会を提供することです。これにより、ドライバがサポートするデバイスIDと特定のデバイスのデバイスIDを比較できます。バス固有の機能や型安全性を犠牲にすることなく、です。

ドライバがバスに登録されるとき、バスのデバイスリストが反復され、ドライバに関連付けられていない各デバイスに対して match コールバックが呼び出されます。

デバイスとドライバのリスト¶

デバイスとドライバのリストは、多くのバスが保持しているローカルなリストを置き換える目的で用意されています。これらはそれぞれ struct devices と struct device_drivers のリストです。バスドライバはリストを自由に使用できますが、バス固有の型への変換が必要な場合があります。

LDM コアは、リストを反復するためのヘルパーファンクションを提供します：

int bus_for_each_dev(struct bus_type * bus, struct device * start,
                     void * data,
                     int (*fn)(struct device *, void *));

int bus_for_each_drv(struct bus_type * bus, struct device_driver * start,
                     void * data, int (*fn)(struct device_driver *, void *));

これらのヘルパーは、それぞれのリストを反復し、リスト内の各デバイスまたはドライバに対してコールバックを呼び出します。すべてのリストアクセスは、バスのロック（現在は読み取りのみ）を取得して同期されます。コールバック呼び出しそうに、リスト内の各オブジェクトの参照カウントがインクリメントされ、次にオブジェクトが取得された後にデクリメントされます。コールバック呼び出し時にはロックは保持されません。

sysfs¶

トップレベルのディレクトリに ‘bus’ という名前のディレクトリがあります。

各バスは、バスディレクトリ内にディレクトリを取得し、2つのデフォルトディレクトリとともにいます：

/sys/bus/pci/
|-- devices
`-- drivers

バスに登録されたドライバは、バスのドライバディレクトリ内にディレクトリを取得します：

/sys/bus/pci/
|-- devices
`-- drivers
    |-- Intel ICH
    |-- Intel ICH Joystick
    |-- agpgart
    `-- e100

そのタイプのバス上で発見された各デバイスは、バスのデバイスディレクトリ内にそのデバイスの物理階層内のディレクトリへのシンリンクが作成されます:

/sys/bus/pci/
|-- devices
|   |-- 00:00.0 -> ../../../root/pci0/00:00.0
|   |-- 00:01.0 -> ../../../root/pci0/00:01.0
|   `-- 00:02.0 -> ../../../root/pci0/00:02.0
`-- drivers

属性のエクスポート¶

struct bus_attribute {
      struct attribute        attr;
      ssize_t (*show)(struct bus_type *, char * buf);
      ssize_t (*store)(struct bus_type *, const char * buf, size_t count);
};

バスドライバーは、デバイス用のDEVICE_ATTR_RWマクロと同様の動作をするBUS_ATTR_RWマクロを使用して属性をエクスポートできます。例えば、このような定義:

static BUS_ATTR_RW(debug);

これは次の宣言に相当します:

static bus_attribute bus_attr_debug;

これにより、バスのsysfsディレクトリから属性を追加または削除するために使用できます:

int bus_create_file(struct bus_type *, struct bus_attribute *);
void bus_remove_file(struct bus_type *, struct bus_attribute *);
