8.1.9. Radiotrackラジオドライバー¶

著者: Stephen M. Benoit <benoits@servicepro.com>

日付: 1996年12月14日

8.1.9.1. 謝辞¶

このドキュメントは、Gideon le Grange（legrang@アクティブ.co.za または legrang@cs.sun.ac.za) が1994年に作成したLinux用のC言語コードを基にし、Frans Brinkman（brinkman@esd.nl) が1996年に作成した拡張版をもとに作成されました。ここに報告されている結果は、著者が自身の環境で行った実験に基づいており、ご自身の環境では異なる結果になる可能性があります…本情報の適切性や有効性について一切の保証、主張、保証はいたしません。AIMS Lab（http://www.aimslab.com/) のRadioTrack カードに関する他のドキュメントは著者に提供されていませんでした。本ドキュメントは、MS Windows以外の環境でRadioTrack カードを使用したいユーザーの助けになれば幸いです。

8.1.9.2. なぜこのドキュメント？¶

以前はMS-Windowsプラットフォームを使用していましたが、Linuxに移行した後、Gideon le Grange氏が作成したコマンドラインソフトウェアでRadioTrack カードを動作させることができることを発見し、そのソフトウェアはとても優れていました。Frans Brinkman氏はX-windowインターフェースを実装し、スキャン機能も追加しました。ハッキングの価値として、チューナーが通常のFMラジオ放送帯域（87.0〜109.0 MHz）を超えて調整できるか試してみたかったのです。北米の放送テレビチャンネルから音声キャリアを拾える可能性があるためです。結果はあまり成功しませんでしたが、Linuxでのioportプログラミングについて学び、カードのハードウェア設計についていくつかの洞察を得ることができました。

それでは、さらに時間を無駄にすることなく、詳細を以下に示します。

8.1.9.3. 物理的な説明¶

RadioTrack カードはISA 8ビットFMラジオカードです。ラジオ周波数（RF）入力は単にアンテナケーブルで、出力はミニチュア電話プラグを通じて得られるパワーアウディオ信号です。そのRF動作周波数は概ね87.0〜109.0 MHz（商業FM放送帯域）に限定されています。ただし、レジスタをプログラムして周波数をこれらの限界を超えるように設定することも可能ですが、実験の結果はあまり期待に応えませんでした。中間周波数（IF）信号を変調する可変周波数振幅発生器（VFO）はおそらく小さな有用な周波数範囲を持ち、上述の限界を超えると巻き戻しやクリッピングが発生する可能性があります。

8.1.9.4. IOPORTを用いたカードの制御¶

RadioTrack (base) ioportは0x30cまたは0x20cのいずれかに設定可能です。関与するioportは1つだけのようです。ioportのデコード回路は非常に単純で、個々のioportビットがラジオカードの特定の機能（またはブロック）に直接対応しています。このため、1回のioport書き込みで複数の機能を同時に変更することが可能です。ioportを通じて得られるフィードバックは「ステレオ検出」ビットのみのようです。

8.1.9.5. プログラミング例¶

Default:        BASE <-- 0xc8  (current volume, no stereo detect,
                                radio enable, tuner adjust disable)

Card Off:       BASE <-- 0x00  (audio mute, no stereo detect,
                                radio disable, tuner adjust disable)

Card On:        BASE <-- 0x00  (see "Card Off", clears any unfinished business)
                BASE <-- 0xc8  (see "Default")

Volume Down:    BASE <-- 0x48  (volume down, no stereo detect,
                                radio enable, tuner adjust disable)
                wait 10 msec
                BASE <-- 0xc8  (see "Default")

Volume Up:      BASE <-- 0x88  (volume up, no stereo detect,
                                radio enable, tuner adjust disable)
                wait 10 msec
                BASE <-- 0xc8  (see "Default")

Check Stereo:   BASE <-- 0xd8  (current volume, stereo detect,
                                radio enable, tuner adjust disable)
                wait 100 msec
                x <-- BASE     (read ioport)
                BASE <-- 0xc8  (see "Default")

                x=0xff ==> "not stereo", x=0xfd ==> "stereo detected"

Set Frequency:  code = (freq*40) + 10486188
                foreach of the 24 bits in code,
                (from Least to Most Significant):
                to write a "zero" bit,
                BASE <-- 0x01  (audio mute, no stereo detect, radio
                                disable, "zero" bit phase 1, tuner adjust)
                BASE <-- 0x03  (audio mute, no stereo detect, radio
                                disable, "zero" bit phase 2, tuner adjust)
                to write a "one" bit,
                BASE <-- 0x05  (audio mute, no stereo detect, radio
                                disable, "one" bit phase 1, tuner adjust)
                BASE <-- 0x07  (audio mute, no stereo detect, radio
                                disable, "one" bit phase 2, tuner adjust)
