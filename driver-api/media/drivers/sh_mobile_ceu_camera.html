8.1.11. クロッピングおよびスケーリングアルゴリズム、sh_mobile_ceu_cameraドライバで使用されるアルゴリズム¶

著者: Guennadi Liakhovetski <g.liakhovetski@gmx.de>

8.1.11.1. 用語¶

センサーのスケーリング: 水平および垂直スケーリング、センサードライバによって設定されるホストスケーリング: -”- ホストドライバの組み合わせスケーリング: sensor_scale * host_scale

上記のチャートにおいて、マイナスとスラッシュは「実際の」データ量を、ポイントとアクセントは「有用な」データを表し、基本的にCEUスケーリングおよびクロッピング出力がクライアントのソース平面にマッピングされている。

このような設定はユーザーのリクエストによって生成される:

S_CROP(左／上 = (5) - (1), 幅／高さ = (5’) - (5)) S_FMT(幅／高さ = (6’) - (6))

ここでは:

(1) 〜 (1’) - 最大幅または高さ (1) 〜 (2) - センサークロップされた左または上 (2) 〜 (2’) - センサークロップされた幅または高さ (3) 〜 (3’) - センサースケール (3) 〜 (4) - CEUクロップされた左または上 (4) 〜 (4’) - CEUクロップされた幅または高さ (5) 〜 (5’) - CEUクロップされた幅または高さに逆センサースケールを適用 (2) 〜 (5) - CEUクロップされた左または上に逆センサースケールを適用 (6) 〜 (6’) - CEUスケール - ユーザー窓

8.1.11.3. S_FMT¶

入力矩形はすでに最適な状態なので、変更しないでください。

  1. 現在のセンサースケールを計算:

    scale_s = ((2’) - (2)) / ((3’) - (3))

2. 「有効な」入力クロップ（センササブウィンドウ）を計算 - 現在のセンサースケールでCEUクロップを入力ウィンドウにスケーリングして戻す - これはユーザーのS_CROP:

width_u = (5’) - (5) = ((4’) - (4)) * scale_s

3. 「有効な」入力ウィンドウからユーザーがリクエストしたウィンドウへの新しい組み合わせスケールを計算:

scale_comb = width_u / ((6’) - (6))

4. 組み合わせスケールを実際の入力ウィンドウに適用してセンサー出力ウィンドウを計算:

width_s_out = ((7’) - (7)) = ((2’) - (2)) / scale_comb

  1. センサー出力ウィンドウに反復的なセンサーS_FMTを適用する。

    subdev->video_ops->s_fmt(.width = width_s_out)

  2. センサー出力ウィンドウを取得（g_fmt）

  3. 新しいセンサースケールを計算:

    scale_s_new = ((3’)_new - (3)_new) / ((2’) - (2))

8. 新しいCEUクロップを計算 - 以前に計算した「有効な」クロップにセンサースケールを適用:

width_ceu = (4’)_new - (4)_new = width_u / scale_s_new left_ceu = (4)_new - (3)_new = ((5) - (2)) / scale_s_new

  1. 新しいウィンドウにCEUクロッピングを適用:

    ceu_crop(.width = width_ceu, .left = left_ceu)

  2. ユーザーがリクエストしたウィンドウにCEUスケーリングを適用:

    scale_ceu = width_ceu / width

8.1.11.4. S_CROP¶

以下の V4L2 クロッピングAPI 述べている:

「…仕様では原点や単位が定義されていないが、慣例上ドライバは未スケーリングのサンプルを0Hを基準に水平にカウントすべきである。」

私たちは助言に従い、クロッピング単位をクライアントの入力ピクセルとして解釈します。

クロッピングは以下の6つのステップで行われます：

  1. センサーからユーザーの矩形を正確に取得します。

  2. 小さければ、より大きなものを取得するまで繰り返します。結果: センサーは2:2’にクロップされ、ターゲットクロップは5:5’、現在の出力形式は6’-6です。

  3. 前ステップではセンサーが出力フレームを可能な限り保持しようとしましたが、変更する可能性があります。再度取得します。

  4. センサーは3:3’にスケール変更されました。センサーのスケールは(2’ - 2)/(3’ - 3)です。中間ウィンドウを計算: 4’ - 4 = (5’ - 5) * (3’ - 3)/(2’ - 2)

  5. ホストスケールを計算し適用: (6’ - 6)/(4’ - 4)

  6. ホストクロップを計算し適用: 6 - 7 = (5 - 2) * (6’ - 6)/(5’ - 5)
