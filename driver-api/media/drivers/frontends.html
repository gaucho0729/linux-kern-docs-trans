struct drxk_config¶

DRX-Kの初期パラメータを設定します

定義

struct drxk_config {
  u8 adr;
  bool single_master;
  bool no_i2c_bridge;
  bool parallel_ts;
  bool dynamic_clk;
  bool enable_merr_cfg;
  bool antenna_dvbt;
  u16 antenna_gpio;
  u8 mpeg_out_clk_strength;
  int chunk_size;
  const char      *microcode_name;
  int qam_demod_parameter_count;
};

メンバ

adr

DRX-KのI2Cアドレス

single_master

デバイスが単一マスターモードで動作しています

no_i2c_bridge

チューナーと通信するためのI2Cブリッジの切り替えを行いません

parallel_ts

真の場合、デバイスが並列TSを使用し、それ以外はシリアルを使用します。

dynamic_clk

真の場合、クロックが動的に調整されます。静的クロックの場合はそれ以外です。

enable_merr_cfg

SIO_PDR_PERR_CFG/SIO_PDR_MVAL_CFGを有効化します。

antenna_dvbt

アンテナをDVB-Cに切り替えるためのGPIOビット。値が1の場合は1=DVBC、0=DVBT。ゼロの場合は逆になります。

antenna_gpio

アンテナを制御するためのGPIOビット

mpeg_out_clk_strength

DRXK MPEG出力クロックのドライブ強度

chunk_size

I2Cメッセージの最大サイズ

microcode_name

マイクロコードを含むファームウェアファイルの名前

qam_demod_parameter_count

デモデューラーのパラメータを設定するコマンドに使用されるパラメータ数。すべてのファームウェアは2パラメータコマンドを使用します。例外は drxk_a3.mc ファームウェアで4パラメータコマンドを使用します。値が0（デフォルト）またはそれ以下の場合、正しいパラメータ数が自動的に検出されます。

説明

On the *_gpio vars、ビット0はUIO-1、ビット1はUIO-2、ビット2はUIO-3です。
