1.19. V4L2 Media Controller関数とデータ構造¶

int v4l2_mc_create_media_graph(struct media_device *mdev)¶

グラフにメディアコントローラーのリンクを作成します。

パラメータ

struct media_device *mdev

ポインタを埋め込む media_device 構造体。

説明

PC顧客のハードウェアに見られる一般的なエンティティ間のリンクを追加します：カメラセンサー、オーディオおよびビデオPLL-IFデコーダー、チューナー、アナログTVデコーダーおよびI/Oエンティティ（ビデオ、VBIおよびSoftware Defined Radio）。

注意

ウェブカメラは非常に単純な方法でモデル化されています：センサーはI/Oエンティティに直接接続されます。スケーラーおよびクロップHWなどの詳細は隠されています。このようなマッピングは、v4l2インターフェース中心のPC消費者向けハードウェアには十分ですが、V4L2サブデバイス中心のカメラハードウェアではこのルーチンを使用すべきではありません。正しいグラフを構築できないからです。

int v4l_enable_media_source(struct video_device *vdev)¶

メディアソースを空き状態で排他使用のために保持します

パラメータ

struct video_device *vdev

ポインタ struct video_device

説明

このインターフェースは、メディアソースが使用可能かどうかを確認するため、enable_sourceハンドラーを呼び出します。enable_sourceハンドラーは、メディアソースが空き状態かどうかを確認し、ビデオデバイスに関連するメディアエンティティとの間でパイプラインを開始する責任があります。このインターフェースは、ソース設定を変更するv4l2-coreおよびdvb-coreインターフェースから呼び出す必要があります。

戻り値

成功時はゼロを、エラー時は負のエラーコードを返します。

void v4l_disable_media_source(struct video_device *vdev)¶

メディアソースを解放します

パラメータ

struct video_device *vdev

ポインタ struct video_device

説明

このインターフェースは、disable_sourceハンドラーを呼び出してメディアソースを解放します。disable_sourceハンドラーは、ビデオデバイスに関連するメディアエンティティとの間でアクティブなメディアパイプラインを停止します。

戻り値

成功時はゼロを、エラー時は負のエラーコードを返します。

int v4l2_create_fwnode_links_to_pad(struct v4l2_subdev *src_sd, struct media_pad *sink)¶

ソースサブデバイスからシンクサブデバイスのピンにフロントノードベースのリンクを作成します。

パラメータ

struct v4l2_subdev *src_sd

ソースサブデバイスへのポインタ

struct media_pad *sink

シンクサブデバイスピンへのポインタ

説明

この関数は、ソースサブデバイスから単一のシンクピンへのフロントノードエンドポイント接続を検索し、適切な接続が見つかった場合、それをそのピンへのメディアリンクに変換します。この関数は、シンクサブデバイスがv4l2-async通知サブデバイスバインドコールバック内で呼び出すことで、バインドされたソースサブデバイスからのリンクを作成できます。

注意

この関数を呼び出すすべてのシンクサブデバイスは、.get_fwnode_padメディア操作を実装する必要があります。これにより、シンクに渡されるエンドポイントがシンクに所有されていることを確認します。

成功時は0を、失敗時は負のエラーコードを返します。

int v4l2_create_fwnode_links(struct v4l2_subdev *src_sd, struct v4l2_subdev *sink_sd)¶

ソースサブデバイスからシンクサブデバイスにフロントノードベースのリンクを作成します。

パラメータ

struct v4l2_subdev *src_sd

ソースサブデバイスへのポインタ

struct v4l2_subdev *sink_sd

シンクサブデバイスへのポインタ

説明

この関数は、ソースとシンクサブデバイス間のすべてのfwnodeエンドポイント接続を検索し、メディアリンクに変換します。この関数は、シンクサブデバイスが、v4l2-async通知サブデバイスバウンドコールバック内で呼び出すことで、バウンドされたソースサブデバイスからすべてのリンクを生成するために使用されます。

注意

この関数を呼び出すすべてのシンクサブデバイスは、.get_fwnode_padメディア操作を実装する必要があります。これにより、シンクに渡されるエンドポイントがシンクに所有されていることを確認します。

成功時は0を、失敗時は負のエラーコードを返します。

int v4l2_pipeline_pm_get(struct media_entity *エンティティ)¶

パイプラインの使用カウントを増やす

パラメータ

struct media_entity *entity

パイプラインのルートエンティティ

説明

パイプライン内のすべてのエンティティの使用カウントを更新し、エンティティを電源ONにする

この関数はビデオノードオープン時に呼び出されるように設計されており、 struct media_entity.use_countを使用して電源状態を追跡します。この関数の使用は、 v4l2_pipeline_link_notify().

成功時は0を、失敗時は負のエラーコードを返します。

void v4l2_pipeline_pm_putとペアで行う必要があります(struct media_entity *エンティティ)¶

パイプラインの使用カウントを減らす

パラメータ

struct media_entity *entity

パイプラインのルートエンティティ

説明

パイプライン内のすべてのエンティティの使用カウントを更新し、エンティティを電源OFFにする

この関数はビデオノードリリース時に呼び出されるように設計されており、 struct media_entity.use_countを使用して電源状態を追跡します。この関数の使用は、 v4l2_pipeline_link_notify().

int v4l2_pipeline_link_notifyを使用します(struct media_link *リンク, u32 フラグ, unsigned int 通知)¶

リンク管理通知コールバック

パラメータ

struct media_link *link

リンク

u32 flags

適用される新しいリンクフラグ

unsigned int notification

リンクの状態変更通知タイプ（MEDIA_DEV_NOTIFY_*）

説明

電源が入ったパイプラインでのリンク管理に応じて、リンクのソースとシンク側のすべてのエンティティの使用カウントを更新し、エンティティを電源ONまたは電源OFFします。この関数の使用は、v4l2_pipeline_pm_{get,put}()とペアで行う必要があります。

成功時は0を返し、失敗時は負のエラーコードを返します。エンティティの電源をオフにする操作は失敗しないと想定されます。この関数は切断イベントでは失敗しません。
