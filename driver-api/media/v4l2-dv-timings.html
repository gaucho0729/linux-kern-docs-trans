1.17. V4L2 DVタイミング関数¶

struct v4l2_fract v4l2_calc_timeperframe(const struct v4l2_dv_timings *t)¶

v4l2_dv_timingsフィールドに基づいてtimeperframeを計算する補助関数です。

パラメータ

const struct v4l2_dv_timings *t

ビデオモードのタイミング設定。

説明

ピクセルクロック値と水平/垂直測定値を使用して予想されるtimeperframeを計算します。これはv4l2_dv_timings構造体が正しく完全に埋め込まれている必要があります。

bool v4l2_detect_cvt(unsigned frame_height, unsigned hfreq, unsigned vsync, unsigned active_width, u32 polarities, bool interlaced, struct v4l2_dv_timings *fmt)¶

指定されたタイミングがCVT標準に合致しているかを検出します。

パラメータ

unsigned frame_height

フレームの総高さ（ブランクを含む）はライン単位で指定します。

unsigned hfreq

水平周波数（Hz単位）。

unsigned vsync

垂直同期の高さ（ライン単位）。

unsigned active_width

画像の有効幅（ブランクを含まない）。これはバージョン2の減らされたブランクの場合にのみ必要です。その他の場合、このパラメータはタイミングに影響を与えません。

u32 polarities

水平および垂直の極性（v4l2_bt_timings構造体の極性と同じ）。

bool interlaced

このフラグがtrueの場合、インターレース形式を示します。

struct v4l2_dv_timings *fmt

結果のタイミング。

説明

この関数は、指定された値が有効なCVT形式に合致しているかを検出しようとします。そうであればtrueを返し、fmtに見つかったCVTタイミングを埋め込みます。

bool v4l2_detect_gtf(unsigned frame_height, unsigned hfreq, unsigned vsync, u32 polarities, bool interlaced, struct v4l2_fract aspect, struct v4l2_dv_timings *fmt)¶

指定されたタイミングがGTF標準に合致しているかを検出します。

パラメータ

u32 polarities

struct v4l2_fract aspect

推奨アスペクト比。GTFは画像高さから画像幅を導出するためのアスペクト比を決定する方法を持っていないため、明示的に渡す必要があります。通常はネイティブスクリーンのアスペクト比が使用されます。正しく埋め込まれていない場合、16:9が仮定されます。

bool can_reduce_fps(struct v4l2_bt_timings *bt)¶

FPSを減らす条件が真であるかを判定します。

パラメータ

struct v4l2_bt_timings *bt

v4l2タイミング構造体

説明

異なるタイミングでは、以下の条件が満たされている場合、FPSを減らすことが可能です：

  • CVTタイミングでは、減らしたブランクv2（vsync == 8）が真である場合。

  • CEA861タイミングでは、 V4L2_DV_FL_CAN_REDUCE_FPS フラグが真である場合。
