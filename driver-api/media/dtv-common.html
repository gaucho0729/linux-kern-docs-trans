2.1. デジタルテレビ共通機能¶

2.1.1. 数学関数¶

信号強度や信号対雑音比（dB）の推定に通常必要となる、一般的な数学関数を提供します。

unsigned int intlog2(u32 値)¶

値のlog2を計算し、結果を24ビット左にシフトします

パラメータ

u32 value

値（0でない必要があります）

説明

有理数値を使用する場合は、以下の方法を使用できます：

intlog2(value) = intlog2(value * 2^x) - x * 2^24

いくつかの使用例：

intlog2(8)は3 << 24 = 3 * 2^24となります

intlog2(9)は3 << 24 + … = 3.16… * 2^24となります

intlog2(1.5) = intlog2(3) - 2^24 = 0.584… * 2^24

戻り値

log2(value) * 2^24

unsigned int intlog10(u32 値)¶

値のlog10を計算し、結果を24ビット左にシフトします

パラメータ

u32 value

値（0でない必要があります）

説明

有理数値を使用する場合は、以下の方法を使用できます：

intlog10(value) = intlog10(value * 10^x) - x * 2^24

使用例：

intlog10(1000)は3 << 24 = 3 * 2^24となります

実装の都合上、intlog10(1000)が正確に3 * 2^24となることはありません

intlog2の類似例を参照してください

戻り値

log10(value) * 2^24

2.1.3. デジタルTV リングバッファ¶

これらのルーチンは、デジタルTVデータの処理およびユーザースペースとのデータコピーに使用されるリングバッファを実装しています。

注意

  1. パフォーマンスの観点から、読み込みおよび書き込みルーチンはバッファサイズや空き容量をチェックしません。これらのルーチンを呼び出す前に、必ずチェックを行う必要があります。例えば：

/* write @buflen: bytes */
free = dvb_ringbuffer_free(rbuf);
if (free >= buflen)
        count = dvb_ringbuffer_write(rbuf, buffer, buflen);
else
        /* do something */

/* read min. 1000, max. @bufsize: bytes */
avail = dvb_ringbuffer_avail(rbuf);
if (avail >= 1000)
        count = dvb_ringbuffer_read(rbuf, buffer, min(avail, bufsize));
else
        /* do something */

  1. 1つのリーダーと1つのライターが存在する場合、読み込みまたは書き込み操作のロックは必要ありません。2つ以上のリーダーはお互いにロックが必要です。バッファのフラッシュは読み込み操作とみなされます。バッファのリセットは読み込みと書き込みの両方の操作とみなされます。2つ以上のライターはお互いにロックが必要です。

VB2ステートマシンを制御するステート

定数

DVB_VB2_STATE_NONE

VB2エンジンが初期化されていない、初期化失敗、またはVB2が解放された状態。

DVB_VB2_STATE_INIT

VB2エンジンが初期化されました。

DVB_VB2_STATE_REQBUFS

バッファが要求されました

DVB_VB2_STATE_STREAMON

VB2がストリーミング中です。呼び出し元は直接確認すべきではありません。代わりに dvb_vb2_is_streaming().

説明

struct dvb_vb2_ctx¶

VB2ハンドラの制御構造体

定義

struct dvb_vb2_ctx {
  struct vb2_queue        vb_q;
  struct mutex            mutex;
  spinlock_t slock;
  struct list_head        dvb_q;
  struct dvb_buffer       *buf;
  int offset;
  int remain;
  int state;
  int buf_siz;

};

メンバ

vb_q

ポインタ struct vb2_queue videobuf2キューと関連付けられています。

mutex

vb2操作をシリアル化するミューテックス。vb2コアによって使用されます wait_prepare および wait_finish 操作に置き換えられています。

slock

バッファがまだ埋まっていない状態を保護するスピンロック。dvb_vb2.cで使用されます。

dvb_q

まだ埋まっていないバッファのリスト。

buf

現在埋められているバッファへのポインタ。

offset

が次の位置へのインデックス buf が埋められる

remain

が埋められるバイト数 buf.

state

が定義するバッファステートのビットマスク enum dvb_vb2_states.

buf_siz

各VB2バッファのサイズ

buf_cnt

VB2バッファの数

nonblocking

ゼロでない場合、デバイスがノンブロッキングモードで動作しています。

flags

が定義するバッファフラグ enum dmx_buffer_flagsのみに設定されます。 DMX_DQBUF. DMX_QBUF このフィールドをゼロにしてください。

count

埋められたバッファの単調カウンター。データストリームのロスを特定するのに役立ちます。のみに設定されます。 DMX_DQBUF. DMX_QBUF このフィールドをゼロにしてください。

name

デバイスタイプの名前。現在は「dvr」または「demux_filter」のいずれかです。
