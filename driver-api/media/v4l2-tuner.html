1.25. チューナー関数とデータ構造¶

enum tuner_mode¶

ティーナーのモード

定数

T_RADIO

ティーナーコアはラジオモードで動作します

T_ANALOG_TV

ティーナーコアはアナログTVモードで動作します

説明

古いボードは単一のティーナーデバイスしか持っていなかったが、一部のデバイスではラジオ用の別個のティーナーが存在します。いずれにしても、ティーナーコアはティーナーチップ（複数可能）がラジオモードで使用されるか、アナログTVモードで使用されるかを把握する必要があります。ラジオモードでは、周波数の指定範囲がTVモードと異なります。このエナムは、ティーナーコアが正しいティーナー範囲で動作し、ラジオモードで異なるティーナーチップを使用するためのものです。

struct tuner_setup¶

ティーナーチップセットの設定

定義

struct tuner_setup {
  unsigned short  addr;
  unsigned int    type;
  unsigned int    mode_mask;
  void *config;
  int (*tuner_callback)(void *dev, int component, int cmd, int arg);
};

メンバ

addr

ティーナーデバイス/チップセットを制御するためのI2Cアドレス

type

TUNER_*マクロで定義されたティーナーのタイプ。それぞれのティーナーモデルには一意の識別子が必要です。

mode_mask

許可されるティーナーモードのマスク：V4L2_TUNER_RADIO、V4L2_TUNER_ANALOG_TVおよび/またはV4L2_TUNER_DIGITAL_TV。ティーナーがラジオ、アナログTVおよび/またはデジタルTVをサポートするかどうかを記述します。

config

複雑なティーナーにティーナー固有の設定を送信するために使用します。非常に少数のティーナーのみが必要であり、新しいティーナーでの使用は避けるべきです。

tuner_callback

一部のティーナーはブリッジドライバーにコールバックする必要があります。たとえば、ブリッジチップセットでGPIOを上げるなどのタスクを行うためです。

説明

古いボードは単一のティーナーデバイスしか持っていなかったが、現在では1つのボードに複数のティーナーデバイスが存在する場合があります。TUNER_SET_TYPE_ADDRを使用してtuner_setup構造体を渡すことで、各ティーナーデバイスを順に設定できます。

複数のデバイスが存在するため、単一のI2Cデバイスにコマンドを送るだけでは不十分です。代わりに、すべてのI2Cデバイスにブロードキャストでコマンドを送る必要があります。

mode_maskを正しく設定することで、特定のティーナーデバイスが受け入れるコマンドを選択できます。たとえば、デバイスがラジオ専用ティーナーの場合、mode_maskをT_RADIOに設定します。その特定のティーナーは、ティーナーがラジオモードにあるときにのみコマンドを受けるようになり、TVモードに設定されているときに無視します。

enum param_type¶

ティーナーパラメータのタイプ

定数

TUNER_PARAM_TYPE_RADIO

ティーナーパラメータはFMおよび/またはAMラジオ用です

TUNER_PARAM_TYPE_PAL

ティーナーパラメータはPALカラーテレビ標準用です

TUNER_PARAM_TYPE_SECAM

ティーナーパラメータはSECAMカラーテレビ標準用です

TUNER_PARAM_TYPE_NTSC

ティーナーパラメータはNTSCカラーテレビ標準用です

TUNER_PARAM_TYPE_DIGITAL

ティーナーパラメータはデジタルTV用です

struct tuner_range¶

ティーナーがサポートする周波数範囲を定義します

定義

struct tuner_range {
  unsigned short limit;
  unsigned char config;
  unsigned char cb;
};

メンバ

limit

この範囲でサポートされる最大周波数（TVの場合62.5kHz、ラジオの場合62.5Hz）を表します。V4L2_TUNER_CAP_LOWで定義されています。

config

このモードを設定するために使用するバンドスイッチバイト（BB）の値

cb

このモードを設定するためにCBバイトの値。

説明

xc3028/xc4000/xc5000などのデジタルチューナーは、ドライバ内に定義されているため、これらの範囲を使用しません。これは「Philips方式」に互換性のあるアナログチューナーで使用され、そのデバイスでは4バイトでチューナーを設定します。

  1. ディバイダーバイト1 (DB1)

  2. ディバイダーバイト2 (DB2)

  3. コントロールバイト (CB)

  4. バンドスイッチバイト (BB)

一部のチューナーでは、追加のオプションのアシスタントバイト (AB) もあります。

struct tuner_params¶

チューナーを設定するために使用するパラメータ。これらはdrivers/media/tuners/tuner-types.cでチューナーのプロパティを指定するために使用されます。ほとんどのパラメータは、tda9887 IF-PLL多標準アナログTV/Radioデモデューラーを基にした古いアナログチューナーで使用されます。

定義

struct tuner_params {
  enum param_type type;
  unsigned int cb_first_if_lower_freq:1;
  unsigned int has_tda9887:1;
  unsigned int port1_fm_high_sensitivity:1;
  unsigned int port2_fm_high_sensitivity:1;
  unsigned int fm_gain_normal:1;
  unsigned int intercarrier_mode:1;
  unsigned int port1_active:1;
  unsigned int port2_active:1;
  unsigned int port1_invert_for_secam_lc:1;
  unsigned int port2_invert_for_secam_lc:1;
  unsigned int port1_set_for_fm_mono:1;
  unsigned int default_pll_gating_18:1;
  unsigned int radio_if:2;
  signed int default_top_low:5;
  signed int default_top_mid:5;
  signed int default_top_high:5;
  signed int default_top_secam_low:5;
  signed int default_top_secam_mid:5;
  signed int default_top_secam_high:5;
  u16 iffreq;
  unsigned int count;
  struct tuner_range *ranges;
};

メンバ

type

チューナーパラメータのタイプで、 enum param_typeで定義されています。チューナーが複数の標準をサポートする場合、1つの標準ごとに1行ずつ使用する配列を使用する必要があります。

cb_first_if_lower_freq

多くのPhilipsベースのチューナーでは、データシートに「バンドスイッチングを伴うチャンネル選択で、目的のチャンネルへのスムーズなチューニングを確保し、不要なチャージポンプ動作を防ぐために、望ましいチャンネル周波数と現在のチャンネル周波数の差を考慮することが推奨されます。不要なチャージポンプ動作は、非常に低いチューニング電圧を引き起こし、オシレーターを極端な状態にすることがあります」というコメントがあります。このチェックが必要なチューナーではcb_first_if_lower_freqを1に設定してください。私はPALでこのチェックをテストしました。まずTV周波数を203MHzに設定し、その後96.6MHz FMラジオに切り替えました。結果として静電気の影響で静止画が表示されるようになりましたが、コントロールバイトを最初に送信したことで問題が解消しました。

has_tda9887

このチューナーがtda9887を使用する場合、1に設定します

port1_fm_high_sensitivity

多くのPhilipsチューナーではtda9887 PORT1を使用してFMラジオの感度を選択します。この設定が1の場合、PORT1を1に設定して適切なFM受信を確保してください。

port2_fm_high_sensitivity

一部のPhilipsチューナーではtda9887 PORT2を使用してFMラジオの感度を選択します。この設定が1の場合、PORT2を1に設定して適切なFM受信を確保してください。

fm_gain_normal

一部のPhilipsチューナーではtda9887 cGainNormalを使用してFMラジオの感度を選択します。この設定が1の場合、レジスタはcGainLowではなくcGainNormalを使用します。

intercarrier_mode

tda9887を使用するほとんどのチューナーではQSSモードを使用します。一部の（安価な）チューナーではIntercarrierモードを使用します。この設定が1の場合、チューナーはIntercarrierモードに設定する必要があります。

port1_active

この設定はPORT1のデフォルト値を設定します。0は非活性、1は活性を意味します。注意：tda9887に実際に書き込まれるビット値は反転しています。したがって、ここでの0はB6ビットの1を意味します。

port2_active

この設定はPORT2のデフォルト値を設定します。0は非活性、1は活性を表します。注意: tda9887に実際に書き込まれるビット値は反転しています。ここでの0はB7ビットでの1を意味します。

port1_invert_for_secam_lc

SECAM-L’標準が選択された場合、PORT1が時折反転することがあります。必要に応じてこのビットを1に設定してください。

port2_invert_for_secam_lc

SECAM-L’標準が選択された場合、PORT2が時どき反転することがあります。必要に応じてこのビットを1に設定してください。

port1_set_for_fm_mono

一部のカードでは、モノラルラジオFMにはPORT1を1に、ステレオには0に設定する必要があります。

default_pll_gating_18

18%（またはデータシートに記載の0%）のL標準PLLゲートインを指定します。ドライバーのデフォルトは36%です。

radio_if

ラジオモードで使用するIF（中間周波数）。別個のラジオIFフィルタを持つチューナーは10.7を使用し、そうでない場合はPAL/SECAMチューナーでは33.3、NTSCチューナーでは41.3を使用します。0=10.7、1=33.3、2=41.3

default_top_low

低域帯のtda9887 TOP値のデフォルト（dB）。デフォルトは0。範囲: -16:+15

default_top_mid

中域帯のtda9887 TOP値のデフォルト（dB）。デフォルトは0。範囲: -16:+15

default_top_high

高域帯のtda9887 TOP値のデフォルト（dB）。デフォルトは0。範囲: -16:+15

default_top_secam_low

SECAM-L/L’の低域帯のtda9887 TOP値のデフォルト（dB）。デフォルトは0。複数のチューナーではSECAM-L/L’標準用に異なるTOP値が必要な場合があります。範囲: -16:+15

default_top_secam_mid

SECAM-L/L’の中域帯のtda9887 TOP値のデフォルト（dB）。デフォルトは0。複数のチューナーではSECAM-L/L’標準用に異なるTOP値が必要な場合があります。範囲: -16:+15

default_top_secam_high

SECAM-L/L’の高域帯のtda9887 TOP値のデフォルト（dB）。デフォルトは0。複数のチューナーではSECAM-L/L’標準用に異なるTOP値が必要な場合があります。範囲: -16:+15

iffreq

デジタルモードでチューナーが使用する中間周波数（IF）。

count

範囲配列のサイズ。

ranges

チューナーがサポートする周波数範囲を示す配列。

struct tunertype¶

既知のチューナーの説明。

定義

struct tunertype {
  char *name;
  unsigned int count;
  struct tuner_params *params;
  u16 min;
  u16 max;
  u32 stepsize;
  u8 *initdata;
  u8 *sleepdata;
};

メンバ

name

チューナーの名前を示す文字列。

count

、バイト単位 struct tuner_params 配列を表しています。

params

ポインタ struct tuner_params 配列を表しています。

min

最小チューナー周波数（62.5kHz単位）。MHzに変換するには16を乗算してください。

max

最小チューナー周波数（62.5kHz単位）。MHzに変換するには16を乗算してください。

stepsize

周波数ステップ（Hz単位）。

initdata

チューナーの初期化に使用するオプションのバイト配列。

sleepdata

チューナーを電源オフにするためのオプションのバイト配列。
