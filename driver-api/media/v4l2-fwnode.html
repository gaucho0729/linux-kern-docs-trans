int v4l2_fwnode_endpoint_parse(struct fwnode_handle *fwnode, struct v4l2_fwnode_endpoint *VEP)¶

すべてのfwnodeノードプロパティを解析

パラメータ

struct fwnode_handle *fwnode

エンドポイントのfwnodeハンドルへのポインタ

struct v4l2_fwnode_endpoint *vep

V4L2 fwnodeデータ構造へのポインタ

説明

この関数は、ファームウェアからV4L2 fwnodeエンドポイント固有のパラメータを解析します。呼び出し元は、 vep.bus_type 有効なメディアバスタイプに割り当てます。呼び出し元は、エンドポイントのデフォルト構成を設定することもできます—これはDTバインディングドキュメンテーションに準拠する必要があります。デバイスが複数のバスタイプをサポートする場合、呼び出し元は正しいタイプが見つかったときにこの関数を呼び出すことができます—そのタイプに有効なデフォルト構成を持つ場合です。

また、 vep.bus_type V4L2_MBUS_UNKNOWNに設定することもできます。この機能を使用するには、DTバインディングに「bus-type」プロパティが必要です。古いドライバでは、 vep.bus_type CSI-2 D-PHY、パラレル、BT.656バス間の推測はサポートされています。推測に依存しないでください vep.bus_type 新しいドライバでは！

callerは、すべてのフィールドを初期化する必要があります。 VEP明示的に値を指定するか、ゼロに設定するかのいずれかで。

関数が失敗した場合、V4L2 fwnodeエンドポイントの状態は変更されません。

注意

この関数は、変動するサイズのプロパティを解析できません（低固定限界を設けない場合）。新しいドライバーでは、 v4l2_fwnode_endpoint_alloc_parse() を使用してください。

戻り値

0 成功時は0、失敗時は負のエラーコードを返します:

-ENOMEM メモリ割当失敗時 -EINVAL パース失敗時 -ENXIO バスタイプの不一致時

parse_endpoint_func parse_endpoint

ドライバのコールバック関数で、各V4L2 fwnodeエンドポイントで呼び出されます。オプションです。

説明

のfwnodeエンドポイントを解析し、 dev 通知者にアシンクロナスサブデバイスリストを埋め込みます。 parse_endpoint コールバック関数は各エンドポイントに対して対応するアシンクロナスサブデバイスポインタを渡して、呼び出し元がアシンクロナスサブデバイス構造体のドライバ固有部分を初期化できるようにします。

この関数を通知者に呼び出す前に、通知者のメモリをゼロに初期化する必要があります。

この関数は登録済みの通知者に対して呼び出すことはできませんし、通知者に対しては一度だけ呼び出すことができます。

以下の struct v4l2_fwnode_endpoint コールバック関数に渡されます parse_endpoint 関数が完了した時点で解放されます。その設定を保持する必要がある場合は、ユーザーがメモリを確保する必要があります。

この関数を使用して埋め込まれたNotifierは、 v4l2_async_notifier_cleanup() 登録解除され、非同期サブデバイスがもはや使用されていない後、呼び出さなければならないです。関数がエラーを返した場合でも同様です。

0 成功した場合、非同期サブデバイスが見つからない場合も含みます

-ENOMEM メモリの割当が失敗した場合 -EINVAL グラフまたはエンドポイントのパースが失敗した場合。その他のエラー コードは parse_endpoint

デバイス ノード内のポートのV4L2 fwnodeエンドポイントを解析します

パラメータ

struct device *dev

解析するエンドポイントを持つデバイス

struct v4l2_async_notifier *notifier

通知者（notifier） dev

size_t asd_struct_size

ドライバの非同期サブデバイス構造体のサイズ、sizeof(を含むstruct v4l2_async_subdev）。この struct v4l2_async_subdev ドライバの非同期サブデバイス構造体の最初のメンバとなる必要があります。つまり、同じメモリアドレスから始まるのです。

unsigned int port

エンドポイントを解析するポート番号

parse_endpoint_func parse_endpoint

ドライバのコールバック関数で、各V4L2 fwnodeエンドポイントで呼び出されます。オプションです。

説明

この関数は、 v4l2_async_notifier_parse_fwnode_endpoints() 例外は、指定されたポート内のエンドポイントのみを解析することです。これは、シンクとソースの両方を持つデバイスで役立ちます：ソースに接続された非同期サブデバイスはすでに別のドライバーによって設定されています（キャプチャ デバイスの場合）。この場合、ドライバーはどのポートを解析するかを把握する必要があります。

のfwnodeエンドポイントを解析し、 dev 指定された port およびNotifierの非同期サブデバイス一覧を埋め込みます。この parse_endpoint コールバック関数は各エンドポイントに対して対応するアシンクロナスサブデバイスポインタを渡して、呼び出し元がアシンクロナスサブデバイス構造体のドライバ固有部分を初期化できるようにします。

Notifierが初めて呼び出される前に、Notifierのメモリはゼロに初期化される必要があります。

この関数は登録済みのNotifierに対して呼び出すことはできません。また、ポートごとに一度だけ呼び出すことができます。

以下の struct v4l2_fwnode_endpoint コールバック関数に渡されます parse_endpoint 関数が完了した時点で解放されます。その設定を保持する必要がある場合は、ユーザーがメモリを確保する必要があります。

この関数を使用して埋め込まれたNotifierは、 v4l2_async_notifier_cleanup() 登録解除され、非同期サブデバイスがもはや使用されていない後、呼び出さなければならないです。関数がエラーを返した場合でも同様です。

戻り値

0 成功した場合、非同期サブデバイスが見つからない場合も含みます

-ENOMEM メモリの割当が失敗した場合 -EINVAL グラフまたはエンドポイントのパースが失敗した場合。その他のエラー コードは parse_endpoint
