ADDRS_RADIO

テレビチューナーのアドレス。以下のI2Cアドレスを表します: 0x42, 0x43, 0x4a, 0x4b, 0x60, 0x61, 0x62, 0x63および0x64。

ADDRS_TV_WITH_DEMOD

デモッドが存在する場合、このテレビチューナーのアドレスはデモッドのアドレスを候補リストから除外します。以下のI2Cアドレスを表します: 0x60, 0x61, 0x62, 0x63および0x64。

注意

上記のすべてのI2Cアドレスは7ビット表記を使用します。

void v4l_bound_align_image(unsigned int *幅, unsigned int wmin, unsigned int wmax, unsigned int walign, unsigned int *高さ, unsigned int hmin, unsigned int hmax, unsigned int halign, unsigned int salign)¶

指定された制約に応じてビデオの寸法を調整します

パラメータ

unsigned int *width

調整が必要な幅のポインタ

unsigned int wmin

最小幅

unsigned int wmax

最大幅

unsigned int walign

幅の下位ビット

unsigned int *height

調整が必要な高さのポインタ

unsigned int hmin

最小高さ

unsigned int hmax

最大高さ。

unsigned int halign

高さの最下位ビット。

unsigned int salign

画像サイズの最下位ビット（例： 幅 * 高さ).

説明

画像をクリップして、 幅 から wmin および wmax, and 高さ から hmin および hmax、含む。

さらに、 幅 は...の倍数になります。 2^{walign}and wakes up processes waiting on the timerfd. While iterating the 高さ は...の倍数になります。 2^{halign}、全体のサイズ 幅 * 高さ は...の倍数になります。 2^{salign}.

注意

  1. クリッピング矩形は、アライメント制約に合わせて縮小または拡大されることがあります。

  2. wmax は...より小さくできません。 wmin.

  3. hmax は...より小さくできません。 hmin.

  4. アライメントは、許容範囲内に可能な画像サイズが存在しないほど高すぎない必要があります。

  5. wmin および hmin は少なくとも1である必要があります（0は使用しないでください）。

  6. For walign, halign および salign、特定のアライメントに気にしない場合は、 0、として 2^0 = 1 、1バイトアライメントはアライメントなしと同じです。

  7. 下向きにのみ調整したい場合は、初期値と同じ最大値を指定してください。
