struct video_device *vdev = video_device_alloc();

1.4.4. ビデオデバイスのクリーンアップ¶

ビデオデバイスノードが削除される必要がある場合（ドライバのアンロード中やUSBデバイスが切断された場合）、以下のコマンドで登録を解除してください：

video_unregister_device() (vdev);

これは、sysfsからデバイスノードを削除し、udevがそれらを削除するようにします。 /dev).

が同時に実行されると、かなりの可能性で video_unregister_device() これにより、新しいオープンはできません。ただし、USBデバイスの場合、一部のアプリケーションがこれらのデバイスノードをまだオープンしている可能性があります。したがって、登録解除後、ファイル操作（releaseを除く）はすべてエラーを返します。

ビデオデバイスノードの最後のユーザーが終了すると、 vdev->release() コールバックが呼び出され、そこで最終的なクリーンアップを行えます。

ビデオデバイスに関連するメディアエンティティを初期化した場合は、必ずクリーンアップしてください：

media_entity_cleanup (&vdev->entity);

これは、releaseコールバックから実行できます。
