1.20. V4L2メディアバス関数およびデータ構造¶

enum v4l2_mbus_type¶

メディアバスの種類

定数

V4L2_MBUS_UNKNOWN

未定義のバス種類、V4L2 メディアバス設定なし

V4L2_MBUS_PARALLEL

HSYNCおよびVSYNCを備えた並列インターフェース

V4L2_MBUS_BT656

埋め込まれた同期を備えた並列インターフェース。BT.1120にも使用可能

V4L2_MBUS_CSI1

MIPI CSI-1 シリアルインターフェース

V4L2_MBUS_CCP2

CCP2（コンパクトカメラポート2）

V4L2_MBUS_CSI2_DPHY

MIPI CSI-2 シリアルインターフェース、D-PHYを搭載

V4L2_MBUS_CSI2_CPHY

MIPI CSI-2 シリアルインターフェース、C-PHYを搭載

V4L2_MBUS_INVALID

無効なバス種類（最後に保持）

struct v4l2_mbus_config¶

メディアバスの設定

定義

struct v4l2_mbus_config {
  enum v4l2_mbus_type type;
  unsigned int flags;
};

メンバ

type

in: インターフェースタイプ

flags

in / out: 設定フラグ、に依存 type
