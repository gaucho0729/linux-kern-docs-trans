1.18. V4L2フラッシュ機能およびデータ構造¶

struct v4l2_flash_ctrl_data¶

フラッシュ制御の初期化データ、LEDフラッシュクラスドライバーがv4l2_flash_configで宣言した機能に基づいて埋め込まれる

定義

struct v4l2_flash_ctrl_data {
  struct v4l2_ctrl_config config;
  u32 cid;
};

メンバ

config

制御の初期化データ

cid

configフィールドが初期化された場合にv4l2フラッシュ制御IDを保持し、それ以外は0

struct v4l2_flash_ops¶

V4L2フラッシュ操作

定義

struct v4l2_flash_ops {
  int (*external_strobe_set)(struct v4l2_flash *v4l2_flash, bool enable);
  enum led_brightness (*intensity_to_led_brightness) (struct v4l2_flash *v4l2_flash, s32 intensity);
  s32 (*led_brightness_to_intensity) (struct v4l2_flash *v4l2_flash, enum led_brightness);
};

メンバ

external_strobe_set

ハードウェアピン状態のアサーションによってフラッシュのストローブを設定する

intensity_to_led_brightness

デバイス固有の方法で強度を明るさに変換する

led_brightness_to_intensity

デバイス固有の方法で明るさを強度に変換する

struct v4l2_flash_config¶

V4L2フラッシュサブデバイス初期化データ

定義

struct v4l2_flash_config {
  char dev_name[32];
  struct led_flash_setting intensity;
  u32 flash_faults;
  unsigned int has_external_strobe:1;
};

メンバ

dev_name

メディアエンティティの名前、システム内での一意

intensity

LEDの非フラッシュストローブ制約

flash_faults

LEDフラッシュクラスデバイスが報告可能なフラッシュエラーのビットマスク；対応するLED_FAULT*ビット定義はヘッダーファイル<linux/led-class-flash.h>にあります

has_external_strobe

外部ストローブ機能

struct v4l2_flash¶

フラッシュサブデバイスコンテキスト

定義

struct v4l2_flash {
  struct led_classdev_flash *fled_cdev;
  struct led_classdev *iled_cdev;
  const struct v4l2_flash_ops *ops;
  struct v4l2_subdev sd;
  struct v4l2_ctrl_handler hdl;
  struct v4l2_ctrl **ctrls;
};

メンバ

fled_cdev

このサブデバイスによって制御されるLEDフラッシュクラスデバイス

iled_cdev

LEDフラッシュクラスデバイスに関連するインジケータLEDを表すLEDクラスデバイス

ops

V4L2固有のフラッシュ操作

sd

V4L2サブデバイス

hdl

フラッシュ制御ハンドラ

ctrls

サブデバイス状態を定義する制御値のポインタ配列

struct v4l2_flash *v4l2_flash_init(struct デバイス *dev, struct fwnode_handle *fwn, struct led_classdev_flash *fled_cdev, const struct v4l2_flash_ops *ops, struct v4l2_flash_config *config)¶

V4L2フラッシュLEDサブデバイスを初期化する

パラメータ

struct device *dev

フラッシュデバイス、例えばI2Cデバイス

struct fwnode_handle *fwn

LEDのfwnode_handle、デバイスのものと同一の場合はNULLでも可

struct led_classdev_flash *fled_cdev

ラップするLEDフラッシュクラスデバイス

const struct v4l2_flash_ops *ops

V4L2フラッシュデバイス操作

struct v4l2_flash_config *config

V4L2フラッシュサブデバイスの初期化データ

説明

指定されたLEDサブシステムデバイスをラップするV4L2フラッシュサブデバイスを作成する。opsポインタはV4L2フラッシュフレームワークによって保存される。この関数が返った後はconfigやその内容への参照は保持されない。

戻り値

有効なポインタ、またはエラーが発生した場合、ERR_PTR()で返値を符号化する。IS_ERR()で確認し、PTR_ERR()で数値の返値を取得する。
