FPGA Region¶

概要¶

このドキュメントはFPGA region APIの使用方法に関する簡単な概要を説明しています。より概念的な視点からのregionの説明はDevice Tree bindingドキュメントで確認できます 1.

このAPIドキュメントの目的として、regionとはFPGAマネージャーとブリッジ（または複数のブリッジ）を再プログラミング可能なFPGA領域または全体のFPGAと関連付ける仕組みです。APIはregionの登録とプログラミングを行う方法を提供します

現在、kernel内でfpga-region.cの上層にあるレイヤーはDevice Treeサポート（of-fpga-region.c）のみです。詳しくは 1で説明されています。DTサポートレイヤーはregionを用いてFPGAをプログラミングし、その後DTを用いて列挙処理を行います。共通のregionコードは他の列挙処理方法を持つスキーマで使用されるように設計されています

fpga-regionは以下の情報を把握するように設定できます:

  • プログラミングに使用するFPGAマネージャーはどれか

  • プログラミング前後に無効化・有効化するブリッジはどれか

FPGAイメージをプログラミングするために必要な追加情報は struct fpga_image_info 以下の通り含まれます:

  • イメージをscatter-gatherバッファ、連続バッファ、またはファームウェアファイル名として参照するポインタ

  • イメージが部分再構成用かなどのフラグ

新しいFPGA regionを追加するAPI¶

  • struct fpga_region — FPGA region構造体

  • devm_fpga_region_create() — 構造体の割り当てと初期化

  • fpga_region_register() — FPGA regionの登録

  • fpga_region_unregister() — FPGA regionの登録解除

FPGA regionのprobe関数では使用するFPGAマネージャーへの参照を取得する必要があります。これは通常、regionのprobe関数内で行われます

  • fpga_mgr_get() — FPGAマネージャーへの参照取得、参照カウントの増加

  • of_fpga_mgr_get() — デバイスノードを指定してFPGAマネージャーへの参照取得、参照カウントの増加

  • fpga_mgr_put() — FPGAマネージャーの参照を解放

FPGA regionではプログラミング時に制御するブリッジを指定する必要があります。regionドライバはprobe時にbridge_list（fpga_region->bridge_list）を構築するか、プログラミング直前にget_bridges（fpga_region->get_bridges）関数でブリッジリストを生成するかを選択できます。FPGAブリッジフレームワークはリストの構築または破壊を処理するため以下のAPIを提供しています

  • fpga_bridge_get_to_list() — FPGAブリッジへの参照取得、リストに追加

  • of_fpga_bridge_get_to_list() — デバイスノードを指定してFPGAブリッジへの参照取得、リストに追加

  • fpga_bridges_put() — ブリッジリストを指定してそれらを解放

struct fpga_region¶

FPGA Region構造体

定義

struct fpga_region {
  struct device dev;
  struct mutex mutex;
  struct list_head bridge_list;
  struct fpga_manager *mgr;
  struct fpga_image_info *info;
  struct fpga_compat_id *compat_id;
  void *priv;
  int (*get_bridges)(struct fpga_region *region);
};

FPGA Regionデバイス

mutex

bridge_list

mgr

FPGAマネージャー

info

FPGAイメージ情報

compat_id

互換性チェック用のFPGAリージョンID

priv

パラメータ

struct device *dev

デバイス親

struct fpga_manager *mgr

このリージョンをプログラミングするマネージャー

int (*get_bridges)(struct fpga_region *)

ブリッジをリストに追加するオプション関数

説明

この関数は、FPGAリージョンドライバのprobe関数で使用することを意図しています。リージョンドライバがregion structを生成した後、 devm_fpga_region_create()、それを fpga_region_register()。リージョンドライバのremove関数は、 fpga_region_unregister()。この関数で割り当てられたregion structはドライバの解除時に自動的に解放されます。probe関数が呼び出す前にエラーを返す場合も含まれます fpga_region_register()、構造体は依然としてクリーンアップされます

戻り値

struct fpga_region またはNULL

void fpga_bridges_put(struct list_head *bridge_list)¶

ブリッジを解放する

パラメータ
