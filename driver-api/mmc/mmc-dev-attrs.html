SDおよびMMC ブロックデバイス属性¶

これらの属性は、SDまたはMMCデバイスに関連付けられたブロックデバイスに定義されています。

以下の属性は読み取り/書き込み可能です。

force_ro

書き込み保護スイッチがオフでも読み取り専用アクセスを強制します。

消去サイズと推奨消去サイズに関する注意:

「erase_size」は、消去操作の最小サイズ（バイト単位）を表します。MMCの場合、「erase_size」はカードが報告する消去グループサイズです。注意点として、「erase_size」はトリムまたはセキュアトリム操作には適用されません。その場合の最小サイズは常に512バイトセクタです。SDの場合、「erase_size」はカードがブロックアドレス方式の場合512、それ以外は0です。

SD/MMCカードは、カード全体を含む任意の大きな領域を消去できます。大きな領域を消去する際、以下の3つの理由により小さなチャンクに分割して実行することが望ましい場合があります:

  1. 単一の消去コマンドは、カード上のすべてのI/O操作を待たせます。全体を消去する場合は問題ではありませんが、1つのパーティションを消去すると、同じカード上の他のパーティションのI/O操作は消去完了まで待たなければなりません。これは数分かかる可能性があります。

  2. ユーザーに消去進捗を報告するため。

  3. 消去タイムアウトが非常に長くなりすぎて実用的ではありません。消去タイムアウトには消去領域のサイズに比例してマージンが乗算されるため、大規模な領域では数分になることがあります。

「erase_size」は特にSDでは1セクタにすぎないため、効率的な単位ではありません。したがって「preferred_erase_size」は大規模な領域を消去する際の適切なチャンクサイズを提供します。

MMCの場合、「preferred_erase_size」はカードが指定する高容量消去サイズを使用します。指定がない場合はカードの容量に基づきます。

SDの場合、「preferred_erase_size」はカードが指定する割当単位サイズです。

「preferred_erase_size」はバイト単位です。

raw_rpmb_size_multに関する注意:

「raw_rpmb_size_mult」は128KBブロックの倍数です。

RPMBのサイズ（バイト）は以下の式で計算されます:

RPMBパーティションサイズ = 128KB × raw_rpmb_size_mult
