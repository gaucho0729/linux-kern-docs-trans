IDT Tsi721 PCI Express-to-SRIOブリッジ用のRapidIOサブシステムmportドライバ¶

1. 概要¶

このドライバーは現在定義されているすべてのRapidIO mportコールバック関数を実装しています。メンテナンス読み込みおよび書き込み操作、インバウンドおよびアウトバウンドRapidIOドアベル、インバウンドメンテナンスポート書き込み、RapidIOメッセージングをサポートしています。

SRIOメンテナンストランザクションを生成するためには、このドライバーはTsi721のDMAチャネルのうちの1つを使用します。このメカニズムは、アウトバウンドウィンドウ変換の変更なしに、より広範なホップカウントおよび宛先IDへのアクセスを提供します。

RapidIOメッセージングサポートは、各メールボックスごとに専用のメッセージングチャネルを使用します。インバウンドメッセージについては、このドライバーは宛先IDマッチングを用いてメッセージを対応するメッセージキューに転送します。メッセージングコールバックはRIONETドライバー（イーサネットを基盤としたRapidIOメッセージングサービス）との完全な互換性を確保するよう実装されています。

  1. モジュールパラメータ:

  • ‘dbg_level’

    • このパラメータは、このデバイスドライバーが生成するデバッグ情報の量を制御します。このパラメータは、特定の機能ブロックに対応するビットマスクのセットで構成されます。マスクの定義については'drivers/rapidio/devices/tsi721.h'を参照してください。このパラメータは動的に変更可能です。デバッグ出力を有効にするにはCONFIG_RAPIDIO_DEBUG=yを設定してください。

  • ‘dma_desc_per_channel’

    • このパラメータは、各登録されたTsi721 DMAチャネルに割り当てられるハードウェアバッファディスクリプタの数を定義します。デフォルト値は128です。

  • ‘dma_txqueue_sz’

    • DMAトランザクションキューのサイズ。各DMAチャネルが受け入れ可能な待機中のトランザクションリクエストの数を定義します。デフォルト値は16です。

  • ‘dma_sel’

    • DMAチャネル選択マスク。ビットマスクで、どのハードウェアDMAチャネル（0 … 6）がDmaEngineコアに登録されるかを定義します。ビットが1に設定されている場合、対応するDMAチャネルが登録されます。このマスクで選択されないDMAチャネルは、このデバイスドライバーでは使用されません。デフォルト値は0x7f（すべてのチャネルを使用）です。

  • ‘pcie_mrrs’

    • PCIe Maximum Read Request Size（MRRS）のオーバーライド値。このパラメータにより、PCIe構成プロセスで設定されたMRRS値を上書きできます。Tsi721は読み込みリクエストサイズとして最大4096Bをサポートしています。このパラメータの値はPCIe仕様で定義されたものに従って設定する必要があります：0 = 128B、1 = 256B、2 = 512B、3 = 1024B、4 = 2048B、5 = 4096B。デフォルト値は‘-1’（プラットフォーム設定を保持）です。

  • ‘mbox_sel’

    • RIOメッセージングMBOX選択マスク。これは、このデバイスドライバがメッセージングMBOXを管理するかどうかを定義するビットマスクです。マスクビット0〜3はそれぞれMBOX0〜MBOX3に対応します。対応するビットが'1'に設定されている場合、MBOXはドライバの制御下にあります。デフォルト値は0x0f（=すべて）です。

2. 既知の問題¶

なし。

3. DMAエンジンのサポート¶

Tsi721 mportドライバは、ローカルシステムメモリとリモートRapidIOデバイス間のDMAデータ転送をサポートします。この機能は、一般的なLinuxカーネルDMAエンジンフレームワークで定義されたSLAVEモードAPIに従って実装されています。

システム要件に応じて、RapidIO DMA操作はCONFIG_RAPIDIO_DMA_ENGINEオプションを設定することで含めたり省いたりできます。Tsi721 miniportドライバは、8つの利用可能なBDMAチャネルから7つを使用してDMAデータ転送をサポートします。1つのBDMAチャネルはメンテナンス読み込み/書き込みリクエストの生成に予約されています。

Tsi721 mportドライバがRAPIDIO_DMA_ENGINEサポートを含んで構築されている場合、このドライバはDMA固有のモジュールパラメータを受け入れます:

「dma_desc_per_channel」

  • Tsi721の各BDMAチャネルが使用するハードウェアバッファ記述子の数を定義します（デフォルトでは128）。

  1. バージョン履歴

1.1.0

DMA操作は、ハードウェアバッファ記述子リングよりも大きなデータスキャッタ/ギャラッタリストをサポートするよう改訂されました。
