フレームバッファライブラリ¶

フレームバッファドライバーは4つのデータ構造に大きく依存しています。これらの構造体は include/linux/fb.h で宣言されており、fb_info、fb_var_screeninfo、fb_fix_screeninfo および fb_monospecs です。最後の3つはユーザー空間からも利用可能です。

fb_info は特定のビデオカードの現在の状態を定義します。fb_info 内には fb_ops 構造体が含まれており、fbdev と fbcon の動作に必要な関数をまとめたものです。fb_info はカーネルだけに見える情報です。

fb_var_screeninfo はビデオカードのユーザー定義の特徴を記述するために使用されます。fb_var_screeninfo を用いることで、ディープス（色深度）や解像度などの設定が可能です。

次の構造体は fb_fix_screeninfo です。これはモードが設定されたときに生成されるプロパティで、それ以降は変更できません。フレームバッファメモリの開始アドレスがこの構造体で「ロック」されるため、変更や移動ができないようにします。

最後の構造体は fb_monospecs です。古いAPIでは fb_monospecs はあまり重要ではありませんでしたが、800x600 のモードを固定周波数モニタに設定するなど、禁止された動作を防ぐことができます。新しいAPIでは fb_monospecs がこのような不正を防ぎ、正しく使用すればモニタが破壊されることを防げます。fb_monospecs はカーネル2.5.x以降のバージョンで初めて利用可能になります。

int fb_find_mode(struct fb_var_screeninfo *var, struct fb_info *info, const char *mode_option, const struct fb_videomode *db, unsigned int dbsize, const struct fb_videomode *default_mode, unsigned int default_bpp)¶

有効なビデオモードを検索します

パラメータ

struct fb_var_screeninfo *var

フレームバッファユーザー定義のディスプレイ部分

struct fb_info *info

フレームバッファ情報構造体

const char *mode_option

検索するビデオモード文字列

const struct fb_videomode *db

ビデオモードデータベース

unsigned int dbsize

、バイト単位 db

const struct fb_videomode *default_mode

フォールバックとして使用するデフォルトビデオモード

unsigned int default_bpp

ピクセルあたりのカラー深度（ビット）

説明

指定されたモードから開始して、適切なビデオモードを検索します mode_option フォールバックとして default_mode. default_mode 失敗した場合、ビデオモードデータベース内のすべてのモードを試します。

有効なモード指定子 mode_option:

<xres>x<yres>[M][R][-<bpp>][@<refresh>][i][p][m]

または

<name>[-<bpp>][@<refresh>]

＜xres＞、＜yres＞、＜bpp＞、＜refresh＞の十進数と＜name＞の文字列を使用します。

yresの後に‘M’が存在する場合（refresh/bppが存在する場合はそれらの前に）、関数はVESA(tm)協調ビデオタイミング（CVT）を使用してタイミングを計算します。‘R’が‘M’の後に存在する場合、フラットパネル用にブランキングを減らして計算します。‘i’または‘p’が存在する場合、インターレースまたはプログレッシブモードを計算します。‘m’が存在する場合、xresの1.8%（8ピクセルに四捨五入）とyresの1.8%のマージンを追加します。‘i’、‘p」、‘m’は‘M’および‘R’の後に必須です。例:

1024x768MR-8@60m - Reduced blank with margins at 60Hz.

失敗した場合ゼロを返し、指定された mode_optionを使用した場合1を返し、 mode_option 無視されたリフレッシュレートを使用した場合2を返し、デフォルトモードを使用した場合3を返し、任意の有効なモードにフォールバックした場合4を返します。

注意

渡されたstruct var はクリアされません！これにより、グレースケールやaccel_flagsフィールドなどの値を指定できます。
