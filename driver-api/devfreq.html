デバイス周波数スケーリング¶

はじめに¶

このフレームワークは、任意のデバイスにおけるダイナミック電圧・周波数スイッチング（DVFS）のための標準的なカーネルインターフェースを提供します。

cpufreqサブシステムと同様のsysfsファイルを通じて、周波数の調整を制御するインターフェースを公開します。

現在の使用状況を測定可能なデバイスは、ガバナによって自動的に周波数を調整できます。

API¶

デバイスドライバーは、 devfreq_profile を初期化し、 devfreq_add_device() 関数を呼び出して devfreq インスタンスを生成する必要があります。

struct devfreq_dev_status¶

devfreqユーザーデバイスからガバナに提供されるデータ。パフォーマンス統計を表します。

定義

struct devfreq_dev_status {
  unsigned long total_time;
  unsigned long busy_time;
  unsigned long current_frequency;
  void *private_data;
};

メンバ

total_time

このdevfreq_dev_statusインスタンスが表す総時間

busy_time

総時間の中でデバイスが動作していた時間

current_frequency

動作周波数

private_data

devfreqフレームワークで指定されていないエントリ。デバイスと特定のガバナは、private_dataを通じて独自のプロトコルを持つ可能性があります。ただし、ガバナ固有のため、このエントリを使用するガバナは、このエントリを認識するデバイスとのみ互換性があります。

struct devfreq_dev_profile¶

devfreqのユーザーデバイスプロファイル

定義

struct devfreq_dev_profile {
  unsigned long initial_freq;
  unsigned int polling_ms;
  enum devfreq_timer timer;
  int (*target)(struct device *dev, unsigned long *freq, u32 flags);
  int (*get_dev_status)(struct device *dev, struct devfreq_dev_status *stat);
  int (*get_cur_freq)(struct device *dev, unsigned long *freq);
  void (*exit)(struct device *dev);
  unsigned long *freq_table;
  unsigned int max_state;
};

メンバ

initial_freq

が呼ばれた際の動作周波数 devfreq_add_device() polling間隔（ms）。0の場合はpollingを無効にします。

polling_ms

タイマータイプはdeferrableまたはdelayedタイマータイプのいずれかです。

timer

デバイスはfreqまたはfreqより高い最小上界値の周波数を設定する必要があります。freqがどの動作周波数よりも大きい場合、最大値を設定します。戻る前にtarget関数は現在の周波数をfreqに設定する必要があります。「flags」パラメータの可能な値は「DEVFREQ_FLAG_*」マクロで説明されています。

target

デバイスは現在のパフォーマンスステータスをdevfreqに提供する必要があります。ガバナはこの直接使用を推奨しません。代わりに、devfreq_update_stats()とdevfreq.last_statusを組み合わせて使用することを推奨します。

get_dev_status

デバイスは現在動作している周波数を提供する必要があります。

get_cur_freq

デバイスは現在動作している周波数を提供する必要があります。

exit

devfreqがエラーまたは devfreq_remove_device() 呼び出しによりdevfreqオブジェクトを削除する際、呼び出されるオプションのコールバック。ユーザーがnotifier-headにdevfreq->nbを登録した場合、このタイミングで登録を解除する必要があります。

freq_table

統計情報およびfreq_tableを昇順で生成するオプションの周波数リスト。

max_state

freq_tableのサイズ。

struct devfreq¶

デバイスdevfreq構造体

定義

struct devfreq {
  struct list_head node;
  struct mutex lock;
  struct device dev;
  struct devfreq_dev_profile *profile;
  const struct devfreq_governor *governor;
  char governor_name[DEVFREQ_NAME_LEN];
  struct notifier_block nb;
  struct delayed_work work;
  unsigned long previous_freq;
  struct devfreq_dev_status last_status;
  void *data;
  struct dev_pm_qos_request user_min_freq_req;
  struct dev_pm_qos_request user_max_freq_req;
  unsigned long scaling_min_freq;
  unsigned long scaling_max_freq;
  bool stop_polling;
  unsigned long suspend_freq;
  unsigned long resume_freq;
  atomic_t suspend_count;
  struct devfreq_stats stats;
  struct srcu_notifier_head transition_notifier_list;
  struct notifier_block nb_min;
  struct notifier_block nb_max;
};

メンバ

node

リストノード - devfreqを登録したデバイスを含みます。

lock

devfreqへのアクセスを保護するミューテックス。

dev

devfreqクラスで登録されたデバイス。dev.parentはdevfreqを使用するデバイスです。

profile

デバイス固有のdevfreqプロファイル

governor

使用状況に基づいて周波数を選択する方法。

governor_name

このdevfreqを使用するためのdevfreq governorの名前

nb

devfreqオブジェクトに運用可能な周波数を再評価するように通知するための通知ブロック。devfreqユーザーは、devfreq.nbを用いて対応するレジスタ通知コールチェーンに登録できます。

work

負荷モニタリング用の遅延作業。

previous_freq

以前に設定された周波数値。

last_status

devfreqユーザー機器情報、パフォーマンス統計

data

ガバナのプライベートデータ。devfreqフレームワークはこのデータに触れない。

user_min_freq_req

PM QoSユーザーからの最小周波数リクエスト (sysfs経由)

user_max_freq_req

PM QoSユーザーからの最大周波数リクエスト (sysfs経由)

scaling_min_freq

OPPインターフェースからの最小周波数リクエストの制限

scaling_max_freq

OPPインターフェースからの最大周波数リクエストの制限

stop_polling

機器のdevfreqポーリング状態。

suspend_freq

スリープフェーズ中に設定された機器の周波数。

resume_freq

再起動フェーズ中に設定された機器の周波数。

suspend_count

機器のスリープリクエストカウンタ。

stats

devfreqデバイスの動作統計

transition_notifier_list

DEVFREQ_TRANSITION_NOTIFIER通知リストのリストヘッド

nb_min

DEV_PM_QOS_MIN_FREQUENCY用の通知ブロック

nb_max

DEV_PM_QOS_MAX_FREQUENCY用の通知ブロック

説明

この機器のdevfreq情報を格納する構造体。

ガバナが構造体 devfreq_governor のコールバック関数の文脈以外でエントリにアクセスする場合、 struct devfreq ガバナは構造体 mutex lock を用いてアクセスを保護する必要があります。 struct devfreqガバナはこの mutex を用いて、構造体 mutex lock 内のプライベートデータを保護できます。 void *data 同様に適用されます。

struct devfreq_simple_ondemand_data¶

void *data fed to struct devfreq and devfreq_add_device

定義

struct devfreq_simple_ondemand_data {
  unsigned int upthreshold;
  unsigned int downdifferential;
};

メンバ

upthreshold

負荷がこの値を超えると周波数がジャンプします。デフォルトを使用する場合は 0 を指定します。有効な値 = 0 〜 100。

downdifferential

負荷が upthreshold - downdifferential よりも下回ると、ガバナは周波数を下げることを検討できます。デフォルトを使用する場合は 0 を指定します。有効な値 = 0 〜 100。downdifferential < upthreshold が成り立つ必要があります。

説明

fed devfreq_simple_ondemand_data ポインタがガバナに NULL である場合、ガバナはデフォルト値を使用します。

struct devfreq_passive_data¶

void *data fed to struct devfreq and devfreq_add_device

定義

struct devfreq_passive_data {
  struct devfreq *parent;
  int (*get_target_freq)(struct devfreq *this, unsigned long *freq);
  struct devfreq *this;
  struct notifier_block nb;
};

メンバ

parent

親機器の devfreq インスタンス。

get_target_freq

オプションのコールバック。passive governor が次の周波数を決定する際に、親 devfreq デバイスの新しい周波数を使用して決定する場合に呼び出されます。passive governor 以外のガバナを使用して、次の周波数を決定するための特定のメソッドを持つ devfreq デバイスでは、このコールバックを使用する必要があります。

this

自身の機器の devfreq インスタンス。

nb

DEVFREQ_TRANSITION_NOTIFIER リスト用の通知ブロック

説明

devfreq_passive_dataは、passive governorを除く他のgovernorで親デバイスのdevfreqインスタンスを設定する必要があります。ただし、「this」および「nb」フィールドの初期化は必要ありません。devfreqコアがそれらを処理します。

struct devfreq_event_data¶

devfreq-eventデバイスのデータ

定義

struct devfreq_event_data {
  unsigned long load_count;
  unsigned long total_count;
};

メンバ

load_count

指定された期間におけるdevfreq-eventデバイスのロードカウント。

total_count

指定された期間におけるdevfreq-eventデバイスの総カウント。各カウントはクロックサイクル、時間単位（ns/us/…）、またはデバイスドライバが望む何でも表現可能です。一般的には利用率はload_count / total_countで計算されます。

説明

この構造体はポーリング期間におけるdevfreq-eventデバイスのデータを含みます。
