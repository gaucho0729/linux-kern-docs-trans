複合ドライバ用コンポーネントヘルパ¶

コンポーネントヘルパーは、ドライバーがサブデバイス（およびそれらにバインドされたドライバー）を集約ドライバーにまとめることができる機能を提供します。すでに複数のサブシステムがこのようなコンポーネントを取得するための関数を提供しています（例：of_clk_get_by_name()）。このようなサブシステム特有の方法が利用できない場合にコンポーネントヘルパーが使用されます。コンポーネントヘルパーは、サブシステムへの標準化が現実的でない特定のハードウェアの集約ドライバーのニッチを埋める役割を果たします。典型的な例は、論理デバイス（例：DRMディスプレイドライバー）がSoC内のさまざまなコンポーネント（スキャンアウトエンジン、ブレンドブロック、さまざまな出力用のトランスコードャーなど）に分散されている場合です。

コンポーネントヘルパーは、実行時依存関係（例：システムのスリープおよび再起動操作）を解決するわけではありません。参照 デバイスリンク.

コンポーネントは component_add() で登録され、 component_del()で解除されます。通常はドライバーのprobeおよびdisconnect関数から行われます。

集約ドライバーはまず、必要なコンポーネントマッチリストを component_match_add()で構築します。これはその後、 component_master_add_with_match()で集約ドライバーとして登録され、 component_master_del().
