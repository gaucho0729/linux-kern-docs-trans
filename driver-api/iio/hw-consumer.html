HW consumer¶

IIOデバイスはハードウェアで直接他のデバイスに接続できる。この場合、IIOプロバイダーとIIOコンシューマ間のバッファはハードウェアによって処理される。産業用I/O HWコンシューマは、ソフトウェアバッファを使わずにこれらのIIOデバイスを結合する方法を提供する。実装は以下の場所に存在する drivers/iio/buffer/hw-consumer.c

  • struct iio_hw_consumer — ハードウェアコンシューマ構造体

  • iio_hw_consumer_alloc() — IIOハードウェアコンシューマを割り当てます

  • iio_hw_consumer_free() — IIOハードウェアコンシューマを解放します

  • iio_hw_consumer_enable() — IIOハードウェアコンシューマを有効化します

  • iio_hw_consumer_disable() — IIOハードウェアコンシューマを無効化します

HWコンシューマ設定¶

標準的なIIOデバイスとして、実装はIIOプロバイダー/コンシューマに基づいている。典型的なIIO HWコンシューマ設定は以下のようになる

static struct iio_hw_consumer *hwc;

static const struct iio_info adc_info = {
        .read_raw = adc_read_raw,
};

static int adc_read_raw(struct iio_dev *indio_dev,
                        struct iio_chan_spec const *chan, int *val,
                        int *val2, long mask)
{
        ret = iio_hw_consumer_enable(hwc);

        /* Acquire data */

        ret = iio_hw_consumer_disable(hwc);
}

static int adc_probe(struct platform_device *pdev)
{
        hwc = devm_iio_hw_consumer_alloc(&iio->dev);
}
