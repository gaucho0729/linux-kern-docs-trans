USB Type-C コネクタ クラス¶

はじめに¶

typec クラスは、システム内の USB Type-C ポートをユーザー空間に統一的に説明するためのものであり、クラスはユーザー空間インターフェースの実装を提供する以外に何の機能も持たない設計となっています。これにより、可能な限り多くのプラットフォームで利用できるようにするための設計です。

プラットフォームは、すべての USB Type-C ポートをこのクラスに登録する必要があります。通常は USB Type-C または PD PHY ドライバーが登録を担当しますが、UCSI などのファームウェアインターフェースドライバー、USB PD コントローラーのドライバー、あるいは Thunderbolt3 コントローラーのドライバーも含まれます。このドキュメントでは、USB Type-C ポートをクラスに登録するコンポーネントを「ポートドライバー」と呼びます。

機能の表示に加え、ポートドライバーがそれらの機能をサポートできる場合、クラスはユーザー空間がポート、パートナー、ケーブルプラグの役割と代替モードを制御できるようにします。

このドキュメントで説明するポートドライバー向けに、クラスは API を提供しています。属性については Documentation/ABI/testing/sysfs-class-typec を参照してください。

ユーザー空間インターフェース¶

すべてのポートは /sys/class/typec/ の下にそれぞれ独立したデバイスとして表示されます。最初のポートは「port0」、次のポートは「port1」、というように続きます。

接続された場合、パートナーも /sys/class/typec/ の下にそれぞれ独立したデバイスとして表示されます。パートナーの親は常にそのポートに接続されているポートです。ポート「port0」に接続されたパートナーは「port0-partner」と名付けられ、デバイスのフルパスは /sys/class/typec/port0/port0-partner/ となります。

ケーブルおよびその上の2つのプラグも、オプションで /sys/class/typec/ の下にそれぞれ独立したデバイスとして表示されます。ポート「port0」に接続されたケーブルは「port0-cable」と名付けられ、SOP Prime 端（USB Power Delivery Specification 第2.4章参照）のプラグは「port0-plug0」と名付けられ、SOP Double Prime 端のプラグは「port1-plug1」と名付けられます。ケーブルの親は常にポートであり、ケーブルプラグの親は常にケーブルです。

ポート、パートナー、またはケーブルプラグがAlternate Modesをサポートする場合、すべてのサポートされているAlternate Mode SVIDには独自のデバイスが割り当てられます。注意点として、Alternate Modeデバイスはtypecクラスに接続されません。Alternate Modeの親デバイスはそのモードをサポートするデバイスであり、例えばport0-partnerのAlternate Modeは/sys/class/typec/port0-partner/以下に表示されます。すべてのサポートされているモードには、Alternate Modeデバイスの下に「mode<index>」という名前のグループが作成され、例えば/sys/class/typec/port0/<alternate mode>/mode1/のように表示されます。モードのエントラーやエクスイットのリクエストは、そのグループ内の「active」属性ファイルを通じて行います。

ケーブルの登録¶

USB Power Delivery Structured VDMをサポートするケーブルが正しく接続された後、ポートドライバーはケーブルと1つまたは2つのプラグを登録する必要があります（ケーブルにCC Double Primeコントローラーが存在するかどうかによって異なります）。SOP Prime通信をサポートするがSOP Double Prime通信をサポートしないケーブルは、1つのプラグのみを登録する必要があります。SOP通信に関する詳細情報は、最新のUSB Power Delivery仕様書の該当章を参照してください。

プラグはそれぞれ独立したデバイスとして表されます。ケーブルの登録後、プラグの登録が続きます。ケーブルはプラグの親デバイスになります。ケーブルに関する詳細はstruct typec_cable_descに、プラグに関する詳細はstruct typec_plug_descに記述します。このクラスは登録時に詳細情報をコピーします。クラスはケーブルおよびそのプラグの登録/解除に以下のAPIを提供します:

代替モード¶

USB Type-Cポート、パートナー、ケーブルプラグはAlternate Modeをサポートする場合があります。各Alternate ModeにはSVIDと呼ばれる識別子があり、これはUSB-IFが提供する標準IDまたはベンダーディバイスIDです。各サポートされるSVIDには1〜6のモードが含まれます。クラスはSVIDごとのモードを記述するstruct typec_mode_descと、すべてのサポートモードを含むstruct typec_altmode_descを提供します。

多重器/多重器解除スイッチ¶

USB Type-Cコネクタには1つまたは複数のmux/demuxスイッチが内蔵されている可能性があります。ケーブルプラグが正反対に挿すことができるため、コネクタからUSBコントローラーへ正しいデータペアをルーティングするスイッチが必要です。代替モードまたはアクセサリーモードがサポートされる場合、コネクタのピンをUSB以外のコンポーネントへルーティングするための別のスイッチも必要です。USB Type-Cコネクタクラスは、このようなスイッチを登録するためのAPIを提供します。
