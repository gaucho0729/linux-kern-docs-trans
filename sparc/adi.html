アプリケーションデータ整合性 (ADI)¶

SPARC M7 プロセッサはアプリケーションデータ整合性（ADI）機能を搭載しています。ADIは、タスクがアドレス空間の任意のサブセットにバージョンタグを設定できるようにします。ADIが有効になり、タスクのアドレス空間の範囲にバージョンタグが設定されると、プロセッサは、これらの範囲のメモリへのポインタのタグとアプリケーションが以前に設定したバージョンを比較します。ポインタのタグがアプリケーションが設定したタグと一致する場合に限り、メモリへのアクセスが許可されます。一致しない場合、プロセッサは例外を発生させます。

ADIを完全に有効にするためにタスクが実行する必要のある手順は次の通り:

  1. ユーザーモードのPSTATE.mcdeビットを設定します。これはタスク全体のアドレス空間のADIの有効/無効のマスタースイッチとなります。

  2. ADIが有効化されるアドレス範囲に対応するTLBエントリのTTE.mcdビットを設定します。MMUは、TTE.mcdビットが設定されたページのみに対してバージョンタグを確認します。

  3. stxa指令とMCD専用のASIのいずれかを使用して仮想アドレスのバージョンタグを設定します。各stxa指令は、ADIブロックサイズのバイト数分のタグを設定します。この手順は、ページ全体のタグを設定するため、ページ全体に対して繰り返す必要があります。

ADIブロックサイズは、ハイパーサーがマシン記述テーブルを通じてカーネルに提供します。ハイパーサーはまた、仮想アドレスの上位ビット数を指定してバージョンタグを指定するための情報を提供します。バージョンタグがメモリの場所に設定されると、タグは物理メモリに保存され、MMUに提示される仮想アドレスのADIバージョンタグビットに同じタグが存在する必要があります。例えばSPARC M7プロセッサでは、MMUはビット63-60を使用してバージョンタグを指定し、ADIブロックサイズはキャッシュラインサイズと同じ64バイトです。タスクがメモリの範囲にADIバージョンを10に設定した場合、そのメモリにアクセスする際には、ビット63-60に0xaを含む仮想アドレスを使用する必要があります。

ADIはmprotect()関数でPROT_ADIフラグを指定してページセットに有効化されます。タスクがADIを初めてページセットに有効化した場合、カーネルはタスクのPSTATE.mcdeビットを設定します。メモリアドレスのバージョンタグは、ASI_MCD_PRIMARYまたはASI_MCD_ST_BLKINIT_PRIMARYを使用してアドレスにstxa指令を実行して設定します。ADIブロックサイズはハイパーサーがカーネルに提供します。カーネルはADIブロックサイズを補助ベクターとともに他のADI情報とユーザー空間に返します。以下の補助ベクターがカーネルによって提供されます:

AT_ADI_BLKSZ

ADIブロックサイズ。これはADIバージョンの粒度とアライメント（バイト単位）です。

AT_ADI_NBITS

VAにおけるADIバージョンビット数

重要な注意事項¶

  • バージョンタグ値の0x0および0xfは予約されています。これらの値は仮想アドレス内の任意のタグと一致し、マッチング例外を発生させません。

  • タグは物理メモリに保存されるため、ユーザー空間から仮想アドレスに設定されます。タグは物理ページがタスクに割り当てられ、そのページにpteが作成された後に設定されます。

  • タスクが設定したバージョンタグを有するメモリページを解放すると、ページはフリーページプールに戻ります。このページが再度タスクに割り当てられた場合、カーネルはブロック初期化ASIを使用してページをクリアし、バージョンタグも同時にクリアします。タスクが解放したページが同じタスクに再割り当てされた場合、タスクがそのページに設定した古いバージョンタグは存在しなくなります。

  • 非障害的なロードではADIタグの不一致は検出されません。

  • カーネルはユーザー領域のページにタグを設定しません。タグの設定はタスクの責任です。カーネルはページがディスクにスワップアウトされ再びスワップインされた場合でも、バージョンタグを保持します。また、ページが移動した場合でもバージョンタグを保持します。

  • ADIは任意のサイズのページに対応します。ユーザー空間のタスクはADIを使用する際、ページサイズに意識する必要がありません。タスクは単に仮想アドレス範囲を選択し、mprotect()を使用して範囲にADIを有効化し、全体の範囲にバージョンタグを設定できます。mprotect()は範囲がページサイズに合わせて整列し、ページサイズの倍数であることを保証します。

  • ADIタグは書き込み可能なメモリにのみ設定できます。例えば、読み取り専用マッピングにはADIタグを設定できません。

ADI関連のトラップ¶

ADIが有効な場合、以下の新しいトラップが発生する可能性があります：

メモリ破壊の妨害¶

ストア操作がTTE.mcd=1のメモリロケーションにアクセスし、タスクがADIを有効にしている（PSTATE.mcde=1）場合、使用されたアドレスのADIタグ（ビット63:60）が対応するキャッシュラインに設定されたタグと一致しない場合、メモリ破壊トラップが発生します。デフォルトでは、これは妨害トラップであり、最初にハイパーコアに送信されます。ハイパーコアはsun4vエラーレポートを作成し、カーネルに再開可能なエラー（TT=0x7e）トラップを送信します。カーネルはこのトラップを引き起こしたタスクにSIGSEGVを送信し、以下の情報を含めます：

siginfo.si_signo = SIGSEGV;
siginfo.errno = 0;
siginfo.si_code = SEGV_ADIDERR;
siginfo.si_addr = addr; /* PC where first mismatch occurred */
siginfo.si_trapno = 0;

正確なメモリ破壊¶

ストアがTTE.mcd=1のメモリ位置にアクセスし、タスクがADIが有効になっている状態（PSTATE.mcde=1）で実行されており、使用されたアドレス（ビット63:60）のADIタグが対応するキャッシュラインに設定されたタグと一致しない場合、メモリ破壊トラップが発生します。MCD正確例外が有効になっている場合（MCDPERR=1）、TT=0x1aでカーネルに正確な例外が送信されます。カーネルはこのトラップによって発生したタスクにSIGSEGVシグナルを送信し、以下の情報を含めます:

siginfo.si_signo = SIGSEGV;
siginfo.errno = 0;
siginfo.si_code = SEGV_ADIPERR;
siginfo.si_addr = addr; /* address that caused trap */
siginfo.si_trapno = 0;
ノート:

ロード時のADIタグの不一致は常に正確なトラップを引き起こします。

MCDが無効化されている¶

タスクがADIを有効にしていない状態でメモリアドレスにADIバージョンを設定しようとすると、プロセッサはMCD無効化トラップを発生させます。このトラップはハイパーサーによって最初に処理され、ハイパーサーはこのトラップをデータアクセス例外トラップとしてカーネルに転送します（エラー種別は0xaに設定されます：無効なASI）。このような場合、カーネルはタスクにSIGSEGVシグナルを送信し、以下の情報を含めます:

siginfo.si_signo = SIGSEGV;
siginfo.errno = 0;
siginfo.si_code = SEGV_ACCADI;
siginfo.si_addr = addr; /* address that caused trap */
siginfo.si_trapno = 0;

ADIを活用するサンプルプログラム¶

以下のサンプルプログラムはADI機能の使用方法を示すために用意されています：

#include <unistd.h>
#include <stdio.h>
#include <stdlib.h>
#include <elf.h>
#include <sys/ipc.h>
#include <sys/shm.h>
#include <sys/mman.h>
#include <asm/asi.h>

#ifndef AT_ADI_BLKSZ
#define AT_ADI_BLKSZ  48
#endif
#ifndef AT_ADI_NBITS
#define AT_ADI_NBITS  49
#endif

#ifndef PROT_ADI
#define PROT_ADI      0x10
#endif

#define BUFFER_SIZE     32*1024*1024UL

main(int argc, char* argv[], char* envp[])
{
        unsigned long i, mcde, adi_blksz, adi_nbits;
        char *shmaddr, *tmp_addr, *end, *veraddr, *clraddr;
        int shmid, version;
      Elf64_auxv_t *auxv;

      adi_blksz = 0;

      while(*envp++ != NULL);
      for (auxv = (Elf64_auxv_t *)envp; auxv->a_type != AT_NULL; auxv++) {
              switch (auxv->a_type) {
              case AT_ADI_BLKSZ:
                      adi_blksz = auxv->a_un.a_val;
                      break;
              case AT_ADI_NBITS:
                      adi_nbits = auxv->a_un.a_val;
                      break;
              }
      }
      if (adi_blksz == 0) {
              fprintf(stderr, "Oops! ADI is not supported\n");
              exit(1);
      }

      printf("ADI capabilities:\n");
      printf("\tBlock size = %ld\n", adi_blksz);
      printf("\tNumber of bits = %ld\n", adi_nbits);

        if ((shmid = shmget(2, BUFFER_SIZE,
                                IPC_CREAT | SHM_R | SHM_W)) < 0) {
                perror("shmget failed");
                exit(1);
        }

        shmaddr = shmat(shmid, NULL, 0);
        if (shmaddr == (char *)-1) {
                perror("shm attach failed");
                shmctl(shmid, IPC_RMID, NULL);
                exit(1);
        }

      if (mprotect(shmaddr, BUFFER_SIZE, PROT_READ|PROT_WRITE|PROT_ADI)) {
              perror("mprotect failed");
              goto err_out;
      }

        /* Set the ADI version tag on the shm segment
         */
        version = 10;
        tmp_addr = shmaddr;
        end = shmaddr + BUFFER_SIZE;
        while (tmp_addr < end) {
                asm volatile(
                        "stxa %1, [%0]0x90\n\t"
                        :
                        : "r" (tmp_addr), "r" (version));
                tmp_addr += adi_blksz;
        }
      asm volatile("membar #Sync\n\t");

        /* Create a versioned address from the normal address by placing
       * version tag in the upper adi_nbits bits
         */
        tmp_addr = (void *) ((unsigned long)shmaddr << adi_nbits);
        tmp_addr = (void *) ((unsigned long)tmp_addr >> adi_nbits);
        veraddr = (void *) (((unsigned long)version << (64-adi_nbits))
                        | (unsigned long)tmp_addr);

        printf("Starting the writes:\n");
        for (i = 0; i < BUFFER_SIZE; i++) {
                veraddr[i] = (char)(i);
                if (!(i % (1024 * 1024)))
                        printf(".");
        }
        printf("\n");

        printf("Verifying data...");
      fflush(stdout);
        for (i = 0; i < BUFFER_SIZE; i++)
                if (veraddr[i] != (char)i)
                        printf("\nIndex %lu mismatched\n", i);
        printf("Done.\n");

        /* Disable ADI and clean up
         */
      if (mprotect(shmaddr, BUFFER_SIZE, PROT_READ|PROT_WRITE)) {
              perror("mprotect failed");
              goto err_out;
      }

        if (shmdt((const void *)shmaddr) != 0)
                perror("Detach failure");
        shmctl(shmid, IPC_RMID, NULL);

        exit(0);

err_out:
        if (shmdt((const void *)shmaddr) != 0)
                perror("Detach failure");
        shmctl(shmid, IPC_RMID, NULL);
        exit(1);
}
