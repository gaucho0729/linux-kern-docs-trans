Notifier エラー注入¶

Notifier error injectionは、指定されたnotifier chainコールバックに人工的なエラーを注入する機能を提供します。notifier call chainの失敗時のエラーハンドリングをテストするのに有用で、これはまれにしか実行されません。以下のnotifierをテストするためのカーネルモジュールがあります。

  • PM notifier

  • Memory hotplug notifier

  • powerpc pSeries reconfig notifier

  • Netdevice notifier

PM notifier error injection module¶

この機能はdebugfsインターフェースを通じて制御されます

/sys/kernel/debug/notifier-error-inject/pm/actions/<notifier event>/error

失敗させる可能性のあるPM notifierイベントは以下の通りです:

  • PM_HIBERNATION_PREPARE

  • PM_SUSPEND_PREPARE

  • PM_RESTORE_PREPARE

例: PM suspendエラーを注入 (-12 = -ENOMEM):

# cd /sys/kernel/debug/notifier-error-inject/pm/
# echo -12 > actions/PM_SUSPEND_PREPARE/error
# echo mem > /sys/power/state
bash: echo: write error: Cannot allocate memory

Memory hotplug notifier error injection module¶

この機能はdebugfsインターフェースを通じて制御されます

/sys/kernel/debug/notifier-error-inject/memory/actions/<notifier event>/error

失敗させる可能性のあるmemory notifierイベントは以下の通りです:

  • MEM_GOING_ONLINE

  • MEM_GOING_OFFLINE

例: memory hotplug offlineエラーを注入 (-12 == -ENOMEM):

# cd /sys/kernel/debug/notifier-error-inject/memory
# echo -12 > actions/MEM_GOING_OFFLINE/error
# echo offline > /sys/devices/system/memory/memoryXXX/state
bash: echo: write error: Cannot allocate memory

powerpc pSeries reconfig notifier error injection module¶

この機能はdebugfsインターフェースを通じて制御されます

/sys/kernel/debug/notifier-error-inject/pSeries-reconfig/actions/<notifier event>/error

失敗させる可能性のあるpSeries reconfig notifierイベントは以下の通りです:

  • PSERIES_RECONFIG_ADD

  • PSERIES_RECONFIG_REMOVE

  • PSERIES_DRCONF_MEM_ADD

  • PSERIES_DRCONF_MEM_REMOVE

Netdevice notifier error injection module¶

この機能はdebugfsインターフェースを通じて制御されます

/sys/kernel/debug/notifier-error-inject/netdev/actions/<notifier event>/error

失敗させる可能性のあるnetdevice notifierイベントは以下の通りです:

  • NETDEV_REGISTER

  • NETDEV_CHANGEMTU

  • NETDEV_CHANGENAME

  • NETDEV_PRE_UP

  • NETDEV_PRE_TYPE_CHANGE

  • NETDEV_POST_INIT

  • NETDEV_PRECHANGEMTU

  • NETDEV_PRECHANGEUPPER

  • NETDEV_CHANGEUPPER

例: netdevice mtu変更エラーを注入 (-22 == -EINVAL):

# cd /sys/kernel/debug/notifier-error-inject/netdev
# echo -22 > actions/NETDEV_CHANGEMTU/error
# ip link set eth0 mtu 1024
RTNETLINK answers: Invalid argument

さらに詳しい使用例については¶

CPUおよびmemory notifier用にnotifier error injection機能を使用するツールがtools/testing/selftestsに含まれています。

  • tools/testing/selftests/cpu-hotplug/on-off-test.sh

  • tools/testing/selftests/memory-hotplug/on-off-test.sh

これらのスクリプトはまずオンラインとオフラインのテストを行い、その後、notifier error injectionモジュールが利用可能であればフォールトインジェクションテストを行います。
