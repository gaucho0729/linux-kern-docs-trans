カーネルドライバー i2c-ocores¶

サポートされているアダプタ:

  • Richard Herveille による OpenCores.org I2C コントローラー (データシートリンクを参照) https://opencores.org/project/i2c/overview

著者: Peter Korsgaard <peter@korsgaard.com>

説明¶

i2c-ocores は Richard Herveille による OpenCores.org I2C コントローラー IP コア用の I2C バスドライバーです。

使い方¶

i2c-ocores はプラットフォームバスを使用するため、ベースアドレスと割込み番号を持つ struct platform_device を提供する必要があります。デバイスの dev.platform_data は、struct ocores_i2c_platform_data（linux/platform_data/i2c-ocores.h を参照）にポインタを指す必要があります。この構造体はレジスタ間の距離と入力クロック速度を記述します。また、i2c_board_info のリストをアタッチする可能性もあります。このドライバーはバスの作成時にこれをバスに追加します。

例: 以下のような感じ:

static struct resource ocores_resources[] = {
      [0] = {
              .start  = MYI2C_BASEADDR,
              .end    = MYI2C_BASEADDR + 8,
              .flags  = IORESOURCE_MEM,
      },
      [1] = {
              .start  = MYI2C_IRQ,
              .end    = MYI2C_IRQ,
              .flags  = IORESOURCE_IRQ,
      },
};

/* optional board info */
struct i2c_board_info ocores_i2c_board_info[] = {
      {
              I2C_BOARD_INFO("tsc2003", 0x48),
              .platform_data = &tsc2003_platform_data,
              .irq = TSC_IRQ
      },
      {
              I2C_BOARD_INFO("adv7180", 0x42 >> 1),
              .irq = ADV_IRQ
      }
};

static struct ocores_i2c_platform_data myi2c_data = {
      .regstep        = 2,            /* two bytes between registers */
      .clock_khz      = 50000,        /* input clock of 50MHz */
      .devices        = ocores_i2c_board_info, /* optional table of devices */
      .num_devices    = ARRAY_SIZE(ocores_i2c_board_info), /* table size */
};

static struct platform_device myi2c = {
      .name                   = "ocores-i2c",
      .dev = {
              .platform_data  = &myi2c_data,
      },
      .num_resources          = ARRAY_SIZE(ocores_resources),
      .resource               = ocores_resources,
};
