i2c-parport カーネルドライバー¶

著者: Jean Delvare <jdelvare@suse.de>

これは、フィリップス、ヴェレマン、ELVなどのi2c-over-parallel-portアダプター複数機種を統合したドライバーです。このドライバーは、古い個別ドライバーの代替として設計されています:

  • i2c-philips-par

  • i2c-elv

  • i2c-velleman

  • video/i2c-parport (このドライバーとは異なり、自作テレックステキストアダプター専用のものです)

現在サポートしているデバイスは以下の通りです:

  • (type=0) フィリップスアダプター

  • (type=1) 自作テレックステキストアダプター

  • (type=2) ヴェレマン K8000アダプター

  • (type=3) ELVアダプター

  • (type=4) アナログデバイセズ ADM1032評価ボード

  • (type=5) アナログデバイセズ評価ボード: ADM1025, ADM1030, ADM1031

  • (type=6) バルコ LPT->DVI (K5800236) アダプター

  • (type=7) One For All JP1並行ポートアダプター

  • (type=8) VCT-jig

これらのデバイスは異なるピン配置設定を使用するため、ドライバーに接続しているデバイスの種類を指定する必要があります。typeモジュールパラメータを使用してください。デバイスの自動検出はできません。必要に応じて、異なるピン配置設定のサポートは簡単に追加可能です。

以前のカーネルではtype=0（フィリップス）がデフォルトでしたが、現在はtypeパラメータが指定されていない場合、ドライバーは初期化に失敗します。

SMBusアラートサポートは、アダプターの並行ポートの割込みピンにこのラインが正しく接続されている場合に利用可能です。

カスタムアダプターの構築¶

i2c-over-parallel-portアダプターを自作する場合、以下に電子回路図の例を示します（Sylvain Munaut氏の著作）:

Device                                                      PC
Side          ___________________Vdd (+)                    Side
               |    |         |
              ---  ---       ---
              | |  | |       | |
              |R|  |R|       |R|
              | |  | |       | |
              ---  ---       ---
               |    |         |
               |    |    /|   |
SCL  ----------x--------o |-----------x-------------------  pin 2
                    |    \|   |       |
                    |         |       |
                    |   |\    |       |
SDA  ----------x----x---| o---x---------------------------  pin 13
               |        |/            |
               |                      |
               |         /|           |
               ---------o |----------------x--------------  pin 3
                         \|           |    |
                                      |    |
                                     ---  ---
                                     | |  | |
                                     |R|  |R|
                                     | |  | |
                                     ---  ---
                                      |    |
                                     ###  ###
                                     GND  GND
備考:

  • これはアナログデバイセズ評価ボードで使用されている正確なピン配置と電子回路です。

  • すべてのインバーター:

      /|
-o |-
  \|

    74HC05を使用しなければなりません。オープンコレクタ出力である必要があります。

  • すべての抵抗は10kΩです。

  • 並行ポートのピン18-25をGNDに接続してください。

  • ピン4-9（D2-D7）はVDDとして使用可能です。ドライバーがそれらをハイに駆動するためです。ADM1032評価ボードはD4-D7を使用します。注意してください。並行ポートから引き出せる電流は制限されています。また、すべての接続されたラインが同じ状態で駆動される必要があります。それ以外の場合、出力バッファの短絡が発生します。したがって、i2c-parportモジュールをロードした後にI2Cアダプターを接続するという安全策が考えられます。初期化前のデータラインの状態は未知である可能性があるからです。

  • これは5Vです！

  • 明らかにSCLを読み取ることはできません（したがって標準準拠ではありません）。非常に簡単に追加可能です。SDA部分をコピーし、別の入力ピンを使用するだけで、（ELV互換ピン配置）以下になります:

    Device                                                      PC
Side          ______________________________Vdd (+)         Side
               |    |            |    |
              ---  ---          ---  ---
              | |  | |          | |  | |
              |R|  |R|          |R|  |R|
              | |  | |          | |  | |
              ---  ---          ---  ---
               |    |            |    |
               |    |      |\    |    |
SCL  ----------x--------x--| o---x------------------------  pin 15
                    |   |  |/         |
                    |   |             |
                    |   |   /|        |
                    |   ---o |-------------x--------------  pin 2
                    |       \|        |    |
                    |                 |    |
                    |                 |    |
                    |      |\         |    |
SDA  ---------------x---x--| o--------x-------------------  pin 10
                        |  |/              |
                        |                  |
                        |   /|             |
                        ---o |------------------x---------  pin 3
                            \|             |    |
                                           |    |
                                          ---  ---
                                          | |  | |
                                          |R|  |R|
                                          | |  | |
                                          ---  ---
                                           |    |
                                          ###  ###
                                          GND  GND

可能であれば、既存のアダプターと同じピン配置設定を使用してください。そうすればコードを変更することすら必要ありません。

類似（ただし異なる）ドライバー¶

このドライバーは、i2cパッケージに含まれるi2c-pportドライバーとは異なります。i2c-pportドライバーは、現代のパラレルポート機能を使用して追加の電子部品を必要としないため、便利です。ただし、他の制限があり、Linux 2.6への移植はまだ行われていません。

このドライバーは、lm_sensorsパッケージに含まれるi2c-pcf-eppドライバーとも異なります。i2c-pcf-eppドライバーは、パラレルポートを直接I2Cバスとして使用しません。代わりに、外部のI2Cバスマスターを制御するために使用されます。このドライバーもLinux 2.6への移植はまだ行われていません。

One For All JP1 パラレルポートアダプター¶

http://www.hifi-remote.com/jp1/
