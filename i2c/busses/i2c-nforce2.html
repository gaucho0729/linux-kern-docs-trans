カーネルドライバー i2c-nforce2¶

サポートされているアダプタ:

  • nForce2 MCP 10de:0064

  • nForce2 Ultra 400 MCP 10de:0084

  • nForce3 Pro150 MCP 10de:00D4

  • nForce3 250Gb MCP 10de:00E4

  • nForce4 MCP 10de:0052

  • nForce4 MCP-04 10de:0034

  • nForce MCP51 10de:0264

  • nForce MCP55 10de:0368

  • nForce MCP61 10de:03EB

  • nForce MCP65 10de:0446

  • nForce MCP67 10de:0542

  • nForce MCP73 10de:07D8

  • nForce MCP78S 10de:0752

  • nForce MCP79 10de:0AA2

データシート:

公開されていませんが、AMD-8111 SMBus 2.0 アダプターに非常に似ているようです。

著者:

  • ハンス・フリードリヒ・フォグト <hfvogt@gmx.net>,

  • Thomas Leibold <thomas@plx.com>,

  • Patrick Dreker <patrick@dreker.de>

説明¶

i2c-nforce2 は nVidia nForce2 MCP に含まれる SMBus 用のドライバーです。

あなたの lspci -v リストが以下のようなものである場合、

00:01.1 SMBus: nVidia Corporation: Unknown device 0064 (rev a2)
        Subsystem: Asustek Computer, Inc.: Unknown device 0c11
        Flags: 66Mhz, fast devsel, IRQ 5
        I/O ports at c000 [size=32]
        Capabilities: <available only to root>

このドライバーがあなたのマザーボードの SMBus をサポートしているはずです。

備考¶

nForce2 チップセット内の SMBus アダプターは、AMD-8111 南橋内の SMBus 2.0 アダプターに非常に似ているようです。ただし、私は AMD-8111 の EC インターフェースとは異なり、直接 I/O アクセスでドライバーを動作させることができました。Asus A7N8X でテストしました。Asus A7N8X の ACPI DSDT テーブルには 2 つの SMBus がリストされており、これらはこのドライバーでサポートされています。
