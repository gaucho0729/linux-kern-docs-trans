i2c-stub¶

説明¶

このモジュールは非常にシンプルな擬似I2C/SMBusドライバーです。6種類のSMBusコマンドを実装しています：Write Quick、(R/W)バイト、(R/W)バイトデータ、(R/W)ワードデータ、(R/W)I2Cブロックデータ、および(R/W)SMBusブロックデータ。

このドライバーをロードする際には、チップアドレスをモジュールパラメータとして指定する必要があります。これにより、SMBusコマンドは指定されたアドレスのみに反応します。

ハードウェアは必要なく、このモジュールに関連付けられていません。指定されたアドレスへのWrite Quickコマンドを受け付けますが、他のコマンド（指定されたアドレスにも適用されます）はメモリ内の配列から読み書きすることで応答します。また、すべてのコマンド処理時にカーネルログに大量に記録します。

バイト操作には自動インクリメントするポインタレジスタが実装されています。これにより、EEPROMなどに見られる連続バイト読み取りが可能です。

SMBusブロックコマンドのサポートはデフォルトで無効化されており、機能モジュールパラメータの対応ビット（0x03000000）を明示的に設定することで有効化する必要があります。

SMBusブロックコマンドは、SMBusブロック操作用のコマンドを設定するために書き込まれます。書き込みは部分的でも可能です。ブロック読み取りコマンドは、これまでに最大で書き込まれたバイト数を常に返します。

典型的な使用例は以下の通りです：

  1. このモジュールをロードする

  2. i2cset（i2c-toolsプロジェクトから）を使用して事前にデータをロードする

  3. ターゲットチップドライバモジュールをロードする

  4. カーネルログでその動作を観察する

i2c-toolsパッケージには、チップダンプからレジスタ値を自動的にロードできるスクリプト i2c-stub-from-dump が含まれています。

パラメータ¶

int chip_addr[10]:

エミュレートするチップのSMBusアドレス

unsigned long functionality:

機能オーバーライドで一部のコマンドを無効化できます。<linux/i2c.h> にある I2C_FUNC_* 定数を参照してください。例えば、値 0x1f0000 は only quick、byte、byte data コマンドを有効化します。

u8 bank_reg[10], u8 bank_mask[10], u8 bank_start[10], u8 bank_end[10]:

オプションのバンク設定。どのレジスタのどのビットがアクティブなバンクを指定し、バンクされたレジスタの範囲を示します。

注意事項¶

ターゲットドライバがバイトやワードを待って変化を監視している場合、スタブがロックアップする可能性があります。i2cset を使ってアンロックしてください。

十分に強制的に操作すると、printk がロギングを喪失する可能性があります。このモジュールは relayfs などのツールが望ましいです。
