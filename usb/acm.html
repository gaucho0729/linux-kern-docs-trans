1. 使い方¶

drivers/usb/class/cdc-acm.c ドライバは、Universal Serial Bus Communication Device Class Abstract Control Model (USB CDC ACM)仕様に準拠したUSBモデムおよびUSB ISDNターミナルアダプターと動作します。

多くのモデムはこの仕様に準拠しており、以下に私が知っているリストを示します：

  • 3Com OfficeConnect 56k

  • 3Com Voice FaxModem Pro

  • 3Com Sportster

  • MultiTech MultiModem 56k

  • Zoom 2986L FaxModem

  • Compaq 56k FaxModem

  • ELSA Microlink 56k

ISDN TAとして動作するものは1つ知っています：

  • 3Com USR ISDN Pro TA

一部の携帯電話もUSB経由で接続します。以下は私が確認した機種です：

  • SonyEricsson K800i

残念ながら多くのモデムやISDN TAは独自のインターフェースを使用しており、このドライバでは動作しません。購入前にACM準拠を確認してください。

モデムを使用するには以下のモジュールをロードする必要があります：

usbcore.ko
uhci-hcd.ko ohci-hcd.ko or ehci-hcd.ko
cdc-acm.ko

その後、モデムは利用可能になります。minicom、ppp、mgettyなどを使って動作確認してください。

2. 効果を確認する¶

最初のステップは /sys/kernel/debug/usb/devices を確認することです。以下のように表示される必要があります：

T:  Bus=01 Lev=00 Prnt=00 Port=00 Cnt=00 Dev#=  1 Spd=12  MxCh= 2
B:  Alloc=  0/900 us ( 0%), #Int=  0, #Iso=  0
D:  Ver= 1.00 Cls=09(hub  ) Sub=00 Prot=00 MxPS= 8 #Cfgs=  1
P:  Vendor=0000 ProdID=0000 Rev= 0.00
S:  Product=USB UHCI Root Hub
S:  SerialNumber=6800
C:* #Ifs= 1 Cfg#= 1 Atr=40 MxPwr=  0mA
I:  If#= 0 Alt= 0 #EPs= 1 Cls=09(hub  ) Sub=00 Prot=00 Driver=hub
E:  Ad=81(I) Atr=03(Int.) MxPS=   8 Ivl=255ms
T:  Bus=01 Lev=01 Prnt=01 Port=01 Cnt=01 Dev#=  2 Spd=12  MxCh= 0
D:  Ver= 1.00 Cls=02(comm.) Sub=00 Prot=00 MxPS= 8 #Cfgs=  2
P:  Vendor=04c1 ProdID=008f Rev= 2.07
S:  Manufacturer=3Com Inc.
S:  Product=3Com U.S. Robotics Pro ISDN TA
S:  SerialNumber=UFT53A49BVT7
C:  #Ifs= 1 Cfg#= 1 Atr=60 MxPwr=  0mA
I:  If#= 0 Alt= 0 #EPs= 3 Cls=ff(vend.) Sub=ff Prot=ff Driver=acm
E:  Ad=85(I) Atr=02(Bulk) MxPS=  64 Ivl=  0ms
E:  Ad=04(O) Atr=02(Bulk) MxPS=  64 Ivl=  0ms
E:  Ad=81(I) Atr=03(Int.) MxPS=  16 Ivl=128ms
C:* #Ifs= 2 Cfg#= 2 Atr=60 MxPwr=  0mA
I:  If#= 0 Alt= 0 #EPs= 1 Cls=02(comm.) Sub=02 Prot=01 Driver=acm
E:  Ad=81(I) Atr=03(Int.) MxPS=  16 Ivl=128ms
I:  If#= 1 Alt= 0 #EPs= 2 Cls=0a(data ) Sub=00 Prot=00 Driver=acm
E:  Ad=85(I) Atr=02(Bulk) MxPS=  64 Ivl=  0ms
E:  Ad=04(O) Atr=02(Bulk) MxPS=  64 Ivl=  0ms

これらの3行（およびCls= 'comm' および 'data' クラス）が存在することは重要です。これはACMデバイスを意味します。Driver=acm はacmドライバがデバイスに使用されていることを示します。Cls=ff(vend.) だけ表示される場合は、ベンダー固有のインターフェースを持つデバイスです：

D:  Ver= 1.00 Cls=02(comm.) Sub=00 Prot=00 MxPS= 8 #Cfgs=  2
I:  If#= 0 Alt= 0 #EPs= 1 Cls=02(comm.) Sub=02 Prot=01 Driver=acm
I:  If#= 1 Alt= 0 #EPs= 2 Cls=0a(data ) Sub=00 Prot=00 Driver=acm

システムログには以下のように表示されるはずです：

usb.c: USB new device connect, assigned device number 2
usb.c: kmalloc IF c7691fa0, numif 1
usb.c: kmalloc IF c7b5f3e0, numif 2
usb.c: skipped 4 class/vendor specific interface descriptors
usb.c: new device strings: Mfr=1, Product=2, SerialNumber=3
usb.c: USB device number 2 default language ID 0x409
Manufacturer: 3Com Inc.
Product: 3Com U.S. Robotics Pro ISDN TA
SerialNumber: UFT53A49BVT7
acm.c: probing config 1
acm.c: probing config 2
ttyACM0: USB ACM device
acm.c: acm_control_msg: rq: 0x22 val: 0x0 len: 0x0 result: 0
acm.c: acm_control_msg: rq: 0x20 val: 0x0 len: 0x7 result: 7
usb.c: acm driver claimed interface c7b5f3e0
usb.c: acm driver claimed interface c7b5f3f8
usb.c: acm driver claimed interface c7691fa0

すべてが正常であれば、minicomを起動してttyACMデバイスに接続し、'at'と入力してみてください。'OK'と返答すればすべて正常です。
