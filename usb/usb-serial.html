USBシリアル¶

はじめに¶

現在のUSBシリアルドライバーは、複数のUSB to serial変換機器や、ユーザー空間からシリアルインターフェースを使用してデバイスと通信するデバイスをサポートしています。

個々の製品セクションを参照してください。各デバイスに関する特定の情報が記載されています。

設定¶

現在、ドライバーは一度に最大256個のシリアルインターフェースを処理できます。

ドライバーが使用するメジャーデバイス番号は188です。ドライバーを使用するには、以下のノードを作成してください：

mknod /dev/ttyUSB0 c 188 0
mknod /dev/ttyUSB1 c 188 1
mknod /dev/ttyUSB2 c 188 2
mknod /dev/ttyUSB3 c 188 3
        .
        .
        .
mknod /dev/ttyUSB254 c 188 254
mknod /dev/ttyUSB255 c 188 255

デバイスがドライバーによって認識されると、システムログにそのデバイスがどのノードに割り当てられているかが記録されます。

HandSpring Visor、Palm USB、およびClié USBドライバー¶

このドライバーはすべてのHandSpring USB、Palm USB、およびSony Clié USBデバイスで動作します。

デバイスがホストに接続しようとするとき、ホストに対して有効なUSBデバイスとして表示されます。このとき、デバイスは正しく列挙され、ポートが割り当てられ、通信が可能になります。デバイスが取り外されたり、デバイス側で接続がキャンセルされると、ドライバーは適切にクリーンアップします。

ノート:

つまり、デバイスと通信するには、通信を試みる前にシンクボタンを押す必要があります。これは現在のpilot-xferや他のパッケージのドキュメンテーションと矛盾しますが、デバイスのハードウェアの仕様上これしか方法がありません。

デバイスが接続されたら、通常は/dev/ttyUSB1（システムに他のusb-serialデバイスが存在しない場合）の2番目のポートで通信を試してください。システムログには、HotSync転送に使用するポートが記載されています。『Generic』ポートはPPPリンクなどの他のデバイス通信にも使用できます。

一部のSony Cliéデバイスでは、/dev/ttyUSB0を使用して通信する必要があります。これはすべてのOSバージョン3.5のデバイスおよび、フラッシュアップグレードで新しいOSバージョンに更新されたほとんどのデバイスに当てはまります。正しいポートを確認するには、カーネルのシステムログを参照してください。

同期ボタンを押した後、システムログに何も表示されない場合は、まずホットリセットを行ってください。それでも解決しない場合は、コールドリセットを行ってください。一部のデバイスはUSBポートと通信する前にこの手順が必要です。

カーネルに組み込まれていないデバイスは、モジュールパラメータで指定できます。例: modprobe visor vendor=0x54c product=0x66

このドライバーのこの部分に関するウェブページとメーリングリストは以下のURLにあります: http://sourceforge.net/projects/usbvisor/

このドライバーに関する質問や問題がございましたら、Greg Kroah-Hartman氏までお問い合わせください greg@kroah.com

PocketPC PDAドライバー¶

このドライバーは、USBケーブル/クレードルを介して、Compaq iPAQ、HP Jornada、Casio EM500、およびWindows CE 3.0またはPocketPC 2002を実行する他のPDAに接続するために使用できます。ActiveSyncでサポートされているほとんどのデバイスは即座にサポートされます。それ以外のデバイスについては、製品IDとベンダーIDを指定するモジュールパラメータを使用してください。例: modprobe ipaq vendor=0x3f0 product=0x1125

このドライバーはシリアルインターフェース（通常は/dev/ttyUSB0）を提供し、ここにpppを実行してTCP/IPリンクをPDAに確立できます。これにより、ファイルの転送、バックアップ、メールのダウンロードなどが可能になります。USBを使用する最大の利点は速度です。私のiPAQへのダウンロード/アップロード速度は73から113キロバイト/秒に達します。

このドライバーはUSB接続を活用するための複数のコンポーネントのうちの1つです。詳しくは以下のURLをご覧ください http://synce.sourceforge.net ここには必要なパッケージと簡単なステップバイステップのガイドが含まれています。

接続後、PDAからftpViewやPocket OutlookなどのWin CEソフトウェア、またはLinux側のxcerdisp、synceユーティリティを使用できます。

Pocket IEを使用するには、以下のURLの指示に従ってください http://www.tekguru.co.uk/EM500/usbtonet.htm Win98で同じ動作を実現します。プロキシサーバーの部分は省略してください。LinuxはWin98とは異なりパケット転送を十分に実行できます。iPAQについては少なくとも1回の変更が必要です。自動同期を無効化するために、スタート/設定/接続メニューに移動し、「自動的に同期…」のチェックを外してください。スタート/プログラム/接続に移動し、ケーブルを接続し、「usbdial」（または新しいUSB接続に付けた名前）を選択してください。「usbdialに接続済み」と表示されるウィンドウが表示され、ステータスが接続済みと表示されれば完了です。最後にPIEを起動してブラウジングを開始してください。

動作しない場合は、usbserialとipaqモジュールをロードし、モジュールパラメータ「debug」を1に設定してシステムログを確認してください。接続前のPDAのソフトリセットも試してみてください。

あなたのPDAによっては他の機能も可能かもしれません。Wes Cilldhaire <billybobjoehenrybob@hotmail.comトシバのE570で、ブートロー�ーダー（電源ボタンを押しながらリセットボタンを押し、ブートローダー画面が表示されるまで電源ボタンを押し続けます）に起動して、ipaqドライバをロードした状態でクレードルに挿すと、/dev/ttyUSB0にターミナルを開き、「USB Reflash」ターミナルが表示され、ROMやmicroPコードのフラッシュが可能です。これでトシバの350ドルのシリアルケーブルが必要だったなんてことはもうありません!! :D 注意: この方法はまだテストされていません。自己責任でご使用ください。

Keyspan PDAシリアルアダプター¶

シングルポートDB-9シリアルアダプターで、iMac向けのPDAアダプターとして推奨されており（マックintoshカタログで販売され、透明な白/緑のdongleで販売）、比較的シンプルなデバイスです。ファームウェアはカスタムで作成されており、このドライバはXircom/Entregaのシングルポートシリアルアダプターにも対応しています。

現在の状況:

動作する項目:

  • 基本的な入出力（'cu'でテスト済み）

  • シリアルラインが追いつかない場合のブロッキングライト

  • ボーレートの変更（最大115200まで）

  • モデム制御ピンの取得/設定（TIOCM{GET,SET,BIS,BIC}）

  • ブレイク送信（ただし、持続時間は疑問のままである）

動作しない項目:

  • デバイス文字列（カーネルログで記録されるもの）には末尾にバイナリゴミが含まれる

  • デバイスIDが正しくなく、他のKeyspan製品と衝突する可能性がある

  • ボーレートの変更はTX/RXをフラッシュして、半角文字の破損を防ぐべきである

今後の大きなタスク:

  • パリティ、7対8ビット/キャラクタ、1または2停止ビット

  • ハードウェアフロー制御

  • 標準USBデスクリプタの一部が未対応: Get_Status, Set_Feature, O_NONBLOCK, select()

このドライバに関するご質問や問題がございましたら、Brian Warner 様までお問い合わせください warner@lothar.com

Cypress M8 CY4601ファミリーシリアルドライバー¶

このドライバーは主にNeil "koyama" Whelchelによって開発されました。以前の形式から改善され、動的シリアルライン設定やラインハンドリングのサポートが追加されました。ドライバーは大体安定しており、smpマシンでテストされています。(デュアルp2)

CY4601ファミリーでサポートされるチップセット:

CY7C63723, CY7C63742, CY7C63743, CY7C64013

サポートされるデバイス:

  • DeLormeのUSB Earthmate GPS (SiRF Star II lp arch)

  • Cypress HID->COM RS232アダプター

注意:

Cypress Semiconductorはhid->comデバイスと関連性を主張していません。

CY4601ファミリーのチップセットを使用するほとんどのデバイスはこのドライバーで動作します。CY4601 USBシリアル仕様に準拠している限りです。

技術的な注意点:

Earthmateは初期設定で4800 8N1で起動します…ドライバーは起動時にこの設定に初期化します。usbserialコアはtermios設定の残り部分を提供し、いくつかのカスタムtermiosを提供して出力が正しい形式でパース可能になるようにします。

デバイスはNMEAコマンドを実行することでsirfモードに移行できます:

$PSRF100,<protocol>,<baud>,<databits>,<stopbits>,<parity>*CHECKSUM
$PSRF100,0,9600,8,1,0*0C

It should then be sufficient to change the port termios to match this
to begin communicating.

私が確認した限りでは、ファームウェア2.31でオンラインに公開されているドキュメントにあるほぼすべてのsirfコマンドをサポートしています。ただし一部のメッセージIDは不明です。

hid->comアダプターは最大115200bpsのボーレートで動作します。注意してください。デバイスはライン電圧を適切に上げるのが困難または不可能です。null modem接続では問題ありませんが、アダプターをハックしてラインをハイに設定しない限り、2つのデバイスを接続しようとすると問題が発生します。

このドライバーはSMP安全です。ファイル転送に使用する際のパフォーマンスは比較的低く、改善中ですが、パッチを受け入れることに問題ありません。URBキューまたはパケットバッファがこの用途に適している可能性があります。

質問、問題、パッチ、機能リクエストなどがあれば、メールで以下よりご連絡ください:

dignome@gmail.com

(問題/パッチは代替としてusb-develに送信することもできます)

Digi AccelePortドライバー¶

このドライバーはDigi AccelePort USB 2および4デバイス、2ポート(パラレルポートを含む)および4ポートUSBシリアルコンバーターをサポートします。このドライバーはまだDigi AccelePort USB 8をサポートしていません。

このドライバーはusb-uhciドライバーでSMP環境でも動作します。uhciドライバーではSMP環境では動作しません。

ドライバーは一般的に動作していますが、まだいくつかのioctlsを実装し、最終的なテストとデバッグを行う必要があります。USB 2のパラレルポートはシリアル/パラレル変換器としてサポートされており、つまりLinuxでは別のUSBシリアルポートとして表示されます。ただし、物理的には本当にパラレルポートです。Digi Acceleport USB 8はまだサポートされていません。

汎用シリアルドライバー¶

あなたのデバイスが上記のリストにないもので、上記モデルと互換性がある場合、"汎用"インターフェースを試してみてください。このインターフェースはデバイスに送信される制御メッセージを提供せず、デバイスのフロー制御をサポートしません。あなたのデバイスには少なくとも1つのバルクインエンドポイント、または1つのバルクアウトエンドポイントが必要です。

汎用ドライバーがあなたのデバイスを認識するためには、以下の情報を提供してください：

echo <vid> <pid> >/sys/bus/usb-serial/drivers/generic/new_id

ここで<vid>と<pid>はあなたのデバイスのベンダーIDと製品IDの16進表現に置き換えてください。ドライバーがモジュールとしてコンパイルされている場合、モジュールをロードする際にも1つのIDを指定できます：

insmod usbserial vendor=0x#### product=0x####

このドライバーはNetChip USB開発ボードに接続して、カスタムドライバーを書く必要なくUSBファームウェアを開発する方法を提供するために成功裏に使用されています。
