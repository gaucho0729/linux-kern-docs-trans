USBデバイスのシステムへの接続を許可（または拒否）¶

著作権 (C) 2007 Inaky Perez-Gonzalez <inaky@linux.intel.com> Intel Corporation

この機能は、USBデバイスがシステムで使用できるかどうかを制御するためのものです。この機能により、ユーザー空間で完全に制御されたUSBデバイスのロックダウンを実装できます。

現在、USBデバイスが接続されるとすぐに設定され、インターフェースがユーザーに利用可能になります。この変更により、rootがデバイスの設定を許可しない限り、使用が不可能になります。

使い方¶

デバイスの接続を許可する:

$ echo 1 > /sys/bus/usb/devices/DEVICE/authorized

デバイスの接続を拒否する:

$ echo 0 > /sys/bus/usb/devices/DEVICE/authorized

ホストXに接続された新しいデバイスがデフォルトで拒否されるように設定する（つまりロックダウンを行う）:

$ echo 0 > /sys/bus/usb/devices/usbX/authorized_default

ロックダウンを解除する:

$ echo 1 > /sys/bus/usb/devices/usbX/authorized_default

デフォルトでは、ワイヤードUSBデバイスは接続を許可される状態であります。ワイヤレスUSBホストでは、新しい接続されたデバイスはデフォルトで拒否されます（これは認証フェーズを行う必要があるためです）。authorized_default属性に「2」を書き込むと、カーネルがデフォルトで内部USBポートに接続されたデバイスのみを許可します。

例: システムロックダウン（不完全）¶

XYZタイプのデバイスのみを接続できるようにするロックダウンを実装したいとします（たとえば、USBポートが見えるキオスクマシン）:

boot up
rc.local ->

 for host in /sys/bus/usb/devices/usb*
 do
    echo 0 > $host/authorized_default
 done

新しいUSBデバイスに対してudevにスクリプトをフックする:

if device_is_my_type $DEV
then
  echo 1 > $device_path/authorized
done

device_is_my_type()はロックダウンの本質です。クラス、タイプ、プロトコルが何かと一致するかどうかを確認するだけでも、セキュリティ検証としては最悪（または、破る意欲のある人にとっては最善）です。より安全な場合は、暗号化と証明書認証やそのような技術を使用してください。ストレージキーのようなシンプルな例としては:

function device_is_my_type()
{
  echo 1 > authorized          # temporarily authorize it
                               # FIXME: make sure none can mount it
  mount DEVICENODE /mntpoint
  sum=$(md5sum /mntpoint/.signature)
  if [ $sum = $(cat /etc/lockdown/keysum) ]
  then
       echo "We are good, connected"
       umount /mntpoint
       # Other stuff so others can use it
  else
       echo 0 > authorized
  fi
}

もちろん、これは不完全です。実際にはPKIを使った証明書検証を行うべきです。共有秘密鍵に依存しないなど、より安全な方法を取るべきです。ただし、アイデアは伝わるでしょう。デバイスギガットキットにアクセスできる誰もがデスクリプターやデバイス情報を偽造できます。信頼しないでください。どうぞ。

インターフェースの許可¶

特定のUSBインターフェースを許可または拒否するための類似アプローチがあります。これにより、USBデバイスの一部のみをブロックできます。

インターフェースを許可する:

$ echo 1 > /sys/bus/usb/devices/INTERFACE/authorized

インターフェースを拒否する:

$ echo 0 > /sys/bus/usb/devices/INTERFACE/authorized

特定のUSBバス上の新しいインターフェースのデフォルト値も変更できます。

インターフェースをデフォルトで許可する:

$ echo 1 > /sys/bus/usb/devices/usbX/interface_authorized_default

インターフェースをデフォルトで拒否する:

$ echo 0 > /sys/bus/usb/devices/usbX/interface_authorized_default

インターフェース_authorized_defaultビットのデフォルト値は1です。したがって、すべてのインターフェースがデフォルトで許可されます。

注意:

無効化されたインターフェースを再認証する場合、ドライバのプロービングを手動で実行する必要があります。これを行うには、INTERFACEを/sys/bus/usb/drivers_probeに書き込む必要があります。

複数のインターフェースが必要なドライバの場合、すべての必要なインターフェースをまず認証する必要があります。その後、ドライバのプロービングを行います。これにより、副作用を回避できます。
