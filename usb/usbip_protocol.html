USB/IPプロトコル¶

プレリミナリドラフト、誤りを含んでいる可能性があります！ 2011年6月28日

USB/IPプロトコルはサーバー/クライアントアーキテクチャを採用しています。サーバーはUSBデバイスをエクスポートし、クライアントはそれらをインポートします。エクスポートされたUSBデバイスのドライバーはクライアントマシンで動作します。

クライアントはエクスポートされたUSBデバイスの一覧を取得できます。一覧を取得するには、クライアントがサーバーに対してTCP/IP接続を開き、TCP/IP接続上にOP_REQ_DEVLISTパケットを送信します（低レベルのトランスポート層ではOP_REQ_DEVLISTパケットが1つまたは複数のパケットに分割される可能性があります）。サーバーはOP_REP_DEVLISTパケットを送信してエクスポートされたUSBデバイスの一覧を返します。最後にTCP/IP接続は閉じられます。

virtual host controller                                 usb host
     "client"                                           "server"
 (imports USB devices)                             (exports USB devices)
         |                                                 |
         |                  OP_REQ_DEVLIST                 |
         | ----------------------------------------------> |
         |                                                 |
         |                  OP_REP_DEVLIST                 |
         | <---------------------------------------------- |
         |                                                 |

クライアントがエクスポートされたUSBデバイスの一覧を知った後、そのうちの1つを使用することを決定できます。まず、クライアントはサーバーに対してTCP/IP接続を開き、OP_REQ_IMPORTパケットを送信します。サーバーはOP_REP_IMPORTで応答します。インポートが成功した場合、TCP/IP接続は保持され、クライアントとサーバー間でURBトラフィックの転送に使用されます。クライアントは2種類のパケットを送信できます：URBを送信するためのUSBIP_CMD_SUBMITと、以前に送信したURBを解除するためのUSBIP_CMD_UNLINKです。サーバーからの応答はそれぞれUSBIP_RET_SUBMITとUSBIP_RET_UNLINKです。

virtual host controller                                 usb host
     "client"                                           "server"
 (imports USB devices)                             (exports USB devices)
         |                                                 |
         |                  OP_REQ_IMPORT                  |
         | ----------------------------------------------> |
         |                                                 |
         |                  OP_REP_IMPORT                  |
         | <---------------------------------------------- |
         |                                                 |
         |                                                 |
         |            USBIP_CMD_SUBMIT(seqnum = n)         |
         | ----------------------------------------------> |
         |                                                 |
         |            USBIP_RET_SUBMIT(seqnum = n)         |
         | <---------------------------------------------- |
         |                        .                        |
         |                        :                        |
         |                                                 |
         |            USBIP_CMD_SUBMIT(seqnum = m)         |
         | ----------------------------------------------> |
         |                                                 |
         |            USBIP_CMD_SUBMIT(seqnum = m+1)       |
         | ----------------------------------------------> |
         |                                                 |
         |            USBIP_CMD_SUBMIT(seqnum = m+2)       |
         | ----------------------------------------------> |
         |                                                 |
         |            USBIP_RET_SUBMIT(seqnum = m)         |
         | <---------------------------------------------- |
         |                                                 |
         |            USBIP_CMD_SUBMIT(seqnum = m+3)       |
         | ----------------------------------------------> |
         |                                                 |
         |            USBIP_RET_SUBMIT(seqnum = m+1)       |
         | <---------------------------------------------- |
         |                                                 |
         |            USBIP_CMD_SUBMIT(seqnum = m+4)       |
         | ----------------------------------------------> |
         |                                                 |
         |            USBIP_RET_SUBMIT(seqnum = m+2)       |
         | <---------------------------------------------- |
         |                        .                        |
         |                        :                        |
         |                                                 |
         |               USBIP_CMD_UNLINK                  |
         | ----------------------------------------------> |
         |                                                 |
         |               USBIP_RET_UNLINK                  |
         | <---------------------------------------------- |
         |                                                 |
