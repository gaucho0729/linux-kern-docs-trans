mach-x3proto¶

int ilsel_enable(ilsel_source_t set)¶

ILSELセットを有効にする。

パラメータ

ilsel_source_t set

ILSELソース（include/asm-sh/ilsel.h内のilsel_source_t enumを参照）。

説明

指定された非アリアスILSELソース（<= ILSEL_KEY）を最高の割り込みレベルで有効にします。呼び出し元は、割り込みレベルが降順になるように呼び出し元を順序付けなければなりません。アリアス化されたFPGAおよび外部ボードIRQは、 ilsel_enable_fixed().

返される値は、後に無効化するために使用できるIRQ番号です。無効化には ilsel_disable().

int ilsel_enable_fixed(ilsel_source_t set, unsigned int レベル)¶

固定された割り込みレベルでILSELセットを有効にする

パラメータ

ilsel_source_t set

ILSELソース（include/asm-sh/ilsel.h内のilsel_source_t enumを参照）。

unsigned int level

割り込みレベル（1 - 15）

説明

指定されたILSELソースを固定された割り込みレベルで有効にします。レベルの確保だけでなく、特殊なILSEL#にのみ存在するアリアスソースにも必要です。

IRQ番号を返します（as ilsel_enable()).

void ilsel_disable(unsigned int irq)¶

ILSELセットを無効にする

unsigned int irq

ILSELセット値のビット位置（有効化ルーチンからの戻り値）

説明

以前に有効にしたILSELセットを無効にする。

SuperHyway¶

int superhyway_add_device(unsigned long base, struct superhyway_device *sdev, struct superhyway_bus *bus)¶

SuperHywayモジュールを追加する

パラメータ

unsigned long base

モジュールがマッピングされている物理アドレス。

struct superhyway_device *sdev

追加するSuperHywayデバイス、または新しいデバイスを割り当てるためにNULL。

struct superhyway_bus *bus

SuperHywayモジュールが存在するバス。

説明

これは新しいSuperHywayモジュールの追加を担当します。この処理により、追加されるモジュールに対して新しいstruct superhyway_deviceが設定されます。 sdev == NULLの場合、何もしません。

デバイスは最初にメモリマップの上から下へスキャンする順序で追加され、追加順序に基づいてIDが割り当てられます。手動でモジュールを追加する場合、メモリ上の位置に関係なく、すでに発見されたデバイスのIDの後にIDが割り当てられます。

superhyway_scan_bus()でさらに作業を行う必要があります。これにより、新しいモジュールが正しく検出され登録されるよう確保できます。
