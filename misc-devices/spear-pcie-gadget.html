Spear PCIe ガジェットドライバ¶

著者¶

Pratyush Anand (pratyush.anand@gmail.com)

場所¶

driver/misc/spear13xx_pcie_gadget.c

サポートされているチップ:¶

SPEAr1300 SPEAr1310

Menuconfig オプション:¶

デバイスドライバ
その他のデバイス

SPEAr13XXプラットフォーム用PCIe gadgetサポート

用途¶

このドライバはconfigfsインターフェースで読み書き可能な複数のノードを持ち、選択されたデュアルモードPCIeコントローラーをデバイスとして構成し、各種レジスタを設定して特定のデバイスタイプとして動作させるのが主な目的です。このドライバはspearのPCIeデバイス機能を表示するために使用できます。

異なるノードの説明:¶

ノードの読み取り動作:¶

リンク

ltssmステータスを表示します。

int_type

サポートされる割り込みの種類

no_of_msi

ホストがMSIを有効にしていない場合ゼロ。正の値はMSIベクターが割り当てられた数です。

vendor_id

設定されたベンダーID（16進数）を返します

device_id

設定されたデバイスID（16進数）を返します

bar0_size:

bar0のサイズ（16進数）を返します。

bar0_address

bar0がマップされたアドレス（16進数）を返します。

bar0_rw_offset

bar0_dataが値を返すためのオフセットを返します。

bar0_data

bar0_rw_offsetのデータを返します。

ノードの書き込み動作:¶

リンク

UPでリンクアップを有効、DOWNで無効にします

int_type

設定する割り込みタイプ（INTA、MSI、NO_INT）を指定します。MSIを選択する場合はno_of_msiノードを設定済みにする必要があります。

no_of_msi

必要なMSIベクター数

inta

INTAをアサートするには1を書き込み、デアサートするには0を書き込みます。

send_msi

送信するMSIベクターを書き込みます。

vendor_id

設定するベンダーID（16進数）を書き込みます

device_id

設定するデバイスID（16進数）を書き込みます

bar0_size

bar0のサイズ（16進数）を書き込みます。デフォルトのbar0サイズは1000（16進）バイトです。

bar0_address

bar0がマップされたアドレス（16進数）を書き込みます。デフォルトのbar0マッピングはSYSRAM1（E0800000）です。常にbarサイズをbarアドレスより先に設定してください。カーネルがアライメントのためにbarサイズとアドレスを変更する可能性があるため、書き込み後にbarサイズとアドレスを読み直して確認してください。

bar0_rw_offset

bar0_dataが値を書き込むためのオフセットを書き込みます。

bar0_data

bar0_rw_offsetに書き込むデータを書き込みます。

ノードのプログラミング例¶

このデバイスがPCIeホストに接続されたときにホストがこのデバイスを1MB RAMとして認識するように、すべてのPCIeレジスタを設定します。

#mount -t configfs none /Config

n番目のPCIeデバイスコントローラーの場合:

# cd /config/pcie_gadget.n/

このディレクトリ内のすべてのノードを設定しました。ベンダーIDを0x104aとして設定します:

# echo 104A >> vendor_id

デバイスIDを0xCD80として設定します:

# echo CD80 >> device_id

BAR0サイズを1MBとして設定します:

# echo 100000 >> bar0_size

設定されたBAR0サイズを確認します:

# cat bar0_size

BAR0アドレスをDDR（0x2100000）として設定します。これはPCIeホストに表示されるメモリの物理アドレスです。同様に、他のペリフェラルもPCIeホストに表示可能にできます。例えばUARTのベースアドレスをBAR0アドレスとして設定すると、このデバイスがホストに接続されるとUARTとして認識されます。

# echo 2100000 >> bar0_address

割り込みタイプをINTAとして設定します:

# echo INTA >> int_type

リンクアップを実行します:

# echo UP >> link

リンクアップが完了した後にのみホストが初期化され、ポートに接続されたPCIeデバイスを検索し始める必要があります。

/*wait till link is up*/
# cat link

接続が確立されるまで待機してください。

INTAをアサートするには:

# echo 1 >> inta

INTAをデアサートするには:

# echo 0 >> inta

MSIを割り込みとして使用する場合、必要なMSIベクターの番号をプログラムする必要があります（例：4）:

# echo 4 >> no_of_msi

MSIを割り込みタイプとして選択する:

# echo MSI >> int_type

リンクアップを実行します:

# echo UP >> link

リンクがアップになるまで待機してください。

# cat link

アプリケーションは、リンクがUPになるまでこのノードを繰り返し読み取ることができます。2つの読み取りの間にスリープできます。

MSIが有効になるまで待機してください。

# cat no_of_msi

4（要求されたMSIベクターの数）を返す必要があります。

MSIベクター2を送信するには:

# echo 2 >> send_msi
# cd -
