4. Intelligent Keyboard (ikbd) Protocol¶

4.1. はじめに¶

アタリ社の Intelligent Keyboard（ikbd）は、柔軟性があり、変更を加えずにさまざまな製品で使用できる汎用キーボード制御装置です。このキーボードはマイクロコントローラーを備えており、マウスやスイッチ式ジョイスティックの接続に便利なインターフェースを提供します。ikbd プロセッサは、1秒単位の解像度で時刻を示すクロックを維持します。ikbd は、さまざまな新しいコンピュータ製品と組み合わせるために十分に汎用的な設計となっています。キーパッドの種類やマウスの解像度など、製品ごとの変化に対応可能です。ikbd は、高速双方向シリアルインターフェースを介してメインプロセッサと通信します。キーボード、ジョイスティック、マウスのさまざまな用途に対応するため、複数のモードで動作可能です。単方向通信媒体のみが利用可能な場合でも、デフォルトモードを慎重に設計することで、制御装置の限られた使用が可能です。

4.2. キーボード¶

キーボードは常にキーボードの押下/離しスキャンコードを返します。ikbd は各キープレスおよびリリースごとにキーボードスキャンコードを生成します。キースキャンの作成（キーキャッチ）コードは1から始まり、付録Aで定義されています。たとえば、スキャンコード表にはISOキーポジションが存在する必要があります。特定のキーボードでそのポジションにキーパッドが存在しなくても。各キーブレイクコードは、作成コードに0x80を論理和することで取得します。

0xF6 から 0xFF までの特別コードは以下の用途に使用されます：

コード

コマンド

0xF6

ステータスレポート

0xF7

絶対的なマウス位置記録

0xF8-0xFB

相対的なマウス位置記録（LSBs はマウスボタン状態によって決定）

0xFC

時刻

0xFD

ジョイスティックレポート（両方のスティック）

0xFE

ジョイスティック0 イベント

0xFF

ジョイスティック1 イベント

このモードでは、シフトキーは異なるスキャンコードを返します。エンターキーとRETurnキーも区別されます。

4.3. マウス¶

マウスポートは、約200カウント（フェーズ変化または「クリック」）毎インチの解像度を持つマウスをサポートする必要があります。マウスは、10インチ毎秒の速度で正確な追跡を可能にするスキャンレートでスキャンされるべきです。ikbd は、マウスの動きを3つの異なる方法で報告できます。相対的な動き、ikbd 内で維持される座標系における絶対的な動き、またはマウスの動きをキーボードカーソル制御キーの同等物に変換する方法です。マウスボタンは、マウスの一部として扱うか、追加のキーボードキーとして扱うことができます。

4.3.1. 相対位置報告¶

相対位置モードでは、マウスイベントが発生するたびに、ikbdは相対的なマウス位置の記録を返します。マウスイベントとは、マウスボタンが押されたり離されたり、またはX軸またはY軸のいずれかで移動量が設定可能なしきい値を超えた場合を指します。しきい値に関係なく、ikbdはすべての解像度のビットをホストコンピュータに返します。注意点として、ikbdはしきい値を超えるdelta xまたはdelta yを含む相対的なマウス位置レポートを返すことがあります。これは、マウスの相対的な移動イベントが生成されないためです：(a) キーボードが「一時停止」している間（イベントはキーボード通信が再開されるまで保存されます）、(b) 任意のイベントが送信されている間です。

相対マウス位置レコードは、キーボードモードに関係なく、3バイトのレコード形式です。

%111110xy           ; mouse position record flag
                    ; where y is the right button state
                    ; and x is the left button state
X                   ; delta x as twos complement integer
Y                   ; delta y as twos complement integer

ボタン状態ビットの値は、MOUSE BUTTON ACTIONがボタンをキーボードの一部として動作させる場合でも有効です。レポートパケットが生成される前の累積移動量が+127…-128の範囲を超える場合、移動量は複数のパケットに分割されます。注意点として、報告されるdelta yの符号はYの原点を選択した結果に基づきます。

4.3.2. 絶対位置報告¶

ikbdは絶対的なマウス位置も保持できます。マウス位置のリセット、X/Yスケーリングの設定、および現在のマウス位置の照会にためのコマンドが存在します。

4.3.3. マウスカーソルキーモード¶

ikbdはマウスの移動を同等のカーソルキー入力に変換できます。各軸ごとに、キーストロークごとのマウスクリック数は独立してプログラマブルです。ikbdは最高の解像度でマウスの移動情報を内部に保持し、スケーリングファクターの倍数ごとにカーソルキーイベントを生成します。マウスの移動は、適切なカーソルキーに対応するブレイクコードを即座に生成します。マウスボタンは、最も想定されるキーボードよりも高いスキャンコードを生成します（例：LEFT=0x74 & RIGHT=0x75）。

4.4. ジョイストック¶

4.4.1. ジョイストックイベント報告¶

このモードでは、ジョイストックの位置が変化するたびに（つまり、ジョイストックのスイッチまたはトリガーの開閉ごとに）、ikbdはレコードを生成します。

ジョイストックイベントレコードは、次の形式の2バイトです：

%1111111x           ; Joystick event marker
                    ; where x is Joystick 0 or 1
%x000yyyy           ; where yyyy is the stick position
                    ; and x is the trigger

4.4.2. ジョイストック照会¶

このモードでは、'Interrogate Joystick'コマンドをikbdに送信することで、いつでもジョイストックポートの現在の状態を照会できます。

ikbdのジョイストック照会への応答は、次の形式の3バイトレポートです：

0xFD                ; joystick report header
%x000yyyy           ; Joystick 0
%x000yyyy           ; Joystick 1
                    ; where x is the trigger
                    ; and yyy is the stick position

4.4.3. ジョイストックモニタリング¶

ジョystickポートの状態をユーザー指定のレートで報告するため、キーボード通信のほぼすべての時間を割り当てるモードが利用可能です。このモードはリセットまたは他のモードに切り替えられるまで維持されます。このモードでのPAUSEコマンドは出力の停止だけでなく、ジョystickのスキャンを一時的に停止します（サンプルがキューに蓄積されません）。

4.4.4. ファイアーボタンモニタリング¶

単一の入力ビットを高速でモニタリングするためのモードが提供されています。このモードでは、ikbdがシリアル通信チャネルが許容する最大レートでジョystick1のファイアーボタンの状態をモニタリングします。データは1バイトあたり8ビットでパッキングされてホストに送信されます。ikbdはリセットまたは他のモードに切り替えられるまでこのモードを維持します。このモードでのPAUSEコマンドは出力の停止だけでなく、ボタンのスキャンを一時的に停止します（サンプルがキューに蓄積されません）。

4.4.5. ジョystickキー・コードモード¶

ikbdは、どちらかのジョystickの使用を同等のカーソル制御キーボード操作（keystroke）に変換するように指示できます。ikbdは単一のブレイクポイント速度ジョystickカーソルを提供します。ジョystickイベントは適切なカーソル移動キーのmake codeを即座に生成し、その後break codeを生成します。ジョystickのトリガーまたはファイアーボタンは、最大のキーマトリクスが想定される場合に使用されるコードよりも上の擬似キー・スキャンコードを生成します（例: JOYSTICK0=0x74, JOYSTICK1=0x75）。

4.5. タイム・オブ・デイ時計¶

ikbdはシステム用にタイム・オブ・デイ時計も保持します。時刻の設定および照会コマンドが利用可能です。時刻保持は1秒の解像度で維持されます。

4.6. ステータス照会¶

ikbdモードおよびパラメータの現在の状態は、ikbd設定コマンドに対応するステータス照会コマンドを送信することで取得できます。

4.7. 電源投入モード¶

電源投入時にキーボードコントローラーは、主なコントローラーの障害（ROMチェックサムおよびRAMテスト）や、押されたままのキー（ストッキングキー）などの簡単な自己診断を実行します。電源投入時に押されたキーはすべてストッキングキーとみなされ、そのBREAK（誤記）コードが返されます（MAKEコードが前に行われていない場合、キーボードのエラーを示すフラグになります）。コントローラーの自己診断がエラーなく完了した場合、コード0xF0が返されます。（このコードはikbdコントローラーのバージョン/リリースを示すために使用されます。ikbdの最初のリリースはバージョン0xF0で、2番目のリリースは0xF1、というように続きます。）ikbdはデフォルトで、X軸およびY軸のいずれかで1単位のしきい値を持つマウス位置報告モード、画面の上部がY=0の原点となる設定、およびジョイストick1のイベント報告モードで動作します。このとき、両方のボタンはマウスに論理的に割り当てられます。どのジョイストックコマンドも実行した後、ikbdはジョイストックがJoystick0とJoystick1の両方に接続されていると仮定します。その後、マウスコマンド（MOUSE DISABLEを除く）が実行されると、ポート0が再びマウスとしてスキャンされ、両方のボタンが論理的にマウスに接続されます。ポート0がマウスと仮定されているときにマウス無効化コマンドが受信された場合、ボタンは論理的にJoystick1に割り当てられます（マウスが他のマウスコマンドで再有効化されるまで）。

4.8. ikbd コマンドセット¶

このセクションには、ikbdに送信できるコマンドの一覧が含まれています。指定されていないコマンドコード（例：0x00）はノーアクション（NOP）として処理されます。

4.8.1. RESET¶

0x80
0x01

注：RESETコマンドはikbdが理解する唯一の2バイトコマンドです。0x80コマンドバイトの後に0x01以外のバイトが続く場合、そのバイトは無視されます（0x80も無視されます）。また、ikbdに200mS以上続くブレイクを送信することでもリセットが発生します。RESETコマンドを実行すると、キーボードはデフォルト（電源投入時）のモードおよびパラメータ設定に戻ります。これは日時時計には影響を与えません。RESETコマンドまたは機能を実行すると、ikbdは簡単な自己診断を実行します。診断が成功した場合、RESETコマンドの受信後（またはブレイクの終了、または電源投入後）300mS以内にコード0xF0を送信します。その後、ikbdはキーマトリクスをスキャンし、閉じているキー（ストッキングキー）を検出します。検出された閉じているキーはブレイクスキャンコードを生成します（MAKEコードが前に行われていない場合、キーマトリクスのエラーを示すフラグになります）。

4.8.2. マウスボタンの動作設定¶

0x07
%00000mss           ; mouse button action
                    ;       (m is presumed = 1 when in MOUSE KEYCODE mode)
                    ; mss=0xy, mouse button press or release causes mouse
                    ;  position report
                    ;  where y=1, mouse key press causes absolute report
                    ;  and x=1, mouse key release causes absolute report
                    ; mss=100, mouse buttons act like keys

このコマンドは、ikbdがマウスのボタンをどのように扱うかを設定します。デフォルトのマウスボタン動作モードは%00000000で、ボタンは論理的にマウスの一部として扱われます。ボタンがキーボードのキーのように動作する場合、LEFT=0x74 & RIGHT=0x75です。

4.8.3. SET RELATIVE MOUSE POSITION REPORTING¶

0x08

相対マウス位置報告の設定。(DEFAULT) マウス位置パケットは、ikbdが動作中に設定可能なしきい値を超えた場合に非同期で生成されます（SET MOUSE THRESHOLDを参照）。マウスキーモードによっては、マウスボタンが押されたり離されたりした際にもマウス位置レポートが生成されることがあります。それ以外の場合は、マウスボタンはキーボードのキーとして動作します。

4.8.4. SET ABSOLUTE MOUSE POSITIONING¶

0x09
XMSB                ; X maximum (in scaled mouse clicks)
XLSB
YMSB                ; Y maximum (in scaled mouse clicks)
YLSB

絶対マウス位置の維持設定。ikbdが維持するXおよびY座標をリセットします。このモードでは、内部的に維持する座標値が0と大きな正数の間で巻き戻さず、負の動きは無視されます。このコマンドはスケーリングされた座標系で達成可能な最大の正数値を設定し、その値を超える動きも無視されます。

4.8.5. SET MOUSE KEYCODE MOSE¶

0x0A
deltax              ; distance in X clicks to return (LEFT) or (RIGHT)
deltay              ; distance in Y clicks to return (UP) or (DOWN)

マウスモニタリングルーチンを設定し、RELATIVEまたはABSOLUTEの動きレコードではなくカーソルの動きキーコードを返します。マウスの移動がユーザー指定のデルタ値を超えた場合、ikbdは適切なカーソルキーコードを返します。キーボードがキースキャンコードモードの場合、マウスの動きは即座に生成コードを発生させ、その後に解除コードが続きます。注意点として、このコマンドはマウス動きの出発点に影響されません。

4.8.6. SET MOUSE THRESHOLD¶

0x0B
X                   ; x threshold in mouse ticks (positive integers)
Y                   ; y threshold in mouse ticks (positive integers)

このコマンドは、マウスイベントが生成されるしきい値を設定します。注意点として、これはホストに返されるデータの解像度には影響しません。このコマンドはRELATIVE MOUSE POSITIONINGモードでのみ有効です。RESET（または電源投入時）のデフォルト値は1です。

4.8.7. SET MOUSE SCALE¶

0x0C
X                   ; horizontal mouse ticks per internal X
Y                   ; vertical mouse ticks per internal Y

このコマンドはABSOLUTE MOUSE POSITIONINGモードのスケール係数を設定します。このモードでは、指定された数のマウスフェーズ変化（「クリック」）が発生するまで、内部的に維持する座標が1ずつ変更されます（各軸ごとに独立してスケーリングされます）。マウス位置情報は、ikbdがABSOLUTE MOUSE POSITIONINGモードで照会される場合にのみ利用可能です。ただし、ikbdがボタンの押しあたり/離しあたりを報告するように指示されている場合は除きます（SET MOUSE BUTTON ACTIONを参照）。

4.8.8. INTERROGATE MOUSE POSITION¶

0x0D
Returns:
        0xF7       ; absolute mouse position header
BUTTONS
        0000dcba   ; where a is right button down since last interrogation
                   ; b is right button up since last
                   ; c is left button down since last
                   ; d is left button up since last
        XMSB       ; X coordinate
        XLSB
        YMSB       ; Y coordinate
        YLSB

INTERROGATE MOUSE POSITIONコマンドは、ABSOLUTE MOUSE POSITIONINGモードで有効です。マウスボタン動作の設定に関係なく有効です。

4.8.9. LOAD MOUSE POSITION¶

0x0E
0x00                ; filler
XMSB                ; X coordinate
XLSB                ; (in scaled coordinate system)
YMSB                ; Y coordinate
YLSB

このコマンドは、ユーザーが内部で保持されている絶対マウス位置を事前に設定できるようにします。

4.8.10. SET Y=0 AT BOTTOM¶

0x0F

このコマンドは、ikbd内の論理的な座標系においてY軸の原点をマウスの相対または絶対移動全体の下端に設定します。これにより、ユーザーに向かうマウス移動は負の符号になり、ユーザーから遠ざかる移動は正の符号になります。

4.8.11. SET Y=0 AT TOP¶

0x10

ikbd内の論理的な座標系においてY軸の原点を上端に設定します。(デフォルト) これにより、ユーザーに向かうマウス移動は正の符号になり、ユーザーから遠ざかる移動は負の符号になります。

4.8.12. RESUME¶

0x11

ホストへのデータ送信を再開します。ikbdの出力が一時停止した後で受信した任意のコマンドも暗黙の再開を引き起こすため、このコマンドは無効コマンドとみなせます。ikbdがこのコマンドを受信した場合、PAUSEDでなければ単に無視されます。

4.8.13. DISABLE MOUSE¶

0x12

すべてのマウスイベントの報告が無効になります(スキャンも内部的に無効になる可能性があります)。有効なマウスモードコマンドはマウス移動の監視を再開します。(有効なマウスモードコマンドはSET RELATIVE MOUSE POSITION REPORTING、SET ABSOLUTE MOUSE POSITIONING、SET MOUSE KEYCODE MODEです。) 注: マウスボタンがキーボードキーのように動作するように指示されている場合、このコマンドはその動作に影響を与えます。

4.8.14. PAUSE OUTPUT¶

0x13

ホストへのデータ送信を一時停止し、有効なコマンドが再受信されるまで待機します。キーマトリクスの活動は依然として監視され、スキャンコードまたはASCII文字がマイクロコントローラーがサポートする最大数までキューイングされ、ホストが出力再開を許可したときに送信されます。JOYSTICK EVENT REPORTINGモードの場合、ジョイスティックイベントもキューイングされます。マウスの動きは出力が一時停止している間も累積されます。ikbdがRELATIVE MOUSE POSITIONING REPORTINGモードの場合、通常のしきい値を超えた動きが累積され、出力再開時に必要な最小数のパケットが生成されます。マウスボタンを押下または解放すると、RELATIVE MOUSE POSITION REPORTINGモードでマウスが動作している場合、累積された動きが即座にパケットとしてキューイングされます。マイクロコントローラーのメモリ制限により、このコマンドは頻繁に使用すべきではありません。出力は一度に<tbd>ミリ秒以上停止してはいけません。出力は現在の「even」の終了時のみ停止します。複数バイトレポートの途中でPAUSE OUTPUTコマンドを受信した場合、パケットは送信を完了した後でPAUSEが有効になります。ikbdがJOYSTICK MONITORINGモードまたはFIRE BUTTON MONITORINGモードの場合、PAUSE OUTPUTコマンドは監視プロセスを一時停止します（つまり、サンプルが送信キューに追加されません）。

4.8.15. ジョイスティックイベントレポートを設定¶

0x14

ジョイスティックイベントレポートモード（デフォルト）に移行します。ジョイスティックのスイッチまたはトリガーの開閉ごとにジョイスティックイベントレコードが生成されます。

4.8.16. ジョイスティックインタロゲーションモードを設定¶

0x15

ジョイスティックイベントレポートを無効化します。ホストは個別にジョイスティックインタロゲートコマンの送信によりジョイスティックの状態を感知する必要があります。

4.8.17. ジョイスティックインタロゲート¶

0x16

ジョイスティックの現在の状態を示すレコードを返します。このコマンドは、ジョイスティックイベントレポートモードまたはジョイスティックインタロゲーションモードのいずれかで有効です。

4.8.18. ジョイスティックモニタリングを設定¶

0x17
rate                ; time between samples in hundredths of a second
Returns: (in packets of two as long as in mode)
        %000000xy   ; where y is JOYSTICK1 Fire button
                    ; and x is JOYSTICK0 Fire button
        %nnnnmmmm   ; where m is JOYSTICK1 state
                    ; and n is JOYSTICK0 state

ikbdはシリアルコマンドラインを監視し、日時時計を維持し、ジョイスティックを監視するのみに設定します。レートはジョイスティックサンプル間のインターバルを設定します。N.B. ユーザーはシリアル通信チャネルが2バイトパケットを送信できるようにする範囲内でレートを設定する必要があります。

4.8.19. ファイアーボタンモニタリングを設定¶

0x18
Returns: (as long as in mode)
        %bbbbbbbb   ; state of the JOYSTICK1 fire button packed
                    ; 8 bits per byte, the first sample if the MSB

ikbdをシリアルコマンドラインの監視、時刻（タイムオブデイ）クロックの維持、ジョイスティック1のファイアボタンの監視のみを行うように設定します。ファイアボタンは、前のバイトがホストに送信されるまでの時間に8回のサンプルを取得するスキャンレートでスキャンされます（つまり、スキャンレート＝8/10 × バウドレート）。サンプル間隔は可能な限り一定に保つ必要があります。

4.8.20. ジョイスティック キーコードモードの設定¶

0x19
RX                  ; length of time (in tenths of seconds) until
                    ; horizontal velocity breakpoint is reached
RY                  ; length of time (in tenths of seconds) until
                    ; vertical velocity breakpoint is reached
TX                  ; length (in tenths of seconds) of joystick closure
                    ; until horizontal cursor key is generated before RX
                    ; has elapsed
TY                  ; length (in tenths of seconds) of joystick closure
                    ; until vertical cursor key is generated before RY
                    ; has elapsed
VX                  ; length (in tenths of seconds) of joystick closure
                    ; until horizontal cursor keystrokes are generated
                    ; after RX has elapsed
VY                  ; length (in tenths of seconds) of joystick closure
                    ; until vertical cursor keystrokes are generated
                    ; after RY has elapsed

このモードでは、ジョイスティック0がカーソルキーストロークをシミュレートするようにスキャンされます。初期閉じる際にはキーストロークペア（押し込み/押し出し）が生成され、その後Rnの十分の1秒後にTnの十分の1秒ごとにキーストロークペアが生成されます。Rnのブレイクポイントに達した後はVnの十分の1秒ごとにキーストロークペアが生成されます。これにより速度（オートリピート）のブレイクポイント機能が提供されます。注意として、RXおよび/またはRYをゼロに設定することで速度機能を無効化できます。この場合、TXおよびTYの値は無意味となり、カーソルの「キーストローク」生成はVXおよびVYによって制御されます。

4.8.21. ジョイスティックの無効化¶

0x1A

ジョイスティックイベントの生成を無効化し（スキャンも内部的に無効化される可能性があります）。有効なジョイスティックモードコマンドによりジョイスティックの監視が再開されます。（ジョイスティックモードコマンドはSET JOYSTICK EVENT REPORTING、SET JOYSTICK INTERROGATION MODE、SET JOYSTICK MONITORING、SET FIRE BUTTON MONITORING、SET JOYSTICK KEYCODE MODEです。）

4.8.22. 時刻（タイムオブデイ）クロックの設定¶

0x1B
YY                  ; year (2 least significant digits)
MM                  ; month
DD                  ; day
hh                  ; hour
mm                  ; minute
ss                  ; second

すべての時刻データは、ikbdにパックされたBCD形式で送信する必要があります。BCD形式で有効でない数字は「無視される」として扱い、日時フィールドの特定の部分を変更しないようにします。これにより、時刻（タイムオブデイ）クロックの一部のサブフィールドのみを設定することが可能です。

4.8.23. 時刻（タイムオブデイ）クロックの照会¶

0x1C
Returns:
        0xFC        ; time-of-day event header
        YY          ; year (2 least significant digits)
        MM          ; month
        DD          ; day
        hh          ; hour
        mm          ; minute
        ss          ; second

All time-of-day is sent in packed BCD format.

4.8.24. メモリの読み込み¶

0x20
ADRMSB              ; address in controller
ADRLSB              ; memory to be loaded
NUM                 ; number of bytes (0-128)
{ data }

このコマンドによりホストがikbdコントローラーのメモリに任意の値を読み込むことが可能です。データバイト間の時間は20ms未満でなければなりません。

4.8.25. メモリの読み出し¶

0x21
ADRMSB              ; address in controller
ADRLSB              ; memory to be read
Returns:
        0xF6        ; status header
        0x20        ; memory access
        { data }    ; 6 data bytes starting at ADR

このコマンドによりホストがikbdコントローラーのメモリから読み出すことが可能です。

4.8.26. コントローラーの実行¶

0x22
ADRMSB              ; address of subroutine in
ADRLSB              ; controller memory to be called

このコマンドによりホストがikbdコントローラーのメモリ内のサブルーチンを実行するように指示できます。

4.8.27. ステータス照会¶

Status commands are formed by inclusively ORing 0x80 with the
relevant SET command.

Example:
0x88 (or 0x89 or 0x8A)  ; request mouse mode
Returns:
        0xF6        ; status response header
        mode        ; 0x08 is RELATIVE
                    ; 0x09 is ABSOLUTE
                    ; 0x0A is KEYCODE
        param1      ; 0 is RELATIVE
                    ; XMSB maximum if ABSOLUTE
                    ; DELTA X is KEYCODE
        param2      ; 0 is RELATIVE
                    ; YMSB maximum if ABSOLUTE
                    ; DELTA Y is KEYCODE
        param3      ; 0 if RELATIVE
                    ; or KEYCODE
                    ; YMSB is ABSOLUTE
        param4      ; 0 if RELATIVE
                    ; or KEYCODE
                    ; YLSB is ABSOLUTE
        0           ; pad
        0

ステータス照会コマンドはikbdが現在のモードまたは特定のコマンドに関連するパラメータを返すように要求します。すべてのステータスレポートは8バイトの長さになるようにパディングされます。ステータスリクエストの応答はホストがステータスレポートヘッダーバイトを除去した後、ikbdの状態を復元するために後でコマンドとして送信できるように設計されています。0パディングバイトはikbdによって無効操作（NOP）として扱われます。

有効なステータス照会コマンドは次の通りです:

0x87    mouse button action
0x88    mouse mode
0x89
0x8A
0x8B    mnouse threshold
0x8C    mouse scale
0x8F    mouse vertical coordinates
0x90    ( returns       0x0F Y=0 at bottom
                0x10 Y=0 at top )
0x92    mouse enable/disable
        ( returns       0x00 enabled)
                0x12 disabled )
0x94    joystick mode
0x95
0x96
0x9A    joystick enable/disable
        ( returns       0x00 enabled
                0x1A disabled )

ホストプログラマの責任は、一度に1つの未処理の照会のみを処理することです。ikbdがジョイスティックモニタリングモードまたはファイアボタンモニタリングモードにある場合、STATUS INQUIRYコマンドは有効ではありません。
