14. rotary-encoder - GPIO 接続デバイス用の汎用ドライバー¶

著者

Daniel Mack <daniel@caiaq.de>, 2009年2月

14.1. 機能¶

回転エンコーダーは、CPUやその他のペリフェラルと2本のワイヤーで接続されるデバイスです。出力は90度位相シフトしており、下降エッジと上昇エッジをトリガーすることで、回転方向を判定できます。

一部のエンコーダーは安定状態で両出力がロー（低電位）になりますが、他には安定状態で両出力がハイ（高電位）になるもの（半周期モード）や、すべてのステップで安定状態になるもの（四分の一周期モード）もあります。

これらの2つの出力の位相ダイアグラムは次のようになります:

                _____       _____       _____
               |     |     |     |     |     |
Channel A  ____|     |_____|     |_____|     |____

               :  :  :  :  :  :  :  :  :  :  :  :
          __       _____       _____       _____
            |     |     |     |     |     |     |
Channel B   |_____|     |_____|     |_____|     |__

               :  :  :  :  :  :  :  :  :  :  :  :
Event          a  b  c  d  a  b  c  d  a  b  c  d

              |<-------->|
                one step

              |<-->|
                one step (half-period mode)

              |<>|
                one step (quarter-period mode)
詳細については、以下のリンクをご参照ください

https://en.wikipedia.org/wiki/Rotary_encoder

14.2. イベント / 状態機械¶

半周期モードでは、上記の状態a)とc)を最後の安定状態と比較して回転方向を判定します。新しい安定状態が最後のものと異なる場合（つまり回転が半分のところで逆転していない場合）、イベントは状態b)とd)で報告されます。

それ以外の場合、以下の通りです:

  1. チャネルAの上昇エッジ、チャネルBが低電位状態

    この状態は時計回りの回転を認識するために使用されます

  2. チャネルBの上昇エッジ、チャネルAが高電位状態

    この状態に移行すると、エンコーダーは「武装」状態に移行します。これは、1ステップの移動の半分を検出していることを意味します。

  3. チャネルAの下降エッジ、チャネルBが高電位状態

    この状態は反時計回りの回転を認識するために使用されます

  4. チャネルBの下降エッジ、チャネルAが低電位状態

    駐車位置。エンコーダーがこの状態に移行した場合、完全な移動が発生している必要があります（半分のところで戻った場合は除く）。この「武装」状態がその情報を提供します。

14.3. プラットフォーム要件¶

このドライバーにはハードウェア依存のコールがありませんため、使用するプラットフォームはgpiolibをサポートする必要があります。また、IRQが両エッジで発生できる必要があります。

14.4. ボード統合¶

このドライバーを使用するには、名前が「rotary-encoder」のplatform_deviceを登録し、IRQと特定のプラットフォームデータを関連付ける必要があります。ドライバーは汎用デバイスプロパティを使用するため、デバイスツリー、ACPI、または静的ボードファイル（例は以下の通り）で実現できます。

/* board support file example */

#include <linux/input.h>
#include <linux/gpio/machine.h>
#include <linux/property.h>

#define GPIO_ROTARY_A 1
#define GPIO_ROTARY_B 2

static struct gpiod_lookup_table rotary_encoder_gpios = {
        .dev_id = "rotary-encoder.0",
        .table = {
                GPIO_LOOKUP_IDX("gpio-0",
                                GPIO_ROTARY_A, NULL, 0, GPIO_ACTIVE_LOW),
                GPIO_LOOKUP_IDX("gpio-0",
                                GPIO_ROTARY_B, NULL, 1, GPIO_ACTIVE_HIGH),
                { },
        },
};

static const struct property_entry rotary_encoder_properties[] __initconst = {
        PROPERTY_ENTRY_U32("rotary-encoder,steps-per-period", 24),
        PROPERTY_ENTRY_U32("linux,axis",                      ABS_X),
        PROPERTY_ENTRY_U32("rotary-encoder,relative_axis",    0),
        { },
};

static struct platform_device rotary_encoder_device = {
        .name           = "rotary-encoder",
        .id             = 0,
};

...

gpiod_add_lookup_table(&rotary_encoder_gpios);
device_add_properties(&rotary_encoder_device, rotary_encoder_properties);
platform_device_register(&rotary_encoder_device);

...

ドライバーがサポートするすべてのプロパティを確認するには、デバイスツリーバインディングドキュメンテーションをご参照ください。
