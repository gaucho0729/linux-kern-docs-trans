18. ヤエリンク usb-p1k フォン用ドライバドキュメンテーション¶

18.1. Status¶

p1k は比較的安価な USB 1.1 フォンで、以下の機能を備えています:

  • キーボードの完全なサポート、yealink.ko / input event API

  • LCD の完全なサポート、yealink.ko / sysfs API

  • LED の完全なサポート、yealink.ko / sysfs API

  • ダイアルトーンの完全なサポート、yealink.ko / sys,fs API

  • リントーンの完全なサポート、yealink.ko / sysfs API

  • オーディオ再生の完全なサポート、snd_usb_audio.ko / alsa API

  • オーディオ録音の完全なサポート、snd_usb_audio.ko / alsa API

ベンダーのドキュメンテーションについては http://www.yealink.com

18.2. キーボード機能¶

現在のキーマッピングは map_p1k_to_key 関数で提供されています:

Physical USB-P1K button layout       input events


           up                             up
     IN           OUT                left,   right
          down                           down

   pickup   C    hangup              enter, backspace, escape
     1      2      3                 1, 2, 3
     4      5      6                 4, 5, 6,
     7      8      9                 7, 8, 9,
     *      0      #                 *, 0, #,

「上」および「下」キーはボタン上の矢印で表され、「受話」および「通話終了」キーはボタン上の緑色と赤色の電話アイコンで表されます。

18.3. LCD 機能¶

LCD は 3 行のディスプレイとして分割・構成されています:

  |[]   [][]   [][]   [][]   in   |[][]
  |[] M [][] D [][] : [][]   out  |[][]
                            store

  NEW REP         SU MO TU WE TH FR SA

  [] [] [] [] [] [] [] [] [] [] [] []
  [] [] [] [] [] [] [] [] [] [] [] []


Line 1  Format (see below)    : 18.e8.M8.88...188
        Icon names            :   M  D  :  IN OUT STORE
Line 2  Format                : .........
        Icon name             : NEW REP SU MO TU WE TH FR SA
Line 3  Format                : 888888888888
フォーマットの説明:

ユーザー空間の観点では、世界は「桁」と「アイコン」に分かれています。桁には文字セットを持ち、アイコンは ON または OFF のみです。

フォーマット指定子:

'8' :  Generic 7 segment digit with individual addressable segments

Reduced capability 7 segment digit, when segments are hard wired together.
'1' : 2 segments digit only able to produce a 1.
'e' : Most significant day of the month digit,
      able to produce at least 1 2 3.
'M' : Most significant minute digit,
      able to produce at least 0 1 2 3 4 5.

Icons or pictograms:
'.' : For example like AM, PM, SU, a 'dot' .. or other single segment
      elements.

18.4. ドライバの使用方法¶

ユーザー空間では、sysfs インターフェースを使用して以下のインターフェースが利用可能です:

/sys/.../
         line1        Read/Write, lcd line1
         line2        Read/Write, lcd line2
         line3        Read/Write, lcd line3

         get_icons    Read, returns a set of available icons.
         hide_icon    Write, hide the element by writing the icon name.
         show_icon    Write, display the element by writing the icon name.

         map_seg7     Read/Write, the 7 segments char set, common for all
                      yealink phones. (see map_to_7segment.h)

         ringtone     Write, upload binary representation of a ringtone,
                      see yealink.c. status EXPERIMENTAL due to potential
                      races between async. and sync usb calls.

18.4.1. lineX¶

/sys/../lineX を読み込むと、現在の値を持つフォーマット文字列が返されます。

例:

cat ./line3
888888888888
Linux Rocks!

/sys/../lineX に書き込むと、対応する LCD 行が設定されます。

  • 余分な文字は無視されます。

  • 書き込まれる文字が許容数より少ない場合、残りの桁は変更されません。

  • タブ 't' および 'n' 文字は元の内容を上書きしません。

  • アイコンにスペースを書き込むと、その内容が常に非表示になります。

例:

date +"%m.%e.%k:%M"  | sed 's/^0/ /' > ./line1

LCD に現在の日付と時刻を更新します。

18.4.2. get_icons¶

読み込むと、すべての利用可能なアイコン名と現在の設定が返されます:

cat ./get_icons
on M
on D
on :
   IN
   OUT
   STORE
   NEW
   REP
   SU
   MO
   TU
   WE
   TH
   FR
   SA
   LED
   DIALTONE
   RINGTONE

18.4.3. アイコンの表示/非表示¶

これらのファイルに書き込むと、アイコンの状態が更新されます。一度に1つのアイコンのみを更新可能です。

アイコンが同時に ./lineX 上にも存在する場合、アイコンの最初の文字で対応する値が更新されます。

例 - 店舗アイコンを点灯する場合:

echo -n "STORE" > ./show_icon

cat ./line1
18.e8.M8.88...188
              S

例 - リントーンを10秒間鳴らす場合:

echo -n RINGTONE > /sys/..../show_icon
sleep 10
echo -n RINGTONE > /sys/..../hide_icon

18.5. サウンド機能¶

サウンドは ALSA ドライバ snd_usb_audio でサポートされています。

デバイスの実用限界は、16ビットチャネルでサンプリングおよび再生レートが8000Hzのものです。

例 - レコーディングテスト:

arecord -v -d 10 -r 8000 -f S16_LE -t wav  foobar.wav

例 - プレイバックテスト:

aplay foobar.wav

18.6. トラブルシューティング¶

Q

yealinkモジュールは問題なくコンパイル・インストールされました。しかし、電話機が初期化されておらず、どのアクションにも反応していません。

A

hiddev0: USB HID v1.00 デバイス [Yealink Network Technology Ltd. VOIP USB フォン] と表示されている場合、hidドライバーがデバイスを最初に取得している可能性があります。他のUSB HIDドライバーよりもyealinkモジュールを先にロードしてください。ディストリビューションのモジュール構成に関するインストラクションを参照してください。

Q

電話機は現在動作しています（バージョンを表示し、キーパッド入力を受け入れます）が、sysfsファイルが見つかりません。

A

sysfsファイルは特定のUSBエンドポイントに位置しています。ほとんどのディストリビューションでは、「find /sys/ -name get_icons」でヒントを得ることができます。
