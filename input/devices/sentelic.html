15.1. 指感パッドのIntellimouseモード（スクロールホイール、4番目と5番目のボタン）¶

  1. MSID 4: スクロールホイールモードに加えて、フォワードページ（4番目のボタン）とバックワードページ（5番目のボタン）

  1. サンプリングレートを200に設定;

  2. サンプリングレートを200に設定;

  3. サンプリングレートを80に設定;

  4. 「デバイスIDを取得」コマンド（0xF2）を発行し、応答を待機;

  5. FSPは0x04を応答します。

        Bit6 => X overflow

                0 = 5th mouse button is not pressed.

  1. MSID 6: 水平および垂直スクロール

  • レジスタ0x40のビット1を1に設定

FSPはスクロールホイールの移動を4ビットで表現し、水平および垂直スクロールを表示します。

  1. MSID 7

FSPは絶対位置を2つのパケット（8バイト）で表現するため、パケット番号でパケットを識別します。

パケット番号が0の場合、パケットはパケット1です。パケット番号が1の場合、パケットはパケット2です。プログラム内でこの番号をカウントしてください。

MSID6の特別なパケットはMSID7を有効にする同時刻に有効になります。

15.6. FSPの有効/無効パケット¶

Bit 7 6 5 4 3 2 1 0       7 6 5 4 3 2 1 0      7 6 5 4 3 2 1 0      7 6 5 4 3 2 1 0
BYTE  |---------------|BYTE |---------------|BYTE|---------------|BYTE|---------------|
  1   |Y|X|0|0|1|M|R|L|  2  |0|1|0|1|1|0|1|E|  3 | | | | | | | | |  4 | | | | | | | | |
      |---------------|     |---------------|    |---------------|    |---------------|

FSP will send out enable/disable packet when FSP receive PS/2 enable/disable
command. Host will receive the packet which Middle, Right, Left button will
be set. The packet only use byte 0 and byte 1 as a pattern of original packet.
Ignore the other bytes of the packet.

Byte 1: Bit7 => 0, Y overflow
        Bit6 => 0, X overflow
        Bit5 => 0, Y sign bit
        Bit4 => 0, X sign bit
        Bit3 => 1
        Bit2 => 1, Middle Button
        Bit1 => 1, Right Button
        Bit0 => 1, Left Button
Byte 2: Bit7~1 => (0101101b)
        Bit0 => 1 = Enable
                0 = Disable
Byte 3: Don't care
Byte 4: Don't care (MOUSE ID 3, 4)
Byte 5~8: Don't care (Absolute packet)

15.8. パケット解析フローを決定するプログラミングシーケンス¶

  1. FSPを識別するには、デバイスID（0x00）およびバージョン（0x01）レジスタを読み取ってください

  2. FSPバージョン < STL3888 Cxの場合、テストモードステータス（0x20）レジスタを読み取ってボタン数を決定してください:

    buttons = reg[0x20] & 0x30

if buttons == 0x30 or buttons == 0x20:
        # two/four buttons
        Refer to 'Finger Sensing Pad PS/2 Mouse Intellimouse'
        section A for packet parsing detail(ignore byte 4, bit ~ 7)
elif buttons == 0x10:
        # 6 buttons
        Refer to 'Finger Sensing Pad PS/2 Mouse Intellimouse'
        section B for packet parsing detail
elif buttons == 0x00:
        # 6 buttons
        Refer to 'Finger Sensing Pad PS/2 Mouse Intellimouse'
        section A for packet parsing detail
  3. FSPバージョン >= STL3888 Cxの場合:

    「Finger Sensing Pad PS/2 Mouse Intellimouse」セクションAのパケット解析の詳細を参照してください（バイト4のビット7～0は無視してください）

15.9. レジスタ読み書きのプログラミング手順¶

レジスタ反転の必要条件:

FSPに送信する前に以下の値は反転する必要があります（C言語の'~'演算子）:

0xe8, 0xe9, 0xee, 0xf2, 0xf3 and 0xff.

レジスタ交換の必要条件:

FSPに送信する前に以下の値は上位4ビットと下位4ビットを交換する必要があります:

10, 20, 40, 60, 80, 100 and 200.

レジスタ読み取り手順:

  1. FSPに0xf3 PS/2コマンドを送信してください;

  2. FSPに0x66 PS/2コマンドを送信してください;

  3. FSPに0x88 PS/2コマンドを送信してください;

  4. FSPに0xf3 PS/2コマンドを送信してください;

5. 読み取るレジスタアドレスが反転不要な場合（「レジスタ反転の必要条件」セクションを参照）、ステップ6に進みます

  1. FSPに0x68 PS/2コマンドを送信してください;

  2. 反転したレジスタアドレスをFSPに送信し、ステップ8に進みます;

6. 読み取るレジスタアドレスが交換不要な場合（「レジスタ交換の必要条件」セクションを参照）、ステップ7に進みます

  1. FSPに0xcc PS/2コマンドを送信してください;

  2. 交換したレジスタアドレスをFSPに送信し、ステップ8に進みます;

  1. FSPに0x66 PS/2コマンドを送信してください;

  1. 元のレジスタアドレスをFSPに送信し、ステップ8に進みます;

  1. FSPに0xe9（状態要求）PS/2コマンドを送信してください;

9. FSPから読み取った応答の4番目のバイトが要求されたレジスタ値になります（??は無視するバイト）:

host: 0xe9
3888: 0xfa (??) (??) (val)

  • Cxリリース以降、ハードウェアは状態要求結果の3番目のバイトにレジスタ値の1の補数を返します:

    host: 0xe9
3888: 0xfa (??) (~val) (val)

レジスタ書き込み手順:

  1. FSPに0xf3 PS/2コマンドを送信してください;

2. 書き込むレジスタアドレスが反転不要な場合（「レジスタ反転の必要条件」セクションを参照）、ステップ3に進みます

  1. FSPに0x74 PS/2コマンドを送信してください;

  2. 反転したレジスタアドレスをFSPに送信し、ステップ5に進みます;

3. 書き込むレジスタアドレスが交換不要な場合（「レジスタ交換の必要条件」セクションを参照）、ステップ4に進みます

  1. FSPに0x77 PS/2コマンドを送信してください;

  2. 交換したレジスタアドレスをFSPに送信し、ステップ5に進みます;

  1. FSPに0x55 PS/2コマンドを送信してください;

  1. レジスタアドレスをFSPに送信し、ステップ5に進みます;

  1. FSPに0xf3 PS/2コマンドを送信してください;

6. 書き込むレジスタ値が反転不要な場合（「レジスタ反転の必要条件」セクションを参照）、ステップ7に進みます

  1. FSPに0x47 PS/2コマンドを送信してください;

  2. 反転したレジスタ値をFSPに送信し、ステップ9に進みます;

7. 書き込むレジスタ値が交換不要な場合（「レジスタ交換の必要条件」セクションを参照）、ステップ8に進みます

  1. FSPに0x44 PS/2コマンドを送信してください;

  2. 交換したレジスタ値をFSPに送信し、ステップ9に進みます;

  1. FSPに0x33 PS/2コマンドを送信してください;

  1. レジスタ値をFSPに送信してください;

  1. レジスタ書き込み手順は完了しました。

  • Cxリリース以降、ハードウェアはステータスリクエスト結果の3番目のバイトのレジスタ値の1の補数を返します。ホストは、レジスタ書き込み終了後に別の0xe9（ステータスリクエスト）PS/2コマンドをFSPに送ることで、レジスタ書き込み操作が成功したかを確認できます（??は無視するバイトを示します）：

    host: 0xe9
3888: 0xfa (??) (~val) (val)

15.10. ページレジスタの読み書きに関するプログラミングシーケンス¶

最大サポートレジスタ数の制限を克服するため、ハードウェアはレジスタを「ページ」と呼ばれる異なるグループに分離しています。各ページは最大255個のレジスタを含むことができます。

電源投入後のデフォルトページは0x82です。したがって、レジスタ0x8301にアクセスするには、以下のシーケンスを使用してページ0x83に切り替え、前のセクションで説明したレジスタ読み書きシーケンスを使用してオフセット0x01から読み書きを行う必要があります。

ページレジスタ読み込みシーケンス：

  1. FSPに0xf3 PS/2コマンドを送信してください;

  2. FSPに0x66 PS/2コマンドを送信してください;

  3. FSPに0x88 PS/2コマンドを送信してください;

  4. FSPに0xf3 PS/2コマンドを送信してください;

  5. 0x83 PS/2コマンドをFSPに送信します。

  6. FSPに0x88 PS/2コマンドを送信してください;

  7. FSPに0xe9（状態要求）PS/2コマンドを送信してください;

  8. FSPから読み取った応答は、リクエストされたページ値である必要があります。

ページレジスタ書き込みシーケンス：

  1. FSPに0xf3 PS/2コマンドを送信してください;

  2. 0x38 PS/2コマンドをFSPに送信します。

  3. FSPに0x88 PS/2コマンドを送信してください;

  4. FSPに0xf3 PS/2コマンドを送信してください;

5. 書き込まれるページアドレスが反転不要（「レジスタ反転要件」セクションを参照）である場合、ステップ6に進みます

  1. FSPに0x47 PS/2コマンドを送信してください;

  2. 反転したページアドレスをFSPに送信し、ステップ9に進みます；

6. 書き込まれるページアドレスが交換不要（「レジスタ交換要件」セクションを参照）である場合、ステップ7に進みます

  1. FSPに0x44 PS/2コマンドを送信してください;

  2. 交換したページアドレスをFSPに送信し、ステップ9に進みます；

  1. FSPに0x33 PS/2コマンドを送信してください;

  2. ページアドレスをFSPに送信します。

  3. ページレジスタ書き込みシーケンスは完了しました。
