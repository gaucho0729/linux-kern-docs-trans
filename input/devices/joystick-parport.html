11.2. はじめに¶

ジョイスティック parport ドライバは、PCやLinuxが動作する他のコンピュータ用に設計されていないジョイスティックやゲームパッドのために使用されます。そのため、PCはこれらのデバイスを接続するための正しいポートが通常ありません。パラレルポートは、単一のビットを任意に変更でき、出力と入力ビットを提供できるため、このようなデバイスを接続するためのPCで最も適したポートです。

11.3. サポートされるデバイス¶

多くのコンソールおよび8ビットコンピュータ用ゲームパッドとジョイスティックがサポートされています。以下のサブセクションでは、それぞれの使用方法について説明します。

11.3.1. NES および SNES¶

Nintendo Entertainment System および Super Nintendo Entertainment System のゲームパッドは、広く入手可能で、簡単に入手できます。また、PCに接続するのも簡単で、処理速度は必要ありません（NES は 108 マイクロ秒、SNES は 165 マイクロ秒、PC ゲームパッドは約 1000 マイクロ秒）。

すべての NES および SNES は、コンピュータ側でクロックされる同期シリアルプロトコルを使用します。これにより、タイミングに敏感ではありません。最大で5つの NES および/または SNES ゲームパッドおよび/または SNES マウスをパラレルポートに同時に接続するため、パラレルポートの出力ラインは共有され、各ゲームパッドには5つの入力ラインのうち1つが割り当てられます。

このプロトコルは gamecon.c ドライバによって処理されるため、NES、SNES ゲームパッドおよび SNES マウスにはこのドライバを使用してください。

PC パラレルポートの主な問題は、ピンのいずれにも +5V の電源がありません。したがって、パッドの信頼できる電源を確保するには、キーボードまたはジョイスティックポートを使用し、パススルーケーブルを作成してください。また、電源供給装置から直接電源を引き出せます（赤いワイヤーは +5V）。

パラレルポートのみを使用する場合は、データピンから電源を取得できます。ほとんどのゲームパッドおよびパラレルポート実装では、1つのピンのみが必要です。私はピン9を推奨します（最高のデータビット）。一方で、NES/SNES以外のデバイスを使用しない場合、ピン4からピン9の間のどのピンも動作します：

(pin 9) -----> Power

残念ながら、電力を多く必要とするパッドや、データピンを通じて十分な電流を供給できないパラレルポートがあります。このような場合、ダイオードを使用して（パラレルポートを破損から守るため）、2つ以上のデータビットの電流を組み合わせる必要があります:

          Diodes
(pin 9) ----|>|-------+------> Power
                    |
(pin 8) ----|>|-------+
                    |
(pin 7) ----|>|-------+
                    |
<and so on>         :
                    |
(pin 4) ----|>|-------+

グランドは比較的簡単です。PCのパラレルポートでは、ピン18からピン25のいずれかがグランドです。よって、これらのピンのいずれかをグランドとして使用してください:

(pin 18) -----> Ground

NESおよびSNESのパッドは、シリアル転送を制御するクロックとレッチの2つの入力ビットを持ち、これらはそれぞれパラレルポートのピン2およびピン3に接続されています:

(pin 2) -----> Clock
(pin 3) -----> Latch

そして最後にNES/SNESのデータワイヤーです。このデータワイヤーは共有されず、各パッドには個別のデータピンが必要です。パラレルポートのピンは以下の通りです:

(pin 10) -----> Pad 1 data
(pin 11) -----> Pad 2 data
(pin 12) -----> Pad 3 data
(pin 13) -----> Pad 4 data
(pin 15) -----> Pad 5 data

ピン14は使用されません。これはパラレルポートで入力ピンではないためです。

これでPC側の必要な情報はすべてです。次にゲームパッド側について説明します。NESおよびSNESは異なるコネクタを使用しています。また、ニンテンドーは自社の機種に専用コネクタを採用したため、クローンメーカーは標準的なD-Cannonコネクタを使用しています。いずれにせよ、ゲームパッドがボタンA、B、ターボA、ターボB、セレクト、スタートを備え、5本のワイヤーで接続されている場合、それはNESまたはNESクローンであり、この接続で動作します。SNESのゲームパッドも5本のワイヤーを使用しますが、ボタンがより多くあります。もちろん、これも動作します:

11.3.2. マルチシステムジョイスティック¶

11.3.2.1. db9.cを使用するマルチシステムジョイスティック¶

マルチシステムジョイスティックおよびその派生機種のためにdb9.cドライバーが作成されました。これはパラレルポートごとに1つのジョイスティック/ゲームパッドのみを許可しますが、インターフェースは簡単に構築でき、ほぼすべての機器と互換性があります。

基本的な1ボタンマルチシステムジョイスティックは、以下の通りパラレルポートにワイヤーを接続します:

(pin  1) -----> Power
(pin 18) -----> Ground

(pin  2) -----> Up
(pin  3) -----> Down
(pin  4) -----> Left
(pin  5) -----> Right
(pin  6) -----> Button 1

ただし、ジョystickがスイッチベース（例：動かすとクリックする）の場合、並列ポートによっては方向やボタン信号に10 kOhmのプルアップ抵抗が必要になる場合があります。以下のようにします：

(pin 2) ------------+------> Up
          Resistor  |
(pin 1) --[10kOhm]--+

まずは試してみてください。動かさない場合、それらを追加してください。TTLベースのジョystick／ゲームパッドではプルアップ抵抗は必要ありません。

2ボタンのジョystickの場合、2番目のボタンを並列ポートのピン7に接続します：

(pin 7) -----> Button 2

以上です。

補足として、すでにデジタルジョystickドライバ0.8.0.2用の別のアダプターを組み上げた場合、db9.cドライバもデバイスタイプ8としてこの機能をサポートしています。（セクション3.2を参照）

11.3.2.2. gamecon.cを使用するマルチシステムジョystick¶

一部の人にとっては1つのジョystickにつき1つの並列ポートでは不十分で、NES/SNES/PSXパッドと1つの並列ポートで使用したい場合があります。これはgamecon.cを使用することで可能です。このドライバは、1ボタンおよび2ボタンのマルチシステムジョystickを含む上記のタイプのデバイスを最大5台サポートしています。

ただし、無料ではありません。複数のジョystickを同時に使用するには、ジョystickが純粋にスイッチベース（つまりTTLではない）で、電源を必要としない必要があります。単純な6つのスイッチのみで構成されています。あなたのジョystickがより多くの機能（例：ターボファイア）を備えている場合、gamecon.cを使用する前にそれらを完全に無効にしなければなりません。

また、接続はやや複雑です。ダイオードを多数使用し、1つのプルアップ抵抗が必要です。まず、db9と同じように方向とボタンを接続しますが、ダイオードを介して以下のようにします：

            Diodes
(pin 2) -----|<|----> Up
(pin 3) -----|<|----> Down
(pin 4) -----|<|----> Left
(pin 5) -----|<|----> Right
(pin 6) -----|<|----> Button 1

2ボタンのジョystickの場合、もう一つのボタンも接続します：

(pin 7) -----|<|----> Button 2

最後に、ジョystickのグランドワイヤーを接続します。これはNES/SNESパッドのセクション2.1で説明されているように、並列ポートの電源とデータに接続します。つまり、各ジョystickに1つのデータピンを割り当てます。電源は共有されます：

Data    ------------+-----> Ground
          Resistor  |
Power   --[10kOhm]--+

以上です。さあ始めましょう！

11.3.2.3. turbografx.cを使用するマルチシステムジョystick¶

TurboGraFXインターフェースは、

Steffen Schwenke <schwenke@burg-halle.de>

によって設計され、並列ポートに最大7台のマルチシステムジョystickを接続できます。Steffenのバージョンでは、各ジョystickに最大5つのボタンをサポートしています。ただし、すべての並列ポートで信頼性が保証されていないため、turbografx.cドライバは各ジョystickに1つのボタンのみをサポートしています。インターフェースの構築方法については、以下のリンクを参照してください：

http://www2.burg-halle.de/~schwenke/parport.html

11.3.3. ソニープレイステーション¶

PSXコントローラーはgamecon.cでサポートされています。PSXコントローラーのピン配置（DirectPadProと互換）：

  +---------+---------+---------+
9 | o  o  o | o  o  o | o  o  o | 1               parallel
   \________|_________|________/                  port pins
    |  |      |  |  |   |
    |  |      |  |  |   +-------->  Clock    ---  (4)
    |  |      |  |  +------------>  Select   ---  (3)
    |  |      |  +--------------->  Power    ---  (5-9)
    |  |      +------------------>  Ground   ---  (18-25)
    |  +------------------------->  Command  ---  (2)
    +---------------------------->  Data     ---  (one of 10,11,12,13,15)

ドライバーがサポートするコントローラーは以下の通りです：

  • 標準PSXパッド

  • NegCon PSXパッド

  • アナログPSXパッド（レッドモード）

  • アナログPSXパッド（グリーンモード）

  • PSX Rumble Pad

  • PSX DDR Pad

11.3.4. セガ¶

すべてのセガコントローラーは、標準の2ボタンマルチシステムジョイストickにほぼ基づいています。ただし、スイッチではなくTTL論理を使用しているため、使用可能なドライバーはdb9.cドライバーのみです。

11.3.4.1. セガマスターシステム¶

SMSゲームパッドは、通常の2ボタンマルチシステムジョイストickとほぼ同じです。ドライバーをMulti2モードに設定し、対応するパラレルポートピンを使用し、以下の回路図を使用してください。

    +-----------> Power
    | +---------> Right
    | | +-------> Left
    | | | +-----> Down
    | | | | +---> Up
    | | | | |
  _____________
5 \ o o o o o / 1
   \ o o x o /
  9 `~~~~~~~' 6
     | |   |
     | |   +----> Button 1
     | +--------> Ground
     +----------> Button 2

11.3.4.2. セガジェネシス（ヨーロッパではセガメガドライブとして販売）¶

セガジェネシス（ヨーロッパではセガメガドライブとして販売）パッドは、セガマスターシステムパッドの拡張です。より多くのボタン（3+1、5+1、6+1）を使用します。以下の回路図を使用してください。

    +-----------> Power
    | +---------> Right
    | | +-------> Left
    | | | +-----> Down
    | | | | +---> Up
    | | | | |
  _____________
5 \ o o o o o / 1
   \ o o o o /
  9 `~~~~~~~' 6
    | | | |
    | | | +----> Button 1
    | | +------> Select
    | +--------> Ground
    +----------> Button 2

セレクトピンはパラレルポートのピン14に接続されます：

(pin 14) -----> Select

それ以降はMulti2ジョイストickを使用するdb9.cドライバーと同じです。

11.3.4.3. セガサターン¶

セガサターンには8つのボタンがあり、Genesis 6パッドのようにハックを使わずに転送するには、1つの追加のセレクトピンが必要です。いずれにしても、db9.cドライバーで処理されます。ピン配置は他のものとは大きく異なります。以下の回路図を使用してください。

    +-----------> Select 1
    | +---------> Power
    | | +-------> Up
    | | | +-----> Down
    | | | | +---> Ground
    | | | | |
  _____________
5 \ o o o o o / 1
   \ o o o o /
  9 `~~~~~~~' 6
     | | | |
     | | | +----> Select 2
     | | +------> Right
     | +--------> Left
     +----------> Power

セレクト1はパラレルポートのピン14、セレクト2はパラレルポートのピン16に接続されます：

(pin 14) -----> Select 1
(pin 16) -----> Select 2

他のピン（上、下、右、左、電源、接地）は、db9.cドライバーを使用するMultiジョイストickと同じです。

11.4. ドライバー¶

パラレルポートインターフェースには3つのドライバーがあります。それぞれ、上記のように異なるジョイストickとパッドのグループを接続できます。以下にコマンドラインを説明します：

11.4.1. gamecon.c¶

gamecon.cを使用すると、1つのパラレルポートに最大5台のデバイスを接続できます。使用するカーネル/モジュールのコマンドラインは以下の通りです：

gamecon.map=port,pad1,pad2,pad3,pad4,pad5

ここで port パラポートインターフェースの番号（例：parport0の場合は0）。

そして pad1 に（木の下から葉に向かって） pad5 は、異なるデータ入力ピン（10、11、12、13、15）に接続されたパッドタイプで、このファイルのセクション2.1で説明されています。

タイプは以下の通りです：

タイプ

ジョイストick/パッド

0

なし

1

SNESパッド

2

NESパッド

4

マルチシステム1ボタンジョystick

5

マルチシステム2ボタンジョystick

6

N64パッド

7

ソニーPSXコントローラー

8

ソニーPSXDDRコントローラー

9

SNESマウス

PSXコントローラーの正確なタイプは使用時に自動で検出されるため、ホットスワップは動作するはずですが（推奨されません）。

複数のパラレルポートを同時に使用したい場合は、gamecon.map2とgamecon.map3を追加のコマンドラインパラメータとして使用して、2つの追加のパラレルポートを指定できます。

PSXドライバー専用のオプションがあります。gamecon.psx_delayはコントローラーとの通信時のコマンド遅延を設定します。デフォルトの25は動作するはずですが、パフォーマンス向上のために下げてみてください。パッドが反応しない場合は、それまでに動作するまで上げてみてください。タイプを8に設定すると、ダンスダンスレボリューションや類似ゲームでの使用が可能になります。矢印キーはキープレスとしてではなく、X軸とY軸として登録されます。

11.4.2. db9.c¶

インターフェースの作成以外には、db9.cドライバーの使用は特に難しいことはありません。以下のカーネル/モジュールコマンドラインを使用します：

db9.dev=port,type

ここで port これはパラレルポートインターフェースの番号（例：parport0は0）です。

注意点：このドライバーは双方向パラレルポートでのみ動作します。パラレルポートが最新であれば問題ありませんが、古いパラレルポートはこの機能を持っていない可能性があります。

11.4.3. turbografx.c¶

turbografx.cドライバーは非常にシンプルなカーネル/モジュールコマンドラインを使用します：

turbografx.map=port,js1,js2,js3,js4,js5,js6,js7

ここで port これはパラレルポートインターフェースの番号（例：parport0は0）です。

jsX インターフェースポート1-7に接続されたマルチシステムジョystickのボタン数です。標準のマルチシステムジョystickの場合、これは1です。

これらのインターフェースを同時に使用したい場合は、turbografx.map2とturbografx.map3を追加のコマンドラインパラメータとして使用して、2つの追加インターフェースを指定できます。
