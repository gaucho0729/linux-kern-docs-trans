3. Apple Touchpad Driver (appletouch)¶

著作権

© 2005 Stelian Pop <stelian@popies.net>

appletouchは、2005年2月以降および2005年10月以降に製造されたApple Aluminium Powerbooksに搭載されているUSBタッチパッド用のLinuxカーネルドライバーです。

このドライバーはJohannes Bergのappletrackpadドライバーから派生しています 1、ただし一部の分野では改善されています：

  • appletouchは完全なカーネルドライバーであり、ユーザー空間のプログラムは必要ありません

  • appletouchはsynaptics X11ドライバーとインターフェースを取ることができ、タッチパッドの加速度、スクロールなど、追加機能を提供できます。

タッチパッドプロトコルの逆コンパイルにはJohannes Berg、改善にはFrank Arnold、タッチパッドセンサーの内部動作に関する追加情報にはAlex Harperが貢献しました。Michael Hanselmannは2005年10月モデルのサポートを追加しました。

3.1. 使い方¶

タッチパッドを基本モードで使用するには、ドライバーをコンパイルしてモジュールをロードしてください。新しい入力デバイスが検出され、/dev/input/mice（gpmやX11を使用して）からマウスデータを読み取ることができます。

X11では、タッチパッドをsynaptics X11ドライバーを使用して設定できます。これにより、加速度、スクロール、2本指タップによる中ボタンのエミュレーション、3本指タップによる右ボタンのエミュレーションなどの追加機能が利用できます。この設定を行うには、最新版のsynapticsドライバーを使用してください（テスト済みバージョンは0.14.2、 2)、X11設定ファイルで新しい入力デバイスを設定してください（下記の例を参考にしてください）。追加の設定については、synapticsドライバーのドキュメンテーションを参照してください：

Section "InputDevice"
        Identifier      "Synaptics Touchpad"
        Driver          "synaptics"
        Option          "SendCoreEvents"        "true"
        Option          "Device"                "/dev/input/mice"
        Option          "Protocol"              "auto-dev"
        Option          "LeftEdge"              "0"
        Option          "RightEdge"             "850"
        Option          "TopEdge"               "0"
        Option          "BottomEdge"            "645"
        Option          "MinSpeed"              "0.4"
        Option          "MaxSpeed"              "1"
        Option          "AccelFactor"           "0.02"
        Option          "FingerLow"             "0"
        Option          "FingerHigh"            "30"
        Option          "MaxTapMove"            "20"
        Option          "MaxTapTime"            "100"
        Option          "HorizScrollDelta"      "0"
        Option          "VertScrollDelta"       "30"
        Option          "SHMConfig"             "on"
EndSection

Section "ServerLayout"
        ...
        InputDevice     "Mouse"
        InputDevice     "Synaptics Touchpad"
...
EndSection

3.2. ノイズ問題¶

タッチパッドセンサーは温度変化に非常に敏感で、温度変化時に多くのノイズを生成します。これは特にラップトップを初めて電源を入れた際によく起こります。

appletouchドライバーはこのノイズを処理し、自動調整を試みますが、完全ではありません。指の動きが認識されなくなった場合は、ドライバーを再ロードしてみてください。

デバッグは「debug」モジュールパラメータを使用して有効にできます。値が0の場合はデバッグが無効になり、1の場合は無効なサンプルのトレースが有効になり、2の場合はすべてのサンプルがトレースされます：

modprobe appletouch debug=1

または:

echo "1" > /sys/module/appletouch/parameters/debug
