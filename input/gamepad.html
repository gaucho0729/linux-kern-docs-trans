4. Linux Gamepad Specification¶

著者

2013 by David Herrmann <dh.herrmann@gmail.com>

4.1. はじめに¶

Linuxはゲームパッドハードウェア用のさまざまな入力ドライバを提供しています。各ゲームパッドごとに異なるボタンマッピングをユーザー空間で処理するのを避けるため、このドキュメントではゲームパッドがデータを報告する仕様を定義しています。

4.2. 構造¶

「ゲームパッド」として、以下のような見た目のデバイスを定義します:

          ____________________________              __
         / [__ZL__]          [__ZR__] \               |
        / [__ TL __]        [__ TR __] \              | Front Triggers
     __/________________________________\__         __|
    /                                  _   \          |
   /      /\           __             (N)   \         |
  /       ||      __  |MO|  __     _       _ \        | Main Pad
 |    <===DP===> |SE|      |ST|   (W) -|- (E) |       |
  \       ||    ___          ___       _     /        |
  /\      \/   /   \        /   \     (S)   /\      __|
 /  \________ | LS  | ____ |  RS | ________/  \       |
|         /  \ \___/ /    \ \___/ /  \         |      | Control Sticks
|        /    \_____/      \_____/    \        |    __|
|       /                              \       |
 \_____/                                \_____/

     |________|______|    |______|___________|
       D-Pad    Left       Right   Action Pad
               Stick       Stick

                 |_____________|
                    Menu Pad

ほとんどのゲームパッドは以下の機能を持っています:

  • アクションパッド 右側にあるダイヤモンド型の4つのボタン。ほとんどのデバイスではボタンのラベルが異なりますので、ここでは NORTH、SOUTH、WEST、EAST と定義します。

  • Dパッド（方向パッド） 左側にある上、下、左、右を指す4つのボタン。

  • メニュー・パッド 異なる配置がありますが、ほとんどの場合2つのボタン: SELECT - START さらに、多くのゲームパッドには特別なシステムボタンとして使用される豪華なブランドボタンがあります。このボタンは他のボタンと見た目が異なり、システムメニューまたはシステム設定を表示するために使用されます。

  • アナログスティック アナログスティックは自由に動かせるスティックで方向を制御します。すべてのデバイスが両方またはいずれかを備えているわけではありませんが、ほとんどの場合存在します。アナログスティックはスティックを押すことでデジタルボタンも提供することがあります。

  • トリガー トリガーはパッドの上部に垂直方向に配置されています。すべてのデバイスが提供しているわけではありませんが、上部のボタンは通常 Left-Trigger および Right-Trigger と名付けられ、下部のボタンは Z-Left および Z-Right と呼ばれます。

  • 振動（Rumble） 複数のデバイスがフォースフィードバック機能を提供していますが、ほとんどは単純な振動モーターです。

4.3. 検出¶

このドキュメントで説明するプロトコルに準拠するすべてのゲームパッドは BTN_GAMEPAD にマッピングされます。これは BTN_SOUTH/BTN_A の別名です。ゲームパッドを識別するために使用できます。ただし、すべてのゲームパッドがすべての機能を提供しているわけではありませんので、必要な機能についてはまずテストする必要があります。各機能のマッピング方法は以下に記載されています。

レガシードライバはこれらの規則に準拠していないことがよくあります。後方互換性のため変更できないため、ユーザー空間で修正マッピングを提供する必要があります。一部のドライバはマッピングを変更するモジュールオプションを提供している場合がありますので、ユーザーにこれらの設定をすることを推奨できます。

すべての新しいゲームパッドはこのマッピングに準拠する必要があります。準拠していない場合は、バグを報告してください。

このようなプロトコルのボタンを再利用している、機能や性能が限定されたデバイスは多く存在します。しかし、それらは互換性を保ちながら実装されています。たとえば、「Nintendo Wii Nunchuk」は2つのトリガーボタンと1つのアナログスティックを提供しますが、これらを「1つのアナログスティックと右側に2つのトリガーボタンを持つゲームパッド」として報告します。このため、もし「本格的な」ゲームパッドのみをサポートする場合、必要なすべての報告されたイベントをテストする必要があります。そうでない場合、一部のイベントのみを報告するデバイスも検出されることになります。

他のゲームパッドに似ず、見た目や感触がゲームパッドとは異なるデバイスは、これらのイベントを報告してはいけません。

4.4. イベント¶

ゲームパッドは以下のイベントを報告します:

  • アクションパッド:

    すべてのゲームパッドデバイスは少なくとも2つのアクションボタンを持っています。これは、すべてのデバイスがBTN_SOUTH（BTN_GAMEPADはこれの別名です）を報告することを意味します。ボタンのラベルに関係なく、コードはボタンの物理的位置に基づいて送信されます。

    2〜3ボタンのパッドは比較的レアで古く、あなたはすべての4つのイベントを報告するゲームパッドのみをフィルタリングしたいかもしれません。

    • 2ボタンパッド:

      2つのアクションボタンしかない場合、それらはBTN_SOUTHとBTN_EASTとして報告されます。縦方向のレイアウトでは上側のボタンがBTN_EAST、水平方向のレイアウトでは右側のボタンがBTN_EASTです。

    • 3ボタンパッド:

      3つのアクションボタンしかない場合、左から右へはBTN_WEST、BTN_SOUTH、BTN_EASTとして報告されます。ボタンが完全に垂直に並んでいる場合、上から下へはBTN_WEST、BTN_SOUTH、BTN_EASTとして報告されます。

    • 4ボタンパッド:

      すべての4つのアクションボタンがある場合、それらは2つの異なる配置で報告されます。ダイヤモンド型の場合は、物理的な位置に基づいてBTN_NORTH、BTN_WEST、BTN_SOUTH、BTN_EASTとして報告されます。長方形型の場合は、左上がBTN_NORTH、左下がBTN_WEST、右下がBTN_SOUTH、右上がBTN_EASTです。

  • D-Pad:

    すべてのゲームパッドは上、下、左、右の4方向を持つD-Padを提供します。一部はデジタルボタンとして、一部はアナログボタンとして、また両方を報告するものもあります。カーネルはこれらを変換しないので、アプリケーションはどちらもサポートし、両方報告された場合にどちらが適切かを選択する必要があります。

    • デジタルボタンは以下の通り報告されます:

      BTN_DPAD_*

    • アナログボタンは以下の通り報告されます:

      ABS_HAT0XとABS_HAT0Y

    (ABS値では、負は左/上、正は右/下を表します)

  • アナログスティック:

    左のアナログスティックはABS_X、ABS_Yとして報告されます。右のアナログスティックはABS_RX、ABS_RYとして報告されます。ゼロ、ワン、またはツーつのスティックが存在する可能性があります。アナログスティックがデジタルボタンを提供する場合、BTN_THUMBL（左/最初）とBTN_THUMBR（右/第二）としてマッピングされます。

    (ABS値では、負は左/上、正は右/下を表します)

  • トリガー:

    トリガー・ボタンはデジタルボタンまたはアナログボタン、あるいは両方として利用可能である場合があります。ユーザー・スペースはすべての状況に対応し、最も適切なモードを選択する必要があります。

    上部のトリガー・ボタンはBTN_TRまたはABS_HAT1X（右）およびBTN_TLまたはABS_HAT1Y（左）として報告されます。下部のトリガー・ボタンはBTN_TR2またはABS_HAT2X（右/ZR）およびBTN_TL2またはABS_HAT2Y（左/ZL）として報告されます。

    上部と下部のトリガー・ボタンの組み合わせが1つだけ存在する場合、これらは「右」トリガーとして報告されます（BTN_TR/ABS_HAT1X）。

    (ABSトリガー値は0から始まり、圧力は正の値として報告されます)

  • メニュー・パッド:

    メニュー・ボタンは常にデジタルであり、ラベルではなく位置に基づいてマッピングされます。つまり：

    • 1ボタンパッド:

      BTN_STARTとしてマッピングされます

    • 2ボタンパッド:

      左ボタンはBTN_SELECTとして、右ボタンはBTN_STARTとしてマッピングされます

    多くのパッドには、ブランド名や特別な記号・意味を持つ第3のボタンも含まれています。このようなボタンはBTN_MODEとしてマッピングされます。例として、ニンテンドーの「ホーム」ボタン、Xboxの「X」ボタン、ソニーの「PS」ボタンがあります。

  • 振動:

    振動はFF_RUMBLEとして宣伝されています。
