6.1. はじめに¶

Linux用のジョystickドライバは、さまざまなジョystickや類似デバイスのサポートを提供します。これはLinuxですべての入力デバイスをサポートする大規模なプロジェクトに基づいています。

このプロジェクトのメールリストは以下の通りです：

linux-input@vger.kernel.org

majordomoに「subscribe linux-input」と送信して linux-inputを購読するには@vger.kernel.org For basic usage you just choose the right options in kernel config and you should be set.

6.2. 使い方¶

基本的な使用方法では、カーネル設定で適切なオプションを選択すれば問題ありません。

6.2.1. ユーティリティ¶

テストやその他の目的（シリアルデバイスなど）には、以下のユーティリティが用意されています、通常はパッケージ化されています： jstest, jscal, and evtest、通常はパッケージ化されています joystick, input-utils, evtestなど。

inputattach シリアルポートに接続されたジョystickを使用する場合は、このユーティリティが必要です。

6.2.2. デバイスノード¶

アプリケーションがジョystickを使用できるようにするには、/devにデバイスノードを作成する必要があります。通常はシステムが自動で行いますが、手動で行うことも可能です：

cd /dev
rm js*
mkdir input
mknod input/js0 c 13 0
mknod input/js1 c 13 1
mknod input/js2 c 13 2
mknod input/js3 c 13 3
ln -s input/js0 js0
ln -s input/js1 js1
ln -s input/js2 js2
ln -s input/js3 js3

inpututilsでテストする際には、これらを生成しておくと便利です：

mknod input/event0 c 13 64
mknod input/event1 c 13 65
mknod input/event2 c 13 66
mknod input/event3 c 13 67

6.2.3. 必要なモジュール¶

すべてのジョystickドライバが動作するには、カーネルにユーザー空間インターフェースモジュールが必要です（ロード済みまたはコンパイル込み）：

modprobe joydev

ゲームポートジョystickを使用する場合は、ゲームポートドライバもロードする必要があります：

modprobe ns558

シリアルポートジョystickを使用する場合は、シリアル入力ラインディスクリミナートモジュールをロードし、inputattachユーティリティを起動する必要があります：

modprobe serport
inputattach -xxx /dev/tts/X &

さらに、ジョystickドライバモジュール自体が必要です。通常はアナログジョystickを使用します：

modprobe analog

自動モジュールロードを行うには、以下のような設定が役立つかもしれません（必要に応じて調整してください）：

alias tty-ldisc-2 serport
alias char-major-13 input
above input joydev ns558 analog
options analog map=gamepad,none,2btn

6.2.4. 動作確認¶

ジョystickドライバの機能をテストするには、ユーティリティパッケージ内のjstestプログラムを使用します。実行には以下のように入力します：

jstest /dev/input/js0

これにより、ジョystickの値が表示され、スティックを動かしたりボタンを押すと更新されます。スティックが中心位置にあるとき、すべての軸はゼロになる必要があります。それ以外の位置でも安定し、-32767から32767までの範囲をカバーする必要があります。すべての条件が満たされれば問題ありませんので、ゲームをプレイできます。:)

満たされない場合は、問題がある可能性があります。ジョystickを校正してみてください。それでも動作しない場合は、このファイルのドライバセクション、トラブルシューティングセクション、FAQを参照してください。

6.2.5. 校正¶

ほとんどのジョystickでは手動校正は必要ありません。ドライバが自動で校正を行います。ただし、線形抵抗を使わないアナログジョystickや、より高い精度を求める場合はjscalプログラムを使用できます：

jscal -c /dev/input/js0

ジョystickパッケージに含まれており、ドライバーが自動で選ぶよりも優れた補正係数を設定できます。

ジョystickを校正した後、jstestコマンドを使用して新しい校正が気に入っているか確認できます。気に入れば、補正係数をファイルに保存できます：

jscal -p /dev/input/js0 > /etc/joystick.cal

さらに、そのファイルを実行するための行をrcスクリプトに追加してください：

source /etc/joystick.cal

この方法で、次回の再起動後もジョystickが校正された状態で維持されます。また、 jscal -p シャットダウンスクリプトにもその行を追加できます。

6.3.1. アナログジョystick¶

analog.cはゲームポートの標準アナログ入力を使用し、したがってすべての標準ジョystickとゲームパッドをサポートします。これには非常に高度なルーチンを使用しており、他のシステムでは見られないデータ精度を実現しています。

また、CH Flightstick Pro、ThrustMaster FCS、または6および8ボタンゲームパッドと互換性のある追加のハットやボタンなどの拡張もサポートしています。Saitek Cyborgの「デジタル」ジョystickもこのドライバーでサポートされています。これらは基本的にCHFスタックの改良版です。

ただし、自動検出可能なタイプは次の通りです：

  • 2軸、4ボタンジョystick

  • 3軸、4ボタンジョystick

  • 4軸、4ボタンジョystick

  • Saitek Cyborgの「デジタル」ジョystick

他のジョystickタイプ（軸、ハット、ボタンの数がより多い/少ない）をサポートする場合は、カーネルコマンドラインまたはモジュールコマンドラインでタイプを指定する必要があります。analogをカーネルに挿入する際には、以下のパラメータを使用します：

analog.map=<type1>,<type2>,<type3>,....

6.3.2. Microsoft SideWinder ジョystick¶

Microsoft ‘Digital Overdrive’ プロトコルはsidewinder.cモジュールでサポートされています。現在サポートされているすべてのジョystick:

  • Microsoft SideWinder 3D Pro

  • Microsoft SideWinder Force Feedback Pro

  • Microsoft SideWinder Force Feedback Wheel

  • Microsoft SideWinder FreeStyle Pro

  • Microsoft SideWinder GamePad (最大4台、チェーン接続)

  • Microsoft SideWinder Precision Pro

  • Microsoft SideWinder Precision Pro USB

は自動検出されるため、モジュールパラメータは必要ありません。

3D Proには1つ注意点があります。9つのボタンが報告されるものの、ジョystickには8つのみが存在します。9番目のボタンはジョystickの裏側にあるモードスイッチです。ただし、これを動かすとジョystickがリセットされ、約1/3秒間応答しなくなります。さらに、ジョystickはその間の位置を新たな中心位置とみなして再中心化します。使用は自由ですが、動作をよく理解した上で行うことをお勧めします。

SideWinder Standardはデジタルジョystickではなく、したがって上記のアナログドライバーでサポートされます。

6.3.3. Logitech ADI デバイス¶

Logitech ADI プロトコルはadi.cモジュールでサポートされています。これはLogitechがこのプロトコルを使用するすべてのデバイスをサポートするはずです。これは以下の例に限らず、以下の通りです:

  • Logitech ThunderPad Digital

  • Logitech WingMan Extreme Digital

  • Logitech WingMan Formula

  • Logitech WingMan GamePad

  • Logitech WingMan GamePad Extreme

  • Logitech WingMan Extreme Digital 3D

ADIデバイスは自動検出され、1つのゲームポートにYケーブルまたはチェーンで接続した場合でも、最大2つの（任意の組み合わせの）デバイスをサポートしています。

Logitech WingMan Joystick、Logitech WingMan Attack、Logitech WingMan Extreme、Logitech WingMan ThunderPadはデジタルジョイスティックではなく、上記のアナログドライバーで処理されます。Logitech WingMan WarriorおよびLogitech Magellanは以下のシリアルドライバーでサポートされています。Logitech WingMan ForceおよびLogitech WingMan Formula Forceは以下のI-Forceドライバーでサポートされています。Logitech CyberManは現時点ではサポートされていません。

6.3.4. Gravis GrIP¶

Gravis GrIPプロトコルはgrip.cモジュールでサポートされています。現在サポートしているデバイスは以下の通りです。

  • Gravis GamePad Pro

  • Gravis BlackHawk Digital

  • Gravis Xterminator

  • Gravis Xterminator DualControl

これらのすべてのデバイスは自動検出され、1つのゲームポートにYケーブルまたはチェーンで接続した場合でも、最大2つのパッドを組み合わせて使用できます。

GrIP MultiPortは現時点ではサポートされていません。Gravis Stingerはシリアルデバイスであり、stingerドライバーでサポートされています。その他のGravisジョイスティックはアナログドライバーでサポートされています。

6.3.5. FPGaming A3DおよびMadCatz A3D¶

FPGamingが開発したAssassin 3Dプロトコルは、FPGaming自身が使用しており、MadCatzにもライセンスされています。A3Dデバイスはa3d.cモジュールでサポートされています。現在サポートしているデバイスは以下の通りです。

トラックボールはUSB mousedevモジュールで通常のマウスとして動作します。USBマウスの設定方法についてはUSBドキュメンテーションを参照してください。

6.3.10. PDPI Lightning 4ゲームカード¶

PDPI Lightning 4ゲームカードはlightning.cモジュールによってサポートされています。モジュールがロードされるとアナログドライバーを使用してジョイストicksを処理できます。デジタル通信ジョイストicksはポート0のみで動作し、Yケーブルを使用して1つのL4カードに最大8台のアナログジョイストicksを接続可能です。2台のカードをシステムに搭載すれば最大16台まで接続可能です。

6.3.11. Trident 4DWave / Aureal Vortex¶

Trident 4DWave DX/NXまたはAureal Vortex/Vortex2チップセット搭載のサウンドカードは「拡張ゲームポート」モードを提供します。このモードではサウンドカードがジョイストickのポーリングを処理します。このモードはpcigame.cモジュールによってサポートされています。モジュールがロードされると、これらのゲームポートの拡張機能をアナログドライバーが利用できます。

6.3.12. Crystal SoundFusion¶

Crystal SoundFusionチップセット搭載のサウンドカードは4DWaveやVortexと同様の「拡張ゲームポート」を提供します。この機能およびSoundFusionポートの通常モードはcs461x.cモジュールによってサポートされています。

6.3.13. SoundBlaster Live!¶

Live!は特別なPCIゲームポートを搭載しており、4DWaveやその他の製品のように拡張機能は提供しませんが、ISA版よりもはるかに高速です。また特別なサポートが必要なため、通常のns558.cモジュールではなくemu10k1-gp.cモジュールが使用されます。

6.3.14. SoundBlaster 64 and 128 - ES1370 and ES1371, ESS Solo1 and S3 SonicVibes¶

これらのPCIサウンドカードは特定のゲームポートを搭載しています。これらはサウンドドライバー自身によって処理されます。適切なカードのゲームポートサポートとサウンドカードサポートをjoystickメニューとsoundメニューで選択してください。

6.3.16. ゲームコンソールおよび8ビットのパッドとジョイスティック¶

これらのパッドとジョイスティックはPCやLinuxが動作する他のコンピュータ用に設計されていません。通常はパラレルポート経由で接続するための特別なコネクタが必要です。

参照 パラレルポート ジョイストリックドライバー を参照してください。

6.3.17. SpaceTec/LabTecデバイス¶

SpaceTecシリアルデバイスはSpaceWareプロトコルを使用して通信します。これはspaceorb.cおよびspaceball.cドライバでサポートされています。現在spaceorb.cでサポートされているデバイスは以下の通りです：

  • SpaceTec SpaceBall Avenger

  • SpaceTec SpaceOrb 360

spaceball.cでサポートされているデバイスは以下の通りです：

  • SpaceTec SpaceBall 4000 FLX

kernelにspaceorb/spaceballおよびserportモジュールをインストールしている必要があります。シリアルポートをドライバに接続するにはinputattachプログラムを実行してください：

inputattach --spaceorb /dev/tts/x &

または:

inputattach --spaceball /dev/tts/x &

ここで/dev/tts/xはデバイスが接続されているシリアルポートです。この操作を実行すると、デバイスが検出され動作を開始します。

SpaceOrbの注意点があります。ボタン#6（ボールの底面にあるボタン）は通常のボタンとして報告されるものの、内部の再センタリングを引き起こし、ゼロポイントをボタンを押した瞬間のボールの位置に移動させます。他の機能に割り当てる前にこの動作をよく考慮してください。

SpaceTec SpaceBall 2003 FLXおよび3003 FLXは現在サポートされていません。

6.3.18. Logitech SWIFTデバイス¶

SWIFTシリアルプロトコルはwarrior.cモジュールでサポートされています。現在サポートされているのは以下の通りです：

  • Logitech WingMan Warrior

今後、Logitech CyberMan（オリジナルのもの、CM2ではない）もサポートされる可能性があります。モジュールを使用するには、モジュールをカーネルにインサート/コンパイルした後、inputattachを実行してください：

inputattach --warrior /dev/tts/x &

/dev/tts/xはWarriorが接続されているシリアルポートです。

6.3.19. Magellan / Space Mouse¶

LogiCad3d（以前はSpace Systems）によって製造され、多くの他の企業（Logitech、HPなど）で使用されるMagellan（またはSpace Mouse）はjoy-magellanモジュールでサポートされています。現在サポートされているのは以下の通りです：

  • Magellan 3D

  • Space Mouse

モデルについては、'Plus'版の追加ボタンは現在サポートされていません。

使用するには、以下のコマンドを使用してシリアルポートをドライバに接続する必要があります：

inputattach --magellan /dev/tts/x &

コマンドを実行すると、Magellanが検出され、初期化され、ビープ音が鳴り、/dev/input/jsXデバイスが使用可能になります。

6.3.20. I-Forceデバイス¶

すべてのI-Forceデバイスはiforceモジュールでサポートされています。これは以下の通りです：

  • AVB Mag Turbo Force

  • AVB Top Shot Pegasus

  • AVB Top Shot Force Feedback Racing Wheel

  • Logitech WingMan Force

  • ロジテック ワイングマン フォースホイール

  • ギルレモット レースリーダー フォースフィードバック

  • ギルレモット フォースフィードバック ライディングホイール

  • スラストマスター モータースポーツGT

使用するには、以下のコマンドを使用してシリアルポートをドライバに接続する必要があります：

inputattach --iforce /dev/tts/x &

コマンドを実行します。その後、I-Forceデバイスが検出され、/dev/input/jsXデバイスが使用可能になります。

USBポート経由でデバイスを使用している場合、inputattachコマンドは必要ありません。

I-Forceドライバーは現在、イベントインターフェース経由でのフォースフィードバックをサポートしています。

注意点として、ロジテック ワイングマン3Dデバイスはこのモジュールではサポートされていません。hidを介してサポートされています。フォースフィードバックはこれらのデバイスではサポートされていません。ロジテック ゲームパッドもhidデバイスです。

6.3.21. グラビス スティングラゲームパッド¶

グラビス スティングラシリアルポートゲームパッドは、ラップトップコンピュータで使用することを目的としており、stinger.cモジュールでサポートされています。使用するには、シリアルポートをドライバーに接続します:

inputattach --stinger /dev/tty/x &

ここでxはシリアルポートの番号です。

6.4. トラブルシューティング¶

ドライバーで問題が発生する可能性が非常に高いです。ドライバーが動作するかテストする場合は、疑問がある場合はjstestユーティリティのいくつかのモードを使用してください。最も役に立つモードは「normal」（1.xインターフェース用）と「old」（0.xインターフェース用）です。実行には以下のようにタイプします:

jstest --normal /dev/input/js0
jstest --old    /dev/input/js0

さらにevtestユーティリティを使用してテストすることもできます:

evtest /dev/input/event0

おっと、FAQを読むのを忘れないでください！:)

6.5. よくある質問¶

Q

「jstest /dev/input/js0」を実行すると「ファイルが見つからない」エラーが発生します。原因は何ですか？

A

Q

古いアタリ/コモドール/アミガ/コンソールのジョイストリックやパッド（9ピンD型コネクタ）をPCのシリアルポートに接続できますか？

A

はい、可能です。ただしシリアルポートやパッドを焼損する可能性があります。もちろん動作しません。

Q

私のジョイストリックがクォーク/クォーク2で動作しません。原因は何ですか？

A

クォーク/クォーク2はジョイストリックをサポートしていません。joy2keyを使用してキーピンチをシミュレートしてください。
