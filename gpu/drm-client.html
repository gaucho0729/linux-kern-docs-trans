カーネルクライアント¶

このライブラリは、fbdev および bootsplash などのカーネル内で実行されるクライアントをサポートします。

GEMベースのドムバッファを仮想アドレスで提供する GEM ドライバはサポートされています。

struct drm_client_funcs¶

DRM クライアント コールバック

定義

struct drm_client_funcs {
  struct module *owner;
  void (*unregister)(struct drm_client_dev *client);
  int (*restore)(struct drm_client_dev *client);
  int (*hotplug)(struct drm_client_dev *client);
};

メンバ

owner

モジュール所有者

unregister

呼び出されるタイミング drm_device 登録が解除される。クライアントは、リソースを解放するために次の関数を使用して応答する必要があります drm_client_release().

このコールバックはオプションです。

restore

drm_lastclose() が呼ばれる際。リスト内の最初にゼロを返すクライアントインスタンスは復元の権限を得、以降のクライアントは呼ばれない。このコールバックはその後呼ばれない 登録解除 が呼び出されています。

コアはコンカレンテアクセスに対する排他性を保証しないことに注意してください。 drm_open()クライアントはこれを自身で確保する必要があります。たとえば、drm_master_internal_acquire() と drm_master_internal_release() を使用して

このコールバックはオプションです。

hotplug

呼び出されるタイミング drm_kms_helper_hotplug_event()このコールバックはその後呼ばれない 登録解除 が呼び出されています。

このコールバックはオプションです。
