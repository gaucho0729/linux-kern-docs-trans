drm/meson AmLogic Mesonビデオ処理ユニット¶

VPU はグローバルなビデオ処理を担当し、クロックゲート、ブロックリセットライン、電源ドメインの管理を含みます。

不足しているもの:

  • ビデオ処理HWブロック全体のフルリセット

  • VPU クロックのスケーリングおよび設定

  • バスクロックゲート

  • ビデオ処理HWブロックの電源投入

  • HDMI コントローラーおよびPHYの電源投入

ビデオ処理ユニット¶

Amlogic Meson ディスプレイコントローラーは、以下に記載するいくつかのコンポーネントから構成されています:

DMC|---------------VPU (Video Processing Unit)----------------|------HHI------|
   | vd1   _______     _____________    _________________     |               |
D  |-------|      |----|            |   |                |    |   HDMI PLL    |
D  | vd2   | VIU  |    | Video Post |   | Video Encoders |<---|-----VCLK      |
R  |-------|      |----| Processing |   |                |    |               |
   | osd2  |      |    |            |---| Enci ----------|----|-----VDAC------|
R  |-------| CSC  |----| Scalers    |   | Encp ----------|----|----HDMI-TX----|
A  | osd1  |      |    | Blenders   |   | Encl ----------|----|---------------|
M  |-------|______|----|____________|   |________________|    |               |
___|__________________________________________________________|_______________|

ビデオ入力ユニット¶

VIU はピクセルスキャンアウトおよび基本的なカラースペース変換を担当します。対応する機能は以下の通りです:

  • OSD1 RGB565/RGB888/xRGB8888 スキャンアウト

  • RGB から x/cb/cr への変換

  • プログレッシブまたはインターレースバッファスキャンアウト

  • OSD1 Vsync でのコミット

  • GXL/GXM 用 HDR OSD マトリクス

不足しているもの:

  • BGR888/xBGR8888/BGRx8888/BGRx8888 モード

  • YUV4:2:2 Y0CbY1Cr スキャンアウト

  • 4:2:2 入力から YUV 4:4:4 への変換

  • カラーキー アルファマッチング

  • ビッグエンディアン スキャンアウト

  • X/Y 反転スキャンアウト

  • グローバル アルファ設定

  • OSD2 サポート（インターレーススイッチングを Vsync で必要）

  • TV オーバースキャンをサポートする OSD1 フルスケーリング

ビデオ後処理¶

VPP は VIU からのスキャンアウト後のすべてのポスト処理を担当します。対応するポスト処理は以下の通りです:

  • ポストブレンド、OSD1 だけをブレンド

    OSD2、VS1、VS1 およびプレブレンド出力を除外

  • OSD1 用の垂直 OSD スケーラー、垂直スケーラーを無効化し、

    インターレーススキャンアウトにのみ使用

  • 中間 FIFO および Amlogic のデフォルト値

不足しているもの:

  • ビデオオーバーレイのプレスケーリング用プレブレンド

  • カーソルフレームバッファ用 OSD2 サポート

  • ポストブレンド前のビデオプレスケーリング

  • TV オーバースキャンをサポートするフル垂直/水平 OSD スケーリング

  • HDR 変換

ビデオエンコーダー¶

VENC はピクセルを出力形式にエンコードします。対応するエンコードは以下の通りです:

  • ENCI エンコーダーおよび VDAC デジタル・アナログ変換器を介した CVBS エンコード

  • TMDS/HDMI エンコード（ENCI_DIV および ENCP を介して）

  • HDMI モード用のより多くのクロックレートの設定

不足しているもの:

  • ENCL を介した LCD パネルエンコード

  • TVパネルの符号化はENCTを介して行われます

VENC経路:

       _____   _____   ____________________
vd1---|     |-|     | | VENC     /---------|----VDAC
vd2---| VIU |-| VPP |-|-----ENCI/-ENCI_DVI-|-|
osd1--|     |-|     | | \                  | X--HDMI-TX
osd2--|_____|-|_____| |  |\-ENCP--ENCP_DVI-|-|
                      |  |                 |
                      |  \--ENCL-----------|----LVDS
                      |____________________|

ENCIはPALまたはNTSC符号化のために設計されており、CVBS符号化にはVDA直接経路を、HDMIにはENCI_DVI符号化器を経由します。ENCPはプログレッシブ符号化のために設計されていますが、1080iのインターレースピクセルも生成可能です。当初はVDACへのピクセル符号化のために設計されており、その出力はENCP_DVI符号化器を経由してHDMIにのみ使用されます。ENCL LVDS符号化器は実装されていません。

ENCIおよびENCP符号化器は各サポートモードに特化したパラメータを必要とし、標準的なビデオタイミングから決定することはできません。

ENCIおよびENCPのDVI符号化器はより汎用的で、ENCIまたはENCPから生成されるピクセルデータに基づいて任意のタイミングを生成できるため、標準的なビデオタイミングをHWパラメータのソースとして使用可能です。

ビデオクロック¶

VCLKは専用PLLから生成される「ピクセルクロック」周波数ジェネレータです。以下を処理します:

  • CVBS 27MHzジェネレータはVCLK2を介してVENCIおよびVDACブロックに送信されます

  • HDMIピクセルクロックジェネレータ

不足しているもの:

  • 2K/4K 10bit形式のピクセルクロック生成

クロックジェネレータスキーム:

 __________   _________            _____
|          | |         |          |     |--ENCI
| HDMI PLL |-| PLL_DIV |--- VCLK--|     |--ENCL
|__________| |_________| \        | MUX |--ENCP
                          --VCLK2-|     |--VDAC
                                  |_____|--HDMI-TX

最終クロックはVCLKまたはVCLK2の入力を受けますが、HDMIクロッキングにはVCLKが優先され、CVBS VDACクロッキングにはVCLK2が優先されます。

VCLKおよびVCLK2は/1、/2、/4、/6または/12の固定された割り当てられたクロック経路を持ちます。

PLL_DIVは1.5、3.5、3.75…などの分数除算を実現し、特殊な2Kおよび4K 10bitクロックを生成します。

HDMIビデオ出力¶

HDMI出力は以下の構成で構成されています:

  • Synopsys DesignWare HDMIコントローラーIP

  • クロックおよびPHYを制御するTOP制御ブロック

  • ビデオをTMDS信号に変換するためのカスタムHDMI PHY

 ___________________________________
|            HDMI TOP               |<= HPD
|___________________________________|
|                  |                |
|  Synopsys HDMI   |   HDMI PHY     |=> TMDS
|    Controller    |________________|
|___________________________________|<=> DDC

HDMI TOPブロックはHPD検出のみをサポートしています。Synopsys HDMIコントローラーの割り込みはTOPブロックの割り込み経路を通じて処理されます。TOPブロックおよびSynopsys HDMIコントローラーとの通信はアドレス+読み書きレジスタペアで行われます。HDMI PHYはHHIレジスタブロック内のレジスタで設定されます。

ピクセルデータはVDACブロックから4:4:4形式で到達し、VPU HDMI マルチプレクサは576iまたは480i形式のためENCI符号化器、または他のすべての形式（インターレースHD形式を含む）のためENCP符号化器を選択します。VDACはENCIまたはENCP符号化器の上にDVI符号化器を搭載し、HDMIコントローラーのDVIタイミングを生成します。

GXBB、GXLおよびGXMはSynopsys DesignWare HDMI TX IPバージョン2.01aを搭載しており、HDCPおよびI2C & S/PDIFオーディオソースインターフェースをサポートしています。

以下を処理します:

  • HPD上昇および下降割り込み

  • HDMIコントローラー割り込み

  • 480iから1080p60へのHDMI PHY初期化

  • VENC & HDMI クロック設定（480i → 1080p60）

  • VENC モード設定（480i → 1080p60）

不足しているもの:

  • PHY、クロックおよびモード設定（2k && 4k モード）

  • SDDC シャッフルモード（HDMI 2.0a）

  • HDCP 設定

  • CEC 管理
