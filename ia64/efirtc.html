EFIリアルタイムクロックドライバ¶

  1. Eranian <eranian@hpl.hp.com>

2000年3月

1. はじめに¶

このドキュメントは、IA-64プラットフォーム用に提供されているefirtc.cドライバについて説明しています。

このドライバの目的は、EFIバージョン0.92が提供するタイムサービスにカーネルおよびユーザーアプリケーションがアクセスできるようにするAPIを提供することです。

EFIはOSが起動した後に実行できる4つのコールを提供しており、GetTime()、SetTime()、GetWakeupTime()、SetWakeupTime()の4つがすべてこのドライバでサポートされています。以下ではこれらのコールとドライバの設計について説明します。

2. 設計決定¶

元々の目的は、時間のサービスにアクセスするための非常にシンプルなドライバを提供することでした。これは、CMOSクロックをポータブルにアクセスするために必要な機能です。/sbin/hwclockというプログラムは、起動時にシステムの時間のビューを初期化するためにこのようなクロックを使用します。

既存のユーザー層アプリケーションがCMOSクロックを使用している影響を最小限に抑えるため、legacy RTCドライバ（driver/char/rtc.c）で使用されているAPIと非常に似たAPIを公開することにしました。しかしEFIはより単純なサービスを提供するため、すべてのioctl()が利用可能ではありません。また、EFIが提供するがlegacyが提供しない機能には新しいioctl()が導入されています。

EFIは時間の表現方法がやや異なります。特に参照日付が異なり、年は4桁の形式で使用されます。エポックは1998年1月1日です。後方互換性のため、この新しい時間表現を公開していません。代わりに、hwclockで使用されているstruct rtc_timeと非常に似た構造体を使用しています。これにより、EFIが進化してもユーザーアプリケーションに影響を与えることなく、柔軟性を保つことができます。

ドライバは2つのインターフェースを提供しており、1つはデバイスファイルとioctl()を通じたインターフェース、もう1つは/procファイルシステムを介した読み取り専用インターフェースです。

現在では/proc/sysインターフェースは提供していません。

legacy RTCとEFIタイムサービスの統一インターフェースを提供するために、include/linux/rtc.hヘッダーファイルを作成しました。これは2つのドライバの「公開」APIを含みます。legacy RTCの詳細は依然としてinclude/linux/mc146818rtc.hにあります。

3. 時間のサービス¶

ドライバのこの部分はEFIの時間のサービスにアクセスするためのものです。legacy RTCコールと互換性のある2つのioctl()、

CMOSクロックを読み取る：

ioctl(d, RTC_RD_TIME, &rtc);

CMOSクロックを書き込む：

ioctl(d, RTC_SET_TIME, &rtc);

rtc は rtc.h で定義されたデータ構造へのポインタであり、struct tm に近い形式です:

struct rtc_time {
        int tm_sec;
        int tm_min;
        int tm_hour;
        int tm_mday;
        int tm_mon;
        int tm_year;
        int tm_wday;
        int tm_yday;
        int tm_isdst;
};

ドライバは EFI 時間とこの形式の間での変換を担当します。

これらの 2 つの ioctl() は hwclock コマンドでテストできます:

読み取りの場合:

# /sbin/hwclock --show
Mon Mar  6 15:32:32 2000  -0.910248 seconds

設定の場合:

# /sbin/hwclock --systohc

時刻を設定するには root 権限が必要です。

4. ウェイクアップアラームサービス¶

EFI は、マシンがいつ起動すべきかを設定する API を提供しています。これは、従来の RTC が提供するインターバルタイマーアラームとは大きく異なります。そのため、同じ ioctl() を使ってサービスにアクセスするのではなく、RTC のインターフェースに 2 つの新しい ioctl() を導入しました。

我々は EFI ドライバ専用の 2 つの新しい ioctl() をインターフェースに追加しました:

アラームの現在の状態を読み取る:

ioctl(d, RTC_WKALM_RD, &wkt)

アラームを設定するか、状態を変更する:

ioctl(d, RTC_WKALM_SET, &wkt)

wkt 構造体は struct rtc_time に加えて、ステータス情報を取得するための 2 つの追加フィールドを含みます:

struct rtc_wkalrm {

        unsigned char enabled; /* =1 if alarm is enabled */
        unsigned char pending; /* =1 if alarm is pending  */

        struct rtc_time time;
}

今日までに、既存のユーザー層アプリケーションはこの機能をサポートしていません。ただし、これらの 2 つの ioctl() を単に使用するだけで、このようなプログラムを書くことは比較的簡単です。

アラームを設定するには root 権限が必要です。
