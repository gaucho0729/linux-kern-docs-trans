ロック¶

このファイルは、PCCARDおよびPCMCIAサブシステムで使用されるロックと排他制御の仕組みについて説明しています。

A) 概要、ロック階層:¶

pcmcia_socket_list_rwsem

  • ソケットのリストのみを保護しています

  • skt_mutex

    • カードの挿入/抜き取りをシリアル化します

    • ops_mutex

      • ソケット操作をシリアル化します

B) 排他制御¶

次の関数および struct pcmcia_socket へのコールバックは、'skt_mutex' を保持しながら呼び出さなければなりません:

socket_detect_change()
send_event()
socket_reset()
socket_shutdown()
socket_setup()
socket_remove()
socket_insert()
socket_early_resume()
socket_late_resume()
socket_resume()
socket_suspend()

struct pcmcia_callback  *callback

次の関数および struct pcmcia_socket へのコールバックは、'ops_mutex' を保持しながら呼び出さなければなりません:

socket_reset()
socket_setup()

struct pccard_operations        *ops
struct pccard_resource_ops      *resource_ops;

send_event() および struct pcmcia_callback *callback は 'ops_mutex' を保持しながら呼び出さないでください。

C) 保護¶

1. グローバルデータ:¶

struct list_head pcmcia_socket_list;

pcmcia_socket_list_rwsem によって保護されています;

2. 各ソケットデータ:¶

resource_ops およびそのデータは ops_mutex によって保護されています。

「main」struct pcmcia_socket は以下の通り保護されています（読み取り専用または単一使用のフィールドは省略）:

  • pcmcia_socket_list_rwsem によって保護されています:

    struct list_head        socket_list;

  • thread_lock によって保護されています:

    unsigned int            thread_events;

  • skt_mutex によって保護されています:

    u_int                   suspended_state;
void                    (*tune_bridge);
struct pcmcia_callback  *callback;
int                     resume_status;

  • ops_mutex によって保護されています:

    socket_state_t          socket;
u_int                   state;
u_short                 lock_count;
pccard_mem_map          cis_mem;
void __iomem            *cis_virt;
struct { }              irq;
io_window_t             io[];
pccard_mem_map          win[];
struct list_head        cis_cache;
size_t                  fake_cis_len;
u8                      *fake_cis;
u_int                   irq_mask;
void                    (*zoom_video);
int                     (*power_hook);
u8                      resource...;
struct list_head        devices_list;
u8                      device_count;
struct                  pcmcia_state;

3. 各PCMCIAデバイスデータ:¶

「main」struct pcmcia_device は以下の通り保護されています（読み取り専用または単一使用のフィールドは省略）:

  • pcmcia_socket->ops_mutex によって保護されています:

    struct list_head        socket_device_list;
struct config_t         *function_config;
u16                     _irq:1;
u16                     _io:1;
u16                     _win:4;
u16                     _locked:1;
u16                     allow_func_id_match:1;
u16                     suspended:1;
u16                     _removed:1;

  • PCMCIAドライバによって保護されています:

    io_req_t                io;
irq_req_t               irq;
config_req_t            conf;
window_handle_t         win;
